# Unity에서 실제 지도 화면을 보며 3D 편집하기

## 시작

1. Unity Hub에서 저장소의 `unity/YeongtongTaxi`를 **Unity 2022.3.62f2**로 연다.
2. Play 모드를 종료하고 **Taxi → 프로젝트 지도 3D 편집 → 프로젝트 지도 열기**를 누른다.
3. `지도 3D Scene` 창과 편집 패널을 나란히 배치한다. Scene 창은 독립 미리보기 공간이므로 기존 FirstDrive 씬이나 저장하지 않은 사용자 씬을 덮어쓰지 않는다.
4. Scene에서 건물·도로 노면·보도·주차장·식당/휴식 부지를 클릭한다. 가려진 도로는 패널의 **선택 대상 → 도로 노면**을 고르거나 이름으로 검색한다.

이 화면은 실행파일의 `WorldBuilder`와 같은 메시 생성·재질·도로 표시·시설을 사용한다. 패널의 카메라 미리보기는 게임의 기본 시야각 62도/표시 거리 700m를 사용한다. 실제 영업의 차량·승객·HUD·시간 진행은 포함하지 않는다. 먼 전체지도 시점에서는 게임 표시 거리 밖이 잘리므로 **F**로 선택 대상 가까이 이동한다. `운전자 높이에서 보기`는 82도 1인칭 카메라 미리보기다. 최종 진입·충돌·운전 감각은 새로 빌드한 exe에서 확인한다.

## 직접 조작

| 할 일 | 조작 |
|---|---|
| 선택 | Scene에서 면 클릭, 또는 패널 이름 검색 |
| 이동 | **W**, 화살표/평면 손잡이 드래그. X/Z 수평 이동만 반영 |
| 방향 | **E**, 수평 원형 손잡이 드래그 |
| 크기 | **R**, X/Z 크기 또는 건물 높이 손잡이 드래그 |
| 정확한 높이·도로 폭 | 패널의 m 단위 숫자 입력 |
| 모양 | **꼭짓점 직접 편집**을 켜고 점 이동. 자기 교차·중복점 등 잘못된 다각형은 거부 |
| 화면 이동 | **F** 또는 **선택으로 이동**, Alt+드래그로 회전, 휠로 확대/축소 |
| 실행취소 | Ctrl+Z / Ctrl+Y 또는 패널 버튼. 한 번의 드래그를 하나의 작업으로 묶음 |
| Scene 창을 닫은 경우 | 편집 패널의 **3D Scene 다시 열기** |

회전·크기 기준점은 선택 객체 꼭짓점의 중심이다. 도로 R 조작은 중심선의 X/Z 배치를 조절하며 도로 폭은 별도 숫자로 수정한다. 원본 고도·지형 경사를 깨지 않도록 수직 위치 이동과 기울이기는 지원하지 않는다. 새 객체 추가/삭제나 차로 주행 그래프 편집은 기존 실행파일 편집기를 이용한다.

## 주차장·식당·휴식 부지

- 부지 전체를 선택하고 W/E/R로 면과 정차 위치를 함께 움직인다.
- **정차점만 이동·회전**을 켜면 부지 형태는 그대로 두고 노란 칸의 위치·방향을 바꾼다. 정확한 X/Z와 방향도 숫자로 입력할 수 있다.
- **지도에서 접근 차로 지정**을 누르고 Scene의 원하는 도로 근처를 클릭한다. 클릭 위치에서 20m 이내의 주행 차로와 차로 위 거리를 연결한다. 다시 버튼을 누르면 취소한다.
- 부지의 접근 노면·건물 간격도 확인한다. **도로 노면을 옮겨도 내비/NPC의 주행 차로는 자동 이동하지 않는다.** 주행 연결 변경은 기존 차로 편집기에서 수행한다.

## 저장과 다른 PC에 적용

1. **프로젝트에 저장**을 누른다. 전체 형상·차로 연결·서비스 위치 검사와 원본 파일 충돌 검사를 통과해야 정식 저장된다.
2. 바뀐 **`config/maps/project/eungye.project.json`**을 커밋·푸시한다. `.unity` 씬이나 개인 초안만 커밋하는 방식이 아니다.
3. 다른 PC에서 pull한 뒤 **Taxi → Build Eungye Hybrid**로 빌드한다.
4. 저장소 루트의 **`builds/EungyeTaxi/EungyeTaxi.exe`**를 실행한다. 기존 exe에는 이후의 지도 수정이 자동으로 반영되지 않으므로 재빌드가 필요하다.

정식 JSON에 기준 지도와 편집 문서가 함께 들어 있어 원본 GIS/재수입용 지도 JSON이 없어도 이 경로로 빌드할 수 있다. 원본 NGII/OSM이나 배포 ZIP을 다시 수정할 필요는 없다. 기존 실행파일 편집기와 같은 정식 저장 형식을 사용하므로 병행할 때에는 한 편집기에서 저장한 뒤 다른 편집기를 다시 열어 최신 내용을 읽는다. 동시에 저장하거나 pull로 파일이 바뀌면 이전 편집기의 덮어쓰기를 차단한다.

## 초안과 복구

변경 객체만 저장하는 초안은 **저장소 루트의 `Library/ProjectMapEditor/session-draft.json`**에 둔다. 마우스 조작 종료/짧은 유휴 시간, 창 닫기, Play 모드 진입, 스크립트 재컴파일 때 보존하며 다음 열기에서 자동 복구한다. 이 초안은 이 PC의 복구용이며 Git 배포 대상이 아니다.

pull이나 다른 편집기의 저장으로 초안의 기준 파일이 바뀌면 자동 복구를 중단한다. **충돌 초안 보관 후 현재 지도 편집**을 누르면 기존 초안을 같은 폴더의 `session-draft.json.preserved-...`에 남기고 최신 정식 지도를 편집한다. 보관된 이전 변경을 최신 지도에 자동 병합하지 않는다. 정식 저장이 성공하면 현재 초안은 제거한다.

## 반응 속도와 검증 범위

처음 열 때 지도 전체를 읽고 배치 메시를 만든다. 드래그 중에는 선택 객체와 영향을 받는 128m 구역만 갱신하고 전체 지도 복사/합성/검사/디스크 저장을 하지 않는다. 카메라 미리보기는 최대 초당 10회 갱신한다. 전체 검사는 정식 저장/빌드 시 수행한다.

자동 검증과 측정 결과, 수동 확인이 남은 범위는 [작업 이력](work-history/2026-10-23-unity-scene-map-editor.md)에 기록한다.
