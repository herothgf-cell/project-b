# Unity에서 실제 지도 화면을 보며 3D 편집하기

## 시작

1. Unity Hub에서 저장소의 `unity/EungyeTaxi`를 **Unity 2022.3.62f2**로 연다.
2. Play 모드를 종료하고 **Taxi → 프로젝트 지도 3D 편집 → 프로젝트 지도 열기**를 누른다.
3. `지도 3D Scene` 창과 편집 패널을 나란히 배치한다. Scene 창은 독립 미리보기 공간이므로 기존 FirstDrive 씬이나 저장하지 않은 사용자 씬을 덮어쓰지 않는다.
4. Scene에서 건물·도로 노면·보도·주차장·식당/휴식 부지를 클릭한다. 가려진 도로는 패널의 **선택 대상 → 도로 노면**을 고르거나 이름으로 검색한다.

이 화면은 실행파일의 `WorldBuilder`와 같은 메시 생성·재질·도로 표시·시설을 사용한다. 패널의 카메라 미리보기는 게임의 기본 시야각 62도/표시 거리 700m를 사용한다. 실제 영업의 차량·승객·HUD·시간 진행은 포함하지 않는다. 먼 전체지도 시점에서는 게임 표시 거리 밖이 잘리므로 **F**로 선택 대상 가까이 이동한다. `운전자 높이에서 보기`는 82도 1인칭 카메라 미리보기다. 최종 진입·충돌·운전 감각은 새로 빌드한 exe에서 확인한다.

## 주변 지도 대신 선택 테두리만 보였던 경우

2026-10-23 수정본은 독립 Scene의 표시 필터를 초기화한다. Unity 스크립트 컴파일이 끝나면 **지도 3D 편집 패널과 지도 3D Scene 창을 모두 닫고**, **Taxi → 프로젝트 지도 3D 편집 → 프로젝트 지도 열기**로 다시 연다. 기존 개인 Scene이나 지도 데이터를 지울 필요는 없다. 이 수정은 Unity 편집기 코드이므로 exe 재빌드는 필요 없다.

## 차로·일방통행·회전 화살표

기존 Esc 지도 편집 기능을 Unity 창으로 통합했다. **차로·표지·신호 → 차로**를 선택하면 Scene에 청록색 차로 경로가 겹쳐 보인다. 노란색은 선택한 차로이며 선 위 꺾쇠가 실제 진행 방향이다. Scene에서 차로를 클릭하거나 도로명 검색/같은 진입 방향의 차로 번호로 선택한다. **F** 또는 선택 위치로 이동으로 확대한다.

- **좌회전/직진/우회전**을 켜거나 끈다. 기존 출구 연결을 허용·차단하며 공유 그래프와 노면 화살표에 반영한다. 해당 출구가 없으면 **다음 차로 클릭하여 연결**로 출구를 먼저 만든다. 연결 회전과 차로변경 방향을 선택하고 Scene의 도착 차로를 클릭한다.
- **같은 도로 일방통행 설정**은 가까운 같은 도로의 반대 방향 차로 목록을 확인한 뒤 폐쇄한다. 다른 도로는 자동 폐쇄하지 않는다. 표시만 필요한 경우 일방통행 표지를 배치한다. 일방통행 표지만 놓는 것은 경로를 바꾸지 않는다.
- **차로 진행 반전**은 경로 자체를 뒤집고 기존 출입 연결을 해제한다. 이후 클릭 연결로 출구/진입을 복원하고 표지 적용 거리·정차 접근 방향을 다시 확인한다. 연결이 끊긴 지도는 검사/정식 저장에서 차단한다.
- 폭·번호·제어점 위치/높이, 점 추가/삭제, 차로 분할·평행 복제·좌회전 대기차로·삭제를 제공한다. 제어점은 Scene 손잡이로 옮길 수 있다. 점 드래그 중에는 전체 지도를 복사하지 않고 손잡이를 놓을 때 반영한다.
- 폐쇄 차로 표시를 켜면 다시 활성화할 수 있다. 교차로 원상 복원과 전체 정식 저장 상태 복원도 실행취소할 수 있다.

차로 분할/대기차로 생성 시 뒤쪽 정차점·서비스 접근·제한속도 구간·종점 신호 연결을 새 구간으로 이어준다. 분할된 차로의 방향 반전은 거리 기준이 모호해 원상 복원 후 수행한다. 새 대기차로의 좌회전 신호 그룹은 별도로 연결하고 전체 검사로 확인한다. 도로 외곽 면과 차로 경로는 별도다. 도로 노면만 옮겨도 NPC 경로가 자동으로 이동하지 않는다.

## 표지·노면·차량/보행 신호

1. **표지** 또는 **노면** 탭에서 종류를 고르고 **Scene 클릭하여 새 시설 배치**를 누른 뒤 원하는 지면을 클릭한다.
2. 시설 표시를 선택해 W 이동/E 회전/R 크기 또는 숫자 입력으로 배치한다. 표지 종류·문구·높이·크기와 근거 메모를 바꿀 수 있다.
3. **차로 클릭하여 연결**로 적용할 차로를 지정한다. 좌/우회전 금지·진입 금지·제한속도는 **게임 규칙 적용**을 켜면 내비/NPC/직접 운전의 공통 규칙에 적용된다. 제한속도는 차로 위 시작/끝 거리도 설정한다. 일방통행·횡단보도·보호구역·비보호 안내는 외형 표시다.
4. 정지선·횡단보도·차선·중앙선은 폭/길이·방향을 조절한다. 신호의 제어 노면으로 연결할 때는 **노면 시설 클릭하여 대상 연결**을 누른다.
5. **신호** 탭에서 선택 차로의 교차로 또는 목록의 교차로를 고르고 **보수적 기본 신호 프로그램 생성**을 누른다. 분리된 접근 단계와 차량/보행 그룹·노면·신호기를 만든다. 기존 프로그램이 있으면 편집하거나 복원한다.
6. 단계별 녹색·황색·전적색 시간과 켤 그룹, 그룹별 진행·적용 차로·횡단보도를 설정한다. 시설의 읽기 쉬운 그룹 목록/지도 클릭으로 연결한다. 상충하는 녹색·미연결 신호는 전체 검사에서 차단한다. 기본 시간표는 게임 설정이며 실제 현장 주기를 자동 확정하지 않는다.

## 검사·시험·자료

**검사·시험·자료** 탭에서 전체 검사, 오류 위치 이동, JSON 가져오기/내보내기, 정식 저장, 저장하고 빌드를 수행한다. 편집 도구는 Unity에 모여 있다. **현재 편집본으로 시험 주행**만 별도의 게임 창을 실행하며 영업 저장을 건드리지 않는다. 차로를 골라 출발/도착을 지정할 수 있다.

정식 저장 전에도 JSON으로 내보내 초안을 전달할 수 있다. 가져오기는 동일 기준 지도만 허용하며 전체 검증 후 한 번의 실행취소로 복원한다. 여러 편집기가 동시에 저장하거나 pull이 정식 파일을 바꾸면 덮어쓰기를 차단한다.

## 직접 조작

| 할 일 | 조작 |
|---|---|
| 선택 | Scene에서 면 클릭, 또는 패널 이름 검색 |
| 이동 | **W**, 화살표/평면 손잡이 드래그. X/Z 수평 이동만 반영 |
| 방향 | **E**, 수평 원형 손잡이 드래그 |
| 크기 | **R**, X/Z 크기 또는 건물 높이 손잡이 드래그 |
| 정확한 높이·도로 폭 | 패널의 m 단위 숫자 입력 |
| 모양 | **꼭짓점 직접 편집**을 켜고 점 이동. 자기 교차·중복점 등 잘못된 다각형은 거부 |
| 화면 이동 | **F** 또는 **선택으로 이동**, Alt+드래그로 회전, 휠로 확대/축소 |
| 실행취소 | Ctrl+Z / Ctrl+Y 또는 패널 버튼. 한 번의 드래그를 하나의 작업으로 묶음 |
| Scene 창을 닫은 경우 | 편집 패널의 **3D Scene 다시 열기** |

회전·크기 기준점은 선택 객체 꼭짓점의 중심이다. 도로 R 조작은 중심선의 X/Z 배치를 조절하며 도로 폭은 별도 숫자로 수정한다. 원본 고도·지형 경사를 깨지 않도록 수직 위치 이동과 기울이기는 지원하지 않는다. 새 객체 추가/삭제와 차로 주행 그래프 편집도 같은 Unity 편집 창에서 수행한다.

## 주차장·식당·휴식 부지

- 부지 전체를 선택하고 W/E/R로 면과 정차 위치를 함께 움직인다.
- **정차점만 이동·회전**을 켜면 부지 형태는 그대로 두고 노란 칸의 위치·방향을 바꾼다. 정확한 X/Z와 방향도 숫자로 입력할 수 있다.
- **지도에서 접근 차로 지정**을 누르고 Scene의 원하는 도로 근처를 클릭한다. 클릭 위치에서 20m 이내의 주행 차로와 차로 위 거리를 연결한다. 다시 버튼을 누르면 취소한다.
- 부지의 접근 노면·건물 간격도 확인한다. **도로 노면을 옮겨도 내비/NPC의 주행 차로는 자동 이동하지 않는다.** 주행 연결은 같은 창의 차로·표지·신호 도구에서 변경한다.

## 저장과 다른 PC에 적용

1. **프로젝트에 저장**을 누른다. 전체 형상·차로 연결·서비스 위치 검사와 원본 파일 충돌 검사를 통과해야 정식 저장된다.
2. 바뀐 **`config/maps/project/eungye.project.json`**을 커밋·푸시한다. `.unity` 씬이나 개인 초안만 커밋하는 방식이 아니다.
3. 다른 PC에서 pull한 뒤 **Taxi → Build Eungye Hybrid**로 빌드한다.
4. 저장소 루트의 **`builds/EungyeTaxi/EungyeTaxi.exe`**를 실행한다. 기존 exe에는 이후의 지도 수정이 자동으로 반영되지 않으므로 재빌드가 필요하다.

정식 JSON에 기준 지도와 편집 문서가 함께 들어 있어 원본 GIS/재수입용 지도 JSON이 없어도 이 경로로 빌드할 수 있다. 원본 NGII/OSM이나 배포 ZIP을 다시 수정할 필요는 없다. 기존 실행파일 편집기와 같은 정식 저장 형식을 사용하므로 병행할 때에는 한 편집기에서 저장한 뒤 다른 편집기를 다시 열어 최신 내용을 읽는다. 동시에 저장하거나 pull로 파일이 바뀌면 이전 편집기의 덮어쓰기를 차단한다.

## 초안과 복구

변경 객체만 저장하는 초안은 **저장소 루트의 `Library/ProjectMapEditor/session-draft.json`**에 둔다. 마우스 조작 종료/짧은 유휴 시간, 창 닫기, Play 모드 진입, 스크립트 재컴파일 때 보존하며 다음 열기에서 자동 복구한다. 이 초안은 이 PC의 복구용이며 Git 배포 대상이 아니다.

pull이나 다른 편집기의 저장으로 초안의 기준 파일이 바뀌면 자동 복구를 중단한다. **충돌 초안 보관 후 현재 지도 편집**을 누르면 기존 초안을 같은 폴더의 `session-draft.json.preserved-...`에 남기고 최신 정식 지도를 편집한다. 보관된 이전 변경을 최신 지도에 자동 병합하지 않는다. 정식 저장이 성공하면 현재 초안은 제거한다.

## 반응 속도와 검증 범위

처음 열 때 지도 전체를 읽고 배치 메시를 만든다. 드래그 중에는 선택 객체와 영향을 받는 128m 구역만 갱신하고 전체 지도 복사/합성/검사/디스크 저장을 하지 않는다. 카메라 미리보기는 최대 초당 10회 갱신한다. 전체 검사는 정식 저장/빌드 시 수행한다.

자동 검증과 측정 결과, 수동 확인이 남은 범위는 [작업 이력](work-history/2026-10-23-unity-scene-map-editor.md)에 기록한다.

## 2026-10-26 유턴 추가

1. 진입할 차로를 선택합니다.
2. **유턴 대상 차로 클릭**(Unity에서는 연결 회전 **유턴**)을 고르고 반대편 출구 차로를 클릭합니다.
3. **표지** 탭에서 실제 표지에 맞는 유턴 조건(상시 양보 / 좌회전 신호 / 보행 신호 / 좌회전·보행 신호)을 놓습니다.
4. 표지를 원래 진입 차로에 연결하고 **게임 규칙에 적용**을 켭니다. 조건 표지는 진입 차로당 하나만 둡니다.
5. 검사 → 저장 → 시험 주행을 합니다. 간격이나 회전 반경이 부족하면 연결을 거부하므로 더 바깥쪽 출구 차로를 확인합니다.

유턴은 좌회전과 별개의 연결입니다. 반대 방향 연결, 최소 회전 반경과 허용 조건을 검사하고 내비/H/NPC/노면 화살표가 같은 경로를 사용합니다. H는 조향만 보조하므로 가감속과 신호·주변 확인은 직접 합니다. 확인된 기본 지도 위치는 T1 동남·북서·북동 접근이며, 촬영 당시 조건은 **좌회전 또는 보행 신호 시**입니다.

첨부 화면의 넓은 황색 경계 사이 공간에는 수인로 중앙 안전지대와 방호울타리가 관찰됩니다. 원본 간격을 한 줄로 줄이지 않고 시설을 추가합니다. [거리뷰 근거와 관찰 범위](map-observations/2026-10-26-uturn-median-observations.md).
