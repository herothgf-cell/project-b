# 은계 혼동 법규 연습 1차 구현·검증

기준일: 2026-10-20. 사용자 승인 범위: 기존 은계 지형 일부를 창작 교육 구간으로 구성할 수 있음. 캐주얼 그래픽/HUD 시안·실물 패드·새 PC 검증은 제외한다.

## 선택한 범위와 순서

기존 우회전·출구 연습은 유지하고, 새로운 맵 체계 없이 기존 직진/좌회전 차로 연결에서 시험할 수 있는 F02·F03·F06·F05를 먼저 선택했다. F03은 시선/주의 의무를 자동 판정하지 않는 비교 장면이다. 62개 전체 또는 은계 모든 교차로에 새 법규 감점을 적용한 것이 아니다.

| 우선순위 | 선택 화면의 상황 | 평가/설명 |
|---|---|---|
| 1 | 적색 점멸 · 정지 후 진행 | 정지선 앞 완전 정지 유무 F02, 직진 완료 |
| 1 | 황색 점멸 · 주변 확인 | 강제 정지를 요구하지 않음. 통과 기록과 시선 확인 판정 보류 F03을 구분 |
| 2 | 녹색 · 출구 정체 | 출구 차량 뒤에 내 차가 들어갈 공간이 생기기 전 정지선 진입 F06 |
| 2 | 녹색 · 출구 공간 있음 | 비교 조건. 불필요한 정지 요구 없음, 출구 정체 평가 기회 없음 |
| 3 | 비보호 좌회전 · 적색 대기 | 적색 진입 기록 보존 F05. 대기 뒤 녹색 전환 |
| 3 | 비보호 좌회전 · 대향차 양보 | 좌회전 충돌 구역 통과 시 대향차 양보 F05 |
| 3 | 비보호 좌회전 · 녹색 / 대향차 없음 | 비교 조건. 불필요한 정지 요구 없이 좌회전 |

현재 지도에서 직진은 `J5750_2576`, 좌회전은 `J5076_2580`의 차로 1 연결이 선택된다. 후보 검색은 비활성 차로 제외·65m 이상 접근부·30m 이상 출구부·접근/연결/출구 3개 간선 경로를 확인한다. 맵이 바뀌면 같은 요건의 가까운 교차로를 선택하며 원본 지형·규제 출처는 수정하지 않는다.

## 이용과 피드백

`builds/EungyeTaxi/EungyeTaxi.exe`의 영업 준비/일시정지/정산에서 기존 **운전 연습 선택**을 연다. 연습 중에는 **F6**으로 다른 상황을 선택할 수 있다. 목록은 스크롤 가능하며 번호만 표시하지 않고 상황 이름·신호/차량 조건·운전 요령을 표시한다.

① 정지선과 ② 통과/양보 위치를 도로에 표시한다. 결과에는 잘한 점, 보완할 위치, 다음 시도 행동을 표시한다. 안내 도로로 빠져나가면 결과를 자동으로 열고, 그 전에는 미완료로 표시한다. 같은 조건 재시도와 다른 조건 선택을 지원한다. 다른 조건을 미리 고르다가 취소해도 같은 조건 재시도는 실제 수행한 조건으로 돌아간다.

가상 표지·신호 운용·정체/대향차는 연습 창에서만 활성화하며 **실제 현장 규제 아님**을 화면에 표시한다. 별도 연습 프로세스에서 영업의 돈·시간·운송 상태를 유지한다. 정지/보류/위반은 독립 법규 장부에 기록하며 승객 매너나 운임을 바꾸지 않는다. 위반 15점은 연습용 게임 제안값으로 범칙금/법정 벌점이 아니다.

## 관찰과 판정 경계

- 정지선 통과 당시 정지·적색·출구 차단을 기록한다. 이후 공간이 생기거나 녹색으로 바뀌어도 이미 관찰한 위반을 없애지 않는다.
- 출구 공간과 대향차 점유는 화면에 배치한 차량의 실제 위치를 사용한다. 대기 시간은 장면을 재현하는 제어 수단이며 법규 성립의 시간 기준이 아니다.
- 비보호 좌회전의 녹색과 대향 녹색은 같은 운용 상태를 표시하며 전용 좌회전 화살표는 켜지 않는다. 점멸은 3D 등화에 실제로 표시하고 HUD에도 점멸임을 명시한다.
- 신규 연습 구간에서는 기존 일반 신호 관찰과 중복 감점하지 않는다. 기존 우회전/출구 연습으로 전환하면 임시 차량·점멸·비보호 운용을 해제한다.
- 잘못된 경로, 미통과, 관찰 불명, 시선 확인 불가를 무위반 완주/100점 성공으로 대신하지 않는다. 황색 점멸의 ‘주의’ 전체를 이동 데이터만으로 준수 판정하지 않는다.
- 연습 대향차·출구 차량은 판단 위치 도착 전 사라지지 않는다. 정지선 앞 정차 후 상황을 진행한다. 정차 시간/6m 공간 등 수치는 교육 장면과 물리 관찰을 위한 프로토 기준이며 전국 법적 기준이 아니다.
