## P11 요청 배정과 발생 시점

기준: [04 요청 배정](content-design/04-passengers-and-reservations.md#요청-배정과-등장-시점--변경-기획-미구현), [11 요청별 콘텐츠](content-design/11-passenger-request-effects.md). 모든 항목은 **기획만·미구현**이다. 기존17종 요청 구현 완료와 구분한다.

- [ ] P11-01 후보 ID 기반 요청 수·종류·순서·시점 추첨, 첫 운송/특정 정차점 고정 제거. 0/1/2건·같은 후보 재수락/저장 복원·신규 후보 변주 검사.
- [ ] P11-02 승차 또는 운행 중 안전 정차에서만 새 요청 제시. 신호 대기 허용 조건·주행 재개 입력 보류·상황 화면 중첩 방지·짧은 운송 미발생 중립 검사.
- [ ] P11-03 개별 요청 상태·관찰·목표 동시 유지, 상충 약속 제외·목적지/경유 변경 최대1개. 첫 요청 결과를 다음 요청이 덮지 않는지 검사.
- [ ] P11-04 개별 결과 합산·시험 상한·중복 사건 감점 방지, UI/F8·저장 이관. EV03 하차 후 전용 사건 전환과 기존 완료 운임 보존 검사.
- [ ] P11-05 실제 운행 중 발생 빈도·답변 여유·경제 영향의 수동 확인. 자동 추첨 분포와 사람 체감 구분.
