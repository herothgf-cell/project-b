# 지도 관찰 근거

현장·거리뷰 관찰과 개인용 안내 자료를 콘텐츠 규칙에서 분리해 보존한다. 관찰되지 않은 접근부나 실제 신호 주기를 확정 자료로 취급하지 않는다. 게임의 현재 지도 규칙은 [월드 기획](../content-design/01-driving-and-traffic.md)과 관련 작업 이력을 따른다.
