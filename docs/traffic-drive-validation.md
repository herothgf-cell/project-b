# T1–T2 교통·시점 확장 검증

2026-10-14 / Unity 2022.3.62f2 / Windows x64.

## 추가한 동작

- 도로 폭 기반 중앙선·차로 구분선·가장자리선, T1·T2 정지선과 횡단보도.
- 두 축이 번갈아 통행하는 신호등. 황색과 전적색을 포함하는 32초 주기이며 T2는 7초 시차.
- 일반 차량 8대. 우측 통행 직진, 적색/황색 접근 정지, 녹색 출발, 앞차·택시 감지, 구간 끝 재순환.
- Q/E 좌우 깜빡이 토글, 외부 앞뒤 램프와 HUD 점멸. 반대쪽 전환, 같은 키 해제, 리셋 시 해제.
- C로 운전석 1인칭/후방 추적 3인칭 전환, B 유지로 뒤보기. 패드 대응 버튼은 README 참조.
- 정지선에서 신호등이 보이도록 건너편 배치. 초기 택시는 정지선 뒤에서 출발하고 리셋 위치의 AI 겹침을 방지.

실제 자료에는 현재 신호·차로 운영 정보가 없어 게임용으로 배치했다. 보행자·보행 신호, 일반 차량의 회전, 신호 위반 점수는 포함하지 않는다. 일반 차량이 교차로를 이미 진입한 경우에는 빠져나가며, 혼잡 시 교차로 진입 금지 판단은 후속 범위다.

실행 로그 `artifacts/player-traffic.log`와 결과 `artifacts/traffic-smoke.txt`에서 `success=True`를 확인했다. 해당 로그에 Exception/Error는 없다. 화면은 `artifacts/traffic-first-person.png`, `artifacts/traffic-third-person.png`, `artifacts/traffic-rear-view.png`에 저장했다. 코드 리뷰의 신호 가시성 지적을 반영한 뒤 다시 빌드·검사했다.

실물 패드 버튼 매핑·손맛, 사용자 수동 키보드 입력, 장시간 밀집 교통 안정성, 모든 충돌 경우는 별도 검증 대상이다. 자동 검사는 입력값과 공개 제어 함수를 사용한다.
