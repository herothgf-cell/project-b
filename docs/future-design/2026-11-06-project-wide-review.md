## 현재 범위에서 먼저 닫을 공백

1. **기존 실패 2건**: `UturnTests.Run`의 보행 신호 유턴 observer 사건 누락, `test_vehicle_durability_player.ps1`의 `arrival locked luggage can tow from unsafe crossing` 실패다. 최근 이력을 인용했으며 이번 재현은 하지 않았다. 제품 결함/fixture 전제 오류를 구분한 뒤 수정한다. 유턴 표시 검사를 법규 판정 정상으로 확대하지 않는다.
2. **사람 싱글20분/전체3일**: 조향·승하차·대화·신호·서비스·사고·마감/저장을 이어서 플레이한 수용 기록이 필요하다. 기존 자동 위치 제어/물리 검사는 이를 대체하지 않는다.
3. **다른 PC LAN/실물 패드**: 2인부터 확인하고 4인 수용으로 넓힌다. 입력 반응, 보정 거리/빈도, 프레임 지연, 판정/순위 동의를 따로 기록한다.
4. **첫 이용자 학습과 가독성**: 호출→승차→하차→시설→마감, 만족도/요구/운전 점수·실수령의 차이, 사고 후 다음 행동을 화면으로 이해하는지 확인한다. 기존 메뉴/HUD 개선은 보존하고 도움말·설정 발견성과 입력 부담을 점검한다.
5. **최신 통합본 지속 성능**: 대표 지역 성능 기록은 존재한다. 현재 사고/설정/교통을 합친 최종본의 장시간 프레임 지연·메모리·LAN 비용은 별도 수용 대상이며 평균 fps 하나로 판정하지 않는다.

P1/P2 반응형 승객·상태 예측 계산·수요/일반차 성향·시설 혼잡/봇 운영·용무 대기·작성된 대체 승하차는 이미 구현됐다. 내구도/수리/견인뿐 아니라 **11/05~06 사고 처리·공업사·종류별 3등급 비용/시간/감점·결과 카드**도 코드와 배포 기록이 있다. 이를 신규 개발 목록에 다시 넣지 않는다. 운송 중 상시 예측 HUD 숨김과 예측 계산 미구현도 다르다.

선택지 효과 구조는 별도 확인이 필요하다. `PassengerRequest.CompleteGoal`는 `Delta(Kind, success)`를 사용하며 답변 종류를 점수 인자로 쓰지 않는다. 선택 답변은 저장되지만 모든 선택지가 독립 효과를 소유하는 구조는 아니다. 동시 작업의 [선택지 구조 조사](2026-11-06-choice-effects-structure-review.md)도 이 한계를 기록했다. 임의 선택지에 만족도·피로·유지 기간·종료 효과를 연결하는 확장은 텍스트 관리창 수정과 다른 게임 코어 작업이다. 기존 부분별 행동 구현은 유지하면서, 동일한 요청의 답변들이 의미 있는 다른 결과를 만들 필요가 있는지 우선 검토할 만하다.

## 마인드맵과 요약의 정합성

저장소 `.mmst` 직접 순회 결과 **340노드, 50%178 / 25%0 / 0%53**이다. 50%는 사용자가 정한 구현 단계이며 출시 완료율이 아니다. 중복 참조/설명 노드가 있어 이 값으로 독립 기능 구현률을 계산하지 않는다. 연결 MindMap AI 제목 `택시` 검색은 0건이었으며 저장소 원본으로 평가했다.

- 사고 가지에 `사고 처리비·시간·피로·공업사 상세안 검토 (11/05 미구현)`이 남았다. 보험 연계와 이미 구현된 게임 사고비를 나눠야 한다.
- 현재 플레이의 `개별 상황 반응은 추가 제안` 0% 설명은 구현된 반응형 승객과 충돌한다.
- 원격 PVP 원안의 미구현 표시는 현재 LAN 경쟁 미구현을 뜻하지 않는다.
- `00-game-overview.md`의 대체 승하차 미제공/PVP 후속, `pvp/00-mode-overview.md`의 초기 미구현/이전 네트워크 권고안은 오래된 표현이다.

현재 요약/원본의 의미를 최신화하고 과거 기록은 당시 기준을 명시하는 편을 권한다. 사용자 노드·접힘·메모·단계를 보존해야 한다. 이번에는 마인드맵 원본과 기존 기능 문서를 일괄 수정하지 않았다.

확장 선택지는 3일 체험판 완성, 단골/성장 중심 장기 개인택시, 짧은 영업 경쟁 강화다. **기본 품질·수용 검증을 먼저 닫고 장기 영업/경쟁 중 주력 경험을 고르는 순서**를 권한다. 기존 모드는 유지하면서 개발 투자 비중을 정하는 문제다. 전국 복원·법인 경영·공개 매칭을 동시에 추진할 근거는 아직 없다.
