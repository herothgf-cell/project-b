# 마인드맵 미구현 요소 우선순위와 단계

2026-11-07 전체 대조는 [현재 미정 목록](2026-11-07-planning-gaps-and-weather.md)을 우선한다. 아래 P1~P4는 이전 추천의 출처이며 현재 필수 개발 순서가 아니다. 날씨·야간은 상세 기획/구현 없음, 승객 프리셋/개별 설정/다양화와 개인 운전 설정5종은 후속 구현됐다. 추천의 중복 말단은 마인드맵 집계에서 제외한다.

사용자 지정 단계는 **실제 구현50% / 기획만 완료25% / 기획 필요0%**다. 50%는 구현 단계 표시이며 검증·밸런스·출시100%를 뜻하지 않는다. 분류 제목은 하위 단계별 개수만 집계하고, 설명/참조는 집계에서 제외한다. 부분 구현은 구현된 동작과 미구현 확장을 나눠 체크한다. 기획 검토/아이디어만 있다는 이유로25%로 표시하지 않는다.

2026-11-03 최신화: P1/P2 구현은 유지하고 대화 UI·신호·네비·닉네임·단거리 배차·조향·LAN 소유자 예측을 추가 반영했다. [현재 구현/검증 잔여](../CURRENT-STATE.md)를 먼저 읽는다. 다음 운송 상태 예측 계산은 구현했지만 운송 중 상시 HUD 카드는 현재 숨김이다. 현재 PvP 맵은 A2이며 A3 재배포를 승인한 뜻이 아니다.

## 상태 예측 구현 계약

기존 검토안의 사전 상태 예측을 다음 표시 계약으로 구체화했다. **새 감점·새 소모량·운임 보정은 추가하지 않는 승인 구현 범위**이다. 기능 기획과 사용자 채택 여부는 별개다.

| 조건 | 표시/계산 | 예외·검증 기준 |
|---|---|---|
| 호출 선택 | 현재 상태, 픽업+운송의 기존 ETA/거리로 도착 예상 연료·포만·피로 표시 | 실제 모델의 복사본으로 계산. 시간/상태/돈·호출을 변경하지 않음 |
| 탑승 중 | 현재 위치부터 남은 운송의 예상 도착 상태 표시 | 정체·요청 경로 변경 후 재계산. 예측을 수입/도착 보장처럼 표현하지 않음 |
| 캠페인 예정시간 경계 | 예상 종료가 경계를 넘으면 현행 피로100 정책도 반영 | 단순 연속 소모 계산만으로 위험을 누락하지 않음. PVP에는 캠페인 날짜/마감 규칙을 적용하지 않음 |
| 시설 비교 | 기존 검증 시설의 실제 접근 경로 시간/거리+현재 서비스 견적/소요시간을 분리 표시 | 비용은 현행 모델/견적 사용. 가장 가까운 곳을 무조건 추천하지 않음 |
| 정보 부족 | 경로/ETA/비용 계산 불가 항목은 ‘예측 불가’ | 0초·무료·안전 도착으로 대체하지 않음. 현재 상태는 계속 표시 |
| 갱신/성능 | 선택/경로/서비스 상태 변경 시와 활성 게임1초 주기로 재계산 | UI 표시만을 위해 매 프레임 전체 차량/경로 검색 금지. 일시정지 중 소모/선택 확정 없음 |
| 표시 우선순위 | 호출 상세/시설 비교의 보조 정보로 제공 | 구토·운행 불가 경고/승객 선택을 가리지 않음. 실제 결과 장부와 구분 |
| 저장 | 예측값은 파생 정보로 재계산 | 원본 상태만 저장. 재개·재선택으로 실제 돈/연료/시간/거래 중복 변화 없음 |

모델 경계값·기존 마감 정책·ETA 없음·경로 변경·일시정지/재개·시설 우회·같은 조건 전후 상태 불변·모드 분리를 구현 수용 기준으로 삼는다. 각 후보의 현재 구현/보류/근거 대기는 위 표와 담당 기획을 따른다.

## 구현50%와 혼동하지 않을 것

기존 취객·수면·음식/짐 사건, 경유, 요청0~2개, 청결/세차, 충돌 내구도/수리/견인, 기본 피로/식사/수면,3단계 수요, 기본 교통/보행, 단일 exe의 싱글/봇 모드는 이미 구현됐다. 이들 기능의 새 이벤트 반응·새 지도·새 경제·원격 통합은 별개다. 이번 마킹은 소스/기획 대조이며 새 게임 빌드나 전체 수동 검증을 의미하지 않는다.
