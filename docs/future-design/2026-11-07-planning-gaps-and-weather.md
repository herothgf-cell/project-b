# 마인드맵 대조: 기획 미정·미구현 전체 목록

기준: **2026-11-07**. [마인드맵 원본](../content-design/택시%20시뮬레이션.mmst)·[글 목차](../content-design/택시%20시뮬레이션-목차.md)·[담당 기획](../content-design/README.md)·[개발 체크리스트](../prototype-development-checklist.md)를 대조한 상태 목록이다. 아이디어의 존재, 상세 기획 완료, 구현, 사람 플레이 수용을 구분한다. 새 날씨/장기 성장의 설계를 승인하거나 개발에 편입한 문서가 아니다.

## 날씨(기상)와 낮밤

**날씨는 기존 아이디어만 있고 상세 기획·런타임 구현은 없다.** 마인드맵의 ‘비/눈·브레이크 영향·와이퍼’와 과거 추천의 ‘비/눈은 기존’은 구현됐다는 뜻이 아니다. 기존 아이디어라는 표현으로 정정한다. 기존 검토의 ‘우선 시각만/제동 변경 제외’도 검토 제안이며 채택된 날씨 규칙은 아니다.

| 요소 | 현재 상태 | 먼저 결정할 것 |
|---|---|---|
| 비/눈 종류·강도·발생 | 아이디어·기획 필요0% / 미구현 | 비/눈 중 첫 범위·강도·지속·전환 조건, 고정 선택/무작위 여부 |
| 강수·소리·젖음/적설·시야 | 상세 기획 없음 / 미구현 | 시각·음향 범위, 도로/신호/보행자 가독성·성능·시점 차이. 안개 등은 추가 후보 |
| 와이퍼/유리 | 아이디어·기획 필요0% / 미구현 | 수동/자동·조작키·빗방울/결로·1/3인칭 안내와 가시성 |
| 제동·노면 영향 | 적용 여부부터 미정 / 미구현 | 물리 변경 유무·강도·안전 제동/난도·평가 예외. 임의 감속 배수를 넣지 않음 |
| 낮밤·등화 | 가상 시계/시간대 수요만 구현, 동적 낮밤 표현은 미구현 | 시계 연결/고정 시간 선택, 하늘/주변광·가로등·차량 등화·야간 시인성 |
| 승객/수요·영업 효과 | 날씨와 연결된 별도 규칙 없음 | 영향 유무부터 결정, 무조건 추가 요금/감점/상태 소모를 붙이지 않음 |
| 싱글/PVP·이어하기 | 날씨 상태/공통 조건 설계 없음 | 저장/복원, PVP 공통 시야·전환/선택·성능 경계 |

코드 대조 근거: `DriveSession.cs`는 고정 ambientLight와 고정 회전/밝기의 Directional Light를 생성한다. Scripts/Editor 검색에서 날씨 전환·강수/와이퍼·시각 연동 조명 제어를 찾지 못했다. 이 조사는 기본 실행 경로/현재 코드의 상태 확인이며 이번에 실제 렌더·전체 플레이 검사를 한 것은 아니다.

용어도 분리한다.

- **승객 깨우기 대기**: 취객/수면 승객이 도착 후 일어나도록 기다리는 기능. 기존 문서의 ‘기상 지연’이며 구현됨.
- **야간 피로 회복**: 다음 날짜로 넘어갈 때 상태를 회복하는 기능. 실제 밤하늘/야간 운전 구현이 아님.
- **기상/날씨**: 비·눈 등 환경 시스템. 미기획·미구현.
- **시간대 수요**: 아침/낮/저녁의 호출/교통 가중. 날씨나 조명과 별도 구현.

| 관계·예약 | 재이용/선호/연락 동의·일정 충돌·노쇼/취소·장기 기억 | 현재 프로토 제외, 신규 승객을 늘리는 작업과 별개 |

위 행 전체가 현재 프로토의 필수 개발 목록은 아니다. 제외·보류를 유지하고 새 채택은 범위 결정 후 한다. 실제 법규의 타당성/현행 규정은 별도 근거 조사 없이 이 목록만으로 확정하지 않는다.

## 기획이 구체적이지만 미구현인 작은 방 화면

| 항목 | 단계 | 근거/남은 일 |
|---|---|---|
| 처음/완료 방 직접 비교 | 25% 기획 완료·미구현 | 13에 같은 화면 전환·성적화 없음·구매0개 처리·읽기 전용을 정의 |
| 다음 날 찜/구매 카드·숨김 | 25% 기획 완료·미구현 | 13에 표시 우선순위·없으면 생략·추가 출발 클릭 없음·숨김/소유 분리 정의 |
| 전체 과거 방 탐색 | 0% 추가 기획 필요 | 최신 이전 회차 열람은 구현. 전체 기록 탐색/호환·보존 상세 결정 필요 |
| 상품별 이미지/아트 | 0% 범위 확정 필요 | 기존 방/물건 레이어와 별도 카드 자산 범위·스타일·크기 결정 필요 |

이는 문서의 정의 수준에 따른 단계이며 개발 지시/실제 사람 수용 완료가 아니다. [13 작은 방](../content-design/13-three-day-room-and-first-purchase.md)을 단일 규칙으로 유지한다.

## 이번에 현재 구현으로 최신화한 것

- 개인 운전 설정5종·기존 브레이크/조향의 실제 적용.
- 승객 프리셋/특성 조합·개별 대사/확률/효과·다양화1차(총24/활성23). 기존11행동/34변주는 재사용 자료다.
- 기존 신호/충격 반응과 추가 상황/복수 행동 제약 분리.
- 작은 방 구매/개인 지출·저장과 미구현 화면 분리.
- 현재 A2 native LAN/순수익 경쟁과 대체된 초기 원격 점수 원안 분리.

10개 추천 가지는 동일 기능을 다시 세지 않도록 **설명·참조**로 바꿨다. 기존 PVP 원안2말단도 현재 필수 미구현 목록에서 제외했다. 원본 노드 ID·부모/순서·접힘·기존 메모/링크·기타 task 필드는 보존하고 최신 판정만 덧붙였다.

## 기획 미정과 구분할 검증 잔여

사람 실제 운행의 특수승객·경유·깨우기 대기·도착/F안내,3일 캠페인/생활 동선/구매 동기, 장시간 가독성/교통·다른PC LAN/지연손실은 구현 수용이다. 기존 자동검사4건의 기대값/실패 원인도 유지보수로 분리한다. 날씨를 포함한 신규 기능의 미기획과 묶지 않는다. 상세는 [직전 검토](../work-history/2026-11-07-open-design-review.md)와 [현재 작업 이력](../work-history/LATEST.md)을 따른다.
