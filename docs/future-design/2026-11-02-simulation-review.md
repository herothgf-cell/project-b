# 시뮬레이션 추가 요소 검토 — 2026-11-02

이번 문서는 코드·기획 대조에 따른 **제안**이다. 채택·수치 확정·구현 지시를 뜻하지 않는다. 현재 플레이 규칙은 `docs/content-design/`, 실제 구현·검증 상태는 개발 체크리스트와 작업 이력을 따른다.

## 추가 후보와 우선순위

비용은 작업 일수 예측이 아닌 상대 범위다. 우선순위는 이번 검토의 제안이며 승인된 로드맵을 대체하지 않는다.

| 우선 | 후보 | 실제 플레이 예시·결과 | 구현 전제/비용 | 적용 모드 |
|---|---|---|---|---|
| 1 | 실제 상황에 반응하는 승객 | 신호 대기가 길면 재촉→안전 설명→이후 재촉 감소. 큰 흔들림 뒤 음식/짐 상태 확인→정차 정리 또는 계속 운행 | 기존 운전/신호/요청 관찰 이벤트 재사용, 중간 | 싱글 우선, 이후 PVP 동일 규칙 |
| 1 | 다음 운송·시설 이용의 상태 예측 | 호출에 예상 종료 연료/피로 위험과 근처 시설 우회시간 표시→지금 수락/먼저 정비 선택 | 기존 ETA·소모·서비스 견적을 함께 계산, 중간 | 공통. PVP 봇도 같은 비용 판단 |
| 1·지도 선행 | 안전 대체 승하차 | 지정점 점유→원래 자리에서 기다리기/검증된 인근 정차공간 제안→승객 동의 후 경로 변경 | 안전 장소 쌍·접근 방향·승객 동선 작성이 먼저. 중간~큼 | 싱글 우선 |
| 2 | 경유 중 실제 용무 대기 | 편의점 방문→합의한 시간 기다리기→복귀 후 원래 목적지. 예상 시간·요금 확인 후 수락 | 현재 ViaStop에 작업 단계·취소/복귀·요금 계약 추가, 중간 | 싱글 우선. PVP는 종료 시점 계약 필요 |
| 2 | 게임 시각과 연결되는 수요/교통 흐름 | 출근 시간은 주거→업무, 저녁은 업무→상업 비중 변화→어디서 다음 손님을 찾을지 판단 | 현재 단계별 가중 확장. 교통 수 증가보다 목적지/방향 분산 우선, 중간 | 공통, PVP는 공용 조건 |
| 2 | 시설 혼잡과 대안 | 가까운 주유소 대기 예상과 조금 먼 빈 시설 비교→이동/대기 시간의 손익 | 서비스 공간 점유·대기 순서·해소·출차 연결 검증, 중간~큼 | 공통, 봇 포함 동일 대기 |
| 2 | 실제 차내 장치 응대 | 음악 끄기/볼륨 조정 같은 실제 조작→약속 이행 확인→승객 반응 변화 | 음악 콘텐츠 확보와 별개로 켜기/끄기부터 작게 시작. 냉난방/창문은 후속, 중간 | 싱글 우선 |
| 3 | 야간·날씨 | 야간 조명과 젖은 노면 가독성·보행자 시인성 변화→속도·경로 선택 | 조명/표지/신호 시야·성능 검증 필요, 큼. 초기에는 제동 물리 변경 제외 | 공통, PVP 동일 날씨/시야 |
| 3 | 단골·개인 예약 | 전날 약속을 잘 지킨 승객의 재호출→다른 호출과 예약 시간 비교 | 3일 일정·신뢰 기억·중복 예약/취소 계약, 큼 | 싱글 중심 |

**권장 첫 묶음:** 상황 반응형 승객 + 다음 운송 상태 예측. 안전 대체 승하차는 장소 쌍을 확보하는 대로 추가한다. 첫 묶음은 이미 구현된 차량·청결·생활 시스템을 재사용해 선택 결과를 더 잘 드러낸다. 경유 용무 대기는 그다음 독립 묶음으로 적합하다.

## 먼저 구체화할 세 가지

### 상황 반응형 승객

기존 유형을 더 늘리기 전에 같은 유형이 실제 상황에 다르게 반응하도록 확장한다. 시간 경과만으로 신호가 길었다고 말하거나 특정 코너를 지났다고 꾸미지 않는다.

| 실제 관찰 | 후속 변주 제안 | 결과 경계 |
|---|---|---|
| 재촉형·실제 신호 대기 누적 | 상황 설명/안전 우선 응답을 기억해 후속 재촉을 줄임 | 적색 진입 유도 없음, 합법 대기로 운전 점수 감점 없음 |
| 음식 허용 후 실제 큰 흔들림 | 컵을 잡았다는 반응 또는 실제 흘림→정리 선택 | 현재 허용 만족도+5 유지. 기존 흘림 사건과 합쳐 한 운송에 같은 오염을 중복 차감하지 않음 |
| 잠든 승객·큰 충격/흔들림 | 깸→안심 안내→다시 수면/도착까지 깨어 있음 | 기존 운전 사건과 동일 이유의 추가 감점 중복 금지. 정당한 긴급제동의 불가피한 결과와 운전 잘못을 구분 |
| 짐 승객·반복 흔들림 | 짐 고정 요청→안전 정차에서 재고정 | 선택 전 소요시간·효과 표시. 짐이 있다는 이유만으로 차량 내구도를 깎지 않음 |

선택창 최대3회/한 번에1개, 조용한 운행 약속, 위험 경고 우선, 주행 중 답변 보류를 유지한다. 모든 대사에 새 수치 보상을 붙일 필요는 없지만 실제 영향이 없는 응대는 변화0임을 정확히 표시한다. 발생 원인·발화·선택·사건 ID를 저장해 재실행으로 다시 추첨하지 않는다.

### 상태 예측과 생활 선택

새 벌점보다 **현재 손실을 미리 판단할 정보**를 먼저 제공한다. 현재 연료/피로와 ETA로 목적지 도착 예상 범위를 계산하고, 주유/식사/휴식 우회시간·서비스 시간·비용을 함께 보여 준다. 정체 때문에 예측은 변하므로 보장이 아닌 추정으로 표시한다. 캠페인 예정 마감 경계에서 피로100이 되는 기존 정책도 포함해 경계 직전 수락의 위험을 누락하지 않는다.

포만/피로 소모량·회복량은 이번 검토에서 바꾸지 않는다. PVP 전용 후보 수치는 콘텐츠27에서 계속 관리한다. 특히 피로만으로 운임을 자동 감액하는 안은 이미 있는 만족도 감액과 중복되는지 먼저 검토한다. 독립 포만 식사 판단과 남은 경기시간/시설 왕복의 손익을 봇에도 적용하는 것이 우선이다. 짧은 경기에서도 식사·휴식을 무조건 강제하지 않는다.

### 안전 대체 승하차

현재 미구현의 원인은 버튼 부족보다 안전한 후보 쌍 부재다. 대표 장소부터 원래 지점/대체 지점, 합법 접근 방향, 횡단·보행 동선, 물리 점유·복귀 경로를 작성한다. 아무 도로 가장자리를 자동 지정하거나 승객을 순간 이동시켜 해결하지 않는다. 합의한 한 운송 ID·한 정산·기한 보호를 유지하고 대체 지점도 막히면 기존 대기로 복귀한다. 게임용 후보와 실제 도로 근거를 구분한다.

## 확장 전 검증과 성능 경계

- 기존 사람20분/3일의 운송·식사·수면·세차·수리·초과 영업을 먼저 기록한다. 출현 빈도, 대사 반복, 순수익, 강제 정비 비율을 확인해 수치 조정과 기능 추가를 구분한다.
- 장시간 교통 교착·시설 출차·저장 복원·기존 최대 프레임 지연은 기존 검증 잔여다. 신규 콘텐츠로 해결됐다고 표시하지 않는다.
- NPC/보행 수를 무작정 늘리지 않고 기존 풀과 분산 예산을 사용한다. 이벤트 구독·주기 제한·캐시로 구현하며 매 프레임 전체 차량/경로 검색을 추가하지 않는다.
- 도로/시설 변경은 진입·정차·출차·보행 공간을 함께 검사한다. 길막을 콘텐츠화하더라도 기술 교착과 분리하고 해소 조건·기한 보호를 제공한다.
- 모델/저장, 위치 제어, 실제 자동 물리 주행, 수동 플레이, 다른PC를 구분한다. 동일 인구/해상도/지점에서 평균뿐 아니라 p95/p99·최대 지연도 전후 비교한다.
- 통합 exe의 싱글/PVP 모드 선택과 기존 저장 경로를 유지한다. 캠페인 전용 상태와 경기 전용 상태를 섞지 않는다.

## 이번 단계에서 미룰 것

부품별 고장·손상에 따른 조향/제동 저하, 보험 과실 판정, 세금/대출, 차량 구매/강화, 무제한 군중은 첫 추가 묶음에서 제외하는 것을 권한다. 사용자가 선택한 내구도0 이전 정상 조작·수리비/시간 중심 범위를 바꾸거나 3일 프로토의 핵심 선택보다 관리 부담을 크게 늘린다. 제외 확정이 아니라 후속 후보 유지다.
