| 구상 | 현재와의 경계 |
|---|---|
| [시뮬레이션 추가 검토](2026-11-02-simulation-review.md) | 현재 구현과 공백·우선순위·적용 모드를 대조한 제안. 채택/구현 지시 아님 |
| [사고·수리](accidents-and-repairs.md) | 충돌 강도별 손상·수리비/시간·내구도0 운행 불가·견인은 구현됨. 보험·책임 판정·성능 저하는 후속 유지 |
| 개인 예약·단골 | 현재 호출/길가 승객과 다른 관계·일정 콘텐츠 |
| 차량 구매·강화·정기정비·다른 연료/차종 | 현재 차량 한 대의 충돌 수리·연료·청결 운영과 구분 |
