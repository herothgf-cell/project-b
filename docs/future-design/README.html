후속 구상

현재 Proto와 구분해 아이디어를 보관한다. 이 목록을 현재 기능·비용·완료 조건으로 적용하지 않는다.

구상 현재와의 경계
시뮬레이션 추가 검토현재 구현과 공백·우선순위·적용 모드를 대조한 제안. 채택/구현 지시 아님
사고·수리충돌 강도별 손상·수리비/시간·내구도0 운행 불가·견인은 구현됨. 보험·책임 판정·성능 저하는 후속 유지
개인 예약·단골현재 호출/길가 승객과 다른 관계·일정 콘텐츠
차량 구매·강화·정기정비·다른 연료/차종현재 차량 한 대의 충돌 수리·연료·청결 운영과 구분
보험·세금·대출·카드 대금현재 현금·미납·실제 생활 비용과 구분
화장실·과식·실제 음악/에어컨 효과현재 포만감·피로·텍스트 응대에 추가하지 않음
날씨·사고 현장·전역 군중현재 기본 교통과 별도 환경 확장. PVP 나1+봇3은 이미 통합 exe의 현재 모드이며 기존 물리 원격4유저 수용은 별도
안전 대체 승하차 장소안전 장소·승객 동선이 정해지기 전 현재 해소 대기만 제공

마인드맵 검토표에 원본 가지별 이동 제안을 정리했다. 원본 마인드맵의 아이디어를 임의 폐기하거나 승인한 것은 아니다. 현재 플레이 규칙은 게임 기획을 따른다.
