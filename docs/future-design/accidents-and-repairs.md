# 사고·수리 후속 기획

## Proto 확장과의 경계

2026-10-29 사용자 선택으로 **수리비·시간 중심, 내구도0 운행 불가**는 Proto 확장 기획에 포함한다. 세부 규칙은 [생활·차량 상태·경제](../content-design/03-life-and-economy.md#추가-기획-충돌-내구도와-수리) 한 곳에서 정의한다. 아직 구현하지 않았으며 현재 실행 파일은 물리 충돌과 기존 M 감점만 제공한다.

과거 ‘신규 사고/수리 전부 Proto 제외’ 결정은 위 범위에 한해 변경했다. [기존 사고 기획 원문](../design-history/content-design/2026-10-27-before-planning-only/08-accidents-and-repairs.md)은 이력으로 남긴다. 구현·검증 상태는 [개발 체크리스트](../prototype-development-checklist.md)를 따른다.

## 별도 후속으로 남기는 요소

| 요소 | 현재 확장안과 다른 점 | 추가 결정 |
|---|---|---|
| 부품별 파손·외형 변형 | Proto는 단일 내구도 | 부위별 손상·모델 표현·정비 항목 |
| 성능 저하 | Proto는0 전까지 조작 성능 동일 | 제동/조향 저하·안전 복구·난도 악순환 방지 |
| 사고 책임·보험 청구 | Proto는 충돌 자체로 과실 확정 안 함, 실수리비 부담 | 관찰 근거·판단 보류·비용 보전·중복 지급 방지 |
| 보험 갱신·세금 | Proto 수리비/미납과 별도 | 주기·고정비·기간·장부 |
| 구급차·대인 사고·사고 현장 정체 | Proto에 새 사고 현장/보행 구조 없음 | 표현 범위·교통 영향·운송 중단 |
| 예약·단골 영향 | Proto 현재 운송과 복구만 처리 | 예약 일정·신뢰·취소 정책 |
| 사고 복습 | Proto 새 리플레이 없음 | 사건 기록·연습 분리·비용 재청구 방지 |

기술적 배치/지도 오류 복구와 게임상 유료 견인은 구분한다. 실제 법적 과실·보험금·수리비를 추정하는 콘텐츠로 표현하지 않는다.
