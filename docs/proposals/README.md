회사에 신규 게임 개발 착수를 제안하는 문서다. 기존 프로토타입은 개발 기반으로 소개하고, 본개발 승인과 기존 구현 완료를 구분한다. 게임명 `오늘도 택시`는 가제다.

## 미확정 사항

- 사용자 요청에 따라 실제 제안 참여자·직군별 인원·총인원은 **회사 제출 전 확인 필요**로 명시했다.
- 핵심 6명·8주 검증·12개월 로드맵·KPI는 회사 심의용 제안 가정이다. 기존 승인 또는 실적이 아니다.
- 회사 표준 인건비·외주 단가가 없어 비용 산정식을 제공한다. 시장 규모·매출 예상치를 임의로 넣지 않았다.
- 첨부 그림은 목표 아트 참고다. 서울 랜드마크·터치 버튼은 현재 은계 PC 빌드의 구현으로 주장하지 않는다.
- 이 제안서는 현재 기획·개발 범위 자체를 변경하지 않는다. 추가 개발은 회사/사용자 승인 후 별도 작업한다.
