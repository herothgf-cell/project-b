# 오늘도 택시 — 제안서 시연 매뉴얼 (V10)

2026-11-10 기준. 회사 내부 검토용. [제안서 V10](project-b-game-proposal-v10.pptx)의 "빌드 Prototype" 필수 항목(별도 조작 문서)이다. V8 매뉴얼에 차량 구매·차고, PvP 내 차, 영업 시간 선택을 더했다.

## 실행

- `builds/EungyeTaxi/EungyeTaxi.exe`(main 최신 실행본). 실행 폴더 전체가 필요하다.
- 통합 메뉴에서 **은계 싱글** 또는 **자체 도시 PVP**를 고른다.
- PvP LAN은 **v17**이다. 양쪽 PC 모두 최신 main 실행본이어야 하며, 이전 v16 실행본과는 접속되지 않는다.
- 기존 저장을 지키려면 이어하기를 쓰고, 새 회차 시작은 확인 후 진행한다.

## 시연 순서 A — 운송 → 내 택시 → PvP (10~15분 권장)

이번 버전의 핵심 흐름이다.

1. **은계 싱글 시작**: 영업 준비 화면의 `영업 시간`에서 하루 길이를 고른다(10/20/30/60분, 기본 20분). 시연은 10분이 편하다.
2. **운송**: M으로 호출을 고르고 승차 위치에 정차해 F로 태운다. 신호·보행자를 지키며 운전하고, 요청이 뜨면 응답한다. 목적지에 정차해 F로 내린다.
3. **정산**: 휴식·주차 거점에서 퇴근하면 수입·비용·순수익이 나온다.
   - 시간이 부족하면 Esc → 설정 → `개발용 테스트` → `지금 바로 퇴근`으로 바로 정산할 수 있다(시연·테스트용).
4. **차고**: 정산 화면의 `내 공간 · 방/차고` → `차고` 탭.
   - 택시 3종(중고 택시·하이브리드 세단·넓은 LPG 택시)의 연료·트렁크·승차감·내구도·회전 차이를 비교한다.
   - `견적 보기`로 새 차 가격, 보상 판매액, 최종 지출, 남는 현금을 확인하고 `이 차로 바꾸기`.
   - 색(2종)과 대시보드 장식(화분)도 살 수 있다. 차·꾸미기는 방 소품과 같은 개인 지출이며 영업 순수익과 따로 계산된다.
5. **새 차로 영업**: `다음 날 준비`로 넘어가면 바꾼 택시로 운행한다. 하이브리드는 큰 짐 손님 호출이 오지 않고, LPG는 회전 반경이 크다.
6. **PvP 내 차**: 메인 메뉴 → PVP. `내 차`에서 싱글에서 산 택시와 색을 고른다(안 산 차는 잠김). `봇 3대와 경기 시작`으로 내 차가 경기에 나오는 것을 확인한다. 성능은 모두 PvP 표준으로 같다.

시험 가격(조정 가능): 하이브리드 26,000원 · LPG 22,000원 · 보상 판매 기준 10,000원(내구도 100) · 색 1,500원 · 장식 2,000원. 정상 플레이로 2일차 정산쯤 살 수 있도록 잡은 **시험값**이며 확정 밸런스가 아니다. `설정 관리.cmd` → 차량에서 바꿀 수 있다(Node.js 필요).

## 시연 순서 B — 승객 응대와 생활 관리

- 취객: 대화 선택을 기억한 반응. 구토는 조건부 사건이며 발생하면 하차 후 세차.
- 잠든 승객: 수면 중 무응답은 감점 없음. 목적지에 정차해 깨운다.
- 생활: 빈차로 시설(F7)에서 주유·식사·세차·휴식. 사고 후 공업사 수리·견인.
- 작은 방: 정산 뒤 내 공간에서 조명 5,000원·러그 8,000원.

## PvP 조작 메모

- 입장 화면: 닉네임(처음 열 때 자동으로 정해지며 바꿀 수 있음), 내 차, 방 규칙(경기 시간 기본 900초 = 15분).
- 나 + 봇 3대(오프라인) 또는 LAN 최대 4명. 수입에서 시설비를 뺀 금액으로 순위를 매긴다.
