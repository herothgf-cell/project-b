# 제안서 V6 검토

2026-11-06. V5 원본을 보존하고 [23장 V6](project-b-game-proposal-v6.pptx)를 작성했다. 참여자는 사용자 확인에 따라 **미정**이다. 필수 항목의 틀과 설명은 포함했으나 실제 참여 인원 소개는 제출 전 확정이 필요하다.

## 수정 내용

- 1장: 가제 명시, 6차 버전 표기.
- 10장: 생성 목업을 실제 작은 방 화면으로 교체. 처음 방 비교와 장기 소유 이월은 후속으로 유지.
- 14·15·23장: 11월 6일 실제 UI 화면 반영. PVP 기본 나1+봇3, 최신 운전 설정과 Space 긴급 제동 구분, 현재 구현과 후속 검증 정리.
- 17·18장 노트: 공식 경쟁작 설명 재확인. 시장 규모·판매 실적을 추정하지 않음.
- 19장: 회사 승인 후 12개월 가정의 각 단계 산출물·통과 조건 보강. 기존 프로토타입 개선부터 시작하며 M2에 범위·예산 재심의.
- 20장: 핵심6명·약12/72인월은 개발 제안 가정, 공유/외주 인원과 비용 별도임을 명시.
- 21장: 이름·인원 미정, 직군/기여는 배정안으로 명시. 실제 제안 참여자와 향후 개발 인력을 분리.
- 22장: 기존 노트의 20명·80%/70%, 생활4~6명3일, 중대 결함0 목표를 본문에 제시. 실적이 아닌 제안 가정이며 미달 시 재심의.
- 별도 [V6 조작 매뉴얼](project-b-prototype-manual-v6.md) 작성. V3~V5 공용 매뉴얼 보존.

## 근거와 해석

현재 상태는 prototype-scope/checklist, content-design/02·10~14, 개인 방·제동·전체 UI·채움 아이콘 작업 이력과 현재 TaxiController/DrivingCamera/DrivingSettings 코드로 대조했다. content-design/14의 ‘모든 신규 생활 미구현’ 문구는 이후 작은 방 구현 이력보다 오래된 설명이므로 구현 판정에는 최신 이력을 적용했다.

2026-11-06 공식 설명 확인: [Taxi Life](https://store.steampowered.com/app/1351240/Taxi_Life_A_City_Driving_Simulator/), [Crazy Taxi](https://store.steampowered.com/app/71230/Crazy_Taxi/), [Euro Truck Simulator 2](https://store.steampowered.com/app/227300/Euro_Truck_Simulator_2/). 비교는 판매 우열이나 기능 부재 주장이 아닌 타겟 적합성 해석이다.

## 검증 범위

23장 PNG 전수 시각 검토, 구조/레이아웃 findings0, Malgun Gothic 원본 폰트 정책 통과, 편집 가능한 표6개, 최종 파일23장 재가져오기 통과. 원본23.5MB는 새 도구 가져오기 용량 제한으로 이미지 해상도/압축을 조정한 사본에서 편집했다. 최종 약5.85MB, 본문·표는 편집 가능하다. 원본 시안 이미지와 V5 파일은 보존했다.

실제 PowerPoint 앱의 폰트 렌더·게임 실행·물리 주행·사람3일/다른PC 검증은 이번 작업에서 수행하지 않았다. 회사 제출 전 참여자와 승인 범위·인력·예산·일정을 확정한다.
