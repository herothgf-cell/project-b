# 오늘도 택시(가제) — 프로토타입 시연 매뉴얼

2026-10-27 / 회사 내부 개발 착수 제안서 부속 문서 / project-b

## 실행 준비

- Windows에서 `builds/EungyeTaxi/EungyeTaxi.exe`를 실행한다. 실행 폴더 전체가 필요하며 exe만 복사하지 않는다.
- 현재 기본 지역은 시흥 은계다. 별도 연습과 기본 은계 영업을 구분한다.
- 기존 진행이 있으면 이어하기를 사용한다. 새 캠페인은 확인 후 이전 진행을 초기화하므로 기존 저장이 필요한 경우 주의한다.
- 실행 배포에는 지도 자료가 포함된다. 개발 PC에서 재빌드할 때는 `distribution/maps/` ZIP을 저장소 루트에 풀고 `pwsh -File tools/check_workspace.ps1 -Strict`로 검사한다.
- 본 문서와 PPT에는 실행 파일이 포함되어 있지 않다. 빌드 위치는 저장소 기준 상대 경로다.

## 기본 조작

| 입력 | 기능 |
|---|---|
| W / ↑ | 전진 입력 |
| S / ↓ | 후진 입력. 전진 중에는 감속 후 후진으로 연결 |
| A·D / ←·→ | 좌우 조향 |
| Space | 제동 |
| Q / E | 좌우 방향지시등. 조향 보조 중에는 해당 회전 요청 |
| C | 1인칭 / 3인칭 전환 |
| Z / X | 1인칭에서 좌우 확인 |
| B (누르고 있기) | 뒤보기 |
| V | 1인칭 회전 시 시선 보조 전환 |
| H | 조향 보조 켜기 / 끄기. 가감속·정지·양보는 직접 수행 |
| F | 현재 단계의 승차·경유 정차·하차·취객 다시 깨우기 |
| M | 전체지도·호출 목록 |
| F7 | 정차 중 해당 생활시설 메뉴 |
| F8 | 운송·법규 상세 기록 |
| Y / I / O / U 또는 화면 클릭 | 제시된 승객 응답 선택. 안전 정차 시 사용 |
| F5 / F6 | 우회전 / 출구 정체 연습 |
| Esc | 일반 주행 중 일시정지 / 메뉴별 닫기 |

패드 입력도 구현되어 있으나 실물 기기별 검증은 별도로 필요하다. 회사 시연은 키보드를 기본으로 한다.

## 권장 시연 순서

1. 실행 후 은계 지역·시간·연료·포만감·피로·청결을 확인한다.
2. M으로 호출의 출발·도착·예상 운임과 경로를 비교하고 수락한다. 선택만으로 수락되지는 않는다.
3. 길안내에 따라 승차 지점으로 이동한다. 지정된 차로 방향과 정차 위치를 맞추고 멈춘 뒤 F를 누른다.
4. 목적지로 직접 운전한다. 승객 요청이 발생하면 안전하게 멈춘 상태에서 화면 선택 또는 지정 키로 응답한다. 한 운송당 요청이 0~2건이므로 매번 발생하지는 않는다.
5. 하차 위치·방향을 맞추고 정차 후 F를 누른다. 최초 예상·운임 조정·실수령과 만족도 결과를 확인한다.
6. M에서 주유소·식당·휴식 거점을 선택한다. 부지 내부 지정 위치에 정차하고 F7로 가능한 서비스를 확인·선택한다.
7. 빈차 상태로 휴식 거점에서 오늘 영업 종료를 선택하고 일일 수입·비용·순수익을 확인한다.
8. 전체 검토 때는 다음 날을 이어서 3일을 완료한다. 빠른 회사 시연과 전체 캠페인 검증을 구분한다.

## 플레이 중 유의할 조건

- 하루 예정 시간은 20분이다. 경계에 도달해도 즉시 정산되지 않으며 초과 영업·피로와 연결된다.
- H는 완전 자동운전이 아니다. 정차·신호·보행자 확인은 직접 해야 한다.
- 시설 입구 도착만으로 서비스를 이용할 수 없다. 내부 정차 위치와 방향을 맞춘다.
- 승객 응답은 속도 0.1m/s 이하가 2초 유지되는 안전한 위치에서 제공된다. 교차로 충돌 영역·횡단보도·회전 중에는 입력이 보류된다.
- 일반 승하차 공간이 점유되어 있으면 원래 장소가 비기를 기다린다. 가까운 대체 장소 이동은 현재 미구현이다.
- 취객 구토 등으로 신규 운송이 잠기면 지원 주유소에서 세차한다.
- 피로 누적은 눈감김·일시 조작 제한·강제 마감으로 이어진다. 정상 수면과 강제 귀가의 결과는 다르다.
- 도착 기한을 넘겨도 승객을 목적지까지 운송하며 하차 정산은 0원이 될 수 있다.
- 게임의 운임·평가·컨디션은 게임용 값이다. 실제 요금·법적 판정·현장 정차 허가를 뜻하지 않는다.

## 현재 구현과 검증 경계

은계 지도·일반 교통·호출·길가 승객·24 정차 후보·17 요청 콘텐츠·취객·생활시설·피로/청결·일일 회계·3일 캠페인·저장/복원·별도 상황 연습이 현재 범위다. 장편 스토리·PvP·협동·차량 구매·사고 수리·보험은 포함되지 않는다.

기존 이력에 자동 검사와 빌드·배포 검증이 기록되어 있다. 이번 제안서 제작에서는 게임을 재빌드하거나 수동 주행하지 않았다. 사람의 전체 20분/3일 경제 체감, 조작감, 장시간 성능, 다른 PC 및 실물 패드는 별도 검토 대상이다.
