## 승객 반응의 전달 방식

5장은 승객의 말/상태→플레이어 대응→운행·하차 결과를 요약한다. 6~7장은 기존 이미지 컨셉에 맞춘 두 장면 시안으로 상태와 반응의 변화를 보여준다. 승객을 옮기는 기능에 기사로서 판단하고 배려하는 재미를 더한다.

- 취객: 짧게 확인하거나 조용히 안내하고, 선택을 기억한 대사·감사를 받는다. 실제 구토 때만 청결 관리로 연결한다. 매번 사고를 일으키는 유형으로 표현하지 않는다.
- 수면 승객: 조용히 운행하고 목적지 정차 뒤 깨운다. 잠든 동안 무응답은 중립이며 도착 후 깨우는 대기는 지각·추가 요금으로 소급하지 않는다.
- 응대 선택과 개별 운행 요청 수락은 구분한다. 편안한 운전 요청은 실제 관찰과 연결하지만 모든 대답이 행동 검증을 가지지는 않는다.

근거: [승객 기획](../content-design/02-passengers-and-fares.md), [요청 판정 조사](../content-tuning-request-outcomes.md), 현재 PassengerJobs.cs. 시안의 표정·포즈·좌석 구도는 목표 연출이며 현재 구현 화면이 아니다. [이미지와 생성 프롬프트](assets/v5/prompts.md).

## 생활과 구현 상태

작은 방·첫 구매 핵심은 최신 구현 이력을 반영했다. 처음 방 비교·전체 과거 방 열람은 후속, 연속 경력·차량 교체·이사는 장기 개발 제안이다. 단골·예약은 계속 제외한다. 생활/시놉시스는 content-design/10~14를 따른다.

23장 렌더 확인, PPT 구조·레이아웃·재가져오기 통과, 편집 가능한 표6개. 실제 PowerPoint 앱의 폰트 렌더와 게임 수동 플레이는 이번 작업에서 새로 검증하지 않았다.
