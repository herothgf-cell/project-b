주의:
- 차량 특성·기사 평점·PvP 내 차 연동은 **제안 단계**이며 사용자 결정 항목이 남아 있다(기획22 §8). 구현되지 않았다.
- 22장 오른쪽 그림은 V7 표지용 생성 시안의 일부이며 같은 시점 전·후 시안이 아니다. 같은 시점 시안(A-1~A-3)은 가이드에 따라 별도 생성 후 교체한다.
- 27장(8주 검증)의 "3일 체험" 문구는 3일 유지 결정과 일치하므로 그대로 둔다.
- 별도 조작 문서는 V8 Manual을 그대로 참조한다(게임 변경 없음).

검증: `validate.py --original v8` 통과, LibreOffice 렌더로 28장 전체 확인(넘침 수정 4건). 실제 PowerPoint 앱 확인은 하지 않았다.

## 2026-11-10 결정 반영 갱신

사용자 결정(기획22 §8)에 따라 3·5·8·15·16·28장의 "7일 시연판"을 "3일 안 차량 교체"로, 16장 목표 구조를 오늘·3일·장기(평점·면허는 보류 표기)로 고쳤다. 사용자 PC에서 다시 저장된 파일을 기준으로 편집했다. `validate.py --original` 통과, 15·16장 렌더 확인.
