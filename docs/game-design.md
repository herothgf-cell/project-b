# 게임 기획 개요

기준일: 2026년 10월 21일 · 버전: 1.0 · 상태: 하루20분·운전자 기획 반영, 전환 미구현

## 프로젝트 개요

| 항목 | 기획 |
|---|---|
| 가제 | 택시 운전 게임 |
| 세계관 | 경제가 어려워져 실직한 주인공이 돈을 벌기 위해 택시 운전 시작 |
| 하이 컨셉 | 짧은 택시 영업에서 정체·신호·승객 요구에 대응하며, 익숙한 길과 자신의 운전 성향을 알아가는 게임 |
| 플레이 | PC 싱글플레이, 차량 직접 조작과 선택형 조향 보조 |
| 성장 | 차량 능력치보다 운전·도로 관찰·경로 선택의 숙련 |
| 핵심 재미 | 기다리기와 우회 판단, 규칙을 지키는 운전 경험, 승객 요구와 하루 수익·컨디션 관리 |
| 공간 | 은계 기반 도로 + 상황을 위한 가상 도로·시설 허용 |
| 플레이 시간 | 하루20분 기준, 식사·휴식을 배분하며 하루 순수익 비교 |
| 프로토 기사 | 개인택시. 차량 1대가 준비된 상태에서 시작 |

## 코어 루프

| 단계 | 행동 | 다음 단계로 이어지는 결과 |
|---|---|---|
| 준비 | 연료·현금·포만감·피로 확인 | 영업 또는 거점 방문 선택 |
| 영업 선택 | 호출·길가 승객 조건 확인 | 픽업 경로 결정 |
| 운송 | 상황 판단·경로 선택·승객 요청 대응 | 운전 행동과 매너 변화 |
| 하차 | 운임 수령·승객 결과 확인 | 법규 사건은 별도 기록 |
| 유지 | 주유·식사·주차장 수면 | 비용 발생·다음 운행 준비 |
| 정산 | 하루 순수익·생활 시간·법규 성향 확인 | 이전 결과 비교·새 하루 |

## 설계 원칙

| 원칙 | 적용 |
|---|---|
| 선택의 다양성 | 대기와 합법적 우회 모두 유효, 특정 경로를 항상 정답으로 만들지 않음 |
| 단서의 가독성 | 신호·표지·보행자·대기열을 행동 전에 확인 가능 |
| 평가 분리 | 승객 매너는 운송별, 법규 성향은 여러 운행에 걸쳐 유지 |
| 현행 법규 근거 | 적용 조건·예외·시행일을 확인하고 판단 보류를 허용 |
| 짧은 체험 | 실제 거리·비용·시간은 게임 목적에 맞게 조정하고 조정값을 명시 |
| 현실성의 범위 | 실제 지역은 기반. 현재 시설·교통 규제의 완전 재현을 약속하지 않음 |

## 프로토와 장기 방향

| 프로토 목표 | 후속 후보 |
|---|---|
| 은계·대표 상황 2종·주유소/식당/주차장·개인택시 | 지역 확장·야간·날씨·추가 면허형 상황 |
| 독립 법규 점수·사건 카드·간단 성향·동일 상황 재시작 | 영상 리플레이·장기 숙련 등급 |
| 승객 기본 운송·매너·간단 요청 | 다양한 대화·음성·관계 서사 |
| 하루 수익·식사/수면·정산·기록 | 개인 예약·단골·사고·수리·보험 청구·법인 모드 |

개인 예약과 사고는 후속 기획을 작성하고 프로토타입 개발에서는 제외한다. 기존 물리 충돌·승객 매너 감점은 현행 기반이며, 사고에 따른 파손·수리비·책임 판정은 추가하지 않는다. 확정 범위는 [로드맵](content-design/00-RoadMap.md)을 따른다.
