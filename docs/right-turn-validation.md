# 우회전 보조 수정과 GitHub 등록 · 2026-10-14

## 증상과 확인

사용자는 3인칭에서 저속·고속 모두 90도 우회전을 진행하기 어렵다고 보고했다. 조향은 시점과 무관한 공통 경로이며, 같은 입력을 적용한 물리 비교에서도 1·3인칭 차이가 거의 없었다.

기존 구현은 가속키를 누른 채 끝까지 조향하면 25km/h에서 4초 만에 약75~76km/h까지 빨라졌다. 전복 방지를 위한 횡가속도 제한에 따라 조향각은 약1.7도로 줄어들었다. 결과적으로 코너에서 가속할수록 회전 반경이 커졌다. 해당 비교에서 T1·T2 우회전 구간의 3인칭 카메라 거리는 최소 약9.4m였으며 차체 안으로 당겨지는 현상은 재현되지 않았다.

## 변경

- 요구 조향각에 맞는 목표 속도를 계산해 코너에서 가속을 점진적으로 제한한다.
- 목표보다 빠르면 최대0.08의 완만한 제동 입력을 보탠다. 현재 차량 상수 기준 약2.35m/s²에 해당한다.
- 기존 최대 조향32도와 고속 횡가속도 제한은 유지한다.
- 1·3인칭과 좌·우 회전에 동일하게 적용한다. 직진 가속, 작은 조향 보정, 후진, 수동 강한 제동은 유지한다.
- 작동할 때 HUD에 ‘코너 감속 보조’를 표시한다. 고속 진입을 즉시 안전하게 만드는 기능은 아니므로 회전 전 직접 감속은 여전히 필요하다.

## 검증

- `CornerAssistTests`: 가속 유지 중 코너 감속, 좌우 대칭, 저속 가속, 직진·작은 조향·후진 보존, 수동 제동 우선, 제동 상한 등 9개 검사 통과.
- 기존 `DriveMathTests` 9개 및 매너·고속 조향 상한 검사 통과.
- 같은 물리 입력을 비교한 `-turnTest`: 4초 후 약15km/h를 유지하고 회전 가능, 차체 최대 기울기 약1도. 1·3인칭과 좌·우 대칭, 회전 방향, 카메라 최소 거리도 검사한다.
- 실제 T1·T2 `-junctionTurnTest`: 각 교차로 양쪽 진입 × 시작속도10/25km/h의 8가지 경우 모두 약2.04~2.14초에 88도 이상 우회전하고 출구 방향으로 약19.6m 이상 이동했다. 차체 접촉으로 막힌 경우는 없었다. 약90도에서 조향을 풀어 출구로 진행시키는 검사이며, 교차로 진입 위치는 도로 형상에 맞춰 지정했다.
- 기존 `-smokeTest`: 가속·제동·후진·복귀·일시정지 및 실제 T1–T2 도로 도착 통과.
- Unity Windows 빌드 성공. 비교 및 실행 로그는 로컬 `artifacts/turn-baseline.txt`, `turn-drive-test.txt`, `junction-turn-test.txt`, `turn-drive-regression.log`에 남긴다.

모든 도로 코너나 사용자 입력 패턴을 검사한 것은 아니다. 일반 차량 간섭은 분리해 검사했으며, 횡단보도·신호 판단은 운전자가 수행한다.

## 저장소 범위

GitHub에는 Unity 소스·설정·메타 파일, 변환 도구, 검사, 문서를 등록한다. 원본 NGII 파일, 추출 도형, 생성된 전체 지도 JSON, 설치 프로그램, Unity 캐시, 실행 파일과 검사 결과는 `.gitignore`로 제외한다. 저장소를 새로 받는 환경의 지도 준비 절차는 루트 README에 설명했다.
