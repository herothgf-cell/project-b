# 앞차 정체·좌회전 신호·1인칭 시야 개선

2026-10-14. 사용자가 보고한 앞차 장기 정지와 1인칭 코너 시야 문제 후속 수정.

## 원인과 변경

기존 128초 검사는 차량의 짧은 이동만 확인해 장기 대기를 놓쳤다. 새384초 검사는 차량별 반복 완주와 연속 정지시간을 측정한다. 기존 로직에서 최대94초 정지와 회전 방향별 편중을 재현했다.

교차로 진입은 정지선 가까이에 도달한 시각을 기록해 현재 진행 가능한 선두 차량 중 먼저 도착한 순서로 부여한다. 출구가 막힌 차량은 다른 방향의 진입 우선순위를 붙잡지 못한다. 차를 순간 이동시키거나 시간 초과로 삭제해서 정체를 숨기는 방식은 추가하지 않았다.

좌회전은 직진과 분리한 녹색 화살표 현시를 사용한다. 기존 직진32초 주기 뒤 주도로 좌회전8초/황색2초/전적색2초, 교차도로 좌회전8초/황색2초/전적색2초를 더한56초 주기다. 가까운 교차로의 직진·좌회전 상태를 HUD에 표시한다. AI는 회전 방향에 해당하는 신호를 기다린다. 매너 판정은 정지선 진입 시의 신호와 실제 출구 방향을 함께 확인한다.

1인칭은 좌측 사이드미러·룸미러·우측 사이드미러를 고정 화면 패널로 표시한다. 각 카메라가 실제 후방 도로와 차량을 렌더링하고 화면을 좌우 반전한다. 약30Hz, 최대180m 범위로 렌더링하며 3인칭·수동 뒤보기에서는 비활성화한다. 1인칭 깜빡이 보조 카메라는 상시 거울과 중복 표시하지 않고, 후진 보조 화면은 유지한다.

시야각82도, 조향·속도에 따른 최대18도 코너 시선 보정을 적용했다. Z/X 또는 패드 오른쪽 스틱으로 최대65도 둘러보고 놓으면 전방으로 돌아온다. V로 자동 보정을 끈다. 운전대·대시보드는 차체에 고정해 시선을 돌릴 때 함께 회전하지 않는다.

## 검증

- `ProtectedSignalTests`: 두 방향의 직진·좌회전 허용 현시가 겹치지 않는지 두 주기를0.1초 간격으로 검사. 주도로33초·교차도로45초 좌회전 화살표 허용 확인.
- `cockpitTest`: 허용 좌회전은 무감점, 좌회전 전용 현시에 직진 또는 직진 현시에 좌회전은12점 감점. 실제 화살표 표시 확인.
- 같은 검사에서 한 방향 출구에 택시를 세우고, 먼저 기다린 차량이 막혀 있어도 반대쪽의 빈 출구 방향은 진입할 수 있음을 확인.
- 거울3개 텍스처 생성·갱신, 후방 방향, 실제 후방 마젠타 표지의 렌더 픽셀4,055개 검출. 좌우65도 보기·중립 복귀·자동 코너 보기·3인칭에서 거울 숨김 확인.
- `flowTest`: 초기 배치에서384초 모의 운행. 일반 차량12대 모두2회 이상 경로 완주. 최대 연속 정지49초(기존94초), 차량별2~8회 완주. 신호 대기와 앞차 대기는 여전히 존재한다.
- `trafficTest`: 적색 정차·녹색 출발·택시 앞 장애물 정차, 기존 시점·깜빡이·일시정지 검사 통과.
- `jobsTest`: 호출·길가 승객·요금·시간 초과·중복 지급 방지·자동 보조 카메라 상태 검사 통과.
- 기존 `stabilityTest`의 혼합 교통 관찰 구간은 고정64초에서 `신호 주기×2`로 변경. 원래32초 주기에서 두 주기를 관찰하던 조건을56초 주기에도 유지한다. 모든 차량을 같은 시점에 재생성하는 시작 대기열을 포함하며, 일반 초기 배치의 정지시간 상한은 별도의384초 검사에서 확인한다.
- 최종 `stabilityTest` 재실행 통과: 112초 관찰 두 구간 모두 모든 차량 진행, 좌우회전4개 완주, 고속 조향·신호·충돌·급가감속·승하차 방향·감액 정산 검사 통과. Unity 최종 빌드 종료0, 실행 로그에서 관리 예외 없음.

로그는 `artifacts/unity-cockpit-build.log`, `artifacts/cockpit-final-*.log`, 요약은 `cockpit-smoke.txt`, `traffic-flow.txt`, `traffic-smoke.txt`, `stability-smoke.txt`, `jobs-smoke.txt`이다. 화면은 `artifacts/cockpit-mirrors.png`, `artifacts/cockpit-look-left.png`.
