# 주행 화면·전체 지도 UI 개선

2026-10-23 · **사용자 시안 승인 · 구현/자동검증 완료 · 수동플레이 확인 별도**

[인터랙션 시안](../ui/2026-10-23-cockpit-map-preview.html) · [주행 배치](../ui/2026-10-23-driving-proposal.png) · [지도 배치](../ui/2026-10-23-map-proposal.png). 배경 도로·좌표·잔액은 설명용 예시이며 실제 지도/실행 화면이 아니다. 사용자가 이 배치를 승인했고 승차·하차 지점 선택 시 포커스 기능을 추가 요청했다.

화면 설명 문구(지도 일시정지, 창작 법규, 항상 표시, 차량 색상, 정체 색상, 주유소 이용 설명)는 지도 상시 표시에서 제거하고 필요하면 정보/도움말에 둔다. 관련 기능이나 필요한 지도 출처 표시는 제거하지 않는다. 지도 모달의 기존 시간/차량 정지 규칙을 보존한다.

아이콘은 글꼴 이모지 대신 자체 도형/텍스처로 제작해 한글 글꼴에서 빈 사각형으로 보이지 않게 한다. 작은 화면에서는 대화·호출 목록이 도로 중앙과 조작 버튼을 가리지 않도록 너비와 여백을 조정한다. 색 외에도 번호·모양·선택 테두리로 상태를 구별한다. 네이버 지도는 배치 참고이며 지도 타일/로고를 복제하지 않는다.

## UI와 독립적으로 진행하는 기능

- 1인칭 자동 코너 시선 이동 기본 해제. 차체 롤/피치 분리, 회전 방향은 짧게 평활. Z/X 수동 확인·B 뒤보기·V 선택적 코너 보기 유지.
- 수동 저속 조향 한도를 약48도로 확대, 추가 조향은30km/h까지 줄이고 이후 기존 제한 사용. H 조향 계산은 기존 유지. 1/3인칭에 동일한 차체 성능 적용.
- 현금10,000원 시작, 운임 입금/식사·주유 결제 즉시 잔액 반영은 기존 장부를 재사용. 순수익=현금−시작금−미납이며, 정산 시 이미 처리한 비용을 다시 차감하지 않는다.
- 제육백반·된장찌개 정식·소고기국밥을 기존 식당 확인 화면에서 선택. 모두 기존 게임값3,000원/50초/포만감+70(시간 경과 먼저 적용,최대100). 메뉴 선택/취소는 무료, 확정 시1회 결제. 실제 음식 가격이나 영양 수치가 아니다.

## 승인 후 추가 동작

전체지도에서 진행 중 운송 또는 선택한 호출의 승차·하차 핀과 우측 승차/하차 버튼을 클릭하면 해당 지점 중심으로 최소2배 확대한다. 내비 목적지·경유지·요금·승객 상태는 변경하지 않는다. 호출번호 핀/목록 클릭은 선택만 하며 별도 수락 때 지도 모달을 닫고 기존 배차로 전달한다. 정지 상태에서 연 지도를 닫으면 원래 정지 상태를 복원하고 이 경우 호출 수락은 막는다. 기존1/2/3 즉시 수락은 제거하며 길가F 승차는 유지한다.

지도내 좌표 버튼은 팝업/복사,법규는 기본OFF,필터는 도형아이콘/툴팁. 밝은 지도는 기존 자체도로/수역 타일의 색을 변환하며 외부타일을 사용하지 않는다. 지도출처는 유지한다. 주행 중 큰속도·기존3종도형게이지·현재잔액·누적순수익,상단정보/퇴근/도움말,좌상단신호/내비,우하단2점수,중앙하단대화로 재배치한다. 날짜준비·정산·재시작 화면의 장부는 유지한다.

## 2026-10-23 플레이 피드백 반영

| 항목 | 수정된 동작 |
|---|---|
| 도움말 | 화면 중앙, 해상도 비례 크기, 닫기 버튼. 좌하단 속도계와 겹치지 않음 |
| 상단 정보 | 기존 운행 점수 사건/운송 기록(F8) 열기. 우하단 기록 버튼 제거 |
| 두 점수 | 만족도 웃는 얼굴 / 운행 점수 방패 도형 아이콘 + 숫자 + 게이지. 두 평가는 별도 유지 |
| 위치 정보 | 전체지도 내 독립 패널에 지역·지도 좌표·방향·인근 교차로 표시, 복사/닫기. 중첩 모달 제거 |
| 시설 선택 | 미니맵/M에서 주유기·식기·P·침대 아이콘 클릭 → 우측 시설명/메뉴/이용 조건/입구 경로 → 길안내 시작 |
| 일반 지점 | 미니맵 클릭 또는 M 지도 클릭(드래그와 구분) → 인근 연결 가능한 차로 미리보기 → 길안내 시작. 주정차 허용 보장은 아님 |
| 호출 선택 | 번호 핀/목록 클릭 → 승차~하차 경로 미리보기. 수락 전 운임/승객/내비를 바꾸지 않음 |
| 표시 기본값 | 도로 상황/차량과 법규 구역 OFF. 시설 ON. M 필터가 미니맵에도 적용 |
| 경로 혼잡 | 동일 방향 차량 관측/정차 사건의 기존 RoadConditions.ExtraSeconds 사용. 구간 추가 지연 2초 미만 초록, 2~6초 미만 주황, 6초 이상 빨강. 게임 관측값이며 외부 실시간 교통정보 아님 |
| 성능/보호 | 경로 색/시설 목록은 1초 캐시. 운송 중 시설 확인은 가능하나 시설 길안내로 승객 목적지 변경 금지. 시설 안내는 입구까지만, 내부 진입/정차/F7 사용은 직접 수행 |

호출 미리보기는 차로 연결의 기본 경로이며 실제 안내는 교통/선호에 따라 다시 탐색할 수 있다. 상황 필터를 꺼도 경로 혼잡 색상은 유지한다. 기존 시안 HTML은 이전 배치 참고 자료이고 현재 동작은 실행파일이 기준이다.
