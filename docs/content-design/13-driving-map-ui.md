# 주행 화면·전체 지도 UI

승인된 주행 배치와 M 전체지도 동작을 정리한다. 점수·운임·생활 규칙은 각 원문을 따르며 이 문서는 표시·입력·미리보기 동작을 정의한다.

## 주행 배치와 정보

| 영역 | 표시·동작 | 조건 |
|---|---|---|
| 실행 직후 | `택시 시뮬래이터` / `지도를 준비 중입니다.` 후 단계별 준비 안내 | 월드 생성 전에 먼저 렌더링, 기존 저장 폴더명/저장 위치는 변경하지 않음 |
| 좌측 상단 | 지역·시각·캠페인 일차/시간·정보·퇴근·도움말 | 지역 제목과 내비 회전 제목은 보통 굵기. 정보는 기록F8 열기 |
| 좌측 상단 안내 | 신호 상태/남은 초·회전/차로/거리/예상 분 | 실제 게임 신호 사용, 교육 조건 신호는 가짜 남은 초 없음 |
| 좌측 하단 | 큰 속도·단위·기어/수동 또는 보조, 연료·포만감·피로 아이콘/게이지/수치 | 해상도별 한 줄/줄바꿈 조정 |
| 연료 오른쪽 | 차량 청결 아이콘·게이지·수치 | 30미만 `세차 필요`, [취객·청결15](15-drunk-passengers-and-cleanliness.md) |
| 상단 잔액 | 현재 잔액 강조·누적 순수익 보조 | 장부의 실제 입출금 반영, 중복 비용 차감 없음 |
| 하단 중앙 | 승객 말풍선·선택 버튼 | 요청 없으면 숨김, 정차 응답 조건은 [요청11](11-passenger-request-effects.md) |
| 요청 패널 위 | 취객 소개·반복 대사·구토 경고/발생·길가 승차 거부 전용 대사 | 긴 요청 선택지를 덮지 않음. 조용한 약속은 일반 수다만 억제하고 구토 경고/발생은 표시 |
| 우측 하단 | 승객 만족도S/요구R·운전 점수 별도 카드 | 만족도 웃는 얼굴·운전 점수 방패, 숫자/게이지. 요구R은 흰 눈금 |
| 상황 TIP | 왼쪽 호출 카드 아래·속도계 위, 숨기기/펼치기 | 서비스 길안내·오류 안내도 같은 카드에 통합, 긴 내용 내부 스크롤 |
| F7 거점 | 도착한 시설의 해당 서비스만 모달 표시 | 시설 밖은 M 안내만 표시하며 시간을 멈추지 않음. 시설 간 이동은 M 지도 |
| 도움말 | 중앙의 해상도 비례 패널·닫기 버튼 | 속도계와 겹치지 않음 |

## 점수 변화·운송 결과

| 표시 | 데이터·동작 | 예외·보존 |
|---|---|---|
| 만족도 | 실제S와 요구R, 시작 점수/청결 포함 안내 | 내부 운전 만족도M을 S 대신 표시하지 않음 |
| 운전 점수 | 캠페인 법규 장부의 현재 점수·실제 준수/위반 변화 | 승객 요청·만족도로 법규 점수 가감 없음 |
| 즉시 알림 | `원인 · 증감치`, 만족도/운전 작은 구분표시. 최대4개 동시·각3초 | 이전 알림 종료를 기다리지 않음. 부호/색 병용, 새 승객 시작값을 가짜 획득으로 알리지 않음 |
| 정산3줄 | `최초 예상 운임` / `운임 조정` / `실수령` | 운임 조정=실수령−최초 예상 운임, 음수/0/양수 부호. 내부 계산 보너스와 구분 |
| 구형 결과 | 최초 예상 운임 없으면 보존된 약정 운임 사용 | 둘째 줄 명칭은 저장 버전과 무관하게 `운임 조정` |
| 완료 만족도 | 최종S/요구R 게이지와0이 아닌 청결/주행/요청 이행/도착 시간 증감 | 긴 시작 계산식·청결 포함 설명·요청 대사/ETA 비교는 완료 팝업에서 생략 |
| 상세F8/저장 | 요청 원문/판정·시작값·주행/요청/안심 회복/시간, 승차 운전 점수·보정 운임·감액·계산용 보너스 | 신규 결과는 하차 시 운전 점수 보존. 긴 상세는 스크롤 |
| 호출 만료 | 탑승하지 않은 호출 취소 표시 | 이전 승객 만족도·가짜 탑승 알림 없음 |

운임 수치는 [04 운임과 보너스 계산](04-passengers-and-reservations.md#운임과-보너스-계산), 운전 점수는 [02 평가](02-driving-evaluation.md)를 따른다. 정산의 `운임 조정`은 모든 운임 변화가 합쳐진 화면용 순증감이며 계산용 보너스 지급액의 직접 표시가 아니다.

## 지도 조작·필터

2026-10-27 추가 간소화: 호출 행은 승차/하차 식별과 예상 운임만 표시한다. 원약정·점수 보정 계산식·지역 수요·경로 비교·기한은 행에서 제외하고 기존 수락 조건/내부 계산은 유지한다. 시설 선택 패널은 시설명/지원 기능·거리·길안내 버튼만 두고 긴 이용 설명은 현장 F7/TIP에서 안내한다. 한글 툴팁은 고정 한 줄 대신 실제 줄 높이로 감싼다. 시설 내부 출발은 지정 출구까지 수동 이동 경로 후 기존 연결 차로 내비를 이어간다. 임의 도로 스냅 반경은 늘리지 않는다.

승차·하차·경유 핀은 해당 정차 차로의 진행 방향 화살표와 함께 표시한다. 화살표는 북쪽 위 지도 기준 `(dx,-dz)`이며 승객의 보도 측면 위치가 아니라 **차량이 맞춰 정차할 방향**이다. 주요 시설 핀은 `주유 전용`/`주유+세차` 지원도 표시한다.

| 동작 | 규칙 |
|---|---|
| M/닫기 | 전체지도 열기/닫기, Esc도 닫기. 모달 중 시간/차량 정지, 닫을 때 이전 일시정지 상태 복원 |
| 확대·이동 | M지도1~8배, 휠/+/−와 드래그. 지도 안 우하단+/−/내 위치, 전체 보기 버튼 없음 |
| 미니맵 | +/− 키·숫자패드·버튼으로300/450/650/1,000/1,500/2,300m 단계, 북쪽 고정·차량 중심. 최대 범위는 은계 전체 |
| 위치 | 상단 위치 버튼→지역·좌표·방향·인근 교차로 독립 패널, 복사/닫기. 중첩 모달 없음 |
| 필터 | 시설ON·교통/법규OFF 기본, 같은 실행 내 선택 유지. M 필터를 미니맵에도 적용 |
| 항상 표시 | 내 위치·승하차·현재 내비·빈차 호출 핀은 필터와 독립. 화면 밖 목표/호출은 가장자리 방향/번호 |
| 법규 표식 | 미니맵은 화살표/대기열/신호 기호, 상세 또는 M에서 이름 |
| 색·출처 | 밝은 지도는 자체 도로/수역 타일 색 변환. 외부 지도 타일·로고 복제 없음, 지도 출처 유지 |

시설·교통·법규 필터는 도형 아이콘·툴팁·선택 테두리를 사용한다. 필터를 꺼도 법규 평가·상황·경로 혼잡색은 유지한다. 지도 일시정지/게임 시설/차량 색상 같은 상시 설명 문장은 필요할 때 도움말에서 제공한다.

## 호출·시설·운송 경로

| 선택·상태 | 표시와 행동 | 상태 보호 |
|---|---|---|
| 호출 핀/목록 | 모든 가용 호출 표시, 번호 클릭은 선택/포커스·승차~하차 미리보기 | 별도 수락 버튼에서 확정. 기존1/2/3 즉시 수락 제거, 길가F 승차 유지 |
| 호출 진입 | 주행·미니맵·M에서 `주변 호출 보기 (M)` | 시설 선택 중에도 호출 목록은 시설 정보 아래 유지 |
| 수락 | 완료 결과 임시 상태 정리 후 기존 배차로 전달·지도 닫기 | 일시정지 복원 대상·마감·경로 단절 등 제한 사유 표시. 미구현 배정안은 [04](04-passengers-and-reservations.md#요청-배정과-등장-시점--변경-기획-미구현) |
| 승차 접근 | 현재 차량→승차는 하늘색 외곽 실선, 승차→하차는 분홍 외곽 점선, 우측 접근 거리 | 수락 후 픽업 동안 두 경로, 탑승 후 운송 경로만 |
| 승하차 위치 | 진행 운송 또는 선택 호출의 핀/우측 버튼 클릭→해당 지점 중심 최소2배 확대 | 목적지·경유지·요금·승객 상태 변경 없음 |
| 시설 선택 | 주유기·식기·P·침대 아이콘→시설명/메뉴/조건/입구 경로 | 현재 위치와 입구를 함께 보도록 범위 조정. 식당 이용·결제 자동 실행 없음 |
| 일반 지점 | 미니맵/M 클릭(드래그와 구분)→연결 가능한 차로 미리보기 | 주정차 허용 보장 아님 |
| 길안내 시작 | 빈차에서 명시 선택해야 실제 목적지 설정 | 시설 안내는 입구까지, 내부 진입/정차/F7은 직접 수행 |
| 운송 중 시설 미리보기 | 승차·하차 핀 유지, 활성 경유 요청은 경유 핀/우측 위치 버튼 유지 | 진행 운송 목적지·운임·영업 상태 보호 |
| 운송 경로 복귀 | 시설 정보 아래 `운송 경로로 돌아가기`→현재 승차/하차/경유 안내 복원 | 지도 개방 시 이전 시설 미리보기보다 진행 운송 경로 우선 |
| 혼잡색 | 관측 추가 지연2초 미만 초록,2~6초 미만 주황,6초 이상 빨강 | 게임 관측값. 외부 실시간 교통정보 아님. 경로색/시설 목록1초 캐시 |

호출 미리보기는 기본 차로 연결 경로이며 실제 안내는 교통/선호에 따라 다시 탐색할 수 있다. 공유 구간도 접근 실선과 운송 점선의 외곽색으로 구분한다.
