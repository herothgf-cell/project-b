화면 설명 문구(지도 일시정지, 창작 법규, 항상 표시, 차량 색상, 정체 색상, 주유소 이용 설명)는 지도 상시 표시에서 제거하고 필요하면 정보/도움말에 둔다. 관련 기능이나 필요한 지도 출처 표시는 제거하지 않는다. 지도 모달의 기존 시간/차량 정지 규칙을 보존한다.

아이콘은 글꼴 이모지 대신 자체 도형/텍스처로 제작해 한글 글꼴에서 빈 사각형으로 보이지 않게 한다. 작은 화면에서는 대화·호출 목록이 도로 중앙과 조작 버튼을 가리지 않도록 너비와 여백을 조정한다. 색 외에도 번호·모양·선택 테두리로 상태를 구별한다. 네이버 지도는 배치 참고이며 지도 타일/로고를 복제하지 않는다.

## UI와 독립적으로 진행하는 기능

- 1인칭 자동 코너 시선 이동 기본 해제. 차체 롤/피치 분리, 회전 방향은 짧게 평활. Z/X 수동 확인·B 뒤보기·V 선택적 코너 보기 유지.
- 수동 저속 조향 한도를 약48도로 확대, 추가 조향은30km/h까지 줄이고 이후 기존 제한 사용. H 조향 계산은 기존 유지. 1/3인칭에 동일한 차체 성능 적용.
- 현금10,000원 시작, 운임 입금/식사·주유 결제 즉시 잔액 반영은 기존 장부를 재사용. 순수익=현금−시작금−미납이며, 정산 시 이미 처리한 비용을 다시 차감하지 않는다.
- 제육백반·된장찌개 정식·소고기국밥을 기존 식당 확인 화면에서 선택. 모두 기존 게임값3,000원/50초/포만감+70(시간 경과 먼저 적용,최대100). 메뉴 선택/취소는 무료, 확정 시1회 결제. 실제 음식 가격이나 영양 수치가 아니다.
