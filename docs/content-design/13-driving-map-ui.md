# 주행 화면·전체 지도 UI 개선

## 2026-10-26 운송 중 지도 미리보기

- 진행 중인 호출은 시설이나 임의 도로를 미리보는 동안에도 승차·하차 핀을 유지한다. 승객 경유 요청이 활성화된 경우 경유 핀과 우측 경유 위치 버튼도 표시한다.
- 시설 정보 아래의 `운송 경로로 돌아가기`는 선택한 시설 미리보기를 지우고 현재 운송의 승차·하차 또는 경유 안내를 다시 표시한다. 지도 개방 시 남아 있던 미리보기보다 진행 중인 운송 경로를 우선 표시한다.
- 미리보기·복귀는 승객 목적지, 경유 요청, 운임, 영업 상태를 바꾸지 않는다. 실제 길안내 시작은 빈차에서만 가능하다.

## 2026-10-23 추가 · 즉시 점수 알림과 간단 운행 결과

| 부분 | 현재 표시 |
|---|---|
| 운행 중 점수 변화 | 화면 상단에 `원인 · 증감치`만 표시. 만족도/운행은 작은 구분표시로 분리. 예: `급제동 · -2`, `신호 위반 · -20`, `요청 이행 · +5` |
| 알림 시점 | 이전 알림의4초 종료를 기다리지 않고 즉시 표시. 최대4개 동시,각3초 뒤 사라짐. 부호·색상 모두 사용,새 승객 시작값을 가짜 점수 획득으로 알리지 않음 |
| 운송 완료 정산 | `기본 운임`=수락/길가 승차 당시 최초 예상 운임, `보너스`=실제 받은 돈−최초 예상 운임(증가/감소 부호), `최종 운임`=실제 지급액 |
| 운송 완료 만족도 | 최종S/요구R 게이지 유지, 아래에는0이 아닌 `청결 · +3`, `주행 · -43`, `요청 이행 · +5`, `도착 시간 · +6`만 표시. 긴 시작 계산식·청결 포함 설명·요청 대사/ETA 비교는 완료 팝업에서 생략 |
| 상세 기록 | 요청 원문/판정·시작값·주행/요청/시간·실제 기본 운임/계산용 보너스는 F8/저장 기록에 보존 |

완료 팝업의 보너스 줄은 **최초 예상 운임 대비 증감 표시**다. 내부 만족도 보너스 산식/기본 운임 M기준 지급률/시간 초과0원 정책은 변경하지 않는다. 예: 최초5,000원→실제3,500원이면 보너스-1,500원·최종3,500원. 최초 운임 저장이 없는 기존 결과는 보존된 약정 운임으로 표시한다. 세부 밸런스는 사용자 직접 플레이 확인으로 남긴다.

2026-10-26 결과 팝업은 위 3줄 요약 아래에 지급 판단을 두 줄로 설명한다. 기본 운임은 운전 만족도 `M`과 요구 `R`을 비교해 기한 내 100%/70%, 보너스는 최종 승객 만족도 `S`와 `R`을 비교해 지급한다. 따라서 `S=60<R=70`이어도 `M=100`이면 기본 운임은 100%이고 보너스는 0원이다. 청결·요청·시간 변화는 `S`에만 반영된다.

화면 설명 문구(지도 일시정지, 창작 법규, 항상 표시, 차량 색상, 정체 색상, 주유소 이용 설명)는 지도 상시 표시에서 제거하고 필요하면 정보/도움말에 둔다. 관련 기능이나 필요한 지도 출처 표시는 제거하지 않는다. 지도 모달의 기존 시간/차량 정지 규칙을 보존한다.

아이콘은 글꼴 이모지 대신 자체 도형/텍스처로 제작해 한글 글꼴에서 빈 사각형으로 보이지 않게 한다. 작은 화면에서는 대화·호출 목록이 도로 중앙과 조작 버튼을 가리지 않도록 너비와 여백을 조정한다. 색 외에도 번호·모양·선택 테두리로 상태를 구별한다. 네이버 지도는 배치 참고이며 지도 타일/로고를 복제하지 않는다.

## UI와 독립적으로 진행하는 기능

- 1인칭 자동 코너 시선 이동 기본 해제. 차체 롤/피치 분리, 회전 방향은 짧게 평활. Z/X 수동 확인·B 뒤보기·V 선택적 코너 보기 유지.
- 수동 저속 조향 한도를 약48도로 확대, 추가 조향은30km/h까지 줄이고 이후 기존 제한 사용. H 조향 계산은 기존 유지. 1/3인칭에 동일한 차체 성능 적용.
- 현금10,000원 시작, 운임 입금/식사·주유 결제 즉시 잔액 반영은 기존 장부를 재사용. 순수익=현금−시작금−미납이며, 정산 시 이미 처리한 비용을 다시 차감하지 않는다.
- 제육백반·된장찌개 정식·소고기국밥을 기존 식당 확인 화면에서 선택. 모두 기존 게임값3,000원/50초/포만감+70(시간 경과 먼저 적용,최대100). 메뉴 선택/취소는 무료, 확정 시1회 결제. 실제 음식 가격이나 영양 수치가 아니다.

## 승인 후 추가 동작

전체지도에서 진행 중 운송 또는 선택한 호출의 승차·하차 핀과 우측 승차/하차 버튼을 클릭하면 해당 지점 중심으로 최소2배 확대한다. 내비 목적지·경유지·요금·승객 상태는 변경하지 않는다. 호출번호 핀/목록 클릭은 선택만 하며 별도 수락 때 지도 모달을 닫고 기존 배차로 전달한다. 정지 상태에서 연 지도를 닫으면 원래 정지 상태를 복원하고 이 경우 호출 수락은 막는다. 기존1/2/3 즉시 수락은 제거하며 길가F 승차는 유지한다.

지도내 좌표 버튼은 팝업/복사,법규는 기본OFF,필터는 도형아이콘/툴팁. 밝은 지도는 기존 자체도로/수역 타일의 색을 변환하며 외부타일을 사용하지 않는다. 지도출처는 유지한다. 주행 중 큰속도·기존3종도형게이지·현재잔액·누적순수익,상단정보/퇴근/도움말,좌상단신호/내비,우하단2점수,중앙하단대화로 재배치한다. 날짜준비·정산·재시작 화면의 장부는 유지한다.

## 호출과 시설 함께 보기·경로 두 구간 (2026-10-23 추가)

- 미니맵 호출 보기 버튼과 번호 핀을 시설 아이콘과 함께 제공. 범위 밖 호출은 가장자리 번호로 표시. M에서 시설을 선택한 상태도 호출 핀 유지.
- 호출 선택 직후 현재 차량→승차는 실선/검정 외곽, 승차→하차는 점선/분홍 외곽으로 표시. 내부 혼잡색은 기존 초록·주황·빨강 유지. 수락 후 승차하러 가는 동안 두 경로 유지, 탑승 후 운송 경로만 표시.
- 식당 등 시설을 클릭하면 현재 위치→입구 경로를 즉시 미리보고 두 지점이 함께 보이도록 지도 범위를 자동 조정. 명시적 길안내 시작/운송 중 목적지 보호는 유지. 식당 이용·결제가 자동 실행되지는 않음.
- 호출 선택도 접근/운송 경로를 포함하는 범위로 표시하며, 승차/하차 개별 버튼은 기존처럼 해당 지점 포커스.
