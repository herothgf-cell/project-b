# 현재 승객 유형·요청·선택·효과 대조표

작성: 2026-11-13. 다양화 기획을 위한 현황 정리이며 신규 기능 제안이나 구현 변경이 아니다.

## 기준과 읽는 법

- `config/content/default-profile.json`의 현재 기본값과 그 안의 `passenger.presets`를 기준으로 한다. 기존 캠페인/사용자 active-profile의 저장값은 다를 수 있다. 배포 실행본을 이번에 실행해 확인한 결과는 아니다.
- 기획02·07·15~17·19·20, 밸런스 문서와 현재 요청/행동 소스를 대조했다. 과거 문서의 수치보다 현재 기본 프로필의 `choice.*` 및 승객별 덮어쓰기를 우선한다.
- S=승객 만족도, F=기사 피로, M=운전 점수. F+는 불이익이다. 아래 대사는 비교를 위한 요약이며 원문 선택지는 뒤의 데이터 표를 참고한다.
- 활성 프리셋29종/전체30종. 활성은 등장 후보라는 뜻이며 차량의 짐 적재 가능 여부·노선·배정 그룹·요청 가용성에 따라 실제 후보가 제한된다.
- 운행 중 요청14종, 하차 후 분실물1종. ShortRoad/RouteAdvice 및 경로 확인 프리셋은 기본 비활성이다.
- 요청0/1/2건 비중=5/40/55%, 평균1.5건. 운행 중 배정 시점15~65%, 응답 후 실제 주행12초 간격, 진행85% 이후 신규 요청 마감. 경로형 요청끼리 중복하지 않으며 Quiet와 대화형 요청의 충돌도 제한한다.
- 유형 응대와 요청 수락은 별개다. 예: 면접 승객의 첫 인사에 답해도 Interview가 자동 배정되거나 OnTime을 수락한 것이 아니다.

## 1. 승객의 행동 유형과 선택 효과

| 행동 유형 | 대화 선택 요약 | 공통 효과·실제 행동 |
|---|---|---|
| 일반·조용함 | 일반은 별도 유형 선택 없음 | 별도 배정 요청에 응답. 조용함은 일반 수다 억제 |
| 취객 | 짧게 확인·설명 / 운전에 집중하며 조용히 안내 | 선택 추가 S/F0. 구토 예정25%, 기상 지연30%; 실제 구토 시 청결을 최대10으로 낮추고 세차 전 신규 호출 잠금 |
| 수면 | 확인·도착 안내 / 조용한 배려 | 선택 추가 S/F0. 이동 중 수면, 도착 후 깨우기. 수면 중 대화 미응답은 중립 |
| 편안한 운행 | 확인·설명 / 집중 안내 | 유형 선택 S/F0. 별도 Comfort 요청의 수락·실제 운전으로 평가 |
| 급한 승객 | 시간 확인·설명 / 안전 운행 안내 | 유형 선택 S/F0. 변주별 ETA 또는 OnTime 대표 요청 후보 |
| 경유 용무 | 용무 확인 / 집중 안내 | 유형 선택 S/F0. 별도 ViaStop 수락 시 안전 경유지에서20초 무료 대기 |
| 짐 | 적재·하역 / 적재 거절 | 공통 S/F0. 수락 시 적재10초+하역10초, 거절 시 작업 없음 |
| 흙 묻은 짐 | 보호 / 그대로 / 적재 거절 | 공통 S/F0. 보호10초로 추가 오염 방지; 그대로면 하차 청결−5; 거절 시 작업 없음 |
| 음식 | 밀봉 / 섭취 허용 / 정차 후 정리 | 밀봉 S0; 허용 즉시S+3, 실제 섭취 청결−2, 흘림25%로 추가−6; 정리10초·S0 |
| 정확한 정차 | 하차 장소 확인 / 원래 운행 안내 | 유형 선택 S/F0. 별도 SafeStop 요청을 수락해야 장소 변경·평가 |
| 수다 | 이야기 듣기 / 집중 운행 안내 | 공통 S/F0, 후속 일반 대사 조절. 아래 개별 승객은 별도 효과 있음 |
| 메스꺼움 보조 특성 | 안전 정차 휴식 / 봉투 준비 | 공통 휴식8초·불편35 완화. 봉투는 사건 시 오염 예방. 미준비 사건은 청결−8. 아래 멀미 승객 개별값 우선 |
| 온도 민감 보조 특성 | 따뜻하게 / 시원하게 / 현재 유지 | 공통 선호 일치15초 S+3, 불일치20초 S−2. 수정 성공 시 −2와 +3을 누적하지 않고 성공 결과로 교체 |
| 젖은 우산 보조 특성 | 감싸기 / 그대로 | 공통 보호6초 또는 실제 탑승 청결−3. 아래 우산 승객 개별값 우선 |

취객·수면의 첫 유효 도착에 기한/운임을 확정하며 깨우는 시간을 소급 지각으로 보지 않는다. 작업 시간에는 영업시간이 흐른다. 온도는 승객 상태 모델이며 실제 에어컨 물리 시뮬레이션은 아니다.

## 2. 개별 승객의 공통값 대비 차이

기본11종 활성(일반·취객·수면·편안한 운행·급한 승객·경유 용무·짐·흙 묻은 짐·음식·정확한 정차·수다)에 다음18종이 추가되어29종이다. 비활성 경로 확인1종은 제외했다.

| 승객 | 특성·선택 | 개별 효과·시간 |
|---|---|---|
| 조용한 출근 손님 | 조용함 | Quiet 배정·수락·성공 시 S+3, 별도 대표 요청 보장 없음 |
| 야간근무를 마친 손님 | 조용함+수면; 도착 안내 / 조용한 배려 | 어느 선택이든 즉시S+1, 흔들림 후 안정6초 |
| 면접을 앞둔 손님 | 조용함+급함 | OnTime 성공+6/실패−3. Interview 요청 자동 배정 아님 |
| 부드러운 운행을 원하는 손님 | 조용함+승차감 | Comfort 성공+6/실패−4 |
| 동네 이야기를 좋아하는 손님 | 수다; 듣기 / 집중 안내 | 즉시 S+2·F+1 / S+1·F0 |
| 조용히 귀가하는 음주 손님 | 조용함+음주; 쉬기 안내 / 상태 확인 | 어느 선택이든 즉시S+1. 구토15%, 기상 지연40% |
| 모임을 마친 수다 손님 | 수다+음주; 듣기 / 쉬기 안내 | 즉시 S+2·F+1 / S+1·F0. 구토30%, 기상 지연15% |
| 여행 가방을 든 손님 | 조용함+짐; 적재 / 거절 | 적재 즉시S+2, 적재8초+하역8초. 거절S0 |
| 화분을 들고 경유하는 손님 | 오염짐+경유; 보호 / 그대로 / 거절 | 보호8초·S+1; 미보호 청결−4. 경유 수락 시15초, 요청 성공+5/실패−4 |
| 간식을 든 출근 손님 | 음식+승차감; 밀봉 / 허용 / 정리 | 즉시S+1/+2/0. 정리6초, 섭취 청결−1, 흘림15%·추가−4. Comfort 성공+5/실패−3 |
| 짐을 싣고 용무를 보는 손님 | 짐+경유; 적재 / 거절 | 적재S+2, 적재6초+하역6초. 경유15초, 요청 성공+5/실패−4 |
| 안전한 하차를 부탁하는 손님 | 조용함+안전 하차 | SafeStop 성공+5/실패−3 |
| 간식을 들고 졸고 있는 손님 | 수면+음식; 밀봉 / 깨어 있을 때 허용 / 정리 | 허용S+3(공통), 섭취 청결−1, 흘림15%·추가−6(공통), 정리10초. 잠든 동안 섭취·흘림 중지 |
| 여행 가방과 함께 쉬는 손님 | 수면+짐; 적재·도착 시 깨우기 / 거절 | 유형 선택S0, 적재7초+하역6초, 깨우기와 하역 모두 끝나야 정산 |
| 화분을 들고 쉬는 손님 | 수면+오염짐; 보호 / 그대로 / 거절 | 유형 선택S0, 보호7초, 미보호 청결−4. 별도 하역시간 없음 |
| 멀미가 걱정되는 손님 | 메스꺼움+승차감; 정차 휴식 / 봉투 | 사건 예정65%, 이동 중 불편 초당0.4. 휴식7초·40완화, 봉투 없는 사건 청결−6. Comfort 별도 평가 |
| 차내 온도에 민감한 손님 | 따뜻하게 / 시원하게 / 현재 유지 | 선호 일치12초 S+4, 불일치18초 S−2. 한 번 수정 가능, 성공 시 결과 교체 |
| 젖은 우산을 든 손님 | 감싸기 / 그대로 | 보호5초 또는 탑승 청결−2 |

## 3. 활성 운행 요청14종

표의 수치는 공통값이다. 위 개별값이 있으면 해당 승객에게 우선 적용한다. 보류/원래대로 선택의 추가S/F는0이다.

| 요청 | 승객 요청 요약 | 플레이어 선택 → 효과 | 실제 행동·판정 |
|---|---|---|---|
| Quiet 조용한 운행 | 조용히 운행해 주세요 | 수락 → 종료S+3 / 보류 →0 | 수락 후 자발적 잡담 위반 시 종료S−5. 현재 말 걸기 UI는 숨김, 안전 안내 제외 |
| Eta 도착 시간 | 얼마나 걸리나요 | 조금 빠르게 / 내비대로 / 여유 있게 → 각각 즉시S+1; 보류0 | 예상 안내만 변경, 기한·속도 변경 없음. ETA 오차 자체 감점 없음 |
| Comfort 편안한 운행 | 멀미가 나니 부드럽게 | 수락 → 성공S+6/실패−4; 보류0 | 불필요한 급가감속 M 추가−1, 필요한 안전제동 제외 |
| OnTime 정시 도착 | 규칙을 지키며 제시간에 | 수락 → 성공S+6/실패−3; 보류0 | 기한·실제 위반으로 판정. 합법 지연 등 판정불가0 |
| LargeRoad 큰길 | 골목 대신 큰길 | 수락 → 성공S+5; 보류0 | 실제 큰길 우선 경로 적용·이행 관찰, 불가/판정불가0 |
| SafeStop 안전 하차 | 가까운 안전한 곳에 하차 | 장소 변경 → 성공S+4/실패−4; 원래대로0 | 검증된 하차 후보와 장소·운임 안내를 사용 |
| Empathy 고민 이야기 | 속상한 일이 있어요 | 듣기 → 즉시S+3·F+1 / 조용한 배려 →S+2·F0 / 보류0 | 대화 응대, 별도 후속 퀘스트 없음 |
| Interview 면접 응원 | 면접을 잘 볼 수 있을까요 | 응원 → 즉시S+3 / 조용한 준비 →S+2 / 보류0 | 실제 면접 결과·합격 보상 없음 |
| Music 음악 | 음악을 바꿔 주세요 | 변경 어려움 안내 / 보류 →모두0 | 실제 음악 변경 기능 없음 |
| FareHelp 요금 안내 | 택시비가 부족한데 요금을 알려 주세요 | 약정 안내 →즉시S+2 / 하차 때 확인 →S+1 / 보류0 | 할인·외상·추가 부채 기능 없음 |
| LocalChat 지역 대화 | 이 동네에서 오래 일했나요 | 짧은 대화 →즉시S+3·F+1 / 안전 운행 안내 →S+2·F0 / 보류0 | 승객 요청 대화는 활성, 운전자가 먼저 하는 말 걸기 UI와 별개 |
| DestinationChange 목적지 변경 | 다른 지점으로 바꿔 주세요 | 변경 →성공S+4/실패−4; 원래대로0 | 새 목적지·운임·기한을 확인하고 같은 운송 변경 |
| ViaStop 경유 용무 | 잠깐 들렀다 가 주세요 | 수락 →성공S+5/실패−4; 거절0 | 안전 경유지 정차·용무20초 후 원래 목적지, 일부 승객15초 |
| RejectIllegal 불법 요구 | 빨간불에도 가 주세요 | 안전 거절 →즉시S+1 / 보류0 | 불법 수락 선택 없음, 실제 위반은 별도 법규 평가 |

공통 미응답: 안전한 응답 기회를 실제로 무시하면 Quiet는 M−2, Empathy/Interview/LocalChat은 S−2. 명시적 보류와 다르다. 종료 요청 S 합계는±10 상한, 즉시 보상·유형 효과는 별도이며 최종S/F는0~100이다.

## 4. 별도 사건·비활성 항목

| 항목 | 선택·효과 | 상태 |
|---|---|---|
| 분실물 | 하차 후 보관·신고/전달 절차 텍스트, 요청 효과0 | 운행 요청 슬롯 밖. 실제 반환 퀘스트 없음 |
| 신호 장기 대기·필요 제동·흔들림 | 상황 설명·상태 확인, 추가S/F0 | 실제 운전 평가와 별도인 응대 |
| 수면 깨기 | 놀람 확인·다시 쉬도록 안내 | 상태·안정 시간 반영, 반복 응대 점수 없음 |

| ShortRoad 짧은 길 | 수락 시 기존 경로 행동·성공S+5 | 기본 비활성, 구저장/사용자 설정 호환용 |
| RouteAdvice 경로 추천 | 빠른길 / 짧은길 → 기존 경로 행동·성공S+4 | 기본 비활성 |

| 운전자 말 걸기 | 내부 대사/Quiet 관찰 코드 보존 | 일반 플레이 버튼·잡담 답변 숨김 |
