상태 표기

구현·배포구현·소스진행 중미결보류·제외개선 필요
표기 뜻
구현·배포소스와 Git 배포 실행본 builds/EungyeTaxi/EungyeTaxi.exe 둘 다 들어 있다
구현·소스소스에만 있고 배포 실행본에는 아직 없다
진행 중다른 작업이 같은 폴더에서 고치는 중이며 커밋되지 않았다
미결: 결정 대기기획자(사용자)의 답이 필요하다
미결: 승인 전기획은 있으나 구현 승인을 받지 않았다
미결: 설계안코드 대조 설계안이나 상세 기획만 있다
보류 / 제외결정으로 미루거나 범위에서 뺐다
개선 필요구현됐지만 사람 플레이 미확인, 알려진 실패, 피드백 반영 대기 중 하나가 있다(비고에 적음)

자동 검사 통과는 사람 체감 확인이 아니다. 거의 모든 구현 항목은 위치 제어 검사나 자동 물리 주행까지만 확인했고, 사람 플레이 확인 여부는 비고에 따로 적는다.
