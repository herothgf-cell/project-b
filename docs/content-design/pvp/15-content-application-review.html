공통 상태·효과 연결 경계

요소 현재 PVP 상태 후속 구현 계약
유형·변주·초기 대사구현. 공통 모델에서 새 객체를 읽고 불변 카드만 노출공통 모델 변경 시 전체37개 검사를 실행
선택 권한구현. client는 범위 내 index만 요청, 서버가 확정현재는 콘텐츠 미리보기 선택이며 실제 경쟁 승객 선점이 아님
단절·복귀구현. 같은 슬롯/선택/차량 위치 보존, 새 epoch 입력만 허용실제 운송 ID·승객 상태·정산 완료 ID까지 이어서 복원해야 함
요청 응답 기억/수면/준비/하역캠페인 완료, PVP 미연결서버 시간·명시적 상태 전이·단일 완료 처리로 연결
음식/짐 오염캠페인 완료, PVP 미연결청결 채택 결정 후 경기/운송/사건 ID로 한 번만 적용
수치캠페인10초, 청결2/6/5 등 시험값을 PVP에 적용하지 않음경기 시간·맵 이동 시간·운임·운전 배점을 함께 조정
승패/경제미구현고액 단건 대 짧은 여러 건의 전략을 검증. 경기 시간을10분으로 고정하지 않음

P2 전체 게이트와 공유 신호/장애물 수용 후 Task4/5의 소유권·운송·정산을 먼저 완성하고 위 행동을 연결한다. 콘텐츠가 보인다는 이유로 실제 PVP 승객 운송 완료로 표시하지 않는다.

기본 경쟁 운송 후속 갱신

2026-10-29 후속에서 공통 승객의 소유권·승하차·약정·정산을 실제 네트워크에 연결했다. 위 표의 유형별 준비/응답/수면/청결 효과와 내구도는 그대로 미연결이다. 최신 수용 범위, 실제 검사를 우선한다.
