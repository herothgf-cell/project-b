# 자체 도시 PVP 기획

현재 기준: **2026-11-10 · A2 · 통합 실행 · LAN v17**(내 차 외형 추가). `builds/EungyeTaxi/EungyeTaxi.exe`에서 PVP를 선택한다. 기본 기존 차량 물리와 공통 승객/생활/법규를 재사용하며 싱글3일·저장과 구분한다.

## 현재 규칙

| 항목 | 제공 범위 | 담당 문서 |
|---|---|---|
| 지도/차량 | A2 자체 도시·같은 WheelCollider·차로/신호 연결. 2026-11-10 신호 교차로19→37(내부 격자 전부+외곽 간선 T 12), 구역마다 ㅓ자 뒷골목 추가, PVP 신호는 직진·보행 단계를 매 주기 돌려(recall) 실제 적색 대기가 생김 | [26 A2](26-city-a2-four-player.md#2026-11-10-신호-교차로-확대와-뒷골목)·[27 통합 모드](27-flow-unified-mode.md) |
| 경기 | 입력한 시간, 나1+봇3 또는 LAN 호스트+참가자 최대4·빈자리봇 | [30 LAN](30-native-lan.md) |
| 승객 | 공용8호출·별도 길가3명·원자 선점·공통17요청/유형/만족도/운임 | [28 승객 공유](28-passenger-parity.md)·[공통 승객](../02-passengers-and-fares.md) |
| 결과 | 실제 운임−발생 영업 비용의 순수익 비교, 운전 평가는 공통 운임에 반영 | [25의 경기 요소](25-simulation-match.md#경기-요소) |
| 생활 | PVP 전용 피로/식사/휴식, 시설 대기·봇도 같은 비용/시간 | [03 PVP 생활](../03-life-and-economy.md#pvp-driver-condition) |
| 사고 | 사람/차량/시설 사고·처리 잠금·공업사·고장/수리 | [08 사고](../08-accident-and-workshop-proposal.md) |
| 조작/화면 | 수동 기본·개인 운전 설정·H 조향 보조·공통 캐주얼 UI | [01 조작](../01-driving-and-traffic.md)·[05 UI](../05-interface-and-navigation.md) |
| 저장/시간 | 캠페인에 쓰지 않는 별도 경기, 지도에서도 공통 경기 계속 | [30 LAN](30-native-lan.md) |
| 내 차 외형 | 싱글에서 한 번이라도 산 차종 외형·색·대시보드 장식을 입장 전 "내 차"에서 선택(미보유 시 기본 택시). 봇은 정해진 외형 중 무작위. **성능·경제는 모두 PvP 표준**(시작 택시 값). LAN v17은 입장 메시지에 외형 ID·색·장식만 추가하고 호스트가 4자리 외형을 배포 | [기획22 §6·§11](../22-growth-direction-and-vehicle-purchase.md) |

지도가 바뀌면 PVP 지도 지문이 바뀌므로 2026-11-10 이전 실행본과는 같은 v17이어도 접속이 거부된다. LAN은 같은 실행본/지도 지문을 확인하고 호스트가 운송·신호·평가·경제를 확정한다. 인터넷 Relay/공개 매칭/호스트 이전/전용 서버는 제공하지 않는다. 양쪽 PC의 실행 폴더를 함께 갱신한다.

## 이전 기획을 읽는 방법

| 자료 | 성격 | 현재와의 관계 |
|---|---|---|
| 00~11 | 초기 독립 PVP 원안·수치 후보·게이트 | 별도 실행파일/Fusion/독립 점수 합산을 현재에 적용하지 않음 |
| 12~24 | 단계별 계획·검사·옛 평면 시험장/확장 구현 기록 | 해당 단계 검증의 증거로 보존, 현재 실행 안내가 아님 |
| 25 | 기존 시뮬레이션 재사용 전환 | 경기 구조를 계승, 옛 실행/2차로 초기 배치는26/27/30으로 대체 |
| 26~28 | 현재 A2·통합 흐름·승객 공유 | 날짜별 캡처/통계는 당시 값, 최신 UI/생활은 상위 담당 문서 |
| 29 | A3 시안·구현/복원 이전 기록 | 현재 지도는A2, A3 자동 재적용 없음 |
| 30 | 현재 LAN 접속·권한·호환·한계 | 원격 플레이의 기준 |

[이전 PVP 목록/개발 순서 전체](../../design-history/content-design/2026-11-06-cleanup/pvp/README.md)를 보존한다. 기존 파일/앵커는 링크 호환을 위해 유지한다. 초기 점수 후보/독립 배포 경로를 현재 제품 규칙으로 재인용하지 않는다.

## 개발·검증·실행본

빌드는 `PrototypeBuild.BuildHybrid`, 배포는 통합 `distribution/EungyeTaxi-build-manifest.json`이다. 이전 `PvpBuild.BuildClient`는 독립 진단용이며 `update_pvp_distribution_manifest.ps1 -VerifyOnly`도 통합 폴더를 검증한다. 구체 실행본/hash는 [최신 작업 이력](../../work-history/LATEST.md)에서 관리한다.

모델/위치 제어/물리 주행/실제 화면/같은PC 두 Player LAN과 다른PC·사람4인·장시간 수용은 구분한다. 자기차 예측/서버 보정은 구현됐지만 모든 환경의 끊김 해결이나 장기 수익 균형을 보장하지 않는다. 사람 전체 경기·다른PC/DPI·지연/손실 수용은 후속이다.
