# PVP 직접 IP 주행 검증 실행 계획 — 2026-10-29

요구: 시험장 잔여 검증과 네트워크 주행, 다른 채팅 보존, 화면 확인 최소화. Fusion SDK/App ID 미준비로 사용자가 대안 확인 요청.

판단: 로드맵의 NGO 대안으로 1.12.0(공식 레지스트리 최소 Unity2021.3, Transport1.4.0)을 별도 worktree에 고정하여 직접 IP 두 Player 시험을 진행한다. 계정/Relay/방화벽 변경 없이 loopback 기본값, LAN 주소는 명시 입력. Fusion 실패나 SDK 최종 채택으로 기록하지 않는다.

1. 검은 화면 캡처 재현 로그 보존. splash 이후 프레임 캡처로 렌더링·HUD를 확인한다. 자동 입력과 사람 체감 구분.
2. NGO 설치 후 입장/입력/예측 검사 실패 확인. SDK 입장 승인에 빌드·프로토콜·지도·설정 일치 검사, 차량 소유자는 전송자 연결 ID 기준. 요청의 임의 선수 ID를 받지 않는다.
3. 서버50Hz, 입력 sequence/범위/빈도 제한, 차량별 권한 상태. 클라이언트 입력 즉시 예측, 승인 sequence까지 제거하고 나머지 입력 재계산. 제한된 입력 이력과 실패 종료. 맵 경계/복구 상태 포함.
4. 시작 화면에서 Host/Join, 실제 두 Player 자동 probe에서 이동/권한수렴/불일치 거절/방장종료 검사. 사람 조작·다른 PC·인터넷·장기 네트워크 프로파일·재접속 자격은 실제 검증 전 미완료.
5. 캠페인 검사·빌드 격리 재검증, 기획/이력/LATEST 기록, feature/pvp-prototype 커밋·푸시. 다른 채팅 소스 연동 및 main 변경은 하지 않는다.

실제 해석/보완: 패키지 lock의 Transport는1.5.0, Mono.Cecil1.11.4로 해결됐다. SDK 스크립트 목록 캐시 실패로 clean build와 목록 검증을 추가했다. 150ms/3% 실험에서 입력 대기열 누적 실패를 확인하여 최신 조작 상태를 서버 한 tick에 한 번 적용하는 방식으로 보완했다. 사람 P1 게이트는 자동으로 닫지 않고, 사용자가 요청한 다음 단계의 제한된 직접 IP 실험을 진행한다.
