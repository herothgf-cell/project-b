# 기존 시뮬레이션 기반 LAN 사람 대전

2026-11-06 후속 보행자 손상 상태를 포함한 프로토콜은 `native-city-lan-v8`다. 양쪽 PC 실행본을 함께 갱신한다. 호스트가 선택한 사고 종류·등급·비용·시간·감점·내구도 손상과 강제 공업사 이동 상태를 복제하며 참가자는 재추첨/청구/감점/손상을 적용하지 않는다. 세부 규칙은 [사고 기획](../08-accident-and-workshop-proposal.md), 실제 검사·배포 결과는 [작업 이력](../../work-history/2026-11-06-pedestrian-durability.md)을 따른다.

2026-11-02. 사용자 선택은 같은 공유기·직접 IPv4부터, 최대4명·빈자리 봇이다. 기존 평면 시험장 네트워크가 아니라 현재 A2 도시·WheelCollider·싱글 공통 승객/법규/내구도/시설을 연결한다. 인터넷 중계·계정·SDK 설치는 추가하지 않는다.

## 접속 방법

1. 양쪽에서 `builds/EungyeTaxi/EungyeTaxi.exe`를 실행하고 PVP를 선택한다.
2. 호스트는 경기 시간을 초로 입력하고 **방 만들기**. 대기실에 표시된 실제 LAN IPv4와 포트를 참가자에게 전달한다.
3. 참가자는 해당 IP와 같은 포트로 **IP로 참가**. `127.0.0.1`은 같은 PC에서만 쓴다.
4. 인원을 확인하고 호스트가 **현재 인원으로 경기 시작**. 모두 지도를 준비한 다음 공통 시계가 출발한다. 남는 자리는 봇이다.
5. 기존 WASD/방향키·Space·M 호출·F 승하차·F7 시설·H 보조를 사용한다. Esc로 나가면 자기 자리는 봇이 이어받는다.

Windows가 허용 여부를 물으면 신뢰하는 개인 네트워크에서 게임 통신을 허용해야 한다. 방화벽 규칙/공유기 설정을 이번 작업에서 자동 변경하지 않는다. 같은 공유기도 게스트 Wi-Fi 격리나 방화벽이 있으면 접속이 안 될 수 있다. 공인 IP/NAT 자동 연결·Relay·서버 목록은 제공하지 않는다. 신뢰 LAN 프로토이며 강한 인증/암호화·악의적 호스트 방어는 범위 밖이다.

## 구현 계약

`PvpNativeLan`은 기존 NGO1.12/UnityTransport를 사용한다. protocol+지도SHA256으로 호환성을 확인하고 clientID→서버좌석을 고정한다. 서버만 운송/가격/법규/정산을 진행한다. 명령 sequence·현재 trip/request·candidateSeed·native 정차/수락 조건을 확인한다. 입력은50Hz 번호 FIFO, 자세/NPC/점수는10Hz, 자기 상세 모델은2Hz이며 상세 존재 태그로 Unity 인라인 null 복원을 구분한다. 도로 사건/정체 비용도 안정 ID로 복제하며 reliable fragmentation/최대1MiB를 사용한다. 자기 차는 로컬 예측, 원격 차는 보간 지연이 있는 구현이며 호스트의 판정 권한은 유지한다. 클라이언트 UI는 첫 상세 상태를 받은 뒤 조작을 허용한다.

빠른 프레임에도 NPC 전체를 실어 작은 LAN용으로 구현했다. 4인 실제 PC/지연·손실 환경·장시간 bandwidth와 체감은 최종 별도 검증 항목이다. 승객/시설 상태는 host authoritative이며 클라이언트의 UI 표시 지연이 있을 수 있다. 기존 오프라인과 싱글은 온라인 인스턴스가 없으면 원래 경로로 동작한다.

## 지도

현재 지도는 사용자 복원 지시를 따른 **A2**다. [A3 전체·시장 골목](29-city-a3-proposal.md)의 구현 이력은 보존하지만 현재 실행 지도에 적용하지 않는다. 필수 은계 입력/배포ZIP은 유지한다. [A2 복원 기준](../../work-history/2026-11-03-pvp-a2-rollback.md)을 따른다.

## 검증 기준

최종 실제 명령/결과는 [작업 이력](../../work-history/2026-11-02-pvp-native-lan.md)을 따른다. `tools/test_pvp_native_lan.ps1 -Reconnect`는 같은 PC 두 Player의 실제 입력 메시지→호스트 WheelCollider 주행, 복제/선점/잘못된 명령/봇 승계/재접속/메뉴 정리를 검사한다. 위치를 제출하거나 이동시키는 검사가 아니다. 다른 PC·사람 직접 운전·원격4명·전구간 장시간 운송 수용을 대신하지 않는다.

## 참가자 표시·복원 성능 후속 (2026-11-02)

[실측/검사 이력](../../work-history/2026-11-02-pvp-client-stutter.md). 10Hz 권한 위치는호스트경기시간기준16샘플에서100ms지연보간·최대100ms외삽하고클라이언트Rigidbody중복보간을끈다. 모델은기존2Hz를유지하되같은운송/목적지/옵션은경로를유지한다. 캠페인코스초기화는replica에서실행하지않고큰길/짧은길요청도옵션이바뀔때만재적용한다. 시설대기정보동일시캐시유지/NPC표시중복·점유차재생성을줄인다. 호스트물리·판정/승객모델·싱글복원은유지한다.

같은실행본10초루팅비교68.75→0.15ms; 표시된1280x720참가자약59fps는짧은이PC검사이며모든환경보장이아니다. 첫경로단발지연은남는다. 재현 `tools/test_pvp_native_lan.ps1 -Reconnect`, 비교용 `-LegacyRouting`(probe한정), 참가자창표시/무음검사 `-Rendered`. 숨김검은캡처를렌더수용으로계산하지않는다.


## 참가자 알림·작은 표시 끊김 후속 (2026-11-02)

상세 복원은 같은 법규 ledger에 사건 ID별 누적/강화를 적용하여 신호 위반 점수·승객 만족도 알림을 보존한다. 반복 패킷은 알림을 중복 생성하지 않고 초기접속/재접속 과거 사건은 기준값으로 처리한다. 만족도 변화 사유는 호스트에서 전달한다. 알림은 불투명 카드/운전·만족도 배지로4초 표시한다. 운행 HUD의 예상 도착 상태는 숨기며 지도·시설 비교 계산은 유지한다.

최대100ms 자세 외삽에 회전도 포함하고10Hz 송신의 프레임 누적 지연을 줄인다. 실제 두 실행본73검사·1280×720 참가자 알림 PNG/주행/재접속 수용과 단발 지연 등 제한은 [작업 이력](../../work-history/2026-11-02-pvp-notification-followup.md)을 따른다. 알림은 서버 사건 모델 fixture로 검증했으며 신호 위반 물리 주행과 구분한다. 다른PC/4인·모든 끊김 제거 수용은 남는다.


## 닉네임과 짧은 경기

입장 전 닉네임(최대12자)을 설정한다. 호스트가 대기실/순위/지도용 이름을 공유하며 빈자리는 봇으로 표시한다. v3 실행본끼리 접속한다. 10분 이하 경기는8호출+3길가를 유지하고 각 승차지에서 실제 경로가 가까운3개 도착지를 우선한다. 호출 휴지30초, 기존 수락 약정/거리 운임 유지. 짧은 경로가 더 낮은 운임일 수 있고 운송 횟수는 조작/정체에 따라 달라진다.

## 참가자 자기 차 예측·보정 (2026-11-04 현재)

`native-city-lan-v3`는 v2의 자기 차 예측에 기본 게임 신호의 호스트 runtime 복제를 추가한다. 양쪽 모두 새 실행본으로 접속하며 v2와 혼용하지 않는다. 자기 차만 동적 Rigidbody/기존 WheelCollider와 로컬 바퀴 갱신을 사용한다. 입력50Hz를 번호순으로 호스트가 처리하고, 실제 새 입력을 처리한 물리 tick에만 ack를 제공한다. 참가자는 해당 입력 이후의 과거 body 상태와 비교해 위치/회전/속도 오차를 현재 상태에 점진 적용한다. 중복/오래된 ack와 새 입력을 처리하지 않은 snapshot은 재보정 근거로 사용하지 않는다. 완전한 PhysX 월드 롤백·재생은 아니다.

호스트가 NPC·모든 택시·보행 수요로 선택한 기본 신호 단계/진행시간/녹색 길이/수요를10Hz snapshot으로 공유한다. 클라이언트는 마지막 권한 단계와 예상 대기를 표시하며 독자적인 수요 생략을 하지 않는다. 편집·교육 신호는 기존 공유 시계로 유지한다. 수동/원격 사람의 일반 제동·조향은 같은 정책을 쓰고, 봇의 자동 전후진은 유지한다. 실제 검증은 [작업 이력](../../work-history/2026-11-04-casual-controls-signals.md)을 따른다.

초기·큰 오차(8m/100도 초과)·시설/경기 종료는 권한 상태로 재설정하며, 입력 ack 또는 snapshot이0.5초 이상 없으면 예측도 제동한다. 다른 택시/NPC는 기존 서버 보간과 바퀴 표시를 유지한다. H 자유 주행은 호스트가 선택한 방향 edge/시작·끝 절단점을 전달해 같은 경로로 로컬 조향하며, 같은 경로는 재생성하지 않는다. 서버가 승객/법규/충돌 손상/현금/정산을 확정한다. 클라이언트 예측 결과로 점수나 운임을 제출하지 않는다.

최종 Windows·Editor 및 같은PC 두 실행본95검사/재접속·실제 주행 결과와 제한은 [이번 이력](../../work-history/2026-11-03-pvp-owner-prediction.md)을 따른다. 다른PC4명·장시간 충돌·실제 네트워크 지연/손실과 사람의 체감은 별도다. 양쪽 모두 새 실행본으로 다시 시작해야 한다.
