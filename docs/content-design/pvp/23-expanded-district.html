확장 PVP 시험장 · 은계형 화면

보존 자료: 초기 독립 PVP/단계별 기록. 아래 “현재/미구현/최신”은 작성 당시 표현이다. 현재 A2·통합 실행·순수익 경쟁·LAN은 PVP 기준을 따른다. 초기 독립 총점/보너스·Fusion 후보·별도 실행 경로는 현행 규칙이 아니다.

사용자 확인에 따라 현재 PVP 자체 시험장을 확장한다. 은계 실제 지형/도로 데이터를 반입하지 않는다. 화면/UI·지도 데이터·확장/승객·시설을 일괄 구현한 뒤 통합 검사를 시작했다.

이 길이/인원/교통량/연료/서비스 비용은 프로토타입 시험 후보다. 경기 시간을10분으로 고정하거나 전체 배점/충돌/SDK·공개 랭킹 수용을 확정한 것은 아니다.

직접 플레이

  1. builds/PvpPrototype/ 전체 폴더를 유지하고 PvpPrototype.exe를 실행한다.
  2. 경기 시간/유예를 입력하고 혼자 경기 시작 · 봇 상대를 누른다. 긴 외곽 운송을 보려면 충분한 시간을 직접 정한다.
  3. 승객을 선택→경로 따라 승차 거점으로→올바른 방향/정차0.2초→E 승차, 목적지에서 E 하차.
  4. WASD/방향키·Space 제동·정차 후 Q 전후진. C/V 추적·운전석 전환, M 전체 지도.
  5. 주유 패널에서 시설을 선택하면 시설 경로를 표시한다. 해당 정차점에서 같은 버튼으로 주유를 요청한다. 진행 중 취소/운송 목적지 길안내 복귀도 가능하다. 비용과 소요 시간을 확인한다.
  6. 결과의 운임점수/안전 보너스/위반/서비스 비용/완료 건수/순위를 확인하고 초기 화면으로 돌아가 새 경기 시작.

검증 구분

모델: 기존 PVP 전체 회귀+확장117관측·32입력 경로, 외곽 공유 교통 실제 모터 주행4경로, 원좌표 이동 후 NPC/정지선, 연료/주유/취소/중복 비용·연속 운송→주유 확인. 실제 Player/화면/최종 배포 결과는 작업 이력에 남긴다.

확정 소스a5c13de 재검사/Windows 재빌드와 프로젝트 밖 복사본 실제 Player0. 사람 자리1회/약1.56km·봇2회/약1.40km, fixture/도로 경계 차단/감점0, 주유 취소·재시도 후2점1회 차감,31/77점·정산/메뉴 복귀/새 경기 확인. 같은 빌드2Player의 결과/교통 일치와 추적/지도/운전석1280×720 실제3화면도 확인했다. 전체139파일93,263,189바이트 해시 검증으로 배포한다. 이는 자동 입력·자동 프레임 검증이며 사람 플레이나 다른PC 검증은 아니다.

사람의 조작감/운전석 시야·봇 수익 경쟁·장시간 서비스 경제·다른PC/인터넷/동시 시설 이용은 별도 수용이다. 유형별 승객 효과, PVP 손상/수리, 복잡한 합류/충돌 책임 전체는 후속이다.
