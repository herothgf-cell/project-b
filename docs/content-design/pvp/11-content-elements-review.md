# PVP 콘텐츠별 요소 검토표

작성일: 2026-10-29
성격: 기존 기획의 항목별 검토·탐색용 표. 새 규칙이나 수치의 확정 문서가 아니다.

기존 [승객 기획](../02-passengers-and-fares.md)의 **요소 → 행동·조건 → 결과 → 예외** 양식을 따른다. 결정 상태는 [09 결정 대장](09-decisions-and-balance.md), 구현 완료는 [08 로드맵](08-development-roadmap.md), 실제 검증은 [작업 이력](../../work-history/2026-10-29-pvp-review-validation.md)을 우선한다. 아래에서 ‘초안’은 구현 완료·사용자 최종 승인을 의미하지 않는다.

## 1. 콘텐츠 범위와 결정 상태

| 콘텐츠 | 구성 요소 | 기획 상태 | 구현 범위·다음 단계 | 원문 |
|---|---|---|---|---|
| 모드 | 실제 사용자 간 운송 경쟁, 운임·운전 기여 | 사용자 확정 방향 | 초기 설정 기반만 있음. 경기 미구현 | [00](00-mode-overview.md) |
| 시작 | 전용 씬, 한글 입력, 나가기, 설정 동결 | 분리 기반 구현 | Task 1 실제 엔진 검증 결과는 이력 참조 | [07](07-network-and-build.md) |
| 경기 | 로비·준비·공통 시작·마감·결과 | 초안 | Task 3~5 | [01](01-match-flow-and-rules.md) |
| 차량 | 빠른 가속·조향·방향 전환 | 방향 확정, 수치·모델 비교 시험 | Task 2 오프라인 → Task 3 온라인 | [02](02-driving-and-traffic.md) |
| 경기장 | 자체 제작, 제한된 공간, 대안 경로 | 자체 제작 확정, 형태·면적 미정 | Task 2, 기존 은계 맵 자동 재사용 금지 | [03](03-map-and-content.md) |
| 승객 | 공용 공급·현장 선점·단일 운송 | 초안 | Task 4 | [04](04-passengers-and-fares.md) |
| 운임 | 고액 한 건과 짧은 여러 건의 선택 | 사용자 요구, 균형은 미검증 | Task 4~5 구현, Task 7 비교 | [04](04-passengers-and-fares.md) |
| 성적 | 완료 운임 환산·안전 보너스·위반 감점 | 산식 초안, 최종 배점 미정 | Task 5 | [05](05-scoring-and-results.md) |
| 교통 | 공유 신호·NPC·보행 보호 | 초안, 수량 미정 | Task 6 | [02](02-driving-and-traffic.md) |
| 화면 | HUD·지도·선점 안내·결과 | 초안, 초기 설정 UI만 구현 | 기능별 최소 화면 후 Task 7 정리 | [06](06-ui-and-feedback.md) |
| 접속 | 초대방·권한 서버·차량 예측 | Fusion 2 Host 권고 후보 | Task 3 검증 후 SDK 채택 | [07](07-network-and-build.md) |
| 운영 | 전용 서버·공개 매칭·랭킹 | 후속, 추진 미정 | Task 8 진입 판단 필요 | [07](07-network-and-build.md) |

경기 시간은 미정이며 10분으로 고정하지 않는다. 인원은 2인 검증 후 확대하는 후보이고, 택시 간 충돌 OFF도 초기 시험안이다. 기존 문서의 시험 숫자와 산술 예제를 제품 확정값으로 읽지 않는다.

## 2. 경기 흐름 요소

담당: [01 경기 진행](01-match-flow-and-rules.md). 모든 경기 전환은 서버가 확정하는 초안이다.

| 요소 | 행동·조건 | 결과 | 예외·검토 항목 |
|---|---|---|---|
| 방 생성·참가 | 맵·규칙·참가 조건 확인 | 같은 구성으로 입장 | 다른 버전·위조 신원 거절 |
| 준비 | 설정 동결 후 로드·준비 응답 | 전원 준비 후 공통 카운트다운 | 설정 변경·준비 철회 시 재확인 |
| 시작 | 공통 시작 틱 도달 | 차량 입력·공급 동시 개방 | 로딩 속도·Host 우위로 조기 출발 금지 |
| 진행 | 승객 탐색·운송·위반 관찰 | 공통 시계와 잠정 성적 갱신 | 메뉴·단절로 전체 시계 정지 금지 |
| 본 경기 마감 | 본 종료 틱 도달 | 신규 승차 금지, 대기 승객 만료 | 같은 틱 승차도 거절 |
| 유예 마감 | 기존 운송만 공통 최종 틱 전 완료 | 유효 하차만 정산 | 유예 채택·길이 미정, 개인별 연장 금지 |
| 최종 종료 | 사건·운송·원장 대조 | 확정 결과 버전 발행 | 같은 최종 틱 신규 하차 금지, 미완료 부분 지급 없음 |
| 게스트 단절 | 유예 내 동일 신원 복귀 | 기존 운송·감점 유지 | 시계 보상·자동 운송 없음 |
| 이탈·권한 유실 | 자격 경계·권한 상태 확인 | 이탈 표시 또는 경기 무효 | 결과 확정 후 단절로 확정 순위 번복 금지 |
| 재경기 | 새 경기 생성 | 새 ID·공급·준비 상태 | 이전 원장·승객 재사용 금지 |

## 3. 차량·교통·법규 요소

담당: [02 주행](02-driving-and-traffic.md). 조작 임계값은 [09](09-decisions-and-balance.md)에만 둔다.

| 요소 | 행동·조건 | 결과·측정 | 예외·검토 항목 |
|---|---|---|---|
| 가속·재가속 | 출발·코너 탈출 입력 | 반응 지연·구간 통과 시간 비교 | 최고속도만 올려 민첩성 완료 판정 금지 |
| 저속 조향 | 좁은 연결로·정차점 진입 | 최소 회전 공간·수정 조향 횟수 | 카메라 방향으로 조향축 반전 금지 |
| 고속 조향 | 차선 변경·급한 반대 입력 | 흔들림·횡이탈·안정 시간 | 장치별 성능 우위 방지 |
| 제동·후진 | 감속 후 명시적 후진 의도 | 정지 거리·오차·재출발 비교 | 동시 입력은 제동 우선, 필요한 급제동을 위반으로 단정 금지 |
| 입력 유실 | 장치·연결 끊김 | 구동 해제·안전 감속 | 마지막 가속 무기한 유지 금지 |
| 복구 | 유효 후방 지점 요청 | 이탈 전 합법 경로로 복귀 | 지름길·승하차·보너스 획득 금지 |
| 신호·정지선 | 접근 방향·위상·통과 증거 | 해당 사건으로 관찰·확정 | 화면 신호와 판정 불일치 검증 |
| 회전·역주행·속도 | 금지 연결·지속 반대 진행·속도 관찰 | 증거 있는 위반만 감점 전달 | 정상 후진·순간 보정·관측 부족 보호 |
| 보행·경계·진로 | 보호 영역과 실제 위험 확인 | 필요한 양보와 침범 구별 | 정상 승하차·합법 차로 변경 보호 |
| 반복 사건 | 동일 접근·접촉의 사건 ID 유지 | 중복 감점 방지, 상향 차액만 전달 | 새 독립 위반까지 면책하지 않음 |
| 택시 간 충돌 | OFF 후보부터 비교 | 접촉 책임·공정성 확인 | 정식 정책 미정, 겹침만으로 가해 판정 금지 |
| 택시–NPC | 별도 접촉·밀기 시험 | 간접 길막·피해 귀속 확인 | 캠페인 내구도·수리비 자동 도입 금지 |
| NPC·보행자 | 서버 공통 생성·경로·신호 반응 | 읽을 수 있는 교통 장면 | 캠페인 교통량 복사·클라이언트 독립 생성 금지 |

| 결과 확정 | 최종 틱 자격·원장 대조 완료 | 같은 결과 버전 재전달 | 로컬 예상 합계로 승자 추정 금지 |
