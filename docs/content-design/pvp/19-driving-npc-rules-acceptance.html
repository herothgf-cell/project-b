경계/불법 연결도로 그래프가 진입을 차단실패 이동/복구로 감점·운임을 만들지 않음. 별도 금지차로/합류 판정 자산은 후속
원장/표시서버 사건ID/revision·상향 차액·안전 구간·근거/보류 전달재접속/예측 replay가 새 사건을 확정하지 않음. 신호/정지선/제한속도 안내

각 조건에서 양쪽 최종 원장·결과가 같았고 공통 NPC/보행 snapshot도 일치했다. 시험 운전기는 제품의 기본 자동 운전 기능이 아니다. 경기 시간120+10초는 검사용이며 제품 경기 시간을 확정하지 않는다.

최신 main HUD 병합 후 실제 소스32b2331에서 Editor 검사·Windows 빌드를 다시 통과했다. 전체139파일93,199,109바이트를 프로젝트/Library 밖으로 복사해 자체 작업 디렉터리에서 격리 검사와 실제 두 Player 기본 운송을 재실행했다. 종료0, host199.541m/client319.404m·33/44점·공유 상태145표본 일치·fixture/도로 경계 차단0. 전용 manifest 해시 검증0이며 기존 싱글130파일112,194,710바이트도 검증0으로 보존했다. 이는 동일 PC의 독립 프로세스·복사본 검사다.

따로 남긴 환경·판정

  • 다른 물리PC LAN/인터넷·방화벽·지속 접속·실물 키보드/패드·사람 조작감·화면 시야/신호 고지 수용.
  • WheelCollider/실차량 접지·다양한 지도/교통량·장시간 부하·전체 수익/공급 균형.
  • 금지차로/합류/복수 신호군과 별도 회전 제한 자산, 복잡한 측면 책임·NPC 간접 봉쇄·장기 교통 오류 복구.
  • 수면/준비/응답/오염의 유형별 행동, PVP 내구도·수리 정책. 캠페인 내구도/수리는 완료 main을 보존해 병합했고 PVP 효과 연결은 별도다.

P2 전체·공개 랭킹 운영 승인으로 올리지 않는다. 이전 17의 위치 제어 검사와 이번 실제 입력 주행 검사를 구분한다.

한 창 시험 후속

이후 21번 한 창 봇 경기를 추가했다. 이전의 단일 창 실제 운송 불가 안내는 당시 상태다. 같은 교통/법규/정산으로 로컬 봇과 직접 시험할 수 있으며 사람 조작감/다른PC/전체 수용 잔여는 유지한다.
