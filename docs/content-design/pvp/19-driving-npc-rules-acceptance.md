## 따로 남긴 환경·판정

- 다른 물리PC LAN/인터넷·방화벽·지속 접속·실물 키보드/패드·사람 조작감·화면 시야/신호 고지 수용.
- WheelCollider/실차량 접지·다양한 지도/교통량·장시간 부하·전체 수익/공급 균형.
- 금지차로/합류/복수 신호군과 별도 회전 제한 자산, 복잡한 측면 책임·NPC 간접 봉쇄·장기 교통 오류 복구.
- 수면/준비/응답/오염의 유형별 행동, PVP 내구도·수리 정책. 캠페인 내구도/수리는 완료 main을 보존해 병합했고 PVP 효과 연결은 별도다.

P2 전체·공개 랭킹 운영 승인으로 올리지 않는다. 이전 [17](17-competition-acceptance.md)의 위치 제어 검사와 이번 실제 입력 주행 검사를 구분한다.
