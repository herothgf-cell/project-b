## 완료 승객 콘텐츠 연결

37변주의 유형·대사는 이제 기본 경쟁 운송에서도 서버가 선택해 표시한다. 모든 유형에 공통인 승차·하차·고정 운임/정산을 연결했으며, 수면·응답 기억·적재/하역·음식/짐 오염·청결 경제의 유형별 효과는 아직 PVP에 연결하지 않았다. [이전 요소별 검토표](15-content-application-review.md)의 유형별 후속 조건을 유지한다.

## 분리해 남긴 검증

| 필요한 환경 | 다음 확인 |
|---|---|
| 다른 PC 2대/실제 LAN | 버전 일치·직접 IP·역할 교환·복귀·동일 결과, 방화벽/실제 지연 기록 |
| 사람 운전/실물 입력 | 경기 시간 설정/준비, 지도·승객 선택, 지정 차로/정차·승하차, 좁은 회전·전후진·패드 |
| 전체 코스 물리 주행 | 위치 제어 없이 실제 승객 경쟁 완주, 장애물/신호 접근의 화면과 판정 일치 |
| 공유 교통 확장 | 일반 NPC·모든 법규·피해 귀속·반복 센서 사건·복구 악용, 부하/보정 측정 |
| 밸런스 플레이 | 고액 단건 대 짧은 여러 건, 공급 접근성·운임/운전 점수 비중·맵 이동시간·경기 길이 |
| 내구도 원본 완료 후 | 커밋된 상태 모델부터 적용 재검토. 다른 채팅의 진행 중 변경을 복사하지 않음 |

동일 세션 재경기 UI와 개별 사건 근거를 여는 상세 UI는 후속이다. 현재는 전체 점수 구성과 가장 최근 원장 항목을 보여 준다.

P2 전체 수용이나 공개 경기/랭킹 운영 승인으로 표시하지 않는다. 사용자가 이번에 다른PC·사람 검증을 별도 정리하고 후속 구현까지 진행하도록 지시한 범위를 따른다.
