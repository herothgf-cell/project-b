실제 입력 주행·공유 NPC·법규 구현 계획

보존 자료: 초기 독립 PVP/단계별 기록. 아래 “현재/미구현/최신”은 작성 당시 표현이다. 현재 A2·통합 실행·순수익 경쟁·LAN은 PVP 기준을 따른다. 초기 독립 총점/보너스·Fusion 후보·별도 실행 경로는 현행 규칙이 아니다.

실행: superpowers:writing-plans / executing-plans. 기존 PVP worktree에서 직접 실행, 마지막 독립 리뷰1회.

목표: 경기 중 위치 제어 없이 가속/조향/제동만으로 실제 모터 운송을 완료하고, 서버 공유 차량/보행자와 근거 기반 법규 사건을 연결한다. 근거는 PVP02/03/05/08/09와 사용자 후속 지시다.

  • 최신 main37b6adb의 완료 내구도·배포를9489e6e로 병합했다. LATEST 양쪽 보존. 다른 checkout/미추적8항목은 수정하지 않는다.
  • 실제 주행은 현재 PVP 평면 차량 모터의 입력 시뮬레이션이다. WheelCollider/사람 운전으로 확대 해석하지 않는다. 시작 배치와 클라이언트 권한 보정 외에 경기 중 authority 위치 복구/fixture를 사용하지 않는다. drive 검사 중 SetFixtureStop 호출은 실패한다.
  • 검사 운전기는 경로 추종/정차/신호·공유 교통 양보 입력만 생성한다. 제품 자동 운전 보조로 기본 활성화하지 않는다.
  • 서버 NPC2대는 합법 외곽 순환로를 따라 신호/앞차/선수에 양보한다. 보행자1명은 남쪽 접근의 적색 구간에 횡단한다. clients는 서버 snapshot 표시/제한된 외삽만 하며 AI를 생성/갱신하지 않는다.
  • 법규: 중앙/남쪽 접근의 swept 정지선→진입 사건 상향, 남쪽 실제 우회전의 정지/전용 신호, 실제 보행 보호, 지속 과속/역주행, 근거가 있는 NPC 후방 추돌. 독립 접촉/고의 진로 방해의 과실이 부족하면 보류한다. 주행 금지/불법 연결은 물리 차단하고 보정·격리·실패 이동으로 점수를 만들지 않는다.
  • 단일 접근/연속 위반의 사건ID·revision 유지, 재접속/예측 replay에서 재확정 금지. 실제 위반을 원장에 반영하고 근거·보류 사유를 표시한다. 캠페인 감점/내구도 수치를 자동 이식하지 않는다.
  • 시험값은09에서 후보로 기록한다. 기존2인/50Hz/차량A/무접촉 유지, 경기 시간은 제품 확정하지 않는다.

실행 단계

  • 1. PvpDrivingPilot와 Editor 주행 검사: 실제 motor 입력으로 스폰→정차점/정차점→정차점 경로 통과, 위치 변경 API 부재·정차 방향·합법 경로/거리 확인. red→green.
  • 2. PvpNpcAuthority/공유 DTO/표시·충돌/예측 연결: 동일 tick NPC snapshot·신호 양보·안전 간격·정차점 미봉쇄·격리 제외 검사.
  • 3. PvpRuleAuthority/관측 DTO/원장 연결: 같은 접근 상향 차액, 정상 진입 뒤 적색 면책, 우회전 정지, 실제 보행 진행, 과속/역주행 지속·접촉 책임/보류, 재접속·중복/복구 제외 검사.
  • 4. 실제 두 Player 운송 러너: authority fixture0/accepted 이동거리·입력 수·승하차·원장/결과 일치, 역할/출발점 교환, 지연·손실 조건. 실제 입력 법규 경로와 negative case를 Editor/Player로 구분한다.
  • 5. 독립 리뷰·기존 경기/재접속/캠페인·내구도/Strict/배포 보존, 필요한 실제 화면 확인, 이력/LATEST/로드맵 갱신·커밋·feature push. 자동 검증에 PC 화면 조작은 필요하지 않았으며 사람 화면 수용은 별도 미검증으로 남겼다.

남길 항목: 다른PC LAN/인터넷·사람 키보드/패드·장시간 체감·전체 교통/과실·공급/수익 밸런스. 이번 완료 범위를 전체 QA/공개 랭킹 승인으로 올리지 않는다. 독립 리뷰/실패 재현 후 부분 관측 초기화·고정 지도 검증·보행자 접촉 띠/분리 탈출을 보완했다. 실제3프로필과 소스32b2331의 최종 재빌드/복사본 운송·격리/139개 파일 해시 검증을 통과했다. 배포 f68fcf2의 feature push 종료0/원격 동일 해시를 확인했다. 동시 작업의 b8ad18a/16aa387 및 main HUD를 보존하며 PVP도 전체 실행 폴더와 전용 manifest로 배포한다. 실제 명령·결과와 별도 PC/사람 수용은 작업 이력/19번 문서에 남겼다.
