변경 절차

  1. 사용자 결정 또는 시험 근거를 이 문서에 날짜·근거와 함께 기록한다.
  2. 규칙 소유 문서와 설정 버전을 갱신한다. 같은 수치를 여러 본문에 복사하지 않는다.
  3. 해당 QA 항목과 개발 단계의 영향을 기록한다.
  4. 진행 중인 경기는 시작 시 고정된 설정을 유지하고, 변경은 다음 경기부터 적용한다.
  5. 문서 초안, 자동검사 통과, 실제 온라인 플레이 완료를 서로 다른 상태로 기록한다.

VehicleHandlingProfile A/B와 ArenaScaleProfile은 Task 2 이력의 실제 자동 측정값을 가진 시험 후보다. Content/Maps/PvpArena01.asset은 외곽 좌표 ±60m와 정차점 ±72m의 회색 상자 맵이며 최종 규모가 아니다. 경로 추정 속도는 외곽18m/s·내부7m/s 비교 입력이다. NPC/신호가 없으며 실제 속도 보장이나 최종 제한속도 규칙이 아니다. 차량 A/B 중 최종 채택은 사람 조작감과 P2 검증 이후 결정한다. 경기 시간·인원·배점·충돌·SDK 상태는 유지한다.

직접 IP 후보 추가 (2026-10-29)

사용자가 Fusion SDK/App ID 미준비와 대안 확인을 답했다. 따라서 NGO1.12.0 + Transport1.5.0을 현재 Unity2022.3.62f2에 설치하고 직접 IP 2인 주행을 시험한다. 이는 기존 대안의 검증 착수이며 Fusion 기술 실패나 NGO 최종 채택 결정이 아니다. Relay/계정/인터넷 초대방은 추가하지 않는다. NGO의 기본 보간을 완전한 예측이라고 부르지 않고, 별도 입력 이력·권한 ACK·재계산을 구현했다. 입력은 서버 tick당 한 번만 적용하며 한꺼번에 도착한 조작 상태는 최신 것으로 합친다.

실제 빌드 GUID·맵 hash·프로토콜·주행 규칙이 같아야 입장 가능하다. 테스트용 고정50Hz/차량A/2인/무접촉이며 경기 시간은 정하지 않는다. 측정 결과·남은 항목.

직접 IP 후보는 패킷 사이 입력을 최대10서버tick(200ms) 유지하고 이후 입력 유실 감속한다. 시험값이며 실제 연결 종료·재접속 정책을 대신하지 않는다. buildGUID가 달라 Editor와 Player 또는 별도 재빌드 간 접속은 거절될 수 있다.

재접속·공통 콘텐츠 시험값 (2026-10-29)

항목 현재 상태 확정과의 경계
재접속 유예30초같은 프로세스/생존 호스트 시험값, 검사3초 축소 가능최종 경기 복귀 정책 미확정
네트워크 차량차량A·무접촉·서버50Hz인원/배점/접촉/SDK의 제품 확정 아님
승객37변주완료 공통 콘텐츠 미리보기와 서버 선택 복원실제 운송/운임/청결 효과 미연결
내구도·수리캠페인에서도 기획/미구현캠페인D0 운행 불가 방향을 PVP 확정으로 가져오지 않음

상세 적용 검토. 경기 시간을10분으로 고정하지 않으며 고액 단건과 짧은 여러 건의 전략 비교는 실제 운송 단계에서 수행한다.

확장 시험장/서비스 추가 후보 — 2026-10-29

사용자는 기존 자체 PVP 시험장 확장·은계형 필요한 UI 차용·승객/시설 구현을 지시했다. 이번 시험 후보는 외곽1,760m·승객8거점·주유2시설·NPC6/보행4, 연료100/실수락5km, 주유5초/2점·고갈 제자리 지원8초/6점이다. 서비스 비용은 안전 위반과 별도이며 완료 시1회, 미완료 무청구다. 경기 시간10분/최종 배점·SDK/충돌·PVP 손상수리를 새로 확정한 것이 아니다. 실제 범위는 23을 따른다.
