완료 승객 콘텐츠 연결

37변주의 유형·대사는 이제 기본 경쟁 운송에서도 서버가 선택해 표시한다. 모든 유형에 공통인 승차·하차·고정 운임/정산을 연결했으며, 수면·응답 기억·적재/하역·음식/짐 오염·청결 경제의 유형별 효과는 아직 PVP에 연결하지 않았다. 이전 요소별 검토표의 유형별 후속 조건을 유지한다.

내구도 원본 완료 후커밋된 상태 모델부터 적용 재검토. 다른 채팅의 진행 중 변경을 복사하지 않음

동일 세션 재경기 UI와 개별 사건 근거를 여는 상세 UI는 후속이다. 현재는 전체 점수 구성과 가장 최근 원장 항목을 보여 준다.

P2 전체 수용이나 공개 경기/랭킹 운영 승인으로 표시하지 않는다. 사용자가 이번에 다른PC·사람 검증을 별도 정리하고 후속 구현까지 진행하도록 지시한 범위를 따른다.

2026-10-29 실제 입력 주행·공유 교통 후속

최신 수용·환경별 잔여 표와 실제 검사 이력을 따른다. 위치 제어 없이 실제 모터 입력으로 운송하고 서버 NPC2대/보행1명·신호/우회전/지속 속도·방향/접촉 책임·보류를 연결했다. 이전의 해당 미구현/미검증 설명은 당시 기록이다. 다른PC·사람/화면 시야·복합 교통/금지차로 자산은 별도 수용으로 남긴다.
