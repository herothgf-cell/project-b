- 법규: 중앙/남쪽 접근의 swept 정지선→진입 사건 상향, 남쪽 실제 우회전의 정지/전용 신호, 실제 보행 보호, 지속 과속/역주행, 근거가 있는 NPC 후방 추돌. 독립 접촉/고의 진로 방해의 과실이 부족하면 보류한다. 주행 금지/불법 연결은 물리 차단하고 보정·격리·실패 이동으로 점수를 만들지 않는다.
- 단일 접근/연속 위반의 사건ID·revision 유지, 재접속/예측 replay에서 재확정 금지. 실제 위반을 원장에 반영하고 근거·보류 사유를 표시한다. 캠페인 감점/내구도 수치를 자동 이식하지 않는다.
