제작 방향과 근거

PVP 경기장은 직접 제작한다. 현재 은계 맵이나 실제 도시를 가져와 경기장으로 사용하는 방식은 이번 기본안에 포함하지 않는다. 빠르게 달릴 수 있는 외곽 도로와 거리는 짧지만 선택이 잦은 내부 연결로를 조합하는 안을 제안한다. 최종 형태·크기·참가 규모·경기 시간은 09 결정·밸런스의 검토 대상이다. 이 문서는 도로 구조·합법 연결·정차점·콘텐츠 카탈로그를 소유한다. 공급·승객 소유권·약정 운임은 04 승객·운임, 표시 방식은 06 UI가 소유한다.

확인한 기존 근거 PVP 설계에 적용할 원칙 분리할 내용
MapCatalog.cs현재 선택 가능 지역은 은계로 제한됨PVP 카탈로그를 별도 경로로 구성하며 은계 보정을 자동 적용하지 않음
기존 길안내 기획방향·회전 제한·정차 방향을 반영한 합법 경로기존 도시 시설 목록을 경기 콘텐츠로 그대로 가져오지 않음
기존 주행·교통 기획놓친 회전은 다음 합법 연결로 복구금지 회전·인도 횡단을 빠른 길로 안내하지 않음

아래 맵·구역·정차점·프리셋 ID는 모두 신규 제안, 아직 없음이다. 실제 씬·지도 데이터·에셋 파일이 생성된 상태를 의미하지 않는다.

후보 경기장의 공간 역할

공간 의도한 운송 선택 제작 규칙 피할 구조
외곽 순환도로긴 이동에서 회전·정지 부담을 줄이는 빠른 경로진행 방향별 차로와 읽기 쉬운 내부 연결부직선 최고속도만으로 모든 운송을 해결하는 구조
내부 연결로거리를 줄이고 다음 호출에 유리한 위치로 이동짧은 회전 연결과 한눈에 이해되는 교차로보이지 않는 회전 제한·불필요한 막다른길
상업 구역가까운 운송과 정차 접근 판단정차 공간을 주행 차로에서 분리합법 승하차가 주행로 전체를 막는 배치
터미널 구역명확한 출발·도착 방향과 여러 운송 조합진입·정차·출구가 이어지는 차량 동선건물 반대편 핀이나 중앙 분리대 너머 접근
창고 구역외곽 이용과 내부 지름 경로 비교넓은 접근 공간, 명확한 진출입 방향시설 마당을 가로지르면 항상 빨라지는 배치
공원 구역보행자 보호와 경로 선택 장면충분한 시야와 분리된 승하차 공간갑자기 나타나는 보행자를 피할 공간이 없는 곳
출발 공간첫 운송 선택을 비슷한 조건에서 시작본선 진입 여유와 합법 방향을 제공특정 출발 위치만 첫 호출에 직접 도착하는 배치

외곽 도로와 내부 연결로 어느 쪽도 항상 우월하지 않게 한다. 거리가 짧은 길은 회전·대기 부담을, 빠른 길은 우회 거리를 감수하되 운임은 실제 우회 거리로 증가하지 않는다. 차량 간 충돌 OFF 후보에서도 좁은 통로·불명확한 출구가 경쟁을 결정하지 않도록 설계한다. 충돌 정책 변화 시 공간을 다시 평가하며 현재의 비접촉 가정에 맞춰 확정하지 않는다.

도로 그래프의 최소 계약

데이터 개념 반드시 표현할 관계 잘못된 연결 방지
도로 구간실제 주행 가능한 중심 경로·경계·경사배경 장식 도로를 운행 그래프에 넣지 않음
방향 차로소속 도로·진행 방향·연결 가능한 끝점같은 도로의 반대 차로를 자유 이동 경로로 연결하지 않음
차로 변경 연결같은 방향의 연결 가능한 구간중앙 분리대·금지 구간을 가로지르는 연결 금지
교차로 연결진입 차로에서 진출 차로로 이어지는 특정 회전 동작화면에서 선이 교차한다는 이유만으로 연결 생성 금지
통행 조건해당 연결의 신호 그룹·회전 제한·양보 조건다른 접근의 신호로 진행 허용하지 않음
정차점 접근연결 차로·진입 경로·정차 방향·출구 경로도로 반대편 핀까지 직선으로 안내하지 않음
복구 지점연결 차로·차량 방향·안전 공간·이전 합법 경로가장 가까운 좌표만 보고 다른 도로로 이동하지 않음
지도 식별카탈로그 ID·콘텐츠 버전·검증된 구성서로 다른 도로·신호 데이터를 가진 참가자를 같은 경기로 시작하지 않음

도로의 시각적 메시와 이동·신호·위반 판정 영역은 같은 정의에서 파생되게 한다. 눈에 보이는 차로와 서버가 판정하는 차로가 다르면 해당 콘텐츠를 경기 선택에서 제외한다. 모든 활성 출발점과 정차점은 허용 방향으로 다른 활성 정차점까지 도달하고 다시 나올 수 있어야 한다. 일방통행 자체는 허용하되 귀환 불가능한 정차점을 만들지 않는다. 우회전·좌회전·유턴은 각각 허용된 연결이 있을 때만 경로에 포함한다. 유턴 장소가 없으면 다음 합법 회전 경로를 제공하고 즉석 반대 차로 진입을 요구하지 않는다.

신호와 빠른 합법 경로

상황 공간·교통 설계 확인할 비교
외곽 장거리 이동흐름이 이어지는 구간과 미리 읽히는 합류부 제공불법 진입 없이 빠른 운송이 가능한가
내부 짧은 경로회전 판단은 주되 불필요한 연속 대기는 줄임짧은 거리의 이점이 대기로 항상 사라지는가
신호 접근적용 방향·정지선·충돌 구역을 멀리서 구별운전자가 늦게 알아차려 급정지해야 하는가
정상 대기짧고 예측 가능한 기다림 뒤 진행 기회 제공합법 대기 시간의 체감이 운송 선택을 압도하는가
정차 후 합류진출입로에서 본선 진행 방향을 확인 가능불법 회전이나 역주행 없이 다음 운송을 시작하는가
경로 놓침다음 연결로에서 자연스럽게 재탐색복구 경로가 원래 경로보다 항상 큰 손해가 되는가

신호 주기·정차 간격·도로 크기 등의 후보 수치는 09에서 관리한다. 합법 주행이 경쟁력을 갖는지는 10 플레이테스트·인수에서 실제 비교하며, 제작만으로 달성했다고 표시하지 않는다.

길안내의 동작

선택·상태 안내할 경로 예외·보호
빠른 길합법 연결과 도로별 이동·신호 대기 예상에 따른 시간 우선 경로항상 외곽 도로를 고정 선택하지 않음
짧은 길합법 연결의 거리 우선 경로인도·공터·반대 차로를 거리 절약 경로로 넣지 않음
승객 접근차량 현재 차로부터 정차점의 합법 진입까지핀 좌표까지 직선 거리로 도착 가능성을 판단하지 않음
운송 시작실제 정차 위치에서 출구를 거쳐 하차점으로 연결정차 구역 내부의 회전·출구 동선을 생략하지 않음
회전 놓침현재 차로·진행 방향에서 다시 합법 경로 계산금지 유턴·후진·벽 통과로 원래 선에 복귀시키지 않음
신호·혼잡 변화공통 교통 상태를 참고해 예상시간 갱신작은 변화마다 경로를 좌우로 번갈아 바꾸지 않음
호출 미리보기접근 경로와 약정 운송의 경로를 구분선택만으로 기존 운송 목적지·계약을 덮어쓰지 않음
경로 없음접근 불가 사유를 표시하고 콘텐츠 오류를 기록잘못된 직선 안내나 순간이동으로 성공 처리하지 않음

내비 예상시간은 약속된 도착 시각이나 운임 보장값이 아니다. 서버가 승인한 목적지·지도 버전을 사용하고, 화면 색·선·회전 안내의 표현은 06에서 정의한다.

승하차 공간의 기하 조건

구성 제작·판정 규칙 실패 시 처리
대기 위치승객은 차도 밖에서 정차 영역을 식별할 수 있게 대기안전한 보행 공간이 없으면 공급 대상에서 제외
차량 정차 영역차량의 위치·방향·정지 상태를 함께 평가핀에 가까워도 반대 차로·잘못된 방향이면 미도착
접근 동선진입 차로부터 허용 회전으로 정차 영역까지 연결접근 불가능한 방향의 호출을 공급하지 않음
출구 동선정차 방향에서 연결된 도로로 다시 진출 가능승차 직후 유턴·인도 횡단을 강요하는 곳 제외
연속 대기 공간경쟁 차량이 접근해도 본선 주행과 출구를 가리지 않음장기 점유 문제가 있으면 정차점 배치·공급을 재조정
보행자 경로승하차 연출과 횡단보도 보호 영역의 관계가 명확건물·벽을 뚫거나 본선을 가로질러 탑승하지 않음
목표 범위같은 시설의 다른 출입구를 별도 정차점으로 식별건물 반대편에서 목적지 도착으로 확정하지 않음

정차 허용 오차·저속 조건·상호작용 유효 범위는 09의 공통 설정을 사용한다. 실제 탑승 확정·동시 접근·소유권 경쟁은 04가 처리한다.

지도 경계와 위치 복구의 악용 방지

경기장 외곽은 시각 경계와 서버 판정 경계를 맞춘다. 갈 수 없는 공간은 사전에 읽히게 하고, 풍경으로 보이는 도로가 실제 출구인 것처럼 오해되지 않게 한다.

조건 서버가 허용할 처리 금지할 이득
경계 접근·차로 이탈마지막 유효 차로·방향·정상 진입 경로를 보존불법 영역에 들어간 위치로 복구 기준을 갱신하지 않음
복구 대상 경계·비주행 영역 통과해당 이동을 통한 승하차·완료 요청을 거절하고 같은 시각의 경계 판정을 우선 처리복구 전에 호출 확보·운임 확정부터 받아 이득을 남기지 못함
복구 요청 승인이탈 전 경로에 속한 유효 복구 지점으로 이동공간상 가깝다는 이유로 벽 반대편·다른 갈림길에 배치하지 않음
목표 방향으로 지름길 시도합법 경로 기준으로 이탈 직전보다 운송 진행을 늘리지 않는 지점 선택경계 넘기·낙하·복구 반복으로 남은 경로를 줄이지 못함
복구 위치 점유같은 합법 경로의 안전한 후방 대체 지점 사용점유를 이유로 앞쪽 목적지 근처에 이동하지 않음
복구 이동 중승하차·경로 통과·안전 보너스의 새 성립 중지순간 이동을 정상 운송 완료로 계산하지 않음
반복 이탈·재접속기존 운송·위반·복구 이력을 유지사건 ID와 요청 제한을 초기화하지 않음
유효 복구 지점 없음안전 정차와 오류 기록, 경기 처리는 01 경기 흐름의 예외 규칙 적용클라이언트 임의 좌표로 복귀하지 않음

도로 위 신호·회전 위반은 02의 사건 판정 대상이며, 그 사실만으로 정상 정차점의 완료 운송을 무효 처리하지 않는다. 지도 밖·비주행 영역의 지름길로 생기는 이득과 구별한다. 클라이언트의 임시 도착·획득 표시는 서버의 유효 영역·정차점 확인 전 확정 상태가 아니다. 이탈 이전에 정상 확정된 운송은 유지하고, 이탈로 생긴 잘못된 요청·예측 표시는 04·05의 서버 상태로 교정한다. 차량 복구 상태 전이는 02 주행·교통, 점수 원장 반영은 05 점수·결과, 복구 요청 제한의 후보 값은 09에서 관리한다.

운송 조합과 확장 순서

단계·조합 먼저 확인할 경험 다음 단계로 넘길 조건
기본 회색 상자 맵터미널↔창고에서 외곽 빠른 길과 내부 짧은 길 비교왕복 합법 연결·정차·복구 경로가 성립
운송 조합 확장상업 구역↔공원, 공원↔터미널에서 연속 호출 위치 선택특정 정차점·방향만 운임 또는 접근에서 상시 우세하지 않음
기본 PVP 콘텐츠공용 승객과 첫 공급을 배치하고 참가 규모를 확대04의 공급 보호와 10의 사람 플레이 검증 충족
NPC 프리셋 비교같은 운송 조합에서 대기·합류·보행 판단 추가교통 운과 장기 막힘이 운송 경쟁을 압도하지 않음
후속 맵격자·가상 항만에서 새로운 경로 구조 제공기존 차량·점수 규칙으로도 선택과 공정성 유지
후속 변형 콘텐츠시간대·시야·교통 장면을 별도 버전으로 검토가독성과 지연 상황을 확인한 뒤 경기 선택에 노출

확장은 실제 도시 반입이나 성능 우위 차량의 해금으로 대체하지 않는다. 승객 성격·외형·연출 변화가 운임·스폰 확률에 영향을 주면 04·05·09에서 별도 검토한다. 출발 위치별 도달성, 합법 최단·최속 경로, 정차 방향, 경계 복구의 자동 검증과 사람 플레이 목록은 10이 소유한다. 현재 카탈로그는 제작 순서를 검토하는 초안이며 플레이 가능한 콘텐츠 목록이 아니다.
