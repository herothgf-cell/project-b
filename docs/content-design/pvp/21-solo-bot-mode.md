# 한 창 1인 테스트 · 봇 상대

사용자 요구: 다른 사람/두 번째 실행 창 없이 직접 운전하면서 승객 운송·NPC·법규·정산을 시험한다. 기존2참가자 권한 모델의 두 번째 자리를 로컬 봇으로 채운다. 봇 전략/속도는 시험 후보이며 온라인 밸런스나 공개 랭킹 기준으로 확정하지 않는다.

## 실행 방법

1. `builds/PvpPrototype/` 전체 폴더를 유지하고 `PvpPrototype.exe`를 실행한다.
2. 초기 화면에서 경기 시간과 마감 유예를 초 단위로 입력한다. 예를 들어180초/30초로 시험할 수 있다. 제품 경기 시간의 기본값을 확정한 것은 아니다.
3. **혼자 경기 시작 · 봇 상대**를 누른다. 참가 인원 검사/IP/포트 입력은 필요 없다. 3초 준비 후 나와 봇의 경기가 시작된다.
4. 오른쪽 대기 승객을 선택해 경로를 띄운다. 승차 지점에 올바른 방향으로 정차하고0.2초 유지한 뒤 **E** 또는 현장 승차 버튼을 누른다. 운송 중에는 목적지 경로로 바뀌며 같은 조건에서 **E** 또는 하차 버튼으로 운임을 정산한다.
5. 본 경기 종료 뒤에는 새 승차가 마감된다. 유예 동안 기존 운송을 마무리하고 최종 운임점수·안전 보너스·감점·완료 건수·순위를 확인한다.
6. **Esc** 또는 **초기 화면으로**를 눌러 나간 뒤 같은 창에서 다시 시작할 수 있다. 이전 점수/승객은 새 경기로 이어지지 않는다.

조작: **W** 가속, **S/Space** 제동, **A/D** 조향, 정차 후 **Q** 전후진 전환, **M** 전체 지도. 보행자 앞을 가로막았다면 정차 후 Q로 후진을 선택하고 W로 공간을 비켜 준다. 다른 참가자가 차지한 승객은 새로 선택한다.

## 검증 기록

모델: 360초+10초의 입력 기반 연속 운송에서 양쪽7회씩, 약1.9km/2.0km, 도로 경계 차단·법규 감점0, 하나의 원장 합계/결과 확인. 기존 PVP Editor 회귀와 Windows 빌드도 통과했다. 실제 단일 Player 정상/위반 모두 각2회 운송·약673/747m·fixture/도로 경계 차단0·나가기/새 경기 정산을 확인했다. 정상77/88점, 위반71/88점(사람3감점/첫 안전 보너스 제외). 기존2Player/재접속6시나리오·격리/Strict/싱글 manifest도 통과했다. 정확한 실패→보완·배포 결과는 [작업 이력](../../work-history/2026-10-29-pvp-solo-bot.md)에 남긴다.

실제 사람 입력/화면 시야·봇 상대 난도/수익 체감·장기 부하·다른PC 직접IP 수용은 별도다. 자동 입력 운송을 사람 플레이나 WheelCollider 검증으로 표시하지 않는다. 기존 [19번 수용](19-driving-npc-rules-acceptance.md)과 [구현 계획](20-solo-bot-mode-plan.md)을 함께 따른다.
