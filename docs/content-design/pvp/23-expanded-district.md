# 확장 PVP 시험장 · 은계형 화면

사용자 확인에 따라 **현재 PVP 자체 시험장**을 확장한다. 은계 실제 지형/도로 데이터를 반입하지 않는다. 화면/UI·지도 데이터·확장/승객·시설을 일괄 구현한 뒤 통합 검사를 시작했다.

이 길이/인원/교통량/연료/서비스 비용은 프로토타입 시험 후보다. 경기 시간을10분으로 고정하거나 전체 배점/충돌/SDK·공개 랭킹 수용을 확정한 것은 아니다.

## 직접 플레이

1. `builds/PvpPrototype/` 전체 폴더를 유지하고 `PvpPrototype.exe`를 실행한다.
2. 경기 시간/유예를 입력하고 **혼자 경기 시작 · 봇 상대**를 누른다. 긴 외곽 운송을 보려면 충분한 시간을 직접 정한다.
3. 승객을 선택→경로 따라 승차 거점으로→올바른 방향/정차0.2초→E 승차, 목적지에서 E 하차.
4. WASD/방향키·Space 제동·정차 후 Q 전후진. C/V 추적·운전석 전환, M 전체 지도.
5. 주유 패널에서 시설을 선택하면 시설 경로를 표시한다. 해당 정차점에서 같은 버튼으로 주유를 요청한다. 진행 중 취소/운송 목적지 길안내 복귀도 가능하다. 비용과 소요 시간을 확인한다.
6. 결과의 운임점수/안전 보너스/위반/서비스 비용/완료 건수/순위를 확인하고 초기 화면으로 돌아가 새 경기 시작.
