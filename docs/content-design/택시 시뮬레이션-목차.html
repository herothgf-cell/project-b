마인드맵 · 기획 목록

2026-11-23 기준으로 원본의 세 갈래를 같은 순서로 표시한다. 실제 기능을 찾을 때는 현재 플레이, 다음에 넣을 콘텐츠를 검토할 때는 성장·후속 구상에서 시작한다. 개별 승객·법규·수치·조건은 담당 문서에서 관리한다.

마인드맵의 각 노드에서 Detail → Links로 담당 문서를 연다. 앱 링크는 GitHub main 문서 주소를 사용하며, 로컬 열람은 아래 상대 링크를 이용한다. 새 문서는 커밋·푸시 후 원격 링크에 반영된다.

관리 기준. 마인드맵은 루트 아래 최대 3단계의 탐색용 개요다. 노드에 진척도나 하위 항목 수를 합산하지 않고, 구현·검증 상태는 담당 기획과 최신 작업 이력을 따른다. 문서를 합치거나 옮기면 마인드맵 링크와 이 목차를 함께 고친다. 이전 관리 기준은 보관본에 있다.
