# 운전 히스토리와 복습

기준일: 2026년 10월 16일 · 버전: 0.6 · 상태: 구현 6de26a5 및 검증 결과 대조

자신의 선택과 이유를 짧게 돌아보고 다음 운행에서 바꿀 행동을 찾는다. 프로토는 **사건 카드 → 하루 누적 → 요약 성향 → 같은 상황 재시작**까지 제공하는 안이다. 수치·보관 범위는 기획 제안이며 현재 구현 완료를 뜻하지 않는다.

## 현재 구현과 검증 범위

F8 및 정산 화면에서 법규/승객 결과를 별도 탭으로 조회한다. 관찰 조건·보조 사용·탑승 여부·이유와 일일 집계를 표시한다. 결산 사건 복습은 별도 실행 프로세스에서 진행하고 원래 사건 ID에 결과를 연결한다. 준비 화면의 우회전 연습도 제공한다. 연습 중 원래 돈·시간·매너·법규를 보존하며 유효 판정이 없으면 평가 없음으로 표시한다.

**남은 확인:** 실제 사용자가 기록을 이해하고 다음 운전에 반영하는지, 창 전환과 반복 복습의 사용성은 수동 확인 대상이다. 영상 리플레이는 구현하지 않았다.

근거: [통합 검증](../prototype-completion-validation.md) · [개발 체크리스트](../prototype-development-checklist.md). 아래 상세 표는 목표 설계를 포함하므로 표의 ‘포함’만으로 검증 완료를 뜻하지 않는다.

## 프로토 포함·제외

| 항목 | 적용 | 최소 내용 / 후속 범위 |
|---|---|---|
| 사건 카드 | 포함 | 상황 조건, 행동, 규칙별 판정, 감점, 짧은 이유 |
| 일일 누적 | 포함 | 하루 법규 점수, 준수·위반·보류, 상황 선택 횟수 |
| 요약 성향 | 포함 | [평가 기준](02-driving-evaluation.md#성향-요약-기준-초안)에 따른 최대 2문장과 카드 링크 |
| 저장·다음 날 연결 | 포함 | 3일 캠페인의 사건·규칙별 누계·최근 성향 유지. 하루 점수만 초기화 |
| 같은 상황 재시작 | 포함 | 준비한 장면의 시작 상태로 돌아가 다른 선택을 해봄 |
| 도식·행동 순서 | 간단히 포함 | 텍스트 순서와 필요시 정적 도로 도식. 주행 영상을 복원하지 않음 |
| 영상 리플레이·임의 시점 되감기 | 제외 | 저장량·재현 구조가 필요한 후속 기능 |
| 장기 실력 등급·배지·능력치 상승 | 제외 | 상황별 숙련 단계와 보상은 후속 검토 |
| 자동 변형 생성·다른 배치 연습 | 제외 | 프로토는 이미 제작한 동일 장면을 재시작 |
| 대량 이력 검색·클라우드 영구 보관 | 제외 | 프로토 저장 게임 안에서 확인하는 범위 |

## 이용 흐름

| 시점 | 화면·행동 |
|---|---|
| 주행 중 | ‘상황이 기록되었습니다’ 정도의 짧은 표시. 카드 열람을 강제하지 않음 |
| 정차·운송 완료 | 승객 운송 결과와 법규 사건을 별도 카드로 확인 |
| 하루 종료 | 수입·비용과 별도로 법규 점수, 오늘의 기록, 요약 성향 표시 |
| 카드 상세 | 조건과 판정 이유 확인 → 같은 상황 재시작 선택 |
| 복습 종료 | 연습 결과 확인 → 결산으로 복귀하거나 다음 날 시작 |

법규 점수로 요금·팁을 자동 변경하지 않는다. 승객을 바꿔도 이전 법규 기록은 유지한다.

## 사건 카드 최소 정보

| 필드 | 표시 예시 / 기록 원칙 |
|---|---|
| 사건·상황 | ‘오른쪽 출구 앞의 긴 줄’, 발생한 날·운송 / 빈차 여부 |
| 조건 | 신호 대기열, 진입 구간, 상대 간격, 승객 재촉 있음 |
| 행동 순서 | 대기열 옆 통과 → 앞부분 진입 → 상대 차량 제동 |
| 관찰 결과 | 정상 진행 방해 조건 확인, 충돌 없음. 확인할 수 없는 영향은 추측하지 않음 |
| 규칙별 판정 | L06 끼어들기 위반 / L07 진로 변경 위반. 적용 조건과 [법규 근거](02-driving-evaluation.md#법규-자료와-확인-범위) 링크 |
| 사건 감점 | -15. 적용 규칙 2개지만 사건당 최대 감점 1회 |
| 도움·판정 상태 | 수동 조향 / 조향 보조 사용 / 보류 사유 등 |
| 다음 행동 | ‘대기열 뒤 합류나 직진 우회를 선택해 보기’ / 같은 상황 재시작 |

‘늦게 봤다’, ‘고의였다’는 해석을 시선이나 결과만으로 확정하지 않는다. 정지선 앞에서 급정지해 보행자를 보호했다면 보호 의무 준수와 접근 감속의 개선 여지를 따로 적는다. 위험을 피하려고 한 필요한 급제동을 자동 위반으로 만들지 않는다.

## 출구 정체 A·B·C 기록 예시

상세 플레이와 기존 5회 누적 예시는 [운전 상황 문서](01-driving-situations.md)에서 확인한다. 아래 세 행은 동일 장면에서 갈라지는 대안이며 한 번의 운행에서 모두 발생한 결과가 아니다.

| 선택 | 기록할 행동 | 법규·점수 | 성향에 남기는 정보 |
|---|---|---|---|
| A 대기 | 뒤 합류 → 간격 유지 → 순서대로 출구 진입 | 관찰한 진로 변경 조건 준수, 감점 0 | 대기 1회. 한 건으로 ‘모범 운전자’ 유형을 부여하지 않음 |
| B 우회 | 직진 유지 → 출구 통과 → 대체 경로 | 이 장면 관련 위반 없음, 감점 0. 수행하지 않은 출구 차로 변경은 평가 기회 없음 | 우회 1회. 대기하지 않았다는 이유로 불이익 없음 |
| C 앞부분 진입 | 신호 대기열 앞으로 진입 → 상대 차량 제동 | 설정된 조건에서 L06·L07 위반, 사건 1건·감점 -15 | 앞부분 진입 1회, 각 규칙 위반 1회 |

방향지시만 켜고 통행 방해 없이 직진하면 끼어들기 위반으로 확정하지 않는다. 진입 후 복귀했더라도 이미 성립한 위반은 유지한다. 실제 소요·거리·연료는 보여주되, 선택하지 않은 경로보다 몇 초 손해 봤다고 확정하지 않는다.

## 하루 누적과 요약

| 구분 | 계산·표시 제안 |
|---|---|
| 하루 점수 | [사건별 감점 규칙](02-driving-evaluation.md#중복과-누적-및-판정-보류)을 적용. 0~100점, 평가 기회가 없으면 ‘평가 기록 없음’ |
| 상황 수 | 사건 단위로 집계. 한 사건에 규칙 2개가 있어도 사건 수는 1건 |
| 규칙별 준수 | 각 규칙의 준수 / 위반 / 보류 횟수. 준수율에는 보류·평가 기회 없음 제외 |
| 경로 선택 | 대기·우회·앞부분 진입 횟수. 규칙별 준수율과 분모를 분리 |
| 최근 성향 | 같은 상황군·규칙의 최근 유효 5건 기준. 5건 미만은 횟수와 기록 부족 안내 |
| 요약 선택 | 유지한 준수 1개, 반복해 놓친 항목 1개를 우선 표시. 해당 기록이 없으면 억지로 채우지 않음 |
| 이전 날 | 이전 사건·누계는 보존. 하루 점수를 여러 날 합산해 실력 등급으로 만들지 않음 |

출구 정체 5회가 ‘대기·앞부분 진입·우회·앞부분 진입 후 복귀·대기’였다면 **선택은 5건**, 출구 차로 변경은 **준수 2건·위반 2건의 4기회**, 우회 1건은 해당 규칙의 기회 없음이다. 규칙 기록이 5건 미만이므로 반복 성향을 확정하지 않는다.

표시 예시: ‘출구 정체에서 대기 2회, 우회 1회, 앞부분 진입 2회. 재촉이 있었던 3건 중 2건에 관련 위반이 있었고, 가장 최근에는 뒤에 합류했습니다.’ 재촉이 위반의 원인이라고 단정하지 않으며 각 사건 카드로 이동할 수 있게 한다.

## 같은 상황 재시작

| 항목 | 프로토 동작 제안 |
|---|---|
| 진입 시점 | 결산 사건 카드의 복습, 준비 화면 또는 Esc 일시정지의 별도 우회전 연습 선택. 진행 중인 운송은 정지 상태로 유지 |
| 재현 범위 | 해당 상황의 준비된 시작 위치·신호·AI 배치·승객 조건을 다시 사용. 실제 운행의 모든 순간을 복원하는 기능은 아님 |
| 연습 방식 | 대기 대신 우회, 더 이른 감속 등 행동을 바꾸어 주행. 안내 사용 여부 표시 |
| 시간·경제 | 연습 중 실제 영업 시간·연료·수입·기록을 진행시키지 않음 |
| 결과 | 원래 사건 아래 ‘연습 1회 / 다른 선택 수행’ 등으로 별도 연결 |
| 누계 | 영업 법규 점수·성향·매너·수익에 반영하지 않음. 이전 위반 기록을 지우지 않음 |
| 복귀 | 연습 종료 후 원래 준비·정산·일시정지로 돌아감. 반복 연습으로 보상 재지급 없음 |

다음 실제 운행에서 달라진 행동이 쌓이면 최근 성향에 반영한다. 조향 보조 사용 자체를 감점하지 않으며, 플레이어가 직접 수행한 판단을 기록한다. 자동 정지처럼 판단을 대신하는 도움은 프로토 범위에서 제외한다.

## 구현: 우회전 연습의 이번 시도 피드백 (2026-10-16)

연습 도로에 ① 정지선과 ② 보행 확인 위치를 표시한다. 주행 중에는 정지선까지 거리와 실제 법규 관찰기의 정지 인식 여부를 보여준다. 우회전 후 횡단 구간을 빠져나오면 일시정지된 결과 창에서 잘한 점·보완할 점·다음 시도 행동을 읽는다. 정지 누락, 전용 적색 진입, 횡단 중 보행자 방해, 잘못된 진행 방향을 각각 설명한다.

결과는 이번 시도의 관찰만 사용한다. 미통과는 미완료, 관찰 정보 부족은 판정 보류이며, 위반 없음도 전체 운전 능력이나 100점 성공을 뜻하지 않는다. 시선 확인은 평가하지 않는다. 기존 법규 감점과 승객 매너는 변경하지 않는다.

결과 창에서 같은 조건 재시도·다른 조건 선택·닫고 계속을 지원한다. R/패드 복귀도 우회전 연습에서는 새 시도로 시작한다. 현재 판정과 정지 인식은 초기화하고 이전 법규 이력은 남긴다. 현재 판정 보기로 중간 상태를 확인하고 F8로 상세 법규 기록을 볼 수 있다. 연습 종료 결과에는 마지막 시도의 요약과 설명을 추가하며 구형 저장은 그대로 읽는다.

## 출구 정체 연습 결과 (2026-10-16)

출구 사건 복습에도 이번 시도의 잘한 점·보완할 위치·다음 행동을 표시한다. ① 대기열 뒤 합류 위치와 ② 앞부분 진입 주의 위치를 지면에 표시한다. 실제 출구 관찰기의 L06/L07 기록을 사용하며, 뒤 합류·대기 / 직진·우회 / 앞부분 진입 / 진행 방해를 구분한다. 우회는 끼어들기 평가 기회 없음으로 설명하고, 관찰 불명은 보류·미통과는 미완료로 남긴다. 이 결과는 신호 등 전체 법규의 종합 합격 표시가 아니며 다른 사건은 F8에 남는다.

같은 조건 재시도와 R/패드 복귀는 저장된 경로·교차로·8대 대기열을 복원하고 보조 운전·입력·깜빡이·이번 관찰을 초기화한다. 이전 이력과 원래 영업은 유지한다. 출발점에서 잠깐 멈춘 것은 줄 끝 대기로 설명하지 않으며, 줄 끝 뒤 4~20m 내 정지 관찰을 사용한다. 연습 대기열 신호 타이머는 차량이 줄 끝 22m 이내로 접근한 뒤 진행하고, 연습 구역은 자동 종료하지 않는다.

## 기록 없는 출구 연습 선택 (2026-10-17)

영업 준비·Esc 일시정지·연습 중 F6의 공통 선택 화면에 출구 정체를 추가한다. 영업 사건이 없어도 준비된 은계 대기열 구간을 별도 연습 창에서 시작한다. 원래 영업의 현금·연료·시간·기록은 유지한다. 같은 창의 출구↔우회전 전환과 같은 조건 재시도를 지원한다. 출구 경로는 연습 창 시작 때 준비해 전환 후에도 같은 구간을 사용한다.
