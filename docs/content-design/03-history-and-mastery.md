# 운전 히스토리와 숙련 진행 기획서

작성일: 2026년 10월 15일 · 버전: 0.3 · 상태: 출구 정체 히스토리 예시 연결안

## 기획 의도

운전 히스토리는 자신의 선택을 돌아보고 다음 운행에서 바꿔볼 행동을 찾는 기록이다. 위반 횟수만 쌓는 장부가 아니라 잘한 판단, 반복되는 어려움, 이전보다 나아진 행동을 함께 보여준다. 숙련은 차량 능력치가 올라가는 효과보다 플레이어가 상황을 더 빨리 읽고 스스로 대응하게 되는 변화로 표현한다.

법규 준수가 타인에게 준 영향을 되짚는 과정도 포함한다. ‘벌점을 피했다’와 함께 ‘보행자의 통행을 보장했다’, ‘위험을 예상해 급정지를 피했다’는 결과를 확인하게 한다.

## 기록의 구성

| 기록 단위 | 보여줄 내용 | 이용 목적 |
|---|---|---|
| 한 상황 | 당시 조건, 내 행동, 판정 이유, 도움 사용 여부 | 구체적인 선택을 이해 |
| 한 운송 | 법규 기록과 별도의 승객 매너 결과, 요구와 처리 | 두 시스템의 결과를 구분해 돌아봄 |
| 하루 | 경험한 상황군, 반복 항목, 개선 사례, 운행 요약 | 다음 날의 연습 목표 선택 |
| 누적 숙련 | 상황군별 경험과 독립 대응, 최근 변화 | 강점과 아직 경험하지 못한 영역 확인 |

장면에는 신호·보행자·도로 조건, 행동 순서와 결과를 연결해 보여준다. 초기 표현은 간단한 도로 도식과 행동 타임라인으로도 충분하다. 실제 주행 영상을 재생하는 기능은 별도의 확장 후보이며 초기 필수 조건으로 두지 않는다.

## 이용 흐름

운송 완료 → 대표 장면과 평가 확인 → 상세 기록을 열거나 다음 운송 선택 → 하루 종료 시 변화 요약 → 연습할 상황 선택 → 복습 또는 다음 날 실제 운행에서 적용.

운송마다 긴 설명을 강제하지 않는다. 주행 중에는 기록이 남았다는 짧은 표시만 제공하며, 정차 또는 운행 종료 후 볼 수 있게 한다. 하루 결산에서는 가장 의미 있는 개선 사례와 반복해서 놓친 항목을 우선 제시하고 전체 기록은 필요할 때 펼친다.

## 기록 카드 예시

| 항목 | 예시 |
|---|---|
| 상황 | 보행자가 횡단하려는 횡단보도에 접근 |
| 관찰 조건 | 보행자와 정지선이 접근 구간에서 보였음 |
| 내 행동 | 늦은 감속 후 정지선 앞에서 정지 |
| 판정 | 보호 의무 준수. 접근 중 사전 감속은 개선 여지 |
| 결과 | 보행자가 통과했고 충돌은 없었음 |
| 다음 연습 | 같은 유형에서 더 일찍 속도를 줄여 보기 |
| 선택 | 상황 설명 보기 / 같은 조건 복습 / 다른 배치 연습 |

‘늦게 봤다’는 해석을 화면 방향만으로 단정하지 않는다. 게임이 관찰할 수 있는 차량 행동을 근거로 설명하고, 원인을 확정할 수 없으면 ‘더 일찍 감속할 여지가 있었습니다’처럼 범위를 좁힌다.

## 출구 정체 기록을 읽는 예시

[출구 정체 플레이와 기록 카드](01-driving-situations.md)에서 대기·우회·앞부분 진입의 상황 진행, 각각의 기록 카드, 5회 누적 예시를 확인할 수 있다.

기록은 ‘한 장면의 선택’과 ‘그 안의 규칙별 판단’을 구분한다. 앞부분 진입 한 번에 끼어들기와 진로 변경 문제가 함께 기록되더라도 사건 수를 두 배로 만들지 않는다. 우회하여 차로 변경을 하지 않았다면 그 규칙은 평가 기회 없음으로 남긴다. 경로 선택 통계와 법규 준수율은 서로 다른 분모를 사용한다.

장면 요약은 ‘재촉이 있던 상황에서 앞부분 진입이 발생함’, 최근 변화는 ‘최근 유사 상황에서는 뒤에 합류함’으로 표현한다. 압박이 행동의 원인이라고 단정하거나 한 번의 실수로 성격을 확정하지 않는다. 복습 결과는 원래 기록 옆에 학습 이력으로 연결하며 실제 영업 성향을 덮어쓰지 않는다.

## 법규 성향과 숙련의 구분

성향은 어떤 조건에서 어떤 행동을 반복하는지, 숙련은 해당 상황을 이해하고 독립적으로 대응하는지를 보여준다. 우회를 선호하는 운전자와 대기를 선호하는 운전자 모두 관련 법규를 준수하고 숙련될 수 있다. 성향을 하나의 선악 등급으로 정렬하지 않는다.

유사한 도로 조건에서 시간 압박과 승객 유무에 따른 준수 기록을 비교한다. 사례 수와 도움 사용 여부를 함께 보여주며, 원인이 불분명하면 행동 사실만 설명한다. 복습 기록은 학습 변화에 사용하고 실제 영업 성향 기록을 덮어쓰지 않는다. 주행 중 자동 행동은 독립 판단과 구분한다.

## 숙련 단계 제안

| 단계 | 플레이어 경험 | 확인할 변화 |
|---|---|---|
| 알아보기 | 안내와 함께 단서 및 규칙을 이해 | 무엇을 확인해야 하는지 설명 가능 |
| 적용하기 | 같은 유형에서 일부 안내를 줄여 운행 | 스스로 적절한 행동 선택 |
| 변형에 대응하기 | 배치·교통·승객 조건이 달라진 상황 경험 | 외운 위치가 달라도 원칙을 적용 |
| 습관으로 유지하기 | 여러 운송에서 안정적으로 대응 | 단발 성공을 넘어 최근 기록에서 일관성 확인 |

단계는 상황군별로 관리하는 안이다. 신호에 익숙하더라도 합류나 승하차 판단까지 숙련된 것으로 보지 않는다. 경험하지 않은 항목은 미경험으로 남기며 낮은 실력으로 평가하지 않는다. 인정에 필요한 횟수와 기간은 후속 조정 항목이다.

숙련 인정은 정답 행동을 수동 입력했는지만 보지 않고 어떤 도움을 받았는지도 함께 표시한다. 조향 보조 사용 자체를 불이익으로 삼지 않는다. 다만 자동 정지 등 판단까지 대신한 기능이 작동했다면 해당 장면을 독립 판단의 증거로 사용하지 않는다.

## 복습과 재도전

복습은 선택한 장면의 의미를 이해하는 활동이다. 당시 조건을 도식으로 확인하고, 같은 조건에서 행동을 바꾸거나 조건 하나가 다른 장면을 운전한다. 안내를 켜고 익힌 뒤 줄일 수 있다.

복습 도중에는 실제 하루의 예약과 영업 시간이 진행되지 않고 연료·수입·단골 신뢰도 변하지 않는 안을 둔다. 연습 성공은 학습 기록에 남기되 실제 운행 기록을 덮어쓰지 않는다. 같은 장면을 반복해 수익이나 신뢰를 얻는 구조도 두지 않는다.

재도전에서 잘한 행동은 최근 개선 사례로 보여준다. 이전 위반을 지우지는 않지만 과거 실수를 영구적인 낙인으로 강조하지 않는다. 최근 추세와 누적 이력을 함께 확인할 수 있게 한다.

## 반복 플레이의 동기

플레이어는 매일 한 가지 자율 연습 목표를 선택할 수 있다. 예를 들어 ‘회전 지점을 놓쳐도 무리하게 차로를 바꾸지 않기’처럼 행동으로 표현한다. 해당 상황을 만나지 않았다면 실패가 아니라 평가 기회 없음으로 종료한다.

새로운 도전은 새로운 판단 조건을 제공한다. 더 빠른 차량이나 법규 위반 허용을 보상으로 주지 않는다. 상황 경험의 폭, 안내 없이 대응한 사례, 안정적인 운행과 승객 신뢰가 진행의 의미가 된다. 배지나 별도 도전 코스 개방은 표현 후보이며 핵심 운행에 과도한 진입 장벽을 만들지 않는다.

## 다른 콘텐츠와의 연결

[상황](01-driving-situations.md)과 [평가](02-driving-evaluation.md)가 기록의 근거다. [승객·예약](04-passengers-and-reservations.md)은 실제 영업에서 비슷한 상황을 다시 경험할 기회를 제공한다. [하루 결산](05-daily-operation.md)은 재무 요약과 별도로 오늘의 운전 변화를 소개한다. 개인 예약의 발생을 특정 복습 점수에 직접 연결하지 않는다.

## 결정 사항과 검토 기준

기록 보관 범위, 요약 장면 수, 숙련 인정 횟수, 도식과 실제 재생의 표현 범위는 후속 결정이다. 초기에는 전체 기록보다 상황별 이유와 최근 개선 사례를 이해하기 쉽게 제공하는 데 집중한다.

플레이테스트에서는 기록을 읽은 사용자가 다음에 바꿀 행동을 말할 수 있는지, 다른 배치에서도 그 행동을 적용하는지, 잘한 운전을 스스로 설명하는지 확인한다. 게임 밖 운전 습관이나 사회적 인식 개선은 별도 조사 없이는 성과로 주장하지 않는다.
