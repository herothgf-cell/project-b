# 승객·운송·요청·운임

## 호출에서 하차까지

| 단계 | 플레이어 행동 | 결과 | 예외 |
|---|---|---|---|
| 호출 탐색 | 출발·도착·예상 운임과 경로 확인 | 선택만으로 배차하지 않음 | 탑승 후 요청을 호출 목록에 미리 공개하지 않음 |
| 수락 | 별도 수락 확정 | 승차 목표·픽업 기한 부여 | 픽업 기한은 max(150, 실제 접근거리m/3+150)초 |
| 길가 승차 | 실제 대기자에게 접근해 정차·F | 호출 목록 없이 승차 시도 | 보이지 않는 손님을 태울 수 없음 |
| 픽업 | 올바른 차로 방향·연석·저속 정차 후 F | 승차·시작 만족도·요구치·약정 확정 | 청결/졸음/점유/기한 조건 충족 필요 |
| 운송 | 목적지 안내에 따라 운전·요청 대응 | 실제 주행·응대·시간을 경험 | 중간 경유 정차와 최종 하차 구분 |
| 하차 | 지정 지점 방향·저속 정차 후 F | 만족도·운임 결과 확정 | 동일 운송 한 번 정산 |
| 운송 기한 초과 | 목적지까지 계속 운송 | 하차 뒤 기본 운임·보너스0원 | 비용은 유지, 도중 승객을 없애지 않음 |

승하차 장소는 기존12곳과 게임용 정차공간12곳, 총24후보다. 가용 호출은 일반2개와 대표 코스1개를 섞어 제공한다. 모든 장소에 항상 손님이 있지는 않으며, 보이는 대기자는 갱신 중 갑자기 눈앞에 생기거나 사라지지 않게 한다. 사용한 빈 하차지는90초간 신규 대기·호출을 쉬고, 이미 있던 대기자는 유지한다.

## 승하차 공간이 막혔을 때

| 조건·선택 | 결과 | 시간·평가 영향 |
|---|---|---|
| 일반 게임용 정차공간 일시 점유 | 임시 정차 차량이 원래 공간을 사용 | 눈앞 갑작스러운 출현·차량/승객 겹침 방지 |
| 현재 목표가 점유됨 | 원래 위치를 유지하고 안전하게 대기 | 같은 호출/운송 유지, 점유를 이유로 임의 취소하지 않음 |
| 대기 해소 | 30초 뒤 앞이 비면 차량이1.5m/s로7m 이동 | 앞이 막히면 더 기다림, 정확히30초 해소 보장 아님 |
| 강제 지연 보호 | 잔여 대기+이동 예상+10초, 최대90초를 사건당 한 번 기한 보정 | 탑승 중 시스템 강제 대기는 ETA/경로 요청 미이행으로 감점하지 않음 |
| 다른 장소 선택 | 현재 제공하지 않음 | 검증되지 않은 인도·반대 차로로 손님을 옮기지 않음 |

영업시간·연료는 계속 소모되며 추가 운임 할증은 없다. 대기 버튼 반복이나 이어하기로 보호 시간을 중복 적립하지 않는다. 고정 코스·생활시설은 이 일반 정차공간 점유와 구분한다.

## 승객의 시간 난도

| 성향 | 탑승 후 기한 | 의도 |
|---|---|---|
| 여유 | ceil(max(90, 안전 ETA×1.75+상황 대기+45))초 | 안정 운전·응대 여유 |
| 보통 | ceil(max(90, 안전 ETA×1.45+상황 대기+45))초 | 표준적인 영업 판단 |
| 급함 | ceil(max(90, 안전 ETA×1.20+상황 대기+45))초 | 같은 길에서도 시간 관리 필요 |

난도·요청은 같은 손님을 다시 수락하거나 이어하기했다고 바뀌지 않는다. 신호를 무시해야만 달성하는 조건을 의도하지 않는다. 목적지·경유 변경 때는 같은 난도를 유지하고 필요한 추가 시간/약정을 먼저 알린다.

## 요청의 발생과 선택

| 조건 | 처리 | 플레이 영향 |
|---|---|---|
| 한 운송 | 요청0/1/2건을20/60/20% 비중으로 배정 | 요청 없는 조용한 운송도 존재 |
| 등장 시점 | 승차 또는 운행 중 안전 정차 | 주행 중 응답 강요 없음, 한 번에 대화 하나 |
| 운행 중 요청 | 진행률25~65%의 시점 이후, 실제 주행20초 이상과 별개 안전 정차 기회 | 급정지·정차 반복으로 요청을 다시 뽑지 않음 |
| 하차 접근 | 진행률85% 또는 유효 도착 이후 새 요청 종료 | 제시할 기회 없던 요청은 미발생 중립 |
| 충돌하는 약속 | 큰길/짧은 길·추천·목적지·경유·안전 하차 등 경로형은 최대1개 | 서로 양립할 수 없는 지시를 동시에 주지 않음 |
| 안전상 보류·정당한 거절·후보 없음 | 중립 | 대답 버튼만으로 운전 점수 가감 없음 |

실제 속도0.1m/s 이하가2초 유지되고 교차로 충돌 영역·횡단보도·회전 중이 아닌 곳에서 응답한다. 정지선 앞 정상 신호 대기는 가능하되 출발하면 입력을 보류하고 다음 안전 정차 때 이어간다. 요청 응답은 영업 시계를 멈추는 수단이 아니다.

## 요청17종의 행동과 결과

요청 결과는 승객 만족도의 요청 변화에 반영한다. 운전 방식 요청은 달성 +8/미달 -10, 대화·편의는 +5/-5, 목적지/경유는 +6/-8이 기본이며 관찰 불가·정당한 보류는0이다. 복수 요청의 합계는 -10~+10이다.

| 요청 | 선택·행동 | 결과·영향 | 예외 |
|---|---|---|---|
| 조용한 운행 | 조용한 응대/보류 | 이행 +5, 불필요한 후속 수다 억제 | 안전한 응답 기회를 무시하면 M -5만 반영, 요청에서 중복 감점 없음 |
| 도착 시간 문의 | 조금 빠르게/내비대로/여유 예상 | 안내와 실제 도착 비교 설명, 요청 변화0 | 기한·차량 성능 변경 없음 |
| DR01 차멀미 | 부드러운 운전 약속·실제 승차감 유지 | 수락 뒤 급가감속 강화 평가, 하차 때 전체 목표 평가 | 개별 주행 배점은 [주행 평가](01-driving-and-traffic.md#행동별-평가), 필요한 제동 제외 |
| DR02 정시 도착 | 법규를 지키며 기한 내 운송 | 기한·실제 위반 관찰 | 재촉으로 약정 기한을 줄이지 않음 |
| DR03 큰길 | 큰길 우선 경로 이행 | 실제 큰길 비율, 안내 대비15%p 여유 | 합법 우회/관찰 부족은 중립 |
| DR04 짧은 길 | 합법 짧은 경로 이행 | 안내거리의125%+30m 참고 비교 | 필요한 우회를 단순 실패로 감점하지 않음 |
| DR05 안전 하차 | 제안된 안전 목적지 확인·변경 | 실제 지정 장소 하차 | 후보 없으면 원래 목적지 유지 |
| CH01 고민 이야기 | 공감/조용한 배려 | 선택에 맞는 응대 | 조용히 배려해도 정상 응대 |
| CH02 길 추천 | 빠른 길/짧은 길 | 경로 적용·실제 결과 설명 | 교통·안전 사유가 불명확하면 중립 |
| CH03 면접 응원 | 격려/조용한 준비 배려 | 응대 반응 | 실제 면접 결과·합격 보상 없음 |
| CH04 음악 | 가능한 범위 안내 | 텍스트 응대 | 실제 음악 재생/변경 없음 |
| CH05 요금 부족 | 약정 안내/하차 때 결제 확인 | 요금 규칙 설명 | 대화만으로 할인·추가 부채 생성 없음 |
| CH06 지역 대화 | 지역 응답/안전 운행 안내 | 짧은 대화 | 검증되지 않은 지역 사실 보장 없음 |
| EV01 목적지 변경 | 새 목적지·운임·기한 확인 후 변경 | 같은 운송의 최종 목적지 변경 | 다른 운송을 중복 생성하지 않음 |
| EV02 중간 경유 | 안전 경유 확인·F 정차·원래 목적지 복귀 | 같은 운송의 경유 목표 | 경유 중에도 시간 흐름 |
| EV03 분실물 | 하차 뒤 보관/신고·전달 절차 안내 | 텍스트 후속 사건, 요청 변화0 | 운행 중 요청 수에 미포함, 원래 운임 소급 변경/반환 퀘스트 없음 |
| EV04 불법 요구 | 안전 거절/정차 후 설명 | 중립, 요청 변화0 | 불법 수락 선택 없음, 실제 위반은 별도 관찰 |

ETA 안내는 현재 예상시간 ±min(30초, ETA의10%) 또는 그대로다. 실제 도착과15초 이내 차이는 예상 범위로 설명하며 ETA 오차만으로 감점하지 않는다. CH01/03/06은 안전한 응답 기회가 있었는데 계속 무시하면 -5가 될 수 있다.

## 시작·최종 만족도

| 값 | 역할·규칙 | 운임과의 연결 |
|---|---|---|
| 요구 R | 승객이 바라는60/70/85점 기준 | 충족하면 약정 전액·보너스 조건 |
| 시작 S0 | clamp(R−기대차+청결 가산,0,100), 기대차 -12/-8/-4/0/4/8/12 중 승객별 결정 | 요구치보다 낮거나 같거나 높게 시작 가능 |
| 주행 변화 | M−100 | [주행 평가](01-driving-and-traffic.md)의 실제 사건·회복 반영 |
| 요청 변화 | 요청별 확정 결과 합계 | 같은 행동을 M/다른 요청에서 중복 감점하지 않음 |
| 안심 회복 | 안정 주행 기회에서 별도 판정 | [회복 규칙](01-driving-and-traffic.md#안정-주행-회복) 참조 |
| 도착 가산 | 안전한 조기 도착0~12점 | 첫 유효 도착에 확정, 위험 운전이면0 |
| 최종 S | clamp(S0+주행+요청+안심+도착,0,100) | 늦음 자체로 S를 추가 차감하지 않되 기한 초과 운임은 별도 |

청결 가산과 승차 거부는 [차량 청결](03-life-and-economy.md#청결과-세차)에서 정의한다. 청결 가산은 S0에 한 번만 포함한다.

## 운임과 보너스

F는 목적지·경유 변경을 반영한 최종 원약정, A는 승차 시 운전 점수로 보정한 약정이다. 모든 floor10은10원 단위 내림이다.

| 조건 | 기본 지급 | 보너스·예외 |
|---|---|---|
| 운전 점수0~70 | 보정률0.9+0.1×점수/70 | 점수는 승차 때 고정 |
| 운전 점수70~100 | 보정률1+0.1×(점수−70)/30 | A=floor10(F×보정률) |
| 기한 내 S≥R | A 전액 | 아래 만족도 보너스 지급 |
| 기한 내 0<S<R | floor10(min(F,A)×S/R) | 보너스0, 만족도 미달에 양의 운임 할증 미적용 |
| S=0 또는 도착 기한 초과 | 0원 | 기본 운임·보너스 모두0 |
| 승차 전 취소·거부 | 지급 없음 | 완료 운송처럼 계산하지 않음 |

보너스 상한 C=floor10(min(F×10%,500원)×가중치), R=60/70/85의 가중치는0.8/1.0/1.3이다. 보너스는 floor10(C×[0.2+0.8×(S−R)/(100−R)])이다. 예를 들어 F=5,000원·R=70에서 S=70/85/100이면 보너스100/300/500원이다. 대화 버튼의 선택이나 요청 종류만으로 이 공통 보너스를 막거나 보장하지 않는다.

## 현재 구현: 취객 유형의 특성과 하차

| 조건·행동 | 결과 | 플레이 영향·보호 |
|---|---|---|
| 취객 배정 | 아래 공통 등장 빈도 표 적용 | 구형 저장의 진행 중 운송은 기존 배정 유지. 취소/거부로 새 배정의 하루 한도를 소모하지 않음 |
| 평소 대사 | 운송 중12~20초 간격의 짧은 수다 | 조용한 약속 뒤 억제, 중요한 경고 우선 |
| 구토 예정 | 취객 중25%, 진행30~70%에서 경고 | 최소3초 뒤 실제 구토, 직전 도착이면 강제 발생 안 함 |
| 실제 구토 | 현재 승객 운송 유지, 신규 호출 잠금 | 청결 수치 급락은 실제 하차 뒤, 별도 사고비/M 감점 없음 |
| 첫 유효 도착 | 도착 시각·예정 지급 확정 | 이후 깨우는 시간을 소급 지각으로 보지 않음 |
| 기상 지연 | 취객 중30%, 구토와 독립 | 15초 후 F로 다시 깨우기,30초면 안전 정차 중 자동 하차 |

기상 대기 중 영업시간은 흐르고 새 승객·시설 이용은 불가하다. 졸음 위험에 따른 중도 취소는 [운전자 상태](03-life-and-economy.md#피로100과-졸음) 규칙을 우선한다.

## 승객 유형과 상호작용: 소스 구현

2026-10-29 일반 승객과11개 특수 유형의 구현을 반영했다. 준비 작업·음식 섭취/흘림·저장과 응대 흐름을 포함한다. BuildHybrid·Player 기능/새 프로세스 복원 검증을 통과했으며 화면·배포의 완료 증거와 남은 검증은 [작업 이력](../work-history/2026-10-29-passenger-types-implementation.md)에서 확인한다. 아래 수치는 체감 검증 전 시험값이다. 구형 저장의 진행 중 운송은 기존 유형·요청·취객 동작을 유지하며 새 유형으로 재추첨하지 않는다.

### 유형·요청·사건의 구분

| 구분 | 의미 | 예시·관계 |
|---|---|---|

취객은 ‘진상’의 하위 분류로 고정하지 않는다. 취한 손님도 협조적일 수 있고, 재촉·간섭은 별도 유형이다. Proto 첫 확장에서는 유형 조합을 하지 않아 취객+차멀미+재촉의 고유 사건·후속 대화가 한 손님에게 겹치지 않게 한다. 기존 DR01/DR02 같은 요청 자체는 취객에게도 호환 조건 내에서 가능하지만, 다른 유형의 전용 사건을 함께 활성화하지 않는다. 일반 승객은 유형 사건 없이 기존 요청만 이용한다.

### 같은 유형 안의 대화·행동 변주

**유형1개가 고정 대본1개를 뜻하지 않는다.** 같은 운행 영향이라도 소개 방식·발생 시점·이전 답변·실제 운전·하차 반응이 달라진다. 각 유형은 기본 흐름과 변주를 두되, 문장만 무작위로 바꿔 앞뒤가 모순되지 않게 한다. 운송마다 주 유형1개와 기본 변주1개를 고정하고, 그 안에서 실제 사건/응답에 따라 분기한다. 변주와 현재 단계도 저장한다. 모든 변주를 한 운송에서 차례로 재생하지 않는다.

유형의 **공통 확인 / 집중 안내**는 실제 버튼 “짧게 확인하고 설명” / “운전에 집중하며 조용히 안내”다. DR·CH·EV 대표 요청의 수락·거절은 별도 기존 선택창에서 처리하며 유형 버튼만으로 약정하지 않는다. 보통 유형은 첫 선택1회, 얕은 잠만 조건부 추가 선택1회를 제공한다. 대표 요청이 없는 유형의 공통 하차 반응은 확인한 변주를 기억한 감사 / 조용한 배려에 감사 / 미응답이면 안전 도착 인사다. 대표 요청 유형은 아래 요청 상태·결과 반응을 사용한다.

승차감·재촉·경로 확인·경유·정밀 하차는 대표 요청의 미제시/답변 대기/수락/안전 보류/성공/중립/미달 상태와 실제 답변 문구를 저장한다. 수락 뒤 후속은 실제 답변 확인에 아래 변주 반응을 덧붙인다. 미제시·답변 대기에는 약속하지 않았음을, 보류에는 원래 운행 유지를 알리며 합의를 꾸며내지 않는다. 하차 때는 실제 요청 평가에 따라 이행 감사/미달 확인/중립 확인/보류 유지로 반응한다. 아래 표의 “요청 결과 반응”은 이 공통 처리를 뜻하고 추가 점수를 만들지 않는다.

후속 유형 대사는 저장한 응답·이동시간·진행과 현재 주행 점수 M을 사용한다. 승차감 및 흔들리는 짐의 안심/불편 분기는 M≥90 기준이며 개별 코너·신호·분기점 이벤트를 별도 검출하지 않는다. 실제 운전·경로 이행은 기존 대표 요청 관찰·평가가 담당한다. 얕은 잠 질문은 한 번만 가능하며 수면 전환과 후속은 진행85% 이전에만 발생한다.

### 구현 범위 선택 이유

### 상태 영향형의 공통 사건 정책

| 유형 | 발동·사전 선택 | 결과·회복 | 수치·중복 규칙 |

실제 작업 대기는 안전 정차에서만 경과하며 이동하면 보류한다. 게임 일시정지 중에는 경과하지 않는다. 준비 작업은 한 운송에서1종만 허용하며 짐/음식/용무 대기를 중첩하지 않는다. 음식 사건은 구토가 아니므로 그 자체로 구토 전용 호출 잠금을 설정하지 않는다. 청결 기준에 따른 세차 필요 여부는 기존 정책을 따른다. 변주·흘림 판정은 후보 시드로 고정하고 새 운송의 오염 사건 식별자는 실제 운송 ID에 연결한다. 같은 후보로 다른 운송을 하더라도 정당한 새 오염은 적용하고 같은 운송의 재개는 중복 적용하지 않는다. 선택·흘림 판정·작업 잔여시간·사건 적용 여부를 저장해 재개·취소·날짜 변경으로 다시 추첨하거나 중복 차감하지 않는다. 차량 내구도는 충돌 규칙으로만 감소한다. 승객이 불만을 말하거나 짐을 실었다는 이유로 내구도·운전자 피로를 직접 깎지 않는다. 경과시간의 일반 피로/연료 영향은 기존 경제 규칙을 따른다.

### 유형과 기존 요청의 배정 연결

| 조건 | 처리 |
|---|---|
| 대표 요청이 필요한 유형 | 승차감 민감→DR01, 재촉→ETA 또는 DR02, 경로 확인→기존 경로 요청1개, 용무/경유→EV02, 정밀 승하차→DR05(SafeStop). 기존0~2개 요청 슬롯 중1개를 그 요청으로 배정 |
| 대화·상태 중심 유형 | 대화·반복 질문은 대표 CH 요청을 강제 배정하지 않고 점수 없는 유형 대사를 진행하며 호환 기존 요청은 별도로 유지. 취객·수면·짐·오염 짐의 상태 사건은 요청 점수와 별도다. 음식 허용 응대 +5는 요청·응대 만족도 합계에 포함하며 유형 선택창도 공통 대화 예산에 포함 |
| 요청0개 추첨 | 대표 요청이 필요한 유형은 배정 대상에서 제외. 취객·일반 또는 별도 약정 없는 후보만 가능 |
| 경유/경로 후보 없음 | 해당 유형은 제외하고 같은 시드로 가용 유형에 재배정. 부적합 요청을 강제로 만들지 않음 |
| 두 번째 요청 | 유형/첫 요청과 호환되는 것만 허용. 경로 변경 최대1개·공통 대화 예산 유지 |
| 요청 등장 시점 | 승차 또는 안전 중간 정차의 기존 규칙 유지. 아직 제시하지 않은 요청의 불이행을 성향 대사로 감점하지 않음 |
| 적재 등 승차 전 선택 | 기존 요청과 합산해 공통 선택창 예산 안에서 처리. 안전 거절하면 유형 사건 없이 기존 운송 유지, 새 운임 페널티 없음 |
| 평가 | 대표 요청 결과는 기존 평가1회. 유형 후속 반응에는 추가 점수 없음. 미발생·안전 거절·관찰 부족은 중립 |

확률 배정은 요청 수→가용 유형→호환 요청 종류/시점 순으로 함께 확정한다. 진행 중 기존 저장 승객은 기존 유형·요청을 유지한다. 새 타입을 늘려도 취객이 다시 희귀해지지 않도록 아래 취객 기회 보완과 별도 유형 가중치를 구분한다.

### 공통 등장 빈도

새 배정은 아래 규칙을 사용한다. 구형 저장의 진행 중 운송은 기존 배정을 유지한다. 등장 빈도와 구토 빈도를 함께 높이지 않는다.

| 항목 | 시험 규칙 | 예외·목적 |
|---|---|---|
| 기본 취객 빈도 | 배정 가능한 운송의30% | 시간·지역 제한 없이 짧은 Proto에서도 체험 |
| 미등장 보완 | 연속 비취객3명 실제 탑승 후 다음 배정 가능 승차는 취객 | 동일 후보·호출 갱신·재수락으로 다시 뽑지 않음 |
| 하루 한도 | 실제 취객 탑승 최대2명 | 기존1명보다 체험 기회 확대, 한도 이후 보완 예약은 다음 날로 유지 |
| 부담 분산 | 모든 특수 유형 뒤 일반 승객1명 확보 | 취객 보완이 대기 중이어도 이 휴식 구간 우선 |
| 짧게 끝낸 영업 | 실제 승차가 적으면 미등장 가능 | 매일 무조건1명 보장으로 표시하지 않음 |
| 상태 확정 | 승차 자격 확인 후 승차 준비 진입 때 영업의 다음 승차 순번에 유형 예약, 같은 순번에는 같은 결과 | 준비 전 유형 비공개. 취소/거부 후 예약 유지, 실제 탑승 완료 때만 순번·보완·한도 소모 |
| 저장 | 성향 예약·연속 미등장·휴식 구간·하루 한도와 확정된 승객을 함께 보존 | 실제 취객 탑승 때 미등장 카운터 초기화, 날짜 변경은 하루 한도만 초기화 |
| 돌발 사건 | 구토·기상 지연 확률과 세차 규칙은 기존 유지 | 빈도 변경으로 비용이 늘어나는지는 따로 검증 |

취객은 공통 승객 유형 중 하나다. 위 등장 시험안의 취객 미선정 시 다른 특수 유형을 배정하는 전체 확률30%를 적용하되, 예전 비취객3종 균등 배정안은 대체한다. 비취객 특수 유형 추첨에 당첨되면 그 운송의 가용 유형에서 균등 선택한다. 휴식 구간에는 모든 특수 유형을 제외하고 일반 승객의 기존 요청은 유지한다. 취객 보완은 다른 유형을 만났더라도 비취객 탑승으로 계산한다. 한도·보완·휴식 때문에 시험 확률이 실제 전체 탑승 비율과 같지는 않다.

### 공통 대화 흐름과 평가

| 단계·조건 | 동작 | 중복·안전 보호 |
|---|---|---|
| 승차 | 주 유형 소개, 기존 요청이 있으면 그 내용에 연결 | 위 유형/요청 호환 배정 사용. 제시·수락 전 목적지/기한 변경 금지 |
| 선택 응답 | 일반 유형은 공통 확인 / 집중 안내2개, 짐·음식은 작업에 맞는2~3개 | 기존 안전 정차 조건에서만 입력, 움직이면 보류. 일반 대사에는 버튼을 매번 붙이지 않음 |
| 다음 반응 | 이전 답변+관찰된 사건으로 분기 | 같은 대사 랜덤 반복만으로 상호작용 완료 표시 금지 |
| 후속 질문 | 기존 요청과 합쳐 운송당 선택창 최대3회, 성향 자체는 최대2회 | 일반 유형 후속은 이동30초 뒤 선택 없는 반응이다. 얕은 잠의 위치 질문만 별도 후속 선택이며 기존 요청2개가 배정되면 억제한다. 준비 선택과 첫 승차 요청은 순차 제시 가능하나 공통 횟수에 포함. 경로 약정 변경은 최대1개 |
| 우선순위 | 구토/운행 불가 경고 → 기존 요청 → 성향 후속 → 일반 수다 | 선택창은1개, 새 경고가 답변을 덮거나 자동 선택하지 않음 |
| 일반 대사 | 기존 취객 잡담은12~20초 간격. 유형 소개는 경과8초 구간, 후속은 실제 이동 누적30~38초 구간, 의미 있는 상태 변경 안내는6초 | 선택창·작업 표시는 별도 유지. 조용한 약속·집중 안내 후 일반 대사 억제. 새 질문은85% 진행 또는 유효 도착 이후 종료 |
| 짧은 운송·기회 없음 | 후속 대사 없이 도착 반응으로 마무리 | 미응답/미발생 중립, 새 질문을 위해 정차·지각을 강제하지 않음 |
| 평가 | 성향별 독립 호감도 게이지/추가 요금 없음 | 기존 요청에 연결한 결과만 기존 요청 합계 -10~+10 안에서1회 반영. 성향 대화만의 보상·감점은0 |
| 실제 위험 운전 | 기존 주행 평가와 요청 관찰 사용 | 같은 충돌·급제동을 성향 불만으로 다시 차감하지 않음 |
| 기억·재개 | 마지막 응답·대사 단계·대기 질문·경계 설정·평가 완료를 보존 | 재시작으로 질문/보상 재발생 금지, 이미 확정된 운임 불변 |

유형의 집중 안내 선택은 후속 일반 대사를 억제한다. 대표 요청은 별도 응답·실제 관찰로 평가하고 하차 결과는 기존 S/R·운임 산식을 사용한다.

## 대화 선택의 실제 효과 표시

선택지에는 행동과 게임 상태 효과를 나누어 표시한다. 확정 보상·하차 판정·확률 사건을 구분하고 ‘추가 오염 없음’ 대신 ‘추가 청결도 감소0’처럼 상태와 수치를 명시한다. 모든 만족도는0~100 범위다. 청결도 차감도0에서 멈추며 아래 음식/짐 차감은 일반 하차 청결도-2와 별도다.

| 선택 | 만족도 효과 | 차량·시간·운행 효과 | 적용 시점 |
|---|---|---|---|
| 간식/음료/도시락 섭취 허용 | +5 | 실제 섭취 청결도-2,25% 확률 흘림 발생 시 추가-6 | 허용 즉시 만족도, 청결은 실제 사건 때 각1회 |
| 밀봉 보관 | 변화0 | 추가 청결도 감소0 | 확정 선택 기억 |
| 정차 중 음식 정리 | 변화0 | 안전 작업10초, 추가 청결도 감소0 | 안전 정차에서만 작업 진행 |
| 짐 적재 허용 / 보류 | 변화0 | 적재10초+하역10초 / 작업0초 | 실제 작업 구간 |
| 오염 짐 보호 / 그대로 / 보류 | 변화0 | 준비10초·추가 청결 감소0 / 실제 하차 추가-5 / 추가 청결 감소0 | 실제 작업·하차 |
| 수면·취객·일반 유형 대화 | 대화 자체 변화0 | 응답 기억·수다 줄임·수면 후속 질문. 구토 경고·기존 운행 요청은 유지 | 선택·후속 사건 |
| 조용한 운행 요청 | 이행+5 | 일반 후속 대화 줄임 | 하차 요청 판정 |
| 승차감 / 약속 시간 | 이행+8, 미이행-10 | 기존 급가감속·위반·기한 관찰. 필요한 제동 제외, 합법 지연은 중립 | 하차 판정, 주행 감점은 기존 규칙 |
| 큰길 / 짧은 길 | 이행+8, 합법 우회·판정 불가0 | 해당 경로 적용 | 하차 실제 주행 판정 |
| 안전 하차 지점 변경 | 이행+8 / 미이행-10 | 사전 제시 목적지·약정 운임·기한으로 변경 | 하차 판정 |
| 목적지 변경 / 경유 | 이행+6 / 미이행-8 | 사전 제시 약정 적용·경유 F 정차 | 하차 판정 |
| 공감·경로 조언·면접·음악·운임 설명·지역 대화 | 응대+5, 판정 불가0 | 해당 안내·경로·조용한 배려. 음악은 실제 음원 변경 없음 | 하차 응대 판정 |
| ETA / 분실물 / 불법 요구 거절 | 변화0 | 예상 안내 / 보관·신고 기록 / 신호 준수 안내 | 해당 안내, 위반은 실제 운전 별도 평가 |
| 안전상 보류 선택 | 변화0 | 원래 운행 유지 | 선택 즉시 |

음식 허용 보상은 저장된 유형·탑승·선택으로 계산한다. 반복 입력/재개로 누적하지 않고 이미 도착해 확정한 운임은 변경하지 않는다. 기존 진행 중 허용 저장도 +5로 계산한다. HUD·알림·정산의 요청 만족도 합계에 유형 응대 보상을 함께 반영하며 직접 운전 점수나 현금을 가산하지 않는다. 선택 직후 실제 만족도 전후 값(상한 적용)을 표시한다. 이후 섭취/흘림에는 실제 청결 차감과 별도 반응을 표시하고 오래된 응답 알림을 새 보상처럼 다시 띄우지 않는다.
