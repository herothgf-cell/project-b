# 승객·운송·요청·운임

## 호출에서 하차까지

| 단계 | 플레이어 행동 | 결과 | 예외 |
|---|---|---|---|
| 호출 탐색 | 출발·도착·예상 운임과 경로 확인 | 선택만으로 배차하지 않음 | 탑승 후 요청을 호출 목록에 미리 공개하지 않음 |
| 수락 | 별도 수락 확정 | 승차 목표·픽업 기한 부여 | 픽업 기한은 max(150, 실제 접근거리m/3+150)초 |
| 길가 승차 | 실제 대기자에게 접근해 정차·F | 호출 목록 없이 승차 시도 | 보이지 않는 손님을 태울 수 없음 |
| 픽업 | 올바른 차로 방향·연석·저속 정차 후 F | 승차·시작 만족도·요구치·약정 확정 | 청결/졸음/점유/기한 조건 충족 필요 |
| 운송 | 목적지 안내에 따라 운전·요청 대응 | 실제 주행·응대·시간을 경험 | 중간 경유 정차와 최종 하차 구분 |
| 하차 | 지정 지점 방향·저속 정차 후 F | 만족도·운임 결과 확정 | 동일 운송 한 번 정산 |
| 운송 기한 초과 | 목적지까지 계속 운송 | 하차 뒤 기본 운임·보너스0원 | 비용은 유지, 도중 승객을 없애지 않음 |

승하차 장소는 기존12곳과 게임용 정차공간12곳, 총24후보다. 가용 호출은 일반2개와 대표 코스1개를 섞어 제공한다. 모든 장소에 항상 손님이 있지는 않으며, 보이는 대기자는 갱신 중 갑자기 눈앞에 생기거나 사라지지 않게 한다. 사용한 빈 하차지는90초간 신규 대기·호출을 쉬고, 이미 있던 대기자는 유지한다.

## 승하차 공간이 막혔을 때

| 조건·선택 | 결과 | 시간·평가 영향 |
|---|---|---|
| 일반 게임용 정차공간 일시 점유 | 임시 정차 차량이 원래 공간을 사용 | 눈앞 갑작스러운 출현·차량/승객 겹침 방지 |
| 현재 목표가 점유됨 | 원래 위치를 유지하고 안전하게 대기 | 같은 호출/운송 유지, 점유를 이유로 임의 취소하지 않음 |
| 대기 해소 | 30초 뒤 앞이 비면 차량이1.5m/s로7m 이동 | 앞이 막히면 더 기다림, 정확히30초 해소 보장 아님 |
| 강제 지연 보호 | 잔여 대기+이동 예상+10초, 최대90초를 사건당 한 번 기한 보정 | 탑승 중 시스템 강제 대기는 ETA/경로 요청 미이행으로 감점하지 않음 |
| 다른 장소 선택 | 현재 제공하지 않음 | 검증되지 않은 인도·반대 차로로 손님을 옮기지 않음 |

영업시간·연료는 계속 소모되며 추가 운임 할증은 없다. 대기 버튼 반복이나 이어하기로 보호 시간을 중복 적립하지 않는다. 고정 코스·생활시설은 이 일반 정차공간 점유와 구분한다.

## 승객의 시간 난도

| 성향 | 탑승 후 기한 | 의도 |
|---|---|---|
| 여유 | ceil(max(90, 안전 ETA×1.75+상황 대기+45))초 | 안정 운전·응대 여유 |
| 보통 | ceil(max(90, 안전 ETA×1.45+상황 대기+45))초 | 표준적인 영업 판단 |
| 급함 | ceil(max(90, 안전 ETA×1.20+상황 대기+45))초 | 같은 길에서도 시간 관리 필요 |

난도·요청은 같은 손님을 다시 수락하거나 이어하기했다고 바뀌지 않는다. 신호를 무시해야만 달성하는 조건을 의도하지 않는다. 목적지·경유 변경 때는 같은 난도를 유지하고 필요한 추가 시간/약정을 먼저 알린다.

## 요청의 발생과 선택

| 조건 | 처리 | 플레이 영향 |
|---|---|---|
| 한 운송 | 요청0/1/2건을20/60/20% 비중으로 배정 | 요청 없는 조용한 운송도 존재 |
| 등장 시점 | 승차 또는 운행 중 안전 정차 | 주행 중 응답 강요 없음, 한 번에 대화 하나 |
| 운행 중 요청 | 진행률25~65%의 시점 이후, 실제 주행20초 이상과 별개 안전 정차 기회 | 급정지·정차 반복으로 요청을 다시 뽑지 않음 |
| 하차 접근 | 진행률85% 또는 유효 도착 이후 새 요청 종료 | 제시할 기회 없던 요청은 미발생 중립 |
| 충돌하는 약속 | 큰길/짧은 길·추천·목적지·경유·안전 하차 등 경로형은 최대1개 | 서로 양립할 수 없는 지시를 동시에 주지 않음 |
| 안전상 보류·정당한 거절·후보 없음 | 중립 | 대답 버튼만으로 운전 점수 가감 없음 |

실제 속도0.1m/s 이하가2초 유지되고 교차로 충돌 영역·횡단보도·회전 중이 아닌 곳에서 응답한다. 정지선 앞 정상 신호 대기는 가능하되 출발하면 입력을 보류하고 다음 안전 정차 때 이어간다. 요청 응답은 영업 시계를 멈추는 수단이 아니다.

## 요청17종의 행동과 결과

요청 결과는 승객 만족도의 요청 변화에 반영한다. 운전 방식 요청은 달성 +8/미달 -10, 대화·편의는 +5/-5, 목적지/경유는 +6/-8이 기본이며 관찰 불가·정당한 보류는0이다. 복수 요청의 합계는 -10~+10이다.

| 요청 | 선택·행동 | 결과·영향 | 예외 |
|---|---|---|---|
| 조용한 운행 | 조용한 응대/보류 | 이행 +5, 불필요한 후속 수다 억제 | 안전한 응답 기회를 무시하면 M -5만 반영, 요청에서 중복 감점 없음 |
| 도착 시간 문의 | 조금 빠르게/내비대로/여유 예상 | 안내와 실제 도착 비교 설명, 요청 변화0 | 기한·차량 성능 변경 없음 |
| DR01 차멀미 | 부드러운 운전 약속·실제 승차감 유지 | 수락 뒤 급가감속 강화 평가, 하차 때 전체 목표 평가 | 개별 주행 배점은 [주행 평가](01-driving-and-traffic.md#행동별-평가), 필요한 제동 제외 |
| DR02 정시 도착 | 법규를 지키며 기한 내 운송 | 기한·실제 위반 관찰 | 재촉으로 약정 기한을 줄이지 않음 |
| DR03 큰길 | 큰길 우선 경로 이행 | 실제 큰길 비율, 안내 대비15%p 여유 | 합법 우회/관찰 부족은 중립 |
| DR04 짧은 길 | 합법 짧은 경로 이행 | 안내거리의125%+30m 참고 비교 | 필요한 우회를 단순 실패로 감점하지 않음 |
| DR05 안전 하차 | 제안된 안전 목적지 확인·변경 | 실제 지정 장소 하차 | 후보 없으면 원래 목적지 유지 |
| CH01 고민 이야기 | 공감/조용한 배려 | 선택에 맞는 응대 | 조용히 배려해도 정상 응대 |
| CH02 길 추천 | 빠른 길/짧은 길 | 경로 적용·실제 결과 설명 | 교통·안전 사유가 불명확하면 중립 |
| CH03 면접 응원 | 격려/조용한 준비 배려 | 응대 반응 | 실제 면접 결과·합격 보상 없음 |
| CH04 음악 | 가능한 범위 안내 | 텍스트 응대 | 실제 음악 재생/변경 없음 |
| CH05 요금 부족 | 약정 안내/하차 때 결제 확인 | 요금 규칙 설명 | 대화만으로 할인·추가 부채 생성 없음 |
| CH06 지역 대화 | 지역 응답/안전 운행 안내 | 짧은 대화 | 검증되지 않은 지역 사실 보장 없음 |
| EV01 목적지 변경 | 새 목적지·운임·기한 확인 후 변경 | 같은 운송의 최종 목적지 변경 | 다른 운송을 중복 생성하지 않음 |
| EV02 중간 경유 | 안전 경유 확인·F 정차·원래 목적지 복귀 | 같은 운송의 경유 목표 | 경유 중에도 시간 흐름 |
| EV03 분실물 | 하차 뒤 보관/신고·전달 절차 안내 | 텍스트 후속 사건, 요청 변화0 | 운행 중 요청 수에 미포함, 원래 운임 소급 변경/반환 퀘스트 없음 |
| EV04 불법 요구 | 안전 거절/정차 후 설명 | 중립, 요청 변화0 | 불법 수락 선택 없음, 실제 위반은 별도 관찰 |

ETA 안내는 현재 예상시간 ±min(30초, ETA의10%) 또는 그대로다. 실제 도착과15초 이내 차이는 예상 범위로 설명하며 ETA 오차만으로 감점하지 않는다. CH01/03/06은 안전한 응답 기회가 있었는데 계속 무시하면 -5가 될 수 있다.

## 시작·최종 만족도

| 값 | 역할·규칙 | 운임과의 연결 |
|---|---|---|
| 요구 R | 승객이 바라는60/70/85점 기준 | 충족하면 약정 전액·보너스 조건 |
| 시작 S0 | clamp(R−기대차+청결 가산,0,100), 기대차 -12/-8/-4/0/4/8/12 중 승객별 결정 | 요구치보다 낮거나 같거나 높게 시작 가능 |
| 주행 변화 | M−100 | [주행 평가](01-driving-and-traffic.md)의 실제 사건·회복 반영 |
| 요청 변화 | 요청별 확정 결과 합계 | 같은 행동을 M/다른 요청에서 중복 감점하지 않음 |
| 안심 회복 | 안정 주행 기회에서 별도 판정 | [회복 규칙](01-driving-and-traffic.md#안정-주행-회복) 참조 |
| 도착 가산 | 안전한 조기 도착0~12점 | 첫 유효 도착에 확정, 위험 운전이면0 |
| 최종 S | clamp(S0+주행+요청+안심+도착,0,100) | 늦음 자체로 S를 추가 차감하지 않되 기한 초과 운임은 별도 |

청결 가산과 승차 거부는 [차량 청결](03-life-and-economy.md#청결과-세차)에서 정의한다. 청결 가산은 S0에 한 번만 포함한다.

## 운임과 보너스

F는 목적지·경유 변경을 반영한 최종 원약정, A는 승차 시 운전 점수로 보정한 약정이다. 모든 floor10은10원 단위 내림이다.

| 조건 | 기본 지급 | 보너스·예외 |
|---|---|---|
| 운전 점수0~70 | 보정률0.9+0.1×점수/70 | 점수는 승차 때 고정 |
| 운전 점수70~100 | 보정률1+0.1×(점수−70)/30 | A=floor10(F×보정률) |
| 기한 내 S≥R | A 전액 | 아래 만족도 보너스 지급 |
| 기한 내 0<S<R | floor10(min(F,A)×S/R) | 보너스0, 만족도 미달에 양의 운임 할증 미적용 |
| S=0 또는 도착 기한 초과 | 0원 | 기본 운임·보너스 모두0 |
| 승차 전 취소·거부 | 지급 없음 | 완료 운송처럼 계산하지 않음 |

보너스 상한 C=floor10(min(F×10%,500원)×가중치), R=60/70/85의 가중치는0.8/1.0/1.3이다. 보너스는 floor10(C×[0.2+0.8×(S−R)/(100−R)])이다. 예를 들어 F=5,000원·R=70에서 S=70/85/100이면 보너스100/300/500원이다. 대화 버튼의 선택이나 요청 종류만으로 이 공통 보너스를 막거나 보장하지 않는다.

## 취객 특성과 하차

| 조건·행동 | 결과 | 플레이 영향·보호 |
|---|---|---|
| 취객 배정 | 후보별20%, 하루 실제 탑승 최대1명 | 취소/거부로 하루 한도를 소모하지 않음 |
| 평소 대사 | 운송 중12~20초 간격의 짧은 수다 | 조용한 약속 뒤 억제, 중요한 경고 우선 |
| 구토 예정 | 취객 중25%, 진행30~70%에서 경고 | 최소3초 뒤 실제 구토, 직전 도착이면 강제 발생 안 함 |
| 실제 구토 | 현재 승객 운송 유지, 신규 호출 잠금 | 청결 수치 급락은 실제 하차 뒤, 별도 사고비/M 감점 없음 |
| 첫 유효 도착 | 도착 시각·예정 지급 확정 | 이후 깨우는 시간을 소급 지각으로 보지 않음 |
| 기상 지연 | 취객 중30%, 구토와 독립 | 15초 후 F로 다시 깨우기,30초면 안전 정차 중 자동 하차 |

기상 대기 중 영업시간은 흐르고 새 승객·시설 이용은 불가하다. 졸음 위험에 따른 중도 취소는 [운전자 상태](03-life-and-economy.md#피로100과-졸음) 규칙을 우선한다.

## 추가 기획: 취객 빈도와 지속 응대 승객

2026-10-29 검토안·미구현. 위 현재 규칙과 구분하며 아래 숫자는 체감 검증 전 시험값이다. 목표는 한 번 답하고 끝나는 손님 대신, 답변을 기억하고 실제 운전에 반응하는 손님을 만나는 것이다. 사용자는 취객 빈도 개선과 진상 등 지속 상호작용 승객의 기획을 요청했다. 세부 빈도·유형·배점은 아래 제안이며 아직 확정하지 않았다.

### 등장 방식 비교와 제안

| 방식 | 장점 | 한계·선택 상태 |
|---|---|---|
| 기존 확률만 증가 | 변경이 작고 무작위성 유지 | 연속 미등장·몰아 등장 가능, 단독 적용 비추천 |
| 매일 첫 손님을 취객으로 고정 | 즉시 체험 | 첫 운송이 반복되고 무작위 배정 취지 약화, 비추천 |
| 기본 확률+미등장 보완+휴식 구간 | 무작위성을 유지하며 긴 공백과 연속 부담 제어 | 상태 저장 필요, 권장 검토안 |

현재 후보별20%·하루1명 제한은 짧은 플레이에서 놓치기 쉽다. 독립 추첨을 가정하면 처음3회 모두 비취객일 확률은51.2%다. 실제 후보는 고정 시드이며 취소/재수락이 새 추첨은 아니므로 이는 설명용 확률이다. 등장 빈도와 구토 빈도를 함께 높이지 않는다.

| 항목 | 시험 규칙 | 예외·목적 |
|---|---|---|
| 기본 취객 빈도 | 배정 가능한 운송의30% | 시간·지역 제한 없이 짧은 Proto에서도 체험 |
| 미등장 보완 | 연속 비취객3명 실제 탑승 후 다음 배정 가능 승차는 취객 | 동일 후보·호출 갱신·재수락으로 다시 뽑지 않음 |
| 하루 한도 | 실제 취객 탑승 최대2명 | 기존1명보다 체험 기회 확대, 한도 이후 보완 예약은 다음 날로 유지 |
| 부담 분산 | 취객 또는 아래 지속 응대 유형 뒤 일반 승객1명 확보 | 취객 보완이 대기 중이어도 이 휴식 구간 우선 |
| 짧게 끝낸 영업 | 실제 승차가 적으면 미등장 가능 | 매일 무조건1명 보장으로 표시하지 않음 |
| 상태 확정 | 최초 유효 승차 확정 때 영업의 승차 순번에 성향 예약, 같은 순번에는 같은 결과 | 사전 표시 없는 성향만 배정. 취소/청결 거부는 순번·보완·한도 미소모 |
| 저장 | 성향 예약·연속 미등장·휴식 구간·하루 한도와 확정된 승객을 함께 보존 | 실제 취객 탑승 때 미등장 카운터 초기화, 날짜 변경은 하루 한도만 초기화 |
| 돌발 사건 | 구토·기상 지연 확률과 세차 규칙은 기존 유지 | 빈도 변경으로 비용이 늘어나는지는 따로 검증 |

Proto에서는 취객1유형을 먼저 개선하고 아래 비취객3유형을 추가하는 안이다. 한 손님에는 주 성향1개만 배정한다. 취객 배정 실패 시 비취객 지속 응대 유형을30%로 추첨하고 세 유형을 균등 배정한다. 휴식 구간에는 모든 지속 응대 유형을 제외한다. 취객 보완은 다른 지속 응대 유형을 만났더라도 비취객 탑승으로 계산한다. 이 비율은 실제 전체 탑승 비율과 같지 않으며 한도·보완·휴식 때문에 달라진다.

### 승객 유형과 상호작용

| 주 성향 | 첫 대사·상황 | 플레이어 선택 | 운행 중 후속 반응·결말 |
|---|---|---|---|
| 취객 | “오늘 좀 마셨어요… 같은 얘기 했나요?” | 짧게 받아주기 / 조용히 모시기 / 정차 때 확인 | 받아주면 앞 대사를 잇는 수다, 조용히 요청하면 수다 억제. 구토 예고와 깨우기는 유지하고 안전 안내 우선 |
| 재촉·불만형 | “늦었는데 더 빨리 못 가요?” | 합법 ETA 설명 / 안전 운행 경계 설정 | 법규 내 진행에는 “생각보다 괜찮네요”, 지연 시 재확인. 위험 운전 요구는 단호하게 거절 가능, 약정 기한 단축 없음 |
| 의심·간섭형 | “왜 이 길로 가죠? 돌아가는 거 아닌가요?” | 경로 이유 설명 / 가능한 대안 확인 | 약속한 경로·안전 우회에 맞춰 수긍 또는 재문의. 목적지/경로 변경은 기존 요청 절차만 사용 |
| 대화·반복 질문형 | “기사님 생각은 어때요?” | 짧게 공감 / 운전에 집중하겠다고 안내 | 앞 답변을 기억해 다른 질문으로 이어짐. 집중 안내 후 질문 중단, 하차 때 짧은 감사 |

경로 대안 확인은 이미 배정된 경로 요청의 선택에만 연결한다. 그런 요청이 없으면 현재 경로를 설명할 뿐 새 요청·약정을 추가하지 않는다.

‘진상’은 재촉·반복 요구·간섭이라는 행동으로 표현한다. 정당한 거절 때문에 플레이어를 벌주거나 성별·나이·직업에 성향을 고정하지 않는다. 폭행·차량 조작 방해·신규 강제 하차·장편 대화·음성 연기는 이번 안에서 제외한다.

### 공통 대화 흐름과 평가

| 단계·조건 | 동작 | 중복·안전 보호 |
|---|---|---|
| 승차 | 주 성향 소개, 기존 요청이 있으면 그 내용에 연결 | 기존0~2개 요청 배정은 유지. 성향만으로 별도 목적지/기한 생성 금지 |
| 선택 응답 | 짧게 응대 / 근거 설명 / 대화 경계 설정 중 상황에 맞는2~3개 | 기존 안전 정차 조건에서만 입력, 움직이면 보류. 일반 대사에는 버튼을 매번 붙이지 않음 |
| 다음 반응 | 이전 답변+관찰된 사건으로 분기 | 같은 대사 랜덤 반복만으로 상호작용 완료 표시 금지 |
| 후속 질문 | 기존 요청과 합쳐 운송당 선택창 최대3회, 성향 자체는 최대2회 | 두 선택창 사이 실제 주행30초, 다른 안전 정차 기회 필요. 경로 약정 변경은 기존 최대1개 |
| 우선순위 | 구토/운행 불가 경고 → 기존 요청 → 성향 후속 → 일반 수다 | 선택창은1개, 새 경고가 답변을 덮거나 자동 선택하지 않음 |
| 일반 대사 | 기존 취객 대사 간격 유지, 비취객은30~45초에 최대1회 | 조용한 약속·집중 안내 후 억제. 새 질문은85% 진행 또는 유효 도착 이후 종료 |
| 짧은 운송·기회 없음 | 후속 대사 없이 도착 반응으로 마무리 | 미응답/미발생 중립, 새 질문을 위해 정차·지각을 강제하지 않음 |
| 평가 | 성향별 독립 호감도 게이지/추가 요금 없음 | 기존 요청에 연결한 결과만 기존 요청 합계 -10~+10 안에서1회 반영. 성향 대화만의 보상·감점은0 |
| 실제 위험 운전 | 기존 주행 평가와 요청 관찰 사용 | 같은 충돌·급제동을 성향 불만으로 다시 차감하지 않음 |
| 기억·재개 | 마지막 응답·대사 단계·대기 질문·경계 설정·평가 완료를 보존 | 재시작으로 질문/보상 재발생 금지, 이미 확정된 운임 불변 |

예: 재촉 → “신호는 지키고 예상 시간에 맞추겠습니다” → 정상 신호 대기는 불만 감점 없음 → 합법 주행 후 “안내해 준 시간대로네요” → 하차 결과는 기존 S/R·운임 산식. 반복 질문을 원치 않으면 안전 정차 때 집중 안내를 선택해 끝낼 수 있다.
