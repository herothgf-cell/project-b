# 마인드맵 가지별 변경 검토표

2026-10-29 추가 검토: 아래 이전 가지 판정 중 내구도/사고 수리 제외는 [Proto 확장](03-life-and-economy.md#추가-기획-충돌-내구도와-수리)에서 부분 변경했다. 취객·진상은 [지속 응대 승객안](02-passengers-and-fares.md#추가-기획-승객-유형과-상호작용)을 연결한다. 승객 유형/준비/청결 사건은 구현했으며 내구도·수리·견인은 사용자 승인에 따라 구현·자동 검증을 완료했다. 최종 Player·수동/전체 캠페인 검증 완료와 구분한다. 이번 작업에서는 .mmst 원본을 변경하지 않았다.


대상은 같은 폴더의 **택시 시뮬레이션.mmst**다. 아래 표는 기존 가지와 최신 기획의 대조 기준이다. 2026-10-27 후속 승인으로 원본에도 현재 규칙·후속 구상 구분과 Detail-Links 갱신을 반영했다. 이동된 기존 아이디어는 별도 가지에 보존했다.

## 표를 읽는 기준

| 작업 | 의미 |
|---|---|
| 추가 | 현재 기획에 있지만 원본 가지에 빠진 내용 |
| 수정 | 현재 문구가 최신 규칙을 잘못 설명하거나 의미가 불분명한 경우 |
| 통합·삭제 | 같은 규칙의 중복 가지를 한 곳으로 합치고 나머지는 제거/참조로 바꿈 |
| 이동 | 아이디어는 보존하되 현재 Proto가 아닌 ‘후속 구상’ 또는 별도 개발 자료로 분리 |

**이동·통합은 아이디어의 영구 폐기가 아니다.** 현재 Proto와 후속 구상/제작 참고를 구분한다. 반복 상세 수치는 대표 가지 한 곳에 두고 다른 가지는 관련 기획으로 연결한다.

## 중복을 없앤 대표 가지 제안

| 규칙 | 대표 가지 한 곳 | 다른 가지에는 이렇게 남김 |
|---|---|---|
| 운임·보너스 산식 | 경제 > 운임 요금 규칙 | 승객 만족도는 ‘운임에 영향’만 연결 |
| 요청 종류·선택·효과 | 승객&보행자 > 승객 대화 > 요청17종 | 별도 변경/경유/분실물 가지는 해당 요청 참조 |
| 청결·세차 결과 | 차량 > 차량 관리 > 청결·세차 | 주유소는 ‘세차 제공’, HUD는 ‘청결 표시’만 |
| 식사·수면 회복/비용 | 맵 > 주요 시설 > 거점 이용 공통 규칙 | 운전자는 상태 변화·영향, 시설은 이용 장소만 연결 |
| 졸음 단계·마감 예외 | 운전자 > 피로도 | 캠페인은 ‘졸음 정책에 따른 당일 마감’만 연결 |
| 지역 수요 | 맵 > 지역 | 경제는 공차 성과, 호출은 이용 가능한 손님 표시만 연결 |
| 기록·연습 | 운전 점수 > 운전 점수 히스토리 | 캠페인은 하루 결과 연결, UI는 화면 위치만 |

대표 가지의 상세 기준은 연결된 기획서에 둔다. 원본을 다시 정리할 때에도 후속 아이디어와 사용자 작성 내용은 보존한다.
