# 마인드맵 관리·대조 기준

## 2026-11-07 원본 대조 반영

[전체 미정·날씨 상태](../future-design/2026-11-07-planning-gaps-and-weather.md)와 [검증 이력](../work-history/2026-11-07-mindmap-weather-review.md)을 따른다. 원본/목차에 승객 프리셋·개별 설정·다양화와 운전 설정을 반영하고, 날씨는 기획 필요0%/미구현으로 명시했다. 상세 계약이 있는 작은 방2항목만25%, 중복 추천/대체된 PVP 원안은 집계 제외다. 기존 ID/부모/순서·접힘·메모/링크는 보존했으며 이 파일 아래11/06 문구는 직전 정리 당시 기록이다.

현재 구현 단계의 숫자가 줄거나 늘어도 독립 기능 완성도의 변화가 아니다. 중복 참조 재분류·새 말단 분리의 결과이며 실제 제품 완료율이나 사람 수용율로 사용하지 않는다. 이전 원본은 [11/07 변경 전 보존본](../design-history/content-design/2026-11-07-mindmap-before-status-review.mmst)에 남겼다.

## 현재 원본과 역할

[사용자 마인드맵](택시%20시뮬레이션.mmst)과 [글 목차](택시%20시뮬레이션-목차.md)는 전체 가지를 찾는 탐색 자료다. 현재 규칙은 [담당 기획 목록](README.md), 구현/미검증은 [체크리스트](../prototype-development-checklist.md), 실제 배포는 [최신 작업 이력](../work-history/LATEST.md)에서 확인한다.

2026-11-06 최신 마인드맵 게시 이후의 운전 설정/아이콘/UI 변경은 담당 문서에 반영돼 있다. 이번 문서 정리로 원본 노드·메모·접힘·task키·사용자 링크를 다시 만들거나 완료율을 올리지 않았다.

## 단계 표시

| 값 | 의미 | 의미하지 않는 것 |
|---|---|---|
| 0% | 기획 필요/보류 | 개발 지시 확정 |
| 25% | 기획 완료·미구현 | 코드 기능 제공 |
| 50% | 구현 단계 | 사람3일·다른PC·LAN 장시간 검증100% |
| 부모 집계 | 하위 단계별 개수 | 평균 제품 완성도 |

설명/참조는 집계에서 제외한다. 같은 기능에 새 수치/문구만 반영했다고 새 기능 노드를 중복 추가하지 않는다. 작은 방 구매 구현과 차량 구매/이사 미구현을 구별한다.

## 수정·보존 원칙

- 기존 ID/메모/접힘·순서와 사용자가 삭제한 제작 참고 가지를 보존한다.
- 숫자/산식은 담당 기획으로 연결하고 마인드맵에 중복 규칙을 만들지 않는다.
- 검토 후보·후속·현재 플레이를 분리한다. 새 제안을 기존 승인으로 취급하지 않는다.
- 자동 구조/링크 검사는 네이티브 앱에서의 실제 시각 확인과 구분한다.

## 이전 가지별 검토

2026-10-27~11-06의 상세 수정표·당시 노드 수·이전 미구현 표시는 [정리 전 보존본](../design-history/content-design/2026-11-06-cleanup/06-mindmap-review.md)에 옮겼다. 당시 사고 제외/고정 신호/이전 PVP 상태를 현재 규칙으로 사용하지 않는다. [이번 정리 이력](../work-history/2026-11-06-content-design-cleanup.md)에 변경 기준을 남긴다.
