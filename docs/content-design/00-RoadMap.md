# 로드맵

작성일: 2026년 10월 15일 · 버전: 0.3 · 상태: 출구 정체 플레이와 히스토리 예시 보완안


## 세계관

* 경제가 어려워지고 직장에서 잘린 주인공이 돈을 벌기 위해 택시를 운전하는 세계관



## 주요 포인트

* 운전할 때 길이 막힐 때 다른 돌아갈까? 를 고민한다.

  * 자주 다니는 길일 수록 조금 더 편한 길을 잘 찾게된다.
* 실제 교통법을 준수하면서 운전하는 모습은 어떤 것인가? 를 경험함
* 장시간 운전해야하는 게임은 지양
* 실제 도로를 기반하지만 특정 상황 유발을 위한 만들어진 맵이나 지형 지물들도 존재할 수 있다.
