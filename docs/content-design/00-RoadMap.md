# 기획 및 프로토타입 로드맵

기준일: 2026년 10월 16일 · 버전: 0.4 · 상태: 사용자 로드맵·추가 결정 반영

## 세계관과 주요 경험

| 항목 | 방향 |
|---|---|
| 세계관 | 경기가 어려워져 실직한 주인공이 돈을 벌기 위해 택시를 운전 |
| 성장 | 운전·지역·경로 판단에 익숙해지며 편한 길을 찾음 |
| 선택 | 정체에서 기다릴지 우회할지 판단하고 결과를 경험 |
| 법규 | 한국 법규를 준수하는 운전을 경험하고 독립적인 성향 기록으로 확인 |
| 시간 | 3일 × 하루 8분, 누적 순수익 30,000원 목표 |
| 공간 | 은계 기반 도로 + 판단 상황을 위한 가상 연결도로·시설 허용 |
| 영업 | 프로토는 개인택시. 법인택시는 후속 |

## 상태와 범위 기준

| 표시 | 의미 |
|---|---|
| 포함 | 프로토 개발 목표에 넣음. 현재 구현 완료와는 다름 |
| 부분 포함 | 표에 적힌 최소 기능만 구현, 나머지는 후속 |
| 제외 | 이번 프로토에서는 개발하지 않음 |
| 기획만 | 후속 플레이 흐름은 작성하되 프로토 개발·검증 범위에서 제외 |
| 수치 제안 | 문서화된 게임 초깃값. 실제 법정 금액·확정 밸런스가 아님 |

현재 상태는 코드와 기존 검증 기록 기준이다. 이번 문서 정리는 게임 기능 구현이나 새 빌드 검증을 의미하지 않는다.

법규 행의 감점은 독립 법규 점수를 뜻한다. 승객 매너 점수와 다른 표·다른 누적 단위로 관리한다. 단속되지 않아도 법규 이력은 남고, 법규 점수가 낮다는 이유만으로 승객 운임이 줄지는 않는다.

## 반영한 사용자 결정

| 항목 | 확정 방향 | 세부 기획 제안 |
|---|---|---|
| 보험·세금 | 갱신과 납부일까지 직접 관리 | 기존 보험 2일차 만료·세금 3일차 기한, 게임용 금액·알림은 05 참고 |
| 캠페인 | 3일 × 8분·누적 순수익 30,000원 | 수익·납부 완료로 성공 판정, 실제 플레이 후 밸런스 조정 |
| 개인 예약 | 프로토 제외·기획만 | 후속 관계→예약→픽업→완료/취소 흐름은 04 |
| 사고 | 프로토 제외·기획만 | 후속 안전조치→기록→운송 처리→수리/복귀 흐름은 08 |

금액·연료 소모·법규 감점·성향 기준 횟수는 테스트할 제안값이다. 후속 예약·사고의 세부 결정을 이유로 프로토 개발을 막지 않는다.

## 프로토 개발 순서와 완료 기준

| 단계 | 목표 | 필요한 기획 | 개발·검증 완료 조건 |
|---|---|---|---|
| 1 | 맵과 주행 기반 정리 | 06의 주행·시설·AI 범위 | 은계 영업·거점 접근과 보조/수동 주행 가능 |
| 2 | 두 대표 상황 | 01 상황표 + 02 법규 근거·감점 | 출구 세 선택 및 우회전 조건별 판단 재현 |
| 3 | 독립 법규 기록 | 02·03의 사건·성향·저장 | 승객 매너와 분리된 카드·누적·재시작 |
| 4 | 승객과 경제 | 04 요청·보상, 05 거점·납부 일정 | 요청 대응·실제 결제·갱신·납부·중복 차감 방지 |
| 5 | 짧은 캠페인 완주 | 07 진행 목표·03/05 저장 | 준비→운송→방문/납부→정산→성공/실패→재도전 |

개발 기간·인원은 자원 확인 후 산정한다. 프로토에서 법규를 지키는 정상 운전으로 비용을 감당하고 수익 목표를 달성할 여지가 있는지 확인한다.
