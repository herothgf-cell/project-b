# 콘텐츠 범위와 현재 구성

현재 기준: 2026-10-27, main 배포 소스 e9c6fae. 이 문서는 현재 플레이 범위만 설명한다. 변경 경위는 [기획 변경 이력](../design-history/content-design/2026-10-27-design-decisions.md), 명령·검증 결과는 [작업 이력](../work-history/LATEST.md)에서 분리한다.

## 핵심 경험과 콘텐츠 묶음

| 묶음 | 플레이어 행동 | 연결 결과 | 담당 기획 |
|---|---|---|---|
| 운송 | 호출 선택·수락 → 방향을 맞춰 픽업 → 목적지 하차 | 운임·만족도·운송 기록 | [04](04-passengers-and-reservations.md), [14](14-passenger-stop-variety.md) |
| 운전 판단 | 신호·보행자·차로·정체를 보고 실제로 운전 | 누적 운전 점수와 운송별 주행 만족도를 별도로 평가 | [01](01-driving-situations.md), [02](02-driving-evaluation.md) |
| 승객 응대 | 요청0~2건에 안전 정차 중 응답하고 실제로 이행 | 요청별 결과 → 승객 만족도 → 하차 정산 | [11](11-passenger-request-effects.md) |
| 영업 동선 | 상대 수요·접근 경로를 보고 호출/공차 이동 선택 | 연료·시간 소비와 공차/탑승 성과 기록, 수요 할증 없음 | [17](17-proto-operation-expansion.md) |
| 공간 점유 | 막힌 일반 승하차 지점이 해소될 때까지 대기 | 같은 운송 유지·기한 보호1회. 현재 대체 이동 없음 | [17](17-proto-operation-expansion.md) |
| 생활 운영 | 주유·식사·수면·세차·마감 선택 | 현금/미납·연료·포만감·피로·청결·영업시간 변화 | [05](05-daily-operation.md), [10](10-driver-condition.md), [15](15-drunk-passengers-and-cleanliness.md) |
| 하루와 기록 | 예정20분 이후 계속 영업하거나 거점에서 마감 | 3일 이월·일별/누적 비교·저장/복습 | [07](07-campaign.md), [03](03-history-and-mastery.md) |
| 월드와 도구 | 방향 경로 안내, M 지도, 편집기·연습 사용 | 주행/승하차/평가가 같은 지도 데이터를 참조 | [06](06-world-map-and-driving.md), [12](12-road-map-editor.md), [13](13-driving-map-ui.md) |

## 현재 기능 상태

| 범위 | 현재 상태 | 구분해야 할 제한 |
|---|---|---|
| P11 요청 다양화 | 후보 ID 기반0/1/2건, 승차/안전 정차 제시, 개별 관찰·저장·합산 구현 | 17종 콘텐츠 중 EV03은 하차 후 별도 사건. 빈도·답변 여유의 사람 체감은 후속 |
| P12 수요·공차 | 주거/업무/상업 상대 수요·단계별 가중, 공차/탑승 거리·시간 집계 구현 | 현실 도시 수요가 아님. 호출 행은 승하차 식별·예상 운임만 간단 표시 |
| P13 공간 점유 | 일반 승하차 후보의 점유·대기·해소·평가 보호·저장 구현 | 현 지도에서 검증된 근거리 안전 대체 쌍0개, 대체 이동 미구현 |
| 운송·생활·캠페인 | 9코스·일반12후보를 포함한24정차 후보, 3일 캠페인, 거점·취객·청결·회계·이어하기 구현 | 코스9개 강제 완주나 고정 수익 성공 조건 없음 |
| 표지·피로 후속 | 조건부 유턴 표지 신호등 상부, 반복 눈감김 후 최종 암전·안전 취소·당일 마감 구현 | 지도 전체의 현장 규제 인증·실제 졸음 생리 모델이 아님 |
| 안정화 | 모델·Editor·위치 제어·일부 연속 물리 주행 및 배포 검증 수행 | 모든 도로 수동 주행·3일 전체 물리 캠페인·다른PC/패드는 별도 |

P11/P12/P13 대기 경로의 개발을 다시 미구현으로 취급하지 않는다. 현재는 기능 구현과 자동 기술 검증을 마친 플레이 가능한 Proto이며, 안전 대체 이동 같은 미구현 확장과 사람의 조작감·경제 체감 검증을 분리해 관리한다.

## 포함하지 않는 요소

| 분류 | 범위 | 현재 요소와의 차이 |
|---|---|---|
| 경영 확장 | 보험·세금·대출·법인·차량 매매 | 현재 비용은 운송/생활 운영 비용과 미납 장부 |
| 관계·퀘스트 | 개인 예약·단골·실물 분실물 반환 | 현재 요청·하차 후 텍스트 사건만 사용 |
| 도시 확장 | 실시간 수요/교통 API·전역 군중·일반 공사·전국 정밀 복원 | 은계 게임용 지도·48대 차량·안전6슬롯 보행 |
| 연출 확장 | 실제 음악 변경·음성 연기·영상 리플레이·악천후 | 텍스트 응대·사건 카드·선택 연습과 구분 |
| 공간 대안 | 미검증 인도·반대 차로·임의 근거리 대체 정차 | 현재 검증된 원래 지점의 해소 대기만 제공 |

신규 아이디어는 승인 없이 필수 범위로 추가하지 않는다. 후속 제안·마인드맵 변경 검토는 [변경 이력](../design-history/content-design/2026-10-27-design-decisions.md)에서 별도 관리하며 .mmst 원본은 수정하지 않는다.
