# 운전 상황 콘텐츠 기획서

작성일: 2026년 10월 15일 · 버전: 0.3 · 상태: 출구 정체 플레이와 히스토리 예시 보완안

## 기획 의도

운전 상황 콘텐츠는 도로의 단서를 읽고 행동을 선택하는 게임의 핵심이다. 플레이어는 택시로 이동하면서 지금 진행해도 되는지, 기다려야 하는지, 경로를 바꿔야 하는지 판단한다. 익숙한 상황도 보행자와 차량, 신호 조건이 바뀌면 다시 살펴보게 만든다.

면허시험에서 다룰 법한 소재를 주행 경험으로 구성한다. 정확한 도시 복원보다 정지선과 신호의 관계, 시야, 다른 이용자의 의도가 읽히는 도로 구성이 우선이다. 실제 시험 문제의 복제나 공식 시험 채점 체계의 재현은 전제하지 않는다.

## 플레이어 경험

처음에는 안내를 통해 무엇을 확인해야 하는지 배운다. 이후 같은 종류의 상황을 다른 장소와 조건에서 만나며 스스로 판단한다. 잘못 선택해도 어떤 단서를 놓쳤는지 이해하고 다시 시도할 수 있다. 올바르게 기다렸을 때 보행자가 통과하거나 교차 흐름이 유지되는 모습을 통해 자신의 행동이 만든 결과를 확인한다.

주요 선택은 실제 가감속, 정차, 방향지시, 차로 유지·변경, 경로 변경으로 수행한다. 선택지 창으로 운전을 계속 중단하지 않는다. 설명과 상황 재구성은 운행 종료 또는 복습에서 제공한다.

## 상황의 진행

| 단계 | 플레이어에게 보이는 것 | 플레이어 행동과 결과 |
|---|---|---|
| 접근 | 신호·표지·노면 표시와 주변 이용자 | 속도와 위치를 조정하며 정보를 확인 |
| 판단 | 진행 가능 공간과 충돌 가능성, 승객의 목적지 | 대기·진행·경로 변경 등을 선택 |
| 행동 | 자신의 차량과 주변 반응 | 선택을 실제 운전으로 수행 |
| 종료 | 해당 구간을 벗어나거나 사건이 해소됨 | 한 상황의 평가를 확정하고 짧게 알림 |
| 회고 | 상황 조건, 행동, 판정 이유 | 운송 종료 후 기록 확인 또는 복습 선택 |

한 장면에서 여러 판단이 생기면 보행자 보호, 신호, 차로 행동을 구분해 기록한다. 같은 행동을 매 순간 새로운 사건처럼 반복 평가하지 않는다. 교통 AI의 오류나 잘못된 안내로 조건이 성립하지 않은 경우는 판정 보류로 처리하고 숙련 결과에서 제외하는 안을 둔다.

## 1차 상황 구성

다음 목록은 콘텐츠 소재다. 보행자 예시 외 세부 법규 판정표는 해당 신호·표지·도로 조건을 정한 뒤 근거를 확인하여 확정한다.

| 상황군 | 관찰할 정보 | 판단의 재미 | 후속 변형 |
|---|---|---|---|
| 횡단보도 접근 | 보행자 위치·이동 의도, 정지선, 신호 유무 | 기다려야 할 때를 알아차리고 부드럽게 정차 | 가려진 시야, 여러 보행자, 뒤차의 재촉 |
| 교차로 회전 | 차량·회전 신호, 횡단보도, 교차 차량 | 한 가지 신호만 보고 출발하지 않고 조건을 함께 확인 | 신호 구성과 시야가 다른 교차로 |
| 교차로 통과 | 전방 출구 공간, 정체, 신호 변화 | 진입 시점과 이후 공간을 함께 판단 | 앞차의 지연, 출구 정체 해소 |
| 차로 변경과 합류 | 노면 표시, 주변 속도·간격, 방향지시 | 가능한 공간을 기다리거나 경로를 유지 | 내비 회전 지점을 놓친 경우 |
| 승하차 위치 선택 | 정차 가능 지점, 보행 동선, 차량 접근 방향 | 승객 요청과 안전한 승하차 위치 조율 | 승객이 편의상 부적절한 지점을 요구 |
| 정차 차량과 시야 제한 | 장애물, 주변 차로, 보행자 등장 가능 공간 | 대기와 합법적 우회 중 선택 | 좁은 도로, 차로별 혼잡 차이 |

상황이 없는 구간도 유지한다. 모든 교차로에서 돌발 사건을 발생시키지 않으며, 기본 관찰에 익숙해진 뒤 조건을 겹친다. 보행자나 차량이 회피할 수 없는 거리에서 갑자기 나타나도록 만드는 방식은 피한다.

## 대표 운행 예시

신호기가 없는 횡단보도에 접근한다. 보행자가 횡단하려는 행동을 플레이어가 볼 수 있는 위치에서 보인다. 택시 뒤에서는 다른 차량이 재촉하고, 승객은 도착 시간을 묻는다.

| 선택 | 장면의 결과 | 피드백 방향 |
|---|---|---|
| 일찍 감속하고 정지선 앞에서 정지 | 보행자가 안전하게 건너고 이후 운행 재개 | 법규 준수와 위험 예측을 각각 설명 |
| 늦게 알아차리고 급정지 | 충돌을 피한 뒤 보행자 통과 | 정지 여부와 접근 과정의 위험을 분리. 필요한 급제동 자체를 무조건 벌점화하지 않음 |
| 횡단하려는 보행자를 무시하고 통과 | 보행자가 멈추거나 통행을 방해받음 | 충돌이 없더라도 해당 보호 의무를 평가 |

도로교통법 제27조 제1항은 횡단보도를 건너고 있거나 건너려는 보행자가 있을 때 횡단보도 앞에서 일시정지하도록 정하며, 정지선이 있으면 그 선을 기준으로 한다. 이 예시는 해당 조건을 명확하게 제시한 상황이다. [국가법령정보센터 제27조](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1030975017), 확인일 2026년 10월 15일. 다른 신호·보호구역 조건에는 별도의 상황 설명을 적용한다.

## 우측 출구 정체에서의 선택

우측으로 빠져야 하지만 출구 차로에 긴 줄이 있다. 옆 차로는 상대적으로 빠르게 움직이고, 직진하면 다음 경로로 돌아갈 수 있다. 플레이어는 줄 뒤에 합류해 기다리거나, 출구를 지나 우회하거나, 줄을 지나 앞부분에서 진입하려 할 수 있다. 선택은 팝업 대신 실제 주행으로 이루어진다.

출구 안내와 대기열은 뒤에서 합류할 수 있는 거리부터 보여준다. 뒤늦은 내비 안내 때문에 진입 기회를 놓친 상황과, 줄을 인지하고도 앞부분 진입을 선택한 상황을 구분한다. 보이지 않은 정보를 이미 알았다고 가정하여 의도를 단정하지 않는다.

| 선택 | 얻는 것과 감수하는 것 | 기록할 사실 |
|---|---|---|
| 줄 뒤에서 기다림 | 우회 거리를 줄이지만 대기 시간이 발생 | 대기열 진입 위치, 간격 유지, 대기 중 행동 |
| 직진 후 다른 길로 우회 | 추가 거리와 연료 사용, 대기 회피 가능 | 경로 변경, 실제 소요, 이후 도로 규칙 준수 |
| 앞부분에서 진입 시도 | 시간을 줄일 수 있으나 통행 방해나 위반 가능 | 진입 위치·방식, 상대 차량 반응, 적용 법규 |

우회와 대기 중 어느 쪽이 항상 빠르도록 만들지 않는다. 허용된 선택 간 효율 차이는 교통 상황에 따라 달라지며, 우회했다고 준법 성향이 낮아지지 않는다. 앞부분 진입도 위치만으로 위반을 확정하지 않는다. 정상적인 차로 합류와 금지된 끼어들기는 별개로 구성한다. 점선이거나 충돌이 없었다는 이유만으로 적법하다고 판단하지도 않는다.

법규 후보는 도로교통법 제23조와 그 조문이 참조하는 제22조 제2항, 진로 변경과 관련한 제19조 제3항이다. 정체 원인과 정지·서행의 이유, 노면 표시, 통행 방해 조건을 장면에 명시한 뒤 판정한다. 근거와 확인 범위는 [법규 성향 기획서](02-driving-evaluation.md)의 법규 자료 기준을 따른다.

### 같은 상황의 변형

| 변형 | 바꾸는 조건 | 확인하려는 선택 |
|---|---|---|
| 시간 여유 | 승객 또는 예약에 여유가 있음 | 기본 대기·우회 선택 |
| 시간 압박 | 승객이 서두르지만 규칙은 동일 | 압박을 받았을 때 준수 여부의 변화 |
| 빈차 운행 | 승객과 매너 요구가 없음 | 승객이 없어도 같은 규칙을 지키는가 |
| 타인의 위반 | 다른 차가 앞부분 진입을 시도 | 따라 하기, 거리 유지, 위험한 진입 방해 등 실제 행동 |
| 안내를 놓침 | 안전하게 진입할 기회를 이미 지남 | 무리한 진입 대신 다음 경로를 받아들이는가 |

다른 차량의 부적절한 행동을 막기 위한 급가속이나 차로 봉쇄도 별도로 기록한다. 상대의 잘못이 플레이어의 위험 행동을 정당화하는 보상 구조를 만들지 않는다.

### 장면 이후의 피드백

실제 이동 시간, 추가 거리, 관찰된 주변 차량의 제동·정체 변화, 법규 판단과 근거를 구분해 보여준다. 지나가지 않은 경로의 시간을 확정 사실처럼 비교하지 않는다. 다른 선택의 결과는 동일 조건의 복습으로 비교하거나 예상치임을 표시한다.

한 번 기다렸다고 ‘모범 운전자’, 한 번 진입했다고 ‘얌체 운전자’로 명명하지 않는다. 여러 유사 상황의 선택을 모아 ‘시간 압박 상황에서 대기열 관련 위반이 반복됨’처럼 관찰 가능한 성향으로 설명한다. 승객 매너 결과와는 별도 기록이다.

## 구체적인 플레이 예시와 히스토리

### 공통 장면 설정

장면명은 ‘오른쪽 출구 앞의 긴 줄’이다. 일반 도심 도로에서 오른쪽 연결도로로 빠져 목적지에 가야 한다. 연결도로 앞 신호 때문에 출구 방향 차량들이 정지·서행하고 있고, 직진 차로는 움직인다. 차로가 없어지는 합류 구간이나 공사로 인한 번갈아 진입 상황은 아니다. 앞부분 진입의 법규 조건을 분명히 하기 위해 신호 대기열을 선택한다.

아래 거리·시간·대사는 장면을 설명하기 위한 기획 예시이며 현재 빌드의 실측값이나 확정 밸런스가 아니다. 세 경로는 동일한 상황에서 갈라지는 대안 플레이이며 한 번의 운행에서 모두 수행한 결과가 아니다.

| 항목 | 예시 설정 |
|---|---|
| 출구 안내 | 출구 약 300m 전부터 내비 안내와 도로 표지 제공 |
| 대기열 | 출구 진입 차로에 약 8대. 뒤에서 안전하게 합류할 기회 제공 |
| 도로 표시 | 진입이 가능한 구간과 변경 금지 표시 구간을 식별 가능하게 구성 |
| 대체 경로 | 직진 후 다음 연결도로로 이동 가능. 역주행·급정지 없이 재탐색 |
| 안내 시간 | 대기 경로 목적지 도착 예상 3분, 우회 예상 3분 40초. 교통에 따라 변동 |
| 승객 | 매너 요구 점수 70점인 승객. ‘조금 서둘러 주실 수 있을까요?’라고 요청 |
| 시간 압박 | 두 정상 경로 모두 운송을 완료할 여유를 둠. 승객의 재촉이 위반을 강제하지 않음 |
| 운전 도움 | 조향 보조를 사용할 수 있으나 진입·대기·가감속은 플레이어가 결정 |

플레이어가 보는 정보는 줄의 길이, 신호 상태, 주변 차량의 움직임과 예상 시간이다. 화면에 ‘착한 선택’이나 ‘나쁜 선택’을 미리 표시하지 않는다. 법규 상세 해설은 장면이 끝난 뒤 확인한다.

### 선택 A 대기열 뒤에서 기다린다

1. 플레이어가 미리 감속하고 주변 차량을 확인한 뒤, 충분한 공간이 있는 대기열 뒤로 들어간다.
2. 대기 중 승객이 시간을 묻는다. 주행 흐름을 방해하지 않는 시점에 예상 시간을 안내할 수 있다.
3. 옆 차로의 차량들이 먼저 지나가지만 택시는 앞차와 간격을 유지한다. 줄이 움직이면 천천히 전진한다.
4. 자기 순서에 따라 출구로 빠진다. 기다렸다고 자동 추가 팁이나 법규 보너스를 지급하지 않는다.
5. 장면 종료 때 ‘출구 정체 상황이 기록되었습니다’라는 짧은 표시를 제공한다.

이 예시에서는 신호가 정상적으로 바뀌어 대기열이 풀린다. 후속 변형에서는 대기가 길어질 수 있다. 대기는 항상 가장 빠른 정답이 아니라 추가 거리를 피하는 선택이다. 기다리는 도중 적법하고 안전하게 우회로 바꾸었다면 그 실제 행동 순서를 기록한다.

**히스토리 카드 A**

| 항목 | 표시 예시 |
|---|---|
| 상황 | 신호로 정지·서행하는 우측 출구 대기열, 승객 탑승·재촉 있음 |
| 내 행동 | 대기열 뒤 합류 → 간격 유지 → 출구 진입 |
| 주변 영향 | 진입 시 다른 차량의 급제동이나 통행 방해가 관찰되지 않음 |
| 법규 기록 | 관찰한 진로 변경 조건 준수. 금지된 앞부분 끼어들기 없음 |
| 선택 기록 | 대기 선택. 순서대로 진입 |
| 성향 표시 | 이번 1건만으로 성향을 확정하지 않음 |
| 다음 보기 | 해당 장면 설명 / 정체가 더 긴 조건으로 연습 |

승객 매너 카드에는 이번 운송의 기존 매너 점수와 요구 달성 여부가 별도로 남는다. 법규 카드의 ‘준수’가 매너 점수를 자동으로 더하지 않는다.

### 선택 B 출구를 지나 다른 길로 돌아간다

1. 플레이어가 대기열을 확인하고 직진 차로를 유지한다. 출구 직전 급하게 멈추거나 여러 차로를 가로지르지 않는다.
2. 출구를 지나면 내비게이션이 다음 연결도로를 안내한다. ‘경로를 다시 안내합니다’라는 중립적 표현을 사용한다.
3. 승객이 길을 묻는다면 ‘출구가 막혀 다른 길로 안내하고 있습니다’라고 설명할 수 있다.
4. 추가 거리를 이동해 목적지로 향한다. 이 예시에서는 대기 경로보다 오래 걸릴 수 있지만 다른 교통 조건에서는 우회가 빨라질 수 있다.
5. 주행거리와 연료 사용은 실제 이동에 따라 반영하고 경로 이탈 자체를 법규 위반으로 기록하지 않는다.

**히스토리 카드 B**

| 항목 | 표시 예시 |
|---|---|
| 상황 | 카드 A와 동일한 출구 정체 조건 |
| 내 행동 | 직진 유지 → 출구 통과 → 대체 경로 이용 |
| 주변 영향 | 출구 앞 강제 진입으로 인한 다른 차량의 제동 없음 |
| 법규 기록 | 이 장면에서 관련 위반 없음. 출구 차로 변경은 수행하지 않아 해당 평가 기회 없음 |
| 선택 기록 | 대기 대신 우회 선택 |
| 성향 표시 | 경로 선택 취향의 근거로 저장. 대기하지 않았다는 이유로 준수 성향 하락 없음 |
| 다음 보기 | 실제 소요·주행거리 / 같은 조건에서 대기 경로 연습 |

우회로에서 새로운 교차로나 보행자 상황을 만나면 각각 별도 사건으로 기록한다. 선택하지 않은 대기 경로의 실제 소요 시간을 알 수 없으므로 ‘대기보다 40초 손해’처럼 확정해서 표시하지 않는다. 최초 예상 시간과 실제 이동 결과만 비교한다.

### 선택 C 대기열을 지나 앞부분으로 들어간다

1. 플레이어가 출구 대기열 옆을 지나 앞부분으로 이동한다. 이 시점만으로 끼어들기 위반을 확정하지 않는다. 직진할 수도 있기 때문이다.
2. 방향지시기를 켜고 신호 대기 차량 사이로 진입한다. 이 예시에서는 상대 차량의 정상 진행을 방해할 정도로 간격이 부족하며, 상대 차량이 제동한다.
3. 뒤 차량들도 속도를 줄이고 대기열 진행이 잠시 끊긴다. 주변 반응은 실제 상황에 따른 제동·정지로 보여주며 모든 차량이 과장되게 경적을 울리도록 만들지는 않는다.
4. 충돌 없이 출구에 진입할 수도 있다. 이 경우에도 금지된 끼어들기나 진로 변경의 적용 조건이 충족되면 위반을 기록한다. 시간을 줄인 결과가 판정을 없애지 않는다.
5. 플레이는 이어지고, 운행 종료 후 행동과 법규 근거를 확인한다. 이 콘텐츠만을 이유로 승객 매너나 요금을 자동 변경하지 않는다.

**히스토리 카드 C**

| 항목 | 표시 예시 |
|---|---|
| 상황 | 신호로 정지·서행하는 대기열. 승객 재촉 있음 |
| 내 행동 | 대기열 옆 통과 → 앞부분 진입 → 상대 차량 제동 |
| 주변 영향 | 뒤 차량의 진행이 끊김. 충돌은 발생하지 않음 |
| 법규 기록 | 설정된 금지 대상 대기 차량 앞으로 끼어듦. 정상 통행을 방해할 우려가 있는 진로 변경 |
| 적용 근거 | 제23조와 제22조 제2항의 대상 조건, 제19조 제3항의 진로 변경 조건 |
| 선택 기록 | 대기열 앞부분 진입. 이 사건 안에서 두 관련 규칙을 함께 기록 |
| 성향 표시 | 이번 위반 1건 기록. ‘얌체 운전자’ 등 인격 유형은 부여하지 않음 |
| 다음 보기 | 진입 전후 도식 / 적용 조건 설명 / 다른 선택으로 재도전 |

법규 설명은 ‘방향지시기를 켰더라도 이 장면의 진입 조건이 허용되는 것은 아닙니다’처럼 해당 조건을 설명한다. 조문별 벌점 합산을 임의로 만들지 않으며 하나의 사건에 포함된 관련 판단으로 묶는다. 법적 근거의 열람본과 기준일은 [법규 성향 기획서](02-driving-evaluation.md)에 기록된 자료 범위를 따른다. 이 장면의 최종 판정표는 적용 기준일의 신호·차로 규정과 함께 확정한다.

### 앞부분 진입을 포기하거나 실패하는 경우

| 실제 행동 | 장면 진행 | 히스토리 처리 |
|---|---|---|
| 방향지시만 켠 뒤 직진 | 다른 차의 통행을 방해하지 않고 다음 경로로 이동 | 방향지시만으로 끼어들기 위반 처리하지 않음. 진입 검토 후 우회로 기록 |
| 진입 중 상대가 제동한 뒤 복귀 | 출구 진입은 실패하고 직진 | 이미 성립한 통행 방해 관련 판단은 유지. 출구 진입 성공 여부와 분리 |
| 변경 금지 구간까지 지나 우회 | 무리한 진입 없이 재탐색 | 놓친 출구 수용으로 기록. 실제 수행하지 않은 차로 변경에 준수 횟수를 주지 않음 |
| 조건이나 차량 반응이 불명확 | 주행을 이어가며 사실만 보존 | 해당 법규 판정 보류, 준수율 산정에서 제외 |

별도 변형으로 정상적인 합류 상황을 제공할 수 있다. 이 경우에는 도로 구조와 법규 조건을 다시 정의한다. 대기열 사례에서 단지 차량이 공간을 내주었다는 이유로 금지된 끼어들기가 자동 허용되는 것으로 설명하지 않는다.

### 운송 종료 화면과 누적 성향 예시

운송 종료 화면에는 두 개의 독립 카드를 제공한다. ‘승객 운송 결과’에는 기존 매너와 요구 달성 여부, ‘법규 히스토리’에는 출구 정체 사건과 근거가 나온다. 법규 성향에서 승객 매너로 자동 가산·감산하지 않는다. 기존 매너 규칙이 같은 행동을 평가한다면 그 결과와 이유는 승객 카드에서 따로 설명한다.

다음은 5번의 실제 영업 기록이 쌓였다고 가정한 설명 예시다. 5회가 성향 확정 기준이라는 의미는 아니다. 도로 구조·시야·교통량은 유사하고 시간 압박과 승객 유무가 기록되어 있다.

| 회차 | 조건 | 행동과 법규 기록 |
|---|---|---|
| 1 | 승객 있음, 여유 있음 | 대기열 뒤 합류. 관찰한 진로 변경 조건 준수 |
| 2 | 승객 있음, 재촉 있음 | 앞부분 진입. 금지된 끼어들기 및 통행 방해 관련 판단 |
| 3 | 빈차, 시간 여유 있음 | 직진 우회. 출구 차로 변경 평가 기회 없음 |
| 4 | 승객 있음, 재촉 있음 | 앞부분 진입 후 복귀. 이미 발생한 통행 방해 관련 판단 유지 |
| 5 | 승객 있음, 재촉 있음 | 대기열 뒤 합류. 관찰한 진로 변경 조건 준수 |

성향 요약 문구 예시: ‘유사한 출구 정체 5건에서 대기 2회, 우회 1회, 앞부분 진입 2회가 기록됐습니다. 재촉이 있었던 3건 중 2건에 관련 위반이 있었고, 가장 최근에는 대기열 뒤로 합류했습니다.’

이 요약은 재촉이 위반의 원인이라고 확정하지 않는다. 경로 선택 횟수와 규칙별 판단 기회도 따로 센다. 하나의 사건에 두 조문이 연결되었다고 앞부분 진입 횟수를 두 번 세지 않는다. 아직 적은 기록이라는 안내와 각 장면으로 가는 링크를 제공한다.

플레이어가 2회차를 복습해 우회에 성공하면 ‘연습에서 다른 선택을 수행함’으로 남긴다. 원래 영업 기록을 준수로 바꾸거나 승객 매너·수익을 다시 지급하지 않는다. 이후 실제 운행의 변화가 쌓이면 최근 성향에 반영한다.

## 추가하면 좋은 상황 후보

출구 정체를 먼저 완성한 뒤 아래 순서로 확장하는 안이다. 각 장면의 법적 정답은 해당 조건과 국내 근거를 확인한 뒤 정한다.

| 우선순위 | 소재 | 플레이어의 갈등 |
|---|---|---|
| 1 | 회전 지점을 놓침 | 다음 경로 수용과 무리한 차로 변경 |
| 1 | 승객이 부적절한 하차 위치를 요구 | 승객 편의와 도로 규칙·보행 동선 |
| 2 | 교차로 출구가 막힘 | 신호가 허용하는 방향과 실제 진입 공간 |
| 2 | 뒤차가 재촉하는 횡단보도 | 타인의 압박과 보행자 확인 |
| 2 | 끼어드는 차를 만남 | 안전 간격 유지와 경쟁·보복성 행동 |
| 3 | 긴급자동차 접근 | 주변 공간을 고려한 양보 방법 |

## 경로 선택과 운전 보조

내비게이션은 목적지와 경로를 알려주고 현재 회전 가능 여부는 도로에서 판단하게 한다. 안내 지점을 놓치면 다음 경로를 제공하여 무리한 차로 변경을 유도하지 않는다. 초기 경로 비교는 거리·예상 시간 중심으로 보여주며, 익숙한 길을 선택하는 것도 유효한 선택으로 인정한다.

조향 보조를 사용하는 경우에도 신호와 보행자 확인, 가감속 및 진행 결정은 플레이어가 담당하는 안을 기본으로 둔다. 보조가 정지까지 자동 수행한 상황은 법규 위반이 없다는 운행 기록과 플레이어가 판단했다는 숙련 증거를 구분한다.

## 다른 콘텐츠와의 연결

[평가](02-driving-evaluation.md)는 장면의 조건과 실제 행동을 받아 판정한다. [히스토리](03-history-and-mastery.md)는 그 조건을 보존해 설명과 재도전에 사용한다. [승객·예약](04-passengers-and-reservations.md)은 상황을 만나는 목적과 가벼운 긴장을 제공하며 법규를 바꾸지 않는다. [주유와 일상](05-daily-operation.md)은 빈차 이동에서도 같은 판단 경험을 이어준다.

## 초기 범위와 후속 결정

초기에는 주간·양호한 시야에서 기본 상황을 이해시키고, 같은 판단을 다른 배치에서 적용하는 변형을 제공한다. 야간·비·여러 압박의 동시 발생은 후속 난도 후보로 둔다. 실제 지역은 활용할 수 있지만 상황 가독성을 위해 도로 배치와 이동 길이를 조정할 수 있다.

결정할 항목은 첫 상황군의 수, 안내 강도, 교통 사건 발생 빈도, 상황별 법규 적용 조건이다. 완성도를 검토할 때에는 플레이어가 선택 전에 단서를 볼 수 있었는지, 결과 설명에 동의하는지, 다른 배치에서도 같은 원칙을 적용하는지 확인한다. 빠른 통과 시간만으로 성공 여부를 판단하지 않는다.
