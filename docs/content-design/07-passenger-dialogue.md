# 승객 대화·선택 스크립트

## 직접 조정하는 관리 도구

루트 `설정 관리.cmd`에서 요청/유형/상황 대사와 실제 연결된 효과·공통 영향 요소를 편집한다. 아래 표는 출하 기본 프로필 기준이며 사용자 프로필은 다음 새 캠페인/방부터 적용, 이어하기는 저장 snapshot을 유지한다. [실행·원복·테스트](../content-tuning-tool-guide.md), [구현·검증/제한](../work-history/2026-11-05-content-tuning-tool-implementation.md)을 따른다.

## 선택지 효과 표시 기준

71개 요청·유형·상황 답변의 효과는 [02 단계 효과 규칙](02-passengers-and-fares.md#선택지별-단계-효과-설정)과 [현재 밸런스 표](../passenger-balance-v1.md)를 읽는다. 이 문서는 말투·기사 행동·후속 대사를 담당하며 같은 배점/피로/비율 표를 다시 유지하지 않는다. 사용자 대사는 관리창 프로필이 우선하며, 이어하기는 저장 당시 효과/응답을 보존한다.

아래 효과 열은 행동 의도다. “자체 점수 없음/중립”은 기본 유형 발화에 별도 자동 보상을 만들지 않는다는 뜻이며, 실제 선택지에 편집된 즉시/운행 중/종료 효과를 무시한다는 뜻이 아니다. 구체 수치·판정 유무는02와 [실제 판정표](../content-tuning-request-outcomes.md)를 확인한다.

## 공통 화면·입력

흰 카드 상단에 `승객 요청` 또는 `승객 이야기`, 파란 말풍선에 승객 대사, 아래에 `답변 선택`과 선택 버튼을 둔다. 각 버튼은 키·기사 대사·`효과`를 분리한다. 아무 결과도 바꾸지 않는 답변은 `효과 없음`으로 표시한다. 수치/작업 설명을 승객이나 기사가 말하는 문장에 섞지 않는다. 선택 뒤에는 기사 답변과 적용 효과를 보여 준다.

대화는 **운행 중에도 클릭 또는 Y/I/O/U로 선택**할 수 있다. 일시정지·지도/결과·다른 선택창·수면·도착 잠금 및 같은 프레임 중복 응답은 기존 우선순위를 유지한다. 새 요청의 운행 중 발생 시점은 기존 안전 정차 조건을 유지하며, 이미 표시된 요청은 출발해도 답변할 수 있다. 미응답 불이익의 정차 기회 판정은 기존대로다.

대화 선택과 실제 작업을 구분한다. 짐 적재/정리·재고정·승하차·경유 용무는 안전 정차 때만 진행한다. 운행 중 재고정을 선택하면 정차할 때까지 남은 시간이 줄지 않는다. 음악·에어컨·창문 실제 조작은 보류한다.

## 요청별 기본 대사

효과/배점·약정 변경의 단일 기준은 [승객·요청 규칙](02-passengers-and-fares.md)과 실제 사전 표시다. 다음은 말투와 의도를 정리한 표이며 새 보상을 추가하지 않는다. ETA·요금·장소는 실제 데이터로 표시한다.

| 요청 | 승객 | 기사 선택/답변 | 표시할 결과 |
|---|---|---|---|
| 조용한 운행 | 조용히 운행해 주세요. | 조용히 모시겠습니다. | 후속 대사 줄임 |
| ETA | 도착까지 얼마나 걸릴까요? | 조금 빠른/현재 내비/여유 있는 예상으로 안내 | 선택한 예상 시간, 교통에 따라 변동 |
| 승차감 | 부드럽게 운전해 주세요. | 급하게 출발하거나 멈추지 않고 부드럽게 모시겠습니다. | 기존 요청 이행 평가 |
| 시간 | 제시간에 도착해 주세요. | 신호와 제한속도를 지키며 가겠습니다. 늦어질 수 있으면 안내할게요. | 기존 기한 유지, 위반/도착 관찰 |
| 큰길 | 골목 대신 큰길로 가 주세요. | 가능한 큰길로 모시겠습니다. | 큰길 경로 적용/하차 시 이행 평가 |
| 짧은 길 | 가능한 짧은 길로 가 주세요. | 짧은 길로 모시겠습니다. | 최단 경로 적용/하차 시 이행 평가 |
| 안전 하차 | 안전한 곳에 내려 주세요. | 확인한 승하차 장소로 목적지를 바꾸겠습니다. | 변경 장소/운임/남은 기한 사전 표시 |
| 공감 | 오늘 속상한 일이 있었어요. | 이야기 들어드릴게요. / 조용히 가실까요? | 응대 평가/후속 대사 줄임 |
| 경로 추천 | 어느 길이 좋을까요? | 빠른 길 / 짧은 길로 가겠습니다. | 선택 경로 적용 |
| 면접 | 잘할 수 있을까요? | 응원할게요! / 조용히 준비하시게 할게요. | 응대 평가, 면접 결과 보상 없음 |
| 음악 | 음악을 바꿔 주세요. | 지금은 음악을 바꾸기 어려워요. | 음악 변경 없음, 응대만 반영 |
| 요금 | 요금을 알려 주세요. | 처음 안내드린 요금은 {요금}원입니다. 최종 금액은 하차할 때 확인할게요. | 실제 약정 유지, 할인 없음 |
| 지역 대화 | 이 동네에서 오래 일하셨어요? | 주변을 다니고 있어요. / 안전하게 모셔다드릴게요. | 응대 평가, 운임/목적지 유지 |
| 목적지 변경 | 다른 지점으로 바꿔 주세요. | 확인한 승하차 장소로 목적지를 바꾸겠습니다. | 장소/약정 사전 표시 |
| 경유 용무 | 잠깐 용무를 보고 갈게요. | 약속한 장소에서 20초 기다린 뒤 원래 목적지로 모시겠습니다. | 정차 용무20초 무료, 영업시간/연료 소모 |
| 분실물 | 분실물을 발견하면 부탁드려요. | 보관·신고를 안내하겠습니다. | 기존 텍스트 사건, 반환 퀘스트 없음 |
| 불법 요구 | 빨간불이어도 가 주세요. | 신호는 지켜야 해요. 안전하게 모셔다드릴게요. | 안전 거절, 실제 운전 평가는 별도 |
| 보류/불가 | 위 요청 공통 | 지금은 요청대로 해 드리기 어렵습니다. 원래대로 모시겠습니다. | 만족도 변화0, 원래 운행 유지 |

## 유형별 대화

각 유형의 승차·중간·하차 변주는 기존 [유형 표](02-passengers-and-fares.md)를 유지한다. 아래 기사 선택을 모호한 `짧게 설명` 대신 사용한다.

| 유형 | 첫 번째 답변 | 다른 답변/추가 선택 | 효과 표기 |
|---|---|---|---|
| 일반 | 별도 유형 질문 없음 | 실제 요청만 응답 | 효과 없음 |
| 취객 | 불편하시면 말씀해 주세요. 천천히 가겠습니다. | 편히 쉬세요. 조용히 모시겠습니다. | 대화 자체 만족도0/후속 대화 정책 |
| 잠자는 승객 | 편히 주무세요. 도착하면 깨워 드릴게요. | 편히 쉬세요. 조용히 모시겠습니다. | 수면/도착 안내/후속 질문 줄임 |
| 승차감 민감 | 급하게 조작하지 않고 부드럽게 가겠습니다. | 말씀 감사합니다. 운전에 집중하겠습니다. | 자체 만족도0, 별도 요청 이행과 구분 |
| 재촉 | 내비 도착 예상 시간을 확인해 드릴게요. | 신호를 지키며 서둘러 가겠습니다. | 자체 만족도0, 기존 시간 요청과 구분 |
| 경로 확인 | 내비 경로를 확인하며 모시겠습니다. | 길이 달라지면 다시 안내해 드릴게요. | 자체 만족도0, 실제 경로 변경은 별도 요청 |
| 용무/경유 | 경유 요청을 확인하고 안내해 드릴게요. | 경유 약속은 별도 요청에서 확인할게요. | 유형 대화만으로 경유 약정 생성 안 함 |
| 많은 짐 | 안전하게 짐을 싣고 내려드릴게요. | 이번에는 짐 적재가 어려워요. | 적재10초/하역10초 또는 작업0초 |
| 흙 묻은 짐 | 보호 깔개를 준비할게요. | 그대로 적재 / 적재 불가 | 준비10초/추가 청결 감소0, 그대로는 하차 청결−5 |
| 음식/음료 | 밀봉해서 보관해 주세요. | 드셔도 괜찮아요. / 안전 정차 중 정리 | 선택지 즉시 효과·실제 섭취/흘림·안전 정리. 수치는 [02](02-passengers-and-fares.md)·[밸런스](../passenger-balance-v1.md) 참조 |
| 정밀 하차 | 안전한 승하차 장소를 확인해 드릴게요. | 보행자 통행을 막지 않는 곳에 세울게요. | 자체 만족도0, 실제 변경은 별도 요청 |
| 대화/반복 | 속상하셨겠어요. / 이 주변을 다니고 있어요. / 내비에서 남은 경로를 확인해 드릴게요. | 편히 쉬세요. 조용히 모시겠습니다. | 자체 만족도0/후속 대화 줄임 |

## 실제 운행 상황 응답

| 상황 | 승객 | 기사 답변 | 효과 |
|---|---|---|---|
| 적색 신호 장기 대기 | 신호가 오래 걸리네요. 왜 기다리는 건가요? | 지금은 빨간불이라 기다리고 있습니다. 신호가 바뀌면 출발할게요. | 효과 없음 |
| 필요한 제동 | 안전을 위한 제동이었군요. | 위험을 피하려고 속도를 줄였습니다. 주변을 확인하고 출발할게요. | 효과 없음, 추가 감점 없음 |
| 흔들림 | 방금 차가 흔들렸네요. 무슨 일이에요? | 차가 흔들려 불편하셨죠? 부드럽게 운전하겠습니다. | 효과 없음, 기존 운전 평가는 별도 |
| 잠에서 깸 | 방금 흔들려서 깼어요. | 놀라셨죠? 차가 흔들렸네요. 천천히 가겠습니다. 편히 쉬세요. | 응답 자체 만족도0, 기존 수면 상태 처리 |
| 음식 흔들림/흘림 | 먹던 음식이 흔들렸어요. / 흘렸어요. | 음료와 음식이 쏟아지지 않게 잡아 주세요. / 쏟은 음식은 안전한 곳에 멈춘 뒤 확인해 주세요. | 설명만으로 청결 추가 변경 없음 |
| 짐 흔들림 | 짐을 다시 고정할까요? | 안전한 곳에 멈추면 짐을 다시 고정하겠습니다. | 안전 정차 중5초/비용0원, 시간·연료 소모 |
| 조용한 응대 공통 | 위 상황 | 편히 쉬세요. 운전에 집중하고 꼭 필요한 안내만 드릴게요. | 만족도 변화0/후속 질문 줄임 |

## 조작 설명

`↑ 가속 · ↓ 감속 / 정차 후 후진 · ←/→ 조향 · Space 제동`을 기본 설명으로 쓴다. 조향 보조에서는 `←/→ 차로 변경`이다. 기존 WASD 입력도 유지하지만 UI의 대표 조작 표시는 방향키다.
