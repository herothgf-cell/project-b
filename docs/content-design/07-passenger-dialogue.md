# 승객 대화·요청·선택 기획

기준 2026-11-07. **승객 프리셋 → 요소 조합 → 주 행동/대표 요청 → 기사 선택 → 실제 효과** 순서로 관리한다. 기본24명 중23명 활성, 신규12명은 [요소별 승객표17](17-passenger-roster-v1.md). 요청의 발생/판정은 [02](02-passengers-and-fares.md), 개별값 편집은 [16](16-passenger-preset-overrides.md)을 따른다.

## 1. 대화를 만드는 요소

| 요소 | 기획자가 정하는 것 | 연결 대상 | 금지하는 혼동 |
|---|---|---|---|
| 승객 정체성 | 이름·소개·프리셋ID | 어떤 사정의 손님인지 설명 | 이름만으로 면접/경유 요청을 강제하지 않음 |
| 대화 성향 | 표준/조용함/대화 선호 | 일반 후속 대사와 수다 행동 | 조용함이 안전 경고를 없애지 않음 |
| 신체 상태 | 음주/졸림/승차감 민감 | 구토·기상/수면/편안한 운행 요청 | 음주와 졸림 특성을 중복하지 않음 |
| 목적 | 급함/경유/안전 하차 | ETA·정시도착/경유/하차장소 요청 | 유형 인사만으로 약정하지 않음 |
| 소지품 | 큰 짐/흙 묻은 짐/음식 | 적재·보호·섭취·흘림 | 짐을 거절해 놓고 적재 완료 대사를 하지 않음 |
| 대사 슬롯 | 소개/승차 변주/선택지/후속/요청/상황 | 각 조건에서 실제 표시할 문구 | 모든 변주를 한 운송에서 순서대로 재생하지 않음 |
| 효과 | 즉시/운행 중/종료·사건 수치 | 선택 장부/작업/차량 상태 | 대사만 바꿔서 새 행동이 생기지 않음 |
| 상속 방식 | 공통값 또는 프리셋 개별값 | 개별값 우선, 삭제하면 공통복원 | 0을 미설정으로 해석하지 않음 |

1차는 새 대화 트리/요청 생성기를 추가하지 않고 기존 슬롯에 승객별 문구와 효과를 작성한다. 대표 요청과 공통 후보 요청은 아래처럼 구분한다.

## 2. 요청의 연결 방식

| 연결 | 대상 | 실제 발생 조건 |
|---|---|---|
| 대표 요청 | 승차감 민감→Comfort, 급함→변주별ETA/OnTime, 경유→ViaStop, 안전 하차→SafeStop | 해당 노선 가용·요청슬롯 확보 시 연결 |
| 공통 대화 후보 | Quiet/Empathy/Interview/LocalChat/FareHelp 등 | 전체 요청 후보의 가용성·가중치에 따라 추첨 |
| 행동 선택 | 수면·음주·짐·음식·수다 | 선택된 승객의 실제 주 행동으로 표시 |
| 운행 상황 | 신호대기·흔들림·필요한제동 | 실제 관찰 사건 및 대화 제한에 따라 표시 |
| 제외 | ShortRoad, RouteAdvice | 이번 새 기본 구성에서 비활성/가중치0. 구 저장/사용자프로필 데이터는 보존 |
| 하차 후 | 분실물 | 운행 중 요청 슬롯과 별도 텍스트 사건 |

면접 손님에게 면접 대사를 넣었더라도 Interview가 항상 배정되는 것은 아니다. 수다 손님도 LocalChat이 배정되지 않으면 주 행동 대화만 한다. 짧은길·빠른길 경로 선택은 제외하고 큰길 요청과 ETA 안내는 유지한다.

## 3. 요청별 대사·선택·1차 효과

S=승객 만족도, F=기사 피로, M=운전 점수. 개별 승객 수치는17이 우선한다. 이 표는 공통값이며 표에 없는 운행중 점/분·비율은0. 모든 명시적 보류는 추가S/F0, 안전상 판정불가도0. 실제 미응답과 구분한다.

| 요소/요청 | 상대 가중치 | 승객 요청 | 기사 선택 | 1차 효과·실제 행동 |
|---|---:|---|---|---|
| 대화/Quiet |3| 잠깐 조용히 가고 싶어요. | 조용히 모시겠습니다 / 응대 어려움 안내 | 수락: 후속수다 제한·종료S+3. 안전한 응답기회 후 무시만 M−2 |
| 정보/ETA |2| 도착까지 얼마나 걸릴까요? | 내비보다 조금 이른 예상 / 내비대로 / 여유 예상 / 안내 보류 | 세 안내 각각 즉시S+1. 실제 경로·기한은 바꾸지 않음 |
| 신체/Comfort |3| 부드럽게 운전해 주세요. | 부드럽게 운행 / 요청 보류 | 성공S+6·실패−4. 불필요한 급가감속 M추가−1, 필요한제동 제외 |
| 목적/OnTime |2| 제시간에 도착하고 싶어요. | 규칙을 지키며 운행 / 요청 보류 | 성공S+6·위반 동반 실패−3. 합법 지연 판정불가0 |
| 경로/LargeRoad |1| 골목보다 큰길로 부탁드려요. | 가능한 큰길 이용 / 요청 보류 | 실제 경로 적용·성공S+5, 불가/중립0 |
| 목적/SafeStop |2| 안전한 곳에 내려 주세요. | 장소·요금 확인 후 변경 / 원래 목적지 유지 | 성공S+4·실패−4. 검증된 후보만 사용 |
| 감정/Empathy |2| 오늘 속상한 일이 있었어요. | 이야기 듣기 / 조용한 배려 / 보류 | 듣기 즉시S+3/F+1, 배려S+2/F0. 안전한 기회 무시S−2 |
| 목적/Interview |2| 면접이 긴장되네요. | 응원 / 조용한 준비 / 보류 | 즉시S+3 / +2. 미응답S−2. 면접 결과 보상 없음 |
| 환경/Music |1| 음악을 바꿀 수 있나요? | 지금 변경하기 어려움 안내 / 보류 | S/F0, 실제 음악조작 미구현 |
| 정보/FareHelp |2| 요금이 얼마나 나오나요? | 약정 요금 안내 / 하차 때 확인 / 보류 | 즉시S+2 / +1, 실제 할인 없음 |
| 대화/LocalChat |2| 이 동네는 어떤가요? | 짧은 대화 / 안전운행 안내 / 보류 | 즉시S+3/F+1 / S+2/F0. 미응답S−2 |
| 목적/DestinationChange |1| 다른 지점으로 바꿔 주세요. | 장소·약정 확인 후 변경 / 원래대로 | 성공S+4·실패−4. 임의 지도점 생성 없음 |
| 목적/ViaStop |1| 잠깐 용무를 보고 갈게요. | 장소·대기시간 확인 후 경유 / 원래대로 | 성공S+5·실패−4. 공통20초, 신규 복합손님15초 무료 대기 |
| 안전/RejectIllegal |1| 신호를 무시하고 가 주세요. | 안전하게 거절 / 요청 보류 | 안전거절 즉시S+1. 실제 위반은 법규/M 별도 평가 |
| 하차 후/LostItem |별도| 분실물이 있으면 부탁드려요. | 보관·신고 안내 | 기존 텍스트 사건, 반환 퀘스트/추가 선택 보상 없음 |

요청0/1/2건 비중은25/60/15%. 가중치는 현재 가용 후보 안의 상대 비중이며 각 행의 고정 발생%가 아니다. 음식/짐 선택과 별도 요청 효과는 함께 발생할 수 있다. 요청 종료 합계 상한±10, 최종S/F0~100은 유지한다.

## 4. 주 행동 선택의 역할

| 요소 | 선택A | 선택B / C | 실제 차이 | 신규 승객 예 |
|---|---|---|---|---|
| 일반/조용함 | 별도 유형 선택 없음 | 배정된 요청에만 답변 | 일반 운송·수다 억제 | 조용한 출근 손님 |
| 졸림 | 도착 안내 약속 | 조용한 배려 | 수면·기상 처리, 변주별 후속 조건 | 야간근무 손님:각S+1/진정6초 |
| 음주 | 불편 여부 확인 | 조용히 쉬도록 안내 | 음주 예정확률·기상, 대화가 구토를 치료하지 않음 | 조용한 귀가:각S+1/구토15%·기상지연40% |
| 승차감/급함/안전하차 | 요청 확인·안내 | 집중 운행 안내 | 유형 응답S0, 실제 약정은 별도 요청창 | 부드러운 운행·면접·안전하차 손님 |
| 대화 선호 | 짧은 이야기 듣기 | 조용한 운행 안내 | 신규 수다손님A S+2/F+1, B S+1/F0 | 동네 이야기·모임 후 손님 |
| 큰 짐 | 안전 적재·하역 | 적재 어려움 안내 | A만 작업과 시간 발생, B작업0 | 여행 가방:8/8초·A S+2, 짐용무:6/6초·A S+2 |
| 흙 묻은 짐 | 보호 후 적재 | 그대로 / 적재 거절 | 보호8초·S+1; 그대로 하차 청결−4; 거절작업0 | 화분 경유 손님 |
| 음식 | 밀봉 보관 | 허용 / 안전정차 정리 | 보관S+1; 허용S+2·섭취청결−1·흘림15%/추가−4; 정리6초·S0 | 간식 출근 손님 |

정체성 이름은 실제 구현되지 않은 행동을 보장하지 않는다. 새12명의 실제 문구·요소·개별값은 [17 상세표](17-passenger-roster-v1.md)와 제작 원본에 함께 기록했다.

## 5. 상황 대화와 입력

| 사건 | 안내·기사 응답 | 효과/우선순위 |
|---|---|---|
| 적색신호 장기대기 | 빨간불이라 기다리고 있으며 바뀌면 출발 | 추가S/F0 |
| 안전상 필요한제동 | 위험을 피하려 속도를 줄였다고 설명 | 추가S/F0, 필요한제동 예외 유지 |
| 흔들림 | 불편을 확인하고 부드러운 운행 안내 | 추가S/F0, 기존 실제 운전 평가 별도 |
| 수면 깨기 | 놀람 확인·다시 쉬도록 안내 | 수면 진정 시간과 실제 상태 사용 |
| 음식 섭취/흘림 | 안전한 곳에서 상태 확인 | 말만으로 청결을 복구하지 않음 |
| 짐 재고정 | 안전정차 후 고정 | 기존/신규5초, 시간·연료 소모 |
| 음주 구토 경고 | 불편 안내 후 기존 사건 진행 | 필수 경고 우선, 구토 min(청결,10)·하차 후 세차 |

대화는 운행 중에도 클릭/Y/I/O/U로 답변할 수 있다. 새 운행중 요청의 발생은 기존 안전정차·실제 주행20초·진행25~65% 조건을 유지한다. 일시정지/지도/결과/다른창/수면/도착잠금과 같은프레임 중복응답은 기존 우선순위다. 적재·정리·재고정·경유작업은 안전 정차 중만 진행한다. 음악·에어컨·창문 실제조작은 보류한다.

화면은 승객 대사, 기사 선택, 효과를 분리한다. 수치를 인물 대사에 쓰지 않고 작업 시간은 효과 안내로 보여준다(신규 경유 답변은 설정과 같은 15초를 명시하며, 대기시간 수정 시 답변도 함께 수정). 관리창에서 공통/개별값을 구분하며 **검증→저장→게임에 적용**, 다음 새 세션부터 반영한다. 기존 저장/사용자 프로필은 유지한다.
