# 맵·기본 주행·조향 보조·교통 기획서

2026-10-21 조작 보완: 가속 토크·상승 속도 완화, 저속42도 중심 조향·안쪽/바깥쪽 앞바퀴 각도 분리, 고속 안정성 한계 유지. 시작 임시 주차 지점은 넓은 국도42 외측 차로 쪽으로 변경한다. M키 큰 전체지도는 실제 경로/승하차/현재위치/법규 이름을 표시하며 열면 영업시간이 멈춘다. 미니맵은 +/− 키와 확대·축소 버튼으로 범위를 조절한다. 매너/운행 점수 게이지는 서로 독립이다.

기준일: 2026년 10월 16일 · 버전: 0.6 · 상태: 구현 6de26a5 및 검증 결과 대조

[로드맵](00-RoadMap.md) · [기획 총괄](README.md) · [운전 상황](01-driving-situations.md)

은계 기반 도로에서 짧은 택시 운송과 경로 판단을 반복한다. 특정 판단을 분명하게 보여주기 위한 가상 구간을 허용하며, 기존 구현과 이번 프로토에 필요한 추가 작업을 구분한다.

## 현재 구현과 검증 범위

은계 전체 도로망과 국도 42호선 차로를 공유해 내비·조향 보조·일반 차량을 운행한다. OSM 도로명·일방통행·회전 제한·횡단보도 대조 결과를 반영하고 보류/임시 시설을 구분한다. 추가 NGII 정밀자료는 대상 구역과 겹침이 없어 은계 시설 확인의 근거로 채택하지 않았다. NPC 24대 180초 및 신호 대기열 회귀 검사를 통과했다.

**남은 확인:** 미확인 차로 연결·규제·시설 현장 대조, 1인칭 시야·일반 차량이 있는 수동 주행이 남았다. 보조 운전의 가감속은 계속 사용자가 직접 한다.

근거: [통합 검증](../prototype-completion-validation.md) · [개발 체크리스트](../prototype-development-checklist.md). 아래 상세 표는 목표 설계를 포함하므로 표의 ‘포함’만으로 검증 완료를 뜻하지 않는다.

## 기본 주행·조향 보조·내비

| 기능 | 플레이어가 결정할 것 | 프로토에서 확인할 것 | 범위 밖 |
|---|---|---|---|
| 수동 주행 | 조향·가감속·정차·방향지시 | 두 핵심 상황과 거점 진출입을 수동으로 수행 가능 | 새 차량 종류·고급 차량 튜닝 |
| 조향 보조 | 경로·차로·회전 선택, 속도·신호·진행 판단 | 차로 유지·변경·회전 조향, 상태·불가 사유 안내 | 자동 신호 정지·자동 양보·충돌 회피를 보장하는 자율주행 |
| 내비 안내 | 목적지·경로 선택과 도로 상황 판단 | 빠른 길/짧은 길 비교, 놓친 출구 재탐색, 조기 회전 안내 | 안내만 따르면 항상 안전·적법하다는 보장 |
| 정체 비교 | 기다릴지 돌아갈지 선택 | 사전 예상 시간과 실제 소요·이동 거리 구분 | 가지 않은 경로의 결과를 확정 사실로 표시 |
| 보조 해제 | 도로 이탈·후진·연결 끝에서 직접 대응 | 해제·수동 전환과 직접 감속 필요를 이해할 수 있음 | 보조 시작 불가 상태의 강제 자동 복구 |
| 숙련 기록 | 플레이어가 수행한 판단 | 보조 사용 여부와 직접 결정한 행동 기록 | 보조가 대신한 행동을 플레이어 숙련으로 자동 인정 |

조향 보조는 신호 판단을 대신하지 않는다. 운전 선택과 [법규 평가](02-driving-evaluation.md), [승객 매너](04-passengers-and-reservations.md), [히스토리](03-history-and-mastery.md)는 각 기준으로 연결한다.

## AI 차량과 보행자

| 대상 | 필요한 행동 | 프로토 제안 범위 | 제외·확장 후보 |
|---|---|---|---|
| 출구 대기 차량 | 신호 대기·출발·앞차 추종·간격 유지 | 대기와 앞부분 진입의 결과가 보이는 최소 대기열 | 전 지역 교통 수요·출퇴근 시간 재현 |
| 직진·교차 차량 | 진행·정지·양보 조건과 출구 공간 확인 | 우회와 우회전 판단에 필요한 흐름 | 복잡한 운전자 성격·경쟁·보복 행동 |
| 택시에 반응하는 차량 | 진입에 따른 감속·정지 | 실제 위치·속도·간격에 따른 관찰 가능한 반응 | 선택마다 과장된 경적·일괄 제동 연출 |
| 핵심 보행자 | 보도 대기, 횡단 의도, 횡단 시작·완료 | 우회전의 ‘없음/건너려 함/건너는 중’을 구분하는 소수 보행자 | 도시 전역 자유 보행·군중·개인 생활 일정 |
| 승하차 승객 | 지정 위치 대기·탑승·하차 | 기존 승객 동선과 횡단 보행자 역할 구분 | 모든 승객의 장거리 보행 추적 |
| 재현·오류 처리 | 동일 조건 반복, 이상 반응 감지 | 시작 상태 기록, 상황 초기화, 잘못된 AI 반응은 법규 판정 보류 | AI 오류를 플레이어 위반으로 확정 |

차량 수와 보행자 수는 장면 가독성·성능·재현성을 기준으로 조정한다. 프로토에 보행자를 포함하는 목적은 우회전 판단 검증이며, 군중 규모가 완성 기준은 아니다.

## 운영 공간과 역할

| 공간 | 플레이 흐름 | 필요한 공간·표시 | 프로토 범위 | 결정·연결 |
|---|---|---|---|---|
| 주유소 | 내비로 이동 → 안전하게 진입·정차 → 주유 확인 → 운행 복귀 | 진출입로, 정차 구역, 연료·예상 비용·결제 결과 | 거점 이용과 비용 표시를 확인할 최소 기능 | 연료량·단가·차감 시점은 [경제 기획](05-daily-operation.md) |
| 식당 | 정차 → 식사 선택·비용 확인 → 운행 복귀 | 접근 동선, 정차 구역, 선택·결과 표시 | 하루 첫 식사 결제, 마감 식비와 중복 방지 | 비용·빈도·미방문 처리는 [05](05-daily-operation.md) |
| 주차장 | 안전하게 진입·정차 → 납부 관리·마감 또는 영업 복귀 | 진출입 경계, 주차 구역, 이용 안내 | 영업 거점·일일 주차비·보험 갱신·세금 납부 메뉴 | 요금·납부 일정·정산은 [05](05-daily-operation.md) |
| 수리 공간 | 사고 후 이동·수리 처리 후보 | 위치·입고 방식 미정 | 프로토 제외·기획만. 주유소·주차장의 프로토 기능에 수리를 추가하지 않음 | [사고·수리](08-accidents-and-repairs.md), [05 경제](05-daily-operation.md)와의 연결은 후속 |

거점 방문 때문에 장거리 이동이나 긴 대기를 강제하지 않는다. 비용의 숫자·적용 시점과 직접 관리하는 보험 갱신·세금 납부일은 [경제 기획](05-daily-operation.md)에서 정의한다. 사고 보험청구는 갱신 관리와 별개이며 프로토에서 제외한다.

| 배치 미확정 | 전용 구간의 정확한 위치·접근 방식, 거점 배치, 차량·보행자 규모 |
| 사용자 확정 | 3일·하루 12분·누적 순수익 30,000원, 보험·세금은 프로토 제외. 개인 예약·신규 사고 콘텐츠는 프로토 제외·기획만 |
| 후속 연계 | 수리 거점·사고 처리·예약 중단 연계는 [08 사고](08-accidents-and-repairs.md)와 [04 승객](04-passengers-and-reservations.md)에 후속 기획으로 유지 |
| 후속 확장 | 기타 면허시험 소재, 야간·기상, 전역 교통·보행자·군중 |

## 프로토 테스트 가독성 보완 (2026-10-16)

미니맵은 기본으로 차량 중심 650m 정사각 범위를 북쪽 고정으로 보여주고 M 또는 버튼으로 전체 지도를 전환한다. 내 차량은 큰 노란 방향 화살표, 선택 경로는 검정 외곽선이 있는 하늘색 선, 선택한 승차·도착 지점은 이름표로 표시한다. 화면 밖 목표는 지도 가장자리의 방향 표시로 유지한다. 임시/확인 시설은 별도 버튼으로 확인하여 경로와 겹치는 기본 표식을 줄인다.

전방 신호 안내는 차량 진행 방향·접근 차로 폭을 기준으로 최대 125m 앞의 신호를 선택한다. 실제 TrafficSystem 상태를 사용해 직진·좌회전 및 우회전 전용 상태를 색과 문자로 함께 표시한다. 비보호는 별도 문구로 구분하며 녹색을 주변 확인 없이 진행해도 된다는 뜻으로 사용하지 않는다. 3D 신호등 등화와 하우징을 확대하고, 우측 사이드미러는 미니맵·신호 패널과 겹치지 않도록 안쪽으로 옮긴다. 현장 규제 확인 여부는 그대로 유지한다.

## 프로토 검증 범위 정정 (2026-10-20)

캐주얼 그래픽·HUD 시안/리디자인, 실물 패드 및 새 PC 검증은 프로토 제외다. 기존 패드 입력 지원은 유지하고, 현재 PC 키보드 주행과 신호·보행자·내비를 읽는 데 필요한 기존 HUD 가독성 문제는 검증한다.

## 2026-10-21 도로 표시와 주유소 보완

- 로컬 노면 표시는 내비/일반 차량이 쓰는 실제 컴파일 차로 연결을 따른다. 반대 방향 사이 황색 중앙선·같은 방향 사이 백색 점선을 그린다. 완전한 편도2+2차로 구간22곳의144단면을 검사했다. 원본 정밀지도 표시는 유지한다.
- 교차로 개구부의 과도한 중앙선/경계 중첩을 잘라낸다. 실제 차로수가 확인되지 않은 연결은 여전히 임시이고 넓이만으로 실측 차로수를 확정하지 않는다.
- 도로에 겹친 건물 원본은 보존한다. 기존22개에 추가3개를 표시·충돌·도로면 조회에서 동일하게 제외했고 실제 차로24,974곳의 건물 충돌 검사를 통과했다.
- 은계북부·남부·동부 주유소는 빈 부지의 게임시설이다. 별도 입구/출구·주유 구역을 갖추고 공통 도로망으로 입구 앞까지 길 안내한다. 시설 내부는 H를 끄고 수동 운전한다. 자동 물리 주행으로3곳 진입·구매·출구 합류를 확인했다.
- 상세 위치·검증 경계: [작업 이력](../work-history/2026-10-21-road-facilities-and-operation.md). 전체 은계 현장 검증이나 수동 캠페인 완료를 뜻하지 않는다.


## 2026-10-21 지도·조작 변경

- **M**: 전체 지도 열기/닫기. Esc로도 닫으며, 이전 일시정지 상태를 복원한다. 지도 중에는 영업·승객 대기 시간이 흐르지 않는다.
- **+/−**(숫자패드 포함): 미니맵 확대/축소. 클릭 버튼도 동일한 300·450·650·1,000·1,500·2,300m 단계를 사용한다. 최대 범위는 은계 전체를 중심에 맞춘다.
- 전체 지도는 **주요 시설**, **교통 상황**, **교통 법규**의 세 필터를 독립적으로 켜고 끈다. 법규 7구역은 하나의 카테고리로 묶는다. 시설에는 주유소 3곳·식당·주차장, 교통에는 이동/대기 차량과 정체·정차 상황을 표시한다. 내 위치·승차·도착·현재 경로는 항상 남긴다.
- 호출 카드에는 경유 법규 상황 설명을 제거한다. 지도에 배치된 구역 이름과 실제 경유 경로는 유지한다. 승차하러 가는 동안 승객 대기 잔여 시간을 표시한다.
- R 및 패드 복귀 단축키는 제거한다. 차량이 맵 아래로 떨어지는 등의 자동 안전 복구는 유지하고, 새 캠페인은 일시정지 메뉴의 확인 절차로 시작한다.
- 전방 신호 안내는 시뮬레이션의 다음 신호 상태 변경까지 초를 표시한다. 접근에 의해 진행되는 교육 상황이나 점멸 조건은 고정 시간이 없다고 안내하며 임의 숫자를 만들지 않는다. 실제 현장 신호 예측 정보는 아니다.
- 운행 점수는 날짜·재실행에 유지하고 **새 캠페인에서 초기화**한다. 승객 매너와 별도로 표시한다. 상세 기준은 [운전 평가](02-driving-evaluation.md)를 따른다.

검증은 현재 작업의 플레이어 UI 검사(1280×720·1600×900·1920×1080), 필터 실제 표시 목록·축척 경계·모달 시간 정지 확인으로 수행한다. 수동 플레이와 현장 시설 대조는 별도다.

## 2026-10-21 교통 표시 보완

- 은계 일반 차량 목표를 24대에서 36대로 확대한다. 공유 차로 연결·신호·차간 대기 판단은 유지한다.
- 전방 신호의 다음 색 변경까지 초를 실제 게임 신호 주기에서 계산한다. 접근 후 유지되는 시나리오 신호는 가짜 카운트다운 대신 조건 진행 안내를 표시한다.
- 신호 접근로에 간략한 횡단보도 표지와 비보호 설정 시 좌회전 표지를 표시한다. 도로 밖 배치·충돌체 제외, ‘게임 설정’ 표기로 현장 시설과 구분한다.
- 실제 표지로 확정하려면 교차로 ID/접근 방향, 표지 종류·위치·사진 또는 정밀지도 속성, 촬영/자료 기준일, 신호 운영 방식이 필요하다. 데이터가 없는 지역을 실제 시설이라고 표시하지 않는다.

## 전체지도 탐색·교통 밀도 보완 (2026-10-21)

M 전체지도는 +/- 버튼·키·휠로 1~8배 확대/축소하고 드래그로 이동한다. 내 위치 버튼은 현재 배율에서 택시를 중심으로, 전체 보기는 1배로 복원한다. 도로·경로·표시물이 같은 변환을 사용하고 지도 밖 그림은 잘라낸다. 기존 필터와 일시정지는 유지한다. 일반 차량은 36→48대로 늘려 전체 도로에서 운행하며, 신호·차로 연결은 기존 공통 정보를 사용한다. 흰색/베이지 건물 메시와 정체 차량을 구분한다. 건물의 실제 외관은 재현하지 않는다.

## 비보호 안내·지도 정비 (2026-10-21)

게임 설정상 비보호인 신호에 기존 도로 표지 크기를35% 키우고, 우측 신호 안내에 강조선과 녹색/대향차 양보 문구를 표시한다. 실제 비보호 여부를 새로 확정한 것은 아니다. 도로 다듬기는 구간별 도로폭/차선→교차로 곡선/정지선→인도/건물 침범→표지/외형 순서. 지도 원본은 유지하고 출처·확인일·실제/임시 구분을 가진 별도 보정 데이터로 관리한다.

## 2026-10-21 선택형 앞차 추종 보완

일반 차량의 기존 차로·신호·예약·안전거리 제동에 MIT 샘플의 같은 방향 앞차 속도 조절을 추가한다. Esc 메뉴 `앞차 추종 보완: ON/OFF`, 최초 ON, 선택 저장. OFF는 기존 AI로 복귀한다. NPC 재생성·경로 초기화 없이 반영하며 택시 조작과 법규 채점은 변경하지 않는다. 샘플 차량 모델·후진 회피·차로 변경은 도입하지 않는다. [선별 범위·출처·설정](../mit-traffic-following.md), [검증 이력](../work-history/2026-10-21-mit-traffic-following.md).

## 미니맵 정보량 조정 (2026-10-21)

기본 미니맵은 현재 위치·경로·승차 사람 기호·도착 깃발을 우선한다. 법규 상황의 긴 이름표 대신 좌회전 화살표/대기열/신호 기호를 표시하며, 화면 밖 목표에는 방향 화살표를 붙인다. 내 위치는 테두리 있는 노란 방향표로 강조한다. 상세 표시를 켜거나 M 전체지도를 열면 기존 상황 이름과 시설 정보를 볼 수 있다. 맵 정비 계획은 사용자 검토 중이며 이번에는 지도 형상·차로·시설 위치를 변경하지 않는다.
