# 승객 운송과 매너 및 요구 콘텐츠

## 2026-10-22 변경 · 승하차 비상등과 결과 대화

승차·하차 성공 시 양쪽 비상등을 켜고 출발(속도1m/s 초과)하면 자동 종료한다. G키로 직접 켜고 끌 수 있으며 Q/E 회전 선택 시 비상등을 해제한다. 운송 완료 팝업은 출발/도착, 만족도, 운행 시간, 요청 결과, 기본 운임·감사 보너스·합계를 표시한다. 팝업에서는 운송/영업 시간을 멈추고 다음 호출 수락을 막는다. 운행 점수는 승객 만족도와 별도다.

승차·하차는 상황 구역 통과 여부와 무관하다. 교통 상황은 실제 목적지까지 자연스러운 경로에서 만날 수 있는 콘텐츠이며 필수 경유지/점수 획득용 내비 목적지로 지정하지 않는다. 9코스·17요청은 유지한다.


기준일: 2026년 10월 22일 · 버전: 0.9 · 상태: 승객 DR/CH/EV 및 요청별 효과 구현·자동 검증 / 수동 체감 후속

승객은 목적지와 간단한 요구를 제공한다. 승객 만족도는 이번 운송의 만족 조건이며, 누적 운행 점수와 별도로 평가한다. 아래 신규 수치는 게임용 조정 초깃값이다.

**2026-10-21 별도 기획:** [프로토 시나리오](09-prototype-scenarios.md)에 승객별 승차·하차 위치와 경로상의 법규/선택 상황 9코스를 추가했다. 기존 조용한 운행·도착 문의, 완료 운송 수에 따른 요청 교대, Y 수락·U 안전상 보류를 유지한다. 아래 DR/CH/EV 확장과 분리하며 코스 제작의 선행 조건으로 요청 확장을 요구하지 않는다. 코스 구현·검증 상태는 해당 문서와 최신 작업 이력을 따른다.

## 현재 구현과 검증 범위

조용한 운행/도착 문의와 DR01~05·CH01~06·EV01~04 요청, 수락·안전상 보류, 완료/목적지 도착 후 시간 초과 결과 저장과 탑승 중 연료 지원을 구현했다. 운송별 핵심 요청은 1개이고 완료 운송 수에 따라 17종을 순환한다. 안전한 응답 기회를 놓친 조용한 운행 요청 외에는 미응답·보류를 추가 감점하지 않는다. 지급액·요구/최종 매너·감점 이유·응답 결과를 기록하며 운송 ID로 중복 기록을 막는다. 마감 시 미탑승 취소와 마지막 탑승 운송의 원래 기한 유지도 검사했다.

**남은 확인:** 위험 회피 급제동의 실제 주행 맥락과 합법적 대기 시 운송 기한 밸런스는 추가 검증이 필요하다. 개인 예약·단골은 계속 기획만 유지한다.

근거: [통합 검증](../prototype-completion-validation.md) · [개발 체크리스트](../prototype-development-checklist.md). 아래 상세 표는 목표 설계를 포함하므로 표의 ‘포함’만으로 검증 완료를 뜻하지 않는다.

## 운송 흐름과 예외

| 순서 | 플레이어 행동 | 결과·예외 |
|---|---|---|
| 선택 | 호출 3개 또는 길가 승객의 목적지·요금·기한·매너 요구 확인 | 수락 전 거절 무료, 동시 운송 불가 |
| 픽업 | 안내된 방향·위치에 정차 후 승차 | 호출 수락부터 별도 대기 시간 시작. 기한은 최대값(180초, 픽업 경로 거리/3 + 180초). 초과 시 빈차 호출만 취소, 운임 없음. 주행 중·반대 방향 탑승 불가 |
| 운송 | 경로 선택, 승객 요청 대응 | 탑승 때 매너 100점 및 운송 제한 시간 시작 |
| 하차 | 목적지의 지정 위치에 정차 | 지급액과 감점 이유, 법규 기록을 서로 다른 카드로 표시 |
| 시간 초과 | 승객 탑승 유지, 목적지 하차 후 실패 정산 | 운임 0원. 해당 운행 비용은 유지. 픽업 대기 기한과 별도 |
| 연료 고갈 | 탑승 중이면 현재 위치에서 20% 공급·같은 운송 유지 | 1,800원·30게임초 경과. 기존 운송 ID·내비·기한 유지. 미탑승 호출은 취소하고 출발지 복귀 |
| 영업 마감 | 신규 수락 중단 | 미탑승 호출 취소, 탑승 임무는 완료 또는 시간 초과 후 정산 |

기한은 상황별 정상 운전과 대기를 포함해 달성 가능하도록 조정한다. 기존 시간 초과 0원 규칙을 유지하되 합법적인 대기로 실패가 반복되는 코스는 기한·거리·교통을 먼저 보정한다. 운행 점수로 시간을 연장하거나 운임을 깎지 않는다.

연료 고갈의 공급량·지원 비용·마감 경계는 [경제 기획](05-daily-operation.md)을 따른다. 연료 고갈 지원은 프로토에 포함하는 운영 예외이며, 사고 수리 콘텐츠와 구분한다. 승객 탑승 중에는 하루 시간이 끝나도 목적지 하차까지 운송을 유지한다.

## 매너 감점표

‘기존’은 기존 감점 값이며 요청 감점은 현재 추가 구현된 값이다. 같은 사건은 지속되는 동안 반복 감점하지 않으며 위험 회피·원인 불명 장면은 맥락을 확인한다.

| 요청 | 제공 방식 | 처리 | 완료 피드백 |
|---|---|---|---|
| 조용히 가고 싶어요 | 운송당 최대 1회 후보 | 간단 수락으로 조용한 모드 표시. 라디오 전체 기능은 불필요 | ‘조용히 운행하겠습니다’ |

최대 1회는 요청 종류별 제한이 아니라 운송당 상호작용 요청 1개를 뜻한다. 재촉 대사는 핵심 판단 장면을 가리지 않는 빈도로 제공한다.

## 승객 요구 확장 (2026-10-19 기획 · 2026-10-21 프로토 적용)

기존 요청을 확장해 실제 수락·경로 적용·목표 결과를 구현했다. `Y`는 안전 정차 상태에서 응답/표시 조건 확정, `U`는 안전상 보류(원래 운행 유지)다. CH01/03은 `I`로 조용한 배려, CH02는 `I`로 짧은 길, CH06은 `I`로 안전 운행 안내 대안을 선택할 수 있다. 교차로 중심에서 교차로 반폭+12m 안쪽이거나 움직이는 동안 대화창을 숨기며 응답 시간을 벌주지 않는다. 운송당 요청 1개, 매너 지급률 100%/70%, 시간 초과 0원은 유지한다. 운행 점수와 승객 만족도는 별도로 기록한다. 운행 점수는 날짜 변경·재실행에도 누적 유지하고 새 캠페인에서 초기화한다. 요청 버튼 응답만으로 운행 점수를 올리지 않는다.

**응답 범위:** CH01/03/06은 짧은 배려 대사, CH02는 Y 빠른 길/I 짧은 길과 ETA를 실제 내비에 적용한다. CH04는 음악 변경 텍스트만, CH05는 현재 약정/기존 지급률 안내만 제공하며 실제 오디오·할인·미수금은 없다. EV04는 불법 요구 거절만 가능하다. EV03은 하차 후 분실물 발견·보관/신고 안내를 원래 운송 ID의 `:lost-item` 후속 텍스트로 기록하며 물품·반환 퀘스트·보상을 생성하지 않는다.

**목표 결과:** DR01은 해당 운송의 급가속·급제동·충돌 횟수(기존 위험 회피 예외 적용), DR02는 하차 시 기한과 운전 위반 건수, DR03은 안내 대비 실제 큰길 주행 비율, DR04는 안내 대비 실제 이동 거리, DR05는 변경한 지정 승하차 위치에 실제 하차했는지를 기록한다. 요청 목표 미달 자체로 기본 주행 감점에 추가 감점을 더하지 않는다. 큰길은 현행 게임 도로 폭12m 이상이며 실제 규제를 확인했다는 뜻은 아니다. 큰길 요청은 연결 경로에 큰길 후보가 있을 때만 제공한다.

**목적지·경유 정책:** DR05/EV01/EV02는 기존 필수 상황을 완료한 뒤 안전한 기존 승하차 지점으로만 변경할 수 있다. 확정 전에 추가 거리·새 약정·남은 기한을 표시한다. 추가 거리는 기존 남은 합법 경로 대비 양의 증가분이며, 약정은 `기존 요금 + 추가거리×4원을 100원 단위 올림`, 기한은 `기존 남은 시간 + 추가거리/4 + 30초`다. 목적지가 가까워져도 이미 약정한 요금을 몰래 내리지 않는다. Y 확정 한 번만 적용하며 동일 운송 ID를 유지한다. 경유지는 F로 실제 정차 확인하고 원래 목적지로 안내하며, 경유 중에도 운송 제한 시간이 흐른다. 별도 경유 할증은 없다. 하차 감사 보너스는 새 기획이며 추가 거리 약정 운임과 별도 항목으로 정산한다.

|---|---|---|---|---|
| DR01 승차감 | “차멀미가 심해요. 부드럽게 운전해 주세요.” | 가감속·제동을 안정적으로 제어. 기존 `DrivingManners`의 급가속·급제동·충돌 판정 활용 | 운송 중 불필요한 급가감속·충돌 최소화. 돌발 위험 회피의 필요한 급제동은 실패로 취급하지 않음 | 부드러운 운행 달성/미달 표시. 신규 만족도·감사 보너스는 [11](11-passenger-request-effects.md) 기준 |
| DR02 정시 도착 | “급해요. 최대한 빨리 가 주세요.” | 내비의 빠른 길/짧은 길 비교 후 합리적인 경로 선택 | 기존 운송 제한시간 내 도착 및 법규 준수. 위반·위험 운전으로 시간을 벌도록 보상하지 않으며 신호 대기·우회 감안해 기한 조정 | 정시 도착 결과와 만족도 표시. 신규 감사 보너스는 합법적 정시 도착 때만 후보 |
| DR03 큰길 선호 | “골목길 말고 큰길로 가 주세요.” | 공유 차로 그래프의 큰길 우선 비용 적용 (폭12m 미만 구간 비용4배) | 경로 그래프상 큰길 후보가 있는 경우에만 출현. 현실 도로 규제 미확인 구간은 확정적으로 안내하지 않음 | 선호 경로 이행/불가 안내를 운송 결과에 기록 |
| DR04 짧은 길 선호 | “골목길이어도 괜찮으니 짧게 가 주세요.” | 짧은 길 선택을 우선 검토 | 합법·주행 가능한 도로만 사용. 좁은 길·일방통행·회전 금지 불확실 구간을 임의 통과하지 않음 | 경로 선택 결과와 승객 반응 |
| DR05 안전 정차 | “여기서 바로 세워 주세요!” | 안전한 정차 지점 탐색 후 하차 제안 | 교차로·횡단보도·통행 방해 등 위험한 곳에서는 즉시 정차 요구를 거절하고 가까운 안전 지점을 안내 | 안전 정차 선택은 감점 없음; 실제 지정 하차 지점 변경·동일 운송 정산 |

**평가 경계:** DR03은 경로 안내의 큰길 비율 대비 실제 비율을 15%포인트 허용 오차로 비교하고, DR04는 안내 거리의 125%+30m 이내를 참고 목표로 사용한다. 합법적인 우회로 목표를 놓쳐도 별도 감점하지 않고 실제 거리·비율을 설명한다. DR05는 아무 곳에서나 하차할 수 있는 기능이 아니다.

### 2. 대화와 편의에 관한 요구 (CH)

대화 선택은 실제 운전 중 긴 텍스트 입력을 요구하지 않는다. 짧은 선택지 2~3개와 자동 응답 문구를 제공하고, 복잡한 선택은 안전 정차 시에만 허용한다. 대화는 승객을 인간적으로 느끼게 하는 짧은 연출이며 관계도/단골 시스템을 이번 절에 도입하지 않는다.

| ID | 승객 대사/요구 | 응답 선택지 예시 | 설계 결과·주의점 |
|---|---|---|---|
| CH01 고민 이야기 | “오늘 속상한 일이 있었어요.” | “무슨 일 있으셨어요?” / “조용히 가실까요?” | 공감 또는 조용한 응대 모두 존중. 대화 강요·침묵 페널티 없음 |
| CH02 길 추천 | “어느 길로 가는 게 좋을까요?” | “빠른 길” / “짧은 길” | 현재 내비의 ETA·거리 비교와 연계. 제안 후 안내한 경로 적용 여부를 명확히 표시 |
| CH03 면접 응원 | “오늘 면접인데 잘할 수 있을까요?” | “응원합니다!” / “조용히 준비하실 수 있게 운행할게요.” | 짧은 격려/배려 대사와 종료 반응. 합격 여부 등 외부 결과를 게임이 단정하지 않음 |
| CH04 음악 변경 | “라디오 음악 좀 바꿔 주세요.” | “바꿔 드릴게요.” / “안전한 때에 조절할게요.” | 초기에는 텍스트 반응만. 실제 오디오·선곡·라디오 UI는 별도 구현 이후에만 연동 |
| CH05 요금 부족 | “택시비가 조금 부족한데요.” | “요금 안내해 드릴게요.” / “가능한 결제 방법을 확인해 볼게요.” | 현재 약정 운임·지급률을 임의로 바꾸지 않음. 할인/미수금은 별도 경제 기획 및 동의 흐름 결정 후 개발 |
| CH06 동네 대화 | “이 동네에서 오래 일하셨어요?” | “이 근처는 익숙해요.” / “안전하게 모셔다드릴게요.” | 게임 내 지역 대사만 사용. 실제 현장 지식이나 사실 미검증 정보를 보장하지 않음 |

**대화 규칙:** 기본 승객 요청이 이미 진행 중이면 새 대화창을 중첩하지 않는다. 진행 중 대화는 교차로·회전·긴급 제동 등 운전 집중 구간에선 자동 연기하며, 응답 지연 자체를 감점하지 않는다. 응답 선택이 승객 취향과 다르더라도 법규 위반 또는 매너 위반으로 환산하지 않는다. 음악·창문 등의 차량 조작은 현행 프로토 범위 밖이다.

### 3. 운행 도중 발생하는 돌발 요청·사건 (EV)

| ID | 사건 트리거 / 승객 대사 | 플레이어 선택 | 상태·경로·운임 처리 방향 | 예외·완료 피드백 |
|---|---|---|---|---|
| EV01 목적지 변경 | 운행 중 “다른 곳으로 목적지를 바꿀 수 있을까요?” | 새 목적지 수락 / 원래 운행 유지 제안 | 수락하면 목적지·경로·ETA·약정 요금을 확정 후 재계산하는 기능. 변경 전후 조건을 승객/운전자에게 확인 | 접근 불가 목적지·마감 충돌 시 거절 가능, 위반 없이 거절하면 감점 없음. 변경 내역은 같은 운송 ID에 기록 |
| EV02 중간 경유 | “약국에 잠깐 들렀다 가 주세요.” | 경유 수락 / 경유 불가 안내 | 안전한 경유 정차 지점, 추가 거리·시간·요금의 사전 안내 필요. 경유 중 운송 상태를 유지하는 단계 신설 | 경유 중 시간 정지·무료 연장 자동 적용 금지. 위 사전 안내·확정 정책 적용 |
| EV03 분실물 | 하차 뒤 지갑 등을 발견하거나 다음 손님이 분실물 발견 | 분실물 보관·신고 / 안전한 전달 절차 안내 | 이전 운송 ID와 연결되는 별도 후속 사건 식별자를 가진 텍스트로 기록. 새 탑승/운임 중복 지급 없이 진행 | 기본 구현에서는 실제 물건·인벤토리/반환 경로 없음. 향후 보상·후속 퀘스트 검토 |
| EV04 불법 요구 | “빨간불이어도 그냥 가 주세요.” | 안전을 이유로 거절 / 정차 후 설명 | 불법 요구를 수락 가능한 운전 미션으로 만들지 않음. 실제 교통 위반은 기존 별도 운행 점수 관찰기가 판정 | 거절·안전상 보류는 감점 없음. 무리한 운전에 추가 보상을 지급하지 않으며 승객 대사와 법규 판정 분리 |

**돌발 이벤트 원칙:** 한 번에 처리 중인 요청 또는 돌발 이벤트는 하나만 노출한다. 기본 호출·승하차·운송과 충돌하거나 영업 마감이 임박하면 이벤트를 생성하지 않거나 안전하게 종료한다. 분실물 후속 사건은 기존 운송 결과를 수정하지 않으며, 별도 ID로 추적한다. 수락/거절 이후 상태를 저장·복구할 때 중복 요금·중복 이벤트가 발생하지 않도록 한다.

### 요구 콘텐츠 공통 운영·검증 기준

| 항목 | 권장 규칙 / 검증 항목 |
|---|---|
| 표시 시점 | 탑승 직후 또는 주행이 안정된 순간에 짧은 대사 표시. 교차로·좌우회전·위험 발생 중 팝업 확대 금지 |
| 응답 방식 | 기존 `Y` 수락·`U` 안전상 보류 호환을 우선. 다지선다 선택은 안전 정차 또는 간단 입력으로 제한 |
| 요청 빈도 | 초기 확장 검증은 **운송당 핵심 요청 1개**를 유지. 돌발 상황의 추가 출현 빈도는 플레이테스트 후 결정 |
| 성공 판정 | 운송 목표와 요청 목표 분리. 합법적 대기·위험 회피 급제동·정당한 거절을 실패로 잘못 판정하지 않음 |
| 보상 | 현행 기본 약정 운임 100%/70%, 기한 초과 0원 유지. 할인·별도 경유 할증 없음. 새 기획의 감사 보너스는 [11](11-passenger-request-effects.md)처럼 기본 운임과 분리 |
| 기록 | 운송 ID, 요청 ID, 유형, 발생 시점, 수락/거절/보류, 판정 근거와 완료 결과를 운송 결과의 요청 문자열에 기록. 법규 기록은 독립 |
| 프로토 회귀 | 기존 요청 2종, 안전상 보류 무감점, 요청의 중복 확정 방지, 3일 경제·정산·저장, 기본 경로 및 승하차 동작 유지 |
| 검증 상태 | C# 요청 모델19묶음 회귀 통과. Unity 통합/실제 수동 운행은 최신 작업 이력에서 구분. 전체17종 수동 운행은 추가 밸런스 확인 대상 |

**후속 제외:** 실제 음악/라디오, 할인·미수금 경제, 분실물 인벤토리·전달 운송, 단골·예약은 이번 확장에 포함하지 않는다. 감사 보너스는 P5-04 신규 개발 항목이며 아직 적용되지 않았다. 구현 범위 안의 요청을 실제 운송에서 반복 검증하고 대사 빈도·거리 허용값을 조정한다.

## 매너 실패와 보상

| 종료 상태 | 지급 | 다른 결과 |
|---|---:|---|
| 기한 내 완료·매너 요구 이상 | 약정 운임 100% | 운송 완료 |
| 기한 내 완료·매너 요구 미달 | 약정 운임 70% | 부족 점수와 주요 감점 이유 표시 |
| 매너 0점이지만 기한 내 완료 | 약정 운임 70% | 자동 게임오버·추가 벌금 없음 |
| 시간 초과 | 0원 | 기존 처리. 중복 미달 페널티 없음, 이미 발생한 비용 유지 |
| 연료 고갈 지원 | 운임은 도착 결과대로 | 탑승 중에는 같은 운송·위치·내비 유지. 지원비·30초만 추가. 시간 초과여도 목적지 하차 후에만 0원 종료 |
| 하루 정산·다음 승객 | 해당 없음 | 법규 히스토리 유지, 승객 만족도는 다음 탑승 때 초기화 |

예시: 약정 5,000원·요구 70점에서 신호 -12, 충돌 -10, 양보 -8이면 70점으로 5,000원 지급한다. 별도 급제동 -4가 적용되면 66점으로 3,500원 지급한다. 법규 사건 기록은 별도로 남는다. 원 단위 절사는 기존 정수 계산을 따른다.

## 단골과 개인 예약의 후속 기획

단골·개인 예약은 사용자 결정에 따라 이번 프로토에서 제외한다. 아래 표는 후속 개발을 위한 설계이며 현재 기능이나 프로토 완료 조건이 아니다. 연락 동의·제안·알림은 가상 승객과 게임 안에서 주고받는 연출이며 실제 연락처 수집이나 외부 메시지 전송을 뜻하지 않는다.

| 단계 | 진입·표시할 정보 | 플레이어 선택 | 다음 상태·관계 피드백 |
|---|---|---|---|
| 일반 승객 운송 | 기존 목적지·매너 요구·간단 요청 | 기존 호출 또는 길가 운송 수행 | 완료 결과와 요청 대응을 기록. 한 번의 운송으로 단골을 확정하지 않음 |
| 재이용·선호 확인 | 다시 만난 승객의 게임 내 이름·이전 요청·선호 | 기억한 선호에 응답, 현재 운송 우선 | 승객이 재이용 의사를 보이는 관계 단계로 연결. 발생 빈도·조건은 미정 |
| 예약 연락 동의 | 승객의 게임 내 예약 제안 수신 요청 | 동의 또는 거절. 나중에 수신 중지 가능 | 동의한 관계에만 개인 예약 후보 생성. 거절 자체로 기존 운임·매너·운행 점수를 깎지 않음 |
| 예약 제안 | 희망 날짜·픽업 시간 범위·장소·목적지·예상 운임·선호 | 조건과 현재 일정을 확인 | 수락 전에는 약속이나 점유 시간으로 확정하지 않음 |
| 수락·거절 | 이동·예상 운송 시간과 필요한 여유 | 수락, 거절, 조건 변경 제안 | 수락해야 예약 확정. 거절은 무료를 기본 제안으로 두고, 변경은 승객의 게임 내 재동의 후 확정 |
| 시간 충돌 확인 | 현재 운송·기존 예약·마감 시간과 겹침, 예상 지각 | 신규 제안 거절 또는 확정 전 시간 변경 | 다른 예약을 몰래 취소하거나 강제 중복 수락하지 않음. 예약 후 교통 지연이 생기면 지연 안내·변경·취소 선택 |
| 픽업 접근 | 약속 시간 범위·안내 경로·대기 장소 | 안전하게 이동·정차, 필요하면 지연 안내 | 수락 시각과 도착 시각을 구분. 신호 위반을 전제로 한 기한을 설정하지 않음 |

## 2026-10-21 매너 변화 안내

승객 만족도 변화는 상단에서 부호·이유와 함께 잠깐 나타났다 사라진다. 새 승객 탑승 때100점으로 돌아가는 것은 획득 보상이 아니라 초기화라고 표시한다. 승객 요청 응답 버튼만으로 매너·운행 점수·팁을 임의 지급하지 않는다.

## 자유 하차·승객 말풍선 (2026-10-21 변경)

탑승 후 교육/교통 상황 구역의 미체험은 목적지 하차나 운임 지급의 차단 조건이 아니다. 목적지·진행 방향·정차 속도와 운송 기한·매너 요금 정책은 유지한다. 미체험은 평가 기회 없음(0점), 이미 관찰한 위반/준수는 그대로 유지한다. 승객이 별도로 요청하고 수락한 실제 경유 정차는 계속 필요하다. PS01/02도 승차 전 상황 조건 없이 탑승한다.

요청은 좌측 말풍선의 손님 대사와 답변 결과로 표시한다. 안전 정차에서 Y/I/U 응답, 주행 중에는 요약과 안전상 보류 안내만 표시한다. 경유/목적지 변경은 새 약정 운임·남은 시간·장소를 보여주며, 일반 대화는 운임/목적지 유지라고 명시한다.

## 호출과 운행 중 대화 분리 (2026-10-21 정정)

호출 카드에는 승객 요청을 미리 보여주지 않는다. 목적지·요금·기한·매너 요구 점수·연료 예측은 유지한다. 요청은 탑승 후에만 손님 대사로 나온다. 내 답변도 실제 선택 결과의 대화로 표시하며 DR/CH/EV 같은 내부 코드는 숨긴다. 불법 요구 응답은 명확하게 신호 준수를 설명하고, 일반적인 수락 문구를 잘못 보여주지 않는다. 변경되는 장소·요금·기한과 유지되는 조건은 별도 줄로 안내한다.

## 하루20분과 운전자 연계 기획

기존9코스·17요청을 재사용하며 [하루 캠페인](07-campaign.md)에 맞춰 길이·기한·노출을 조정한다. [운전자](10-driver-condition.md)의 피로100은 신규 수락·승차를 제한하고 미탑승 호출은 취소한다. 탑승 중이면 현재 운송·기한을 유지하고 목적지 하차 후 휴식을 안내한다. 식사·수면은 빈차로만 이용한다. 포만감·피로 수치 자체로 매너·요금·법규 점수를 바꾸지 않는다. 이 연결은 신규 기획이며 아직 구현되지 않았다.

### 2026-10-21 승차·보도 정정

승차 전에는 목적지의 교통 상황을 먼저 통과하도록 요구하지 않는다. 대기 승객은 차로 중심 기반 임시 섬 대신 전체 도로 노면 바깥의 검증된 오른쪽 보도에 배치한다. 차량의 정차 차로·방향·저속 판정은 유지하여 내비와 같은 위치에서 F로 승차한다.

### 하루20분 운전자 연결 (2026-10-21)

피로100에서 미탑승 호출을 취소하고 호출 수락·길가 승차를 차단한다. 탑승한 승객은 원래 기한으로 목적지까지 유지하며 컨디션으로 매너·운임을 감점하지 않는다. 기존9코스·17요청과 상황 미체험 승하차를 유지한다. 호출 카드에 교통 상황 설명 대신 예상 운송 후 피로·마감 초과 가능성을 표시한다. 추정은 교통에 따라 달라진다.

## 요청별 효과·피드백 보완 기획 (2026-10-22)

현재 17종 각각의 `선택지 → 실제 적용 효과 → 주행 중 안내 → 하차 후 만족도·보너스`는 [요청별 효과 기획](11-passenger-request-effects.md)에 정리했다. ETA 문의의 세 가지 답변, DR01 멀미 요청 수락 뒤 급가감속 매너 감점 강화, DR/CH/EV 하차 만족도와 **요구 점수 초과분에 비례한** 소액 감사 보너스는 새 기획이며 아직 구현되지 않았다. 기존 단일 ETA 안내·기본 급가감속 점수·현행 100%/70%/0원 운임과 구분해서 읽는다. 대사 선택만으로 보너스나 법규 점수 변경은 없다.


## 2026-10-21 자연 운송 경로 정정

교통 상황은 승하차나 내비 경유지가 아니다. 일반 목적지 경로 위 상황만 선택·배치하며 미체험 상태에서도 승차/하차와 목적지 변경 요청이 가능하다. 실제 진행 중인 상황 관찰과 선택 패널 중에는 안전상 경로 변경 응답을 보류한다. 승객이 요청하고 수락한 중간 정차만 별도 경유 기능으로 유지한다.


## 2026-10-22 픽업 접근 여유

호출 정렬과 픽업 기한은 현재 진행 방향의 실제 도로 경로를 함께 사용한다. 직선상 가까워도 일방통행/우회 때문에 먼 호출은 낮게 배치한다. 픽업 기한은 max(180초, 실제 경로거리/3+180초)로 조정한다. 첫1.72km 접근에서558초 만료된 자동 주행을 근거로 한 게임 테스트 값이며 도착 보장이 아니다. 승차 후 기한과 강제 상황 경유 금지는 유지한다. 검증 결과는 [작업 이력](../work-history/2026-10-22-day-access-balance.md)을 따른다.

## 2026-10-22 요청 효과 구현·만족도 용어 적용

최신 구현은 [11 요청 효과](11-passenger-request-effects.md)의 ETA 세 선택(Y 빠르게/I 기준/O 여유), DR01 수락 뒤 불필요한 급가감속 -4점 대체, DR/CH/EV 하차 변화량과 조건부 비례 감사 보너스를 적용한다. 사용자 표시의 승객 만족도를 승객 만족도로 변경했다. 기존 기본 점수 M으로 기본 운임을 정하고 최종 S=M+Δ는 별도 피드백/보너스로 쓴다. F8에 기본 운임·감사 보너스·합계·M+Δ=S·요구/초과 점수·판정 이유를 보존한다. 긴 결과는 내용 높이로 확장한다.

교통 지연·합법적 우회와 불필요한 경로 이탈을 기존 관찰로 구별할 수 없는 DR02/03/04 미달은 판정 불가·중립이다. 단순 미체험이나 안전한 답변 기회 없음으로 벌점을 만들지 않는다. 미확인 이유와 관찰 근거는 하차 기록에 표시한다. 17종 요청의 위치 제어 통합 검사, 기본+보너스 장부·JSON 복원·중복 지급 방지, 실제 DrivingManners 코드의 DR01 -4점 대체를 검사했다. 전체 수동 주행의 체감은 후속이다.

정상 하차 또는 시간 초과 후 실제 목적지 하차 시 생활 거점 선택을 제공한다. 자동 경유 없이 주유·식사·수면·귀가 주차장을 고르면 기존 공유 도로 경로로 안내한다. 새 호출 수락/닫기로 계속 영업할 수 있다.
