## 1. 주행·교통·운전 평가 (구 01)

대은로 J2225는 본선 양 보도를 잇는 횡단보도, J1566은 황색 띠가 있는 보행 포장이다. 마유로 계수교는 바깥 분기 차로를 백색 빗금으로 구분한다. [치수와 대조 자료](../work-history/2026-11-20-additional-road-repairs.md).

2026-11-17 사용자 첨부 확인: J7841_867 동쪽에서 서행 진입은 직진/우회전만 허용한다. 동쪽 상류 J8314_858 서행 노면 화살표는 숨기되 통행 권한은 유지한다. 남쪽 반대 차로 내부의 잘못된 흰 실선은 제거하고 기존 유턴 표시를 가장 가까운 반대 차로와의 중앙에 정렬한다. [r46 구현·검증](../work-history/2026-11-17-j7841-road-report.md).

[현재 점수 구조 도식·웹 GPT 배점안 적용 검토(2026-11-07)](../future-design/2026-11-07-driving-score-application-review.md): 현재 +3 준수 회복과 제안의 난이도별 획득·안전배려 B·상한을 구분한다. 검토 문서이며 신규 배점은 미채택·미적용이다.

### 개인 운전 설정

2026-11-20 기본 택시의 수동 최대 조향각은 35km/h 17°, 45km/h 9.83°, 50km/h 6.48°, 55km/h 3.93°를 거쳐 60km/h 2.68°로 줄어든다. 약한 입력에도 같은 비율을 적용하며 저속 주차와 60km/h 이상 제한, H 보조의 조향 계산은 기존 기준을 쓴다. [변경 전후 물리 주행](../work-history/2026-11-20-city-steering-response.md).

2026-11-12: 40~50km/h 완만한 커브를 위한 중속 조향 여유와 제한된 회전 보조를 추가한다. 60km/h 이상은 기존 한계로 돌아가며 좁은 직각 교차로는 감속한다. 설정의 조향 빠른 선택은 부드럽게(90/80/110%), 표준(100/100/100%), 빠르게(115/135/125%) 순으로 민감도/반응/복원을 바꾼다. 브레이크·데드존은 보존하며 적용 전에는 저장되지 않는다. [검증](../work-history/2026-11-12-curve-steering.md).

일시정지→설정에서 PC별 수동 조작감을 조절한다. 적용은 저장, 취소/Esc는 미적용이다. H 조향 보조·봇·Space/안전 제동은 이 개인 설정과 구분한다.

| 설정 | 범위 | 기본값 |
|---|---|---:|
| 조향 민감도 | 50~150% | 100% |
| 조향 반응 / 핸들 복원 | 각각25~200% | 각각100% |
| 패드 데드존 | 0~40% | 15% |
| 일반 브레이크 감속 | 50~150% | 100% |

높은 브레이크 설정도 실제 마찰 한계보다 짧은 정지를 보장하지 않는다. LAN은 양쪽 실행본을 함께 갱신하며 현재 호환 계약은 [LAN 기획](pvp/30-native-lan.md)을 따른다. [설정 검증](../work-history/2026-11-06-driving-settings.md)·[브레이크/기존 좌회전 신호 복구 검증](../work-history/2026-11-06-braking-left-signal-repair-ui.md)은 별도로 남긴다.

게임 평가 수치 표는 출하 기본 프로필 기준이다. 구현된 법규 감점·M·관찰 수치는 [설정 관리 도구](../content-tuning-tool-guide.md)에서 조정하며, 위반 사실·예외·중복 방지와 실제 법률 자료는 점수 조정과 구분한다. 감점0이어도 위반 사실은 유지한다. [설정 도구 구현·검증/제한](../work-history/2026-11-05-content-tuning-tool-implementation.md).

### 기본 조작과 신호 수요 제어

사용자 승인으로 싱글/PVP 공통 제동·조향과 기본 게임 신호의 수요 제어를 구현한다. [설계/범위](../superpowers/specs/2026-11-04-casual-controls-signals-design.md), [구현·검증 이력](../work-history/2026-11-04-casual-controls-signals.md)을 따른다. 아래 값은 게임 시험값이며 실제 도로 신호를 복원한 값이 아니다.

| 항목 | 적용 규칙 |
|---|---|
| 일반 제동 | S/↓/패드 제동 강화(토크 계수0.18→0.30). Space 긴급제동 유지. 반대 페달로 멈춘 뒤 계속 누르면 정차 유지, 놓았다 다시 눌러 후진/전진. 일반 봇의 자동 기어 전환은 보존 |

| 보호 | 황색/정리 시간 유지. 보행 녹색은 전체 유지하며 횡단 중에는 정리 이후에도 전적색 유지. 실제 점유/출구 정체/양보 조건은 계속 적용 |

| 안내 | 다음 색 변경과 내 방향 녹색 예상 시간을 구분. 수요에 따라 예상값이 달라짐. 우회전은 신호·보행자 조건 확인 안내 |

### 주행에서 선택하는 것

| 상황 | 행동 | 결과·플레이 영향 | 판단 원칙 |
|---|---|---|---|
| 신호 교차로 | 자기 진행 신호·정지선 확인 | 정지/진입 시점이 운전 평가에 반영 | 다른 방향 신호를 자기 신호로 보지 않음 |
| 우회전 | 필요한 정지·보행자 확인 후 진행 | 단순 정지 누락과 신호/보행 보호 위반 구분 | 보행 신호 색만 보고 사람을 무시하지 않음 |
| 비보호 좌회전 | 허용 신호와 대향 차량을 보고 양보 | 신호가 허용해도 안전한 진입 간격 필요 | 표지는 해당 방향 신호등 위에서 읽을 수 있게 배치 |
| 유턴 | 해당 접근의 표지·허용 조건 확인 | 가능한 구역/시점에만 회전 | 확인되지 않은 반대 방향까지 허용하지 않음 |
| 대기열·출구 정체 | 줄 뒤 대기 또는 연결도로 우회 | 실제 대기시간·주행거리·통행 방해가 달라짐 | 일반 영업에서는 출구 정체 선택 팝업을 띄우지 않음 |
| 경로 이탈·놓친 회전 | 연결된 다음 경로로 다시 안내받음 | 추가 시간·연료 부담 | 반대 차로·인도·금지 회전으로 복구를 강요하지 않음 |
| 자동 조향 보조 | 켜거나 끄고 운전 | 차로 유지·변경·회전 조향을 도움 | 가속·제동·정지·양보까지 자동 운전하는 기능이 아님 |

수동 저속 회전은 충분히 꺾이되 속도가 올라갈수록 민감도를 줄인다. 1·3인칭을 선택하고 좌우/후방을 확인할 수 있다. 조작감의 내부 계산식은 플레이 규칙으로 설명하지 않는다.

### 두 운전 평가의 구분

| 지표 | 의미 | 시작·범위 | 결과의 연결 |
|---|---|---|---|
| 운전 점수 | 캠페인 동안 관찰한 법규 준수·위반 | 새 캠페인100, 0~100 | 다음 승객 승차 때 운임 보정에 사용 |
| 운전 만족도 M | 이번 승객이 경험한 실제 주행 | 승차100, 0~100 | 최종 승객 만족도에 주행 변화로 반영 |

운전 점수는 차량 성능이나 피로 회복 능력이 아니다. 버튼 선택·단순 정차만으로 점수를 지급하지 않는다. 불명확한 상황은 사실과 보류 사유를 남기며 위반으로 단정하지 않는다.

### 행동별 평가

아래 값은 게임 배점이다. 같은 법규 사건에서 위반이 여러 개 성립하면 가장 큰 감점 한 번을 적용한다. M은 별도 주행 평가이므로 법규 점수와 더한 하나의 점수로 표시하지 않는다.

| 관찰한 행동 | 운전 점수 | 운전 만족도(M) | 영향·예외 |
|---|---:|---:|---|
| 새 사건에서 위반 없이 준수 확인 | +3 | 자동 상승 없음 | 상한100, 같은 사건 재지급 없음 |
| 적색 신호 직진 | -20 | -12 | 실제 자기 방향 진입이 확인된 경우 |
| 전방 적색에 우회전 전 단순 정지 누락 | -5 | -4 | 전용 적색·보행 위험과 구분 |
| 우회전 전용 적색 위반 | -20 | -12 | 잠깐 정지했다고 적색 진행이 허용되지는 않음 |
| 횡단 중/횡단하려는 보행자 보호 위반 | -25 | 양보 위반 -8 | 충돌하지 않았어도 보호 위반은 성립할 수 있음 |
| 금지 대상 대기 차량 앞으로 끼어듦 | -15 | 실제 주행 영향 별도 | 일반 차로변경과 금지 끼어들기를 구분 |
| 다른 차 정상 통행을 방해하는 진로 변경 | -15 | 양보 위반 -8 | 상대 급제동만으로 무조건 확정하지 않음 |
| 적색 정지선 침범 후 교차로 진입 전 정차 | -1 | 0 | 같은 접근에서 더 큰 위반 발생 시 최대 감점으로 갱신, 중복 합산 없음 |
| 방향 차로 역주행 | -10 | -10 | 반대 전진2초·8m, 속도2m/s 이상. 후진·주차·교차로 회전·짧은 흔들림 제외 |
| 중앙선 침범 | -10 | -10 | 은계의 황색 실선 중앙선을 차체 중심이 전진으로 통과. 같은 역주행 사건과 중복 감점하지 않음 |
| 비허용 유턴 | -20 | -12 | 지정 유턴 조건 위반 또는 은계 황색 실선 통과 후 반대 방향으로 전환. 표시된 유턴 개구부는 실선 판정에서 제외 |
| 지정 게임 제한속도 초과 | -5 | 별도 관찰 | 제한+3km/h를2초 관찰. 현실의 모든 과속 단속 재현 아님 |
| 불필요한 급가속·급제동 | 직접 변화 없음 | 각 -2 | 필요한 위험 회피 제동은 제외 |
| 차멀미 요청 수락 후 불필요한 급가감속 | 별도 법규 관찰 | 기본 감점에 선택지 추가값 반영 | 현재 추가값은 [선택 효과 기준](../passenger-balance-v1.md), 필요한 제동 제외 |
| 차량·시설/사람 사고 | 게임 사고 등급 감점은 별도 적용 | 충돌 기본 -10 | 연속 접촉 중복 방지. [사고 처리](04-life-vehicle-economy.md#s08)와 [차량 손상·수리](04-life-vehicle-economy.md#추가-기획-충돌-내구도와-수리)는 구현, 보험·현실 과실 판정은 제외 |
| 인도·도로 경계 침범 | 별도 법규 관찰 | -5 | 지속 침범을 매 순간 중복 차감하지 않음 |
| 합법 대기·필요한 제동·정당한 거절 | 불이익 없음 | 0 | 기다린 것만으로 회복을 적립하지 않음 |

우회전 서행은 주행 행동으로 안내하되, 일괄 속도 숫자 하나로 모든 상황에 감점을 확정하지 않는다. 어린이 보호구역·단속 카메라·버스전용차로 등 추가 장면은 현재 적용 범위와 혼합하지 않는다.
