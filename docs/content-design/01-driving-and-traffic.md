## 주행에서 선택하는 것

| 상황 | 행동 | 결과·플레이 영향 | 판단 원칙 |
|---|---|---|---|
| 신호 교차로 | 자기 진행 신호·정지선 확인 | 정지/진입 시점이 운전 평가에 반영 | 다른 방향 신호를 자기 신호로 보지 않음 |
| 우회전 | 필요한 정지·보행자 확인 후 진행 | 단순 정지 누락과 신호/보행 보호 위반 구분 | 보행 신호 색만 보고 사람을 무시하지 않음 |
| 비보호 좌회전 | 허용 신호와 대향 차량을 보고 양보 | 신호가 허용해도 안전한 진입 간격 필요 | 표지는 해당 방향 신호등 위에서 읽을 수 있게 배치 |
| 유턴 | 해당 접근의 표지·허용 조건 확인 | 가능한 구역/시점에만 회전 | 확인되지 않은 반대 방향까지 허용하지 않음 |
| 대기열·출구 정체 | 줄 뒤 대기 또는 연결도로 우회 | 실제 대기시간·주행거리·통행 방해가 달라짐 | 일반 영업에서는 출구 정체 선택 팝업을 띄우지 않음 |
| 경로 이탈·놓친 회전 | 연결된 다음 경로로 다시 안내받음 | 추가 시간·연료 부담 | 반대 차로·인도·금지 회전으로 복구를 강요하지 않음 |
| 자동 조향 보조 | 켜거나 끄고 운전 | 차로 유지·변경·회전 조향을 도움 | 가속·제동·정지·양보까지 자동 운전하는 기능이 아님 |

수동 저속 회전은 충분히 꺾이되 속도가 올라갈수록 민감도를 줄인다. 1·3인칭을 선택하고 좌우/후방을 확인할 수 있다. 조작감의 내부 계산식은 플레이 규칙으로 설명하지 않는다.

## 두 운전 평가의 구분

| 지표 | 의미 | 시작·범위 | 결과의 연결 |
|---|---|---|---|
| 운전 점수 | 캠페인 동안 관찰한 법규 준수·위반 | 새 캠페인100, 0~100 | 다음 승객 승차 때 운임 보정에 사용 |
| 운전 만족도 M | 이번 승객이 경험한 실제 주행 | 승차100, 0~100 | 최종 승객 만족도에 주행 변화로 반영 |

운전 점수는 차량 성능이나 피로 회복 능력이 아니다. 버튼 선택·단순 정차만으로 점수를 지급하지 않는다. 불명확한 상황은 사실과 보류 사유를 남기며 위반으로 단정하지 않는다.

## 행동별 평가

아래 값은 게임 배점이다. 같은 법규 사건에서 위반이 여러 개 성립하면 가장 큰 감점 한 번을 적용한다. M은 별도 주행 평가이므로 법규 점수와 더한 하나의 점수로 표시하지 않는다.

| 관찰한 행동 | 운전 점수 | M | 영향·예외 |
|---|---:|---:|---|
| 새 사건에서 위반 없이 준수 확인 | +3 | 자동 상승 없음 | 상한100, 같은 사건 재지급 없음 |
| 적색 신호 직진 | -20 | -12 | 실제 자기 방향 진입이 확인된 경우 |
| 전방 적색에 우회전 전 단순 정지 누락 | -5 | -4 | 전용 적색·보행 위험과 구분 |
| 우회전 전용 적색 위반 | -20 | -12 | 잠깐 정지했다고 적색 진행이 허용되지는 않음 |
| 횡단 중/횡단하려는 보행자 보호 위반 | -25 | 양보 위반 -8 | 충돌하지 않았어도 보호 위반은 성립할 수 있음 |
| 금지 대상 대기 차량 앞으로 끼어듦 | -15 | 실제 주행 영향 별도 | 일반 차로변경과 금지 끼어들기를 구분 |
| 다른 차 정상 통행을 방해하는 진로 변경 | -15 | 양보 위반 -8 | 상대 급제동만으로 무조건 확정하지 않음 |
| 적색 정지선 침범 후 교차로 진입 전 정차 | -1 | 0 | 같은 접근에서 더 큰 위반 발생 시 최대 감점으로 갱신, 중복 합산 없음 |
| 방향 차로 역주행 | -10 | -10 | 반대 전진2초·8m, 속도2m/s 이상. 후진·주차·교차로 회전·짧은 흔들림 제외 |
| 지정 게임 제한속도 초과 | -5 | 별도 관찰 | 제한+3km/h를2초 관찰. 현실의 모든 과속 단속 재현 아님 |
| 불필요한 급가속·급제동 | 직접 변화 없음 | 각 -2 | 필요한 위험 회피 제동은 제외 |
| 차멀미 요청 수락 후 불필요한 급가감속 | 별도 법규 관찰 | 각 -4 | 기본 -2를 대체, 중첩하지 않음 |
| 차량·시설 충돌 | 충돌만으로 법규 단정 안 함 | -10 | 현재는 같은 접촉 연속 차감 방지·수리/보험 비용 없음. [추가 내구도 기획](03-life-and-economy.md#추가-기획-충돌-내구도와-수리)은 미구현 |
| 인도·도로 경계 침범 | 별도 법규 관찰 | -5 | 지속 침범을 매 순간 중복 차감하지 않음 |
| 합법 대기·필요한 제동·정당한 거절 | 불이익 없음 | 0 | 기다린 것만으로 회복을 적립하지 않음 |

우회전 서행은 주행 행동으로 안내하되, 일괄 속도 숫자 하나로 모든 상황에 감점을 확정하지 않는다. 어린이 보호구역·단속 카메라·버스전용차로 등 추가 장면은 현재 적용 범위와 혼합하지 않는다.

## 교통과 보행자

| 대상·상태 | 행동 | 플레이어에게 미치는 영향 |
|---|---|---|
| 일반 차량 | 같은 도로 방향·신호·안전거리로 운행, 최대72대 | 대기·차로변경·양보 판단의 실제 맥락 |
| 일반 보도 행인 | 안전 보도에서 걷고 잠시 쉼 | 택시 승객·호출 핀과 구분 |
| 일반 횡단자 | 녹색에서 출발, 녹색 마지막2초 신규 진입 안 함 | 이미 건너는 사람이 적색 전환 뒤에도 완주하도록 양보 |
| 드문 무단횡단 | 지정된 J5076의 한 명만 정상5회 후 적색8초 이상 대기·안전 조건에서 출발 | 모든 사람이 적색에 건너는 설정은 아님. 보이는 위험에 대응 |
| 상황 보행자 | 우회전 판단 장면에 맞춰 등장 | 같은 횡단의 일반 행인과 중복 연출하지 않음 |

일반 행인은 안전 보도3명·횡단3명으로 구성한다. 필요한 안전 공간이 없는 장소는 비워 둔다. 보행자는 사고 비용을 발생시키는 수익 방해물이 아니라 관찰·보호의 대상이다. 승객은 별도의 대기·탑승 상호작용을 갖는다.

## 교차로 표지 배치

현재 포장된 신호 교차로에는 횡단보도 글자 안내판을 자동 추가하지 않는다. 횡단보도 노면표시와 보행·차량 신호를 유지하고 필요한 방향별 비보호/유턴 조건만 표시한다. 비보호 좌회전은 화살표+‘비보호’ 도안으로 신호 상부에 작은 판을 사용한다. 표시 수정으로 통행 허용·양보·위반 판정이나 지도 시설의 실제 확인 상태를 바꾸지 않는다. [화면/표지 기준](05-interface-and-navigation.md#도로-위-표지의-실제-표현)을 따른다.


## 교차로 도색·주행 연결과 생활 교통 분산

| 요소 | 적용 규칙 | 비용·안전 경계 |
|---|---|---|
| 녹색 신호 진입 | 실제 회전 경로를 점유한 차량·보행자와 출구 확보를 확인 | 다른 접근로의 넓은 교차로 경계 안에 있다는 이유만으로 정체시키지 않음 |
| 회전 경로 점유 검색 | 정지 위치부터 출구까지 실제 곡선을 포함하는 범위에서 후보를 수집하고 차량 몸체와 경로의 간격으로 판정 | 교차로 중심 사각형 밖의 장애물도 놓치지 않음. 경로별 범위를 캐시하며 차량을 지우거나 장애물을 무시해 통과시키지 않음 |
| 접근 방향별 신호등 | 해당 방향에 활성 좌회전 연결과 진출로가 없으면 3색등, 보호 좌회전이 있으면 4색등 | 반대 방향의 좌회전 연결을 공유하지 않음. 근거가 없는 방향은 기존 표현을 유지하며 비보호 허용을 새로 만들지 않음 |
| 교차로 차선 | 교차로 실제 폭·정지선·횡단보도 영역에서 종방향 도색을 절단 | 겹친 같은 선은 한 번만 표시 |
