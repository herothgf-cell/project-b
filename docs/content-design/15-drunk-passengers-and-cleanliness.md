# 취객 운송·차량 청결도·세차

취객은 일반 승객의 특성이며 [승객 요청](04-passengers-and-reservations.md#승객-요청과-응답) 건수와 별도로 처리한다. 이 문서는 플레이 규칙을 정의한다. 날짜별 변경 경위는 [이전 기획](../design-history/content-design/15-drunk-passengers-and-cleanliness-history.md), 실제 구현·검증 상태는 [P9 체크리스트](../prototype-development-checklist.md)와 [작업 이력](../work-history/LATEST.md)을 따른다. 확률·시간·비용은 게임 시험값이다.

## 발생 조건과 운송 흐름

| 단계 | 조건·수치 | 플레이어가 알 수 있는 내용 | 처리·예외 |
|---|---|---|---|
| 취객 배정 | 승객 후보별 고정 시드 20%, 하루 실제 탑승 최대 1명 | 승차 직후 취객 대사 | 시간대·출발지 고정 없음. 재수락·재실행으로 재추첨하지 않음. 픽업 취소·청결 거부는 하루 한도 미소모 |
| 평소 취객 대사 | 운송 중 12~20게임초 간격, 6종을 순서대로 변주 | 말끝을 흐리는 짧은 대사·목적지 확인 등 | 운전 입력·시간을 강제로 멈추지 않는 텍스트. 조용한 응대 약속을 했으면 일반 수다 억제. 긴 요청 선택지와 겹쳐 가리지 않음 |
| 구토 예정 | 취객 중 25%, 운송당 1회. 경로 진행률 30~70%에 경고 시작 | “속이 안 좋아요… 토할 것 같아요.” 같은 명확한 사전 대사 | 진행률이 한 번에 넘어가도 경고를 먼저 표시. 요청 답변이나 위험 정차를 강제하지 않음 |
| 실제 구토 | 경고 이후 3게임초 이상 지나고 아직 운송 중 | 구토 발생·현재 승객 하차 후 세차 필요 안내 | 조용한 운행 약속 중에도 경고·구토는 표시. 경고 후 3초 전에 유효 도착하면 구토를 강제로 발생시키거나 하차를 지연하지 않음 |
| 구토 직후 | 세차 전 미청소 상태 기록 | 신규 호출 수락 불가 안내 | 현재 탑승 승객·목적지·약정·기한은 유지. 신규 호출은 세차할 때까지 잠금. 청결 수치 급락은 실제 하차 뒤 적용 |
| 첫 유효 도착 | 기존 방향·정차 조건에서 F 하차 시도 | 도착 완료·운임 판정 확정 | 도착 기한·조기 도착 가산은 이 시각으로 확정. 뒤의 기상 대기를 도착 지각으로 계산하지 않음 |
| 기상 지연 | 취객 중 30%, 구토와 독립 추첨 | “손님이 일어나지 않습니다”, 대기 초·다시 깨우기 안내 | 15게임초 뒤 F로 다시 깨우기, 30초면 안전 정차 중 자동 하차. 위치를 벗어나면 대기하고 돌아와 안전 정차해야 하차 |
| 실제 하차 | 운송 ID별 한 번 | 지급 결과·청결 저하·세차 안내 | 일반 운송은 청결 -2, 구토 운송은 min(C,10). 운임·보너스 한 번 정산. 구토 자체로 M·법규 점수 즉시 감점 없음 |

구토와 기상 지연은 함께 발생할 수 있다. 도착 전 운송 기한을 넘겼다면 기존 시간 초과 0원 규칙을 적용한다. 기상 대기 중 다른 승객·호출·시설 이용은 불가하며 영업 시계는 계속 흐른다. 구토 경고·일반 수다는 자동 대사이고, 선택을 요구하는 승객 요청의 정차 조건과 구분한다.

## 청결 상태와 승차 거부

| 상태 | 호출 수락 | 길가 승객에게 F로 승차 시도 | 점수·정산·저장 |
|---|---|---|---|
| C≥80, 세차 필요 잠금 없음 | 가능 | 가능 | 승차 시작 만족도 S0에 +3 한 번 포함. M·요구 R에 직접 가산하지 않음 |
| 30≤C<80, 잠금 없음 | 가능 | 가능 | 청결 가산 없음 |
| 평상시 누적으로 C<30, 아직 거부 없음 | 경고 후 기존 첫 수락 허용 | 승객이 더럽다며 거부 | 거부된 호출은 종료, 실제 운송·운임·초기 만족도 추첨 없음. 첫 거부 뒤 호출 잠금 |
| 구토 후 세차 전 | **첫 거부를 기다리지 않고 즉시 수락 불가** | 시도는 허용하고 “차가 너무 더러워서 못 타겠어요. 세차하고 와 주세요.” 같은 승객 대사로 거부 | 거부 시 운송 생성·요금·법규/M 감점 없음. 세차 전 반복 새 호출 수락 방지 |
| 세차 완료 | 잠금 해제 | 정상 승차 | C=100, 구토 미청소·거부 잠금 해제 |

호출 잠금은 **배차 수락 제한**이다. 길가 상호작용까지 막아 승객 대사가 사라지면 안 된다. 같은 승객의 동일 거부는 중복 기록하지 않고, 대기 승객 재생성은 기존 쿨다운을 따른다. 날짜 변경·저장 복원으로 구토 미청소 잠금을 풀지 않는다. 구형 저장에 잠금 필드가 없더라도 C<30이면 세차 필요로 복원하고, 진행 중 구토 기록이 있으면 새 호출 제한을 복구한다.

기존 탑승객은 청결 때문에 중도 하차시키거나 요금을 별도 삭감하지 않는다. 청결 가산은 승차 때 고정되므로 하차 때 다시 더하지 않는다.

## 주유소 세차·실내 청소

| 항목 | 규칙 | 예외·확인 |
|---|---|---|
| 장소 | 기존 은계 주유소 3곳의 지정 정차 구역, F7 메뉴 | 빈차·저속·방향·이용 가능한 영업 상태 검사. 별도 세차장 추가 없음 |
| 선택 | 주유와 별도인 세차·실내 청소 | 연료 구매 없이 단독 이용 가능, 확인/취소 구분 |
| 비용·시간 | 2,000원·30게임초 | 엔진 정지, 거래 ID로 한 번 청구·시간 차감. 취소 시 모두 변화 없음 |
| 회복 | C=100, 미청소·호출 잠금 해제 | 완료된 세차만 해제. 주유·다음 날·재실행은 세차 대체 아님 |
| 돈 부족 | 부족분 미납으로 진행 가능 | 더러움 때문에 영업이 영구 차단되지 않음 |
| 예정 마감 직전 | 현재 초과 영업 정책에 따라 서비스 사용 가능 | 옛 남은30초 미만 무조건 거절 규칙은 사용하지 않음. [영업·휴식](05-daily-operation.md) 기준 |
| 장부·추천 | 세차비를 주유·식사와 분리해 비용·순수익에 한 번 포함 | 하차 후 C<30이면 연료보다 세차 주유소를 우선 추천. 추천 클릭만으로 결제·이동하지 않음 |

## 화면과 저장

| 항목 | 표시·보존 내용 |
|---|---|
| 주행 HUD | 연료 우측 C/100 게이지, 30 미만 세차 필요. 구토 직후 아직 수치가 낮아지기 전에도 호출 잠금 사유 안내 |
| 취객 대사 | 승차·평소 수다·구토 예고·구토·기상 대기. 중요한 경고를 일반 수다가 덮어쓰지 않음 |
| 호출 UI | 세차 전 수락 불가 사유, 현재 운송 종료 후 주유소 안내 |
| 길가 거부 | 승객의 직접 거부 대사와 세차 필요. 입력 실패처럼 보이지 않게 명시 |
| 하차·F8·장부 | 첫 도착/실제 하차 시각, 구토·기상 대기, 청결, 운송 지급, 세차비를 기록. 간단 정산창은 기존 3줄 구조 유지 |
| 진행 저장 | 취객 배정·경고 여부와 경과·구토·대사 진행·기상 대기·청결·미청소 잠금·거부 기록을 운송/위치/회계와 함께 보존 |
| 복원 오류 | 손상 원본을 덮지 않고 이어하기 차단. 지도 리비전 변경은 별도 확인 절차 |

## 플레이 확인 사례

| 사례 | 기대 결과 |
|---|---|
| 일반·취객·구토·기상·둘 다 | 특성별 상태와 정상 운송 보존, 하루 취객 한도 |
| 경로 진행률 급변 | 구토 전에 경고가 먼저 보이고 최소3초 확보 |
| 경고 직후 도착 | 불필요한 구토/하차 지연 없음 |
| 조용한 약속 | 평소 수다 억제, 구토 경고·발생은 전달 |
| 구토 하차 후 바로 호출 수락 | 첫 거부 없이 차단, 세차 안내 |
| 세차 전 길가 F | 승객 거부 대사, 운임·운송 수 증가 없음 |
| 구토 중/하차 후 저장·다음 날 | 경고/구토 중복 없음, 잠금 유지, 세차만 해제 |
| 세차 취소·돈 부족·중복 입력 | 취소 무변화, 미납 처리, 세차비·시간 1회 |
| 수동 하루·3일 | 취객 빈도·대사 반복감·기상 대기·세차 이동/비용의 체감 확인 |

자동 상태 검사·위치 제어·자동 물리 주행·사람의 수동 플레이를 구분해 기록한다. 수동 경제 밸런스 완료 여부는 이 문서의 기획 표로 대신하지 않는다.
