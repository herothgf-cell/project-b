실직 후 돈을 벌기 위해 택시를 운전하는 주인공이 짧은 운송 안에서 길과 교통 상황을 판단한다. 선택은 가감속·정차·차로 변경·경로 변경으로 수행하고, 해설은 상황 종료 후 짧게 제공한다. 아래는 콘텐츠 기획이며 구현 완료 목록이 아니다.

## 현재 구현과 검증 범위

출구 정체 A/B/C와 우회전 R1~R5 상황·판정이 구현됐다. A/B/C 및 진입 포기·복귀 후 운송은 자동 검사에서 목적지 도착과 운임 지급을 확인했다. 접근부는 좌표 제어, 이후는 Rigidbody 주행이다. 우회전 신호·보행 조건 경계도 자동 검사했다.

**남은 확인:** 접근부를 포함한 수동 전 구간 주행, 일반 교통과의 상호작용, 장면 단서 가독성과 체감 난도는 남아 있다.

근거: [통합 검증](../prototype-completion-validation.md) · [개발 체크리스트](../prototype-development-checklist.md). 아래 상세 표는 목표 설계를 포함하므로 표의 ‘포함’만으로 검증 완료를 뜻하지 않는다.

| 예외 | 조건이 불명확하거나 AI·안내 오류 발생 | 사실만 보존하고 해당 법규 판정 보류·집계 제외 |

## 상황 1 — 우측 출구 정체

우측 연결도로로 빠져야 하지만 신호 대기열이 길다. 직진 차로와 다음 연결도로는 열려 있어 대기 또는 우회가 가능하다. 신호 대기열과 차로가 없어지는 정상 합류는 서로 다른 상황으로 구성한다.

### 공통 장면 설정

아래 수치는 장면 설명용 예시이며 현재 빌드의 실측값·확정 밸런스가 아니다. A·B·C는 같은 상황에서 갈라지는 대안 플레이다.

| 항목 | 설정·확인 사항 |
|---|---|
| 장면명 | 오른쪽 출구 앞의 긴 줄 |
| 정체 원인 | 연결도로 앞 신호로 출구 방향 차량이 정지·서행. 공사 합류·차로 소멸은 아님 |
| 안내와 대기열 | 출구 약 300m 전부터 내비·표지와 약 8대의 줄을 볼 수 있고 뒤에서 합류할 기회 제공 |
| 노면 표시 | 진로 변경 가능 구간과 변경 금지 구간을 식별 가능하게 배치 |
| 대체 경로 | 직진 후 다음 연결도로로 이동. 출구를 놓쳐도 역주행·급정지 없이 재탐색 |
| 예상 시간 | 대기 경로 3분, 우회 경로 3분 40초 등 예상치를 표시하되 교통 조건에 따라 변동 |
| 승객 압박 | “조금 서둘러 주실 수 있을까요?”라는 요청. 두 정상 경로 모두 운송 완료 여유 확보 |
| 운전 도움 | 조향 보조 사용 가능. 진입·대기·가감속 판단은 플레이어 담당 |
| 법규 조건 | 정지·서행 이유, 표시, 진입 방식, 정상 통행 방해를 함께 기록. 근거는 [법규 기획](02-driving-evaluation.md) 참조 |

### 세 선택과 플레이 흐름

| 선택 | 실제 플레이 | 얻는 것·감수하는 것 | 평가 기준 |
|---|---|---|---|
| A. 줄 뒤에서 기다림 | 감속·주변 확인 → 뒤에 합류 → 간격 유지 → 줄을 따라 출구 진입 | 추가 거리 회피, 대기 시간 발생 | 대기 자체에 자동 팁·법규 보너스 없음. 합류·대기 중 실제 행동 기록 |
| B. 직진 후 우회 | 직진 유지 → 출구 통과 → “경로를 다시 안내합니다” → 다음 연결도로 이용 | 추가 거리·연료 사용, 대기 회피 가능 | 경로 변경 자체는 위반으로 취급하지 않음. 출구 차로 변경은 평가 기회 없음 |
| C. 앞부분 진입 | 대기열 옆 통과 → 방향지시 → 부족한 간격으로 신호 대기 차량 앞에 진입 → 상대 차량 제동 | 시간을 줄일 수 있지만 통행 방해·위반 가능 | 옆을 지나는 것만으로 위반 확정하지 않음. 실제 진입과 [적용 조건](02-driving-evaluation.md)을 확인 |

대기와 우회 중 항상 빠른 선택을 정하지 않는다. 앞부분 진입은 점선·방향지시·무충돌만으로 허용 여부를 정하지 않으며, 금지 대상 대기열과 정상 합류를 구분한다.

### 선택별 히스토리 카드

| 항목 | 카드 A — 대기 | 카드 B — 우회 | 카드 C — 앞부분 진입 |
|---|---|---|---|
| 상황 | 신호 대기열, 승객 탑승·재촉 | A와 같은 출구 정체 조건 | A와 같은 출구 정체 조건 |
| 내 행동 | 뒤 합류 → 간격 유지 → 출구 진입 | 직진 유지 → 출구 통과 → 대체 경로 | 옆 통과 → 앞부분 진입 → 상대 차량 제동 |
| 주변 영향 | 진입에 따른 급제동·통행 방해 관찰 안 됨 | 출구 앞 강제 진입에 따른 제동 없음 | 뒤 차량 진행이 끊김. 충돌은 없음 |
| 법규 기록 | 관찰한 진로 변경 조건 준수 | 관련 위반 없음. 출구 차로 변경은 미경험 | 설정된 금지 대기열 진입·통행 방해 조건에 대한 판단 기록 |
| 적용 근거 | 해당 장면의 진로 변경 조건 | 실제 수행한 경로의 규칙 | [제23조·제22조 제2항·제19조 제3항 근거](02-driving-evaluation.md) |
| 선택 기록 | 대기 후 순서대로 진입 | 대기 대신 우회 | 대기열 앞부분 진입 한 사건 |
| 성향 표시 | 한 건으로 성향 확정하지 않음 | 대기하지 않았다는 이유로 준수 성향 하락 없음 | 위반 사실을 남기되 인격 유형 부여 없음 |
| 다음 보기 | 장면 설명 / 정체가 긴 조건 연습 | 실제 소요·거리 / 같은 조건에서 대기 | 진입 전후 / 근거 조건 / 다른 선택 재도전 |

| 피드백 항목 | 표시 원칙 |
|---|---|
| 시간·거리·연료 | 실제 운행 결과와 사전 예상치를 구분. 비용은 [경제 기획](05-daily-operation.md) 적용 |
| 선택하지 않은 경로 | “대기보다 40초 손해”처럼 확정하지 않음. 같은 조건의 복습 또는 예상치로만 비교 |
| 승객 결과 | [매너·요구 달성](04-passengers-and-reservations.md)을 별도 카드로 표시. 법규 카드에서 자동 가감산하지 않음 |
| 판정 설명 | 해당 조건과 관찰 행동을 짧게 설명. 관련 조문이 여러 개여도 사건 횟수 중복 집계 금지 |
| 새로운 사건 | 우회로에서 만난 교차로·보행자 상황은 별도 사건으로 기록 |

### 중간에 선택을 바꾸는 경우

| 실제 행동 | 진행·히스토리 처리 |
|---|---|
| 대기 중 우회로 변경 | 허용된 구간·안전한 조건인지 확인하고 ‘대기 → 우회’의 실제 순서 기록 |
| 방향지시만 켠 뒤 직진 | 방향지시만으로 끼어들기 위반 처리하지 않음. 방해 여부 확인 후 ‘진입 검토 → 우회’ 기록 |
| 진입 중 상대 제동 후 복귀 | 출구 진입 실패와 이미 발생한 통행 방해 관련 판단을 분리 |
| 변경 금지 구간을 지나 우회 | 놓친 출구 수용으로 기록. 하지 않은 차로 변경에 준수 횟수를 부여하지 않음 |
| 조건·차량 반응 불명확 | 사실 보존, 해당 법규 판정 보류·준수율 집계 제외 |

### 변형과 누적 히스토리 예시

| 변형 | 바꾸는 조건 | 프로토 적용 |
|---|---|---|
| 여유 / 재촉 | 같은 도로에서 승객 대사·시간 여유만 변경 | 핵심 장면 안정화 후 단순 변형 |
| 승객 / 빈차 | 매너 요구가 없는 빈차에서도 동일 법규 적용 | 기록 범위 확인에 포함 |
| 안내를 놓침 | 안전한 출구 진입 기회를 지난 상태 | 다음 경로 안내 확인에 포함 |
| 타인의 위반 | 다른 차의 앞부분 진입 | 확장 후보. 따라 하기·급가속·차로 봉쇄 등 실제 행동 기록 |

다음 5회는 누적 표시 예시이며 성향 확정에 필요한 최소 횟수가 아니다. 도로·시야·교통 조건이 유사한 기록을 가정한다.

| 회차 | 조건 | 행동·법규 기록 |
|---|---|---|
| 1 | 승객 있음, 여유 | 뒤 합류. 관찰한 진로 변경 조건 준수 |
| 2 | 승객 있음, 재촉 | 앞부분 진입. 금지된 끼어들기·통행 방해 관련 판단 |
| 3 | 빈차, 여유 | 직진 우회. 출구 차로 변경 평가 기회 없음 |
| 4 | 승객 있음, 재촉 | 앞부분 진입 후 복귀. 이미 발생한 통행 방해 관련 판단 유지 |
| 5 | 승객 있음, 재촉 | 뒤 합류. 관찰한 진로 변경 조건 준수 |

| 표시 | 예시·제한 |
|---|---|
| 누적 요약 | “출구 정체 5건: 대기 2회, 우회 1회, 앞부분 진입 2회. 재촉이 있던 3건 중 2건에 관련 위반이 있었고 최근에는 뒤로 합류했습니다.” |
| 해석 | 재촉을 위반의 원인으로 확정하지 않음. 선택 횟수와 규칙별 평가 기회를 별도 집계 |
| 복습 | 2회차를 우회로 다시 해도 원래 영업 기록은 유지. 연습에서 다른 선택을 수행했다고 표시 |
| 연결 | 각 근거 장면을 열 수 있게 하고 기록 부족 안내·최근 변화는 [히스토리 기준](03-history-and-mastery.md) 적용 |

## 상황 2 — 보행 신호는 녹색인데 사람이 없는 우회전

보행 신호 색만 보고 행동을 결정하지 않도록 차량 신호·우회전전용신호·보행자 상태를 함께 읽는 장면이다. 아래는 제작 조건표이며 신호별 법적 판정은 [우회전 조건별 판정](02-driving-evaluation.md#우회전-조건별-판정)을 따른다.

| 항목 | 프로토 설정 |
|---|---|
| 공통 질문 | “우회전할 횡단보도의 보행 신호는 녹색이고 건너는 사람이 없다. 무엇을 더 확인해야 하는가?” |
| 기본 장소 | 주간·양호한 시야의 짧은 가상 교차로. 우회전 경로상 어느 횡단보도인지 명확히 표시 |
| 필수 관찰 | 차량 신호, 우회전전용신호 유무·등화, 정지선, 교차 교통, 건너는 사람·건너려는 사람 |
| ‘사람 없음’ 조건 | 횡단 중인 사람뿐 아니라 건너려는 사람도 없음. 가려서 확인할 수 없는 경우와 구분 |
| 입력 | 감속·정지·주변 확인·진행을 실제 운전으로 수행. 보행 녹색이라는 이유만으로 자동 진행시키지 않음 |
| 기록 | 접근/정지/진행 시점의 신호 상태, 보행자 상태, 정지 위치·행동, 주변 영향, 조향 보조 사용 |
| 설명 | 신호·보행자 조건과 실제 행동을 나란히 표시하고 [02의 근거](02-driving-evaluation.md#우회전-조건별-판정)로 연결 |

| 조건 ID | 차량 신호 | 우회전전용신호 | 보행 신호·사람 | 확인 목적 |
|---|---|---|---|---|
| R1 | 적색 | 없음 | 녹색 / 건너거나 건너려는 사람 없음 | 차량 신호에 따른 정지·진행 조건 구분 |
| R2 | 녹색 | 없음 | 녹색 / 건너거나 건너려는 사람 없음 | R1과 비교하여 보행 신호 하나로 판단하지 않는지 확인 |
| R3 | 녹색 | 있음 / 적색 | 녹색 / 건너거나 건너려는 사람 없음 | 우회전전용신호를 확인하는지 검증 |
| R4 | 녹색 | 있음 / 녹색 화살표 | 적색 / 건너거나 건너려는 사람 없음 | 전용신호가 있는 별도 조건과 보행자 확인을 검증 |
| R5 | R1 또는 R2와 동일 | 없음 | 녹색 / 건너는 사람 또는 건너려는 사람 있음 | 같은 배치에서 보행자 조건만 바꾼 최소 변형 |

R1·R2를 핵심으로 제작하고 R3·R4는 전용신호 판정 비교에 필요한 최소 변형으로 둔다. R4는 보행 녹색 고정 사례와 분리하며, 모순된 동시 신호를 만들지 않도록 신호 운영을 먼저 확정한다. 보행자를 회피 불가능한 거리에서 갑자기 생성하지 않는다.
