# 운전 상황 콘텐츠 기획서

기준일: 2026년 10월 19일 · 버전: 0.7 · 상태: 기존 구현 6de26a5 및 검증 대조 + 은계 지도 연동 상황 선택 이벤트 신규 기획(미구현)

[로드맵](00-RoadMap.md) · [기획 총괄](README.md) · [맵·주행](06-world-map-and-driving.md)

실직 후 돈을 벌기 위해 택시를 운전하는 주인공이 짧은 운송 안에서 길과 교통 상황을 판단한다. 선택은 가감속·정차·차로 변경·경로 변경으로 수행하고, 해설은 상황 종료 후 짧게 제공한다. 아래는 콘텐츠 기획이며 구현 완료 목록이 아니다.

## 현재 구현과 검증 범위

출구 정체 A/B/C와 우회전 R1~R5 상황·판정이 구현됐다. A/B/C 및 진입 포기·복귀 후 운송은 자동 검사에서 목적지 도착과 운임 지급을 확인했다. 접근부는 좌표 제어, 이후는 Rigidbody 주행이다. 우회전 신호·보행 조건 경계도 자동 검사했다. **은계 실제 주행 구간에 진입할 때 자동으로 상황 선택지를 띄우는 기능은 신규 기획이며 미구현이다.**

**남은 확인:** 접근부를 포함한 수동 전 구간 주행, 일반 교통과의 상호작용, 장면 단서 가독성과 체감 난도는 남아 있다.

근거: [통합 검증](../prototype-completion-validation.md) · [개발 체크리스트](../prototype-development-checklist.md). 아래 상세 표는 목표 설계를 포함하므로 표의 ‘포함’만으로 검증 완료를 뜻하지 않는다.

## 은계 지도 연동 · 상황 판단 선택 이벤트 (신규 기획, 미구현)

### 목표와 프로토 적용 경계

은계 지도의 **실제 주행 가능한 도로 구간**에 기존 두 상황(출구 정체 A/B/C, 우회전 R1~R5)을 연결한다. 플레이어가 지정된 방향에서 판단 지점에 접근하면 게임을 잠시 멈추고 **운전 계획 선택지**를 제공한다. 선택 확정 또는 건너뛰기 후 같은 자리에서 주행을 재개하며, **법규 준수·승객 매너·요금은 메뉴 선택이 아닌 실제 주행 및 기존 규칙**으로 판정한다.

- **현재 구현:** F5 출구 정체 상황 시작, R1~R5 연습 선택, 별도 연습 창/결과, 법규 관찰과 내비 연동이 존재한다. **지도 진입 자동 감지 → 영업 중 자동 일시정지 → 계획 선택**은 아직 구현하지 않았다.
- **새 프로토 검증 목표:** 은계 지도에서 출구 정체 **1개 구간**, 우회전 **1개 교차로(진입 방향 지정)**만 먼저 연결한다. 두 곳 모두 현재 생성된 도로망·차로·승하차 경로와 물리적으로 연결되는지 확인한 뒤 등록한다. 실제 지점 좌표·도로 ID·교차로 ID는 **미확정**이며, 지도 원본만으로 실제 신호 운영이나 규제를 검증했다고 주장하지 않는다.
- **기존 기능 보존:** 연습 선택/재도전은 계속 별도 흐름이며, 영업 중 자동 이벤트는 연습 창으로 이동하거나 택시를 순간 이동시키지 않는다. 실전의 운송·법규 기록과 연습 기록을 분리한다.

### 지도에 배치하는 방법

| 요소 | 저장할 정보 | 발생 조건·예외 |
|---|---|---|
| `ScenarioZone` | 상황 ID(`exit-queue`, `right-turn`), 은계 도로/차로 ID, 교차로 ID, 지정 접근 방향, 판정 시작·종료 구간, 가상/확인 여부 | 차 위치만이 아니라 **진행 방향·해당 차로·접근 구간**이 일치할 때만 발동. 반대방향·교차로 통과 후 역방향 재진입은 제외 |
| 사전 안내 | 접근 거리, 내비 예고 문구, 화면 단서 표시 위치 | 선택 UI가 뜨기 전에 표지·대기열·정지선 등을 확인할 수 있어야 함. 예고 거리 예: 출구 약 300m |
| 선택 트리거 | 상황별 결정 지점까지 남은 거리, 최소 시야·분기 가능 거리 | 출구 정체 예: 결정 지점 150~200m 전, 우회전 예: 70~100m 전. **예시 수치**, 지도 배치·실측 속도 검증 후 확정 |
| 상황 준비 | 교통 AI·신호·보행 상태·대체 경로의 준비 완료 플래그 | 메뉴 직전에 차량·보행자를 갑자기 생성하지 않음. 사전 준비 불가·지도 데이터 불명확·경로 단절 시 자동 이벤트 생략/보류 |
| 중복 방지 | 상황 ID+방향+캠페인 최초 노출 여부, 진행 중 이벤트 ID | 첫 자동 팝업 후 반복 방문은 짧은 HUD 안내만 표시. 한 접근에 팝업 1회, 후진·재진입·화면 재열기로 중복 점수/보상 불가 |
| 위치와 기록 | 실제 진입 도로·방향, 선택 계획, 변경·건너뛰기, 구간 종료 및 실제 관찰 | 선택한 분기와 실제 운전·법규 사건을 각각 저장. 완료하지 않은 경로의 시간·위반을 확정 기록하지 않음 |

지도에 연결하는 것은 **기존 물리 도로와 상황 관찰 영역의 결합**이지, 사용자 앞에 별도의 연습용 가상 도로를 강제로 붙이거나 실제 은계 교차로의 신호를 검증 없이 덮어쓰는 기능이 아니다. 장면용 임시 신호·대기열은 명확히 ‘가상 상황’으로 표시하고, 일반 통행과 충돌하는 구간에서는 안전하게 배치를 생략한다.

### 실전 진행 흐름

| 단계 | 화면·플레이어 경험 | 시스템 처리 |
|---|---|---|
| 1. 자유 주행 | 기존 호출·내비대로 운행 | 도로 ID/접근 방향/상황 가용성 감시. 승객 탑승 여부와 관계없이 실제 법규 기록은 계속 가능 |
| 2. 사전 예고 | “앞쪽에 출구 정체가 있습니다” 같은 짧은 HUD 알림 | 충분한 거리에서 교통·경로 단서를 미리 보이게 함. 팝업 전에도 무리한 제동을 요구하지 않음 |
| 3. 판단 시점 | **최초 방문 시** 선택 패널을 열고 주행 일시정지 | Unity 물리·AI·교차 신호·운송 기한·영업 타이머·연료 소비를 동일하게 멈춤. 팝업 중 운임·점수·남은 시간이 변하지 않음 |
| 4. 계획 선택 | 출구는 대기/우회/앞부분 진입 검토/직접 운전, 우회전은 신호·보행 상태 판단 계획/직접 운전 | 계획만 기록. 필요하면 내비 추천 경로·짧은 HUD 안내를 변경하지만 조향·제동·회전 및 안전 판단을 자동 실행하지 않음 |
| 5. 주행 재개 | 같은 차량 위치·속도·진행 상황으로 복귀 | 모든 타이머/물리/AI를 함께 재개. 재개 직후 교통 충돌이나 순간 경로 재배치가 없어야 함 |
| 6. 결과 | 상황 영역 이탈 시 짧은 안내, 영업/법규 히스토리에서 상세 확인 | 선택 계획·실제 행동 차이, 운송 시간/거리·연료, 법규 준수/위반/보류를 분리 기록. 승객 결과·요금은 기존 흐름 유지 |
| 7. 재방문 | 같은 상황은 기본적으로 짧은 표시 후 직접 주행 | 플레이어 설정으로 선택 UI 재표시 또는 연습 모드에서 같은 조건 재도전 가능(설정 기능은 후속 구현) |

**중요:** A/B/C나 우회전 응답은 *운전 계획*이고 법적 정답 선택이 아니다. 예컨대 ‘앞부분 진입 검토’를 고른 뒤 실제로 뒤 합류·우회를 했다면 선택만으로 L06/L07 위반을 부여하지 않는다. ‘정지 후 우회전’을 골라도 실제로 정지하지 않았다면 주행 관찰에 따라 판정한다. 메뉴에 정답·해설을 선공개하지 않고 구간을 통과한 뒤 설명한다.

### 팝업 UI·일시정지·중첩 예외

| 항목 | 설계 기준 |
|---|---|
| 짧은 UI | 제목, 관찰 가능한 신호·도로·대기열 단서, 2~4개 계획, **직접 운전/건너뛰기**, 선택 후 재개 버튼. 불법 운전을 권장하거나 정답을 미리 표시하지 않음 |
| 정지 구현 | 기존 `DriveSession`의 일시정지 흐름과 상태를 통합 관리. `Time.timeScale=0` 상태에서도 메뉴 입력·닫기가 가능하도록 UI 입력 및 상태 복구 보장 |
| 기존 메뉴 충돌 | 연습 선택·연습 실행, Esc 메뉴, 하루 준비·정산, 결제·거점 메뉴, 법규 히스토리, 운송 종료·승하차 전환 중에는 새 선택지를 띄우지 않음. 상황을 놓치면 안전하게 건너뛰고 자동 판정만 가능한 범위에서 유지 |
| 카운트다운 | 선택 중 시간제한 없음. 선택 화면을 오래 보았다는 이유로 승객 운송 실패·신호 변경·연료 차감이 생기지 않음 |
| 재진입·연속 발생 | 상황 ID별 최초 1회 자동 팝업을 기본값으로 검토. 하루 최대 1~2회 수준에서 가독성과 몰입도를 테스트하는 **초깃값 제안**이며 최종 확정 아님 |
| 도로 위험 구간 | 정지선 직전·회전 중·이미 충돌 위험이 진행 중인 순간에는 뒤늦게 팝업을 띄우지 않음. 트리거 놓침은 미발생으로 처리, 잘못된 선택을 강제하지 않음 |
| 상황 중 선택 변경 | 메뉴에서 고른 계획과 다른 실제 경로로 변경 가능. 내비는 합법 경로로 재탐색하고 결과에는 ‘선택 변경’만 기록; 운전 점수는 실제 행동으로 산정 |
| 저장 경계 | 현재 캠페인 정산 저장 형식에 이벤트 노출·완료 기록을 추가할 때 이전 저장과 호환성/중복 방지를 검증. 영업 시간 정지 중 체크포인트가 오염되지 않게 처리 |

### 기존 구현과의 연결·개발 순서

| 단계 | 재사용·신규 작업 | 완료 기준 |
|---|---|---|
| 1. 구간 선정 | 은계 통합 도로망에서 출구 정체 1구간·우회전 1교차로의 **실제 연결 및 대체 경로** 확인. 지도·시설 임시/검증 상태 등록 | 어느 방향으로 접근할 때 어떤 이벤트가 나오는지 좌표·도로 ID와 함께 확인 |
| 2. 자동 감지 | 신규 `ScenarioZone`/트리거 관리자가 접근·방향·중복·메뉴 충돌 판정 | 해당 방향 최초 접근에서만 알림, 반대 방향·재진입·다른 메뉴 중에는 중복 팝업 없음 |
| 3. 선택·일시정지 | 기존 `DriveSession`/일시정지 UX와 연동하는 신규 선택 패널. 운송·신호·교통·경제 타이머 동시 정지/복원 | 팝업 전후 차량 상태·남은 시간·신호 단계·AI 위치가 뜻밖에 변하지 않음 |
| 4. 상황 연결 | 기존 `ExitQueueSituation`, `ExitQueueObserver`, `RightTurnSituation` 및 내비 연계. 영업 중 연습 인스턴스/리셋은 사용하지 않음 | 메뉴에서 선택한 계획에 맞춰 안내만 바뀌고 실제 행동에 따른 결과가 정확히 기록 |
| 5. 피드백·회귀 | 기존 법규 장부·승객 매너·운송/정산·연습 기록 분리, 반복 플레이 검사 | 강제 위반 없음, 운임·세금·연료·하루 마감·F5/F6 연습·기존 저장 회귀 통과 |

이 기능의 초기 목표는 **운전 중 판단 경험의 가독성** 검증이다. 게임 전체를 선택지 중심의 자동 주행 게임으로 바꾸거나 전 지역 모든 교차로에서 자동 정지하는 방향은 채택하지 않는다.

## 상황 1 — 우측 출구 정체

우측 연결도로로 빠져야 하지만 신호 대기열이 길다. 직진 차로와 다음 연결도로는 열려 있어 대기 또는 우회가 가능하다. 신호 대기열과 차로가 없어지는 정상 합류는 서로 다른 상황으로 구성한다.

**지도 연동 후속 적용:** 은계 통합 도로망에서 실제 우회 경로가 연결되는 출구 1곳을 선정한다. 사전 안내 후 최초 접근에서는 ‘뒤 합류 / 다음 연결도로 우회 / 앞부분 진입 검토 / 직접 운전’ 계획을 보여 준다. C는 금지된 끼어들기 실행 버튼이 아니며, 선택 이후 실제 차량 조작과 AI 반응으로 L06·L07을 판정한다. 기존 A/B/C 실전·연습 판정은 그대로 재사용한다.

### 공통 장면 설정

아래 수치는 장면 설명용 예시이며 현재 빌드의 실측값·확정 밸런스가 아니다. A·B·C는 같은 상황에서 갈라지는 대안 플레이다.

| 항목 | 설정·확인 사항 |
|---|---|
| 장면명 | 오른쪽 출구 앞의 긴 줄 |
| 정체 원인 | 연결도로 앞 신호로 출구 방향 차량이 정지·서행. 공사 합류·차로 소멸은 아님 |
| 안내와 대기열 | 출구 약 300m 전부터 내비·표지와 약 8대의 줄을 볼 수 있고 뒤에서 합류할 기회 제공 |
| 노면 표시 | 진로 변경 가능 구간과 변경 금지 구간을 식별 가능하게 배치 |
| 대체 경로 | 직진 후 다음 연결도로로 이동. 출구를 놓쳐도 역주행·급정지 없이 재탐색 |
| 예상 시간 | 대기 경로 3분, 우회 경로 3분 40초 등 예상치를 표시하되 교통 조건에 따라 변동 |
| 승객 압박 | “조금 서둘러 주실 수 있을까요?”라는 요청. 두 정상 경로 모두 운송 완료 여유 확보 |
| 운전 도움 | 조향 보조 사용 가능. 진입·대기·가감속 판단은 플레이어 담당 |
| 법규 조건 | 정지·서행 이유, 표시, 진입 방식, 정상 통행 방해를 함께 기록. 근거는 [법규 기획](02-driving-evaluation.md) 참조 |

### 세 선택과 플레이 흐름

| 선택 | 실제 플레이 | 얻는 것·감수하는 것 | 평가 기준 |
|---|---|---|---|
| A. 줄 뒤에서 기다림 | 감속·주변 확인 → 뒤에 합류 → 간격 유지 → 줄을 따라 출구 진입 | 추가 거리 회피, 대기 시간 발생 | 대기 자체에 자동 팁·법규 보너스 없음. 합류·대기 중 실제 행동 기록 |
| B. 직진 후 우회 | 직진 유지 → 출구 통과 → “경로를 다시 안내합니다” → 다음 연결도로 이용 | 추가 거리·연료 사용, 대기 회피 가능 | 경로 변경 자체는 위반으로 취급하지 않음. 출구 차로 변경은 평가 기회 없음 |
| C. 앞부분 진입 | 대기열 옆 통과 → 방향지시 → 부족한 간격으로 신호 대기 차량 앞에 진입 → 상대 차량 제동 | 시간을 줄일 수 있지만 통행 방해·위반 가능 | 옆을 지나는 것만으로 위반 확정하지 않음. 실제 진입과 [적용 조건](02-driving-evaluation.md)을 확인 |

대기와 우회 중 항상 빠른 선택을 정하지 않는다. 앞부분 진입은 점선·방향지시·무충돌만으로 허용 여부를 정하지 않으며, 금지 대상 대기열과 정상 합류를 구분한다.

### 선택별 히스토리 카드

| 항목 | 카드 A — 대기 | 카드 B — 우회 | 카드 C — 앞부분 진입 |
|---|---|---|---|
| 상황 | 신호 대기열, 승객 탑승·재촉 | A와 같은 출구 정체 조건 | A와 같은 출구 정체 조건 |
| 내 행동 | 뒤 합류 → 간격 유지 → 출구 진입 | 직진 유지 → 출구 통과 → 대체 경로 | 옆 통과 → 앞부분 진입 → 상대 차량 제동 |
| 주변 영향 | 진입에 따른 급제동·통행 방해 관찰 안 됨 | 출구 앞 강제 진입에 따른 제동 없음 | 뒤 차량 진행이 끊김. 충돌은 없음 |
| 법규 기록 | 관찰한 진로 변경 조건 준수 | 관련 위반 없음. 출구 차로 변경은 미경험 | 설정된 금지 대기열 진입·통행 방해 조건에 대한 판단 기록 |
| 적용 근거 | 해당 장면의 진로 변경 조건 | 실제 수행한 경로의 규칙 | [제23조·제22조 제2항·제19조 제3항 근거](02-driving-evaluation.md) |
| 선택 기록 | 대기 후 순서대로 진입 | 대기 대신 우회 | 대기열 앞부분 진입 한 사건 |
| 성향 표시 | 한 건으로 성향 확정하지 않음 | 대기하지 않았다는 이유로 준수 성향 하락 없음 | 위반 사실을 남기되 인격 유형 부여 없음 |
| 다음 보기 | 장면 설명 / 정체가 긴 조건 연습 | 실제 소요·거리 / 같은 조건에서 대기 | 진입 전후 / 근거 조건 / 다른 선택 재도전 |

| 피드백 항목 | 표시 원칙 |
|---|---|
| 시간·거리·연료 | 실제 운행 결과와 사전 예상치를 구분. 비용은 [경제 기획](05-daily-operation.md) 적용 |
| 선택하지 않은 경로 | “대기보다 40초 손해”처럼 확정하지 않음. 같은 조건의 복습 또는 예상치로만 비교 |
| 승객 결과 | [매너·요구 달성](04-passengers-and-reservations.md)을 별도 카드로 표시. 법규 카드에서 자동 가감산하지 않음 |
| 판정 설명 | 해당 조건과 관찰 행동을 짧게 설명. 관련 조문이 여러 개여도 사건 횟수 중복 집계 금지 |
| 새로운 사건 | 우회로에서 만난 교차로·보행자 상황은 별도 사건으로 기록 |

### 중간에 선택을 바꾸는 경우

| 실제 행동 | 진행·히스토리 처리 |
|---|---|
| 대기 중 우회로 변경 | 허용된 구간·안전한 조건인지 확인하고 ‘대기 → 우회’의 실제 순서 기록 |
| 방향지시만 켠 뒤 직진 | 방향지시만으로 끼어들기 위반 처리하지 않음. 방해 여부 확인 후 ‘진입 검토 → 우회’ 기록 |
| 진입 중 상대 제동 후 복귀 | 출구 진입 실패와 이미 발생한 통행 방해 관련 판단을 분리 |
| 변경 금지 구간을 지나 우회 | 놓친 출구 수용으로 기록. 하지 않은 차로 변경에 준수 횟수를 부여하지 않음 |
| 조건·차량 반응 불명확 | 사실 보존, 해당 법규 판정 보류·준수율 집계 제외 |

### 변형과 누적 히스토리 예시

| 변형 | 바꾸는 조건 | 프로토 적용 |
|---|---|---|
| 여유 / 재촉 | 같은 도로에서 승객 대사·시간 여유만 변경 | 핵심 장면 안정화 후 단순 변형 |
| 승객 / 빈차 | 매너 요구가 없는 빈차에서도 동일 법규 적용 | 기록 범위 확인에 포함 |
| 안내를 놓침 | 안전한 출구 진입 기회를 지난 상태 | 다음 경로 안내 확인에 포함 |
| 타인의 위반 | 다른 차의 앞부분 진입 | 확장 후보. 따라 하기·급가속·차로 봉쇄 등 실제 행동 기록 |

다음 5회는 누적 표시 예시이며 성향 확정에 필요한 최소 횟수가 아니다. 도로·시야·교통 조건이 유사한 기록을 가정한다.

| 회차 | 조건 | 행동·법규 기록 |
|---|---|---|
| 1 | 승객 있음, 여유 | 뒤 합류. 관찰한 진로 변경 조건 준수 |
| 2 | 승객 있음, 재촉 | 앞부분 진입. 금지된 끼어들기·통행 방해 관련 판단 |
| 3 | 빈차, 여유 | 직진 우회. 출구 차로 변경 평가 기회 없음 |
| 4 | 승객 있음, 재촉 | 앞부분 진입 후 복귀. 이미 발생한 통행 방해 관련 판단 유지 |
| 5 | 승객 있음, 재촉 | 뒤 합류. 관찰한 진로 변경 조건 준수 |

| 표시 | 예시·제한 |
|---|---|
| 누적 요약 | “출구 정체 5건: 대기 2회, 우회 1회, 앞부분 진입 2회. 재촉이 있던 3건 중 2건에 관련 위반이 있었고 최근에는 뒤로 합류했습니다.” |
| 해석 | 재촉을 위반의 원인으로 확정하지 않음. 선택 횟수와 규칙별 평가 기회를 별도 집계 |
| 복습 | 2회차를 우회로 다시 해도 원래 영업 기록은 유지. 연습에서 다른 선택을 수행했다고 표시 |
| 연결 | 각 근거 장면을 열 수 있게 하고 기록 부족 안내·최근 변화는 [히스토리 기준](03-history-and-mastery.md) 적용 |

## 상황 2 — 보행 신호는 녹색인데 사람이 없는 우회전

보행 신호 색만 보고 행동을 결정하지 않도록 차량 신호·우회전전용신호·보행자 상태를 함께 읽는 장면이다. 아래는 제작 조건표이며 신호별 법적 판정은 [우회전 조건별 판정](02-driving-evaluation.md#우회전-조건별-판정)을 따른다.

**지도 연동 후속 적용:** 은계에서 진입 방향·정지선·차로 연결이 확인된 교차로 1곳을 먼저 선정한다. 최초 접근 시 차량 신호·우회전 전용신호·보행자 유무 등 **운전자가 볼 수 있는 조건만 제시**하고 ‘확인 후 판단 / 직접 운전’ 계획을 선택하게 한다. R1~R5는 같은 교차로를 다양한 조건으로 복습할 수 있지만, 영업 중 현실 시설로 오인할 수 있는 가상 신호는 명확히 구분하고 매 통과마다 조건을 강제로 바꾸지 않는다.

| 항목 | 프로토 설정 |
|---|---|
| 공통 질문 | “우회전할 횡단보도의 보행 신호는 녹색이고 건너는 사람이 없다. 무엇을 더 확인해야 하는가?” |
| 기본 장소 | 주간·양호한 시야의 짧은 가상 교차로. 우회전 경로상 어느 횡단보도인지 명확히 표시 |
| 필수 관찰 | 차량 신호, 우회전전용신호 유무·등화, 정지선, 교차 교통, 건너는 사람·건너려는 사람 |
| ‘사람 없음’ 조건 | 횡단 중인 사람뿐 아니라 건너려는 사람도 없음. 가려서 확인할 수 없는 경우와 구분 |
| 입력 | 감속·정지·주변 확인·진행을 실제 운전으로 수행. 보행 녹색이라는 이유만으로 자동 진행시키지 않음 |
| 기록 | 접근/정지/진행 시점의 신호 상태, 보행자 상태, 정지 위치·행동, 주변 영향, 조향 보조 사용 |
| 설명 | 신호·보행자 조건과 실제 행동을 나란히 표시하고 [02의 근거](02-driving-evaluation.md#우회전-조건별-판정)로 연결 |

| 조건 ID | 차량 신호 | 우회전전용신호 | 보행 신호·사람 | 확인 목적 |
|---|---|---|---|---|
| R1 | 적색 | 없음 | 녹색 / 건너거나 건너려는 사람 없음 | 차량 신호에 따른 정지·진행 조건 구분 |
| R2 | 녹색 | 없음 | 녹색 / 건너거나 건너려는 사람 없음 | R1과 비교하여 보행 신호 하나로 판단하지 않는지 확인 |
| R3 | 녹색 | 있음 / 적색 | 녹색 / 건너거나 건너려는 사람 없음 | 우회전전용신호를 확인하는지 검증 |
| R4 | 녹색 | 있음 / 녹색 화살표 | 적색 / 건너거나 건너려는 사람 없음 | 전용신호가 있는 별도 조건과 보행자 확인을 검증 |
| R5 | R1 또는 R2와 동일 | 없음 | 녹색 / 건너는 사람 또는 건너려는 사람 있음 | 같은 배치에서 보행자 조건만 바꾼 최소 변형 |

### 현재 연습 선택과 상황 진행

- 준비 화면과 Esc 일시정지 메뉴에서 **우회전 연습 선택 · 상황과 운전 요령**을 연다. R1~R5 및 R5 횡단 중의 6개 이름, 신호/보행자 조건, 운전 요령을 함께 표시한다.
- 연습 중 **F6 / 조건 변경 · 다시 연습**으로 선택창을 연다. 메뉴 동안 정지하며 취소하면 기존 상태로 돌아간다. 선택을 확정하면 해당 상황 출발점으로 돌아가고 이전 연습 판정은 유지한다. 결과는 조건 변경 포함으로 구분한다.
- 영업 중 연습은 별도 창에서 실행한다. 원래 승객·돈·연료·영업 시간을 유지하고, 연습 종료 후 일시정지 상태의 원래 영업으로 돌아온다.
- 기존 교차로 85m 접근 타이머를 폐기했다. R1은 적색을 유지하며 정지 후 확인·서행 우회전을 연습한다.
- R3은 진입 방향 정지선 앞 3m 이내의 정차를 확인한 뒤 4초 후 전용 녹색으로 바뀐다. R5 두 장면은 같은 정차 확인 뒤 보행자가 횡단을 진행하고 6초 후 통행이 끝난다. 느린 접근이나 멀리서 대기하는 동안 조건이 사라지지 않는다.
- 위 4초/6초는 장면 연출 시간이며 법규상 정지 시간이나 새 감점 기준이 아니다. 정지선 위치·차로·차량 앞부분·정차 속도 허용치는 기존 판정 기준과 맞춘다.

R1·R2를 핵심으로 제작하고 R3·R4는 전용신호 판정 비교에 필요한 최소 변형으로 둔다. R4는 보행 녹색 고정 사례와 분리하며, 모순된 동시 신호를 만들지 않도록 신호 운영을 먼저 확정한다. 보행자를 회피 불가능한 거리에서 갑자기 생성하지 않는다.

## 은계 일반 영업의 법규 상황 구역 (2026-10-20)

사용자 요청의 최종 적용 위치는 기본 은계 지도다. 승객 승차 후 목적지까지 내비가 점멸·출구 정체·비보호 좌회전 구역을 경유하고, 같은 차량으로 상황 판단과 운송을 이어간다. 지도/차량 교체·자동 일시정지 없이 결과 알림과 정차 시 상세 설명을 제공한다. 선택형 연습은 동일 조건 재시도 수단으로 유지한다. [배치 7곳·시간 예산·관찰·검증](../eungye-in-service-law-zones.md)을 따른다. 이 연속 운송 기능은 P4의 자동 정지·운전 계획 팝업을 완료했다는 뜻은 아니다.
