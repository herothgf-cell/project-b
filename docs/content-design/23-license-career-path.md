# 23 개인택시 면허 경로 (본편 기획 · 보류)

**상태: 기획·설정 초안(2026-11-10) · 본편 기획 단계로 보류 · 미구현.** 사용자 결정에 따라 지금 개발하지 않고, 본편 범위를 정할 때 다시 검토한다. 현재 시놉시스([10](10-restarting-driver-synopsis.md))의 "중고 개인택시로 시작"은 그대로 유지한다. 관련 결정은 [22 §8](22-growth-direction-and-vehicle-purchase.md).

## 1. 왜 검토하는가

- **한국 택시 기사만의 성장 경로**다. 법인택시 기사로 일하며 무사고 경력을 쌓고, 개인택시 면허를 사서 "내 택시"를 갖는 흐름은 해외 택시 게임에 없는 USP다.
- 이미 있는 **운전 점수(법규 준수·사고)** 가 장기 목표와 직접 연결된다. 지금은 3일 안에서만 의미가 있다.
- "내 차·내 집"에 더해 **"내 사업"** 이라는 세 번째 장기 목표가 생긴다.

## 2. 현실 참고 (게임에서는 단순화)

| 현실 요소 | 참고 내용 | 게임 처리 |
|---|---|---|
| 개인택시 면허 양수 | 운전 경력·무사고 기간, 교통안전교육, 운전적성 정밀검사 등이 필요. 최근 "5년 이상 무사고" 방향으로 정리되는 추세라는 안내가 있음 | "무사고 영업일 N일 + 운전 점수 기준"으로 단순화 |
| 면허(번호판) 가격 | 지역별 차이가 크고 서울은 1억 원 안팎 거래 사례가 보도됨 | 게임 화폐로 큰 장기 목표 가격. 현실 가격을 그대로 쓰지 않음 |
| 법인택시 근무 | 회사 차를 쓰고 사납금 또는 월급제로 정산 | 하루 정산에 "회사 납입금" 항목 추가 |

현실 제도는 지역·시기에 따라 바뀐다. 채택 시 한국교통안전공단·지자체 기준을 다시 조사하고, 게임 안에서는 "실제 절차 안내가 아님"을 명시한다.

## 3. 설정 변형안

| 구분 | 현재 시놉시스(10) | 면허 경로 변형 |
|---|---|---|
| 시작 | 남은 자금으로 중고 개인택시를 사서 시작 | 실직 후 **법인택시 회사에 취업**해 회사 차로 시작 |
| 초반 동기 | 오늘 일을 해낼 수 있다는 확인 | 같음 + 회사 납입금을 넘겨 남는 돈 만들기 |
| 중반 | 차·집 목표 선택 | **무사고 기록**을 쌓으며 면허 자금 저축 |
| 전환점 | 차량 교체 | **개인택시 면허 취득** → 내 택시 구매·꾸미기 시작 |
| 후반 | 이사·정착 | 같음(이사, 내 택시 꾸미기) |

두 안을 합치는 방법도 있다: 캠페인 시작 시 "법인 기사로 시작 / 중고 개인택시로 시작"을 고르게 하고, 면허 경로를 긴 모드로 둔다.

## 4. 게임 시스템 연결

| 시스템 | 현재 | 면허 경로에서의 역할 |
|---|---|---|
| 운전 점수 | 3일 캠페인 안 법규 평가 | 면허 자격의 핵심 기록(무사고·벌점 누적) |
| 사고·공업사 | 사고 등급·수리비 | 중대 사고 시 무사고 기록 초기화 |
| 하루 정산 | 수입·비용·순수익 | 법인 기간: 회사 납입금 차감 |
| 차량 구매(22) | 3일 안 교체 1회 | 법인 기간에는 불가, 면허 취득 후 가능 |
| 기사 평점(22 보류) | 없음 | 법인 회사 평가·배차 우선권으로 재활용 가능 |
| PvP | 외형만 공유 | 영향 없음 |

## 5. 할거리 (마인드맵에 추가)

마인드맵 `기존 아이디어·후속 구상 > 개인택시 면허 경로 (기획23, 본편 보류)` 아래에 0%로 등록했다.

1. 시작 형태 결정: 법인 시작 / 개인 시작 / 선택형
2. 법인택시 정산: 회사 납입금(사납금)·월급제 중 방식과 금액
3. 무사고 기록 규칙: 기간, 초기화 조건(사고 등급·벌점)
4. 면허 자격 조건 단순화: 영업일·운전 점수·교육 이벤트
5. 면허 가격과 저축 페이스(R 배수)
6. 면허 취득 연출과 이후 개인 영업 전환(차량 구매 연결)
7. 현실 제도 재조사(교통안전공단·지자체 최신 기준)
8. 시놉시스(10)·성장 단계(12) 개정 범위

## 6. 보류 해제 조건

- 3일 캠페인과 차량 교체(22)의 사람 플레이 검증이 끝나고,
- 본편 범위(연속 경력·플레이 시간)를 정할 때 함께 검토한다.
