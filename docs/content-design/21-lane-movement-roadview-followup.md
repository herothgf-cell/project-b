원본 차로 번호는 차로 수가 아니다. 짧은 NGII 조각을 건너 실제 활성 출구까지 확인해 역할을 그린다. 기하학적 회차 연결은 기존 그래프에서만 읽으며 새 유턴 허용 지점·조건·신호 단계를 만들지 않는다. 분리된 우회전 길에 활성 출구가 없으면 임의의 우회전 화살표를 추가하지 않는다. 같은 물리 차로의 연속 조각은 표시를 중복하지 않고, 말단 조각도 임시 경계 제거 범위에 포함한다.

## 주차장 안내 중 좌회전 누락

실행 시 `EungyeConnectivityRepair`가 원본 차로를 나누지만 생활 시설의 `laneAt`이 나뉘기 전 값으로 남았다. 주차장 목표가 분할 조각 길이를 초과해 약52.25m 앞에 잘못 잡혔고, 현재 경로 검사가 이를 거부해 방향지시등 없는 공유 차로의 좌회전 수요가 빠졌다. 같은 분할 규칙으로 런타임 생활 시설의 차로와 거리만 옮겨 목표의 원래 위치·진행 방향을 보존한다. 작성 지도 원본과 사용자 저장은 바꾸지 않는다. 수요의 경로 검증·금지 접근·기존 신호 시간은 유지한다.

재현 검사는 실제 M지도→영업 시작·마감 주차장 안내→J7917_2565 동향 35/20/10/6m 접근→Q 꺼짐60초/켜짐60초 대기를 사용한다. 위치 제어 검사이며 사람 주행 또는 전체 캠페인 검사가 아니다.
