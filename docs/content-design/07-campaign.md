# 프로토타입 캠페인과 진행 목표

기준일: 2026년 10월 16일 · 버전: 0.6 · 상태: 구현 6de26a5 및 검증 결과 대조

실직한 주인공이 개인택시 운행으로 생계를 이어간다. 짧은 기간의 수입 목표가 운행의 목적을 만들고, 경로 판단과 법규 성향 기록이 반복 플레이의 차이를 보여준다.

## 현재 구현과 검증 범위

3일 × 하루 480초·순수익 30,000원, 보험 갱신·세금 납부 성공 조건이 현재 기본값이다. 준비·마감·마지막 운송·정산·결과·저장 복원을 연결했다. 최종 자동 주행은 6건/실패 0건, 운임 65,400원·순수익 39,209원으로 성공했다.

**남은 확인:** 자동 조향/가감속, 일반 차량 제외 조건의 검사다. 일별 법규 80점으로 무위반 완주 증거가 아니며 정상/우회/위반 선택의 반복 수동 캠페인 비교는 미완료다.

근거: [통합 검증](../prototype-completion-validation.md) · [개발 체크리스트](../prototype-development-checklist.md). 아래 상세 표는 목표 설계를 포함하므로 표의 ‘포함’만으로 검증 완료를 뜻하지 않는다.

## 프로토타입 범위

| 포함 | 제외 |
|---|---|
| 날짜·하루 영업 시간·순수익 목표·일일 정산·성공/실패·재도전 | 장편 서사·다지역 해금·무한 경영·차량 구매·법인 모드 |
| 기본 영업과 상황 체험을 연결한 짧은 캠페인 | 법규 점수로 강제 게임오버, 승객 매너로 법규 이력 삭제 |
| 하루 정산 저장과 이어하기 | 운행 중 모든 상태의 즉시 저장 |
| 보험 만료·세금 기한을 직접 관리하는 3일 일정 | 개인 예약·단골·사고·수리 콘텐츠는 기획만 |

## 기간과 목표

| 항목 | 현재 프로토 값 | 과거 v1 값 | 상태 |
|---|---|---|---|
| 기간 | 3일 | 7일 | 현재 기본값 적용 |
| 하루 영업 | 8분 | 10분 | 현재 기본값 적용 |
| 목표 | 누적 순수익 30,000원 | 100,000원 | 현재 기본값 적용, 테스트 후 밸런스 조정 |
| 총 플레이 | 영업 24분 + 마지막 운송·결산 | 영업 최대 70분 + 마지막 운송·결산 | 목표 시간이며 실측 아님 |
| 운영 현금 | 10,000원 제공, 목표에서 제외 | 초기 현금 없음 | 현재 적용 |

3일 × 8분을 기본으로 설계한다. 거점 이용·연료 지원의 시간 경과로 실제 조작 시간은 줄 수 있고, 마지막 운송·메뉴·결산 시간은 추가된다. 운행 수입·비용을 측정하여 목표 달성 난도를 조정한다.

## 하루 진행과 종료

| 상태 | 시작·전환 | 플레이어에게 표시 |
|---|---|---|
| 준비 | 주차장에서 시작, 보험 유효 여부 확인 | 날짜·목표 잔액·연료·보험 만료·세금 기한 |
| 영업 | 호출·길가 승객·거점 방문 | 남은 영업 시간·현재 매너·현금 |
| 마감 예고 | 종료 60초 전 마감 임박 표시 | 신규 장거리 운송에 주의 안내 |
| 마감 | 시간 만료 또는 주차장 종료 선택 | 신규 수락 중단, 미탑승 호출 취소 |
| 마지막 운송 | 탑승 중인 임무만 처리 | 원래 운송 기한 유지. 초과하면 기존 실패 처리 |
| 정산 | 마지막 운송 완료·실패 후, 납부 확인 | 비용·미납·예정 납부·목표·법규 성향·승객 결과 |
| 다음 날 | 성공 조건 미충족이고 남은 날짜 있음 | 완료 정산 저장 후 다음 날 준비, 출발 전 보험 유효 확인 |
| 결과 | 수익·납부 조건 달성 또는 최종일 | 성공·부족액·미납·다시 시작 |

일시정지·결과 확인·복습에서 영업 시간은 흐르지 않는다. 거점 이용·연료 고갈 복구의 시간 경과는 [경제 문서](05-daily-operation.md)를 따른다. 사고에 따른 운송 종료·수리·보험 청구는 프로토에 넣지 않는다.

## 목표와 평가 분리

| 항목 | 캠페인에 미치는 영향 |
|---|---|
| 목표 달성액 | 현금 − 시작 운영 현금 − 미납. 상세 장부는 경제 문서 기준 |
| 성공 | 하루 정산 후 목표 이상이고 캠페인의 보험 갱신·세금 납부 완료. 모두 충족하면 조기 성공 가능 |
| 실패 | 최종일 목표 미달 또는 납부 조건 미충족. 보험 만료 후 갱신 자금이 없으면 출발 불가·도전 종료 선택 |
| 법규 성향 | 별도 운전 결과. 수익 성공을 법규 준수 인증으로 표시하지 않음 |
| 승객 매너 | 각 운송의 지급률에 반영, 법규 성향과 독립 |
| 미납 | 목표 달성액에 이미 반영. 결제 때 이중 차감하지 않음 |
| 예정 납부 | 기한 전 금액은 별도 표시. 아직 납부하지 않은 비용을 남기고 조기 성공하지 않음 |

보험·세금 관리는 단순한 납부 일정 체험이다. 1일차부터 미리 결제할 수 있으며 실제 연간 보험료·세무 신고·법정 기한은 재현하지 않는다.

## 날짜별 납부 일정 제안

| 날짜 | 확인할 일정 | 플레이 선택 |
|---|---|---|
| 1일차 | 기존 보험 2일차 종료 만료·세금 3일차 마감 기한 | 먼저 납부하거나 영업 자금을 남기기 |
| 2일차 | 보험 만료 안내 | 주차장에서 갱신, 3일차 영업 준비 |
| 3일차 | 갱신된 계약·세금 납부 확인 | 미납 세금 결제 후 최종 목표 확인 |

날짜 배치는 테스트용이다. 보험은 기존 계약의 만료가 임박한 설정이며 매 3일마다 갱신하지 않는다.

## 하루별 체험 구성 제안

| 단계 | 체험 | 유도 방법 |
|---|---|---|
| 첫 운행 | 조작·안전한 승하차·매너 조건 | 짧은 동선과 간단 안내 |
| 출구 상황 | 대기·우회·앞부분 진입 | 같은 목적지에 대체 경로 제공 |
| 우회전 상황 | 신호·보행자 조건 읽기 | 사람이 없는 기본 장면과 보행자 있는 비교 장면 |
| 거점 이용 | 주유·식사·마감 | 연료·미식사 안내, 가까운 거점 |
| 이후 운행 | 익숙한 길에서 스스로 판단 | 같은 위치만 암기하지 않도록 조건 변형 |

상황 전용 연습은 별도 진입도 가능하다. 반복 연습에 운임·비용·캠페인 시간이 붙지 않으며 본 캠페인 성향을 덮어쓰지 않는다. 모든 운송에 강제 사건을 넣지 않는다.

## 1일차부터 다시 시작

준비 화면·Esc 일시정지·하루 정산 화면의 **1일차부터 다시 시작**을 누르면 확인창을 연다. 확인 후 새 캠페인 저장에 성공했을 때만 1일차 준비로 돌아간다.

- 초기 상태: 현금 10,000원, 연료 35%, 미납 0원, 순수익 0원, 보험 미갱신·세금 미납(기한 전).
- 현재 승객·내비 경로와 운송/법규/연습 기록을 초기화하고 임시 주차장에서 정차 상태로 시작한다.
- 취소·저장 실패는 현재 캠페인과 저장을 보존한다. 저장 실패 시 재시작을 다시 요청할 수 있다.
- 결제 확인·기록 열람·별도 복습 실행 중에는 재시작을 겹쳐 실행하지 않는다. 같은 확인 입력을 반복해도 한 번만 처리한다.
- 기존 종료 결과의 새 도전도 같은 확인 화면을 사용한다. 은계 맵 선택은 유지한다.

## 난도 조정과 완료 기준

| 확인 항목 | 기준 |
|---|---|
| 합법적 운행 | 규칙을 지키는 기본 운송과 대기로 목표를 달성할 여지가 있음 |
| 시간 | 최초 전체 체험과 재도전의 실제 소요를 측정 |
| 경제 | 몇 건의 정상 운송이 일일 비용을 감당하는지 실측 |
| 선택 | 특정 경로가 모든 교통 조건에서 정답이 되지 않음 |
| 저장 | 다음 날 시작·종료·재시작에서 수입과 비용 중복 없음 |
| 결과 | 수익 결과와 법규 성향·승객 매너를 구분해 이해 가능 |

초기 검증은 3일 캠페인으로 정상 운행 3회, 우회 선호 3회, 법규 위반 선택 포함 운행 3회를 비교하는 제안이다. 추가로 납부 누락·자금 부족·연료 고갈 분기를 확인한다. 사고 콘텐츠는 검증 범위에서 제외한다. 목표액·비용·운송 기한은 결과에 따라 조정한다.
