# 개인택시 경제와 생활 거점

기준일: 2026-10-26. 현재 구현 규칙을 통합했다. 이전 수치·설계 변경은 [변경 이력](../design-history/content-design/05-daily-operation-history.md), 실행 검증은 [최신 작업 기록](../work-history/LATEST.md)을 따른다. 기본은 [3일 캠페인](07-campaign.md)이며 하루 20분 뒤에도 초과 영업할 수 있다.

## 수입과 정산

| 콘텐츠 | 조건·처리 | 상태 |
|---|---|---|
| 운임·보너스 | 하차 확정 시 실제 지급액을 동일 운송 ID에 한 번 입금. 계산은 [04 운임과 보너스 계산](04-passengers-and-reservations.md#운임과-보너스-계산)이 단일 기준 | 구현 |
| 운송 완료창 | 기본 운임(변경 전 최초 예상) / 운임 조정(최초 예상 대비 실제 증감) / 최종 운임(실수령)의 3줄. 예: 5,000 / -1,500 / 3,500원 | 구현 |
| 계산 상세 | 완료창의 운임 조정은 순증감 표시이며 계산용 만족도 보너스와 구분. F8의 실제 기본 지급액·보너스 분해 보존 | 구현 |
| 중복 방지 | 결과창 닫기·생활 거점 선택·재실행으로 재지급하지 않음 | 구현·자동 검사 |
| 밸런스 | 수익·운송량·생활 시간은 사용자 직접 플레이로 확인. 거래 검사를 근거로 경제 체감 완료 처리하지 않음 | 수동 확인 남음 |

## 비용과 이용 조건

가격·회복량은 게임 시험값이다. 아래 시간은 영업 경과 초이며, [10 운전자](10-driver-condition.md)의 컨디션도 함께 반영한다. 영업 중인 빈차가 지정 위치·방향으로 정차한 뒤 F7 메뉴에서 확인한다. 취소는 돈·시간·회복에 영향을 주지 않는다.

| 항목 | 비용 | 소비 시간·효과 | 제한·회계 |
|---|---:|---|---|
| 주유 | 실제 보충 1%포인트당 40원, 원 단위 올림 | +10%포인트 버튼마다 10초, 공회전 소모 반영 | 잔여 용량만 구매, 현금 부족 시 불가, 반복 구매 메뉴 유지 |
| 식사 | 3,000원/회 | 50초 경과 후 포만감 +70(상한 100) | 잔액 부족분 미납, 반복 이용마다 별도 비용. 마감 자동 식비 없음 |
| 수면 | 무료 | 100초·피로 -40, 수면 중 포만감 감소·통상 피로 증가 없음 | 주차장·휴식 구역, 미탑승 호출은 취소 후 이용 |
| 휴식·영업 종료 | 수면 무료, 하루 주차 500원 | 수면 100초·피로 -40 후 그날 정산 | 빈차·주차장 또는 휴식 구역. 주차비는 하루 한 번 |
| 세차·실내 청소 | [15 청결·세차 기준](15-drunk-passengers-and-cleanliness.md) | 기존 주유소에서 주유와 별도 선택 | `wash` 비용·부족분 미납·중복 청구 방지. 구토 후 호출 잠금과 해제도 15 기준 |
| 연료 고갈 지원 | 연료 800원 + 지원 1,000원 | 20% 보충·30초 | 필수 지원 부족금 미납, 사고 수리비와 구분 |
| 보험·세금·사고·수리 | 없음 | 프로토 제외 | 갱신·납부 일정·청구·관련 성공 조건 없음 |

예정 시간보다 서비스 시간이 길거나 초과 영업 중이어도 식사·수면·세차를 이용할 수 있다. 이용 중 최초 20분 경계를 넘는 경우의 피로 처리는 [10](10-driver-condition.md)을 따른다. 서비스 확정별 거래 ID로 비용·시간·회복을 한 번만 적용한다.

호출 수락 후 **승차 전에는 주유·세차 가능**하다. 호출/승객 ID를 유지하며 주유 10초·세차 30초는 승객 대기시간에서도 차감한다. 대기시간이 소진되면 기존 호출 만료로 처리한다. 이용 또는 메뉴 종료 후 픽업 안내로 돌아온다. 탑승 중에는 이용할 수 없다.

F7은 **현재 정차한 시설의 서비스만** 표시한다. 주유소는 그 시설의 주유/지원되는 세차, 식당은 식사, 주차·휴식 거점은 수면/영업 종료다. 시설 밖 F7은 전체 목록을 열거나 시간을 멈추지 않고 M 지도 안내를 TIP에 표시한다. 다른 시설 탐색·길안내는 M에서 한다. 픽업 중에는 M 주유소 길안내만 허용하며 현재 호출·기한은 유지한다.

지도와 F7은 같은 시설 능력을 사용해 `주유 전용`/`주유+세차`를 구분한다. 현재 은계 3곳은 모두 주유+세차를 지원한다. 구분을 보여주기 위해 기존 시설의 세차를 임의로 제거하지 않는다. 별도 중앙 생활 안내 패널은 없애고 기존 좌측 스크롤 TIP에 서비스 목적지·오류 알림을 통합한다.

## 시설과 접근

| 시설 | 위치·동선 | 가능한 행동·조건 |
|---|---|---|
| 주유소 3곳 | 게임시설, 입구·정차 구역·출구 구분 | 빈차로 지정 방향 정차 후 주유 또는 세차 선택 |
| 은계 남부 식당 | 남부 블록 남측 독립 건물·간판·주차 칸·진입/출구. 승하차 7과 별개 | 내부 지정 칸에서만 식사. 도로변·입구·칸 밖·반대 방향·이동 중·탑승 중 불가 |
| 식당 메뉴 | 제육백반·된장찌개 정식·소고기국밥 | 가격·시간·회복 동일. 선택만으로 결제하지 않음 |
| 식당 안내 | 지도 핀은 내부 칸, 내비/H 목적지는 도로 입구 접근점 | 입구부터 H를 끄고 직접 주차. 주유·수면·마감 제공 안 함 |
| 기존 주차장 | 기본 출발·휴식·마감 거점 | 수면 / 영업 계속 / 휴식·영업 종료 |
| 동부 휴식 구역 | 주유소 출구 뒤 같은 방향 약 80m, 게임용 별도 주차면·진입/진출 유도선 | 무료 수면·휴식 후 마감 가능, 주유 없음 |
| 하차 후 생활 안내 | 주유·식사·수면·귀가 주차장과 실제 방향 경로 거리 표시 | 연료 15% 이하·포만감 25 미만·피로 70 이상·예정 마감 3분 이내·거리로 추천. 청결 관련 우선순위는 15 기준 |

생활 안내는 플레이어가 선택할 때만 내비를 변경하며 시계 정지·자동 결제·자동 마감을 하지 않는다. 실제 이용은 도착 후 F7로 확인한다. 게임시설을 실제 상호·필지·운영 정보로 표현하지 않는다. 원본 도로에 시설용 지름길을 추가하지 않는다.

| 메뉴·복습·순간 이동 | 정지 시간과 순간 이동 거리를 연료 소비에 추가하지 않음 |

## 장부·저장

| 항목 | 계산·정책 |
|---|---|
| 시작 자금 | 새 캠페인 10,000원, 수익에서 제외 |
| 현금 | 시작 자금 + 실제 입금 − 실제 결제 |
| 미납 | 식사·세차·주차·필수 지원에서 발생했으나 아직 결제하지 못한 비용 |
| 누적 순수익 | 현금 − 캠페인 시작 자금 − 미납. 미납 결제 때 현금·미납을 함께 감소해 비용 중복 차감 방지 |
| 하루 순수익 | 해당 날짜 운임 − 해당 날짜 발생 비용(미납 포함). 이전 날짜 미납을 다시 비용으로 계산하지 않음 |
| 결과 | 수입·비용·미납·순수익·운송 건수·식사/수면 횟수와 시간·종료 연료/컨디션·실제 영업시간 |
| 적자·평가 | 적자도 유효 결과. 연료 잔량을 현금으로 환산하거나 법규 점수와 합산한 종합 순위를 만들지 않음 |
| 저장 | v3 중단 운송·시간·장부·컨디션·청결·대기를 함께 복원. 운행 사건 즉시 저널 보존 |
| 새 캠페인 | 확인·저장 성공 후 새 ID·초기값 적용. 취소·저장 실패 시 현 상태·기존 파일 보존 |
