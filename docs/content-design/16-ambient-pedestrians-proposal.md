# 일반 보행자 추가 검토·승인안

작성2026-10-26 · **A안 사용자 승인 / 구현 진행 중**. 사용자 “구현 진행해줘”에 따라 4거점 최대12명 안을 구현한다.

## 검토 결과
기존 [월드·운전 기획06](06-world-map-and-driving.md#ai-차량과-보행자)은 우회전 판단을 위한 소수 상황 보행자와 승하차 승객의 역할 분리를 기획했다. 기본 은계의 일상 보도 보행은 아직 없다. R5/PS09 상황 보행자와 편집 횡단 Walker는 일부 구현돼 있다.

기본 정식 문서에는 신호 프로그램0개와 명시 횡단보도3개가 있어, 연결 프로그램을 요구하는 `RoadMapFacilities`의 편집 Walker 자동 생성은 현재 충족되지 않는다. 보행 신호등을 표시하는 것과 행인을 생성하는 것은 별도다. `document.scene` 객체23,229개 중 보도18,200개가 있지만, 그 수가 안전한 보행 경로 수를 뜻하지 않는다.

기존 Walker에는 보도 이동/안전 접지/횡단 의도/저장이 없고 같은 녹색에 시작점으로 되돌아갈 수 있다. 차량 양보도 관련 횡단 경로와 완주까지의 점유를 연결해야 한다. 새 보행자를 단순히 켜는 것만으로는 충분하지 않다.

A안은2026-10-26 사용자 승인되었다. 다음 수치와 동작을 구현 기준으로 사용한다. 거점은 [위치 검토 기록](../work-history/2026-10-26-junction-trip-followups.md)의 사거리들을 사용한다. T2의 안전 보행 경로는 추가 확인이 필요하다.

## A안의 실제 동작
- **보도 보행8명:** 검증된20~40m 보도 구간을1.2~1.4m/s로 걷고 끝에서 잠깐 쉰다. 몸통 반경과 여유까지 보도 안에 두고 실제 보도 높이를 따른다. 건물·난간·물·차로를 가로지르지 않는다.
- **횡단 최대4명:** 보도 대기→해당 보행 녹색·차량 비점유 확인→횡단→반대 보도 도착. 적색과 녹색 마지막2초에는 새로 진입하지 않는다. 같은 녹색에 재횡단/순간 이동하지 않는다.
- 횡단 도중 적색으로 바뀌어도 도착까지 계속 보호한다. 관련 경로의 차량만 양보하고, 보도에서 걷거나 적색을 기다리는 사람 때문에 사거리 전체를 막지 않는다. 정지선을 지난 차량도 앞의 횡단자를 보호한다.
- 상황용 R5/PS09가 같은 횡단을 사용할 때는 일반 횡단을 겹쳐 생성하지 않는다. 상황 보행자도12명 예산 안에서 관리한다. 신호와 도로를 임의로 만들어 숫자를 채우지 않는다.
- 최초 배치는 월드 표시 전, 이후 보충은 카메라 밖·택시80m 이상·안전 보도일 때만 한다. 횡단 중에는 화면 밖이라는 이유로 사람/점유를 지우지 않는다.
- 보행 상태와 진행 위치를 저장하고, 재시작할 때 횡단 점유를 차량 이동보다 먼저 복원한다. 기존 저장에 보행 정보가 없으면 안전한 보도 대기 상태로 시작한다.
- 사람은 차를 튕기게 하는 물리 장애물 대신 이동/점유로 양보를 연결한다. 접촉은 기존 충돌 사건으로 한 번만 기록하며 별도 사고 요금은 추가하지 않는다. 기존 시나리오와 법규 판정의 중복을 막는다.

## 승인 후 필수 확인만 수행
1. 실제 배치 경로와 대표 횡단 한 곳에서 접지·장애물·적색 신규 진입 금지·녹색 진입·적색 전환 후 완주까지 차량 양보를 확인한다.
2. 승객/행인이 함께 있는 화면에서 외형·F 입력·지도 핀이 구분되는지 확인한다.
3. 횡단 중 저장·재시작 한 번으로 진행 위치/양보 점유와 중복 생성·판정 방지를 확인한다.

이 짧은 검사에서 오류나 성능 문제가 생겼을 때만 원인을 확인하는 검사를 추가한다. 현재는 설계 검토만 수행했으며 자동 물리·수동 플레이 결과가 아니다.
