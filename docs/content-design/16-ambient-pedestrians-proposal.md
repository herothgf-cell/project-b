# 일반 보행자·횡단·차량 양보

현재 기준: 2026-10-27. 상황용 보행자·승객과 별도로 안전6슬롯(보도3·횡단3)을 사용한다. 초기 A/B안과 구현 전 조사는 [기획 변경 이력](../design-history/content-design/2026-10-27-design-decisions.md)에 분리한다.

## 행동·결과·영향

| 조건·상태 | 보행 행동 | 차량·평가에 미치는 영향 | 보호·예외 |
|---|---|---|---|
| 검증된 안전 보도 | 1.2~1.4m/s 이동, 끝에서 잠시 쉼 | 배경 생활감. 승객 탑승/F 입력·개별 지도 핀 없음 | 실제 높이·몸통 여유·건물/난간/차로 간섭 검사 |
| 일반 횡단 대기 | 해당 보행 신호 녹색·차량 비점유일 때 출발 | 관련 차량 경로에만 횡단 점유·양보 연결 | 적색/녹색 마지막2초 신규 진입 금지 |
| 이미 횡단 중 적색 전환 | 반대 보도까지 횡단 유지 | 완주까지 양보 유지 | 적색이 됐다고 사람을 제거하지 않음 |
| 횡단 완료 | 보도 대기 | 같은 녹색에 즉시 재횡단하지 않음 | 시작점 순간 이동 없음 |
| 지정 무단횡단 | J5076_2580의 한 명만 정상5회 완료 후 적색8초 이상 대기·안전 조건을 충족하면 출발 | 보이는 보행자 위험에 대응 필요 | 모든 일반 행인이 적색 출발하는 정책 아님. 횟수/대기/상태 저장 |
| 상황용 보행자 중복 | 같은 횡단 일반 슬롯을 숨김 | 중복 점유·차량 양보 중복 방지 | 횡단 중에는 감추지 않음 |
| 상황 종료 후 재표시 | 카메라 밖·택시80m 이상에서 복귀 | 화면 안 갑작스러운 생성 방지 | 초기6명 외 동적 인원 보충 없음 |
| 보행자 접촉·보호 위반 | 기존 실제 관찰 사건 기록 | 해당 충돌·법규 규칙 적용, 별도 사고 비용 없음 | 상황/일반 중복 판정 방지. 신호 색만으로 사람 유무를 생략하지 않음 |
| 저장·재실행 | 진행 위치·신호 예외·횡단 점유 복원 | 차량 이동보다 횡단 점유 먼저 복원 | 구형 저장은 안전 보도 대기에서 시작 |

NPC는 연결된 횡단 경로에 자동 양보한다. 수동/H 운전에서 가감속·제동 판단은 운전자 책임이며, 주변 사람이 자동으로 사라지거나 차량을 강제로 피해 주지 않는다. 게임의 지정 무단횡단은 현실 규제 판단의 근거가 아니다.
