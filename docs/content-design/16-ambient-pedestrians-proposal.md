# 일반 보행자 추가 검토·승인안

작성2026-10-26 · **A안 사용자 승인 / 안전6슬롯 소스 구현·실행 검증 중**. 사용자 “구현 진행해줘” 승인으로 보도3명·횡단3명을 구현했다.

## 검토 결과

기존 [월드·운전 기획06](06-world-map-and-driving.md#ai-차량과-보행자)은 우회전 판단을 위한 소수 상황 보행자와 승하차 승객의 역할 분리를 기획했다. 구현 전 기본 은계에는 일상 보도 보행이 없었다. R5/PS09 상황 보행자와 편집 횡단 Walker는 일부 구현돼 있다.

기본 정식 문서에는 신호 프로그램0개와 명시 횡단보도3개가 있어, 연결 프로그램을 요구하는 `RoadMapFacilities`의 편집 Walker 자동 생성은 현재 충족되지 않는다. 보행 신호등을 표시하는 것과 행인을 생성하는 것은 별도다. `document.scene` 객체23,229개 중 보도18,200개가 있지만, 그 수가 안전한 보행 경로 수를 뜻하지 않는다.

기존 Walker에는 보도 이동/안전 접지/횡단 의도/저장이 없고 같은 녹색에 시작점으로 되돌아갈 수 있다. 차량 양보도 관련 횡단 경로와 완주까지의 점유를 연결해야 한다. 새 보행자를 단순히 켜는 것만으로는 충분하지 않다.
