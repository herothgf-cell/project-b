# 운전자 설정과 하루 컨디션

기준일: 2026-10-21 · 버전: 0.1 · 상태: 합의 방향을 구체화한 기획, 미구현

하루 20분의 영업에서 식사·수면 시점을 선택하고 하루 수익을 비교한다. 배고픔·피로는 영업 가능 시간에 영향을 주며 조향·가속·제동·시야를 강제로 바꾸지 않는다. 수치와 시간대는 아래 테스트 초깃값이며 실제 생리 기준이 아니다.

## 캐릭터 설정과 역할

| 항목 | 설정 |
|---|---|
| 배경 | 경기 악화로 실직한 뒤 개인택시로 생계를 이어가는 운전자 |
| 시작 | 차량 한 대가 준비된 상태. 면허 취득·차량 구입 과정 생략 |
| 하루 목적 | 운송·경로·식사·휴식을 스스로 배치하고 얼마를 남겼는지 확인 |
| 성장 | 플레이어의 판단 숙련. 캐릭터 능력치 구매·운전 성능 강화 제외 |
| 이름·나이·성별 | 프로토 진행 조건으로 고정하지 않음. 외형·대사 확정 때 별도 결정 |
| 반복 조건 | 같은 시작 현금·연료·컨디션으로 새 하루 시작. 이전 수익·피로 이월 없음 |

## 포함과 제외

| 포함 | 제외 |
|---|---|
| 포만감·피로 수치, 단계별 안내 | 스트레스·질병·체력 등 추가 능력치 |
| 식당 식사·지정 주차장 수면 | 실내 보행·침대 조작·수면 미니게임 |
| 피로 한계의 신규 승객 수락 제한 | 자동 핸들 틀기·제동 지연·졸음 암전·강제 충돌 |
| 식사·수면에 따른 영업 시간 소비 | 컨디션만으로 운행 점수·매너·운임 자동 감점 |

## 수치와 변화 제안

시간 단위는 [캠페인](07-campaign.md)의 영업 예산이다. 1분은 실제 주행 60초에 해당하고, 게임 시각으로는 36분이다.

| 요소 | 초깃값·범위 | 변화 | 영향 |
|---|---|---|---|
| 포만감 | 시작 80, 범위 0~100 | 깨어 있는 영업 및 수면의 예산 1분당 -5 | 25 미만이면 배고픔 안내·깨어 있을 때 피로 증가율 1.5배 |
| 피로 | 시작 10, 범위 0~100 | 깨어 있는 예산 1분당 +4, 배고프면 +6 | 70부터 휴식 권장, 100이면 신규 운송 수락 불가 |
| 식사 | 식당에서 3,000원 제안 | 게임 30분 = 예산 50초 소비, 완료 시 포만감 +70(상한100) | 경과 중 통상 피로 증가, 수면을 대신하지 않음 |
| 수면 | 지정 주차장에서 추가 이용료 없음 | 게임 60분 = 예산 100초 소비, 완료 시 피로 -40(하한0) | 수면 중 통상 피로 증가 없음, 포만감은 경과만큼 감소 |
| 일시정지·메뉴·복습·결과 | 변화 없음 | 컨디션·영업 시계 정지 | 창을 오래 열어 상태가 회복되지 않음 |

식사는 경과에 따른 포만감 감소와 피로 증가를 먼저 적용하고 회복량을 더한다. 수면은 경과 포만감 감소와 피로 회복만 적용한다. 경과 중 배고픔 경계를 넘으면 해당 구간부터 증가율을 바꾸며, 프레임 수에 따라 결과가 달라지지 않게 한다. 단순 정차는 깨어 있는 상태다. 마감 후 마지막 운송의 추가 실제 시간에도 같은 변화율을 적용하되 영업 예산을 새로 지급하지 않는다.

## 상태별 행동

| 상태 | 운전·운송 | 다음 선택 |
|---|---|---|
| 포만감 25 이상·피로 70 미만 | 정상 운전·승객 수락 | 운송·거점 방문 자유 선택 |
| 포만감 25 미만 | 조작·운임 변화 없이 피로가 빨리 증가 | 식당 안내, 식사 또는 계속 영업 |
| 포만감 0 | 수치 하한 유지, 굶주림 자체로 운송 중단 없음 | 식사하면 회복. 추가 중첩 페널티 없음 |
| 피로 70~99 | 현재 운송·신규 수락 가능 | 휴식 권장, 예상 운송 후 상태 안내 |
| 피로 100·빈차 | 신규 호출 수락·길가 승차 차단 | 직접 주차장으로 이동해 수면 또는 퇴근 |
| 피로 100·픽업 전 | 아직 탑승하지 않은 호출 취소, 픽업 기한 종료 | 매너/법규 자동 감점 없이 휴식 안내 |
| 피로 100·탑승 중 | 기존 운송과 원래 기한 유지, 조작 성능 유지 | 목적지 하차 후 수락 차단. 승객을 도중에 내리게 하지 않음 |

차단은 수락·승차 직전에 재확인한다. 새 호출 목록을 열어 두었다고 피로 제한을 우회하지 않는다. 수면 후 피로가 100 미만이고 영업시간이 남으면 다시 영업할 수 있다.

## 식사와 수면 이용 흐름

| 단계 | 식당 | 주차장 수면 |
|---|---|---|
| 접근 | 직접 이동·빈차·정차 | 직접 이동·빈차·정차 |
| 호출 처리 | 픽업 전 호출이 있다면 취소 후 이용 | 동일 |
| 확인 | 가격·50초 소비·예상 포만감 | 100초 소비·예상 피로 |
| 확정 | 결제/미납·시간 경과·상태 회복을 한 번 처리 | 시간 경과·회복을 한 번 처리 |
| 완료 | 영업 복귀 또는 마감 | 영업 복귀 또는 마감 |
| 취소 | 돈·시간·상태 변화 없음 | 동일 |

반복 식사는 허용하되 매번 비용·시간을 소비한다. 자동 마감 식비와 자동 포만감 회복은 제거한다. 자금 부족 식사는 기존 생활비 미납 정책을 유지하며 미납도 순수익에서 차감한다. 수면에는 별도 요금을 붙이지 않고 하루 마감 주차비는 한 번만 낸다.

남은 예산이 이용 시간보다 짧으면 해당 행동을 시작하지 못하고 종료를 안내한다. 정확히 같으면 이용 완료 후 정산한다. 탑승 중에는 식사·수면 불가다. 피로 한계·저연료·적자가 겹쳐도 식사 미납과 무료 수면 경로를 제공하며 신규 대출 시스템은 만들지 않는다.

## 화면과 기록

| 위치 | 정보 |
|---|---|
| 준비 | 운전자 배경 한 줄, 시작 포만감·피로, 하루 종료 시각 |
| 주행 | 포만감·피로와 단계 아이콘, 한계 접근 안내. 신호 시야를 가리지 않음 |
| 거점 | 이용 전후 수치·시간·가격, 확정/취소 |
| 결과 | 식사 횟수·수면 횟수·각 소비 시간·최종 컨디션·운송 건수·순수익 |
| 저장 | 회계 재개 기준에 맞춰 컨디션도 복원. 회계만 되돌리고 회복 상태만 남기지 않음 |

운행 사건의 기존 즉시 저장 저널을 이번 기획 때문에 삭제하거나 회계 저장으로 되돌리지 않는다. 새 하루의 기록은 별도 식별자로 분리하고 이전 완료 결과를 보존한다.

## 검증 기준

| 확인 | 기준 |
|---|---|
| 조작 독립 | 같은 입력에서 컨디션에 따른 조향·가감속·제동 차이 없음 |
| 시간 | 식사50초·수면100초가 한 번만 소비, 메뉴·복습은 정지 |
| 한계 | 피로100의 빈차/픽업 전/탑승 중 상태가 표대로 처리 |
| 비용 | 반복 식사는 각각 결제, 마감 자동 식비 없음, 미납 이중 차감 없음 |
| 반복 | 새 하루 초기값 동일, 완료 결과는 보존, 재시작 취소/저장 실패는 현 상태 유지 |
| 밸런스 | 일반 교통에서 식사1회·휴식0~1회가 자연스러운지 측정. 수치로 강제 정답을 만들지 않음 |
