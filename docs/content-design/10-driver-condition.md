# 운전자 설정과 하루 컨디션

기준일: 2026-10-26. 포만감·피로·식사·수면과 **피로 100 졸음 사건·초과 영업**은 구현 상태다. 이전 피로 한계 승차 차단/조작 영향 없음 규칙은 [변경 이력](../design-history/content-design/10-driver-condition-history.md)에 보존한다. 수치·시간은 게임 시험값이며 실제 생리 기준이 아니다.

## 캐릭터와 범위

| 항목 | 설정·조건 |
|---|---|
| 배경 | 경기 악화로 실직한 뒤 개인택시로 생계를 이어가는 운전자 |
| 시작 | 차량 한 대 준비. 면허 취득·차량 구입 과정 생략 |
| 목적 | 운송·경로·식사·휴식을 스스로 배치하고 남긴 수익 비교 |
| 성장 | 플레이어 판단 숙련. 능력치 구매·차량 성능 강화 제외 |
| 이름·나이·성별 | 프로토 진행 조건으로 고정하지 않음 |
| 반복 | 3일 내 상태 이월, 새 캠페인에서 동일 초기값. [07 캠페인](07-campaign.md) 기준 |
| 포함 | 포만감·피로 안내, 거점 식사/수면, 이동 중 졸음, 저장 복원 |
| 제외 | 스트레스·질병·추가 체력, 실내 보행·침대 조작·수면 미니게임, 강제 충돌 |

## 수치와 행동 조건

| 요소·상태 | 수치·시간 | 영향 |
|---|---|---|
| 포만감 | 새 캠페인 80, 범위 0~100. 영업·수면 1분당 -5 | 25 미만이면 배고픔 안내와 깨어 있을 때 피로 증가율 1.5배 |
| 피로 | 새 캠페인 10, 범위 0~100. 깨어 있는 영업 1분당 +4, 배고프면 +6 | 70부터 휴식 권장, 100이면 이동 중 졸음 가능 |
| 포만감 0 | 하한 유지 | 굶주림만으로 운송 중단·추가 중첩 페널티 없음 |
| 피로 70~99 | 현재 운송·신규 호출·길가 승차 가능 | 운송 후 예상 피로와 휴식 권장 |
| 피로 100 | 빈차·픽업 전·탑승 중 모두 영업 계속 가능 | 피로만으로 호출 취소/승차 차단하지 않음. 졸음은 아래 조건 적용 |
| 식사 | 50초 경과 후 포만감 +70, 상한 100 | 경과 중 포만감 감소·통상 피로 증가 먼저 반영 |
| 수면 | 100초, 피로 -40(하한 0) | 수면 중 포만감 감소, 통상 피로 증가 없음. 졸음 상태 해제 |
| 다음 날 야간 수면 | 피로 -60(하한 0), 다음 날 예산 미소비 | 포만감 이월. 마감 휴식 회복과 별도로 적용 |
| 최초 예정 20분 경계 | 피로 100으로 설정·초과 영업 | 자동 정산 없음. 경계는 날짜당 한 번만 적용 |
| 서비스 중 경계 통과 | 식사는 경과·회복 뒤 피로 100, 수면은 피로 100에서 수면 회복 적용 | 회복 뒤 이미 초과 시간이라는 이유로 재설정하지 않음 |
| 정차 | 깨어 있는 영업 시간 | 일반 컨디션은 경과, 새 졸음 추첨용 이동 시간은 적립하지 않음 |
| 일시정지·메뉴·복습·결과 | 시간 정지 | 컨디션·졸음도 정지, 창을 오래 열어 자동 회복하지 않음 |

배고픔 경계는 경과 구간별로 적용해 큰 시간 한 번과 작은 프레임 분할의 결과를 같게 한다. 포만감·피로 숫자만으로 만족도·법규 점수·운임을 자동 감점하지 않는다. 졸음 증상 이외에 상시 조향/가감속 성능 저하를 추가하지 않는다.

## 졸음 사건

| 단계·조건 | 동작 |
|---|---|
| 추첨 | 피로 100·실제 이동·영업 진행 중 20초마다 25% 확률. 정차·메뉴·일시정지·결과·연습은 적립 제외 |
| 예고 | 2초 동안 `졸음이 몰려옵니다 · 가까운 생활 거점에서 쉬세요` 표시 |
| 시야 축소 | 같은 확률로 선택되는 증상 하나. 3초 동안 가장자리 어둡게·중앙 시야 축소, 차량 조작 가능 |
| 조작 중단 | 다른 증상. 1초 동안 조향·가속·제동 입력 미적용, 현재 물리 속도로 이동. H 보조로 우회 불가 |
| 중복 방지 | 사건 중 재추첨 없음. 종료 후 다음 20초를 새로 적립 |
| 정차 중 진행 | 이미 시작된 예고·증상은 정차해도 진행하여 종료 |
| 수면·회복 | 피로 100 미만이면 추첨 대기·예고·진행 증상 해제 |
| 저장·복원 | 단계·남은 시간·난수 진행 보존. 재실행 재추첨 없음 |
| 평가 | 졸음 자체 감점 없음. 실제 충돌·법규 위반은 기존 관찰 규칙으로 평가 |

## 거점 이용·마감

| 단계 | 조건·처리 |
|---|---|
| 접근 | 식당 또는 주차장/휴식 구역으로 직접 이동·빈차·지정 방향 정차 |
| 호출 | 미탑승 호출은 취소 후 식사/수면 이용. 탑승 중은 목적지 하차 후 이용 |
| 확인 | 소비 시간·가격·회복 후 예상 상태를 표시. 비용·시설 조건은 [05](05-daily-operation.md) 기준 |
| 확정 | 비용/미납·경과·회복을 동일 이용 ID에 한 번 적용 |
| 취소 | 돈·시간·상태 변화 없음 |
| 계속 영업 | 남은 예정 시간과 관계없이 서비스 이용·호출 재개 가능, 자동 호출 수락 없음 |
| 휴식·영업 종료 | 빈차로 주차장·휴식 구역에 정차 후 무료 수면 100초·피로 40 회복, 실제 초과 시간·비용·결과 한 번 정산 |
| 자금 부족 | 식사는 미납·수면은 무료, 신규 대출 없음. 미납도 비용으로 기록 |
| 세차 | [15](15-drunk-passengers-and-cleanliness.md)의 시간만큼 깨어 있는 컨디션 경과. 식사/수면 대체 아님 |
