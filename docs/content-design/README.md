# 택시 운전 게임 콘텐츠 기획 목록

기준일: 2026년 10월 16일 · 버전: 0.4 · 상태: 로드맵·프로토타입 범위 정리

## 공통 흐름과 경계

| 흐름 | 연결 |
|---|---|
| 준비 | 연료·현금·보험 만료·세금 기한 → 영업/거점 이용 선택 |
| 운송 | 호출·탑승 → 경로와 교통 상황 판단 → 승객 요청 → 하차·운임 |
| 유지 | 주유·식사·주차·직접 갱신/납부 → 다음 운행 |
| 하루 마감 | 손익·미납·목표·독립 법규 성향 → 저장 → 다음 날/결과 |
| 복습 | 사건 카드 → 동일 상황 재시작 → 캠페인 돈·시간·성향과 분리 |
| 후속 콘텐츠 | 개인 예약·단골·사고·수리·보험 청구는 기획만 |

## 공통 적용 기준

| 항목 | 기준 |
|---|---|
| 성장 | 플레이어의 관찰·운전·경로 판단 숙련 |
| 법규와 매너 | 별도 점수·별도 기록. 법규 점수로 승객 운임·관계를 자동 변경하지 않음 |
| 현실성과 가독성 | 실제 지역 기반 위에 판단에 필요한 도로·신호·상황을 읽기 쉽게 구성 |
| 확정 방향 | 개인택시, 3일 × 8분·3만원, 보험·세금 직접 관리, 예약·사고 프로토 제외 |
| 조정할 수치 | 감점·성향 기준 횟수·연료·거점 비용·보험료·고지액·기한 배치는 테스트용 제안 |
| 구현 상태 | 기존 코드와 신규 개발 목표를 각 문서에서 분리. 기획 작성은 개발 완료가 아님 |

후속 예약·사고의 미정 항목은 각 문서에 남긴다. 프로토 개발은 위 확정 범위로 진행하며, 핵심 범위를 바꾸는 선택은 사용자에게 확인한다.
