# 택시 시뮬레이션 기획서

이 폴더는 **플레이어가 무엇을 보고, 어떤 행동을 선택하며, 어떤 결과를 받는가**를 정의한다. 개발 순서·코드 구조·시험/배포 내역은 본문에서 분리했다. 기존 여러 문서에 반복되던 조건·수치·효과는 아래 담당 문서 한 곳에만 둔다.

## 문서를 쓰는 기준

- 각 표는 조건/행동 → 결과 → 다른 경험에 미치는 영향 → 예외 순서로 읽는다.
- 규칙의 숫자는 담당 문서에만 적고, 다른 주제에서는 해당 항목으로 연결한다.
- 현재 Proto·후속 구상을 구분한다. ‘언젠가 할 것’을 현재 기능처럼 적지 않는다.
- 게임 배점·회복량·시간은 밸런스 값이며 실제 벌점·생리 기준·수익 보장이 아니다.
- .mmst 원본은 사용자 검토 전 수정하지 않는다. [변경 검토표](06-mindmap-review.md)는 적용 지시가 아닌 제안이다.
