## 2026-10-29 승객 확장과 차량 기획

[승객 유형·상호작용](02-passengers-and-fares.md#추가-기획-승객-유형과-상호작용)은 일반 승객과11유형·34변주, 준비/하역, 음식·짐 오염을 포함한다. 구현·실행 검증 상태는 [최신 작업 기록](../work-history/2026-10-29-passenger-types-implementation.md)을 따른다. [충돌 내구도·수리](03-life-and-economy.md#추가-기획-충돌-내구도와-수리)는 사용자 1차 확인 완료·미구현으로 별도 관리한다.

## 문서를 쓰는 기준

- 각 표는 조건/행동 → 결과 → 다른 경험에 미치는 영향 → 예외 순서로 읽는다.
- 규칙의 숫자는 담당 문서에만 적고, 다른 주제에서는 해당 항목으로 연결한다.
- 현재 Proto·후속 구상을 구분한다. ‘언젠가 할 것’을 현재 기능처럼 적지 않는다.
- 게임 배점·회복량·시간은 밸런스 값이며 실제 벌점·생리 기준·수익 보장이 아니다.
- .mmst는 사용자 승인(2026-10-27)에 따라 최신 기획과 Detail-Links를 직접 반영한다. 변경 전 원안은 별도 기획 이력에 보존하며, 현재 규칙의 상세는 연결된 담당 문서 한 곳에 둔다.
