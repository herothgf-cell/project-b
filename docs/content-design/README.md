# 택시 운전 게임 콘텐츠 기획 총괄

작성일: 2026년 10월 15일 · 버전: 0.2 · 상태: 법규 성향 콘텐츠 분리 보완안

이 게임은 택시 운행 중 만나는 교통 상황에서 스스로 판단하고, 법규를 지키는 운전이 자신과 주변에 주는 의미를 경험하는 게임이다. 성장의 중심은 플레이어의 관찰, 운전, 경로 판단 숙련이다. 실제 지역의 정밀 재현보다 판단에 필요한 도로와 신호, 다른 도로 이용자의 행동을 이해하기 쉽게 제시하는 것이 중요하다.

각 문서는 콘텐츠의 의도, 플레이 흐름, 선택과 결과, 연결 관계, 상황 예시와 결정 사항을 다룬다. 구현 구조, 작업 일정, 코드 명세는 이 문서군의 범위에 포함하지 않는다.

## 방향과 제안의 구분

사용자가 제시한 방향은 법규 준수 중심의 판단, 별도 준수 점수와 히스토리, 승객 요구, 직접 주유, 단골과 개인 예약, 보험·세금 및 기사 설정의 검토다. 아래 문서의 구체적인 진행 규칙, 화면 구성, 보상 방식과 상황 목록은 이를 구체화한 1차 제안이다. 확정되지 않은 수치나 영업 형태를 현재 구현 사실로 취급하지 않는다.

기존 [게임 기획서](../game-design.md)의 지역 재현·기간 수익 목표 중심 방향과 단골 제외 방침은 이번 콘텐츠 기획의 변경 검토 대상이다. 현재 빌드의 규칙은 [경제 구현 기록](../economy-progression-validation.md) 등 기존 구현 문서에 남아 있다. 본 문서군은 향후 콘텐츠 방향이며 빌드가 이미 이 내용을 제공한다는 의미가 아니다.

## 전체 플레이 흐름

운행 준비와 예약 확인 → 승객 선택과 탑승 → 경로 선택 → 교통 상황 판단과 승객 대응 → 하차와 운행 평가 → 다음 운송 또는 주유 → 하루 결산과 기록 확인 → 선택한 상황 복습 또는 다음 날 운행.

운송은 반복해서 상황을 만나는 생활의 맥락이다. 법규 준수 성향은 독립 콘텐츠이며 현재 승객 매너 점수와 분리한다. 법규 기록은 빈차에서도 누적되고 승객별로 초기화되지 않는다. 안전·승차감은 행동을 설명하는 정보로 활용하며 별도 종합 점수 도입은 확정하지 않는다. 히스토리는 법규 기록을 다음 연습 목표로 바꾼다. 승객 서비스는 재이용과 예약으로 이어질 수 있지만 법규 성향 점수가 요금·팁·단골 신뢰를 자동으로 조정하지 않는다.

## 공통 기획 원칙

- 좋은 운전은 위반하지 않은 결과뿐 아니라 위험을 일찍 읽고 적절히 대응한 과정으로 보여준다.
- 신호, 표지, 보행자 행동 등 판단 근거를 플레이어가 선택 전에 인지할 수 있어야 한다.
- 법규 의무, 권장되는 안전 행동, 승객의 취향은 서로 다른 기준으로 표시한다.
- 조향 보조는 조작을 돕는다. 플레이어가 선택하지 않은 자동 행동으로 판단 숙련을 인정하지 않는다.
- 법규 준수 운전으로 운송과 예약을 정상적으로 수행할 수 있도록 시간 여유를 설계한다.
- 학습 성과는 게임 안에서 관찰한 행동으로 표현한다. 실제 운전 능력이나 사회적 인식 개선 효과가 검증되었다고 주장하지 않는다.

## 먼저 결정할 사항

| 결정 | 1차안 | 결정에 따른 영향 |
|---|---|---|
| 기사 설정 | 개인택시 기사 권장, 미확정 | 비용 부담, 예약 전달 방식, 차량 관리의 맥락 |
| 기본 진행 목표 | 운행 지속과 숙련 변화 중심, 기간 수익 도전은 별도 후보 | 기존 7일 수익 목표와 실패 처리 재정의 |
| 평가 표현 | 법규 성향 콘텐츠와 승객 매너 시스템 분리 | 성향 축·기록 범위·보조 수치는 후속 검토 |
| 초기 상황 | 관찰 단서가 분명한 보행자·신호·차로·승하차 상황 | 상황별 법규와 변형 조건의 상세 확인 |
| 시간 규모 | 하루 길이와 캠페인 기간 미확정 | 예약 간격, 주유 빈도, 비용 납부 이벤트 |

## 참고작 적용 범위

Taxi Life는 승객 요청, 운송 평가, 교통 사건에 따른 경로 변경, 연료 보충·정비와 회사 운영 요소를 소개한다. 본 기획은 운송과 소규모 요청, 경로 변화, 차량 관리를 참고하며 회사 확장은 우선 범위에서 제외한다. 별도 법규 히스토리와 개인 예약은 우리 게임의 기획안으로 구분한다. 근거: [Taxi Life 공식 Steam 소개](https://store.steampowered.com/app/1351240/Taxi_Life_A_City_Driving_Simulator/), [Nacon 공식 소개](https://www.nacongaming.com/en/taxi-life), 확인일 2026년 10월 15일.
