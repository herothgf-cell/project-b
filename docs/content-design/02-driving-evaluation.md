# 법규 준수 성향 콘텐츠와 승객 매너의 분리 기획서

작성일: 2026년 10월 15일 · 버전: 0.2 · 상태: 독립 법규 콘텐츠 보완안

## 기획 의도

법규는 하나의 독립 콘텐츠다. 한국의 도로교통법과 관련 규정에 근거한 상황을 경험하고, 자신의 선택이 쌓인 운전 성향을 확인한다. 이는 현재 승객이 요구하는 매너 점수와 별개의 시스템이다. 승객이 없는 운행에서도 기록되며, 하차하거나 새 승객을 태워도 누적 성향이 초기화되지 않는다.

성향은 현실의 인격이나 심리를 판정하는 말이 아니다. 게임에서 관찰한 준수·위반 행동이 어떤 조건에서 반복되는지 설명한다. 위반 이유가 서두름인지 규칙을 몰랐기 때문인지는 행동만으로 단정하지 않는다.

## 두 시스템의 역할

| 구분 | 법규 준수 성향 콘텐츠 | 승객 매너 시스템 |
|---|---|---|
| 목적 | 규칙을 지키는 방식과 반복되는 선택을 이해 | 해당 승객의 운송 요구를 만족시키는 재미 |
| 적용 구간 | 빈차 이동과 승객 운송 모두 | 승객별 운송과 요구 조건 |
| 기준 | 국내 법규의 적용 조건과 실제 행동 | 승객에게 안내된 매너 요구와 운송 규칙 |
| 결과 | 사건 기록, 규칙별 준수, 상황별 성향, 복습 | 현재 매너 점수, 요구 달성 여부, 승객 반응 |
| 유지 단위 | 여러 운행의 이력과 최근 변화 | 개별 승객 운송 단위 |
| 보상 연결 | 성향 확인과 연습 주제 제안 | 기존 운송 보상 체계, 변경은 별도 기획 |

법규 성향이 승객 요금·팁·단골 신뢰를 자동으로 조정하지 않는다. 승객 매너가 높아도 법규 위반 기록이 남을 수 있고, 준법 운전자라도 승객의 개별 요구를 충족하지 못할 수 있다. 같은 충돌이나 신호 관련 행동을 양쪽이 관찰할 수는 있으나, 결과는 각 시스템의 기준으로 별도 설명한다. 이번 수정은 기존 매너 규칙을 삭제하거나 요금 공식을 변경하는 결정이 아니다.

안전·승차감은 실제 운전 행동을 설명하는 관찰 정보다. 법규 의무에 해당하는 행동과 권장 안전 행동을 구분하며, 이를 자동으로 제3의 종합 점수로 만들지는 않는다. 승객 매너에 어떤 관찰 항목을 사용할지는 승객 기획에서 정한다.

## 콘텐츠의 반복 흐름

주행 중 상황을 만남 → 도로 단서와 시간·승객 조건을 보고 선택 → 실제 행동과 법규 판단 기록 → 하루 종료 시 성향 변화 확인 → 근거 장면 확인 → 원할 때 다른 조건에서 재도전.

단속되었는지와 규칙을 지켰는지는 별개다. 게임의 학습 기록은 단속 연출이 없어도 남는다. 범칙금·과태료·벌점 등 단속 콘텐츠는 별도 채택 항목이며, 도입할 경우 발생 조건과 법적 근거를 따로 정한다. 카메라가 없으므로 위반이 아니라는 표현은 사용하지 않는다.

## 성향을 읽는 방법

| 성향을 살필 축 | 관찰할 행동 | 표현 예시 |
|---|---|---|
| 시간 압박과 준수 | 여유 있는 운행과 촉박한 운행에서의 규칙 준수 | 촉박한 운행에서 진로 변경 관련 위반이 반복됐습니다 |
| 정체에서의 선택 | 대기·우회·앞부분 진입과 각각의 적법성 | 정체 시 우회를 자주 선택하며 관련 규칙을 준수했습니다 |
| 주변 압박에 대한 반응 | 뒤차의 재촉이나 타 차량 위반 뒤 실제 행동 | 재촉을 받은 상황에서도 필요한 정지를 유지했습니다 |
| 보행자 보호 | 적용 조건에서의 정지·통행 방해 여부 | 경험한 보행자 보호 상황에서 정지를 지켰습니다 |
| 승객 유무와 일관성 | 유사 상황의 빈차·탑승 운행 기록 | 승객 유무에 관계없이 신호 준수가 유지됐습니다 |

대기와 우회는 경로 선택 취향이고, 위반 여부는 별도의 법규 결과다. 기다리는 운전자만 높은 등급을 받는 구조로 만들지 않는다. 성향은 하나의 유형에 고정하지 않고 여러 축으로 보여주며 최근 기록과 전체 이력을 구분한다.

조건이 다른 기록을 단순 비교하여 원인을 단정하지 않는다. 시야·신호·교통 조건이 유사한 장면을 비교하고, 사례가 부족하면 ‘아직 판단할 기록이 부족합니다’라고 표시한다. 인정 횟수와 최근 기록의 범위는 미확정이다.

## 점수와 히스토리 표현

규칙별 준수율은 보조 수치로 사용할 수 있다. 준수로 판정된 기회를 준수 또는 위반으로 판정된 전체 기회로 나누며, 미경험과 판정 보류는 제외한다. 기회가 없으면 100점을 주지 않고 미경험으로 표시한다. 쉬운 상황을 반복한 횟수만으로 다양한 상황을 경험한 것처럼 보여주지 않는다.

기록 카드에는 상황 조건, 플레이어 행동, 법규 근거, 준수·위반·보류, 관찰된 주변 영향, 도움 사용 여부를 담는다. 한 번의 지속적인 행동을 매 순간 새로운 위반으로 쌓지 않는다. 중요한 위반은 평균에 묻히지 않도록 개별 이력을 남긴다. 수치 배점과 중요도는 후속 결정이다.

‘얌체’, ‘난폭한 사람’ 같은 인격 명칭 대신 ‘대기열 앞 진입 반복’, ‘시간 압박 상황에서 준수 유지’처럼 행동을 서술한다. 잘못을 이후 행동으로 개선할 수 있게 최근 추세를 보여주되, 과거 기록 자체를 보상 점수로 지우지 않는다.

## 한국 법규를 콘텐츠로 옮기는 기준

| 자료 | 사용하는 목적 | 확인할 내용 |
|---|---|---|
| 도로교통법 및 관련 법률 | 준수 의무와 금지 행위 | 조문, 적용 대상, 예외, 시행일 |
| 도로교통법 시행령 | 위임된 세부 내용과 단속 관련 기준 | 해당 행위와 연결되는 조항·별표 |
| 도로교통법 시행규칙 | 신호·표지 등 세부 규정과 처분 기준 | 실제 장면의 표시와 해당 규정의 일치 |
| 경찰청·한국도로교통공단의 공식 안내 | 상황 설명과 교육 표현 | 원문 근거, 게시·개정 시점, 적용 범위 |

법률·하위 규정·교육 설명을 같은 효력의 자료로 다루지 않는다. 법규 위반, 위험 행동, 비배려 행동, 승객 불만을 각각 구분한다. 국내법이 아닌 해외 운전 상식이나 커뮤니티 다수 의견을 정답 근거로 삼지 않는다.

상황마다 ‘상황 설명 → 적용 조문 → 적용 조건 → 예외 → 게임에서 관찰 가능한 행동 → 설명 문구’를 작성한다. 국내 각종 법률을 전부 도입하기보다 해당 콘텐츠에 직접 필요한 규정부터 확인한다. 신호·노면·상대 차량 상태가 빠져 판정이 어려우면 위반을 확정하지 않고 근거를 보완한다.

### 출구 대기열 사례의 근거와 확인 범위

도로교통법 제23조는 제22조 제2항에 해당하는 차 앞으로의 끼어들기를 금지한다. 제19조 제3항은 변경하려는 방향의 다른 차의 정상 통행을 방해할 우려가 있는 진로 변경을 제한한다. 따라서 ‘앞에서 들어갔다’, ‘점선이었다’, ‘충돌하지 않았다’ 하나만으로 판정하지 않는다. 정지·서행 이유와 진입 조건을 함께 정해야 한다.

- [국가법령정보센터 제23조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?lsJoLnkSeq=1030974719): 열람본 시행 2026년 7월 1일.
- [국가법령정보센터 제19조 제3항](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1028652667): 열람본 시행 2026년 7월 1일.
- [법제처 생활법령정보 진로양보와 앞지르기](https://easylaw.go.kr/CSP/CnpClsMain.laf?ccfNo=2&cciNo=1&cnpClsNo=3&csmSeq=684&popMenu=ov): 제22조 제2항의 대상 설명, 자료 기준일 2026년 9월 15일.

확인일은 2026년 10월 15일이다. 일반 법령 링크가 2027년 4월 14일 시행 예정본으로 연결되는 경우도 확인되어, 시행 예정본을 현행 규칙으로 혼용하지 않는다. 위 자료는 기획 근거로 사용하며, 구체적인 장면 판정표 확정 시 선택한 기준일의 법령·하위 규정과 예외를 다시 대조한다. 범칙금·과태료·벌점의 구체 금액은 이번 범위에 포함하지 않는다.

## 먼저 추가할 콘텐츠

1. 출구 대기열의 대기·우회·앞부분 진입을 동일한 도로에서 경험한다. 시간 여유와 승객 유무를 바꾸어 선택을 비교한다.
2. 운행 종료 시 ‘승객 매너 결과’와 ‘법규 기록’을 별도 카드로 제공한다. 법규 상세는 원할 때 열어본다.
3. 하루 성향 요약에 반복 행동 한 가지와 유지한 준수 한 가지를 근거 장면과 연결해 보여준다.
4. 동일 조건 재도전과 다른 배치 재도전을 제공한다. 연습 결과는 실제 영업 성향과 구분한다.
5. 법규 설명 카드에 적용 조건과 근거를 표시하여 ‘왜 위반인가’뿐 아니라 ‘어떤 조건에서는 다르게 판단하는가’를 이해하게 한다.

## 연결과 결정 사항

[운전 상황](01-driving-situations.md)이 선택 기회를, [히스토리](03-history-and-mastery.md)가 누적 기록과 복습을 제공한다. [승객](04-passengers-and-reservations.md)의 요구는 상황의 압박 조건이 될 수 있지만 법규 결과의 기준을 바꾸지 않는다. [하루 결산](05-daily-operation.md)은 성향 요약과 승객 매너·수입을 별도로 보여준다.

후속 결정은 성향 축의 수, 기록이 충분하다고 보는 기준, 요약 수치 표현, 단속 콘텐츠의 도입 여부다. 사용자가 자기 행동의 근거를 이해하는지, 합법적 우회가 부당하게 평가되지 않는지, 승객 매너와 법규 기록을 다른 시스템으로 인지하는지 확인한다.
