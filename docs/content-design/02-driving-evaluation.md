# 법규 준수 성향

## 2026-10-26 운전 점수·회복·운임 효과

사용자 표시 명칭을 **운전 점수**로 통일한다. 이 점수는 캠페인 전체의 준수·위반 기록으로 계산하며, 이번 승객의 운전 만족도 `M` 및 승객 만족도 `S`와 별개다. 새 캠페인은100점, 날짜 변경·저장 복원은 현재 점수를 이어간다.

신규 사건에서 실제 준수가 관찰되고 같은 사건에 위반이 없으면 **+3점** 회복한다(기존+1, 상한100). 한 사건에 준수 규칙이 여러 개 있어도 한 번만 회복한다. 보류·기회 없음·버튼 선택에는 회복을 주지 않고, 같은 사건 ID는 재지급하지 않는다. 기존 저장 사건의 당시+1 회복량은 유지하며 새 정책 사건만+3으로 기록한다. 회복해도 과거 위반 기록은 남는다.

높은 점수의 효과는 **새 운송 기본 운임 보정**이다. 승차 시 운전 점수 `D`를 고정한다. `D<=70`이면 `k=0.9+0.1×D/70`, `D>70`이면 `k=1+0.1×(D-70)/30`이다. 0점90%,70점100%,100점110%를 연결하는 게임용 시험값이며, 이후 운송 중 점수 변화는 다음 승객부터 반영한다.

최종 경유·목적지 변경을 반영한 원약정 `F`에 `k`를 적용해 10원 단위로 내림한 보정 약정을 만든다. 정상 하차의 기본 운임은 이 보정 약정에 `S-R` 미달 감액(1점당0.5%,최대20%)을 한 번 적용한다. 보너스는 [11의 기존 별도 산식](11-passenger-request-effects.md)을 사용한다. 기한 초과 지급0원, 기존 완료 지급액과 진행 중 구형 운송의 약정은 소급 변경하지 않는다.

예: 원약정5,000원에서 승차 시 운전 점수가0/70/100이면 만족도 감액 전 기본 약정은4,500/5,000/5,500원이다. 운전 점수100, `S=R-10`이면 보정 약정5,500원에서5% 감액해5,220원(10원 내림)을 지급하고 보너스는0원이다. HUD·호출/승차·결과/F8은 운전 점수 보정과 승객 만족도 감액을 구분해서 설명한다.

운전 점수는 운임 보정과 준수·위반 피드백에 사용한다. 차량 조향 성능·피로·시야·승객의 요구치 `R`를 바꾸는 능력치로 쓰지 않는다. 점수 회복 경계, 구형/신형 사건 혼합, 동일 ID, 승차 스냅샷, 정산 순서·저장 복원과 실제 수익 변화를 검증한다.

기준일: 2026년 10월 19일 · 버전: 0.7 · 상태: 기존 구현 6de26a5 및 검증 대조 + 도로 주행 법규 자동 판정 후속 백로그 추가

한국 도로교통법에 맞는 선택을 경험하고, 기록으로 자신의 운전 행동을 돌아보는 독립 콘텐츠다. **아래 점수·횟수는 게임 밸런스 초안이며 사용자 확정값이나 실제 법적 벌점이 아니다.**

## 현재 구현과 검증 범위

승객 매너와 독립된 법규 장부, 사건당 최대 감점, 규칙별 준수·위반·보류·기회 없음, 일일 집계와 요약을 구현했다. 유효 판정이 없는 기록은 점수 성과로 표시하지 않는다. 앞부분 진입 뒤 복귀 시 이미 성립한 위반은 유지하되 관찰하지 않은 방해를 추가 위반으로 만들지 않는다.

**남은 확인:** 실제 교차로 전체의 법규 검증과 무위반 수동 완주는 미완료다. 개별 후보의 적용 법조문·예외 전수 감수는 별도이며 현재 게임 판정과 현실 전체 규정을 동일시하지 않는다.

근거: [통합 검증](../prototype-completion-validation.md) · [개발 체크리스트](../prototype-development-checklist.md). 아래 상세 표는 목표 설계를 포함하므로 표의 ‘포함’만으로 검증 완료를 뜻하지 않는다.

## 규칙별 감점 초안

아래는 **조건이 확인된 위반 1건의 감점 후보**다. 신규 사건은 관찰로 준수가 확인되고 같은 사건에 위반이 없으면 사건당 3점 회복한다(최대 100점). 구형 저장 사건의1점 회복은 보존한다. 보류·기회 없음·선택 버튼만으로는 회복하지 않는다. 근거 번호는 [법규 자료](#법규-자료와-확인-범위)에 연결된다.

## 전체 도로 주행 법규 자동 판정 확장 백로그 (후속 기획만 · 2026-10-19)

> **명확한 범위:** 아래 F01~F62는 **이번 프로토 제외·향후 후보**이다. 게임 코드 및 현재 L01~L08 판정·감점·저장·운임 로직을 변경하지 않는다. '전체'는 택시가 도로를 주행하며 실제로 마주치는 주요 *운전자 준수 의무의 확장 후보를 체계적으로 수집한다*는 뜻이지, 모든 법령·하위규정의 완전한 목록을 법적으로 인증했다는 뜻이 아니다. 면허 발급·자격·행정처분 등 **차량 주행 궤적으로 감지할 수 없는 주제**는 자동 위반 판정 목록과 별도로 둔다.

### 기존 규칙과의 관계·우선순위

- **기존 L01~L04·L06·L07 유지:** 동일 사건을 새 ID로 한 번 더 감점하지 않는다. F36(보행자 보호 도시 전역)은 기존 L04의 *적용 공간 확대*이고 F37은 기존 L05 후보의 *실현 작업*이다. F05(비보호 좌회전)·F06(꼬리물기) 등은 현행 L01~L08이 커버하지 않는 별도 조건이다. L08의 서행 기준이 미확정이라는 기존 보류 원칙을 유지한다.
- **P1 (1차 확장):** 현재 차량 물리·노면·신호·기본 내비·승하차로 검증 가능한 도로부터. *P1이어도 지도에 규제 데이터가 확인되기 전에는 위반을 확정하지 않는다.*
- **P2 (2차 확장):** 교차로 우선권, 보행자·타차량의 동적 행위, 도로 시설 확인이 필요한 항목.
- **P3 (장기 확장):** 철길·고속도로·야간/날씨·통학버스·실내 조작처럼 새 맵/AI/상태/UI가 필요한 항목. 존재하지 않는 요소는 '미관찰·프로토 제외'.
- **판정 유형:** `준수` / `위반` / `보류` / `기회 없음`. 사건당 가장 큰 감점 1개 적용, 규칙별 건수 별도 기록이라는 기존 장부 구조를 이어간다. F-ID의 감점 수치는 **전부 미정**이며 현재 실제 범칙금·벌점과 연결하지 않는다.

### 후속 규칙 후보 카탈로그

다음 표의 조문과 운전면허 학과시험 문항 번호는 **근거 조사 출발점**이다. 국가법령정보센터의 실제 시행 조문, 시행령·시행규칙·현장 표지/시간제 규제를 각 규칙 구현 직전에 재확인한다. 안전운전 *권장 행동*과 확정 가능한 *법적 의무*가 혼합되지 않도록 최종 검증하고, 법적 위반요건을 특정하지 못하면 게임용 안전 힌트로만 제시한다.

## 우회전 조건별 판정

기본 장면은 **일반 교차로에서 우회전 후 만나는 횡단보도의 보행 신호가 녹색이고, 횡단 중이거나 횡단하려는 보행자가 없는 경우**다. 전방 차량 신호, 회전 전·후 횡단보도, 전용 신호를 각각 확인한다. 아래는 S1·S2·S5·S6을 조합한 장면 기획이며, 보행 신호 하나만으로 정답을 정하지 않는다.

| 우회전 전용 신호 | 전방 차량 신호 / 보행 조건 | 가능한 행동 | 게임 판정 |
|---|---|---|---|
| 없음 | 적색 / 회전 전·후 횡단 중·횡단하려는 사람 없음 | 먼저 정지. 신호에 따라 진행하는 다른 차마를 방해하지 않으며 서행 우회전 | 정지 생략은 L02. 보행 녹색만을 이유로 통과를 L04 위반 처리하지 않음 |
| 없음 | 녹색 / 회전 후 보행 녹색·보행자 없음 | 주변을 확인하고 서행 우회전 가능 | 적색 신호용 정지를 요구하지 않음. 보행자 보호 의무가 발생하지 않았다면 L04 평가 기회 없음 |
| 없음 | 적색 또는 녹색 / 횡단 중이거나 횡단하려는 사람이 있음 | 횡단보도 앞에서 정지하고 통행 보장. 정지선이 있으면 그 선 앞 | 필요한 정지 누락은 L04. 전방 적색의 선행 정지 의무도 따로 기록 |
| 있음: 적색 | 전방 신호·보행자 유무와 무관 | 우회전 신호에 따라 대기 | 우회전하면 L03. 일시정지 후 출발도 위반 |
| 있음: 녹색 화살표 | 별도 신호 변형 / 보행자와 다른 교통 확인 | 표시 방향으로 서행 진행하되 보행자 보호 | 신호 허용과 보행자 보호를 따로 기록. 횡단 중 보행자를 무시하면 L04 |
| 후속 보호구역 변형 | 어린이 보호구역의 **신호 없는** 횡단보도 | 사람이 없어도 일시정지 | L05 적용 후보, 프로토 제외. 보행 녹색인 기본 장면과 다른 조건 |
| 조건 불명확 | 신호가 가려짐, 보행자 의도 불명, AI·신호 충돌 | 관찰 사실을 보존하고 설명 보완 | 해당 규칙 판정 보류, 감점·준수율 제외 |

전용 녹색 화살표 변형에 회전 진로와 충돌하는 보행 녹색을 임의로 동시에 배치하지 않는다. 횡단보도로 다가오는 사람이 있다면 이미 차도에 들어왔는지만 보지 말고 횡단하려는 행동을 확인한다. 단순히 근처에 있다는 이유만으로 의도를 확정하지 않는다.

일시정지는 차량이 완전히 멈추는 행동이다. 법적 의무를 ‘무조건 3초’ 같은 고정 시간으로 만들지 않는다. 게임의 속도 측정 오차 허용치는 구현 검증 항목이다. 경찰 수신호, 대각선 횡단보도, 신호 고장은 별도 근거·장면을 준비하기 전 기본 판정표에서 제외한다.

## 중복과 누적 및 판정 보류

| 항목 | 프로토 규칙 제안 |
|---|---|
| 사건 단위 | 상황 접근부터 구간 이탈·해소까지 1건. 지속 행동을 매 프레임 재감점하지 않음 |
| 여러 규칙 위반 | 적용 규칙을 모두 남기되 **점수는 가장 큰 감점 1회만** 적용. 출구 끼어들기 L06 + L07이면 -15, 규칙별 위반은 각각 1회 |
| 별개 상황 | 출구 사건 종료 후 다른 횡단보도에 접근하면 새 사건. 같은 사건 재전송·화면 재열기는 추가 감점하지 않음 |
| 캠페인 운전 점수 | `max(0, 100 - 확정된 사건별 감점 합계)`. 0점이 되어도 이후 사건은 계속 기록 |
| 준수율 | 규칙별 `준수 / (준수 + 위반)`. 한 사건에서 같은 규칙은 최대 1기회. 미경험·보류 제외 |
| 기회 없음 | 우회하며 차로 변경을 하지 않았다면 변경 규칙은 평가 기회 없음. 하루 평가 기회가 전혀 없으면 100점 대신 ‘평가 기록 없음’ |
| 보류 | 신호·표지·상대 행동 누락, AI 오류, 근거 확인 대기. 사유를 남기고 자동 위반·준수로 변환하지 않음 |
| 정정 | 잘못된 판정은 이유를 남기고 캠페인 운전 점수·누계를 재계산. 복습 성공은 정정 사유가 아님 |
| 도움·복습 | 조향 보조 사용 여부를 기록하며 사용 자체로 감점하지 않음. 판단을 대신하는 자동 정지는 프로토 제외. 연습은 영업 점수·성향 누계에 합산하지 않음 |
| 다음 날 | 운전 점수·사건·최근 성향을 유지한다. 새 캠페인에서만 100점으로 초기화하며 승객 교체로 초기화하지 않음 |

단속되지 않아도 학습 기록은 남는다. 적법한 우회도 유효한 선택이며, 기다린 시간만으로 추가 점수를 주지 않고 실제 준수 관찰에서만 회복한다.

## 성향 요약 기준 초안

성향은 인격 평가가 아니라 반복 행동의 설명이다. 하루 점수로 유형을 정하지 않고 **같은 상황군·같은 규칙의 유효 기회**를 비교한다.

| 조건 | 표시 방법 |
|---|---|
| 해당 규칙 유효 기록 0건 | 미경험 |
| 유효 기록 1~4건 | 준수·위반 횟수만 표시, ‘성향을 보기에는 기록 부족’ |
| 최근 5건 중 같은 위반 3건 이상 | ‘최근 출구 정체 진로 변경 5건 중 3건에서 통행 방해 관련 위반’ |
| 최근 5건 중 준수 4건 이상 | ‘최근 보행자 보호 5건 중 4건 준수’. 남은 위반은 숨기지 않음 |
| 위 조건에 해당하지 않음 | 최근 5건의 횟수만 표시, 유형 부여 안 함 |
| 대기·우회·앞부분 진입 | 상황 전체의 선택 횟수로 별도 집계. 법규 준수율과 분모를 섞지 않음 |
| 시간 압박·승객 유무 비교 | 각 조건에 유사 사례가 5건 이상일 때 횟수·비율 비교. 부족하면 ‘재촉 있었던 3건 중 위반 2건’처럼 사실만 표시 |

‘재촉 때문에 위반했다’, ‘얌체 운전자’처럼 원인이나 성격을 단정하지 않는다. 뒤차의 재촉에도 정지를 유지한 행동, 빈차·탑승 운행의 차이도 같은 방식으로 기록한다. 하루 결산은 요약 최대 2개와 근거 카드 링크를 제공한다.

## 실생활 혼동 가능성 재검토 (2026-10-20)

F01~F62는 모두가 헷갈리는 규칙 62개라는 뜻이 아니다. [62개 검토표](../road-law-confusion-review.md)에서 조건 혼동 교육 후보 26개, 기본 수칙·실행 판단 22개, 특수 상황·별도 상태 14개로 구분했다. 이는 공식 안내 및 조건 구조에 따른 기획 평가이며 전국 오답률 순위는 아니다. 현재 L01~L08·법규 감점·운임은 변경하지 않았다. 후보 선정은 도로/표지 데이터 확인과 개별 법적 조건 검증 후 별도로 진행한다.

## 은계 혼동 연습 1차 반영 (2026-10-20)

후속 후보에서 F02·F03·F06·F05를 선택해 별도 연습 7종으로 구성했다. F03의 시선/주의 의무는 자동 채점하지 않으며 F06 출구 공간이 있는 비교 장면은 평가 기회 없음으로 구분한다. 법규 결과·승객 매너·운임 분리는 유지한다. [구현·검증 경계](../eungye-confusion-practice-validation.md)를 따른다. 전 교차로의 62항목 자동 감점 구현이 아니다.


## 일반 은계 운송으로 통합 (2026-10-20)

법규 상황은 기본 은계 맵의 서로 다른 7개 도로 구역에 둔다. 승객 승차 후 목적지까지 안내된 경유 구역에서 실제 운전을 관찰하고, 하차·요금 지급까지 같은 영업 세션을 유지한다. 경로·신호·주변 차량을 보고 판단하는 흐름이며 결과 화면 때문에 자동 정지하지 않는다. 정차 시 상세 결과와 F8 기록에서 잘한 점·잘못한 위치·다음 행동을 확인한다. 기존 별도 연습은 재시도 수단이다. [구역·검증 상세](../eungye-in-service-law-zones.md).

관찰 가능한 창작 조건에서만 채점하고, 차량 때문에 안전한 연출 배치를 할 수 없으면 구역 통과/관찰 보류를 표시한다. 시선/주의 전체를 자동 준수로 확정하지 않으며 실제 현장 규제 자료의 확인 상태를 덮어쓰지 않는다.

## 2026-10-21 운전 점수 변경

화면 명칭은 운전 점수다. 점수는 사건 발생 순서대로 0~100점에 제한하며 같은 사건 ID의 중복 감점·회복은 방지한다. 날짜가 바뀌어도 유지한다. 새 캠페인 확인 시에만 기록과 함께 초기화한다(사용자 확정). 점수 변화는 상단에 부호와 이유가 잠깐 나타났다 사라진다. 기존 일일 감점 합계는 사건 검토용 통계이며 누적 점수와 구분한다. 승객 매너·요금과 직접 연동하지 않는다.
