# 법규 준수 성향

작성일: 2026년 10월 16일 · 버전: 0.4 · 상태: 프로토 범위·점수 제안

한국 도로교통법에 맞는 선택을 경험하고, 기록으로 자신의 운전 행동을 돌아보는 독립 콘텐츠다. **아래 점수·횟수는 게임 밸런스 초안이며 사용자 확정값이나 실제 법적 벌점이 아니다.**

## 역할과 프로토 범위

| 구분 | 법규 준수 성향 | 승객 매너 |
|---|---|---|
| 목적 | 어떤 조건에서 규칙을 지키거나 놓치는지 확인 | 해당 승객의 운송 요구 충족 |
| 적용 | 빈차·승객 운송 모두 | 승객별 운송 |
| 수치 | 하루 법규 점수 100점에서 감점 + 규칙별 준수 기록 | [승객 문서](04-passengers-and-reservations.md)의 별도 점수 |
| 유지 | 하루 점수는 다음 날 초기화, 사건·누계·최근 성향은 유지 | 승객 운송 단위 |
| 결과 | 사건 카드, 일일 요약, 다음에 바꿀 행동 | 요구 달성·승객 반응·운송 보상 |
| 서로의 영향 | 법규 점수로 매너·요금·팁을 자동 변경하지 않음 | 매너가 높아도 법규 위반 기록은 남음 |

| 항목 | 프로토 적용 | 해야 할 것 / 제외 범위 |
|---|---|---|
| 출구 정체·우회전·횡단보도 | 포함 | [상황 문서](01-driving-situations.md)의 조건과 아래 판정표 연결 |
| 일일 점수·사건·요약 성향 | 포함 | 승객 결과와 다른 카드로 표시. 저장 범위는 [히스토리](03-history-and-mastery.md) 참고 |
| 동일 상황 재시작 | 포함 | 영업 기록과 구분해 연습 |
| 모든 도로법규의 자동 판정 | 제외 | 우선 채택한 상황의 관찰 가능한 조건부터 구현 |
| 범칙금·과태료·면허 벌점·단속 카메라 | 제외 | 점수와 돈을 연결하려면 별도 기획 필요 |
| 사고 수리·보험청구·책임 판정 | 제외 | [사고·수리](08-accidents-and-repairs.md)에 후속 기획만 유지 |
| 종합 인격 등급·장기 숙련 등급 | 제외 | 행동 사실과 경험 횟수만 설명 |

같은 행동을 두 시스템이 관찰할 수는 있지만 각 기준과 결과를 따로 설명한다. 기존 승객 매너 규칙의 삭제·배점 변경은 이 문서의 범위가 아니다.

## 규칙별 감점 초안

아래는 **조건이 확인된 위반 1건의 감점 후보**다. 준수는 0점 감점이며 추가 점수를 적립하지 않는다. 근거 번호는 [법규 자료](#법규-자료와-확인-범위)에 연결된다.

| ID | 규칙·위반 행동 | 판정에 필요한 조건 | 게임 감점 | 근거 / 프로토 |
|---|---|---|---:|---|
| L01 | 적색 신호에 직진 진입 | 자기 진행 방향의 신호·정지선·진입 시점 확인 | -20 | S1 / 포함 |
| L02 | 전방 적색에 정지 없이 우회전 | 우회전 전용 신호 없음. 정지선이 있으면 그 직전, 없으면 횡단보도 또는 교차로 직전의 정지 누락 | -15 | S1·S5 / 포함 |
| L03 | 우회전 전용 적색에 우회전 | 적용되는 우회전 신호가 적색. 잠깐 정지했어도 진행 불가 | -20 | S1·S5 / 포함 |
| L04 | 횡단 중·횡단하려는 보행자가 있는데 필요한 정지를 하지 않음 | 보행자 행동·횡단보도·정지선과 진입 시점 확인. 충돌 유무와 별개 | -25 | S2 / 포함 |
| L05 | 어린이 보호구역의 신호 없는 횡단보도에서 정지 누락 | 보호구역 지정과 해당 횡단보도에 신호기가 없음을 확인. 보행자 유무 무관 | -20 | S2 / 후속 후보, 프로토 제외 |
| L06 | 금지 대상 대기 차량 앞으로 끼어듦 | 제22조 제2항의 정지·서행 이유 확인. 대표 예시는 신호 대기열 | -15 | S3 / 포함 |
| L07 | 다른 차의 정상 통행에 장애를 줄 우려가 있는 진로 변경 | 상대 진행·간격·진입 궤적 확인. 상대 급제동만으로 자동 확정하지 않음 | -15 | S4 / 포함 |
| L08 | 우회전 시 서행 의무를 지키지 않음 | 우회전 구간의 차량 속도와 즉시 정지 가능한 상태를 판별할 기준 필요 | -10 | S6 / 기준 확정 전 감점 보류 |
| 확장 | 과속·변경 금지 표시 침범·불법 승하차 | 제한속도·표지·노면·장소별 예외를 별도 검증 | 미정 | 이번 프로토 판정표 밖. 승객 매너의 동명 항목과 혼동 금지 |

L08의 서행을 임의의 전국 공통 속도 숫자로 설명하지 않는다. 프로토는 속도·행동 사실을 기록하며 L08 감점은 보류한다. L05 보호구역 장면은 [운전 상황의 확장 후보](01-driving-situations.md)에만 둔다. 충돌만으로 특정 법규 위반을 확정하지 않으며 사고 처리·수리비·보험청구·책임 판정은 [후속 기획](08-accidents-and-repairs.md)으로 분리한다.

## 우회전 조건별 판정

기본 장면은 **일반 교차로에서 우회전 후 만나는 횡단보도의 보행 신호가 녹색이고, 횡단 중이거나 횡단하려는 보행자가 없는 경우**다. 전방 차량 신호, 회전 전·후 횡단보도, 전용 신호를 각각 확인한다. 아래는 S1·S2·S5·S6을 조합한 장면 기획이며, 보행 신호 하나만으로 정답을 정하지 않는다.

| 우회전 전용 신호 | 전방 차량 신호 / 보행 조건 | 가능한 행동 | 게임 판정 |
|---|---|---|---|
| 없음 | 적색 / 회전 전·후 횡단 중·횡단하려는 사람 없음 | 먼저 정지. 신호에 따라 진행하는 다른 차마를 방해하지 않으며 서행 우회전 | 정지 생략은 L02. 보행 녹색만을 이유로 통과를 L04 위반 처리하지 않음 |
| 없음 | 녹색 / 회전 후 보행 녹색·보행자 없음 | 주변을 확인하고 서행 우회전 가능 | 적색 신호용 정지를 요구하지 않음. 보행자 보호 의무가 발생하지 않았다면 L04 평가 기회 없음 |
| 없음 | 적색 또는 녹색 / 횡단 중이거나 횡단하려는 사람이 있음 | 횡단보도 앞에서 정지하고 통행 보장. 정지선이 있으면 그 선 앞 | 필요한 정지 누락은 L04. 전방 적색의 선행 정지 의무도 따로 기록 |
| 있음: 적색 | 전방 신호·보행자 유무와 무관 | 우회전 신호에 따라 대기 | 우회전하면 L03. 일시정지 후 출발도 위반 |
| 있음: 녹색 화살표 | 별도 신호 변형 / 보행자와 다른 교통 확인 | 표시 방향으로 서행 진행하되 보행자 보호 | 신호 허용과 보행자 보호를 따로 기록. 횡단 중 보행자를 무시하면 L04 |
| 후속 보호구역 변형 | 어린이 보호구역의 **신호 없는** 횡단보도 | 사람이 없어도 일시정지 | L05 적용 후보, 프로토 제외. 보행 녹색인 기본 장면과 다른 조건 |
| 조건 불명확 | 신호가 가려짐, 보행자 의도 불명, AI·신호 충돌 | 관찰 사실을 보존하고 설명 보완 | 해당 규칙 판정 보류, 감점·준수율 제외 |

전용 녹색 화살표 변형에 회전 진로와 충돌하는 보행 녹색을 임의로 동시에 배치하지 않는다. 횡단보도로 다가오는 사람이 있다면 이미 차도에 들어왔는지만 보지 말고 횡단하려는 행동을 확인한다. 단순히 근처에 있다는 이유만으로 의도를 확정하지 않는다.

일시정지는 차량이 완전히 멈추는 행동이다. 법적 의무를 ‘무조건 3초’ 같은 고정 시간으로 만들지 않는다. 게임의 속도 측정 오차 허용치는 구현 검증 항목이다. 경찰 수신호, 대각선 횡단보도, 신호 고장은 별도 근거·장면을 준비하기 전 기본 판정표에서 제외한다.

## 중복과 누적 및 판정 보류

| 항목 | 프로토 규칙 제안 |
|---|---|
| 사건 단위 | 상황 접근부터 구간 이탈·해소까지 1건. 지속 행동을 매 프레임 재감점하지 않음 |
| 여러 규칙 위반 | 적용 규칙을 모두 남기되 **점수는 가장 큰 감점 1회만** 적용. 출구 끼어들기 L06 + L07이면 -15, 규칙별 위반은 각각 1회 |
| 별개 상황 | 출구 사건 종료 후 다른 횡단보도에 접근하면 새 사건. 같은 사건 재전송·화면 재열기는 추가 감점하지 않음 |
| 하루 점수 | `max(0, 100 - 확정된 사건별 감점 합계)`. 0점이 되어도 이후 사건은 계속 기록 |
| 준수율 | 규칙별 `준수 / (준수 + 위반)`. 한 사건에서 같은 규칙은 최대 1기회. 미경험·보류 제외 |
| 기회 없음 | 우회하며 차로 변경을 하지 않았다면 변경 규칙은 평가 기회 없음. 하루 평가 기회가 전혀 없으면 100점 대신 ‘평가 기록 없음’ |
| 보류 | 신호·표지·상대 행동 누락, AI 오류, 근거 확인 대기. 사유를 남기고 자동 위반·준수로 변환하지 않음 |
| 정정 | 잘못된 판정은 이유를 남기고 일일 점수·누계를 재계산. 복습 성공은 정정 사유가 아님 |
| 도움·복습 | 조향 보조 사용 여부를 기록하며 사용 자체로 감점하지 않음. 판단을 대신하는 자동 정지는 프로토 제외. 연습은 영업 점수·성향 누계에 합산하지 않음 |
| 다음 날 | 하루 점수만 100점으로 시작. 사건·최근 성향은 유지하며 승객 교체로 초기화하지 않음 |

단속되지 않아도 학습 기록은 남는다. 적법한 우회도 유효한 선택이며, 기다렸다고 추가 점수를 주지 않는다.

## 성향 요약 기준 초안

성향은 인격 평가가 아니라 반복 행동의 설명이다. 하루 점수로 유형을 정하지 않고 **같은 상황군·같은 규칙의 유효 기회**를 비교한다.

| 조건 | 표시 방법 |
|---|---|
| 해당 규칙 유효 기록 0건 | 미경험 |
| 유효 기록 1~4건 | 준수·위반 횟수만 표시, ‘성향을 보기에는 기록 부족’ |
| 최근 5건 중 같은 위반 3건 이상 | ‘최근 출구 정체 진로 변경 5건 중 3건에서 통행 방해 관련 위반’ |
| 최근 5건 중 준수 4건 이상 | ‘최근 보행자 보호 5건 중 4건 준수’. 남은 위반은 숨기지 않음 |
| 위 조건에 해당하지 않음 | 최근 5건의 횟수만 표시, 유형 부여 안 함 |
| 대기·우회·앞부분 진입 | 상황 전체의 선택 횟수로 별도 집계. 법규 준수율과 분모를 섞지 않음 |
| 시간 압박·승객 유무 비교 | 각 조건에 유사 사례가 5건 이상일 때 횟수·비율 비교. 부족하면 ‘재촉 있었던 3건 중 위반 2건’처럼 사실만 표시 |

‘재촉 때문에 위반했다’, ‘얌체 운전자’처럼 원인이나 성격을 단정하지 않는다. 뒤차의 재촉에도 정지를 유지한 행동, 빈차·탑승 운행의 차이도 같은 방식으로 기록한다. 하루 결산은 요약 최대 2개와 근거 카드 링크를 제공한다.

## 법규 자료와 확인 범위

기준·확인일은 **2026년 10월 16일**이다. 아래 법률 조문은 시행 2026년 10월 13일 열람본이며, 2027년 4월 14일 시행 예정본은 기준으로 사용하지 않았다. 법률·시행규칙·교육 안내의 역할을 구분하고, 링크가 최신 본문으로 바뀔 수 있으므로 구현 시 시행일을 다시 확인한다.
