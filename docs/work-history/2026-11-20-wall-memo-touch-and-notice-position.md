# 숙소 벽 메모 선택과 1인칭 운행 알림

덕성프라자 숙소 그림에 붙은 메모 세 장의 전체 면을 눌러 목표를 선택할 수 있다. 방 벽과 오른쪽 목록 모두 같은 저장 동작을 사용한다. 아침에는 선택 후 영업 준비로 돌아가며, 메모를 다시 열어 바꿀 수 있다.

싱글 1인칭에서도 운행 알림의 왼쪽 여백은 외부 시점과 같다. 왼쪽 사이드미러 위에 간격을 확보하고, 알림을 접었다가 왼쪽 탭에서 다시 열 수 있다.

## 통합 및 재현

- 원격 학생 재회와 로컬 은계 r50 프라자 출차 변경을 병합했다. 재회 호출을 배정하면서 로컬 경력의 자동 빈차등을 유지한다.
- 입력 처리와 위치 계산은 `PersonalRoomHUD.cs`와 `CockpitUI.cs`, Player 관찰은 `ShiftDevEndProbe.cs`에 있다.
- 새 경력의 숙소에서 벽의 세 목표 중 하나를 누른다. 영업 준비에 선택한 목표가 표시된다. 출차 후 C로 시점을 바꾸면 왼쪽 운행 알림을 비교할 수 있다.
- Windows 포인터 검사는 `pwsh -File tools/test_wall_memo_pointer.ps1`로 실행한다. 별도 경력과 별도 창에 포인터 입력을 보낸다. 실물 터치스크린에서 손가락으로 누르는 체감은 수동 확인 항목이다.

## 실행본 결과

- Unity 2022.3.62f2 `PrototypeBuild.BuildHybrid` 종료 0. 기존 r50 배포 폴더에 이 빌드의 관리 어셈블리를 반영한 구성으로 검사했다. 필수 지도 입력 문제 0.
- 숨긴 Windows Player 창에 누름·뗌 입력을 보내 벽에서 차량·생계·숙소 목표를 차례로 선택했다. 매번 영업 준비로 돌아가고 벽 메모와 계정 목표가 일치했다. 너비 1280·1600·1920에서 두 시점의 알림 왼쪽 여백이 같고 1인칭 미러 위 간격이 확보됐다. `WALL_MEMO_POINTER_OK`.
- `tools/test_home_base_player.ps1` 위치 제어 검사 23건. 프라자 출차와 귀가, 저연료 안내와 소멸, 시설 F 상호작용 통과.
- `tools/test_passenger_stories_player.ps1` 첫 만남 42건, 약속·재회 21건, 탑승 중 재실행과 하차 8건 통과.
- 기존 손님 이야기 결말 회귀 검사에서 운송 20건, 검사 142건 통과.
