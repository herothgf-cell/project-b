# 2026-11-24 길 아는 기사 · 퇴근 후 드라이브 · 차마다 다른 손맛 (08 3장·5장, 은계 싱글)

## 요구

자리 비움 일괄 작업(3차)의 1단계. 은계 싱글에 작은 것 세 가지를 넣는다.

- 미션 "길 아는 기사": 길안내를 끄고 도착하면 손님 한마디와 팁. 큰 경로 이탈 시 실패, 벌칙 없음.
- 퇴근 후 드라이브: 정산 뒤 선택하는 자유 주행. 미터기·호출 없음, 영업 시계·수익·연료 회계에 영향 없음, 라디오와 밤 조명 유지. 숙소 칸에서 F로 종료.
- 차마다 다른 손맛: 차종별 조향 반응·차체 기울기·제동 감각 차이. 싱글 전용, PvP 표준 성능 규칙 유지. 승객 승차감 판정에 미치는 영향이 있으면 표로 보고.

공통: 새 게이지·누적 등급 금지, 새 수치는 설정 툴에서 조절, 기존 저장 호환.

## 구현

### 1. 미션 "길 아는 기사"

- 기존 선택형 미션(급행·초록불·커피·칼정차)에 다섯 번째로 넣었다. 호출판 카드에 `[미션] 길 아는 기사 · 성공 시 +N원 · 길안내 없이 도착 · 크게 돌아가면 실패`로 보인다.
- 손님이 탄 뒤부터 하차까지 길안내를 숨긴다: 도로 위 안내선, M 지도의 경로선, 화면 위 회전 안내와 남은 거리. 승차지까지 가는 길은 평소처럼 안내한다. 목적지 이름은 화면 위 안내 칸에 계속 보이고 M 지도의 하차 표시도 그대로다.
- 미션이 끝나는 경우(모두 벌칙 없음, 약정 운임 그대로, 길안내가 즉시 돌아옴):
  - 실제 주행 거리가 약정 경로 거리 × 1.35 + 120m를 넘음(큰 경로 이탈)
  - **L** 키로 길안내를 다시 켬
  - 주행 보조(H)를 켬
- 성공하면 영수증에 `길 아는 기사 팁 (운임과 별도) +N원 · "기사님 길 잘 아시네요."` 줄이 붙는다. 금액은 운임의 15%(100원 올림)이고, 기존 미션과 같은 장부 항목(`mission:<운송>`)이라 한 운송에 한 번만 들어간다.
- 저장: 운송에 `missionVoid`(미션이 끝났는지) 한 칸을 더했다. 예전 저장은 기본값으로 열린다.

### 2. 퇴근 후 드라이브

- 하루 정산 화면 왼쪽 아래에 "퇴근 후 드라이브 (기록·수익 영향 없음)" 버튼이 생긴다. 숙소가 있고 차가 고장 상태가 아닐 때만 나온다.
- 누르면 숙소 주차 칸에서 출발한다. 장부는 **정산된 상태 그대로** 두고 정산 화면만 비켜 준다. 그래서 영업 시계, 수입, 연료, 피로·포만, 내구도, 사고 처리, 법규 기록이 움직일 수 없다(기존 코드가 모두 "영업 중"일 때만 계산한다).
- 드라이브 중에는 호출판이 비고 호출 수락이 거절된다. 시설 이용(F7·주유·매장)과 운전 평가도 멈춘다. 하늘과 가로등은 21시 조명으로 고정하고, 은계 FM 자막이 45초마다 한 줄씩(3종 순환) 나온다.
- 화면 위에 "퇴근 후 드라이브 · 미터기·호출 없음 · 숙소 칸에 세우고 F로 마치기" 한 줄이 뜬다. 숙소 칸에 반듯하게 세우고 F를 누르면 정산 화면으로 돌아오고, 다시 고를 수도 있다. 칸 밖에서 F를 누르면 안내만 나온다.
- 저장하는 값은 없다. 드라이브 중 게임을 끄면 다음에 정산 화면으로 열린다.

### 3. 차마다 다른 손맛

차종마다 네 가지 값을 둔다. PvP는 이 값을 쓰지 않고 항상 표준 차량이다.

| 차 | 핸들 반응 | 차체 기울기(연출) | 제동 쏠림(연출) | 브레이크 드는 시간 |
|---|---:|---:|---:|---:|
| 표준(PvP·연습) | 1 | 1 | 1 | 0초 |
| 아버지의 택시 | 1 | 1.25 | 1.2 | 0초 |
| 하이브리드 세단 | 1.25 | 0.8 | 0.8 | 0초 |
| 넓은 LPG 택시 | 0.85 | 1.1 | 1.1 | 0.2초 |

- **핸들 반응**: 사람이 조작할 때 핸들이 입력을 따라가는 빠르기다. 최대 조향각과 타이어 물리는 그대로다(회전 반경 차이는 기존 `steerFactor`).
- **차체 기울기·제동 쏠림**: 보이는 연출만 바꾼다. 설정 → 감각 탭의 0~100% 막대에 곱해진다.
- **브레이크 드는 시간**: 일반 제동(S·패드 브레이크)이 최대까지 드는 시간이다. 스페이스 급제동과 페달을 떼는 동작은 항상 즉시다.
- 차고의 차량 카드에 "손맛: 핸들 반응 빠름 · 차체가 단단함 · 브레이크가 바로 듦" 같은 한 줄이 붙는다.

### 승객 승차감 판정에 미치는 영향

판정 기준(코드 확인): 시속 7km 이상에서 종방향 가속이 4.5m/s² 초과 또는 감속이 6m/s² 초과인 상태가 0.45초 넘게 이어지면 급가속·급제동이다. 차의 승차감 계수(LPG 1.08, 컴포트 댐퍼 1.10)로 기준이 완화된다. 횡방향 가속은 판정에 쓰지 않는다.

| 손맛 값 | 판정에 미치는 영향 | 근거 |
|---|---|---|
| 핸들 반응 | 없음 | 급가속·급제동 판정은 종방향만 본다. 안정 주행 보상은 이동 거리 기준이다. |
| 차체 기울기·제동 쏠림 | 없음 | 연출만 바뀐다. |
| 브레이크 드는 시간(LPG 0.2초) | **있음(완화 방향)** | 제동이 0.2초에 걸쳐 들어 기준 초과 시점이 최대 0.2초 늦다. 약 0.65초 안쪽의 짧게 밟았다 떼는 제동은 판정을 피할 수 있다. 길게 밟는 급제동은 그대로 잡힌다. |
| 같은 값의 부작용 | 정지 거리 증가 | 계산상 시속 30km에서 약 +0.8m, 50km에서 약 +1.4m(속도 × 0.2초 ÷ 2). |

아버지의 택시와 하이브리드는 판정이 바뀌지 않는다. LPG는 기존 승차감 계수 1.08에 더해 조금 더 너그러워진다. 위 수치는 계산값이고 주행으로 재지 않았다.

## 판단이 필요했던 곳과 고른 쪽

| 판단 | 고른 쪽 | 이유 |
|---|---|---|
| "길안내를 끈다"를 누가 하나 | 미션을 수락하면 승차 후 자동으로 꺼짐 | 설정을 찾아 끄게 하면 미션 수락과 조작이 따로 논다. 다시 켜는 키(L)는 따로 둔다. |
| 길안내 다시 켜는 키 | L | N은 퇴근 키로 이미 쓰인다. 비어 있는 글자 키 중에서 골랐다. |
| 큰 경로 이탈 기준 | 실제 주행 거리가 약정 경로 × 1.35 + 120m 초과 | 내비 경로와 다른 길(지름길 포함)은 허용해야 "아는 길"이 된다. 경로에서 벗어난 순간이 아니라 총 주행 거리로 본다. 120m는 1km 안팎 운송에서 차로 변경·정차 위치 차이를 봐주는 여유다. |
| 보상의 장부 처리 | 기존 미션 추가금 항목 재사용, 영수증 표기만 "팁" | 팁 항목(`tip:`)과 섞으면 하루 연속 기록·팁 확률에 영향을 준다. 중복 지급 방지는 기존 미션 경로가 이미 한다. |
| 드라이브의 무영향 보장 방법 | 장부를 정산 상태로 둔 채 달리게 함 | 값을 저장했다가 되돌리는 방식보다 안전하다. 사고·수리비·법규 감점도 같은 이유로 생기지 않는다. |
| 드라이브 중 사고·법규 | 충돌해도 사고 처리 없음, 운전 평가 없음 | "영향 없음"을 지키려면 둘 다 꺼야 한다. 물리 충돌은 그대로다. |
| 드라이브 조명 | 21시 고정 | 영업 종료 시각은 영업 길이에 따라 달라 밤이 아닐 수 있다. 요구가 "밤 조명 유지"다. |
| 라디오 | 밤 멘트 3줄 순환 | 기존 은계 FM은 하루 일정표 자막이라 영업이 끝나면 더 나올 것이 없다. 음원은 원래 없다. |
| 아버지의 택시 물리 | 표준 그대로(연출만 느슨하게) | 08은 "무겁고 느슨하게"를 제안했지만, 시작 차의 물리를 바꾸면 첫날 체감과 지금까지의 조향 측정 기준이 모두 바뀐다. 차이는 새 차를 샀을 때 느끼게 했다. |
| 제동 차이를 어디에 두나 | 제동력이 아닌 "드는 시간" | 제동력을 바꾸면 주행 보조와 자동 검사의 정지 거리가 달라진다. 급제동(스페이스)은 건드리지 않았다. |
| 공업사 타이어·브레이크 부품(08 제안) | 넣지 않음 | 이번 요구는 차종별 차이까지다. |

### 회귀 검사 메모: 매장 검사의 비교 방식 수정

매장 검사(`-facilityArtCheck -refreshmentCheck`)의 "구매 후 저장된 영업 시계가 같은지" 1건이 이번 빌드에서 반복 실패했다. 게임 동작 문제가 아니었다. 실패 시점의 값은 현금 18,500/18,500원, 영업 시계 20.4399999901652/20.4399999901652초로 같았다. 저장 파일이 소수를 16자리로 적는데 검사는 17자리까지 완전히 같은지 비교하고 있어서, 구매 시점의 시계 값에 따라 통과와 실패가 갈렸다(이전 커밋 실행본은 같은 검사를 통과). 비교를 100만분의 1초 오차 허용으로 바꿨고 40건 통과한다. 게임 코드는 바꾸지 않았다.

### 자동 검사가 확인하지 못한 것

- **길을 모르고 달리는 느낌, 이탈 기준 1.35배+120m가 적당한지.** 검사는 거리 값을 직접 넣어 규칙만 확인했다.
- **L 키 입력.** 검사는 같은 함수를 직접 불렀다.
- **핸들 반응과 브레이크 드는 시간의 체감.** 사람 입력에만 적용되는 값이라 자동 주행으로는 재지 못한다. 값이 차에 들어가는 것까지만 확인했다. 브레이크 드는 시간 로직은 실행 검사가 없다.
- **밤 드라이브의 분위기, 21시 조명에서 도로가 잘 보이는지, 라디오 자막 간격.**
- 차량을 실제로 구매한 저장에서의 확인(검사는 값을 직접 적용했다).
