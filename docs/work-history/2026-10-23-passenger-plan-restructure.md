- 승객 기획서의 날짜별 히스토리를 본문에서 빼고 별도 문서로 보존한다.
- `매너`를 사용자용 `운전 만족도`로 정리하고 감점·상승 요인을 함께 설명한다.
- 기본 요청과 DR/CH/EV 확장 요청의 응답·효과를 한 절로 합친다.

안정 주행 회복은 **신규 제안**이다. 실제 이동 500m 또는 이동 시간 60초마다 +2, 운송당 최대 +6이며 해당 운송의 불필요한 급가감속 손실만 회복한다. 100점 상한, 법규·충돌·인도 침범 감점 비회복, 정차·반복 구간 누적 금지를 기획했다. 코드·실행 파일은 변경하지 않았다.

## 수행한 확인과 결과

- `DrivingManners.cs`·`MannerLedger.cs` 확인: 현재 `M`은 100점 시작·감점만 적용, 회복 함수는 없음.
- 기존 04 원문을 별도 기록으로 복사한 뒤 본문에서 날짜별 이력을 제거. 관련 04 앵커 참조를 갱신하고 구형 보너스와 신규 보너스의 상태를 나누어 표시.
- 문서 링크·용어·diff의 정적 확인 수행. Unity 빌드나 자동 물리 운행은 문서 작업 범위에 없어 수행하지 않음.
- 다른 주제의 미커밋 파일은 승객 기획 변경과 분리해 보존한다.

## 미검증·다음 작업

- 회복 규칙과 신규 `S0/Δtime/보너스`는 코드·빌드에 미적용. P8 구현 시 단위 계산·저장 복원·위치 제어·자동 물리·사람의 실제 주행을 따로 확인한다.
