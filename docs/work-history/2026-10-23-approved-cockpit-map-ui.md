# 승인된 주행 HUD·전체지도와 승하차 포커스

## 요청/승인

사용자가 시안13 배치를 승인했고 M 지도에서 승차·하차 지점을 선택할 때 포커스하도록 추가 요청했다. 기존 README/라이선스/XMind/편집기계획과 LATEST 사용자 변경을 보존했다. 새 원본지도/경유규칙/경제규칙은 추가하지 않았다.

## 검증 근거

- 모델 `pwsh -File tools/test_prototype.ps1`:23묶음 종료0.
- `tools/check_workspace.ps1 -Strict`:입력오류0/종료0,필수입력3개·ZIP변경없음.
- `PrototypeBuild.BuildHybrid`:최종 `artifacts/approved-ui-build-clip.log` 종료0/PROTOTYPE_BUILD_OK.
- 지도상호작용 `-mapInteractionTest -hybridV2 -uiCapture`:최종 `artifacts/approved-ui-render-clip.log` 16항목/종료0. 초기1280배율검사 소수점비교 실패를 허용오차.01로 수정. 선택만으로 운송/장부/목적지 변경 없음,승하차2포커스,별도수락1회,원래pause복원 검사.
- 실제GUI 렌더 1280×720/1600×900/1920×1080 각각 주행/현재운송지도 PNG6장 생성. 1280주행/지도,1600지도,1920주행 육안 확인. 아이콘누락·경로가 지도밖으로 새는 현상을 발견해 수정 후 재렌더. `artifacts/hud-live-*.png`,`map-live-*.png`.
- 기존 위치제어 회귀 `-presentationHudTest -hybridV2 -batchmode -nographics`:20항목/종료0. 기본수동,시작목적지없음,승하차/비상등/결과중복지급방지/도움말기본접힘.
- 렌더 성능 `-trafficPerformanceTest -hybridV2 -trafficT2`:종료0. T2 J6199_11987 정차30.002초,일반차량48대,Direct3D11,평균59.963FPS/p99 16.971ms. 특정위치짧은검사이며 전체맵/다른PC성능보장이 아님.
- 최종 실행로그3개에서 FAIL/Exception 없음. GUI 실제OS마우스클릭·모든승객말풍선픽셀·전체캠페인·수동주행은 별도 미검증. 지도행동검사는 공개메서드 호출이며 마우스클릭 검증과 구분한다.

## 실행/다음 확인

`builds/EungyeTaxi/EungyeTaxi.exe` 실행→영업시작→M→호출목록 또는번호핀→승차/하차 포커스→선택한호출수락. 운송중 M에서 승차/하차핀 또는 우측버튼을 누르면 해당위치만 확대된다. 지도오른쪽하단 내위치/+/-와 휠,상단위치정보/복사 사용.

다음은 사용자 직접플레이의 클릭감/하단대화가 운전시야에 미치는 영향/모든요청장문/다른화면비 확인이다. 원자료입력/지도ZIP은 그대로이며 배포manifest를 실제sourcecommit/파일해시로 갱신한다.
