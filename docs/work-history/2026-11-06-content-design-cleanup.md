# 콘텐츠 기획서 최신화·중복 정리

## 요청과 작업 기준

사용자 요청: `docs/content-design/`의 기획을 현재 기준으로 정리하고 중복·오래된 설명을 최신화한다. 새 기능·게임 수치 변경 요청으로 확장하지 않았다.

시작 시 `AGENTS.md`, `LATEST.md`, 개발 체크리스트·프로토 범위를 읽고 `git status --short`를 확인했다. 시작 main은 실제 `4563c6d`였다. 기존 미추적10항목(라이선스/마인드맵/이전 편집기 문서 등)을 보존했다. 작업 중 별도 제안서V6·HUD 시안 작업이 main/LATEST에 추가됐으며 그 문서/이미지·게시 이력도 되돌리지 않는다.

## 코드·자료 대조

- `DrivingSettings.cs`: 조향 민감도/반응/복원·데드존·브레이크5항목, 기본값과 범위.
- `PvpNativeLan.cs`: 현재 `native-city-lan-v11`, 입력/권한 계약.
- `AccidentSeverityPolicy.cs` 및 사고 구현 이력: 대상별 등급비용/시간/점수·보행자 손상 상한.
- `CampaignAccount.cs`, `PersonalRoomHUD.cs`, 개인 방 테스트/구현 이력: 조명/러그 가격·소유/저장·개인 지출과 영업 순수익 분리.
- `PassengerJobsChoiceEffects.cs`, 밸런스v1·요청 판정표·프리셋: 단계별 효과와 실제 판정의 차이. 사용자 대사/설정, 진행 저장 snapshot, 별도 인계 revision6 미적용 경계를 보존했다.

이는 코드/문서 대조이며 이번에 게임 검사를 다시 실행했다는 뜻이 아니다.

## 검증

문서 자동 검사와 코드/프로필의 정적 대조만 수행했다. 검증 스크립트·상세 보고서는 로컬 `artifacts/`에 있으며 Git 배포 대상이 아니다.

| 실제 검사 | 결과 |
|---|---|
| Python `artifacts/audit_content_design.py` | exit0. 콘텐츠48문서/614로컬링크, 보존4문서/100링크. 파일/앵커 누락0·제목 문제0·완전 동일 문단 반복0. 시작 시 존재한02 효과표 앵커 누락1건도 해소 |
| Python `artifacts/check_content_design_references.py` | exit0. 다른 문서의 콘텐츠 앵커 링크46개 누락0, 코드/프리셋8항목 대조 통과 |
| `git -c core.safecrlf=false diff --check` | exit0. 공백 오류 없음 |
| 변경 범위 점검 | 이번 변경은 Markdown만. 게임 소스/실행폴더/지도/사용자 마인드맵·생성 목차/프리셋 변경 없음 |

기계 검사의 동일 문단0은 의미가 비슷한 모든 문장을 자동 판정했다는 뜻이 아니다. 의미 중복/충돌은 위 변경표의 대상 문서/현재 코드를 직접 대조해 정리했다. 새 게임 테스트 통과나 사람 플레이 결과로 기록하지 않는다.

## 미검증·다음 작업

- 문서 정리만 수행했다. 새 Unity 빌드·위치 제어·자동 물리 주행·수동 플레이·전체3일·다른PC/LAN 검사는 수행하지 않았다.
- 작은 방의 사람3일 구매 동기/가격, 특수승객·경유·기상·도착 안내의 실제 주행 수용, 다른PC/DPI·LAN 장시간은 기존 잔여다. 이번 문서 작업으로 완료 표시하지 않는다.
- 마인드맵 원본/자동 목차의 노드·완료율과 사용자 메모/접힘은 변경하지 않았다. 06에서 탐색 snapshot과 현재 담당 문서의 차이를 설명한다.
- 배포 실행본은 기존 `0bba941`의 은계 싱글/A2·LANv11이며 `PrototypeBuild.BuildHybrid` 기준을 유지한다. 이번 게임/생성 지도/원본 입력/지도 ZIP/manifest/사용자 저장 변경 없음. 필수 로컬 입력은 직전 Strict exit0/issues0 기록을 인용하며 이번 Strict/manifest 재검사는 하지 않았다.
