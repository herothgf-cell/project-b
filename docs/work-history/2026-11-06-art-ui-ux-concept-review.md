# 아트/UI/UX 현재 컨셉 확인

## 요구사항과 확인 결과

사용자는 이 작업자의 역할을 아트/UI/UX 전담으로 지정하고 현재 디자인 컨셉 확인을 요청했다. 새 디자인 제작이나 게임 변경은 요청하지 않았다.

- 현재 승인 방향: 밝은 아이보리·하늘색 바탕, 흰 둥근 카드, 얕은 그림자, 남색 글자, 초록 주요 행동·파랑 안내·빨강 경고.
- 아트: 친근한 성인 캐주얼 3D 초상 4종과 채움형 공통 아이콘 20종/의미별 색 배지. 초상은 표시용이며 승객 성격/효과를 결정하지 않는다.
- UX: 도로·신호·보행자 시야 우선, 큰 방향/거리와 짧은 제목, 현재 필요한 수치, 승차 장소/도착지 구분, 요청/정산 동일 초상, 정산에서 생활거점 연결.
- 경험의 기획 방향: 한국 생활권의 택시 영업과 재출발, 자신이 선택한 차와 집으로의 성장. 현재 작은 방/조명·러그와 장기 차량 구매/이사 기획을 구분한다.
- 적용 상태: 싱글/PVP/설정/결과/개인 공간의 UI 통일은 구현 이력·코드로 확인. 시안의 캐주얼 도시·차량 외형은 현재 월드 적용 완료가 아니며 마지막 별도 검토 대상이다.
- 저장 캡처 관찰: 밝은 카드/초상 방향은 일치한다. 주행 화면의 카드 점유 면적·대화 효과 설명 밀도, 단순한 월드 외형과 UI 초상의 시각적 완성도 차이는 후속 아트/UX 검토 지점이다. 새 사용자 테스트 결과는 아니다.
- 문서 주의: `docs/content-design/14-personal-life-design-guide.md`의 모든 생활 기능 미구현 표기는 후속 작은 방 구현 이력보다 오래된 상태다. 이번에는 확인만 하고 해당 문서 수정은 하지 않았다.
