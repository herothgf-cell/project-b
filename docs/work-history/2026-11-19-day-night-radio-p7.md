# P7 낮밤 조명과 은계 FM

기획31과 낮밤·라디오 시안에 따라 P6 배포 dc8b57f 다음에 작업했다.

- 영업 시작 08:00부터 마감 20:00까지 아침·낮·노을·밤의 태양 각도·색, 하늘·환경광을 보간한다. 초과 영업은 밤이다. 비 조건이면 환경광과 태양광을 낮춘다.
- 노을과 밤에는 지도 도로 시설 근처의 가로등과 바닥 빛, 일부 건물 창을 표시한다. 창 밝기와 위치 선택은 지도 시드로 재현된다. 전조등은 자기 차와 가까운 차량을 합해 최대 4대다.
- 은계 FM은 아침 인사, 교통 정보, 동네 소식, 손님 사연, 마감 문구를 하단 1줄씩 표시한다. 비·행사·금요일·공사 카드에 따라 문구가 달라지며, 한 줄은 보이는 시간 기준 6초다. 승객 대화·지도·설정 화면을 열면 숨긴다. 콘텐츠 관리에서 라디오 문구를 편집할 수 있다.
- 저장 형식 9에서 당일 라디오 진행과 남은 표시 시간을 보존한다. 이전 이어하기는 기존 시간을 기준으로 이미 지난 안내를 건너뛴다.
- 정산 뒤 숙소의 밤, 다음 날 준비에서 여는 숙소의 아침을 기존 방·소품 아트로 표시한다. 화면 설정에 라디오 자막과 PvP 낮밤 조명 스위치를 추가했다.

주요 변경은 DayLightController·DayLightCity·LocalLightSurface, RainPresentation, RadioTicker·RadioSchedule, DriveSession·BusinessProgress, 운전 설정·PersonalRoomHUD, 콘텐츠 편집기와 실행 검증 도구다.

## 검증

- 콘텐츠 설정 C# 1,465건(라디오 25건), Node 편집기 107건, C#/Node UTF-8 및 이관 프로필 해시 일치. 날씨 설정 모델 3,148건, 숙소 모델 17건, 시각/비 조명 보간 23건, 표시·숙소 배치 24건.
- 첫 P7 후보의 `ApprovedEungyeRoads.VerifyAndBuild` 종료 0, 은계 39곳·1,482경로 및 r14~r46 저장 이관 1,063건. 기존 운전 설정 Player 20건, P6 배포본 운송 중 저장 9건과 P7 후보 복원 23건.
- 야간 후보 Player의 첫 신호·표지 검사 338건을 통과했다. 고정 카메라 캡처에서 켜진 신호와 비보호 화살표가 어두워 밝기를 보정했다. 주간과 꺼진 렌즈는 기존 재질을 사용한다.

- `tools/test_night_lighting_player.ps1 -SignageOnly`의 밝기 보정 후 야간 신호·표지 검사 340건을 통과했다. Direct3D11 카메라에서 켜진 신호, 꺼진 렌즈, 비보호 화살표 밝기를 함께 확인했다. 은계 강제 야간에서 가로등 61개와 건물 창 6,691개를 표시했다.
- 같은 PC에서 `tools/test_pvp_native_lan.ps1 -Rendered -ParkedSeconds 15 -DayLightPhase Day|Night`를 각각 실행했다. 호스트·참가 Player와 봇 2대를 사용했다. 주간 비교 후보의 호스트 전체 frame p95는 21.54ms였다. 신호 보정까지 적용한 야간 후보에서는 전체 972프레임 p95가 22.12ms, 안정 구간 890프레임 p95가 16.68ms였다. 두 실행 모두 호스트 20건과 참가 18건을 통과했다.
- 전체 frame p95가 기준 22ms를 넘겨 PvP 조명의 출하 기본값을 끔으로 설정했다. 화면 표시 설정에서 켤 수 있다. 강제 야간 측정 후보 이후 출하본 코드는 이 기본값 한 줄을 바꿨다.

- 출하본 `PrototypeBuild.BuildHybrid` 종료 0, `tools/check_workspace.ps1 -Strict` 필수 입력 문제 0. 지도 JSON·ZIP은 수정하지 않았다.
- 출하본 `tools/test_night_lighting_player.ps1`에서 야간 신호·표지 340건과 조명·자막·이어하기·숙소·표시 설정 23건을 통과했다. Direct3D11 은계 싱글 야간 480프레임의 p95는 16.668ms였다. 카메라·신호 검사는 고정 위치에서 수행했다.

## 실행과 남은 검증

통합 실행본 → 은계 싱글. 영업 준비 후 은계 FM을 확인하고, 시간이 흐르면 하늘·건물 창·전조등이 바뀐다. 정산 → 숙소에서는 밤, 2일차 이상 준비 → 숙소 보기에서는 아침이 표시된다.

캠페인 전체 수동 주행과 다른 PC 사이의 실제 LAN은 미검증이다.
