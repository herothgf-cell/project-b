## 요청·실제 작업

시뮬레이션에 추가로 구현할 요소를 검토해 달라는 요청에 따라 현재 체크리스트·범위·콘텐츠02/03/27과 관련 코드를 대조했다. 구현 지시는 없으므로 신규 기능·수치·런타임·사용자 저장은 변경하지 않았다.

- `docs/future-design/2026-11-02-simulation-review.md`: 구현/공백 표, 후보9개·우선순위/적용 모드/상대 비용, 권장 첫 묶음, 안전·저장·성능 검증 경계.
- 후속 README와 사고 문서: 내구도/수리/견인의 오래된 미구현 표기와 PVP 전체를 미래 구상으로 묶은 표기를 현재 구현 상태로 정정.
- 체크리스트·범위: 이번 검토 링크와 제안/채택 경계를 추가. 기존 완료 상태나 프로토 수치를 바꾸지 않음.
- LATEST: 현재 통합 배포와 이번 검토의 다음 결정을 인계.

## 검증·한계

읽기 시작 시 `git status --short`에서 기존 untracked7항목을 확인하고 보존했다. 초기 `git diff --quiet` 종료0, 현재 main `6244be9`의 문서/소스를 읽었다. 변경 문서7개의 상대 Markdown 링크143개 존재 검사에서 `DOC_LINKS_OK files=7 relativeLinks=143`, 명령 종료0을 확인했다. `git diff --check`도 종료0이다. 최초 두 기존 문서의 CRLF 안내는 LF 정규화로 정리했다.

이번은 문서/코드 검토이며 새 모델 시험·Unity 빌드·자동 물리 주행·수동20분/3일·다른PC 검사를 수행하지 않았다. 기존 배포 수용 결과를 이번 검토의 신규 시험 결과로 재사용하지 않는다.
