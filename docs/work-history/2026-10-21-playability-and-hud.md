# 수동 시내 운전·한글 HUD·전체지도·프로토 비용 축소

## 요청과 변경

사용자 요청: 급가감속 완화, 좁은 도로 좌우회전과 수동 운전을 쉽게, 시작 지점 보완, 한글 잘림 수정, 큰 전체지도, 승객 매너/법규 점수 UI, 보험·세금 프로토 제외.

- `DriveMath`/`TaxiController`: 뒷바퀴 최대 토크 각1100→550Nm, 약0.56초 토크 상승, S 일반 제동 완화·Space 긴급 제동 유지. 저속 중심 조향32→42도·앞바퀴 안팎 각도 분리. 고속 횡가속5m/s² 한계와 H 조향 전용 정책 유지.
- `DrivingManners`: 가속4.5/제동−6.0m/s²의 지속0.45초 초과를 평가, 2점·6초 중복 간격. 실제 필요한 제동 예외 유지. 법적 기준이 아닌 게임 조작/승차감 수치다.
- `ServiceStops`: 은계 임시 주차/출발점을 좁은 승하차10/차로711에서 넓은 국도42 외측 승하차1/차로273으로 이동. 실제 주차 시설 확인을 의미하지 않으며 다른 지역 배치는 유지한다.
- `FullMapOverlay`: G키/미니맵 버튼, 실제 경로·승차/도착·방향 화살표·7개 법규 구역 이름. 지도 동안 주행/영업시간 정지, 닫으면 기존 일시정지 여부 복원, 같은 프레임 Esc 이중 처리 차단. M 미니맵 범위 전환은 유지한다.
- `DriveHUD`/`DrivingReadability`/`KoreanText`: 한국어 버튼 글꼴/줄바꿈/폭 정리, 지도 밖 승차·도착 이름표 비중첩. 승객 탑승 전은 미평가, 탑승 후 실제 매너 게이지와 요구선. 법규는 오늘 실제 점수·유효 관찰 수 별도 게이지, 기록 전 회색 표시.
- `CampaignAccount`/`BusinessProgress`/`BusinessHUD`/`EconomyLedger`: 보험·세금 메뉴·비용·새 미납·보험 출발 제한·완납 목표 조건 제거. 기존 계정v2 거래를 먼저 검증한 뒤 보험/세금 거래만 제외해 v3로 정규화. 현금/미납/일일 순수익 재계산, 연료·일반 생활비·승객·법규 이력 보존, 반복 로딩 중복 보정 방지.
- 기획 범위·콘텐츠 경제/캠페인/지도·체크리스트·PC 실행 안내 갱신. 원본 지도3개는 변경하지 않았다.
