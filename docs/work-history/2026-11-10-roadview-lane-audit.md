## 조사 방법과 한계

- **거리뷰 접근 제한**: 내장 브라우저와 웹 가져오기 모두 `map.naver.com`을 안전 정책으로 차단한다. 사용자가 직접 연 네이버 지도 탭도 화면을 읽을 수 없었다. Chrome 확장(Claude in Chrome)은 연결되지 않았다. 그래서 좌표로 새 파노라마를 찾을 수 없었다.
- **대신 사용한 자료**: 저장소 문서·지도 메타데이터에 기록된 네이버 파노라마 ID 26개(2024-03~2026-05 촬영)의 이미지를 `panorama.pstatic.net` 타일로 받아 이어 붙였다(임시 폴더, 저장소에 넣지 않음). 이 중 7곳은 이번에 직접 다시 봤고, 나머지는 이전 기록(기획20·21)의 관찰을 인용한다.
- **게임 쪽**: 정식 지도 `config/maps/project/eungye.project.json`의 차로 1891개·교차로 규칙 129개·시설 69개를 읽기 전용 스크립트로 집계했다. 실행본 `builds/EungyeTaxi/EungyeTaxi.exe`(브랜치 출하 484c9bc)를 `-singlePlayer -brightUiCheck -laneMovementReview`로 실행해 렌더 5장을 새로 찍었다: `LANE_MOVEMENT_PLAYER_RESULT PASS checks=31`, exit 0. 위치 제어 렌더이며 물리 주행·사람 플레이·전체 캠페인 검사가 아니다.

## 수정 후보와 우선순위 (사용자 확인 전, 미적용)

1. **(높음) 스쿨존·제한속도 표지 배치**: 은계로·은행로 학교 주변에 `제한속도 30` 시설을 넣어 과속 판정을 실제로 작동시키기. 기획01의 범위 변경이 필요하므로 먼저 결정.
2. **(높음) 유턴 표시↔판정 일치**: 위 후속 확인 결과 J866·J5057 원본 회차 곡선은 유턴 표지가 없어 유턴 시 항상 위반, 내비 안내도 없음. A안(유턴 연결+조건 표지) 또는 B안(비활성).
3. **(중간) 미확인 교차로 거리뷰 대조**: 대은로 3곳, 은계로 북쪽 2곳, J5074, J5852. Chrome 확장 연결 또는 사용자가 거리뷰 링크(파노라마 ID 포함)를 주면 이번과 같은 방법으로 진행 가능.
4. **(중간) 은계로 중앙분리대 외형**: 노란 실선 → 분리대(녹지/펜스) 외형.
5. **(낮음) J5057 교차로 내부 선 정리**, 스쿨존 적색·황색 포장 외형.
