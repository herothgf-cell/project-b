- 최종 파일 6,256,960바이트, SHA256 `f1267cecc12c66a9d5e67dc4c054354ec24f0f9668fc8fa65bdd24eb87d16202`.
- 중간 오류: 글꼴 속성을 `fontFamily`에서 문서화된 `typeface`와 theme defaultFont로 수정. 재가져오기 검사의 런타임 패키지 경로 설정 후 통과. 최종 파일 하드링크 저장은 제한 실행에서 EPERM이 발생하여 승인된 권한 확장 실행으로 완료했다. 검증을 생략하지 않았다.

- 게임의 위치 제어 검사·자동 물리 주행·수동 플레이·전체 캠페인 검사는 이번 문서 작업에서 실행하지 않았다. PPT에 실린 자동 검사 결과는 기존 이력의 인용이다.
- PowerPoint 네이티브 앱에서의 재생 검사는 수행하지 않았다. Artifact Tool 렌더 및 PPTX 구조/가져오기 검증 범위다.

## 실행·재현

제안서는 PowerPoint에서 `docs/proposals/project-b-game-proposal-v1.pptx`를 연다. 게임 시연은 별도 매뉴얼을 따른다. 작업용 제작 코드·렌더·검증 영수증은 Git 제외 `artifacts/proposal-20261027/`에 있다. 원본 참조 이미지는 PPT에 내장되어 다른 PC 열람에 임시 이미지 경로가 필요하지 않다.

로컬 환경: 번들 Node `C:/Users/DRI/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node.exe`, Python은 같은 런타임의 `dependencies/python/python.exe`. 제작 재실행 시 `RUNTIME_NODE_MODULES`에 번들 node_modules를 지정하며 기존 최종 출력은 덮어쓰지 않는다. 기존 파일이 있으면 새 리비전 출력명을 사용한다.
