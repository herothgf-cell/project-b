# 교차로 진입 차로별 진행 방향 계획

## 요구사항

교차로 부근에서 각 차로가 좌회전용인지 직진용인지 등을 구분해야 한다. 앞선 요청대로 이번 채팅은 계획만 정리한다.

## 실제 변경

- `docs/map-polish-plan.md`에 교차로ID·접근 방향·차로ID/왼쪽부터 순번·노면 화살표/표지·허용 진행 방향·연결 출구 차로·거리뷰 촬영월/위치·확인 상태를 기록하는 표와 판정 기준을 추가했다.
- `docs/work-history/LATEST.md`에 이 계획과 미검증 상태를 인계했다.
- 관련 체크리스트의 기존 미완료 항목은 `docs/prototype-development-checklist.md`의 '우선 동선 전 구간의 정확한 촬영점/양 방향/교차로별 차로 및 신호 운영 확정'이다. 이 파일에는 다른 진행 중 변경이 있어 이번 문서 작업에 섞지 않았다.
- 게임 지도·설정·코드·빌드는 변경하지 않았다.

## 검증과 결과

- 기존 `docs/map-polish-plan.md`, `docs/prototype-development-checklist.md`, `docs/prototype-scope.md`, `docs/content-design/06-world-map-and-driving.md`와 `EungyeHybridBuilder.cs`의 내부 차로 임시 회전 연결을 대조했다.
- 문서 변경은 `git diff --check`와 변경 파일 확인으로 검증했다. 거리뷰 신규 관찰, 자동 검사, Unity 빌드, 물리 주행, 수동 플레이는 수행하지 않았다.

## 미검증·다음 작업

- 현재 은계 내부 교차로의 차로별 실제 허용 방향과 출구 차로 연결은 미확인이다. 기존 근처 거리뷰 관찰만으로 좌회전/직진/우회전 차로를 확정하지 않는다.
- 다음 채팅에서 우선 동선의 교차로ID·진입 방향별 거리뷰 촬영점을 정하고 표를 채운다. 확인된 연결부터 공통 차로 그래프를 보정하고, 금지 방향 경로가 생성되지 않는지 자동·수동 주행으로 별도 검증한다.

## 실행·재현

1. `docs/map-polish-plan.md`의 '교차로 진입 차로별 진행 방향' 표를 사용한다.
2. 게임의 교차로ID와 진입 도로·차로ID를 뽑고 네이버 지도에서 접근로마다 정지선 앞뒤 거리뷰를 확인한다.
3. 촬영월·보이는 화살표/표지·허용 방향·미확인 사항을 기입한다. 현재 작업에는 실행 명령이나 빌드 결과가 없다.
