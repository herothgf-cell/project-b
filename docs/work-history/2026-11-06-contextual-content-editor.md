# 2026-11-06 승객 요청·대화·효과의 상황별 연결 편집

## 요구사항
- 사용 여부를 `사용 / 사용 안함`으로 단순화하고, 숫자 입력 범위와 등장 가중치를 구분한다.
- 요청별 실제 승객 대사·기사 답변·선택 결과를 게임처럼 읽으며 문구/효과를 함께 편집한다.
- 승객 유형·상황·효과·공통 영향 요소·법규도 실제 연결과 판정 조건을 이해할 수 있게 한다.

## 구현
- 숫자 필드별 목록을 요청 17종·승객 유형 12종·상황·효과·법규 상황 단위로 묶었다. 327개 설정(289 편집/38 고정)과 별도 법규 참조76개를 모두 탐색한다.
- 상세 첫 화면에 현재 프로필의 승객 대사와 번호별 답변·결과를 표시한다. 선택지를 누르면 문구/효과 편집칸으로 이동한다. 같은 ID의 공유 입력·미리보기는 즉시 동기화하며 입력 중 포커스를 유지한다.
- 사용 여부에는 참/거짓·숫자 범위를 표시하지 않는다. 숫자는 `입력 가능한 값`과 단위를 표시한다. 현재/기본 대사와 ID·조건·효과를 검색한다. 연결 항목 이동 때 검색/필터를 풀어 목적지를 가리지 않는다.
- 기본 후보 추첨 비중을 표시한다. 기본 일반 요청16종의 가중치가 모두1이면 1/16=6.25%다. 같은 자격 후보 추첨에서만 같은 비중이며 실제 전체 등장 확률은 아니다. 0건 배정·대표 유형 요청 연결·경로 자격·조합 제외·안전 정차 기회가 실제 등장에 영향을 준다. 분실물은 별도 하차 후 조건부10% 사건이다.
- 빈 기사 답변 override도 실제 내장 선택지 문구를 미리 보여준다. `{errandSeconds}`는 미리보기에서 현재 용무 시간으로 표시하고 원문 편집값은 보존한다. 현재 한국어 문구 편집이며 다국어 로케일 엔진을 추가하지 않았다.
- 법규의 상황·관찰 조건·법규 감점·독립 M 영향을 묶었다. 준수 회복은 위반 없는 사건에만 적용하며 0점 위반도 회복을 막는다고 명시했다. 고정 결과·참조·기술 정보는 편집 가능한 값과 구분한다.
- 공통 설정과 실제 사용 요청/상황을 양방향으로 연결한다. 공유 설정/상세 판정은 접고, 데스크톱 저장·적용 버튼을 하단에 유지했다. 다른 항목 선택 시 상세 스크롤을 처음으로 이동하며 같은 항목 편집 때는 유지한다.
