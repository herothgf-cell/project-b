- **J866 로드뷰 확인(카카오, 2026-06 촬영)**: 유턴 보조표지는 "보행신호시 / 좌회전시"로, 게임 조건(좌회전·보행 신호시)과 같다. 교차로 안 좌회전 유도선은 흰 점선이며, 원본 지도 자료의 황색 실선(kind 525, type 111)과 다르다.
- **77곳 대조**: 11/19 점검 도구(`-mapAudit`)의 게임 위 시점 화면과, 같은 중심·같은 축척(가로 154m, 북쪽 위)의 카카오 항공사진(0단계 타일, 1픽셀 약 12.5cm)을 나란히 붙였다. 좌표 변환은 EPSG:5186 게임 좌표 → WGS84 → 카카오 좌표(Bessel TM×2.5, 실측 두 점으로 보정)다. 하위 에이전트 3개가 26·26·25장씩 나눠 판정했고, 핵심 사례는 직접 다시 봤다.
- **원인 확인(J7973·J866)**: 원본 노면표시만 따로 그려 보니 원본은 깔끔했다. 게임이 차로에서 자동 생성한 중앙선·차선이 위치가 어긋난 채 겹쳐 그려진다. 원본 노면표시는 교차로 주변 30~40m에만 있다.
