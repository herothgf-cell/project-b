# 2026-11-03 신호·네비·PvP 닉네임/짧은 운송·조향

## 요청과 범위

신호 대기 단축·양방향 직진 검토, 닉네임 입력, 승차/하차 경로 거리, 신호 변경 카운트다운 단순화. 후속 지시로 닉네임 외 공통 기능을 싱글/PVP에 적용하고10분 PVP의 운송 회전과 좌우 조향 반응을 개선한다. 기존 실제 음악/에어컨/창문 보류와 최소 검증 선호를 유지한다.

## 실제 구현

- 기본 보호 신호에만 별도 런타임 프로그램: 주축 양방향 직진10/황색2/정리2→허용 좌회전 방향별4/2/2→교차축 동일→보행10/정리2. 없는 좌회전은 생략. 직진·좌회전·교차축·보행을 상충해서 열지 않으며 우회전의 정지/양보·교차로 점유 보호는 유지한다. 최장 기본 주기80→72초, 좌회전 없는 사거리는40초. 편집 신호·교육 관찰·기존 실제 비보호 권한은 보존한다. 실제 도로 시간표 변경/현장 확인 주장 아님.
- 신호 안내는 현재 접근 신호(직진·좌회전 화살표 등)의 다음 실제 색 변화까지 초만 표시한다. 편집 프로그램도 경계 시간을 계산하고 조건부/고정 신호는 시간 미정. 실제 규칙 판정과 신호등 모양은 유지한다.
- 네비의 다음 회전 거리와 별도로 승차까지/하차까지/경유까지 경로 잔여 거리를 표시한다. 공차 시설 안내는 도착까지. 실제 경유/대체 지점 경로를 따르며 직선거리로 대체하지 않는다.
- PVP 입장 전12자 닉네임 필수. 글자/숫자/공백/밑줄/하이픈만 보존, 빈 입력 차단. 로컬 설정을 저장하고 LAN handshake→호스트 슬롯→room→각 PC의 로컬 슬롯 순서로 배포한다. 재접속 슬롯/빈자리 봇 정책 유지. 기존 소유자 예측 통신v2에 이름 필드를 추가하고 이전v1 거부를 유지한다. 검증 이름은 probe에서만 제공하고 사용자 설정을 쓰지 않는다.
- 10분 이하 신규 공유 호출: 승차 수요 분산과8호출+3길가를 유지하고 실제 연결된80m 이상 도착지 중 가장 가까운3곳에서 선택한다. 승차지별 순위는1회 계산·캐시하며 정렬 중 길찾기를 반복하지 않는다. 호출 휴지는60→30초. 수락된 운송·거리 운임/기한은 그대로다. 기존 장거리 위주20분 경기와 싱글 배차는 유지한다. 회전 수 보장은 아니며 직접10분 경제 체감은 별도다.
- 키/패드·LAN 원격 조향 입력 램프를4.5~2.2/s→9~6/s로 통일(0→최대 약0.11~0.17초). 저·중속 수동 조향 가산0.40→0.55, 최대52도/30km/h 이상 기존 각도·충돌/제동/횡그립 제한 유지. 순간 차체 회전/속도 배속을 넣지 않는다.

관련 파일: DriveFlowPolicy, TrafficSystem/RoadMapSignalProgram, DrivingReadability, PvpPrototypePanel/PvpNativeLan/PvpDriverPresentation, PassengerJobs/PassengerJobsDemand/PvpSimulationCallBoard, TaxiController/DriveMath, DriveFlowBuild/PvpNativeLanProbe. 지도JSON/ZIP/저장 위치·기존 사용자 마인드맵은 바꾸지 않는다.
