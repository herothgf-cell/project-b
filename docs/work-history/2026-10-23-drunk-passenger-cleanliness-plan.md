# 취객 운송·차량 청결도 프로토 기획 (2026-10-23)

## 요구사항

- 취객을 프로토타입 승객으로 추가하고 운송 중 확률적 구토, 도착 후 확률적 기상 지연을 기획한다.
- 구토한 승객이 하차한 뒤 청결도를 크게 낮추며, 낮은 청결은 다음 승차 거부, 높은 청결은 승차 만족도 가산으로 연결한다.
- 세차를 기존 주유소에서 제공하고 청결 수치를 주행 HUD 연료 표시 오른쪽에 배치한다.
