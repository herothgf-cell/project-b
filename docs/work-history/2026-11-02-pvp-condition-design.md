# 2026-11-02 PVP 피로·포만감 기획 분리 정리

## 요구와 실제 변경
사용자 요청: 기존 기획 문서 안에서 PVP 모드로 구분해 별도로 정리하고 채팅에도 요약한다.

`docs/content-design/03-life-and-economy.md`에 모드별 적용 표와 `pvp-driver-condition` 전용 항목을 추가했다. 기존 콘텐츠27의 현재 소모량/20분 사례/후보 수치를 옮기고, 캠페인·현행 PVP·개선 제안을 구분했다. 식사/휴식 비용·시간·효과, 봇 동등 규칙, 호출/정산 안내, 단거리/장거리 선택, 우회시간을 포함한 손익과 채택 전 결정 사항을 표로 정리했다. 준비 지연/운임 보정의 구간은 중첩하지 않는 후보로 명시했다.

콘텐츠27에는 본문 중복 대신 단일 기준 링크를 남겼다. 공통/PVP 기획 목록과 로드맵에서 연결했고, 초기 PVP UI 문서의 생활 게이지 제외 문구가 현행 모드에 적용되지 않는다는 안내를 추가했다. 기존 캠페인 규칙/승객/내구도/실행 코드/배포 파일은 변경하지 않았다.

## 상태·검증·남은 항목
문서 링크 대상/전용 앵커, diff 공백 오류를 마지막에 확인한다. 문서 작업이므로 Unity/Player 검사와 재빌드는 하지 않는다. 모든 개선 수치는 후보이며 게임 미적용·밸런스 미검증이다.20분은 예시이고 경기 시간 확정이 아니다. 효과 조합·정산 순서·졸음 대체 범위·시설 종료 처리·경기 길이별 수치/봇 선택을 결정한 뒤 구현/게임 검증해야 한다.

기존 실행본은 소스61c9e98,140파일115,186,267바이트이며 [통합 배포 기록](2026-11-02-pvp-flow-release.md)을 유지한다. 다른 체크아웃은 조작하지 않는다.

최종 문서 검사 결과: 링크 대상199개와 PVP 전용 앵커 확인 통과, `git diff --check` 종료0. 게임 코드/배포 변경 없음.
