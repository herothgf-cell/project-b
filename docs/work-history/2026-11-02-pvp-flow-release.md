- `flow-mode2` 실제 창: 초기 메뉴/PVP설정 캡처 후 월드 생성85,767,393ms 공백, 종료2. 역시 복원 검증 완료 근거 아님. 실제 완주를 새 실행에서 확인해야 한다.
