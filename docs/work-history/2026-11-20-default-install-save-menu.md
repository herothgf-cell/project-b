# 기본 설치 폴더의 싱글 시작과 일시정지 메뉴

기본 설치에는 도로·조향·차내 조작 커밋이 별도로 누적되어 있었고, 싱글 버튼은 즉시 게임을 시작했다. 이전 워크트리에서 검증한 메뉴 패치(3e5b397)의 게임 소스 7개와 경력 기획 변경을 기본 프로젝트 코드에 병합했다. 기존 도로 빌드 ab8aa9f의 데이터와 사용자 콘텐츠 설정을 유지하고 PrototypeBuild.BuildHybrid로 다시 컴파일한 Assembly-CSharp.dll을 설치했다.

타이틀은 ‘싱글 / 마을에서 택시 운용’ → ‘처음부터 하기 / 불러오기’다. 처음부터 하기는 기존 경력을 보존한 새 슬롯을 사용한다. 불러오기는 실제 저장을 시각순으로 표시한다. 일시정지에서는 연습 선택과 처음 이야기 다시 보기를 제거하고 ‘불러오기’와 ‘처음부터 다시하기’를 표시한다. 새 버전은 기존 게임을 종료하고 기본 경로 builds/EungyeTaxi/EungyeTaxi.exe를 다시 열면 적용된다.

검증은 기본 폴더 DLL의 실제 메서드에서 메뉴 문자열과 버튼 연결 13건 확인, 은계 r49 필수 입력 문제 0건, Unity 빌드 종료 0이다. 기본 폴더 Player의 임시 저장 통합 검사는 -batchmode -nographics -unifiedModeCheck로 재현한다. 사용자 입력이나 저장 슬롯을 직접 조작하지 않는다.
