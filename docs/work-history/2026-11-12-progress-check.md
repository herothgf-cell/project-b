# 2026-11-12 프로젝트 진행 상황 점검

진행 상황 확인 요청에 따라 최신 이력, CURRENT-STATE, 체크리스트, 프로토타입 범위, 기획22를 현재 코드와 출하 기록에 대조했다. 시작 main은 `6e0152a`이며 로컬 `origin/main`과 0/0이었다. 원격 재조회는 하지 않았다.

- 은계 싱글 3일과 A2 PvP를 통합 실행본으로 배포했다. 최신 게임 소스 `575ca46`, 출하 `9ae2297`, Unity 2022.3.62f2, BuildHybrid, LAN v17이다.
- 차량 교체·차고·PvP 내 차는 main 병합 및 배포 상태다. 싱글 영업 시간 10/20/30/60분 선택과 개발용 정산 기능, J5057·J866 유턴 수정, A2 신호 37곳·생활 골목·승객 요청 빈도 조정이 반영됐다. 요청 평균 1.5건은 출하 기본 비중의 기대값이며 기존 사용자 프로필은 저장값을 사용한다.
- 제안서 V10 문서와 방 조명·러그 이미지 및 생성 도구는 로컬 변경으로 확인했다. 기존 변경과 점검 문서는 별도다.

이력의 PvP 신호 적색 32.0초는 위치 제어 실측이다. 기존 자동 검사 실패는 Editor 교통 3건, 실행본 `test_pvp_simulation` 은계 6건·A2 5건으로 이전 빌드에서도 재현됐다. 이번에는 새 빌드, 위치 제어, 자동 물리 주행, 수동 플레이, 전체 캠페인 검사를 수행하지 않았다.

다음은 싱글 3일의 차종 체감·교체 가격, J5057/J866 유턴, PvP 신호/뒷골목·호출 운송과 실제 다른 PC LAN 검증이다. 두 PC는 같은 최신 빌드가 필요하다. 기존 v17이라도 PvP 지도 지문이 다르면 접속이 거부된다. 스쿨존 제한속도와 미확인 교차로는 별도 작업 후보다.

실행 경로는 `builds/EungyeTaxi/EungyeTaxi.exe`다. 이 기록, LATEST, 개발 체크리스트의 병합 상태만 갱신했다.
