## 실행·재현

기본 실행은 `builds/EungyeTaxi/EungyeTaxi.exe`, 지역은 은계다. 취객은 후보별20%·하루 실제 탑승 최대1명이며 시간대/시작 지점 고정이 아니다. 구토25%와 기상 지연30%는 독립 추첨이다.

1. 취객 승차 후 소개·반복 대사를 확인한다. 구토 대상이면 예고 후3게임초 이상 뒤 구토한다.
2. 정상 목적지 하차 후 새 호출을 수락하면 세차 안내로 제한된다. 길가 대기 승객에게 F를 누르면 직접 거부 대사가 보인다.
3. 주유소3곳 중 하나에서 F7 세차를 완료하면 청결100·호출 재개. 세차 전 재실행/다음 날에도 잠금 유지.
4. 자동 재현은 위 exe에 `-passengerCareTest -careCapture`를 전달한다. 별도 테스트 저장을 사용하는 저장/복원 인자를 순서대로 실행한다.
