# 2026-11-24 직접 플레이 확인 목록 (제한속도, 사고 과실 구분)

사용자가 다음 묶음을 시작하기 전에 직접 플레이하기로 했다(2026-11-24). 아래는 그때 볼 것이다. 자동 검사 통과는 체감 확인이 아니다.

실행: `builds/EungyeTaxi/EungyeTaxi.exe` → 은계 싱글. 실제 경력과 섞이지 않게 새 슬롯을 권한다. 이 실행본에는 다른 세션의 직접 플레이 피드백 반영(커밋 d385ff4a, 지도 r53)도 들어 있다.

## 결정 기록

- **단속 카메라의 과태료(돈으로 내는 벌금) 도입: 허용**(사용자 2026-11-24). 공공데이터 이용 조건 확인은 구현 전에 한다.
- **골목 주차: 두 질문 모두 허용**(사용자 2026-11-24). (1) 실제와 대수·위치가 같지 않은 주차 차량을 "게임 연출"로 밝히고 넣는다. (2) 그 골목에서 일반 차량을 뺀다. 추천하며 건 조건: 대상은 로드뷰에서 노상 주차를 확인한 은행로144번길 한 곳, 지도 자료에 "게임 연출, 근거: 로드뷰 확인" 표기, 대수와 켜고 끄기는 설정 툴, 골목을 뺄 때 주변 일반 차량 흐름을 먼저 확인하고 눈에 띄게 막히면 사용자에게 다시 묻는다. 구현은 시작하지 않았다(직접 플레이 뒤).

## 제한속도

| 볼 것 | 어디서 | 판단할 것 |
|---|---|---|
| 속도계 왼쪽의 원형 숫자 | 어디서나, 1인칭(V)과 3인칭 모두 | 눈에 들어오는지, 다른 표시를 가리지 않는지 |
| 숫자가 바뀌는 순간 | 수인로(60) ↔ 일반 도로(50) ↔ 학교 앞·번길(30) | 바뀐 것을 알아챌 수 있는지. 소리나 강조가 필요한지 |
| 넘었을 때 깜빡임 | 제한을 조금 넘겨 달리기 | 경고로 충분한지, 거슬리는지 |
| 과속 판정 | 일반 도로에서 시속 60을 넘겨 3초 이상 | 여유 10km/h와 3초가 답답한지 느슨한지. 감점 5가 적당한지 |
| 학교 앞 30 | 은계로 은빛초·은계유치원·은계초 앞, 은계중앙로 은계유치원 앞 | 넓은 길에서 갑자기 30이 되는 것이 납득되는지. 반경 60m가 길거나 짧지 않은지 |
| 교차하는 도로까지 30이 되는 곳 | 위 학교 앞 교차로를 가로질러 지나가기 | 학교와 상관없는 길에서 30이 뜨는 곳이 있는지(있으면 위치를 적어 둔다) |
| 수인로 60 | 수인로 직진 | 다른 길보다 시원하게 느껴지는지. 신호에 자주 걸려 차이가 없는지 |
| 수인로의 좌회전·유턴 대기 차로 | 수인로 교차로 앞 | 60이 유지되는지(검사 중 50으로 읽히던 곳을 고쳤다) |
| 일반 차량 속도 | 학교 앞과 번길(약 27km/h), 일반 도로(약 45), 수인로(약 54) | 앞차가 너무 느려 답답한지, 줄이 길어지는지, 교차로가 막히는지 |
| 호출 소요 시간 | 호출 3~4건 | 전보다 늦어져 지각이 늘었는지. 급행·초록불 미션이 어려워졌는지 |
| 손님 반응 | 손님을 태우고 20km/h 넘게 초과 | "과속 · 손님이 불안해해요"가 나오는지, 감점 3이 적당한지 |
| 퇴근 후 드라이브 | 정산 뒤 드라이브 | 표시는 나오고 과속 기록은 남지 않는지 |

끄고 비교: 설정 툴 "법규"에서 `law.speed.enabled`를 0으로 두면 이전 동작이다.

## 사고 과실 구분

| 볼 것 | 방법 | 판단할 것 |
|---|---|---|
| 내가 박았을 때 | 일반 차량이나 시설에 부딪히기 | 이전과 같은 사고 화면·처리비·감점이 나오는지 |
| 서 있다가 받혔을 때 | 차로에 멈춰 뒤차가 닿게 두기(일반 차량은 대개 멈추므로 잘 안 일어난다) | "상대 차량 과실 · 처리비와 감점 없음" 알림이 나오고 사고 화면이 안 뜨는지. 손님이 타고 있으면 운행이 이어지는지 |
| 억울한 경우 | 평소 플레이 중 | 받혔는데 내 사고가 된 경우가 있는지. 특히 일반 차량이 차로를 바꾸며 옆을 친 경우 |
| 넘어간 경우 | 평소 플레이 중 | 내가 박았는데 상대 과실로 넘어간 경우가 있는지. 특히 아주 느리게 움직이다 닿은 경우 |
| 알림 문구 | 상대 과실이 났을 때 | 6초가 적당한지, 사유가 이해되는지 |

끄고 비교: `accident.fault.enabled`를 0으로 두면 이전 동작이다.

## 함께 들어간 다른 작업 (커밋 d385ff4a)

추격 카메라, 운전석 시점, 주행 소리, 설정 막대, 호출 패널, P51 신호가 바뀌었다. 이 변경의 확인 항목은 그 작업의 기록을 따른다([LATEST](LATEST.md)의 "직접 플레이 피드백 반영").

## 적어 두면 좋은 것

- 과속으로 감점된 위치와 그때 속도. 여유와 지속 시간을 조정하는 근거가 된다.
- 제한속도가 이상하게 느껴진 위치(도로 이름이나 근처 건물).
- 사고가 났을 때 내가 본 상황과 게임의 판정이 달랐던 경우.
