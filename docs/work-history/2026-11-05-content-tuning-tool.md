# 승객·대화·효과·법규 관리 도구 조사·설계안

## 요구와 실제 작업

승객 요청/대화 선택지/효과/법규별 정리와 현재 설정의 영향 요소를 직접 조정할 도구 요청. 사용자는 **게임과 별도로 켜는 관리창, 표와 검색 편집**을 선택했다. 로컬 브라우저·Node 구성과 적용 시점은 작성자 제안이다.

최신 인계·체크리스트·범위·승객/대화/주행/PVP 기획·법규 자료와 현재 코드를 대조했다. 요청17종·일반+특수11유형·짐/음식/수면/상황 응대·법규 점수/M/만족도/운임 연결을 조사했다. 법규76개 자료 색인과 실제 판정 구현은 구분했다.

`docs/superpowers/specs/2026-11-05-content-tuning-tool-design.md`에 관리창5분류·검색·영향 연결·프로필/기본값·원복·게임 반영·저장/LAN·실제 미리보기·배포 검증을 작성했다. 설계 검토 담당 에이전트의 읽기 전용 검토 결과는 `nothing important left`다. **사용자 설계 확인·구현은 아직**이다. Node v24.21.0과 npm/pwsh 존재 확인. 서버·패키지 설치·제품 코드는 작성하지 않았다.

## 검증과 한계

문서 연결·`git diff --check` 결과는 아래 영수증에 기록한다. rg에 경로 와일드카드를 직접 넘긴 검색과 없는 `PassengerCare.cs` 검색은 오류2였으며 이후 `-g` 필터로 실제 소비 지점을 확인했다. 해당 파일을 검사했다고 표시하지 않는다. 다른 작업이 LATEST/체크리스트를 갱신한 것을 확인하고 최신 내용을 보존하여 이번 항목만 추가했다.

빌드·위치 제어·자동 물리 주행·수동 플레이·전체 캠페인 검사는 미수행. 도구 구현·런타임 설정 전환·저장/LAN·실제 화면·법률 최신성 검증도 미수행이다. 별도 HUD/가독성/메뉴/서비스 소스와 미추적 Unity 자료는 이번 작업에 섞지 않는다.
