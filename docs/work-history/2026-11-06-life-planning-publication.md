# 생활 기획 정리·화면 시안·메인 게시

사용자 요청: 기획을 정리하고 실제 게임 같은 화면 시안으로 설명하며 기획 내용을 메인에 우선 푸시한다.

14 안내 문서에10~13 읽기 순서와 현재 최소 범위, 화면 흐름/회계 예시를 정리했다. 기존 artifacts/ui-bright/player-navigation/07-single-day-summary.png를 확인하여 시각 스타일을 참고한 생성 목업을 요청했다. 목업은 구현 화면이 아니다.

원격 메인은 로컬 작업 브랜치의 여러 게임 변경보다 이전 상태다. 원격 기준 별도 artifacts/planning-main 작업 트리에 개인 생활 기획 파일과 관련 이력만 선택 복사하고 공용 색인에는 링크만 추가한다. 코드/빌드/배포/지도 변경은 게시하지 않는다. 기존 작업 공간과 미추적 자료를 보존한다.

검증은 문서 diff/선택 파일 및 원격 커밋 확인으로 한정한다. 게임 빌드·플레이·Strict/manifest 검사는 하지 않았다. 현재 작업 브랜치의 LANv9 실행 상태를 메인 배포 상태로 주장하지 않는다. 게시 결과는 실제 git push 및 원격 해시로 확인한다.

화면 목업은 생성 결과를 직접 확인했고 정산/구매전/구매후의 동일 방과 현금 계산이 의도대로 표현됐다. docs/content-design/images/three-day-room-mockup.png에 저장했다. 선택 문서의 링크 존재를 확인해 누락된 감사 보고서/참조 이력을 함께 게시한다. diff 공백 검사에서 EOF 여백을 수정했다.
