# 하루20분 호출 접근·실운행 검증

## 요구와 진행 계획

일반 차량48대를 유지하고 승객 운송·식사·수면·주유를 연속 물리 주행으로 확인한다. 기존 지도 정합/전체 수동 확인은 별도 미완료다.

1. 이전558.62초 픽업 만료 원인: 호출 정렬은 직선거리, 기한은 방향 도로거리. 실제 접근거리로 정렬·픽업 기한을 보완한다.
2. 기존 모델 회귀와 BuildHybrid를 실행하고 기본 시작점에서 같은 일반 영업 호출을 선택한다.
3. 연속 물리 운행 결과에 따라 오류를 수정한다. 위치 이동/회계 주입으로 성공을 만들지 않는다.
4. 결과·미검증·실행파일 manifest와 개별 기획서를 갱신한다.

## 변경

- PassengerJobs: 현재 방향의 공유 HdRoadGraph 경로로 픽업/중반 식당 접근 거리 계산. 호출 생성마다 후보별 계산을 한 번만 수행하고 정렬에 재사용. 도달 불가 후보 제외.
- OneDayOfferPolicy: 픽업 기한 max(180초, 방향 경로거리/3+180초). 앞선1.72km/558초 실패에 여유 제공. 승차 후 운송 기한·운임·상황 경유 금지는 유지.
- 결과 비교 버전 eungye-day20-v3-access. 기존 결과 저장 보존, 다른 설정 버전 비교 제외.
- OneDayCampaignTests에 기존 실패 구간 기한 여유/가까운 픽업 최소값 회귀 추가. 변경 전 실패(exit1), 변경 후 모델21묶음 성공(exit0).

## 출발 조건 정정

북쪽 지도 기본점에서 시작한 이전 검사는 일반 게임과 달랐다. BusinessProgress의 일반 준비 단계는 이미 기존 주차장에서 배치하지만 테스트 모드가 이를 건너뛰었다. 사용자도 주차장 출발을 선택했으며, 하루 물리 검증이 같은 PlaceAtParking 절차를 출발 전에 호출하도록 수정했다. 일반 게임의 시작점을 새로 옮긴 작업은 아니다. 출발 전 1회 배치를 제외하고 운행 중 위치 이동/회계 주입은 하지 않는다.

수정 전 북쪽 출발 진단 주행: 픽업562.8초 성공, 하차767.9초/5,700원/매너100/자연 상황 체험=True, 식사50초/3,000원 완료. 주유 접근 중 검사를 중단해 실제 주차장 조건으로 다시 시작한다. artifacts/day-north-start-baseline.txt와 day-north-physical-baseline.txt에 보존. 이 결과는 정상 시작의 하루 밸런스 근거로 쓰지 않는다.

리뷰 보완: 빈 호출 목록은 3초 간격으로 재생성하여 주유소에서 차로 복귀 뒤 갱신한다. 자동 주행 기한은 실제 픽업 예산보다 짧지 않게 한다. 실패한 식사/수면/주유는 수행 횟수에 넣지 않으며 주유 구간 충돌/운행 점수도 검증한다.

## 정상 주차장 출발 1차 — 미통과

`day-parking-build.log` exit0, 공유 도로144쌍 검사 통과. `day-parking-live.log` exit1. 첫 픽업358.9초, 하차632.2초/5,700원/매너100/자연 상황 관찰 성공. 식사50초/3,000원, 동쪽 주유소 실제 진입·10%/400원 결제·진출 성공. 주차장1165.8초 도착으로100초 수면 예산 부족, 완료로 처리하지 않음. 운송1건·이동4,812.9m·순수익1,800원·연료48.88%·충돌0/급제동0/신호 감점1.

신호 감점 원인: 자동 검증 운전의 정지 기억이 교차로 단위로 남아 다른 방향 재방문 때 재사용됐다(J8066_6364 적색 우회전). 검증 조작의 기록을 방향/방문별로 바꾸고 각 구간 시작·접근 이탈 시 초기화한다. 일반 차량/사용자 신호 평가를 느슨하게 변경하지 않는다.

생활 동선: 주유소의 접근거리만 최소화하면 복귀가 길었다(동쪽 접근514m+주차장1,864m). 후속 검사 정책은 주유소 접근+출구 후 주차장 복귀 합계를 최소화한다. 사용자에게도 가능한 기존 주유소 선택이며 도로·생활비·수면 시간을 줄이지 않는다. 최종 검사 도구는 정산 도중 미완료 구간을 Update에서 종료하여 timeScale0 대기로 성공/실패 처리가 무한정 멈추지 않도록 한다.

## 승인된 휴식 주차구역

기존 주차장 복귀까지 가장 짧은 동부 주유소를 선택해도 수면100초가 부족했다. 신호 정지 기억을 고친 두 번째 검사(day-planned-baseline.txt)는 충돌0/신호감점0/급제동0이었지만1165.82초 도착해 수면 실패(exit1). 사용자에게 동선 한계를 설명한 뒤 인근 휴식 주차구역 추가 승인을 받았다.

동부 주유소 같은 진행 방향80m 뒤에 별도 파란 주차면·진입·진출을 배치했다. 게임 좌표(1177.85,886.79), 공유 차로 local:8265:6305:9056:10851의 접근486m 지점. 기존 건물/수면/도로 간섭 검사를 거친 게임 창작 시설이며 실제 시설 확인이 아니다. F7 수면 안내는 기존 주차장과 추가 구역의 실제 방향 거리를 비교한다. 주유3곳·출발/마감 주차장은 유지하며 추가 구역에서는 수면만 가능하다. 무료100초/피로40 회복·일1200초·운임·생활비는 바꾸지 않았다. 결과 설정 버전 eungye-day20-v3-access-rest.

변경 파일: PassengerJobs/OneDayOfferPolicy(접근·기한), BusinessProgress(기존 주차장 배치 검증 공개), FuelStationLayout/ServiceStops(휴식 시설), FullMapOverlay/DrivingReadability(지도 표시), LiveTrafficValidationTest/OneDayTrafficDriveTest/TrafficPerformanceProbe(검증), MapIdentityProbe 및 Editor 회귀 검사, 모델 검사, 기획04/05/07/09/10·범위·체크리스트·맵 정비표.
