# 제안서 양식 검토·마인드맵 기반 제품 비전 보강

## 요구사항

사용자가 다시 제시한 회사 제안 양식의 충족 여부를 검토하고, 마인드맵을 참고해 시뮬레이션의 다양한 기능과 완성될 게임 모습을 보여준다. 필요한 경우 첨부 콘셉트에 맞춘 예시 이미지를 생성·배치한다.

## 실제 변경

- `docs/proposals/proposal-v2-review.md`: 필수 19항목의 1차 평가·2차 위치, 선택 항목과 미확정 사항, 마인드맵 근거 가지를 대조했다. 실제 참여자 정보는 사용자 기존 지시에 따라 확인 필요를 유지.
- `docs/proposals/assets/taxi-life-concept-v2.png`, `taxi-garage-concept-v2.png`: 내장 image_gen으로 생성해 저장소에 복사·PPT 내장. 실제 화면과 구분한 목표 시안.
- `docs/proposals/assets/concept-prompts-v2.md`: 전체 생성 프롬프트·도구·용도·경계 기록.
- `docs/proposals/README.md`, `docs/work-history/LATEST.md`: 최신 자료와 인계 갱신.
- 게임 코드/현재 기획/체크리스트/빌드/지도/manifest는 변경하지 않았다. 별도 조작 매뉴얼은 현재 동작이 같아 기존 파일 유지.

## 근거 및 범위 판단

실제 작업 파일 `docs/content-design/택시 시뮬레이션.mmst`를 JSON으로 읽어 전체 가지와 후속 가지를 확인했다. 현재 기획·범위·개발 체크리스트·사고/수리 후속 기획을 대조했다. 차량 구입·정비·단골·예약을 장기 동기에 연결하고, 날씨·사고/보험·금융·욕구·PvP는 우선순위를 나눈 후보로 제시했다. 원본은 변경하지 않았다.

마인드맵 입력/종료 SHA256 비교 기준: `7c4e5d0c86970d633040a4cf77b4d9511af2c3b5aabe6a636ba3622e850b6666`. 기존 사용자 변경은 보존한다.

12개월/핵심6명은 확장 전제 없이 확정하지 않았다. M2에서 채택 범위·일정·인월 재산정을 명시했다. 제안서 수정은 게임 기능 구현 승인으로 취급하지 않았다.

## 검증과 결과

- 실제 1차 PPTX ZIP/XML에서 24장 제목을 추출해 제작 소스와 대조. 첫 추출의 콘솔 cp949 오류는 UTF-8 출력으로 해결했다.
- Artifact Tool 2차 제작 실행 종료0. 32장 렌더·개별 이미지 검토 완료. 본문/표 편집 가능, 표10개.
- 최종 패키지 지적0, 레이아웃 지적0/경고0, Malgun Gothic 603개 텍스트 스크립트 검사 통과, 32장 재가져오기 통과.
- 최종 PPTX 11,592,152바이트. SHA256 `73b2f73056ba07ca1aeeeeb1cc81d776899fb874ba73f603c29b87791e6e820f`.
- 생성 이미지 2장을 직접 검토하고, 목표 시안/실제 지역과 다름을 캡션과 노트로 표시했다. 라이선스 차량/확정 디자인으로 주장하지 않았다.
- 실제 PowerPoint 앱에서의 재생·글꼴 확인은 수행하지 않았다. Artifact Tool 렌더 및 패키지/레이아웃 검사 범위다.
- 위치 제어 검사·자동 물리 주행·수동 플레이·전체 캠페인·게임 재빌드·Strict 재실행은 이번 문서 작업에서 하지 않았다. PPT의 자동 검사 수치는 이전 이력 인용이다.

## 실행·재현 및 다음 작업

`docs/proposals/project-b-game-proposal-v2.pptx`를 연다. 요구사항 대조는 `docs/proposals/proposal-v2-review.md`, 게임 시연은 기존 매뉴얼을 따른다. 제작 스크립트·검증 보고·렌더는 Git 제외 `artifacts/proposal-v2-20261027/`에 둔다. `revise.mjs`는 1차 제작 소스를 읽어 2차 `build.mjs`를 만든다. 번들 Node와 `RUNTIME_NODE_MODULES`를 사용하며 finalizer의 하드링크 단계에 승인된 권한 확장 실행을 사용했다. 재실행은 새 최종 출력명을 사용한다.

회사 제출 전 참여자·담당자·타겟/KPI·채택 기능·비용·일정 및 네이티브 PowerPoint 표시 확인이 남았다. 현재 게임 후속은 기존 인계대로 수동20분/3일 경제·운전 조작감·장시간 성능·실물 패드 검증이다. 필수 입력과 배포 상태는 기존 인계를 유지한다.

실제 기록 커밋은 `git log -1 --oneline -- docs/work-history/2026-10-27-game-proposal-v2.md`로 확인한다. 사용자 `.mmst` 및 기존 untracked를 커밋에 포함하지 않는다.
