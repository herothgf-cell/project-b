# 주행 HUD·승객 대화창 검토용 시안

## 요청과 제작

현재 컨셉을 유지하면서 주행 HUD/승객 대화창의 가독성을 개선한 시안을 먼저 확인하겠다는 사용자 요청이다. 게임 적용 승인은 아니다. 내장 image_gen으로 기존 실행 캡처를 참고한 검토용 PNG 두 장을 생성하고 채팅에 표시했다.

- `docs/ui/2026-11-06-hud-dialogue-preview/driving-hud.png`: 상단 정보 한 줄, 내비/운송 묶음, 오른쪽 지도/돈, 하단 차량 상태/평가로 중앙 시야 확보.
- `docs/ui/2026-11-06-hud-dialogue-preview/passenger-dialogue.png`: 하단 중앙 초상/큰 대사, 답변과 효과 구분, 성공·실패 별도 배지. 효과를 숨기지 않고 두 응답과 단축키 유지.

원본 참고는 `docs/ui/2026-11-06-filled-icons-trip-flow/05-single-passenger-request.png`다. 밝은 아이보리/흰 카드·남색 글씨·파란 내비·초록 주요 행동, 초상과 기존 프로토타입 도시 분위기를 유지하도록 요청했다. 새로운 시스템/보상은 제안하지 않았다. 생성 그림의 지도/회전 방향/신호/수치는 배치 예시이며 실제 주행 판단 자료가 아니다. 신호는 실제 적용 시 기존 다음 등화/잔여 초 계약을 그대로 사용해야 한다.

## 검증과 한계

두 생성 결과를 눈으로 확인했다. 대사/응답/효과 구분과 5종 상태·만족도/요구·운전 점수의 표시를 확인했다. 생성기 때문에 두 장의 카드 크기/세부 배치가 완전히 같지 않고, 신호 그림/화살표는 런타임 정확성을 갖지 않는다. 긴 대사·다중 선택·해상도별 배치/클릭 영역은 미검증이며 후속 상세 설계 대상이다. 실제 게임 실행 캡처로 오인하지 않도록 시안 표시를 넣었다.

게임 코드/규칙/빌드/저장/지도/배포 manifest는 수정하지 않았다. 새 위치 제어·물리 주행·수동 플레이·전체 캠페인 검사 없음. 현재 은계/A2·LANv11·실행본0bba941/BuildHybrid 유지, 필수 지도 입력은 직전 Strict exit0/issues0 인용·이번 재검사 없음. 기존 미추적10항목 보존.

## 변경 파일·재현·다음 작업

변경은 PNG2장, 생성 프롬프트 `docs/ui/2026-11-06-hud-dialogue-preview/prompts.txt`, 이 기록과 LATEST다. PNG를 열어 검토한다. 생성은 내장 image_gen/edit 참조 경로 방식, 투명 배경 false로 수행했으며 생성 결과는 비결정적이다. 다음은 사용자가 시안을 검토한 후 배치/정보 밀도 수정 또는 게임 적용 범위를 결정하는 것이다.
