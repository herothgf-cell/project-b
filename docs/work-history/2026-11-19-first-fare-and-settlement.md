# 첫날 숙소 근거리 호출과 하차 결과

은계 r47 P7 배포본의 첫 운송 점검에서 ‘physical curb dropoff’가 실패했다. 첫날 첫 호출을 숙소 가까이에서 잡고, 하차 동작 결과와 다음에 필요한 행동이 화면에 드러나게 수정했다.

## 이전 주행의 원인

2026-11-19 17:44:12에 기록된 테스트 전용 저장에서 승차지 EG-GAME-08-B(30)와 목적지 EG-GAME-10-B(38), 호출 시드, 운임 6,600원을 주행 로그와 대조했다. 기한 145.60초에 실제 하차 시간은 178.67초였다. 승객은 F 한 번으로 내렸고 ‘늦은 도착 · 승객 하차 완료 / 요금 0원’이 기록됐다. 기존 물리 검사는 정시 완료만 인정해 늦게 마친 운송도 하차 실패로 보고했다. 과거 영수증의 시간 표시도 제한 시간에서 잘린 값을 사용했다.

## 구현

- 첫날 첫 호출의 1번 슬롯을 숙소 주차 칸에서 **도로를 따라** 가장 가까운 이용 가능한 승차지에 배정한다. 점유·쿨다운·접근 가능성·연료 조건을 반영하고 첫 호출은 기존 ‘여유’ 기한으로 계약한다. 수락 여부를 경력에 저장한다.
- 늦게 도착한 영수증에 하차 완료와 기한 초과를 함께 표시하고 실제 하차 시각을 사용한다. 운송 규칙에 따라 늦은 운송의 운임은 0원이다.
- 정차 칸 안내와 F 입력 결과에 정차 방향·감속·점유·승객 준비·다시 깨우기 등 실제 필요한 다음 동작을 표시한다.
- 주요 변경 파일은 PassengerJobs.cs, FatherStoryState.cs, StopArrivalGuidance.cs, StopArrivalPresentation.cs, RideCompletionPanel.cs, BusinessProgress.cs, OneDayTrafficDriveTest.cs, tools/test_first_fare_player.ps1이다. 배포 빌드는 PrototypeBuild.BuildHybrid다.

## 재현 방법

새 경력은 `pwsh -File tools/test_first_fare_player.ps1`, 이전 30→38 경로는 같은 명령에 `-PreviousRoute`를 붙인다. 각 실행은 독립 디렉터리의 테스트 저장, 일반 차량과 차량 물리를 사용한다. 이전 경로 재현은 기존 제안의 시드·기한을 고정하고, 일찍 도착할 경우 기한까지 기다린다. 새 경력 검사는 정상 생성한 1번 제안을 수락한다.

초기 수정 후보에서는 숙소 정차 위치에서 바로 승차(공차 0m), 유상 운송 1,473.7m, 실수령 9,990원, 수첩 해금을 확인했다. 이 후보의 귀갓길 자동 운전은 도로 접근 지점에 도착했지만 별도 신호 판정 1건으로 검사가 정산 앞에서 종료됐다. 원래 30→38 제안을 복원한 후보의 별도 주행에서는 F 1회, 정차 가능, 공간 점유 없음, 승객 하차와 0원 정산 기록 1건을 확인했다. 수정 전 배포본을 무작위 호출로 다시 실행한 비교 검사는 다른 호출을 선택했고 첫 픽업 접근 중 100초 정체로 종료됐다.

## 건물 안쪽 숙소와 출입구

추가 요청에 따라 r47 덕성프라자(`37612022:B0010000:7014`)의 1층을 게임용 주차장으로 설계했다. 기존 건물 윤곽과 상층부를 남기고 남쪽 외벽에 폭 22m 개구부, 입구 기둥과 간판을 배치했다. 건물 내부에 천장과 조명, 영업차 칸과 아버지 차 보관 칸을 둔다. 진입 차량은 안에서 돌아 출구를 향해 주차한다.

지도 로컬 좌표 (X,Z) 기준 출입구는 (261.67,528.26), 영업차 칸은 (256.53,537.56), 보관 칸은 (263.37,536.07)이다. 도로에서의 진입 지점은 (284.13,509.11), 출차 후 합류 지점은 (233.21,519.65)로 같은 방향 차로를 따라 연결된다. 최초 호출 후보는 차고 출구의 도로 연결점을 기준으로 선정한다. 숙소 거리에는 차고 출차 경로도 포함한다.

2.0×4.8m 차체를 0.2m 간격으로 샘플링한 기하 검사에서 차체 5,409점과 벽·이웃 건물·보관차를 대조했다. 주차한 차체의 가장 가까운 도로 가장자리까지 9.78m, 주행 궤적에서 보관차까지 최소 4.95m였다. 건물 내부 주차·실제 퇴근, 물리 접촉 및 화면 검사는 아래에 별도로 기록한다.

## 최종 실행본 검증

- 은계 r47 통합 Player를 `PrototypeBuild.BuildHybrid`로 빌드했다(종료 0). 차고가 분할된 도로의 먼 끝에 연결되던 문제를 진입·합류점을 각 방향 차로에 투영해 고쳤다. 실내 구조·표지·차로는 HomeGarage.cs, 기존 건물과의 결합은 WorldBuilder.cs와 RoadEnvironment.cs, 숙소 정차 및 복귀는 ServiceStops와 HomeGarageParking에서 관리한다. - `tools/test_first_fare_player.ps1`에서 새 경력 생성 후 일반 교통과 차량 물리로 주행했다. 차고에서 도로 합류까지 34.04m, 출발부터 첫 승차까지 417.81m였다. 승차지 27 → 하차지 30의 약정 경로는 694.45m, 제시 운임은 5,800원이었다. 정차 후 F 한 번에 완료했고 실수령은 6,540원이었다. 집으로 돌아와 진입로부터 실내 주차까지 73.04m 주행 후 F로 퇴근했다. 총 2,587.98m, 운송 1건, 순수입 4,540원, 충돌과 신호 위반 0건. 정산과 저장을 모두 확인했다.
- 같은 실행본에서 `-PreviousRoute`로 이전 호출을 복원했다. 2,039.27m를 물리 주행해 F 한 번에 기한 초과 하차, 운임 0원, 영수증 정확히 1건을 확인했다. 새 호출과 이전 호출 모두 성공으로 종료했다.
- 별도 Player 검사에서 숙소 상호작용 14건(도로에서 퇴근 거부 포함), 차량 보관 47건, 재실행 13건, PvP 차량 표시 12건을 확인했다. `tools/check_workspace.ps1 -Strict` 필수 입력 문제 0건. 지도 JSON 변경 없음.
- 최종 빌드의 자동 물리 검사는 첫날 첫 운송과 정산까지다. 같은 저장의 4일 연속 물리 운전 및 초행자의 수동 입출차 체감은 미검증이다.
