# 2026-11-26 직접 플레이 피드백 8차: 제한속도 필터 기본 끔, 파출소·응급실 건물과 생활시설 (은계 싱글)

## 요구 (사용자, 2026-11-26)

1. 지도의 과속(제한속도) 도로 표시 필터는 기본 꺼짐으로 한다.
2. 파출소·응급실을 건물 디자인으로 만든다("딸랑 판떼기만 있으면").
3. 파출소·응급실도 생활시설에 넣는다. M 지도에서 보이지 않는다. UI가 부족하면 시안을 만들고 개선한다.

## 원인

- 전체 지도에는 응급실이 다른 시설과 같은 작은 파란 아이콘으로만 있어 눈에 띄지 않았다. 파출소 이름표는 다른 이름표와 겹치면 밀려났다.
- 오른쪽 "생활시설" 패널의 탭은 주유·식사·수면·세차·수리·간식뿐이라 파출소·응급실이 없었다.
- 건물은 7차에서 기존 지도 건물에 판 간판만 붙였고, 응급실은 길가 기둥 표지뿐이었다.

## 시안

[시안](../ui/2026-11-26-care-facilities/mock-care-facilities.png): 생활시설 패널에 "파출소"·"응급실" 탭과 카드(거리, 할 일, 길 안내), 지도에는 색이 다른 큰 핀(남색 방패 / 빨간 십자)과 항상 보이는 이름표. 사용자 지시("시안 만들고 개선해")대로 이어서 구현했다.

## 구현

| 내용 | 동작 |
|---|---|
| 제한속도 필터 | 전체 지도·미니맵의 제한속도 구간 표시(`ShowLimits`) 기본 꺼짐. 단속 카메라는 켜짐 그대로 |
| 생활시설 탭 | 패널 탭에 파출소·응급실 추가(3열 3줄, 선택 안 됐을 때 아래에 남색/빨간 줄). 파출소 카드: 거리·시간, "분실물 맡기기 · 사례 +300원", 맡길 물건(주인 대기 시간 포함) 또는 "지금은 맡길 물건이 없어요", "앞 정차 칸에 서서 F → 맡기기", 길 안내(맡길 물건이 있으면 강조 버튼), 실제 주소. 응급실 카드: 거리·시간, "응급 손님은 앞 정차 칸에 내려 드려요", 게임 전용 안내, 길 안내. 운송 중에는 길 안내 버튼을 막는다(`CareFacilitiesUI`) |
| 지도 핀 | 전체 지도는 36px 큰 핀(파출소 남색 원+흰 방패, 응급실 빨간 사각+흰 십자)과 같은 색 이름표("파출소 · 은행파출소", "응급실 · 은계 응급의료센터")를 항상 그린다. 다른 이름표는 이 자리를 피한다. 미니맵은 24px 같은 핀 |
| 파출소 건물 | 지도 건물 바닥 모양에 맞춘 2층 건물을 기존 건물보다 조금 크게 세운다: 흰 벽, 사방 남색 띠와 앞면 "POLICE 은행파출소", 청색 띠, 유리 출입문과 남색 차양, 금색 휘장, 1·2층 창, 지붕 테·적청 경광등·안테나, 옆에 순찰차. 7차의 보도와 정차 칸은 유지, 판 간판·기둥 표지는 없앴다(`CareBuildings.BuildPolice`) |
| 응급실 | 정차 칸 쪽 건물 면 1층을 응급센터 입구로 꾸민다: 흰 외장, 빨간 띠 "응급의료센터 EMERGENCY", 높은 곳의 빨간 십자 조명 상자, 유리 자동문과 창, 보도 위 기둥 넷 차양("+ 응급실"), 세워 둔 구급차. 기둥 표지는 없앴다(`CareBuildings.BuildEmergency`) |
| 충돌 | 새 건물 물체에는 충돌체가 없다(주행·사고 판정 그대로) |

## 미검증 / 남은 것

- 건물은 검사 카메라 한 각도로만 봤다. 밤 조명(간판·십자 발광)은 없다.
- 응급실 입구 앞 구급차가 차양 기둥과 조금 겹쳐 보인다.
- 파출소 핀은 내 차가 바로 앞에 있으면 "내 위치" 표시에 가려진다.
- 배포 실행본은 갱신하지 않았다.

## 실행·재현

- 플레이: M 지도 → 오른쪽 "생활시설" → 파출소/응급실 탭. 지도 왼쪽 위 60 버튼으로 제한속도 구간을 켠다.
- 검사: `EungyeTaxi.exe -contentTest -lostCheck -lostOutput <폴더>`
