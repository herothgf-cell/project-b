# P4 아버지의 택시와 첫날 이야기

기획33과 첫날 인트로·아버지 수첩·벽 메모·차량 보관 시안을 적용했다. P3 배포 b66aa70 기준으로 작업했다.

- 새 은계 경력에서 첫 출발을 고르면 8·10·8초 인트로를 한 번 재생한다. Esc나 클릭으로 건너뛰고, 은계 메뉴에서 다시 볼 수 있다. 시안에서 추출한 3컷을 교체 가능한 임시 아트로 넣었다.
- 숙소 주차 칸 운전석에서 K로 빈차등을 켠다. 첫 탑승에 수동 미터기 J 또는 자동 보조를 안내한다. 첫 완료 운송에서 수첩을 발견한다. 수첩은 숙소와 일시정지 메뉴에서 열 수 있다.
- 무위반 정산과 목표 50%를 수첩에 연결했다. 동네 별·금요일 조건은 후속 단계에서 연결할 수 있게 저장 상태에 인터페이스를 둔다.
- 2일차부터 수다 손님이 하루 한 번 택시 일에 관해 묻는다. 어느 답을 골라도 기본 만족도 +1이며, 안전하게 정차한 뒤 응답할 수 있다. 콘텐츠 관리의 승객 → 아버지 이야기에서 질문·응답·효과를 바꾼다.
- 첫날 정산 뒤 숙소 벽에 차·집·일단 버티자 중 하나를 붙일 수 있고, 이후에도 바꿀 수 있다. 일단 버티자는 3일차 정산에서 다시 고를 수 있다. 차 목표의 기본 대상은 하이브리드 세단이며, 이전에 선택한 넓은 LPG의 저장은 그대로 읽는다. 넓은 호실 목표는 P2의 저축 금액을 사용한다.
- 아버지의 택시를 보상 판매에서 제외한다. 새 차의 정가를 내고, 다음 날 새 차로 출발하면 아버지의 택시를 숙소 주차장에서 볼 수 있다. 차고에서 다음 날 운행할 보유 차를 다시 고를 수 있고, 보관 비용은 없다. 과거 차값 정산 내역은 소급 변경하지 않는다.
- 외부 캠페인 저장 형식 6, 계정 스냅숏 형식 5. 이전 경력은 건너뛴 상태로 이관하며 새 경력에는 독립적으로 인트로가 있다. 은계 r47 지도와 LAN v19을 사용한다.

주요 변경은 IntroCutscene·DrivingCamera·CockpitPresentation, BusinessProgress·FatherStoryState·PassengerJobs·PassengerBehaviorUI, LogbookHUD·PersonalRoomHUD·OneDayHUD, VehicleCatalog·CampaignAccount·EconomyLedger·VehicleGarageHUD, 콘텐츠 설정과 실행 검증 도구다.

## 검증과 재현

- 모델 `tools/test_content_tuning.ps1` 884건, UTF-8·프로필 이관 C#/Node 해시 일치. 콘텐츠 원본 확인 `node tools/content-editor/choice-catalog.mjs . --verify`.
- 차고 모델 `tools/test_vehicle_garage.ps1` 75건, 숙소 모델 17건, 차량 내구도 191건. 콘텐츠 편집기 Node 103건.
- 전체 `tools/test_prototype.ps1`는 앞 20개 검사 모음 통과 후 `ManualHandlingTests`의 S키 일반 제동 기대값에서 종료 1. 같은 테스트를 P3 기준 소스로 재컴파일해 같은 결과(8.823529)를 확인했다.
- 첫 P4 통합 후보의 `ApprovedEungyeRoads.VerifyAndBuild` 종료 0, 승하차 39곳과 방향별 1,482경로, r14~r46 저장 이관 1,063건.
- 같은 후보의 차고 Player 47건·재실행 13건·PvP 외형 12건. 기존 3일 → 4·5일 계속 영업 및 별도 새 경력 Player 16+5건.
- 최종 `PrototypeBuild.BuildHybrid` 종료 0. `tools/test_father_story_player.ps1` 위치 제어 23건과 별도 재실행 7건. 인트로 3컷을 모두 보았고 추가 재생 시간이 30초 이내였다. 첫 운송·숙소 마감·월세·수첩, 2일차 질문 응답, 저장 복원과 3일차 메모 교체를 확인했다. 자동 물리 주행과 수동 캠페인 플레이는 수행하지 않았다.
- P3 실행본으로 운송 중 테스트 저장 형식 5를 생성해 저장 검사 9건, P4 실행본이 이 파일을 읽고 운송을 마치는 복원 23건을 통과했다. 소스는 최종 Player 시험 설정 한 줄이 바뀌기 전 P4 후보와 같다.
- 은계 r47 지도와 배포 ZIP에 변경이 없으며 `tools/check_workspace.ps1 -Strict` 입력 문제 0.

통합 실행본에서 은계 싱글 → 새 경력 → 영업 시작. 인트로 종료 후 K로 빈차등을 켜고 첫 운송을 마친다. 숙소 주차 칸에서 퇴근하고 정산 → 숙소 → 벽 메모로 들어간다. 다음 개발은 P5 하루 조건 카드다.
