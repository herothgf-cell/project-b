# 2026-11-24 직접 플레이 피드백 5차: 제한속도 표지 위치·모양, 빨간 포장 제거, 승객 얼굴과 이름·나이대 맞춤

## 요구 (사용자, 2026-11-24, 스크린샷 2장)

1. 표지판이 횡단보도나 차도 위에 서 있는 곳을 고친다.
2. 도로 표지판은 나무위키 "도로교통표지판/대한민국"을 참고한다.
3. 바닥의 과속 구간 빨간 포장을 없앤다.
4. 승객 프로필 사진과 성별·이름·나이대가 어느 정도 맞는 얼굴로 한다(노인 얼굴인데 학생이라고 나옴).

## 참고한 표지 규격

나무위키 해당 문서를 읽었다(긴 문서라 일부만 직접 확인). 확인한 것은 색상표(빨강 #b92021, 파랑 #00498b, 검정 #262626, 하양 #eaeaea)와 아래 세 가지다.

- 해제표지(427)는 해제할 표지를 빗금 친 영역에 넣은 사각형이다.
- 어린이보호(324)는 지시표지다.
- 어린이보호구역 보조표지는 폐지됐다.

최고속도제한(224)의 빨간 테 원형·흰 바탕·검은 숫자는 문서에서 직접 확인하지 못했다. 일반적인 실물 형태로 그렸다. 지주 높이·위치도 문서에 없어 인도 가장자리, 표지 중심 약 2.1m로 잡았다.

## 구현

| 내용 | 동작 |
|---|---|
| 표지 위치 | 예전에는 차로 중심에서 오른쪽으로 3.1m 고정이라 교차로 출구에서는 횡단보도·차도 위에 섰다. 이제는 구간 변화 지점 기준 앞으로 3·7·11·15·20·25·30m(없으면 뒤로 3·7m)에서 오른쪽 2~16m를 훑는다. 그중 인도 면(지도 인도 영역, 도로 선분·건물 밖)이면서 교차로 횡단보도 범위(교차로 반폭+1.8+2.4+3m)와 OSM 횡단보도(도로 방향 ±폭/2+2m) 밖인 첫 자리에 세운다. 자리가 없으면 세우지 않는다(84곳 중 7곳) |
| 표지 모양 | 시작: 규제표지 224 형태(빨간 테·흰 바탕·검은 숫자) + 보조표지(흰 판·검은 테·검은 글씨 "여기부터"). 어린이보호구역 시작은 위에 지시표지 324 형태(파란 사각·흰 어른과 아이)를 달고 보조표지 "어린이보호구역"을 붙인다. 끝: 해제표지 427 형태(흰 사각 안의 제한 표지에 검은 빗금 3줄) + 보조표지 "구간 끝" / "보호구역 해제". 예전의 회색 사선 원(유럽식)은 없앴다 |
| 빨간 포장 | 어린이보호구역 바닥 빨간 포장 메시를 만들지 않는다. 지도·미니맵의 구간 선과 진입 알림 띠는 그대로다 |
| 승객 얼굴·이름·나이대 | 초상 그림은 4장이다(안경 쓴 젊은 남성, 젊은 여성, 50대 남성, 70대 여성). 예전에는 얼굴과 이름(30개)을 따로 해시로 골라 서로 맞지 않았다. 이제 `PassengerPresentation.Persona`가 얼굴을 먼저 정하고, 이름은 그 얼굴의 성별·세대 이름표(젊은 남 12, 젊은 여 12, 50대 남 10, 70대 여 10)에서 고르며 나이대(20대/50대/70대)를 붙인다. 운행 화면의 승객 이름 옆에 "· 70대"처럼 나이대를 쓴다 |
| 이야기 승객 | 이야기마다 맞는 얼굴만 쓴다: 막차 놓친 학생·첫 면접·속상한 하루 → 젊은 남녀, 회식 후 귀가 → 50대 남성·젊은 남성, 화분 선물 → 70대 여성·50대 남성 등. 학생 재회는 처음 태운 학생과 같은 사람(같은 얼굴·이름)이다. 이야기는 탑승 때 정해지므로, 픽업 가는 동안 보인 얼굴이 맞으면 그대로 두고, 이야기 고를 때도 이미 보인 얼굴에 맞는 이야기를 먼저 고른다(막차 학생은 예외로 우선 배정되며, 그때는 탑승 순간 얼굴이 젊은 얼굴로 바뀔 수 있다). 기사 수첩 손님 카드도 손님 유형에 맞는 얼굴을 쓴다 |
| 검사용 빌드 | 배포 폴더가 사용 중일 때(사용자 플레이·다른 검사) 쓰는 `PrototypeBuild.BuildHybridTrial`을 더했다. 출력은 `artifacts/hybrid-trial/`(Git 제외) |

- 배포 반영: 사용자가 게임을 닫은 뒤 소스 HEAD 864995e4(다른 세션의 방지턱 1af502bd·기획 HTML 864995e4 포함)에서 `PrototypeBuild.BuildHybrid`로 `builds/EungyeTaxi/`를 다시 만들었다. `distribution/EungyeTaxi-build-manifest.json`은 145파일, 크기·SHA256 대조 불일치 0이다(Python 대조). 배포 실행본 회귀: `-contentTest -speedLimitCheck` 32, `-brightUiCheck` 104, `-contentTest -passengerStoryCheck` 42, `-contentTest -bumpCheck` 12건 통과.

- 저장 주의: 이번 검사 중 플레이어 저장 폴더를 백업본(22:14)으로 복원하는 단계가 사용자 플레이 중에 돌았다. `-contentTest` 검사는 임시 폴더에 저장하므로 복원이 필요 없었다. 실행 중인 게임이 곧 저장을 다시 썼다(22:21 이후). 복원 뒤 22:20 시점의 `.bak`·보조 파일은 22:14 내용이다.
