# 2026-11-26 응급실을 지도 안으로 (은계 싱글)

## 요구 (사용자, 2026-11-26)

"응급실이 지도 밖이면 갈 수가 없잖아." 세 방법(지도 안 응급실 / 서쪽 출구 뒤 암전 / 지도 확장) 중 **지도 안 응급실**을 골랐다.

## 이전 상태

응급실은 실제 신천연합병원 응급실(대야동, 은계 지도 서쪽 밖 약 0.9km)이었다. 응급 손님은 지도 안에서 병원에 가장 가까운 정류장에 내려 주고, 남은 길과 빈 차 복귀는 암전으로 시간만 흘렀다. 지도·생활거점에는 "응급실 · 지도 밖", "○○ 방면" 표시와 "방면 ←" 길가 표지가 있었다(6차 피드백, c2bb45c7).

## 구현

| 내용 | 동작 |
|---|---|
| 위치 | 게임 전용 "은계 응급의료센터"(지도 524, 388). 은계 남부 "은계중앙로 남쪽 반대편"(게임 승하차 7 반대편) 정차 칸 바로 동쪽 건물 서쪽 면이다. 내리는 정차 칸에서 8m. 실제 의료시설이 아니며, 실제 가장 가까운 응급실(신천연합병원)은 근거 칸에 남겼다 |
| 자료 | `config/maps/eungye-care-points.json`과 Resources 사본의 `hospital`을 바꿨다. 필수 입력 manifest 대상 파일이 아니다 |
| 응급 손님 | 응급실 앞 정차 칸까지 직접 운전해 내려 주면 운행이 끝난다. 암전과 지도 밖 구간 시간·연료·피로 처리는 없다(`OutOfTownTrip.ArriveEmergency`). 응급실이 60m 안에 있으면 지도 안으로 본다(`EmergencyRules.InMap`). 운임은 탑승 구간 시간 기준(×1.3)이고, 지도 밖 구간 몫은 빠졌다 |
| 표시 | 지도 핀 "응급실"(병원 십자, 건물 위치). 설명: "게임 전용 응급실 · 앞 정차 칸에 내려 드림 · 실제 가장 가까운 응급실은 지도 서쪽 밖 신천연합병원". 생활거점 버튼 "응급실 · 은계 응급의료센터 + 거리". 길 안내 "은계 응급의료센터 · 앞 정차 칸". 호출 카드 "은계 응급의료센터 앞 정차 칸까지". 정차 칸과 건물 사이에 빨간 "+ 응급실 · 은계 응급의료센터" 표지 |

## 변경 파일

- `config/maps/eungye-care-points.json`, `unity/EungyeTaxi/Assets/Resources/eungye-care-points.json`
- `PassengerJobsCallBoard.cs`(EmergencyRules·카드 문구), `OutOfTownTrip.cs`(지도 안 도착), `LostItems.cs`(안내·표지), `MapDestinationUI.cs`(지도 핀), `ServiceStops.cs`(생활거점 버튼)
- 검사: `LostItemProbe.cs`(암전 없음, 시간 0초, 정차 칸 8m)

## 검증

검사용 빌드 `artifacts/er-trial`(r69, 6차 c2bb45c7 포함)로 했다.

| 검사 | 결과 |
|---|---|
| `-contentTest -lostCheck` | 24건 통과. 응급실 쪽 정차 칸 "은계중앙로 남쪽 반대편"(8m), 응급 운임 7,300원·기한 164초, 내려 주면 바로 "응급실 도착"(암전 없음, 영업 시간 0초 경과), 감사 카드 |
| `-contentTest -feedback6Check` | 13건 통과. 지도 핀 "은계 응급의료센터", 생활거점 줄 |

## 미검증 / 남은 것

- 응급실 표지·지도 핀은 캡처로 보지 않았다.
- 사람 플레이: 응급 손님 기한이 직접 운전에 맞는지, 위치가 자연스러운지.
- 배포: 사용자 지시("현재까지 마무리된 작업까지만")로 소스 5be9a52f(단속 카메라·6차·미션 띠 포함, 지도 r69)에서 `BuildHybrid`로 다시 만들었다. 진행 중이던 지도 r70 미커밋 변경은 빌드 동안만 잠시 치웠다가 그대로 되돌렸다. manifest 145파일 불일치 0, 지도 해시 b527c7c8…(r69). 배포 실행본 회귀: 제한속도 35, 6차 14, 분실물·응급 24, 방지턱 12, 미션 96, 화면 104건 통과. r70 지도는 다음 배포 묶음이다.
