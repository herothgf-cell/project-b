# 은계 r48 수인로 도색 재점검

## 범위와 근거

- Claude의 수인로 도색 커밋 `4c2b939`를 직전 r47과 대조했다. 두 버전은 원본 지도·주행 경로·신호·횡단보도 위치가 동일하고, 수인로의 도색 시설과 렌더러가 다르다. 비교 화면은 [r48 기록](2026-11-20-suinro-repaint-phase1.md)에 있다.
- [네이버 거리뷰](https://map.naver.com/p?c=18.00,0,0,0,adh&p=cz5FGgtmPfVryv7O6_HCRA,85,-20,80,Float)의 2026년 5월 최신 수인로 화면에서 보도 쪽 노면 경계와 본선 차선이 별도임을 확인했다. [카카오맵](https://map.kakao.com/)에서 은계센트럴타운을 찾아 최신 스카이뷰를 열고, 기존 동일 축척 항공 비교 중 J6478·J866·J7973을 다시 읽었다. 항공사진의 촬영 월과 노면 치수는 실측하지 않았다.

## 수정

- J6478 보행육교의 중앙 황색 빗금 안전지대가 r48에서 중앙선 재도색으로 지워졌다. r49에 노란 경계와 빗금 19개를 복원하고 양 끝을 기존 황색 복선에 연결했다. 실제 모양을 근사하되 현재 게임 주행 경로의 차량 폭을 기준으로 위치를 조정했다. 경계선과 빗금의 표시 유형을 구분해 빗금이 중앙선 침범 판정을 추가로 만들지 않는다.
- r48 렌더러가 황색 원본선을 처리할 때 기존 마스크를 검사하지 않는 분기를 발견했다. 현재 지도 데이터에서는 이 분기로 다시 나타난 황색선을 찾지 못했다. 수인로에만 횡방향 황색 원본선과 안전지대 외곽을 대체하고, 기존 마스크는 방향이 평행한 황색선을 계속 대체하도록 수정했다.
- 카카오 로드뷰에서 확인된 J866의 황색 원본 유도선 4개를 흰 점선으로 그리는 동작과 기존 흰 점선 유도선 처리는 유지했다. 별도 현장 근거가 없는 J10580의 흰 실선 유도선을 원본 방식으로 유지하도록 정정했다.
- J7973의 네 우회전 경로와 횡단보도, 원본 지도, 전체 신호와 차로 그래프를 r48과 비교해 동일함을 확인했다.
- 층별 점검 카메라는 숨김 창의 화면 버퍼를 읽을 때 검게 캡처됐다. 카메라가 직접 렌더링한 텍스처를 읽도록 검사용 코드를 바꿨다.

J866·J7973 접근부에는 기존 노란 도색 조각이 남아 있고 J10580의 고가·램프 겹침도 게임 화면에 보인다. J7973 동쪽 접근의 기존 NPC 유턴 검사 실패는 [r48 기록](2026-11-20-suinro-repaint-phase1.md)에 남아 있다. 수동 주행과 전체 캠페인은 이번 검증 범위 밖이다.

## 실행·재현

- Unity 2022.3.62f2에서 `SuinroRepaintReview.Apply`는 정확한 r48 지도에서 도색만 수정한다. `SuinroRepaintReview.VerifyAndBuild`는 J6478 택시 폭 여유, 노면 렌더, 39곳의 경로, 저장 이관과 통합 빌드를 검증한다.
- 실행 대상은 `builds/EungyeTaxi/EungyeTaxi.exe`다. `-singlePlayer -contentTest -dayLightDayProbe -mapAudit -mapAuditLayers "J6478_4105|J7973_3744|J866_5285|J10580_1415"`로 정사영 화면을 확인한다.
- 고정 카메라 결과는 로컬 `artifacts/suinro-r49/player-final/`에 기록했다.
