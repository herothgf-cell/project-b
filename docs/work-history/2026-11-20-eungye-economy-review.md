# 은계 싱글 r50 운임·생활물가 점검

요청은 현재 생활물가와 현실 택시 운임을 기준으로 게임의 경제 밸런스를 점검하는 것이었다. [비교표·손익·조정 우선순위](../content-design/04-life-vehicle-economy.md)에 2026년 11월 20일 열람한 시흥 중형택시 요율, 10월 경기 외식비, 은계 한 매장의 커피값, 11월 19일 경기 자동차부탄 가격과 제조사 도심연비를 연결했다.

## 확인한 구현과 플레이 결과

- 통합 배포본 은계 싱글 새 경력, 기본 20분 설정. 자동 운전기가 일반 교통에서 숙소 출발 → 첫 호출 승하차 → 숙소 복귀 → F 마감·저장을 진행했다. 자동 물리 주행 1회, 위치 제어 0회. 주행 중 세 번 읽은 테스트 저장의 `live.jobs.offers`에서 아래 제시액을 확인했다. 호출판은 갱신되므로 마감 저장에는 당시 세 판이 모두 보존되지 않는다.

| 관찰 시점 | 약정 탑승 거리(m) | 같은 순서의 제시액(원) |
|---|---|---|
| 출차·첫 호출 | 694.45 / 690.65 / 820.85 | 5,800 / 5,800 / 6,300 |
| 하차 후 | 1,023.05 / 1,023.26 / 1,340.81 | 7,100 / 7,100 / 8,400 |
| 숙소 복귀 중 | 619.44 / 669.15 / 704.09 | 5,500 / 5,700 / 5,900 |

- 선택한 호출은 `EG-GAME-04-B → EG-GAME-08-B`다. 제시 5,800원, 승차 운전 점수 100, 만족도 55/요구 60, 보너스 0원. 제시액 × 55/60을 10원 단위로 내리면 실제 지급 5,310원과 일치한다.
- 642.04 영업초, 총 2,587.97m, 운송 1회, 충돌·적신호 위반·급제동 각 0회. 저장의 거래는 운임 +5,310원, 주차 −500원, 월세 −1,500원, 정산 0원이다. 시작 현금 10,000원 → 마감 13,310원. 식사·주유 각 0회, 연료 60% → 48.74%. 실수령과 정산에 가상의 유류비를 추가하지 않았다.
- 같은 수입에서 식당 3,000원과 10단위 주유 400원을 결제했을 때의 당일 손익은 −90원이다. 시흥 기본요금 2건에 게임 고정비와 경기 백반값을 대입한 −1,241원도 모의 계산이다.
