# 원본 UI 컨셉과 현재 구현 비교

## 요청과 확인 범위

사용자가 첨부한 기존 컨셉 보드 11장의 반영 정도, 주행 UI의 유사성, 남은 디자인 작업을 확인했다. 첨부 그림은 시각 참고이며 그림 속 기능·금액·보상은 신규 구현 지시로 해석하지 않는다.

LATEST, 프로토타입 범위/체크리스트, 콘텐츠 기획05, 전체 UI 방향 문서와 CockpitUI/PassengerDialogueUI 코드를 대조했다. 실제 화면은 `docs/ui/2026-11-06-hud-dialogue-applied/05a-single-navigation.png`, `dialogue-single-1280.png`, 기존 정산 캡처 `docs/ui/2026-11-06-filled-icons-trip-flow/06-single-receipt.png`를 육안 확인했다. 새 실행 캡처가 아니라 이전 검증 때 보관한 화면이다. 시작 git status는 깨끗했다.

## 판단

현재는 가독성과 밝은 카드 테마의 일부 반영이며 원본 컨셉의 시각 완성 상태는 아니다. 직전 HUD 작업은 중간 승인 시안을 적용한 것으로 원본 컨셉 전체의 구현 완료와 구분한다.

| 대상 | 현재와 원본의 차이 |
|---|---|
| 공통 색/카드 | 남색 글자·흰 카드·파랑 안내·초록 행동은 반영. 원본의 입체 버튼, 테두리 하이라이트, 풍부한 그림자는 부족 |
| 주행 배치 | 현재 긴 흰 상단 바/좌측 안내 카드/좌하단 사각 속도계. 원본은 좌상단 작은 반투명 상태칩/상단 중앙 안내/하단 중앙 반원 속도계 |
| 승객 | 현재 작은 정적 상반신 초상과 중앙 하단 선택지. 원본은 큰 캐릭터·표정/포즈·말풍선과 좌하단 승객 정보 묶음 |
| 지도 | 밝은 지도·방향·경로는 존재. 원본처럼 지도 아래 목적지/시간/운임이 하나의 카드로 묶이지 않음 |
| 정산 | 실제 운임/평가 및 후속 행동은 표시. 원본의 큰 감사 포즈·축하 장식·여정 도식 등 감정적 연출은 부족 |
| 월드 | 회색 단순 건물/각진 택시는 원본의 풍부한 거리·수목·둥근 차량과 큰 차이. UI와 별도 아트 작업 |

## 남은 디자인 우선순위 제안 — 신규 구현 완료 항목 아님

1. 주행 HUD: 원본 상세 주행 그림을 기준으로 작은 짙은 반투명 상태 패널, 상단 중앙 안내, 하단 중앙 반원 속도계, 좌하단 승객 카드, 우상단 지도/운송 정보를 재구성하는 시안을 우선 검토한다. 포만감/피로/연료/청결/내구도, 점수, 기한, 신호 잔여초와 3구/4구·자료 출처는 보존한다. 현재 플랫폼의 실제 조작과 연결되지 않는 터치 페달은 그림만 따라 추가하지 않는다.
2. 공통 아트: 버튼/패널의 깊이감, 통일된 아이콘, 캐릭터의 표정과 포즈 세트. 기존 승객 다양성을 유지하고 시안 속 단일 인물로 모두 대체하지 않는다.
3. 승객 요청·상황 선택·정산: 큰 초상/상황 삽화, 읽기 순서, 답변/효과 구분, 감사/축하 연출. 긴 선택지는 현재 스크롤과 수치를 유지한다.
4. 지도·시설·설정·개인 공간·일일/PVP 결과의 동일 스타일 적용과 버튼 상태/전환 연출, 작은 화면·긴 문구·패드 포커스 검토.
5. 차량·도시 월드 아트: 모델/재질/조명/거리 소품/수목 등 별도 범위. UI 개선만으로 원본 배경 수준에 도달하지 않는다.

그림의 레벨업·차량 업그레이드·업적·일일 보상·즐겨찾기 등을 모두 확정 개발 잔여 항목으로 취급하지 않는다. 실제 현재 기획 범위와 별도 결정한다. 신호의 실제 현장 3구 배치 조사는 이전 작업과 마찬가지로 별도 후속이다.
