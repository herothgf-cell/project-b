# 일과 개인 생활의 최소 콘텐츠 기획

후속: 사용자가 이 작업을 중단했고 이후 반복 인물을 제외했다. 실직 후 재출발·차량/주거 성장으로 변경한 [후속 이력](2026-11-06-restarting-life-synopsis.md)과 [새 기획](../content-design/11-personal-life-and-growth.md)을 현재 방향으로 따른다. 아래는 당시 초안과 검토 기록이며 개발 승인/현행 기능이 아니다.

## 요구와 산출물

현재 구현을 활용해 택시 기사의 일과 개인 생활을 자연스럽게 연결하는 최소 콘텐츠를 구체적으로 기획하고 단순 반복/의무를 피하도록 요청받았다.

[검토용 기획안](../content-design/09-work-and-personal-life-proposal.md)은 친구1명·기존 안전 거점2곳·풍경 남기기/짧은 만남2장면·마감 개인 기록을 제안한다. 실제 이동과 활동시간을 영업 기회와 연결하고 사진/대화 선택을 다음 날에 기억한다. 일정 강제·관계 점수·회복 보상·일일 과제는 추가하지 않는다. 인물/취향·20/45초는 작성자 제안이며 신규 구현/수치 승인이 아니다.

## 현재 근거와 범위

- 시작 LATEST·scope·체크리스트·생활/캠페인/화면 기획과 `ServiceStops.cs`, `EconomyLedger.cs`, `BusinessProgress.cs`를 대조했다. 정상 마감 거점/수면·1200초 경계·깨어 있는 경과·개인 기록 저장을 구분했다.
- 최신 선택지 효과는 소스c116ce4에서 구현되었다. 앞선 전체 점검의 미구현 설명은 당시 상태다. 동시 배포 작업의 최종v9 BuildHybrid/manifest/Strict 완료 기록은 해당 이력에 있으며 이번 기획 작업의 실행 결과가 아니다.
- 시작 시 실행폴더8파일/FirstDrive 씬 수정과 기존 미추적 자료가 있었다. 이후 다른 작업의 manifest·공유 이력/체크리스트 변경도 관찰했다. 이번은 문서만 선택하며 해당 소스/빌드/설정·저장/지도·원본 마인드맵을 건드리지 않는다.

## 검증과 남은 항목

브레인스토밍 스킬에 따른 별도 검토자에게 구현 계획을 막는 질문/모순·반복/의무 위험을 검토 요청했다. 검토 결과와 최종 링크/diff 검사는 아래에 기록한다.

- 검토자 지적3건을 반영했다. 대화 결과를 읽고 취소해 무료로 반복하는 경로는 시간 먼저 확정/주제 나중 선택으로 닫았다. 늦은 사진 공유는 별도 멱등 사건과 정산별 고정 후속/정산 후 기록 답변으로 구분했다. 활동 중 피로100·연료0·1200초 경계 위험은 전체 구간 사전 예측/차단으로 정하고 부분 청구는 만들지 않았다.
- 회차별 개인 기록 보존이 새로운 저장 필드/완료 회차 UI 연결을 필요로 한다는 검토도 반영해, 단순 대사 추가 이상의 개발임을 명시했다. 위치2곳은 이미 알려진 현장 검증 선행조건이다.

새 Unity 빌드·모델/Player 검사·위치 제어·자동 물리 주행·수동 플레이·전체3일·다른PC 수용은 수행하지 않았다. 필수 로컬 입력/ZIP은 미변경이며 최신 다른 작업의 Strict 정상 기록을 인용한다. 이번 Strict/manifest 재실행은 없다.

다음은 기획 방향 수용, 기존 장소2곳의 실제 서비스 ID/진입·점유·경관 검증, 구현 계획이다. 보상 없이도 자발적으로 방문할 만큼 매력적인지는 사람 플레이로 확인해야 한다.
