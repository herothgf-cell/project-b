# 은계 도로 표시·주유 시설·운송 마감

기준일: 2026-10-21. 기본 실행은 은계이며 별도 연습 맵으로 대체하지 않는다. 소스/실행파일은 main으로 배포한다. 실제 소스 커밋은 `distribution/EungyeTaxi-build-manifest.json`의 `sourceCommit`을 따른다.

## 요구와 구현

- 흰 박스는 원본 건물 도형을 높이3m로 돌출한 형상이 생성 주행 차로와 겹친 사례다. 스크린샷만으로 객체 ID를 확정하지 않고 동일 유형을 실제 맵/공통 차로와 대조했다. 추가3개 `37612022:B0010000:1`, `37612022:B0010000:158`, `37612023:B0010000:4537`를 표시·충돌·도로면 조회에서 함께 제외한다. 곡선 구간 `:158`은 약(324.6,1488.5). 기존22개 제외와 합쳐25개 보류,3362개 건물 유지. 원본 파일은 삭제하지 않는다.
- 로컬 표시를 내비/H/일반 차량의 컴파일 차로와 맞춘다. 반대 방향 사이 황색 중앙선·동일 방향 사이 백색 점선, 일방통행에 황색 중앙선 없음. 짧은 원본 조각마다 점선 주기가 초기화되던 문제를 연속 차로 기준으로 수정한다. 교차로 내부의 중첩 중앙선/경계선을 잘라내며 수입 정밀지도 표시는 유지한다. 자료 없는 실제 차로수·규제는 여전히 임시다.
- 영업은3일×720초(12분),순수익30,000원. 운송 기한은 `max(120, ceil(거리/4+90+상황대기))`초로 완화하고 약정 운임은 유지한다. 승객 탑승 중 N 마감 금지. 날짜 시계0은 신규 호출을 막고 목적지 하차까지 정산 대기한다. 운송 기한 초과도 승객/내비를 유지해 목적지 하차 때0원·실패1회만 기록한다.
- 새 캠페인 연료60%,실주행4%포인트/km+경과0.1%포인트/분. 기존12.5/km+0.5/분에서 완화한다. 기존 저장의 현금·남은 연료·ID·기록은 유지하고 새 시간/소모율을 적용한다. 탑승 중 고갈은 현재 위치에서20% 공급·1,800원·30초를 적용하고 같은 운송/기한을 유지한다. 빈차/미탑승 고갈은 기존 출발지 복귀 정책이다.
- 화면 명칭은 ‘운전 점수’. 내부 Law 장부/규칙 식별자는 유지하고 승객 매너·요금과 분리한다. 보험·세금은 계속 프로토 제외한다.

## 주유소 위치와 사용

모두 **실제 시설 위치를 확인한 주유소가 아닌 빈 부지의 게임시설**이다. 북부·남부·동부 각1곳, 별도 진입/진출로·캐노피·주유기·주유 정차선·방향 화살표를 추가한다. 원본 건물/수면과 부지 간격을 검사하며 기존 건물을 지워 부지를 만들지 않는다.

| 시설/지도 번호 | 도로 접근 차로 | 배치 기준(월드x,z,대략) |
|---|---|---|
| 은계북부/1 | `local:5978:17124:10508:15987`, at196 | 도로 중심(773.27,1671.98) 우측 부지 |
| 은계남부/2 | `local:5204:826:7659:817`, at42 | 도로 중심(562.44,82.45) 우측 부지 |
| 은계동부/3 | `local:8265:6305:9056:10851`, at434 | 도로 중심(1158.74,805.14) 우측 부지 |

F7에서 선택 → 공통 내비/H가 **도로 입구 앞까지** 안내 → H 해제 후 화살표를 따라 수동 진입 → 주유 구역에서 같은 방향으로 정차 → F7 비용 확인/확정 → 별도 출구에서 도로 차량에 양보. H는 부지 내부를 자동 운전하지 않는다. 도로변·입구·반대 방향·구역 밖은 결제 불가다. 미니맵의 노란1·2·3, G 전체지도 이름표/목록으로 찾는다.

3곳당 노면3개,총9개만 추가하고 HD공유 차로 그래프1765개/기존 건물3387개는 바꾸지 않는다. 원본 지도3개와 전달 ZIP 해시는 변경하지 않는다.

- 실제 은계 차로수·신호·시설 전수 현장 대조는 미완료. 이번 차선 수정은 공통 게임 차로와 표시 일치이며 실측 확정이 아니다.
