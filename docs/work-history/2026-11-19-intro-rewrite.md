# 첫 실행 인트로 개정과 구현 점검 후속

## 요구

- Codex 구현(P1~P7, 실내 차고·첫 호출) 점검과 "시작할 때 이야기가 어색하다"는 사용자 피드백. 사용자가 직접 수정을 요청했다.

## 점검 결과(요약)

- P1~P7은 기획 28~34대로 구현되어 있고, 원격 `4616f7f` 실행본으로 이야기 흐름 Player 23+7검사를 다시 통과했다.
- 어색함의 원인: 인트로가 시안을 잘라 만든 400×225 임시 그림 3장을 흰 카드에 확대해 띄움(흐림), 컷1 문장(회사)과 그림(숙소 방) 불일치, 마지막 컷(도로 주행)과 실제 출발 장소(실내 차고) 불일치, 첫날 불안과 맞지 않는 "오늘부터, 내 핸들로." 대사.
- 문구 불일치: 메뉴 설명 "3일 영업", 3일차 정산 버튼 "계속하기", 도움말 "N 퇴근"(화면 안내는 F), 4일차 미터기 자동 보조 종료 안내 없음.

## 구현

- `IntroCutscene.cs` 재작성: 4컷 25초(6·6·7·6초). 전체 화면 2.39:1 화면 + 위아래 검은 띠, 컷마다 페이드, 자막은 아래 띠에 한 글자씩. 클릭 = 다음 컷, Esc = 전체 건너뛰기, `n / 4` 표시.
  1. 검은 화면 "3월 첫째 주" — "다니던 회사가 문을 닫았다."
  2. 숙소 원룸 그림 + 월세 안내 쪽지 — "모아 둔 돈으로는 몇 달 못 버틴다."
  3. 실내 차고의 아버지 택시를 실시간 렌더(카메라 접근) — "아버지가 30년 몰던 택시. 남은 건 이 차 하나다."
  4. 운전석 실시간 렌더(사진 액자 → 앞유리) — "일단, 오늘 하루만 나가 보자."
- `DrivingCamera.RenderIntroShot`: 별도 카메라로 차고·운전석 장면을 RenderTexture에 그려 HUD를 가린 채 표시.
- `BusinessProgress`: 첫 인트로 전에 택시를 숙소 차고 칸에 배치. 첫 인트로 종료 시 운전석을 `<저장 이름>-first-drive.png`로 저장하고 목표 달성 비교 화면의 "첫날 운전석"으로 사용(이전 경력은 "기록 없음" 표시). 4일차 출발 시 "오늘부터 미터기는 직접 켭니다" 안내.
- 문구: 메뉴 "아버지의 택시로 다시 시작 · 3일 뒤에도 계속 영업", 3일차 버튼 "4일차 영업 준비"(이후 일차 번호 자동), 도움말 "F 또는 N 퇴근 (숙소 주차 칸에 정차 후)".
- 임시 그림 `Resources/UI/intro-office|intro-taxi|intro-first-drive.png` 삭제.
- 기획 [33 §4](../content-design/33-backstory-presentation.md) 개정, 실제 캡처 `images/intro-v2-cut-1~4.png`.
