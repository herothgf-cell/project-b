# 기획 미정·미구현·검증 잔여 구분

후속 정정: 사용자의 마인드맵 포함 요청에 따라 [전체 말단 대조·날씨 목록](../future-design/2026-11-07-planning-gaps-and-weather.md)을 추가했다. 날씨/야간은 상세 기획·구현이 없는 기존 아이디어다. 아래의 ‘기상 대기’는 잠든 승객 깨우기를 뜻한다. 직전 조사에서 진행 중이던 승객 다양화1차도 이후309e49e 출하 이력으로 완료됐으며 최신 상태는 [후속 기록](2026-11-07-mindmap-weather-review.md)을 따른다.

## 검토 기준

사용자가 현재 기획 미정/남은 사항의 정리를 요청했다. `AGENTS.md`, `LATEST.md`, 콘텐츠 기획 목록·10~17·요청 판정표·개발 체크리스트와 최근 승객 개별 설정 구현 이력을 읽었다. 시작 HEAD는 `780d1a5`이며 `git status --short`에서 승객 다양화/편집기/기본 프로필·관련 테스트의 별도 미커밋 변경을 확인했다. 해당 변경과 기존 미추적 자료를 수정/정리/커밋하지 않는다.

이번은 현황 조사다. 새 제품 규칙·우선순위·미채택 기능을 승인하거나 게임 코드/밸런스를 변경하지 않는다. 다음 목록에서 현재3일 프로토의 잔여와 장기 성장 제안을 분리한다.

가격 비율과12~18회 영업은 검증 전 장기 가설이며 출시 기간 확정값이 아니다. 현재 방2종 시험 가격과 혼동하지 않는다. Quiet 등 모든 요청에 실패를 추가하는 것이 확정된 것도 아니다. 응답 완료형과 실제 운행 약속형을 구분해 검토해야 한다.

## 기획은 있으나 아직 미구현인 항목

- 작은 방: 처음/완료 방 직접 비교, 전체 과거 회차 방 탐색, 다음 날 찜/구매 상품 카드·상품 이미지·카드 숨김. 현재 방/구매/저장·최신 이전 회차 읽기 전용은 이미 구현이다. [13 상태표](../content-design/13-three-day-room-and-first-purchase.md).
- 장기 성장: 연속 영업, 차량 구매/꾸미기, 아파트 이사·후보 시승/새 집 미리보기, 날짜별 수요3구성/짧은 비교 회고. 미채택 확장 제안이며 현재3일 필수 잔여로 자동 편입하지 않는다. [11](../content-design/11-personal-life-and-growth.md)·[12](../content-design/12-career-growth-stages.md).
- 추가 서사:3컷 인트로·장기 이야기 진행은 후속 후보, 반복 인물 중심의09 초안은 현재 방향으로 채택하지 않는다. [10](../content-design/10-restarting-driver-synopsis.md).
- 승객 확장: 초상 편집·새 소지품/실제 장치/행동 진행기 등은15의 후속 후보이며 현재 프리셋 생성·특성 조합·승객별 대사/확률/효과 덮어쓰기와 구분한다.

## 구현 후 검증·유지보수 잔여

- 사람의 실제 운행에서 특수승객·적재/하역·경유·기상 대기·도착/F안내를 연속 확인하고,3일 동안 운송/식사/휴식/주유/청결/사고 복귀와 개인 소비의 이해도를 확인한다. 가격/수익의 체감 판단은 사용자 플레이와 구분해 남긴다.
- HUD/대화창·신호/도로 표시의 해상도/DPI별 장시간 가독성, 맵/차량 외형의 후속 검토. 실제3구/비보호 접근 추가는 읽을 수 있는 현장 근거를 먼저 확보한다.
- 다른PC LAN·장시간/지연·손실·전체 운송, 일반 차량 대기열/반복 정체·성능을 확인한다. 같은PC 두 Player/짧은 자동 검사는 이를 대신하지 않는다.
- 기존 검사4건은 최신 승객 설정 작업에서 baseline 실패로 구분됐다. PassengerBehavior/PassengerSituation2건, ChoiceStructureAudit 미응답 기대값, ManualHandlingTests 제동 기대값의 의도/실제 동작을 대조해야 한다. 기획 미정과 별도의 유지보수다. [실제 실패 기록](2026-11-07-passenger-overrides.md).

체크리스트의 예전 미완료 항목 중 방 구매·사고/공업사·대체 승하차·LAN은 후속 구현 이력으로 대체된 부분이 있다. 체크되지 않은 모든 행을 현재 미구현으로 합산하지 않았다. 이번 조사에서 체크를 일괄 수정하지 않는다.

## 직전 조사 시 진행 중이던 항목 — 이후 완료

현재 작업 폴더에는 신규 승객12명을 더한 다양화1차의 문서/설정/테스트 변경이 있다. 로컬 `docs/content-design/17-passenger-roster-v1.md` 구성표는 현재 미커밋 작업 자료이며 최신 출하 완료와 구분한다. 최신 완료 이력은 승객 프리셋/개별 덮어쓰기 구현·LANv13·실행본 `780d1a5`다. 다양화 작업의 최종 검증/빌드는 해당 작업 이력에서 확인해야 한다.

## 현재 프로토에 추가하지 않는 것

예약·단골·보험·세금·과실/구급차와 실제 음악/에어컨/창문 조작은 제외/보류다. 단순히 후속 표에 있다는 이유로 현재 필수 개발에 넣지 않는다. 야간/비·눈·전국 맵 확대 등도 별도 범위 결정이 필요하다.

## 이번 수행/미수행·재개

- 실제 수행: git 상태/최근 커밋 조회, 최신 기획/체크리스트/구현 이력 읽기·상태 구분. 문서 상대 링크15개 존재 검사 누락0, diff 공백 검사 exit0.
- 미수행: Unity 빌드·위치 제어/물리 주행·수동 플레이·전체3일·다른PC, Strict/배포 manifest 재검증. 이전 검증을 이번 새 검사로 주장하지 않는다.
- 게임/지도/ZIP/프리셋/사용자 저장 변경 없음. 기본 은계 싱글/A2 통합exe·BuildHybrid와 직전 Strict issues0 기록을 유지한다. 미커밋 승객 다양화는 별도 작업 그대로 보존한다.
- 다음 결정은 현재 프로토의 실제 운송 수용과 작은 방 잔여를 먼저 볼지, 장기 성장 기획을 구체화할지 사용자 범위에 따라 정한다.
