# 승객 코스·요청·운행 피드백

기준일: 2026-10-21. 기본 맵 은계, 실행 대상 builds/EungyeTaxi/EungyeTaxi.exe.

## 사용자 결정

승객 요구 확장과 문서09의 9개 코스를 기본 영업에 반영한다. 상단 연료/점수 알림, 지도 키·필터, 복귀 단축키 제거, 창 제목, 일반 차량 확대와 신호 남은 시간, 승차 대기 기한을 추가한다. 개별 기획 문서를 함께 갱신한다. 운행 점수는 날짜 변경·재실행에도 유지하고 **새 캠페인에서는 초기화**한다.

## 구현

- 공유 차로/내비를 쓰는 PS01~09 일반 운송 코스. PS01/02는 승차 전, 나머지는 탑승 후 통과한다. 선택 자체가 아니라 실제 주행 관찰로 판정한다. 호출 카드의 경유 상황 설명은 제거하고 운송/지도 안내는 유지한다.
- 승객 요청17종(기존2 + 운전5/대화6/사건4), 한 운송당 하나. 안전 정차에서 응답, 위험/교차로에서는 보류. 목적지/경유 변경은 현재 위치의 실제 공유 경로 거리 차이와 새 운임/시간을 확인 후 적용한다. 음악/분실물은 문서04의 텍스트 수준이며 실제 오디오·인벤토리는 없다.
- 누적 운행 점수 0~100. 사건당 최대 위반 감점, 위반 없는 유효 준수 사건당1점 회복. 보류·기회 없음·선택만으로는 가점 없음. 날짜 변경에 유지하고 새 캠페인만 초기화. 승객 매너/운임과 독립.
- 점수 사건 변경은 캠페인ID별 저널에 저장. 기존 하루 정산 회계 저장과 시점이 다르며 미정산 회계의 이어하기 기능을 확대하지 않는다. 창 제목은 택시 시뮬레이터, 기존 저장폴더는 유지한다.
- 상단 연료15% 이하 주유기 아이콘·잔량,5% 이하 적색. 점수 변화 알림은 잠깐 나타났다 사라진다. 승객 교체의100점은 보상 대신 초기화로 설명한다.
- M 전체지도, +/- 미니맵6단계, 클릭 확대/축소. 시설/교통/법규 필터, 승차/도착/현재위치/경로는 계속 표시한다. R/패드 복귀 단축키 제거, 안전 자동복귀 유지.
- 일반 차량24→36대, 실제 신호 주기 기반 남은 시간. 시나리오 유지 신호는 고정 초 대신 조건 안내. 간략한 게임 표지는 도로·건물·지도경계 검사 후 충돌체 없이 배치하며 현장 확인시설로 표시하지 않는다.
