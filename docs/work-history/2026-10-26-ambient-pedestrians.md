# 2026-10-26 일반 보행자 구현·통합

## 승인과 범위
사용자가 이전 턴의 [A안](../design-history/content-design/2026-10-27-before-planning-only/16-ambient-pedestrians-proposal.md)에 “구현 진행해줘”로 승인했다. 후보 J5057/J5076/T1/T2, 보도8명+횡단4명 최대12명(상황 보행자 포함), 실제 안전 경로가 없는 슬롯은 비우는 기준이다. 보행자와 승객은 외형·데이터·탑승 입력·지도 핀을 분리한다.

이번 작업도 사용자 지시에 따라 구현 변경의 필수 검사만 수행한다. 전수 모델·전체 캠페인·장시간 반복 검사는 실행하지 않는다. 시작 기준 main6fb97e8, 분리 작업 공간 codex/ambient-pedestrians. 기존 사용자 미추적 파일을 보존한다.

## 구현 기준과 판단
횡단 진입은 보행 녹색·잔여2초 초과·차량 비점유일 때만 허용하고, 진입 후 적색으로 바뀌어도 보도 도착까지 점유를 유지한다. NPC는 경로가 겹치는 횡단에 양보하며 이미 정지선을 지난 경우도 확인한다. 기존 H 기능은 차로 조향 보조이므로 수동/H 가감속은 계속 운전자 소유로 둔다. 이 판단과 다른 자동 제동을 원한다면 별도 운전 제어 정책 조정이 필요하다.

## 실행·재현·보존
기본 실행은 `builds/EungyeTaxi/EungyeTaxi.exe`. J5076(x507.6,z258.0) 주변 보도/횡단, J5057(x505.7,z444.9) 횡단, T2(x619.9,z1198.7) 보도/횡단에서 볼 수 있다. 적색에는 보도 끝에서 기다리므로 늘 횡단 중인 것은 아니다. T1은 안전 경로 부족으로 비워 두었다.

검사 재현은 필요할 때만 같은 exe에 `-ambientPedestrianTest` 후 별도 프로세스 `-ambientPedestrianReloadTest`. 캡처만 필요하면 `-ambientPedestrianTest -ambientCaptureOnly`. 모두 사용자 캠페인과 별개 artifacts 경로를 사용한다. 실행 로그·PNG·격리 checkpoint·검토 보고서는 기본 저장소 `artifacts/2026-10-26-ambient-pedestrians/`에 보존한다.

## 내린 판단
- NPC 자동 양보와 택시 관찰·접촉을 연결하되 수동/H 가감속은 운전자 소유를 유지했다. H는 기존에 조향만 담당하며 자동 제동까지 원하면 별도 제어 정책 변경이 필요하다.
- 안전 재등장을 기다리는 숨긴 행인은 신규 횡단도 시작하지 못하게 했다. 잘못 보수적으로 판단했을 때의 비용은 행인이 더 오래 기다리는 것이며, 보이지 않는 상태로 차도에 진입시키지 않는다.
