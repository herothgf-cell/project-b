# P5 하루 조건 카드

기획29와 하루 조건 카드 시안에 따라 은계 경력의 준비·영업·정산에 당일 조건을 연결했다. P4 배포 e2c8bfb를 기준으로 작업했다.

- 평일·비 오는 날·상가 행사·금요일·도로 공사는 경력 시드별로 섞인 5장 순환을 따른다. 한 경력의 연속 5일에 같은 카드가 다시 나오지 않는다. 캠페인 형식 7에 순환 시작일과 오늘의 카드, 정산마다 카드 식별자를 저장한다. 이전 저장이 영업 중이거나 정산에 도착한 경우 그날의 운송과 날씨를 이어가고 다음 날부터 새 카드가 시작된다.
- 비 ×1.3(전 지역 및 빈 호출 목록 갱신), 상가 행사 ×2(저녁 상가 출발), 금요일 ×2(저녁·초과 상가 출발 및 주거 도착)를 기존 수요 위에 적용한다. 운임은 기존 규칙을 사용한다. 상가 행사의 저녁 교통은 기본 상업 도착 비중 ×1.5로, 교통차 전체 수를 유지한다.
- 비 카드의 게임 시각 12시부터 기존 비·와이퍼·차량 제동과 탑승 청결 -2를 적용한다. 기존 청결 설정으로 조절할 수 있다. 비의 우산, 상가 행사의 짐·음식, 금요일의 음주·수면, 공사의 시간에 급한 손님은 선택 가중치를 높인다. 기존 안전 조건·일일 음주 상한을 유지한다.
- 계수로 현대오일뱅크 앞 48번 Y08 서행 바깥 차로의 기존 구간만 공사 카드에 통제한다. 차로 `local:11589:16123:10729:15920:part:1`, 대략 1149.3/1609.5 → 1119.0/1600.6이다. 옆 차로와 기존 합류 경로를 사용한다. 런타임 내비·보조 조향·교통 경로와 지도 표시에만 적용한다.
- 준비 카드에 실제 수요 지도와 단서를 표시하고 영업 상단에 카드 배지를 배치했다. 정산에는 실제 운송 수·세차비, 자료가 있는 경우 이전 평일 운송 평균을 표시한다.
- 비 카드를 마감하면 아버지 수첩 p.2, 첫 금요일에 출발하면 p.3을 연다. 동네 별에 의한 p.2 해금은 P6 인터페이스를 이어 쓴다.
- 콘텐츠 관리의 생활 → 하루 조건에서 카드 문구, 수요·승객·교통 배수와 비 시작 시각을 편집한다. 싱글용 프로필 키는 LAN에서 제외한다.

주요 변경은 DailyConditions·DailyConditionHUD·BusinessProgress·EconomyLedger, PassengerDemandPolicy·PassengerJobs·PassengerBehavior·VehicleCare, RainPolicy·설정, DailyRoadConstruction·HdRoadGraph·RoadNavigation·DistrictTraffic과 지도/정산 UI다.
