# 2026-11-17 은계 차로 전환과 분리시설

색칠한 58개 구간을 r42 게임 지도와 대조했다. 차로 수가 달라지는 구간은 해당 방향의 실제 경로와 노면을 함께 맞추고, 중앙과 보도에 있는 시설은 형태와 개구부를 대조했다. 출처와 시설별 게임 좌표는 `config/maps/eungye-road-facilities.json`에, 남은 항목은 [색상 구간 점검표](../content-design/road-survey/2026-11-17-transitions-and-facilities.md)에 기록했다.

## 사용자 확인

[55–62번 전체 지도](../content-design/images/eungye-r43-transition-facility-questions.png). 지도 점은 질문용 근사 위치이며, 시설 배치는 주변 거리뷰의 횡단보도와 차로 선형을 기준으로 삼았다.

| 번호 | 확인 내용 |
|---|---|
|55|은계남로 동행에서 횡단보도를 지난 뒤 차로 배분이 바뀐다. 거리뷰 `(230,90)`와 `(250,90)` 사이의 고원 횡단을 대조했다.|
|56|은계중앙로 남행은 버스정류장부터 좌회전 차로가 시작하고 중간 신호가 하나 더 있다. 최신 촬영의 차로, 상가 진입부와 횡단을 대조했다.|
|57|OUT 표지 다음 횡단보도를 지나서도 북서행 바깥 차로는 직진할 수 있다.|
|58|네이처포레 정문 전 동2/서2, 횡단 뒤 동1/서3, 이후 동2/서1이다.|
|59|수인로 금속 난간은 교량 본선의 중앙분리대처럼 이어진다.|
|60|에머랄드빌딩 앞 북동행 정지선에는 2차로가 있다.|
|61|계수교차로 북동행이 3→4→5→6차로로 늘어난다. 정지선은 좌 / 좌 / 직 / 직 / 직 / 우다. 게임 북쪽 경계 `z=1750` 밖 교차로의 진출 도로가 성립할 때 연결한다.|
|62|계수로 고가 아래 적백 플라스틱 임시 방호벽은 현재도 있다.|

## 구현 기준

- `ConfirmedCorridorsR43*.cs`는 대조한 구간과 새 접근부를 만들고, 도색에 쓰이는 방향과 내비에서 쓸 수 있는 연결을 함께 검증한다. `ReviewedMidblockControl.cs`는 기존 시설 배열의 신호 교차로 표식을 사용해 별도 지도 스키마 변경 없이 신호를 구성한다.
- `ReviewedRoadFacilities.cs`가 기존 W빔·검정 황띠 난간·주황 탄성봉과 함께 적백 임시 방호벽과 어두운 보도 난간을 그린다. 여러 개의 짧은 폴리라인으로 나눠 시설 종류가 바뀌는 곳과 차로 접속, 횡단보도에 공간을 둔다. 치수는 게임 근사다.
- 은계남로 서행 출입로가 추가되면서 기존 `EG-GAME-12` 정차 위치가 출입구 이후 차로에 속한다. `PassengerStopCatalog.cs`는 원래 지정된 정차 위치·방향·ID를 유지하며, 해당 분기가 있는 지도에서만 차로 참조를 옮긴다.

## 지도 확인과 남은 범위

- 은계남로 55번은 거리뷰 고원 횡단 위치를 기준으로 동행 차로 전환을 시작한다. 기존 횡단 시설에는 손대지 않았다. 56번 추가 신호의 주기는 게임 조정값이다. 네이처포레의 차로 전환 구간 길이는 확인 사진으로 추정했다.
- 59번 수인로 본선은 차로 안전 여유가 확인된 두 구간에 금속 W빔을 넣었다. 게임 지도에서 램프 쪽 차로가 벌어지는 사이 구간은 여유 거리 때문에 비워 두었다. 62번 적백 방호벽도 거리뷰에서 확인한 고가 아래 부분을 배치했다. 시설이 바뀌는 지점의 정확한 끝 좌표는 현장 확인이 필요하다.
- 60번 에메랄드빌딩 앞 정지선 두 차로는 기존 지도와 일치한다. 상류의 세 차로가 줄어드는 시작점은 확인이 남았다. 61번 정지선 여섯 차로는 지도 북쪽 경계 밖 실제 교차로다.

## 검증 및 실행

- Unity 배치 메서드 `ConfirmedCorridorsR43.Preview`에서 네이처포레 세 단면, 55번 동행 차로 전환, 56번 좌회전 신호, 노면 방향과 이전 r42 승하차 39곳의 1,482개 경로를 확인했다. 새 시설 31곳(난간·방호벽 739개 모듈 및 분리봉 138개)에 대해 횡단 공간과 택시 외곽 8,287개 위치를 검사했다. 차량 위치 제어 충돌 검사이며, 플레이 동안의 물리 주행과는 구분한다.
- `ConfirmedCorridorsR43.Preview`와 `ConfirmedCorridorsR43.Apply` 모두 종료 0. 이전 44–47·49–54번 회귀를 통과했고, 저장 전후 검증 결과가 일치했다. 작성 지도 r43 내용 지문은 `e0f8ce711e8c1b5dcd814d0bea2c9f7f454d63baa28be4b3d8cf86df37b4d6bb`이며 원본 지도 지문은 보존했다.
- `config/maps/local-input-manifest.json`의 작성 지도와 도로시설 크기·SHA256을 갱신했다. `pwsh -File tools/check_workspace.ps1 -Strict` 종료 0, 필수 입력 문제 0. 원본 재수입용 선택 JSON 2개는 로컬에 없다.
