# Proto 후속 확장 기획 정리

## 요청·실제 변경

사용자가 P11 승객 요청 다양화 → 지역별 수요/공차 수익성 → 승하차 공간 점유 순서를 선택하고 기획 문서 반영을 요청했다. 마인드맵은 직접 검토 후 수정 여부를 알리므로 **원본은 변경하지 않는다**.

- `docs/content-design/17-proto-operation-expansion.md` 신설: 기존 기반/신규 개발 차이, 단계별 최소 범위·예외·저장·완료 조건, 검토가 필요한 수치·정책, 마인드맵 가지별 변경안.
- `docs/content-design/README.md`, `00-RoadMap.md`, `14-passenger-stop-variety.md`: 문서 연결 및 지역 수요의 선택적 제안→선택된 후속 계획 구분. 구현 완료로 표시하지 않음.
- `docs/prototype-scope.md`, `docs/prototype-development-checklist.md`: 기존 Proto 잔여 P11/안정화/수동 검증과 P12/P13 확장 마감 분리. 완료된 P9-08을 남은 신규 구현 요약에서 제외하되 기존 완료 근거는 유지.
- `docs/work-history/LATEST.md`: 최신 문서 작업과 다음 순서 연결.

## 검증·남은 항목

변경 문서8개의 상대 파일 링크189개 확인, 누락0·종료0(절 앵커 검사는 제외). `git diff --check` 종료0. `.mmst` SHA256 전후 모두 `f1951492f9c5a13941e60a17d92eb31b1a7471fb8aba7996d47a0c2e02f00937`로 일치한다. 기존 사용자 변경과 untracked 파일은 보존한다.

게임 코드·지도·빌드·배포 manifest·입력 ZIP은 변경하지 않았다. 문서만 변경하므로 Unity 빌드/게임 회귀 검사는 실행하지 않는다. P11/P12/P13 구현은 이번 작업에 포함하지 않는다. P12 시간대/가중치 및 P13 점유 시간·대안 위치·기한/평가 보정 세부는 후속 검토 대상이다. 마인드맵 변경안은17의 마지막 절에서 확인하고 사용자 승인 뒤에만 원본에 반영한다.

기본 빌드/지역은 은계 `builds/EungyeTaxi/EungyeTaxi.exe`, 기존 배포52108d0 유지. 필수 로컬 입력은 직전 Strict0·선택 입력2개 부재 상태이며 이번 작업에서 다시 검사하지 않았다. Proto 상태는 핵심 플레이 가능, 기존 신규 개발/안정화/수동 전체 캠페인 검증 미완료다.
