# 싱글 시작 선택과 일시정지 메뉴

모드 선택에서 싱글 설명을 ‘마을에서 택시 운용’으로 바꿨다. 싱글을 누르면 ‘처음부터 하기’와 ‘불러오기’가 열린다. ‘처음부터 하기’는 기존 저장이 있을 때 별도 파일을 사용한다. ‘불러오기’에는 마지막 저장이 최근인 순서로 경력을 표시한다. 기존 기본 슬롯과 백업만 남은 슬롯도 목록에 포함한다.

일시정지에서 운전 연습 선택·처음 이야기 다시 보기 버튼을 제거했다. ‘불러오기’에서 현재 경력을 선택하면 디스크의 체크포인트로 돌아간다. 다른 경력으로 이동할 때는 현재 진행을 먼저 저장한다. ‘처음부터 다시하기’는 기존 확인 창을 거쳐 별도 슬롯에서 시작한다.

타이틀 전환은 UnifiedModeBootstrap과 CasualMenuUI, 일시정지는 DriveHUD와 OneDayHUD, 저장 선택·복원은 CampaignSaveLocation과 BusinessProgress를 변경했다. UnifiedModeProbe에 타이틀의 슬롯 선택, 두 번째 새 경력 생성과 첫 번째 저장 파일 보존 검사를 추가했다.

## 재현

은계 통합 실행본에서 싱글 → 처음부터 하기 → 영업 시작 후 모드 선택으로 돌아온다. 싱글 → 불러오기 → 방금 저장한 시각을 선택해 영업을 계속한다. 자동 검사는 실행본에 `-batchmode -nographics -unifiedModeCheck`를 전달하며 별도의 임시 경력을 사용한다.

## 검증 결과

은계 r49 필수 지도 입력 검사 문제 0건. PrototypeBuild.BuildHybrid 종료 0. 통합 Player 검사 67 항목 통과, UNIFIED_MODE_RESULT PASS, 종료 0. 운행 중인 경력의 ID와 일시정지 복원, 재개, 새 경력을 만든 뒤 원본 바이트 보존, 손상된 파일 쓰기 거부를 확인했다. 운전 입력과 마우스 클릭을 대신해 메뉴가 호출하는 동작을 실행했다. 팝업의 실제 화면 배치는 수동 검증하지 않았다.
