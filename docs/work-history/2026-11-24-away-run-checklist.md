# 2026-11-24 자리 비움 일괄 작업(2차) · 돌아와서 직접 확인할 체크리스트

[08 재미 보강](../content-design/08-fun-improvements.md)을 기준으로 질문 없이 진행했다. 범위는 은계 싱글이고, PvP 규칙과 공유 주행 물리는 바꾸지 않았다. **자동 검사 통과는 체감 확인이 아니다.** 아래 항목은 모두 직접 플레이로 확인해야 한다.

| 단계 | 내용 | 기록 |
|---|---|---|
| 0 | 선택형 미션 4종 상태 확인: 이미 완료, 추가 작업 없음 | [기록](2026-11-24-mission-status-check.md) |
| 1 | 추가 주행음(엔진 부하·타이어 한계·바람)과 패드 진동 | [기록](2026-11-24-drive-sound-rumble.md) |
| 2 | 연속 배차 | [기록](2026-11-24-chained-dispatch.md) |
| 3 | 살아 있는 미터기 설계안·비교표·전환 스위치(기본 꺼짐) | [설계안](2026-11-24-living-meter-design.md) |

공통 실행: `builds/EungyeTaxi/EungyeTaxi.exe` → 은계 싱글. 실제 경력과 섞이지 않게 새 슬롯을 권한다.

## 1단계 · 소리와 패드 진동

- [ ] Esc → 설정 → 감각 탭에 "추가 주행음", "패드 진동" 막대가 있고 6개 막대가 한 화면에 보이는지([화면](../ui/2026-11-24-feel/settings-feel-tab.png)).
- [ ] 가속할 때 엔진 부하음, 급한 코너에서 타이어 소리, 시속 60km 이상에서 바람 소리가 들리는지. 0%와 100%를 비교한다.
- [ ] 손님 요청 창이나 라디오 자막이 떠 있을 때 위 소리가 작아지는지.
- [ ] Xbox 계열 패드: 주행 중 약한 진동, 급제동 진동, 충돌 순간 강한 진동. 진동 0%면 멈추는지. 일시정지·메뉴에서 멈추는지.

**결정할 것**: 녹음 교체 여부(부족 음원 목록은 1단계 기록), 다른 패드(DualSense 등) 지원 여부.

## 2단계 · 연속 배차

- [ ] 손님을 태우고 하차지 400m 안에서 M을 열면 "다음 호출 미리 잡기" 2건이 보이는지. 400m 밖에서는 안 보이는지.
- [ ] 하나를 눌러 예약하면 "예약됨"으로 바뀌고 "예약 취소"가 되는지. 정차 중 요약에 "다음 호출 예약됨"이 뜨는지.
- [ ] 하차 영수증이 예약 전과 같은지. 결과가 끝나면 바로 예약한 승차지로 안내가 시작되는지.
- [ ] 예약 상태로 저장하고 다시 불러와도 예약이 남는지.

**결정할 것**: 예약을 지도 대신 정차 중 요약에서 바로 고르게 할지, 400m·600m·2건.

## 3단계 · 살아 있는 미터기 (결정 필요)

- [ ] [설계안](2026-11-24-living-meter-design.md)의 비교표를 읽고 스위치를 켤지 정한다(기본 꺼짐 = 현재 약정 방식, 오늘 경제는 바뀌지 않음).
- [ ] 켜 본다면: 설정 툴 → "살아 있는 미터기" → `meter.enabled`=1. 신호를 오래 기다린 운송의 수령액이 늘어나는지, 우회하면 더 받는지 본다.

**결정할 것**: 초안 A(현재 단가 유지)·B(시흥 비율, 수입 약 −25%), 지각·미터 미작동 규칙 선택지 1~3, 운행 중 미터 표시 여부.

## 알려 둘 것

- **푸시하지 않았다.** 이번 작업 커밋과, 그 전에 요청받은 `storefront-drive-audio` 병합(시설 매장·세단 엔진음) 커밋이 모두 로컬에만 있다. 병합 푸시는 "push 하지 마" 지시가 온 뒤라 자동 승인 단계에서 막혔다. 원하면 직접 푸시하거나 요청하면 된다.
- 함께 고친 것:
  - 큰 짐 호출에 이야기 손님이나 다른 유형이 배정되던 문제
  - 정차 중 미리 보기가 비던 문제
- 새 검사는 모두 `-contentTest`(시험 캠페인)로 돌렸다. 운전 설정 검사(`-drivingSettingsCheck`)를 실제 저장에서 돌리면 뒤쪽 기존 단계가 저장 상태(내구도 등)에 따라 멈출 수 있다.
