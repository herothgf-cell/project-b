# 2026-11-23 자리 비움 일괄 작업 · 돌아와서 직접 확인할 체크리스트

08 재미 보강 3단계(은계 싱글만)를 질문 없이 진행한 결과다. 자동 검사 통과는 체감 확인이 아니다. 아래 항목은 모두 **직접 플레이로 확인해야** 한다.

- 1단계 호출판 변주·판단 재료: [기록](2026-11-23-call-board-variety.md)
- 2단계 정차 중 모아 보기·마지막 한 콜: [기록](2026-11-23-idle-time-last-call.md)
- 3단계 선택형 미션 4종: [기록](2026-11-23-optional-missions.md)

공통 실행: `builds/EungyeTaxi/EungyeTaxi.exe` → 은계 싱글 → 영업 시작. PvP는 바뀌지 않았다.

## 1단계 · 호출판

- [ ] M → 오른쪽 "호출 목록" 카드에 다음이 보이는지: [성격], 승차 → 하차, 예상 운임 · 기한, 픽업 거리 · 약 N분 · 하차지 수요.
- [ ] 카드가 길어져 목록이 스크롤되는데, 1280×720과 1920×1080에서 읽기 불편하지 않은지.
- [ ] "급한 손님 · 기한 짧음 · 고액"이 실제로 고민되는 선택인지(운임 ×1.4, 기한 ×0.75).
- [ ] "큰 짐"을 수락하면 큰 짐 손님이 타는지(트렁크 없는 차에서는 나오지 않음).
- [ ] "목적지 미공개"는 탑승 전까지 카드·지도 핀·하차 버튼에 목적지가 안 보이고, 타면 안내가 시작되는지. 다른 HUD 줄에 목적지가 새어 나오는지도 본다.
- [ ] "근거리 · 무난"이 거의 안 나오는지(검사에서는 차고 출발 기준 픽업이 587m 이상이라 한 번도 안 나옴).

**결정할 것**: 근거리 기준을 넓힐지, 목적지 미공개에 보상을 줄지, 카드 정보량을 줄일지.

## 2단계 · 운전 중 빈 시간

- [ ] 손님을 태우고 빨간불에 멈춰 1.5초 기다리면, 왼쪽 운행 알림 맨 위에 "정차 중 · …"(요청 알림, 하차 후 가까운 승차 지점)이 나오는지. 출발하면 바로 사라지는지.
- [ ] 운행 알림 패널을 "◀ 숨기기"로 접었을 때 요약이 안 보이는 점을 그대로 둘지.
- [ ] 영업 종료 4분 전에 M: "마지막 한 콜 · 숙소 방향"(짧은 호출)과 "· 반대 방향 고액" 두 장, "하차 후 덕성프라자까지 약 N m", "즉시 귀가" 버튼.
- [ ] "즉시 귀가"가 덕성프라자 안내를 시작하는지.

**결정할 것**: 승객 요청 선택지를 정차 중에만 열도록 바꿀지(이번에는 요청 기한 규칙 때문에 바꾸지 않음), 마지막 한 콜 시작 시점.

## 3단계 · 선택형 미션

- [ ] 호출판마다 한 건에 "[미션] 이름 · 성공 시 +N원 · 목표"가 붙는지.
- [ ] 급행: 신호에 걸려도 정차 시간은 빼고 판정되는지, 목표(안전 운송 시간 ×1.1)가 빡빡한지.
- [ ] 초록불 타기: 실제 신호에서 3곳 연속 무정차가 가능한지. 정지선 앞에서 아주 느리게 굴러간 경우 처리.
- [ ] 커피 든 손님: 너무 쉬운지(급가감속만 없으면 성공).
- [ ] 칼정차: 30cm 정차가 가능한 정도인지.
- [ ] 실패해도 운임이 그대로인지, 영수증에 "미션 … 실패 · 기본 운임은 그대로" 줄이 나오는지. 성공하면 "미션 추가금 (운임과 별도)" 줄.
- [ ] 지각하면 기존 규칙대로 0원이고 추가금도 없는지.

**결정할 것**: 호출판마다 1건(100%)이 많은지, 운전 중 진행 상황(예: 초록불 2/3) 표시를 넣을지, 기록(F8) 내역에도 미션 줄을 넣을지.

## 알려 둘 것

- 실행본 검사는 이 PC의 실제 싱글 저장 슬롯에서 돌았다. 검사용 운송 기록, 영업 시간 진행, 첫 출차 표시 같은 상태가 저장에 남았다. 평소 경력으로 플레이하려면 새 슬롯을 만드는 편이 안전하다.
- 기존 `-contentTest -worldFollowupTest`는 변경 전 실행본에서도 같은 NullReference로 실패한다(기존 문제).
- 지각 0원 같은 기존 운임 규칙과 저장 형식은 바꾸지 않았다. 새 필드는 모두 기본값이 있어 예전 저장이 열린다.
