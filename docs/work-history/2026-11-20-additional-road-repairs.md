# 대은로·대야도서관 횡단부, 덕성프라자 차고, 계수교 포장 수정

[도로 추가 점검](2026-11-20-additional-road-audit.md)의 여섯 지점을 다시 대조했다. 프로젝트 지도 r49를 합성할 때 도로와 보행 포장을 보정한다. 지도 ZIP과 저장 형식은 기존 r49를 사용한다.

| 위치 | 현장 대조와 적용 |
|---|---|
| ① 대은로 J2225 | 항공 대조에서 본선을 가로지르는 횡단보도를 확인했다. 지선용 6m 조각을 대은로에 직각으로 놓인 27.10m 횡단보도로 교체했다. 게임의 열린 진입로를 피해 중심을 남서쪽으로 9.23m 옮겨 양쪽 보도 373·374의 연석에 맞췄다. |
| ② J1927 동쪽 | 덕성프라자 차고 입·출구 안내 곡선을 따라 그린 포장 박스가 본선까지 들어갔다. 보도 3073·3085의 차도측 연석에서 각 포장을 끝낸다. 이전 돌출은 입구 약 8.65m, 출구 약 9.07m다. |
| ③ 마유로 계수교 | 카카오 항공사진에서 각 방향 본선 두 차로와 바깥 분기 차로, 그 사이의 빗금 구간을 확인했다. 폭 40m 원본 세 구간에서 173m 길이의 차도 외곽과 보도 위치를 정리했다. 남측 약 18.2m에서 중앙 약 32m로 넓어졌다가 북측 약 19m로 이어진다. 양쪽 바깥 포장과 빗금 58개, 경계선 4개를 반영했다. 치수는 영상 축척에 맞춘 게임 근사값이고 별도 램프 주행 경로는 추가하지 않았다. [카카오 스카이뷰](https://map.kakao.com/?urlX=458417.0&urlY=1097010.0) |
| ④ J13005 | 사자교와 나란한 측로에 붙는 길이며 교량 본선과의 평면 분기는 항공사진에서 확인되지 않는다. 차량이 보도·녹지를 넘어 본선으로 들어가는 연결을 만들지 않았다. [카카오 스카이뷰](https://map.kakao.com/?urlX=458001.0&urlY=1095509.0) |
| ⑤ J1566 | 도서관과 상가 사이 은행로173번길을 횡단하는 넓은 포장과 양 끝 황색 띠가 보인다. 지선용 흰 줄무늬를 게임 연석 기준 폭 12.10m, 길이 13.07m의 회색 보행 포장과 양끝 약 1m 띠로 교체했다. 시각 포장이며 차가 밟는 물리 과속방지턱은 추가하지 않았다. [카카오 스카이뷰](https://map.kakao.com/?urlX=455148.0&urlY=1096188.0) |
| ⑥ 북서쪽 은계로 | 항공사진에서 본선 가장자리의 지선 입구만 가로지르는 횡단보도를 확인했다. 이 횡단보도의 범위는 현재 지선 폭이 맞다. [카카오 스카이뷰](https://map.kakao.com/?urlX=454924.0&urlY=1097290.0) |

## 검증 및 재현

코드는 Unity의 Scripts/MapSupplements.cs, HomeGarage.cs, MayuBridgeShoulders.cs, RoadMapComposer.cs에 있다. Unity 2022.3.62f2 프로젝트에서 EungyeSupplementTests.RunDaeunCrossing, HomeGarageApronTests.Run, MayuOverpassTests.VerifyBridgeShoulders로 두 횡단부·차고 입출구·교량 단면을 재검사할 수 있다. 회귀 검사는 두 횡단부 이외의 보완 횡단보도 37개의 원본 속성도 비교한다.

별도 점검한 네 연결 차로에서 5cm 간격으로 차 중심과 오른쪽 0.95m까지 보도에 겹치는 표본은 없었다. +1.4m에서 여유 공간 일부가 보도와 겹치므로 회전 시 차체 모서리의 수동 주행 체감은 미검증이다. 현장 참고 사진과 변경 전후 화면은 로컬 artifacts/nov20-additional-road-review/에 보관한다.

Unity 편집기에서 두 횡단부의 메시·연석 검사, 차고 포장 두 면의 본선 침범 0 및 계수교 7개 단면 검사에 통과했다. 기존 J10580 검사 16건, 시설 출발 호출과 승하차지 사이 경로 1,482건 회귀 검사를 통과했다. tools/test_prototype.ps1 종료 0, 필수 지도 입력 문제 0.
