## 0단계 · 문서 정리

- [ ] [08의 5장](../content-design/08-fun-improvements.md)에 37의 내용이 5.1~5.4로 들어간 것이 맞는 방향인지. 37 원문은 `docs/content-design/archive/37-driver-judgment-systems.md`에 있다.
- [ ] "겹치는 항목을 합치며 정한 것" 다섯 줄(길 지식, 승강장, 단속 카메라, 목적지 비공개, 돌발)에 동의하는지. 특히 **호출 목적지 전면 비공개를 보류**로 적었다.

## 1단계 · 미션 "길 아는 기사"

- [ ] 호출판에 `[미션] 길 아는 기사 · 성공 시 +N원` 카드가 나오는지. 미션은 호출판마다 한 건이고 다섯 종류 중 하나라 여러 번 새로 받아야 볼 수 있다.
- [ ] 손님이 탄 뒤 도로 안내선, M 지도의 경로선, 화면 위 회전 안내가 사라지고 "미션 · 길 아는 기사 · 길안내 꺼짐"과 목적지 이름이 보이는지.
- [ ] 길안내 없이 도착하면 영수증에 `길 아는 기사 팁 (운임과 별도)`와 "기사님 길 잘 아시네요."가 붙는지.
- [ ] L을 누르면 길안내가 돌아오고 미션만 끝나는지(운임 그대로, 알림 한 장).
- [ ] 일부러 크게 돌아가면 미션이 끝나고 길안내가 돌아오는지. **이탈 기준(약정 경로 × 1.35 + 120m)이 너무 빡빡하거나 느슨하지 않은지.**
- [ ] 은계 길을 모르는 상태에서 이 미션이 재미인지 스트레스인지.

**결정할 것**: 길안내 다시 켜는 키(L), 팁 비율 15%, 37이 제안한 상시 "내비 단계 3종"으로 넓힐지(넓히면 이 미션을 그 안으로 흡수).

## 1단계 · 퇴근 후 드라이브

빠르게 보려면 Esc → 설정 → "지금 바로 퇴근 (개발용)"으로 정산 화면을 띄운다.

- [ ] 정산 화면 왼쪽 아래에 "퇴근 후 드라이브 (기록·수익 영향 없음)" 버튼이 보이는지.
- [ ] 누르면 숙소 칸에서 밤 조명으로 출발하고, 화면 위에 마치는 방법 한 줄이 보이는지([검사 캡처](../ui/2026-11-24-evening-drive/evening-drive.png)).
- [ ] 은계 FM 자막이 약 45초마다 한 줄씩 나오는지. 간격과 문구가 어울리는지.
- [ ] 한참 달린 뒤 숙소 칸에 세우고 F를 누르면 정산 화면으로 돌아오고, **잔액·연료·내구도·운전 점수가 출발 전과 같은지.**
- [ ] 칸 밖에서 F를 누르면 안내만 나오는지. M 지도에 호출이 없는지.
- [ ] 21시 조명에서 도로와 차선이 충분히 보이는지.

**알고 있는 어색한 점**: 드라이브 중에도 왼쪽 위 영업 시계(멈춘 상태)와 오른쪽 아래 "생활거점"·"퇴근" 버튼, "정차한 시설은 F로 이용하세요" 도움말이 그대로 보인다. 누르면 동작하지 않거나 안내만 나온다. 화면을 따로 정리할지는 결정이 필요하다.

**결정할 것**: 드라이브 중 충돌해도 사고 처리가 없는 것(지금), 조명 시각 21시, 드라이브용 화면을 따로 만들지.

## 1단계 · 차마다 다른 손맛

차를 사야 차이를 볼 수 있다(하이브리드 26,000원, LPG 22,000원). 설정 툴에서 가격을 잠시 낮추면 빨리 볼 수 있다.

- [ ] 차고의 차량 카드에 "손맛: …" 한 줄이 보이는지.
- [ ] 하이브리드: 핸들이 더 빨리 따라오는지, 차체 기울기가 덜한지.
- [ ] LPG: 핸들이 묵직한지, 브레이크(S·패드)가 부드럽게 드는지. **정지선에서 밀리는 느낌이 불편하지 않은지**(계산상 시속 50km에서 약 1.4m 더 감).
- [ ] 아버지의 택시: 운전 느낌은 전과 같고 차체 기울기와 제동 쏠림만 조금 커 보이는지.
- [ ] PvP에서는 차이가 없는지.

**결정할 것**: 아버지의 택시도 물리(핸들 반응·브레이크)를 느슨하게 할지(지금은 연출만), 공업사 타이어·브레이크 부품을 넣을지.

## 2단계 · 설계안 7종 (결정 필요)

- [ ] [08의 5.5](../content-design/08-fun-improvements.md) 요약 표와 [설계안](2026-11-24-next-candidates-design.md)을 읽고 어느 시험판을 어떤 순서로 만들지 정한다.

제안한 순서: 과속 방지턱 → 시외 장거리 콜 → 국도42 구간(일반 차량 속도만) → 유혹(카메라 없이) → 문 여는 정차 차량 → "저 차 따라가 주세요" → 승강장.

**결정할 것**
- 준법 방향과 부딪히는 유혹·따라가기 미션을 넣을지.
- 단속 카메라·승강장·제한속도·방지턱 치수의 실제 조사를 할지, 게임 전용 시설로 밝히고 넣을지.
- 시외 콜 운임 상한과 10분 영업에서의 허용 여부.
- 돌발 상황에서 사고 과실 예외를 만들지.
- "저 버스 따라가 주세요"를 승용차 표적으로 바꿔도 되는지(버스는 코드와 지도에 없다).

## 알려 둘 것

- 3차 작업은 작업 중에는 로컬 커밋만 두었고, 사용자 요청으로 2026-11-24에 푸시했다. 설계안 7종은 보완한 뒤 진행하기로 했다.
- 미션 종류가 넷에서 다섯으로 늘어 호출판마다 붙는 미션 종류의 추첨이 달라졌다. 같은 저장이라도 다음 호출판부터 다른 미션이 나올 수 있다.
- 매장 검사의 비교 1건을 고쳤다. 게임 문제가 아니라 검사가 저장된 시계 값을 소수 17자리까지 같은지 비교하던 것이다([메모](2026-11-24-know-road-evening-drive-vehicle-feel.md)).
- 자동 검사가 확인하지 못한 것: L 키 실제 입력, 핸들 반응과 브레이크 드는 시간(사람 입력에만 적용), 실제로 차를 산 저장에서의 손맛, 밤 드라이브의 분위기.
