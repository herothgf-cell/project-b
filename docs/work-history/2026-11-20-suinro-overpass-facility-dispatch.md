# 수인로 교차로 도색·마유로 고가·시설 출발 길찾기

## 현장 대조와 수정

- 수인로의 2026년 5월 네이버 거리뷰에서 보도 가장자리 황색선과 차도 백색 구분선을 확인했다. J7973·J866의 노면표시는 카카오 스카이뷰와 r49 실행본 원본 도색층을 같은 중심으로 대조했다. 두 지점에서 정지선과 섬을 가로지르는 구 도색 및 고립된 조각의 원본 ID 47개를 식별했다. 같은 ID로 나뉜 중앙선은 정지선 쪽 조각에만 적용했다. [거리뷰](https://map.naver.com/p?c=18.00,0,0,0,adh&p=cz5FGgtmPfVryv7O6_HCRA,85,-20,80,Float) · [항공 대조 기록](2026-11-20-map-aerial-comparison-plan.md)
- J10580에서 북동–남서 방향 마유로가 대각선 수인로 위를 지난다. 상판과 난간, 상판 도색, 높이별 차로 탐색·신호 처리를 적용하고 층 사이의 잘못된 회전 연결 두 개를 제거했다. 게임의 고가 높이 6.2m와 접속 경사는 항공사진의 평면 위치에 맞춘 근삿값이다.
- 시설에서 승차지·지도 목적지를 선택할 때 시설 출구 경로와 도로 경로를 이어서 미리보기, 호출 수락, 내비 안내에 사용한다. 승차지에 이미 도착해 경로 길이가 0인 경우도 구분한다.

## 전체 도로 점검

원본 지도 도로 889개·차로 레코드 2,200개·노면표시 578개를 검사했다. 정확히 겹치는 원본 쌍 14개는 렌더러 중복 제거 전 수치다. Windows Player에서 은계 전역을 260m 폭의 겹치는 99개 구역으로 촬영했다. 전체 시트와 의심 타일 6개를 확대해서 확인했다.

| 지점 | 관찰 |
|---|---|
| J2225 (221, 1201) | 실제 항공사진에서 차도를 가로지르는 횡단보도가 게임에서는 도로 중앙에 짧게 표시된다. |
| J1927 동쪽 (263, 521) | 진입면 두 곳이 본선으로 돌출한다. |
| 북동쪽 (1467, 1604) | 도색 폭에 비해 포장 폭이 넓어졌다가 짧은 거리에서 줄어든다. |
| J13005 (1301, 1004) | 지선 끝과 본선 사이에 녹지가 보인다. 실제 차량 통행 여부 확인이 필요하다. |

로컬 근거는 `artifacts/suinro-facility-review/`와 `artifacts/map-audit-20261119/compare/`에 있다. 전체 타일 촬영은 실제 화면의 범위 검사이며 개별 도로의 현장 측량과 장시간 수동 주행은 별도다.

## 재현

소스 커밋 `358f2fa`에서 도색 렌더러, 고가 회귀 16건, 시설 경로, 승하차 39곳 사이 1,482개 경로와 저장 이관 1,127건이 통과했다. 필수 입력 검사 문제 0, BuildHybrid 종료 0이다.

배포 Player에서 식당 주차 칸에 정차한 상태로 지도 목적지 지정과 승차 호출 수락을 확인했다. 안내 거리는 1,897.51m였고, 차를 재배치하지 않고 안내를 따라 물리 주행으로 출차한 뒤 본선 차로 2047에서 동일 승차 목표까지 1,868.18m 안내가 유지됐다.

- 통합 Editor 검사와 빌드는 Unity 2022.3.62f2에서 `MayuOverpassTests.VerifyRelease`를 실행한다. 지도 패키지 r49에서 실행 시 도로·도색을 합성한다.
- Windows Player에 `-singlePlayer -contentTest -oneDayMode -hybridV2 -restaurantExitTest`를 주면 식당 주차 칸에서 지도 목적지와 호출을 선택하고, 수락한 승차 안내선을 따라 출구를 통과해 본선에서 같은 승차 목표를 계속 안내하는지 검사한다.
- `-singlePlayer -contentTest -dayLightDayProbe -mapAudit -mapAuditLayers "J7973_3744|J866_5285|J10580_1415" -mapAuditOutput <출력 폴더>`는 세 곳 도색층과 고가 사선 화면을 촬영한다. `-singlePlayer -presentationTest -dayLightDayProbe -roadContinuityViews`는 전체 도로 화면과 촬영 범위를 기록한다.
최종 Player의 99개 타일에 도로 객체 4,025개가 모두 포함됐고 화면·표지 검사 359건이 통과했다. J866의 추가 황색 도색 조각 16개를 처리하고 J10580 램프 차로 끝 6곳에 지상 포장을 연결했다. 배포 manifest 143개 파일의 크기·SHA256 검증을 통과했고 선택 사용자 설정도 별도로 검증했다.
