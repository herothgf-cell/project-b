## 요구와 반영

| 요구 | 반영 |
|---|---|
| 하루20분 | 독립 하루1,200초 영업 예산·하루 순수익 비교, 고정3만원 성공/실패 제거 기획 |
| 배고픔·피로 | 별도 운전자 문서, 식사/휴식 시점·신규 운송 가능 여부에 영향. 조향·가감속·제동·시야 변경 없음 |
| 관련 문서 연결 | 캠페인·경제·로드맵·범위·승객 시나리오·체크리스트 정합성 반영 |
| 구현과 기획 구분 | 기존3일×720초·목표30,000원 구현 기록 유지, 새 P7 작업6개 미완료 표시 |

08~20시 표시·식사50초·수면100초·포만감/피로 수치는 테스트 제안이다. 메뉴 정지와 거점 시간 건너뛰기를 구분하며 식사1회·수면1회면 실제 조작 예산은17분30초다. 마감 후 마지막 운송은 기존 기한으로 목적지까지 유지한다. 기존9코스·17요청과 운행 사건 즉시 저장을 재사용하고 보험·세금·예약·사고 제외는 유지한다.

| P7 상태 | 6개 신규 작업 모두 미완료, 기존 구현 완료 기록 보존 |

| 게임 검증 | 코드 변경 없음. 위치 제어·자동 물리·수동 플레이·새 하루 캠페인 검사 미실시 |

현재 실행 대상은 `builds/EungyeTaxi/EungyeTaxi.exe`, 빌드는 `PrototypeBuild.BuildHybrid`다. 지도 입력·배포 파일·manifest는 이 작업에서 변경하지 않았고 로컬 입력 해시를 재검증하지 않았다. 작업 시작부터 있던 코드·지도·빌드·라이선스 변경과 다른 진행 작업은 보존했다. 작업 중 추가된 경제 문서의10% 주유 정책도 보존·본문 연결했다. 최초 문서 작성 단계에서는 커밋·푸시하지 않았다. 이후 사용자 요청에 따라 하루20분 기획만 선별하여 커밋·푸시한다. 같은 문서에 추가된 승차·보도·10% 주유·우회전 유지보수 변경은 작업 폴더에 보존하고 이번 커밋에서 제외한다. 실제 커밋은 git log -1 --oneline -- docs/work-history/2026-10-21-one-day-driver-design.md로 확인한다.
