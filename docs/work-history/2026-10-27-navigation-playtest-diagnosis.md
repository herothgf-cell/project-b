# 호수 서쪽·남쪽 내비 우회 진단

## 요청·결론

플레이 스크린샷1의 파란 지름길과 스크린샷5의 북동쪽 연결도로를 정식 프로젝트 지도 `config/maps/project/eungye.project.json`의 방향 차로에 대응했다. 두 우회는 현재 그래프의 차로별 회전과 **차로변경 연결이 시작10~42m 한 구간에만 있는 한계**로 재현된다. 단순 일방통행 때문이나 최단 탐색 오류라는 근거는 없다. 이 결과가 실제 도로에서 차로변경/회전이 금지되어 있다는 현장 검증은 아니다.

생산 코드·지도·입력 manifest·ZIP은 변경하지 않았다. 실제 차량의3차로 대신 인접1차로를 출발로 선택하거나 존재하지 않는 변경 연결을 탐색 중 생성하면 H/NPC 공통 경로의 연결·차선 근거를 우회하므로 적용하지 않았다.

## 스크린샷1

- 출발 대응 차로: `local:2103:5502:4463:8575` (은행고길 북동행). 화면의 정확한 출발 진행거리는 알 수 없어 비교는 차로 시작0m를 사용한다. 출발 진행거리만큼 두 경로가 똑같이 줄어들어 비교 차이는 유지된다.
- 목적지 대응: S04 `local:8265:6305:9056:10851` @434.46582m, 북행 접근.
- 파란 지름길: `join:local:2103:5502:4463:8575:0` → `local:4711:8643:7608:9494` (x471/z864→x761/z949). 동행 연결은 이미 존재한다.
- 지름길에서 우회전 `join:local:4711:8643:7608:9494:1`은 남하3차로 `local:7737:9374:7933:6566`으로 들어간다. 북행 목적지로 가려면 다음 교차로에서 남하1차로 `local:7847:9404:8047:6565`의 좌회전이 필요하다.
- `change:local:7737:9374:7933:6566:local:7792:9389:7990:6566`은3→2차로의42m 지점으로 연결한다. 2→1차로 변경은2차로10m 지점에서 출발하므로 연속 이동할 수 없다. 후반부 변경 연결은 없다.
- 현재 북쪽 우회는 남하2차로로 진입한 뒤1차로 변경을 사용한다. 독립 Node.js Dijkstra 대조: 물리 길이1948.34m, 차로변경12m×2 비용 포함1972.34. 지름길 경유를 강제하면 남쪽 블록을 돌아 물리 길이/비용2306.88m로 오히려334.54비용m 길다. 이는 현재 그래프에서의 비교이며 실제 도로 최단거리 주장은 아니다.

## 스크린샷5

- 차량 위치 대응 후보: 남동행3차로 `local:6266:11718:7563:9778:part:2`, 차로변경 창을 지난 부분. 화면만으로 진행거리/차로를 확정한 저장 스냅샷은 없으며, 해당 차로에서 화면의 서쪽·남쪽 우회 형상을 재현한다.
- 목적지 대응: EG-GAME-03 `local:9032:10757:8270:6402` @520m, 남서행 접근. 스크린샷1의 북행 S04와 접근 방향이 다르다.
- 사용자가 그린 짧은 북동 연결은1차로 `local:6355:11817:7686:9830:part:2` → 좌회전 `join:local:6355:11817:7686:9830:-1` → `local:8025:9707:8449:10031`이다.
- 현재3차로 후반에는1차로로 갈 변경 연결이 없다. 출발 후보 차로 시작0m 기준3차로 우회1940.70m, 같은 도로1차로 비교914.70m로1026.00m 차이다. 인접1차로를 동일한 차량 위치라고 가정해 경로를 제시하면 허위 연결이 된다.

## 검사·변경 파일·남은 작업

- 추가 파일: `unity/EungyeTaxi/Assets/Editor/PlaytestNavigationAudit.cs`. 정식 프로젝트 지도를 합성하여 네 경로·차로변경 끝/출발 노드·회전 차로를 읽기 전용으로 검사하고 전체 edge ID를 로그에 남긴다. 생산 행동을 변경하지 않은 진단용 회귀다.
- 재현: Unity 프로젝트 `unity/EungyeTaxi`에서 `-executeMethod PlaytestNavigationAudit.Run -batchmode -nographics -quit`. 성공 표식 `PLAYTEST_NAVIGATION_AUDIT_OK`. Unity 실행 결과는 주 작업자가 단일 프로세스로 수행한 통합 기록에 별도 기재한다.
- 독립 Node.js의 JSON 방향 그래프/Dijkstra 대조 종료0, `git diff --check` 종료0. 이 독립 대조는 Unity 실제 실행·자동 물리 주행·수동 플레이 검증을 대체하지 않는다.
- 우회 자체 해소에는 같은 도로의 후속 점선/차로변경 가능 구간을 확인하여 두 번째 변경 연결을 지도 편집으로 추가하는 작업이 필요하다. 변경 시 공통 내비/H/NPC 연결 검증, 지도 manifest/ZIP 동기화가 함께 필요하다. 확인되지 않은 양방향·임의 회전은 추가하지 않는다.
