# 은계 프로젝트 지도 편집기 사용법

## Unity 3D 직접 편집 (권장)

실행파일과 같은 지도 형상을 보면서 이동·회전·크기를 조절하려면 **Unity → Taxi → 프로젝트 지도 3D 편집**을 사용한다. [시작·W/E/R 조작·정차점·저장·PC 이동 사용법](unity-map-editor-guide.md).

Unity 편집기에 기존 Esc 차로·표지·노면·신호 기능과 건물/부지 생성·삭제를 통합했다. **Unity → Taxi → 프로젝트 지도 3D 편집**에서 모든 편집을 수행하고 정식 프로젝트 JSON으로 저장한다. 아래 실행파일 편집기는 이전 사용법으로 유지하며 Unity 사용법을 우선한다.


## 건물·보도·부지까지 수정하고 다른 PC에 적용하기

**정식 지도 원본은 Git의 `config/maps/project/eungye.project.json`이다.** 기준 지도와 편집한 차로·건물·보도·생활 부지를 함께 담는다. 예전 NGII/OSM 원본은 재수입용으로 별도 보존하며, 프로젝트 편집은 그 원본을 덮어쓰지 않는다.

1. `builds/EungyeTaxi/EungyeTaxi.exe` 실행 → 출발 → **Esc → 지도 편집**.
2. 상단 **건물·부지** 탭에서 종류를 고른다. 지도에서 면을 클릭하거나 왼쪽 목록/이름 검색으로 대상을 선택한다.
3. 선택한 대상을 드래그해 이동한다. 오른쪽에서 이름·높이·폭을 바꾸거나 회전·확대/축소한다. **꼭짓점 편집**으로 모양을 바꾸고 점을 추가/삭제한다. **새 ... 놓기**를 선택하면 지도 클릭 위치에 새 객체가 생긴다.
4. 주차장·식당·휴식 부지는 **정차 위치**를 부지 안에 두고 **접근 차로**를 지도에서 선택한다. 노란 정차 칸과 방향이 실제 영업 시작/마감·식사·수면 판정에 쓰인다. 내비 목표는 지정한 접근 차로이고 전체지도/미니맵 핀은 부지 내부 정차 위치다. 식당 건물은 ‘건물’, 앞마당은 ‘식당 부지’로 각각 편집한다.
5. **검사 → 저장하고 시험**으로 형상과 경로를 확인한다. 도로 노면은 외형이고, 내비·NPC가 다닐 경로는 **차로** 탭에서 함께 조정한다. 부지만 옮겼을 때 진입 노면도 함께 연결한다.
6. **프로젝트** 탭 → 저장소 루트(`.git`과 `unity`가 있는 `project-b`)를 확인 → **프로젝트에 저장 · 배포 자료 확정**. 실행파일이 저장소 안에 있으면 경로를 자동으로 찾는다.
7. 바뀐 `config/maps/project/eungye.project.json`을 Git으로 커밋·푸시한다. 게임 편집기의 저장 버튼은 Git을 자동 실행하지 않는다.
8. 다른 PC에서 **pull → Unity의 Taxi > Build Eungye Hybrid → 새 exe 실행**. 빌드가 정식 프로젝트 지도를 포함하므로 동일한 수정 내용이 적용된다. 빌드된 실행 폴더도 커밋·푸시했다면 다른 PC는 pull 후 바로 실행할 수 있다.

상단 **개인 저장**, 자동 초안, **다음 실행에 사용**은 이 PC의 개인 수정본이다. 다른 PC에 전달하려면 반드시 **프로젝트에 저장**을 사용한다. 프로젝트 저장 후에도 이미 시작한 영업 지도는 그대로이며, 시험 창이나 새 빌드 실행에서 변경을 확인한다. 새 프로젝트 버전과 맞지 않는 예전 개인 기본 수정본은 자동 적용하지 않는다.

저장소가 다른 편집기나 pull로 변경되면 덮어쓰기를 차단한다. 현재 초안을 개인 저장한 뒤 **저장소의 프로젝트 지도 다시 열기**로 최신본을 불러온다. 기준 지도까지 달라졌다면 새 빌드로 편집한다. 직전 정식 저장은 같은 폴더의 `.bak`에 남지만 Git 배포 대상은 아니다.

지도 범위 밖, 자기 교차 다각형, 잘못된 차로 연결/정차 위치 등은 정식 저장과 빌드에서 거부한다. 기존 수입 보도 중 구멍이나 분리된 조각이 있는 자료는 여러 편집 면으로 보일 수 있다. 실제 운전으로 진입 폭·연석·건물 간격을 확인하는 과정은 별도로 필요하다.

## 지도 데이터 위치

| 자료 | 위치/역할 | Git 전달 |
|---|---|---|
| 정식 프로젝트 지도 | `config/maps/project/eungye.project.json` — 빌드에 적용할 기준·편집 데이터 | 포함 |
| 빌드용 복사본 | `Assets/Resources/eungye-project-map.json` — BuildHybrid가 정식 파일에서 생성 | 제외 |
| 개인 수정본·자동 초안 | Unity 사용자 데이터의 `RoadMaps/` — 개인 작업/시험용 | 제외 |
| GIS 원본 | `data/raw/` — 재수입 작업용 NGII/OSM | 제외 |
| 배포 실행파일 | `builds/EungyeTaxi/` — 위 프로젝트 지도 포함 | 포함 |

현재 정식 프로젝트 지도가 있으면 **BuildHybrid에 재수입용 입력 2개나 원본 GIS가 필요하지 않다.** `pwsh -File tools/check_workspace.ps1 -Strict`는 프로젝트 구조와 존재하는 입력의 해시를 확인하고, Unity 빌드가 정식 지도 내부 해시·형상·연결을 검사한다. 재수입 작업은 `-RequireRawInputs`로 입력 2개를 모두 확인한다. 정식 지도 파일을 지우고 재수입하면 편집한 내용이 사라질 수 있으므로 Git 이력을 먼저 보존한다.


## 수정할 도로는 어떻게 고르나요?

**출발 → Esc → 지도 편집**을 열면 기본으로 **간편 편집**이 나온다.

1. **지도에서 수정할 도로 선을 클릭한다.** ID를 알 필요가 없다. 휠로 확대하고 오른쪽/중간 버튼 드래그로 이동한다. 왼쪽 도로명 검색, **T1로 이동**, **내 위치**로 위치를 찾을 수도 있다.
2. 왼쪽에서 도로 이름과 **남쪽 진입/북쪽 진입** 등의 방향을 확인한다. ‘남쪽 진입’은 남쪽에서 교차로로 들어오는 방향이다. 필요한 방향 카드를 누른다.
3. 오른쪽에서 **1차로·2차로·3차로** 중 수정할 차로를 누른다. 운전자 기준 왼쪽이1차로다. 지도에서는 선택 차로가 노란색, 같은 진입 방향은 밝은색, 다른 도로는 어둡게 보인다.
4. 큰 **← 좌회전 / ↑ 직진 / → 우회전** 버튼을 눌러 허용 방향을 바꾼다. 켜진 방향은 초록색으로 표시한다.
5. **저장하고 시험**을 누른다. 수정본 저장·연결 검사·별도 시험 창 실행을 차례로 수행한다. 출발/도착을 지정하지 않았으면 선택 차로 주변에서 자동 추천한다.

도로 이름 자료가 없으면 ‘이름 없는 도로’로 표시한다. 이때는 지도 모양과 교차로·진입 방향을 보고 고른다. 도로 선을 잘못 선택했다면 확대 후 다시 클릭한다. 노면에 놓은 시설을 클릭하면 해당 시설이 선택되므로 도로 선의 빈 부분을 클릭한다.

## 간편 편집 기능

| 할 일 | 조작 |
|---|---|
| 차로 방향 수정 | 도로 클릭 → 진입 방향 → 차로 번호 → 큰 방향 버튼 |
| 새 출구 연결 | 진입 차로 선택 → **출구 차로를 클릭해서 연결** → 지도에서 도착 차로 클릭. 노란 점선 미리보기와 생성된 곡선을 확인 |
| 연결 취소 | Esc 또는 연결 선택 취소. 이미 연결된 출구는 중복 생성하지 않음 |
| 회색 방향 버튼 | 해당 출구 연결이 아직 없는 상태. 출구 차로를 클릭해 연결한 뒤 방향을 선택 |
| 도로 모양 수정 | **모양 다듬기 · 제어점 표시**를 켜고 지도에 나타난 점을 드래그 |
| 차로 폭 | **− 좁게 / + 넓게** 버튼으로0.1m씩 조정 |
| 표지·노면 배치 | 위쪽 표지/노면 탭 → 종류의 **놓기** 버튼 → 지도에서 위치 클릭 |
| 시설 이동·회전 | 시설을 클릭해 선택하고 드래그. 오른쪽 **왼쪽 회전/오른쪽 회전**은15도씩 회전 |
| 시설 적용 대상 | **적용할 차로를 지도에서 선택** → 해당 차로 클릭. ID 복사 불필요 |
| 신호 기본형 | 신호 탭 → **기본 신호 만들기 / 가져오기** → 기본/차량 여유/보행 여유 시간 선택 |
| 신호 녹색 대상 | 단계를 선택해 진입 방향·좌/직/우/보행 목록을 체크. 적용 차로/횡단보도 선택 버튼으로 지도의 대상을 연결 |
| 신호기 연결 | 신호기를 선택하고 읽을 수 있는 진행 이름을 고른 뒤 **제어할 정지선/횡단보도 선택** → 지도 클릭 |
| 저장본 열기 | 왼쪽 **저장한 수정본 열기** → 이름과 리비전으로 선택 |
| 다음 영업에 적용 | 검사·저장 후 **다음 실행에 사용**. 게임을 다시 실행하면 적용 |
| 기본 지도 복귀 | 왼쪽 **기본 지도 사용으로 전환**. 다음 실행부터 반영되며 초안 보존 |
| 자세한 수치·ID·파일 경로 | 상단 **고급 편집**. 돌아올 때 **간편 편집으로 돌아가기** |

**저장하고 시험**에서 오류가 나오면 아래 ‘수정 필요’ 항목을 눌러 해당 위치로 이동한다. 저장한 초안은 보존되고 오류가 있는 지도는 시험/기본 적용을 막는다. 표지의 게임 규칙 적용과 제한속도 범위는 오른쪽에서 확인한다. 제한속도 표지를 놓기만 하면 안내용이며 규칙 적용을 별도로 켠다.

편집 중 변경분은2초 간격으로 `.autosave.json` 초안에 보관한다. 상단 **저장**이 사용자가 확정하는 저장이다. 간편 저장의 기본 파일명은 수정본 ID로 자동 지정하므로 파일 경로를 직접 입력할 필요가 없다. 저장한 수정본 목록에서 자동 초안도 이름·리비전으로 열 수 있다.

시험 창은 원래 영업과 분리된다. 시험을 종료해 편집기로 돌아온 뒤 편집기를 닫는다. 기존 영업의 시간·연료·돈·점수 저장에는 시험 결과를 반영하지 않는다.

버튼은 문구가 영역 안에 들어오도록 글자 크기와 표시 길이를 맞추고, 긴 작업 버튼에는 충분한 높이를 둔다. 아래 고급 안내는 상세 수치와 파일 교환이 필요할 때 사용한다.

# 고급 편집 상세 안내

기본 실행: `builds/EungyeTaxi/EungyeTaxi.exe`. Unity 설치 없이 실행파일에서 편집한다. 편집본은 원본 지도와 별도 JSON이며, 영업 도중의 도로는 교체하지 않는다.

## 처음 한 번 따라하기

1. 은계 게임을 실행한다. 출발 준비 화면이면 출발한 뒤 `Esc`를 누르고 **지도 편집**을 연다.
2. 처음에는 T1 교차로 `J4396_13458` 부근을 보여준다. 왼쪽 차로 목록 또는 지도에서 차로를 클릭한다. 다른 교차로는 왼쪽 검색에 ID를 입력하고 해당 교차로를 누른다.
3. 오른쪽 **허용 방향**에서 좌회전·직진·우회전을 바꾼다. 아래 **출구/차로변경 연결** 목록은 실제 공유 그래프 연결이다. 방향을 끄면 해당 출구가 제거되며 노면 화살표·내비·H·NPC도 그 연결을 사용한다.
4. **검사**를 누른다. 오류가 있으면 하단 오류를 클릭해 위치로 이동하고 수정한다. 출구를 전부 없애거나 필수 승하차·거점 접근이 끊기면 시험/기본 사용을 지정할 수 없다.
5. 왼쪽 JSON 경로를 확인하고 **저장**한다. 오류가 있는 초안도 저장할 수 있다.
6. 출발 차로를 선택하고 오른쪽 아래 **선택 차로를 출발로**, 도착 차로를 선택하고 **선택 차로를 도착으로**를 누른다. **시험 주행**을 누르면 수정 지도와 일반 차량을 포함한 별도 창이 열린다. W/A/S/D로 운전하고 H 조향 보조와 내비 경로를 확인한다. H는 가감속·신호 판단을 대신하지 않는다.
7. 시험 창 상단 **시험 종료 · 편집기로 돌아가기**를 눌러 닫는다. 부모 영업 창은 정지 상태이며 잔액·연료·시간·운행 기록에 시험 결과를 저장하지 않는다. 시험 창을 종료한 뒤 편집기를 닫을 수 있다.
8. 수정본을 실제 영업에 쓸 때는 **기본 사용 지정**을 누른다. 검사와 저장을 통과한 수정본을 별도로 보관한다. 게임을 종료하고 다시 실행하면 해당 이름과 리비전이 적용된다. 현재 영업에는 계속 기존 지도가 사용된다.

## 지도와 차로 조작

| 조작/기능 | 사용법 |
|---|---|
| 확대·축소 | 지도 위 마우스 휠. 표시 폭 30~2,500m |
| 지도 이동 | 마우스 중간 버튼 또는 오른쪽 버튼 드래그 |
| 선택 | 차로 선 또는 시설 표시 클릭. 선택 차로는 노란색, 선택 제어점은 붉은색 |
| 중심선 수정 | 선택 차로의 제어점을 왼쪽 버튼으로 드래그하거나 오른쪽 X/Z 입력. 공유 끝점은 연결된 차로와 함께 이동 |
| 높이 | 선택점 높이 입력. 지면0m 기준 최대1.5m의 게임용 도로 높이 보정. 인접 끝점 높이를 함께 맞춘다 |
| 폭·번호 | 오른쪽 차로 폭 2.6~5m. 번호는 교차로를 바라보는 운전자 왼쪽부터 |
| 제어점 추가/삭제 | 선택점 다음 구간에 중간점 추가. 양 끝점은 삭제할 수 없음 |
| 평행 차로 추가 | 선택 차로 오른쪽에 평행 차로와 출구 곡선 생성. 진입 연결을 별도로 만들어야 함 |
| 짧은 좌회전 차로 | 기존 좌회전 출구가 있고 길이65m 이상인 차로에서 생성. 끝55m 중 벌어짐25m가 기본값. 이후 제어점으로 조정 |
| 차로 변경 구간 | 구간 양 끝을 제어점으로 만들고 선택점 분할. 새 연결의 차로변경 방향 -1/1을 지정하고 구간 끝의 대상 차로에 연결 |
| 새 출구 연결 | 대상 차로의 ID 복사 → 출발 차로 선택 → 새 연결 대상 ID 붙여넣기 → 회전 -1/0/1 입력 → 연결 곡선 생성 |
| 기존 연결 제거 | 출구/차로변경 연결 목록에서 해당 연결 해제 |
| 차로 삭제 | 삭제 영향 확인 → 연결/종속 시설 제거. 한 번의 취소로 함께 복원. 필수 승하차 차로 삭제는 적용 차단 |
| 변경 전 비교 | 상단 변경 전 차로 겹침 체크. 회색 기준 차로와 수정본을 비교 |
| 3D 확인 | 상단 3D 확인. 편집 영역 주변의 차로·노면·표지·신호를 확인하고 평면 보기로 돌아와 수정 |
| 취소/다시 실행 | 상단 버튼. 문서 전체 참조를 함께 복원하며 최근30개 작업 보관 |

평행 차로·대기차로 생성 직후에는 반드시 출입 연결과 승하차 접근을 검사한다. 여러 점을 추가·삭제하거나 차로를 분할한 뒤에는 높이 입력도 다시 확인한다. 유턴은 별도 연결과 허용 조건 표지를 함께 지정한다. 아래 2026-10-26 유턴 추가 절을 따른다.

## 노면과 표지

상단 **노면**에서 정지선(`stopLine`), 횡단보도(`crosswalk`), 일반 차로선(`line`), 중앙선(`centreLine`)을 지도 중앙에 추가한다. 선택 후 위치·방향·폭·길이·배율을 입력한다. 정지선/횡단보도에는 교차로 ID, 접근 축0/1과 방향+1/-1을 지정한다. 해당 접근의 기존 노면 대신 수정 노면을 그리고 정지 위치와 보행 구간을 반영한다.

상단 **표지**에서 추가한 표지를 선택해 종류와 문구·높이·회전·크기를 바꾼다. **지면/선택 차로 끝 가장자리에 맞춤**은 적용 차로 ID를 기준으로 위치를 잡는다.

| 표지 | 게임 규칙 적용 |
|---|---|
| 좌회전 금지·우회전 금지 | 지정 차로에서 해당 방향 연결 제거 |
| 진입 금지 | 지정 차로와 그 차로로 들어오는 연결 폐쇄. 필수 접근이 끊기면 적용 차단 |
| 제한속도 | 적용 차로 ID, 시작/끝 거리(m), 속도 지정. NPC 속도·내비 예상 시간·플레이어 운전 기록 공유 |
| 일방통행·비보호 좌회전·횡단보도·보호구역·방향 안내 | 안내용 외형. 지원하지 않는 규칙 적용은 검사에서 차단 |

제한속도는 게임용 규칙이다. 직접 운전에서는 설정 속도+3km/h를 넘는 상태가2초 이어질 때5점 감점 사건을 기록한다. 제한속도 구간을 벗어나거나 속도를 줄이면 관찰을 초기화한다.

표지/차로의 근거 상태는 `game`(게임 창작), `estimated`(추정), `observed`(관찰)로 기록한다. 거리뷰 URL·촬영월·확인일·메모와 외형/규칙 확인 체크를 따로 저장한다. 화면에 그렸다는 이유로 실제 현장 규제가 확정되지는 않는다.

## 차량·보행 신호

1. 교차로를 선택하고 **신호 → 기존 신호 가져오기 / 그룹 편집 시작**을 누른다. 처음 가져오면 차량·보행 그룹, 단계와 연결된 정지선/횡단보도·신호기를 생성한다.
2. 편집용 가져오기는 안전한 **접근 방향별 분리 단계**로 시작한다. 기존 비보호 운영을 그대로 재현하는 기능은 아니다. 단계 시간은 게임 설정이며 실제 주기를 확정한 자료가 아니다.
3. 각 단계에서 녹색·황색·정리 시간을 입력하고 허용할 그룹을 체크한다. 녹색1~120초, 황색0~10초, 정리1~30초를 지원한다. 보행은 황색 중 적색이다.
4. 그룹에 접근 축·방향·회전과 적용 차로 ID 목록을 입력한다. 회전은 좌-1/직0/우1이다. 차로 ID 목록을 비우면 해당 접근의 모든 차로, 입력하면 지정 진입 차로에만 적용한다. 목록은 쉼표로 구분한다.
5. 새 보행 그룹에는 같은 교차로의 **횡단보도 ID**를 입력한다. 노면 도구에서 횡단보도를 선택한 뒤 시설 ID 복사로 가져올 수 있다.
6. 신호기를 추가/선택하고 그룹ID, 제어 정지선 또는 횡단보도ID, 위치·높이·방향을 설정한다. ID는 각 그룹/시설의 복사 버튼으로 가져온다. 신호기를 옮겨도 정지선 위치는 따로 유지한다.
7. **검사**를 통과한 뒤 시험 주행에서 차량 정지/출발·점등·보행 횡단을 확인한다. 임의 신호를 지정한 교차로에서는 해당 프로그램이 NPC와 직접 운전 판정에 적용된다.

현재 충돌 검사는 보수적이다. 보행과 차량의 동시 녹색, 다른 축 차량의 동시 녹색, 마주 오는 방향의 회전이 포함된 동시 녹색을 차단한다. 같은 축의 반대 방향 직진은 허용한다. 비보호·양보 혼합을 임의 시간표로 만드는 기능은 제공하지 않는다. 미연결 신호기·없는 그룹/횡단보도·한 번도 허용되지 않는 그룹은 수정 후 적용해야 한다.

신호 속성은 길기 때문에 오른쪽 패널을 스크롤한다. 가져온 프로그램을 제거하려면 **신호 편집 원상 복원**을 사용한다. 노면까지 되돌리려면 왼쪽 **선택 교차로 원상 복원**을 사용한다.

## 저장·전달·복원

- **저장**은 왼쪽 JSON 경로로 쓴다. 경로를 바꿔 저장하면 내보내기, 받은 파일 경로를 넣고 불러오면 가져오기다. 저장 시 이전 파일은 `.bak`으로 보존한다.
- **폴더 열기**는 `Application.persistentDataPath/RoadMaps`를 연다. 일반 Windows에서는 사용자 `AppData/LocalLow/Taxi Prototype/택시 시뮬레이터/RoadMaps` 아래다. 실제 위치는 버튼으로 확인한다.
- **기본 사용 지정**은 유효한 수정본을 `active.json`으로 보관한다. 원래 초안 파일을 나중에 바꿔도 다시 지정하기 전에는 기본 수정본에 반영되지 않는다.
- **기본 지정 해제**는 다음 실행부터 원래 지도 사용. 초안을 삭제하지 않는다.
- **마지막 정상 적용 백업 불러오기**는 `active.json.bak`을 초안으로 연다. 백업이 없으면 읽기 실패를 알린다.
- **교차로 원상 복원** 또는 **전체 초안 기본 복원**도 취소 가능한 편집 작업이다. 기본 지정 파일 변경은 별도다.
- 다른 PC에는 JSON을 전달하고 동일한 빌드의 편집기에서 불러온다. 기준 해시가 다르면 자동 적용하지 않는다. 손상/불일치 기본 수정본으로 실행한 경우 기준 지도로 시작하고 적용 실패 사유를 표시한다.
- 시험 창은 임시 JSON을 사용하고 닫히면 정리한다. 영업 저장과 수정본 저장은 서로 다른 파일이다.

## 오류 해결과 검증 범위

하단 오류에는 대상 ID와 해결 방법이 나온다. 끝점 단절은 공유 끝점으로 이동하거나 연결 곡선을 다시 생성하고, 없는/폐쇄된 출구는 연결을 제거하거나 대상을 재지정한다. 접근 불가는 필요한 차로/연결을 복원한다. 급격한 형상·건물/검토 보도 침범은 제어점을 조정하고 3D·시험 주행으로 확인한다.

자동 검사는 저장·취소·기본 자료 호환, 연결/신호 오류 차단, 실행파일 화면과 별도 프로세스 격리를 확인한다. 모든 편집 결과의 차량 회전반경·전체 맵 건물/보도·일반 교통 흐름·사용자의 수동 하루 플레이를 보장하는 검사는 아니다. 고가·터널·지형 조각·건물 제작은 지원하지 않는다. 실제 실행한 검증과 남은 항목은 [작업 이력](work-history/2026-10-22-road-map-editor-implementation.md)을 따른다.

## 2026-10-26 유턴 추가

1. 진입할 차로를 선택합니다.
2. **유턴 대상 차로 클릭**(Unity에서는 연결 회전 **유턴**)을 고르고 반대편 출구 차로를 클릭합니다.
3. **표지** 탭에서 실제 표지에 맞는 유턴 조건(상시 양보 / 좌회전 신호 / 보행 신호 / 좌회전·보행 신호)을 놓습니다.
4. 표지를 원래 진입 차로에 연결하고 **게임 규칙에 적용**을 켭니다. 조건 표지는 진입 차로당 하나만 둡니다.
5. 검사 → 저장 → 시험 주행을 합니다. 간격이나 회전 반경이 부족하면 연결을 거부하므로 더 바깥쪽 출구 차로를 확인합니다.

유턴은 좌회전과 별개의 연결입니다. 반대 방향 연결, 최소 회전 반경과 허용 조건을 검사하고 내비/H/NPC/노면 화살표가 같은 경로를 사용합니다. H는 조향만 보조하므로 가감속과 신호·주변 확인은 직접 합니다. 확인된 기본 지도 위치는 T1 동남·북서·북동 접근이며, 촬영 당시 조건은 **좌회전 또는 보행 신호 시**입니다.

첨부 화면의 넓은 황색 경계 사이 공간에는 수인로 중앙 안전지대와 방호울타리가 관찰됩니다. 원본 간격을 한 줄로 줄이지 않고 시설을 추가합니다. [거리뷰 근거와 관찰 범위](map-observations/2026-10-26-uturn-median-observations.md).
