# 운전 안정화·교통·매너 검증

2026-10-14, Unity 2022.3.62f2 / Windows / RTX 5060 Ti. 실행 파일: `builds/YeongtongTaxi/YeongtongTaxi.exe`.

## 구현

- 고속 조향을 휠베이스2.6m·이론 횡가속5m/s² 범위로 제한. 무게중심 하향, 접지 중 롤·피치 감쇠, 월드 아래 방향 다운포스, 충돌 복원 속도 제한.
- 방향을 가진 도로 그래프에서 우측 차로와 도착 방향을 고려해 경로 탐색. 일반 도로 중간의 즉시 역방향 전환은 제외하고, 막다른 길만 예외. 현재 현장의 회전 금지·일방통행 자료를 반영한 것은 아님.
- 승하차8곳: 오른쪽 연석에 같은 방향으로 정차해야 F 가능. 진행 방향 기준 전후4.5m·좌우1.15m 이내, 방향 내적0.85 초과, 속도0.56m/s 미만. 반대 차로·반대 방향·주행 중 승하차 거절.
- 승객은 도로 밖 인도에 배치. 건물과 겹치는 후보 제외. 보도 조각1,325개 및 승하차 전용 보도8곳에 실제 충돌체 배치. 약2m 폭·16cm 높이의 게임용 보도이며 실제 보도 측량 복원은 아님.
- 일반 차량12대: 직진8대, T1·T2 좌회전·우회전4대. 회전 감속·깜빡이, 경로를 따라 앞차·택시·건물 감지, 대기열 및 출구 확보. 정지선 가까이의 선두 차량만 교차로 진입 순서를 받음. 교차로 한 대씩 통과하는 보수적인 시제품 제어.
- 승차 시 매너100점. 적색 신호12, 충돌10, 급가속3, 급제동4, 도로 경계 침범5 감점. 사건별 대기시간과 지속 상태 잠금 적용. 역주행·과속·보행자 양보·교통사고 과실 전체를 판정하지 않음.
- 승객 요구60·70·85점. 기한 내 요구 달성100%, 미달70%, 시간 초과0원. 원 단위 정산은 정수 연산. 호출 목록·운송 HUD에 요구 점수와 현재 점수 표시.

## 검사 중 수정한 결함

1. 후진 가속과 제동의 부호가 뒤바뀌던 감점: 이동 방향 기준 가속도로 수정하고 역방향 정책 검사 추가.
2. 황색·적색으로 바뀌어도 정지선 전 차량이 교차로 진입 순서를 점유: 진입 전 신호 변경 시 해제.
3. 뒤차가 먼저 진입 순서를 잡아 앞차와 서로 기다리던 혼합 교통 교착: 장애물 확인 후, 정지선1.5m 이내 선두 차량만 예약.
4. 부동소수점으로 4,900원의70%가3,429원으로 절삭되던 정산: 정수 계산으로3,430원 지급.

## 검증 범위

고속 안정성은 평평한 격리 시험장에서 검사했으며 모든 연석 충돌·사고 조건의 전복 방지를 보장하는 검사는 아니다. 급가속 검출은 물리 힘을 추가해 임계값을 넘겼고, 급제동은 실제 제동 입력으로 확인했다. 평지의 보통 가속에서 급가속 감점이 항상 발생하는 설정은 아니다.

승객 상태 검사에서는 차량을 지정 장소로 이동시켜 방향과 정산을 분리 확인했다. 전체56개 운송 경로를 사람이 직접 주행한 것은 아니다. 혼합 교통 검사는 유한한128초 구간의 진행 확인이며 무기한 교착 부재를 증명하지 않는다. 패드 매핑은 유지했으나 실물 패드 확인은 별도이다.

최종 교차로 예약 수정 뒤에는 영향을 받는 안정성·혼합 교통·교통 회귀를 다시 실행했고, 승객·카메라·기본 주행 검사는 바로 앞 빌드에서 통과했다. 빌드/실행 로그에 C# 컴파일 오류나 관리 예외는 발견되지 않았다.
