# 04. 보행자·보호구역·특별 보호

관련 F36~F46, X02~X03. 근거: [S01·S03·S12·S13·S16](12-sources-and-verification.md).

## 보행자 상태를 명시적으로 표현한다

`None / WaitingWithoutCrossingIntent / IntendsToCross / Crossing / FinishingCrossing / Unknown`을 기획 상태로 권고한다. 기존 `PedestrianState`와 통합할 때 실제 enum을 확인하고 새 상태를 무리하게 덮어쓰지 않는다. 사람의 시선·피부색·외형으로 의도나 장애를 추정하지 않고 NPC의 이동 목표·명시적 행동과 가시성을 이용한다.

| 장소·조건 | 기본 요구 행동 | 구분해야 할 예외·오판 |
|---|---|---|
| 일반 횡단보도, 통행 중 또는 통행하려는 보행자 | 횡단보도 앞 일시정지·보호 | 사람의 차도 진입 여부만을 유일 조건으로 삼지 않음 |
| 일반 횡단보도, 보행자·횡단 의도 없음 | 신호·다른 표지·주변 위험을 따름 | 모든 횡단보도에서 무조건 정지라는 교육 금지 |
| 어린이 보호구역 내 신호기 없는 횡단보도 | 보행자 유무와 관계없이 일시정지 | ‘밤이라 가중 처벌 시간 밖’이라는 이유로 의무 해제 금지 |
| 신호 변경 뒤 횡단 중인 사람 | 안전한 횡단 완료를 보호 | 차량 녹색이 켜졌다고 즉시 출발 강요 금지 |
| 무신호 교차로 또는 부근 횡단 | 보행자 통행 보호 | 횡단보도 도형이 없으면 보호 대상 아님으로 처리 금지 |
| 보도 없는 좁은 길·보행자우선도로 | 해당 조항에 따른 안전거리·서행, 필요시 일시정지 | 주차장·도로 외 장소도 관련 보호 의무 확인 |
| 주유소·식당·주차장 출입을 위한 보도 횡단 | 보도 횡단 직전 일시정지, 좌우 확인, 보행 통행 보호 | 시설 이용 요청이 보행자보다 우선하지 않음 |
| 예상치 못한 위험한 횡단 | 가능한 안전 대응·필요한 급제동 | 보행자 잘못을 이유로 방치하거나 위험 회피 제동에 승차감 벌점 부과 금지 |

보행 신호·차량 신호·전용 우회전 신호와 보행자의 실제 위치를 따로 기록한다. 무단횡단의 법적 책임이나 사고 과실비율까지 이 보호 관찰자로 확정하지 않는다.

## 특별 보호 상태

어린이·시각장애인 등 보호가 필요한 구체 상황은 법49의 적용 요건을 확인하여 시나리오 속 상태로 명시한다. 단순히 작거나 느린 캐릭터 모두를 법률상 특정 보호 대상으로 자동 분류하지 않는다.

통학버스는 어린이 탑승 표시, 승하차 점멸, 진행 방향, 차로 수·중앙분리 구조를 함께 모델링한다. F44의 일시정지·서행과 F45의 앞지르기 금지는 별개다. 일반 노란색 버스와 혼동하지 않는다. 긴급자동차 양보는 장소에 맞게 정지·우측 피양 등의 선택을 구성하며, NPC가 안전하게 비킬 공간도 함께 제공한다.

## 재미로 바꾸는 방식

보행자는 수익을 빼앗는 장애물이 아니라 관찰과 판단의 대상이다. ‘사람이 없는 일반 횡단보도’와 ‘사람이 없어도 정지가 필요한 보호구역 무신호 횡단보도’를 같은 도로 형상으로 비교하면 조건 차이를 학습할 수 있다. 승객이 재촉하더라도 정당한 정지 자체에는 서비스 불이익을 주지 않는다.

## 수용 조건

1. 횡단 의도 있음/없음/불명, 횡단 시작 전/중/완료, 가림막 있음/없음의 정상·위반 쌍.
2. 일반 구역/어린이 보호구역, 신호 있음/없음, 처분 가중시간 안/밖의 조합.
3. 시설 진입·진출 양방향, 두 번째 횡단보도, 이미 정지했으나 새로운 사람이 접근하는 경우.
4. 일반 보행자·연출 보행자 중복 생성 금지, NPC 텔레포트로 피할 수 없는 감점 금지.
5. 급제동 원인과 실제 위험을 연결해 필요한 회피 제동은 기존 M 감점에서 제외.

법적 금액·벌점은 위반 조항·장소에 따라 다르다. ‘보행자 보호’라는 하나의 이름에 동일한 벌점·과태료를 전역 적용하지 않는다.
