## 이 문서 묶음의 목적

게임에서 만날 수 있는 행동을 먼저 목록화하고, 법규·처분·시험·게임 평가를 서로 다른 기준으로 연결한다. 도로교통법 전체를 구현하자는 제안이나 모든 후보의 최신 법률 감수가 끝났다는 선언이 아니다. 실제 처분·면허시험을 대신하는 자료도 아니다.

## 다섯 장부를 합치지 않는다

1. **행동의 법적 평가**: 적용 조건·예외를 충족하는지. 위반/준수/관찰 보류/해당 없음.
2. **단속과 처분**: 적발 증거, 행위자 특정, 범칙금 또는 과태료 등 적절한 절차, 법정 벌점.
3. **도로주행시험**: 시험에만 적용되는 감점·실격과 반복 채점.
4. **장내기능시험**: 전용 코스의 조작·시간·검지선·실격 기준.
5. **게임 평가**: 기존 운전 점수, 승객 운전 만족도 M, 운임·PVP 결과.

예: 정지 중 기어 중립 여부에 대한 시험 감점을 일반 운행의 범칙금으로 바꾸지 않는다. 기존 게임의 제한속도 +3km/h·2초 관찰을 실제 단속 허용치로 설명하지 않는다. 한 게임 사건의 최대 감점 1회 정책도 실제 처분이나 시험의 중복 채점 원칙으로 확대하지 않는다.

## 현재 저장소와의 관계

검토 기준 커밋: `ec3bc4bcd066570643ef2d1b878052bbbffbbded`.

- 현재 플레이·배점의 단일 기준은 [주행·교통 기획](../content-design/01-driving-and-traffic.md)과 [기술 참조](../technical-reference/driving-evaluation-reference.md)다. 이 묶음은 이를 자동으로 대체하지 않는다.
- 기존 [법규 후보 62개 검토](../road-law-confusion-review.md)의 F 번호를 유지한다. 기존 코드의 L 번호와 F 번호는 서로 다른 식별자다.
- [기존 7개 영업 법규 구역](../eungye-in-service-law-zones.md)은 이미 존재하는 콘텐츠다. 실재 은계의 현장 규제를 인증한 데이터가 아니라, 은계 지형 위에 구성한 게임 상황이다.
- 기본 실행본은 `builds/EungyeTaxi/EungyeTaxi.exe`, 빌드는 `PrototypeBuild.BuildHybrid`. 싱글/PVP 통합 상태, 배포 파일·지도·저장 데이터는 이번 문서 작업으로 바뀌지 않는다.

## 적용 원칙

**P0** 기존 오판·중복·예외 보강 → **P1** 일상 영업에 반복 출현하는 신규 상황 → **P2** 특수도로·야간·전용 시험 모드 순으로 권고한다. 우선순위는 법률상 위험도나 전국 위반 빈도의 통계가 아니라 이 프로젝트의 개발 제안이다.

법령의 조회일, 공포일, 시행일은 다르다. 이 묶음의 2026-11-02는 조사일이다. 동적 현행 링크와 과거 개정 PDF를 함께 사용했으며, 전체 법령·모든 별표의 동일 시행일 스냅샷 대조는 완료하지 않았다. 실제 금액 차감이나 교육용 확정 판정은 해당 행의 원문·시행일·예외 재확인 후 활성화한다.
