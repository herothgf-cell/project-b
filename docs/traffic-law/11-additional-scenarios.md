# 11. 추가·보강하면 좋은 운전 상황 24개

아래는 **기획 제안**이다. 법적 근거는 [전체 규칙 목록](01-law-catalog.md), 실제 구현 연결은 [08](08-game-rule-mapping.md), 현행 규정의 확인 범위는 [12](12-sources-and-verification.md)에 따른다. 기존 콘텐츠를 신규 개발 완료처럼 표시하지 않는다.

**추천 순서:** 기존 신호·보행 판정의 오판 방지 → 안전한 승하차·시설 출입 → 보호구역·차로변경 → 긴급/기상/시험 확장. 이는 개발 효용 판단이지 실제 위반 빈도 순위가 아니다.

## A. 기존 장면을 더 정확하게 만드는 P0: 6개

| ID·상태 | 장면과 발생 조건 | 요구되는 선택·행동 | 비교할 반례와 필요한 보강 |
|---|---|---|---|
| SC01 기존 보강 | 전방 적색, 전용 우회전 신호 없음. 뒤차와 승객이 재촉 | 필요한 위치에서 정지 후 교통을 확인하고 우회전 | 사람 없는 상태라도 첫 정지는 필요. 교통 위험이 해소될 때까지 기다리는 행동에 불이익 금지. X02 |
| SC02 기존 보강 | 전용 우회전 적색인데 횡단보도는 비어 있음 | 전용 허용 신호까지 대기 | 정지 후 진행할 수 있는 SC01과 비교. 접근별 전용 신호 결합 필요. X03 |
| SC03 기존 보강 | 우회전 첫 횡단보도는 비었지만 회전 후 횡단하려는 사람이 나타남 | 두 번째 보호 기회를 다시 보고 정지 | 첫 정지의 면제 효과 없음. 사람을 갑자기 생성해 피할 수 없게 하지 않음. F36 |
| SC04 기존 비교 | 같은 형상의 교차로에서 적색 점멸/황색 점멸 | 적색은 정지, 황색은 다른 교통에 주의하며 진행 | 황색에 불필요한 강제 정지 판정 금지. 시선 관찰 불가하면 보류. F02~F03 |
| SC05 기존 비교 | 비보호 좌회전: 적색/녹색, 대향차 있음/없음 | 신호와 양보 조건을 모두 확인 | 녹색만으로 좌회전 우선권 부여 금지. 접근 가능한 틈을 AI가 제공. F04~F05 |
| SC06 기존 보강 | 녹색인데 출구 정체, 옆 차로 출구는 비어 있음 | 내 진로의 공간이 확보될 때까지 대기하거나 사전에 합법 경로 선택 | 다른 차로의 빈 공간을 내 출구로 계산하지 않음. 뒤늦은 돌발 장애와 구분. F06 |

이 6개는 현재 신호·우회전·법규 구역과 연결되는 개선안이다. 새로운 팝업 6개를 추가하자는 뜻이 아니며, 필요한 조건을 자연 운송 과정에서 읽을 수 있게 만드는 것이 목적이다.

### 우선 착수 묶음

첫 확장은 **SC07 + SC10 + SC08**을 권고한다. 각각 승하차, 기존 생활 거점, 일상 교차로와 연결되므로 별도 장거리 맵 없이 운송의 판단을 늘릴 수 있다. 단, 실제 부지·보도·표지 정보와 합법 대체 경로가 확보된 지점만 채택한다. PVP용 창작 도시는 같은 규칙을 명확히 읽히는 구역으로 먼저 검증하기 좋다.

## D. 모든 카드의 공통 이벤트 명세

각 카드에는 `관련 ruleId / 발동 구역·운송 단계 / 사전 안내 / 환경·NPC 준비 / 관찰 증거 / 준수·위반·예외·보류 / 기존 M 영향 / 단속 연계 / 싱글·PVP 차이 / 재현 seed`를 기록한다.

비교 상황은 같은 도로에서 한 조건만 바꾸는 방식이 좋다. 단순 정답 버튼보다 실제 정지·신호·경로·승하차 행동을 관찰한다. 초기에는 설명을 돕되 숙련 플레이에서 매번 진행을 중단하는 팝업을 강제하지 않는다. 현행 팝업 빈도·캠페인 진행 정책을 이 문서만으로 변경하지 않는다.

## E. 공정성·수용 기준

보행자나 차량이 피할 수 없는 위치에 갑자기 나타나면 그 사건을 위반 확정하지 않는다. 상황은 플레이어가 읽고 대응할 수 있는 시야와 거리를 확보한 뒤 활성화한다. 안전하게 배치하지 못하면 보류한다.

PVP에서는 상대 위치에 따라 시나리오를 몰래 유리하게 바꾸거나 봇의 정지 의무를 면제하지 않는다. 무리한 승객 요청을 안전하게 거절한 플레이어가 무조건 손해 보는 구조를 피한다. 법규를 지킨 결과, 현실 단속 결과, 승객 감정, 승패 기여를 별도로 설명한다.

카드마다 최소 정상/위반/예외/보류 4종, 사람/봇 입력, 반복·저장 복원·경계값 재현을 갖춘 뒤 구현 완료로 승격한다. 이 문서의 24개는 제작 추천 목록이며 신규 상황을 실행 코드에 추가한 결과가 아니다.
