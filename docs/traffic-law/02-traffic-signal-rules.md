# 02. 신호·교차로 판정 명세

관련: F01~F17, X01~X03. 근거: [출처 S01·S03·S13~S16](12-sources-and-verification.md). 아래는 구현을 위한 기본 규칙과 증거 요구사항이다. 현행 코드의 배점을 변경하지 않는다.

## 우회전 결정표

| 조건 | 요구 행동 | 금지되는 오판 |
|---|---|---|
| 우회전 전용 신호가 적색 | 허용 신호까지 대기 | 완전 정지를 한 번 했다는 이유로 우회전 허용 |
| 전용 신호가 허용 상태 | 해당 신호에 따르되 보행자·다른 교통 보호 | 화살표가 있으니 사람을 무시해도 된다는 판정 |
| 전용 신호 없음 + 전방 차량 적색 | 정지선, 횡단보도, 교차로 직전 등 적용 정지 위치에서 일시정지 후 다른 교통을 방해하지 않는 범위에서 우회전 | 보행자 없으면 처음부터 무정지 통과 |
| 전용 신호 없음 + 전방 차량 녹색 | 우측 가장자리를 따라 서행, 보행자·다른 교통에 필요한 양보 | 녹색이라는 이유만으로 모든 차량에 무조건 완전 정지 요구 |
| 횡단 중이거나 횡단하려는 보행자 | 해당 횡단보도 앞에서 일시정지하고 보호 | 보행자가 아직 차도에 발을 내딛지 않았다는 이유로 무시 |
| 처음 정지한 뒤 두 번째 횡단보도에 사람이 나타남 | 새 충돌·보호 기회를 다시 관찰하고 필요한 정지 | 교차로 입구에서 한 번 정지했으므로 이후 보호 의무 면제 |
| 신호 방향·전용 신호 연결이 불명확 | `Deferred`와 사유 기록 | 가장 가까운 신호등 색을 임의로 사용 |

보행 신호 색만을 우회전 허가 스위치로 사용하지 않는다. 전방 횡단보도와 우회전 후 횡단보도를 각각 모델링하고, 보행자가 신호 전환 뒤에도 횡단을 마치지 않았다면 보호한다. 현실 일시정지에 일률적인 ‘3초 정지 의무’를 만들지 않는다. 정지 인식 속도·유지 틱·수치 오차는 게임 관측 설정으로만 표시한다.

## 교차로 규칙표

| 상황 | 준수 조건 | 판정에 필요한 입력 | 정상 반례 |
|---|---|---|---|
| 적색 직진 | 법정 정지 위치에서 대기 | 접근 차로, 실제 진행 신호, 정지선/교차로 경계, 차량 앞부분 이동 궤적 | 다른 방향만 적색인 교차로 |
| 황색 전환 | 진입 전 정지 / 이미 진입한 경우 신속하게 진출 | 황색 전환 시각과 선·교차로 진입 시각, 정지선 유무 | 정상 신호로 진입한 뒤 교차로 안에서 황색이 됨 |
| 적색 점멸 | 완전 정지 후 주의 진행 | 점멸 종류, 정지 기록, 교차 교통 | 정지 후 안전하게 진행 |
| 황색 점멸 | 다른 교통에 주의해 진행 | 점멸 종류, 위험/표지 상태 | 다른 정지 의무 없이 안전하게 통과 |
| 비보호 좌회전 | 허용 표지+녹색+대향 교통 양보 | 접근별 표지, 차량 신호, 대향 직진/우회전 궤적 | 녹색·대향차 없음·보행자 없음 |
| 꼬리물기 | 진입해도 교차 교통을 막지 않을 출구 공간 확보 | 차량 길이, 출구 점유, 진입 순간의 예측 가능한 정체 | 정상 진입 뒤 예측 어려운 돌발 장애물 발생 |
| 무신호 교차로 | 서행과 조건별 양보; 시야 불량·교통 빈번 등 정지 조건 따로 적용 | 신호 운영 여부, 도로 폭, 도착/진입 순서, 진행 방향, 표지 | 적법하게 먼저 진입한 차가 나중 차에게 무조건 양보하도록 하지 않음 |
| 회전교차로 | 진입 전 서행, 회전 차량 양보, 반시계 통행 | 진입/회전 차로, 양보선, 회전 차량 궤적 | 이미 회전 중인 차의 진출을 새 진입차가 막지 않음 |
| 경찰 수신호 | 적법한 교통정리자의 지시를 적용 | 권한 역할, 지시 내용·방향, 신호기와 충돌 | 택시 승객의 손짓은 교통정리 지시가 아님 |

황색은 특히 법령·판례의 사실관계가 중요하다. 감속 한계가 곧 법적 면책이라는 안내를 하지 않으며, 시점이나 경계가 불명확하면 현재처럼 보류한다. 출구 정체 때문에 뒤늦게 신호가 바뀐 경우도 ‘어느 시점에 어떤 규칙이 성립했는지’를 분리한다.

## 사건의 시작과 종료

`접근 식별 → 신호/표지 스냅샷 → 정지 확인 → 진입 → 회전/횡단 위험 → 진출 → 확정`을 권고한다. 특정 사건을 한 프레임씩 새 위반으로 생성하지 않는다. 처음의 적색 진입은 나중에 녹색이 되어도 지우지 않는다. 반대로 정지선 부근에서 기다리는 동안 정당하게 신호가 바뀐 뒤 진입한 것을 예전 적색으로 처벌하지 않는다.

현재 `DrivingLaw`와 `ServiceLawZones`/`ConfusionPractice`의 소유권 분리를 유지한다. 같은 교차로 사건을 일반 관찰자와 연출 관찰자가 동시에 기록하지 않아야 한다.

## 최소 수용 테스트

- 동일 접근에서 차량 신호/우회전 전용 신호/보행 상태를 조합한 허용·위반 쌍.
- 정지선 전후 한 물리 틱, 저프레임 고속 통과, 차체 앞부분과 중심점 차이, 지도 이동/텔레포트.
- 우회전 전에 정지했으나 전용 적색을 진행한 경우, 두 번째 횡단보도에서 추가 양보한 경우.
- 교차로에 들어오기 전 적색과 이미 진입한 뒤 적색의 구분, 황색 증거 부족 보류.
- 동일 사건 재진입·저장 복원·재시작에서 중복 감점/준수 회복 없음.

어느 경우에도 정지 버튼을 누른 사실만으로 법규 준수 점수를 지급하지 않는다. 실제 법적 처분 종류는 이 표에서 추론하지 않고 [07](07-penalties-and-points.md)의 별도 매핑으로 결정한다.
