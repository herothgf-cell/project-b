# 01. 게임에서 발생 가능한 교통규칙 총목록

기준: 2026-11-02 조사. [출처 S01~S20](12-sources-and-verification.md). **62개 기존 후보 + 6개 기존 핵심 규칙/사고 후 조치 + 8개 택시 항목 = 76개 관리 항목**이다. 항목 수는 법률상 위반 종류 수가 아니며, 한 항목에 여러 적용 조건이 들어갈 수 있다.

## 읽는 방법

`법`은 도로교통법, `영`은 시행령, `규칙`은 시행규칙이다. 조문은 구현 시 확인할 근거 위치를 연결한 것으로, 해당 조문의 모든 항·단서·판례를 전수 감수했다는 뜻이 아니다. 아래 허용/위반은 기본 원칙이며 긴급피난 등 일반적 위법성 판단까지 자동화하지 않는다. 각 규칙의 실제 처분은 [07](07-penalties-and-points.md), 구현 상태는 [08](08-game-rule-mapping.md)를 별도로 본다.

P0=기존 판정 정밀화, P1=일상 영업 우선 확장, P2=특수 상황/추가 시스템 이후. 기존 F 번호는 [이전 검토](../road-law-confusion-review.md)와 같은 의미로 유지한다.

## 공통 출시 차단 조건

각 행의 자동 판정은 (1) 유효한 원문 버전, (2) 예외 조건, (3) 지도·신호·상태 증거, (4) 정상/위반/경계/보류 테스트가 준비된 뒤 활성화한다. 나머지는 교육 설명 또는 관찰 보류로 남긴다. **목록에 있음 = 구현됨 = 현실 전체와 일치함**이 아니다.
