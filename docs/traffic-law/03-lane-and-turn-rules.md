# 03. 차로·회전·속도·차간거리

관련 F14~F35, X04~X05. 근거: [S01~S03·S07~S09](12-sources-and-verification.md).

## 차로 판정에 필요한 데이터

도로 방향, 차로 중심선/폭, 중앙선과 차선의 구분, 실선·점선·혼합선의 어느 측인지, 차종 제한, 표지·시간·기상 조건, 실제 연결 차로를 분리한다. OSM/지도에 값이 없다는 사실은 법적 제한이 없다는 뜻이 아니다. 현실 현장 미확인과 창작 PVP 규제를 명시적으로 구별한다.

| 규칙 | 허용·위반의 핵심 | 구현 주의 |
|---|---|---|
| 중앙선·역주행 | 우측 통행 원칙과 중앙선·일방통행을 위반하지 않음 | 역주행 관측 임계와 실제 법적 성립은 다름. 교차로 회전·주차 후진·지도 투영 오류 제외 |
| 진로변경 금지 | 선 종류·금지 표지와 적용 방향 확인 | 모든 교차로의 모든 차로변경을 같은 이유로 일괄 위반 처리하지 않음 |
| 진로변경 방법 | 다른 차의 정상 통행을 방해할 우려가 있으면 변경하지 않음 | 상대차의 급제동 하나가 아니라 주행 궤적·충돌 예상·관찰 가능성 함께 기록 |
| 방향지시 | 일반도로는 행위 지점 전 30m, 고속도로는 100m의 사전 신호 등 시행령 별표2 조건에 맞추고 행위 종료까지 유지 | 거리 단위와 차로변경 시작점을 확정. 시험의 종료 후 10m 기준은 별도 |
| 끼어들기 | 법23의 보호 대상 정지·서행 차량 앞으로 끼어들지 않음 | 정당한 합류·일반 차로변경을 자동으로 새치기 처리하지 않음 |
| 앞지르기 | 앞지르기 정의, 방법, 금지 장소·시기를 함께 판단 | 옆 차로 차가 더 빨리 지나갔다고 항상 앞지르기 위반은 아님 |
| 유턴 | 위치·신호·보조 표지의 조건 및 타 교통에 대한 위험/방해 여부 | ‘유턴금지 표지가 안 보임=어디서나 가능’, ‘표지 없음=전국 무조건 금지’ 모두 금지 |
| 버스전용차로 | 운용시간·차종·예외를 확인 | 택시 승하차를 위한 일시 통행 예외와 그 장소의 정차 허용 여부는 별개 |

방향지시 사전 거리의 구체 적용 행위와 예외는 영21·별표2를 데이터화할 때 다시 대조한다. 자동조향 보조가 회전했다는 이유로 플레이어의 방향지시 입력 의무를 임의 면제하지 않는다. 단, 조작 없는 현재 모드에 새 감점을 먼저 붙이지 않는다.

## 택시의 버스전용차로 예외

승객을 태우거나 내려주기 위한 일시 통행은 시행령 제10조의 조건을 확인한다. 다른 전용차로 통행 차량의 통행 방해 여부와 목적 달성 후 이탈을 함께 본다. 이를 버스전용차로 장거리 주행·정류소 임의 정차의 허가로 해석하지 않는다. 도로 유형 및 실제 규제 정보가 없으면 예외 자동 판정을 켜지 않는다.

## 속도 규칙

속도 근거는 법17과 **시행규칙19**다. 이전 설명에서 시행령을 속도 기본 기준의 주된 위치로 적은 부분은 이 문서에서 바로잡는다. 구간의 실제 지정 제한을 우선 확인하고 시내 모든 도로를 일률적으로 50km/h로 고정하지 않는다.

| 상황 | 검토할 규칙 | 구현 입력 |
|---|---|---|
| 일반 지정속도 | 유효한 최고·최저 제한 | 도로 구간·방향·표지 시작/종료 |
| 보호구역·시간제 | 현재 구간의 유효 제한 | 구역과 표지의 시간 조건; 처분 가중시간과 분리 |
| 비로 젖은 노면 / 20mm 미만 적설 | 최고속도 감속 기준 20% | 단순 비 이펙트가 아니라 법정 노면·적설 조건 |
| 가시거리 100m 이내 등 해당 악천후 / 결빙 / 20mm 이상 적설 | 최고속도 감속 기준 50% | 시야·노면·적설 및 적용 조건 |
| 가변형 속도제한 표지 | 해당 조문의 적용 관계 확인 | 표지 유효값·시간, 중복 감속 방지 |

위 수치는 S07의 공식 법령 설명을 정리한 것이다. 날씨 기능을 넣을 때 규칙19 원문과 가변표지의 관계를 재검증한다. 고속 초과운전의 형사처벌 영역을 일반 범칙금 표로 무제한 연장하지 않는다.

## 안전거리·서행

안전거리는 앞차가 갑자기 정지해도 충돌을 피할 수 있는 필요한 거리라는 취지다. ‘무조건 2초’, ‘속도의 숫자만큼 미터’는 교육용·시뮬레이션 기준 후보이지 모든 도로의 법정 수치가 아니다. 서행도 위험 시 즉시 정지할 수 있는 느린 속도라는 개념으로, 게임 전체에 10km/h 하나를 법적 기준으로 부여하지 않는다.

제동 성능·노면·시야·앞차 상태를 이용한 안전 여유는 **게임 경고**에 사용할 수 있다. 이 수치만으로 현실 법규 위반·법정 벌점을 자동 확정하지 않는다.

## 현재 코드 보존과 QA

`DrivingLaw.CheckEditorSpeed()`의 제한+3km/h·2초, `ObserveWrongWay()`의 2초·8m·전진/차로 신뢰도 필터는 현재 게임 관측 규칙이다. 변경하려면 기존 회귀와 플레이 감각을 검증하는 별도 작업이 필요하다.

필수 비교: 실선의 양측/혼합선 방향, 동일 신호 다른 차로, 허용 유턴 경계, 정상 합류/금지 끼어들기, 동일 초과속도에서 구역·차종·시간 차이, 긴급 회피 제동, km/h와 m/s 변환, 지도 재생성 후 차로 ID 변경. 관찰 불충분한 경우 준수 보상을 주지 말고 보류한다.
