# 10. 장내기능시험 기준

대상: **제1종 보통연습면허 및 제2종 보통연습면허**. 대형·특수·이륜 면허의 코스·배점을 섞지 않는다. 근거: 시행규칙 제66조·별표24의 **2026-02-24 개정 PDF**, 코스 자체는 별표23 추가 확인. [S03·S04](12-sources-and-verification.md)

100점 만점에서 **80점 이상**, 별도 실격 사유가 없어야 합격한다. 아래 숫자는 장내기능시험 전용이며 일반 도로에서의 법정 벌점·속도 허용치가 아니다.

SK-D02·D07 등 한 항목에 여러 감점 조건이 있다. 각 조건을 어떤 발생 단위로 중복 채점할지 별표의 문구와 검정 세부 운영을 확인한다. 표의 10점을 읽고 모든 위반 조합을 무조건 한 번만 감점하거나 무조건 세 배 감점한다고 가정하지 않는다.

전체 제한시간을 임의의 전국 공통 숫자로 만들지 않는다. 코스 설계·별표23과 연결한다. 바퀴 접촉 기준과 차체 중심점 기준은 다르다.

## 4. 제작 제안

현재 은계 영업 지도에 직각주차 검지선·돌발등·경사로 시험 시간을 억지로 붙이지 않는다. 별도 연습장에 `시작 준비 → 기본조작 → 경사로 → 교차로/주차/가속 등 코스 → 종료`를 배치하고 순서·형상은 별표23 및 제작할 시험장 프로필에 맞춰 확정한다. 이 흐름은 제작 제안이지 전국 모든 실제 시험장의 동일 순서라는 뜻이 아니다.

현재 게임에 없는 벨트·기어·시동·와이퍼·전조등·비상등·주차브레이크는 조작 UI와 상태를 먼저 만들어야 한다. 자동변속·수동변속·전기차 프로필을 섞지 않는다. 조향 보조 연습과 시험 모사를 분리한다.

## 5. QA 경계값

시간: 돌발 2초, 정지 후 비상등 3초, 주차 120초 및 추가 120초, 전체 초과 5초, 출발/경사로 30초의 경계 직전·동일·직후. 공간: 0.5m/1m 뒤밀림, 바퀴 검지선/연석 접촉, 앞범퍼 정지선. 속도: 가속구간 20km/h와 비가속구간 제한의 서로 다른 비교 조건.

일시정지 메뉴에서 시험 시간을 정지할지, 창 전환·재시작 시 성적을 무효화할지 명시한다. 미구현 입력을 자동 통과시켜 실제 기능시험과 동일하다고 표시하지 않는다. 이번 작업에서는 연습장·채점 코드를 추가하거나 실행 검증하지 않았다.
