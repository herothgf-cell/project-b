# 06. 택시 영업 규칙과 서비스 평가

관련 TX01~TX08. 출처 [S17·S18](12-sources-and-verification.md). 택시운송사업의 발전에 관한 법률 제16조를 중심으로 여객자동차 운수사업법·운임 공고·사업구역·운송약관 등을 함께 확인한다. 택시 관련 처분을 도로교통법 범칙금 하나로 합치지 않는다.

## 항목별 기획

| ID | 기본 규칙 | 게임에서 필요한 증거 | 법규로 단정하지 않을 것 |
|---|---|---|---|
| TX01 승차거부 | 정당한 사유 없는 승차거부 금지 | 실제 승차 요구, 영업 상태, 거절 사유, 제공 가능한 안전 대안 | 호출 미수락·게임 메뉴 취소를 항상 현실 승차거부로 간주 |
| TX02 중도 하차 | 정당한 사유 없는 중도 하차 강요 금지 | 계약된 목적지, 하차 결정 주체, 안전 문제·상황 기록 | 모든 경로 변경·안전한 정차를 중도 하차 위반으로 간주 |
| TX03 운임 | 부당한 운임·요금 수수 금지 | 지역/시간별 운임, 미터 상태, 합의 경로, 도로 통제·승객 요청 | 빠른 길보다 길었다는 사실만으로 고의 우회·부당요금 확정 |
| TX04 합승 | 금지 원칙과 적법한 플랫폼 중개 예외 구별 | 중개 방식, 승객 동의, 안전·보호 요건, 해당 법령 버전 | ‘모든 합승은 불법’ 또는 ‘동의만 있으면 항상 합법’ |
| TX05 결제·영수증 | 법정 조건에서 요구에 응함 | 장치 설치, 요구·응답, 실제 결제 장애와 대응 | 장치 장애 한 번을 고의 거부로 확정 |
| TX06 사업구역 | 출발·도착·영업 형태에 맞는 규칙 적용 | 면허 사업구역, 시계외 운송 조건, 지역 공고 | 시 경계를 넘은 모든 운송을 불법 영업으로 처리 |
| TX07 자격·차량 | 운전면허와 별도 운수종사·사업 요건 확인 | 종사 자격, 차량 용도, 사업 상태 | 게임 운전점수만으로 실제 택시 종사자격을 대체 |
| TX08 승하차 안전 | 안전한 정차·개문·출발, 금지 장소 회피 | 정차 장소, 속도, 문, 주변 보행자·자전거, 벨트 상태 | 승객이 급하다고 법규 위반을 정당화 |

TX04의 플랫폼 예외와 TX06의 구체 지역 요건은 현행 본문·하위 규정·지역 공고를 추가 대조해야 한다. 이번에는 후보와 입력 요건을 남기고 금액·자격정지 기간을 확정하지 않는다. 과거 지자체 사례의 ‘1차·2차·3차’ 수치를 현재 전국 공통값으로 복사하지 않는다.

## 법규와 서비스 만족도를 분리

친절한 설명, 짐 싣기 도움, 적절한 실내 온도, 조용한 운행, 쾌적한 가감속은 좋은 게임 소재지만 모두 독립된 교통법규 위반/준수 항목은 아니다. 승객이 싫어한 선택이라고 곧 불법은 아니다. 반대로 높은 팁·만족도가 법규 위반을 지우지 않는다.

현재 운전 점수의 운임 보정, M과 최종 승객 만족도, 요청 수락·거절 정책은 기존 콘텐츠 문서를 유지한다. 이 조사로 실제 택시의 법정 운임이 운전자 평판에 따라 달라진다고 설명해서는 안 된다. 기존 운임 보정은 게임 경제 규칙이다.

## 우선 제작할 영업 상황

‘정류소 앞 하차 요청 → 안전한 대체 위치 제안’, ‘길을 놓침 → 합법적 재탐색’, ‘카드결제 요청 → 정상 결제·영수증’, ‘문 옆 자전거 → 개문 대기’가 일상 영업과 직접 연결된다. 승차거부·부당요금은 실제 거절 사유나 우회 원인을 기록할 수 있게 된 뒤 판정한다.

PVP에서는 실제 호출 경쟁과 운송 계약을 구분한다. 선택하지 않은 공용 호출마다 승차거부 벌점을 주지 않는다. 플레이어와 봇의 응대 정책을 맞춘 후 공유 규칙을 적용하며, 현재 PVP 승객 요소가 전부 싱글과 동등하게 검증됐다고 표시하지 않는다.
