# 05. 주정차·택시 승하차 장소

관련 F47~F54, TX08. 근거: [S01·S03·S12·S19](12-sources-and-verification.md). 구간별 실제 현장 규제와 지자체의 적법한 허용 표지를 확인해야 한다.

## 먼저 구별할 세 가지

- **신호·교통정리·위험 방지를 위한 정지**와 **승하차·대기 목적 정차**를 구분한다.
- 정차의 5분 기준은 ‘어디에서나 5분까지 허용’이라는 뜻이 아니다. 운전자가 떠나 즉시 운전할 수 없는 상태 등은 지속시간만으로 정차가 되지 않는다.
- **정차·주차 모두 금지**와 **주차만 금지**는 다르다. 비상등·택시 표시·승객의 요청이 금지를 해제하지 않는다.

## 장소별 목록

아래 거리 수치는 법32·33의 규정 위치를 연결한 기본 조사값이다. 경계 측정과 개별 단서까지 확인하기 전에는 자동 단속을 활성화하지 않는다.

## 승하차 지점 선택 명세

`정차 가능 구역 → 실제 공간 확보 → 보행/자전거 통로 확인 → 충분한 정지 → 문 개방 안전 → 승하차 → 문 닫힘 → 방향지시·후방 확인 → 출발` 순서로 분리한다.

승객 목적지 좌표가 금지 장소에 있으면 주변 합법 승하차 지점으로 이동하는 대안을 제공한다. 목적지에 가까운 불법 위치만 완료 트리거로 두지 않는다. 불법 장소 요청을 정중히 거절하고 안전한 대안을 제시하는 행동은 기존 기획의 정당한 거절·합법 대기 무감점 원칙과 연결한다.

## 추천 비교 장면

- 버스정류소 앞에서 즉시 내려 달라는 요청 / 조금 지난 합법 공간으로 안내.
- 보호구역 안 임의 정차 / 표시된 승하차 허용구역의 유효 시간·방법 충족.
- 비상등을 켠 차로 중간 하차 / 안전한 가장자리 정차.
- 횡단보도 앞 신호대기 / 같은 장소에서 승객을 기다리며 정차.
- 주차브레이크 없는 경사지 종료 / 굴림 방지 후 종료.

이 장면의 승객 인내·추가 이동 거리·일시 점유는 게임 디자인 변수다. 지자체 CCTV의 촬영 간격이나 신고 접수 간격을 합법적 유예시간으로 안내하지 않는다.

## QA 경계

차량 중심만이 아니라 앞뒤 차체가 금지 영역에 걸치는지 확인한다. 거리 경계 4.9/5.0/5.1m와 9.9/10.0/10.1m는 **센서 테스트용**이며 현실 측정 관행을 인증한 수치가 아니다. 시간제 표지 경계, 탑승 완료 전 출발, 문 개방 중 자전거 접근, 위험 회피로 정지한 경우를 반드시 포함한다.
