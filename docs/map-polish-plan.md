# 은계 도로·맵 정비 순서

2026-10-21 제안. 현재 지도 데이터와 생성 방식을 기준으로 한다.

1. 시작 주차장→주유소→주요 승하차의 짧은 시험 동선1개를 먼저 선정한다. 전역을 한꺼번에 꾸미기보다 같은 동선에서 차로/외형/교통을 비교한다.
2. 도로별 차로수·폭·통행방향·회전 연결·속도 설정을 공통 차로 그래프에 보정한다. 내비·H·NPC·차선 표시가 함께 같은 데이터를 사용해야 한다.
3. 교차로 모서리 곡선·정지선·횡단보도·인도 경계를 정리한다. 택시 저속 회전과 NPC 2대 연속 회전을 자동 주행/수동 플레이로 확인한다.
4. 도로/인도에 침범한 건물은 원본ID를 기록하고 표시·충돌·도로 조회에서 함께 보류한다. 외형만 지워 보이지 않는 벽을 남기지 않는다. 실제 외관 작업은 그 다음이다.
5. 표지·신호는 접근 방향에서 미리 보이는지 확인한다. 실제 확인/자료 기반/게임 창작을 구분하고 출처·확인일을 남긴다.
6. 보정은 원본 raw/생성 결과에 즉석 덮어쓰지 말고 별도 구간ID 기반 설정으로 관리한다. 재생성 후 적용되도록 생성 파이프라인에 포함하고 입력 변경 시 manifest 해시도 갱신한다.

필요 자료: 교차로ID 또는 지도 위치, 접근 방향, 차로 화살표/중앙선/정지선/표지 사진과 촬영일. 확인 못한 구간은 임시 설정 유지. 우선 추천 동선은 현재 시작점·주유소1·승하차1~5를 연결하는 구간이며 실제 주행 경로를 확인한 뒤 범위를 확정한다.

이번 기능 작업에서는 지도 원본과 차로 연결을 임의로 변경하지 않았다. 현장 자료 없는 곳을 실제와 같다고 표시하지 않는다.

자료 확인: [정밀지도 제공 범위](work-history/2026-10-21-hdmap-coverage-check.md)에 따르면 현재 확보 자료는 국도42 등 일부이고 은계 T1~T3 차로 중심선은 없다. 해당 구간은 현장 근거 전까지 임시 설정으로 유지한다.
