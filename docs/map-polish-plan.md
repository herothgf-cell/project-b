## 2026-10-22 추가 계획: 교차로 진입 차로별 진행 방향

교차로는 도로 전체의 차로 수만 확인해서는 부족하다. **각 진입 방향의 각 차로**에 대해 좌회전·직진·우회전·겸용(좌회전+직진 등)·유턴 허용 여부를 따로 확인한다. 순번은 운전자가 교차로를 향해 볼 때 왼쪽부터 매기고, 게임의 차로ID·원본 도로ID와 함께 기록한다. 좌회전 차로가 교차로 앞에서 새로 생기거나 없어지는 시작·종료 위치도 확인한다.

| 교차로ID | 진입 도로ID·접근 방향 | 진입 차로ID·왼쪽부터 순번 | 노면 화살표·표지·차선 | 허용 진행 방향 | 연결될 출구 차로ID | 거리뷰 촬영월·확인 지점 | 상태 |
|---|---|---|---|---|---|---|---|
| 검토 시 입력 | 검토 시 입력 | 검토 시 입력 | 보이는 것만 기록 | 좌회전/직진/우회전/겸용/유턴/미확인 | 검토 시 입력 | 검토 시 입력 | 확인/추정/미확인 |

담당자가 각 접근로의 정지선 전후 거리뷰를 양방향으로 이동하며 화살표, 차선, 중앙 분리시설, 표지와 교차로 건너편 연결을 대조한다. 사진에서 가려진 차로·오래된 촬영분·입체 교차로의 다른 층은 `미확인`으로 둔다. 차량이 실제로 한 번 회전하는 장면이나 차로 위치만으로 허용 방향을 확정하지 않는다. 실제 차로별 연결을 확인한 구간부터 내비·H·NPC·차선 표시가 사용하는 공통 차로 그래프에 반영하고, 진입 차로에서 금지된 출구로 경로가 생성되지 않는지 검사한다. 현재 내부 도로의 임시 회전 연결을 실제 규제로 표시하지 않는다.

### 교차로 전체 거리뷰 점검표

네이버 거리뷰를 **주요 현장 대조 수단**으로 사용한다. 우선 동선의 교차로부터 시작하고, 이후 게임 맵의 나머지 교차로도 ID 목록을 만들어 누락 없이 순차 점검한다. 교차로 한 장면만 보지 않고 모든 진입 방향에서 교차로 전방, 정지선 근처, 통과 후 출구를 이동하며 살펴본다.

| 교차로·진입 방향마다 기록할 것 | 확인 내용 |
|---|---|
| 도로·차로 | 진입/출구 차로 수, 차로 증감 위치, 중앙선·차로 경계선(실선/점선), 좌·직·우·겸용·유턴 차로, 진입 차로와 출구 차로 연결 |
| 노면 마크·규제 | 방향 화살표, 안내 문자·유도선, 정지선, 횡단보도, 속도·어린이보호구역·버스/자전거 등 보이는 노면표시 |
| 시설·주변 | 방향별 신호등, 도로 표지판, 중앙 분리시설, 보도·연석·안전 울타리, 건물명·주요 출입구 |
| 근거·상태 | 교차로ID, 접근 방향, 거리뷰 촬영 연월, 확인한 촬영 지점/파노라마 링크, 보이는 사실과 가려짐·오래된 장면·다른 높이 도로 등 미확인 사유 |

점검 결과는 `확인/추정/미확인`으로 나누고 교차로별 **전체 진입 방향 수·검토한 방향 수·미확인 방향 수**를 집계한다. 거리뷰 화면에서 신호의 실제 운영 방식이나 시간대별 규제, 정확한 치수까지 판독할 수 없으면 확정하지 않는다. 거리뷰 확인 후 게임 설정을 바꾸는 단계와 게임 안에서 자동 주행·수동 플레이로 작동을 검사하는 단계는 별도로 기록한다.

1. 시작 주차장→주유소→주요 승하차의 짧은 시험 동선1개를 먼저 선정한다. 전역을 한꺼번에 꾸미기보다 같은 동선에서 차로/외형/교통을 비교한다.
2. 담당자가 게임의 교차로·도로 좌표를 네이버 지도에서 직접 찾아 주변 거리뷰를 양방향으로 살펴본다. 촬영 시점과 화면에서 확인한 차로 수·중앙선·회전 화살표·정지선·횡단보도·인도·표지·건물명을 구간ID별로 기록한다. 거리뷰에 가려졌거나 촬영 시점이 오래된 항목은 `미확인`으로 남긴다.
3. 거리뷰에서 확인한 내용과 좌표를 가진 NGII·OSM 도형을 대조한 뒤 도로별 차로수·폭·통행방향·회전 연결·속도 설정을 공통 차로 그래프에 보정한다. 내비·H·NPC·차선 표시가 함께 같은 데이터를 사용해야 한다.
4. 교차로 모서리 곡선·정지선·횡단보도·인도 경계를 정리한다. 택시 저속 회전과 NPC 2대 연속 회전을 자동 주행/수동 플레이로 확인한다. 이는 거리뷰 확인과 다른, 게임 작동 검사다.
5. 도로/인도에 침범한 건물은 원본ID를 기록하고 표시·충돌·도로 조회에서 함께 보류한다. 외형만 지워 보이지 않는 벽을 남기지 않는다. 실제 외관 작업은 그 다음이다.
6. 표지·신호는 접근 방향에서 미리 보이는지 확인한다. 실제 확인/자료 기반/게임 창작을 구분하고 출처·확인일을 남긴다.
7. 보정은 원본 raw/생성 결과에 즉석 덮어쓰지 말고 별도 구간ID 기반 설정으로 관리한다. 재생성 후 적용되도록 생성 파이프라인에 포함하고 입력 변경 시 manifest 해시도 갱신한다.

확인 입력: 게임의 교차로ID 또는 지도 좌표, 접근 방향. 담당자가 거리뷰에서 보이는 시설과 촬영일을 직접 기록한다. 사용자가 사진을 별도로 준비해야 한다는 뜻은 아니다. 확인 못한 구간은 임시 설정 유지. 우선 추천 동선은 현재 시작점·주유소1·승하차1~5를 연결하는 구간이며 실제 주행 경로를 확인한 뒤 범위를 확정한다. 거리뷰 사진 자체는 게임 자료로 복제하지 않는다.
