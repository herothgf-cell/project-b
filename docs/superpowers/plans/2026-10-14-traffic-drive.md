# T1–T2 교통·시점 확장

사용자 요청을 기존 시제품의 확장 범위로 실행한다. Unity 2022.3.62f2와 원본 보존 방식을 유지한다. 이번 신호·차선은 현재 실제 규칙이 아니라 게임용 설정이다.

## 설계

- T1·T2 접근부에 중앙선/차선, 정지선, 횡단보도와 방향별 신호등을 배치한다. 중심 축은 원본 T1–T2 연결 방향이며 횡단 축은 각 교차로에 연결된 20m 도로 방향을 따른다.
- 주도로 녹색 12초, 황색 3초, 전적색 2초, 교차도로 녹색 10초, 황색 3초, 전적색 2초의 32초 순환. 두 교차로는 시차를 둔다. 보행자·좌회전 AI는 이번에 포함하지 않는다.
- 일반 차량 8대를 직진 경로에 배치한다. 우측 통행, 신호 정지, 앞차/택시 감지, 정지거리 감속, 구역 끝 재순환을 구현한다. 이미 교차로에 진입한 차량은 빠져나온다.
- Q/E 또는 패드 LB/RB로 좌/우 방향지시등을 토글한다. 반대쪽을 켜면 전환되고 같은 키를 다시 누르면 꺼진다. 외부 앞뒤 램프와 HUD에 표시하며 자동 해제는 이번 범위에서 제외한다.
- C/패드 Back으로 1인칭·3인칭 전환, B/패드 오른쪽 스틱 클릭 유지 시 후방 확인. 1인칭은 운전석 위치+간단한 대시보드이며 차체 외부는 카메라에서 숨긴다. 기본은 기존 3인칭이다.

## 구현 순서

1. TrafficRules 순수 C# 신호/정지거리/깜빡이 정책 테스트 RED→GREEN.
2. TrafficSystem/TrafficCar: 차선·횡단보도·신호 표현, 경로와 차량 제어. 기존 WorldBuilder 임시 중앙선은 교차로 주변에서 제거한다.
3. TaxiSignals/DrivingCamera: 방향지시등, 시점 전환, 뒤보기, HUD 조작 안내. DriveSession에서 연결한다.
4. TrafficSmokeTest: 신호 정지·재출발, 장애물 정지, 일시정지, 카메라 모드/뒤보기, 깜빡이와 시점별 화면 캡처. 기존 주행 회귀 검사는 차량 교통을 비활성화한 별도 모드로 유지한다.
5. Windows 빌드·실행·코드 리뷰·화면 검토, 문서 갱신 후 직접 실행.

## 완료 기준

신호의 양방향 동시 녹색 없음, AI의 정지선 정지 및 녹색 재출발, 택시/앞차 감지, 카메라 2종 캡처, 깜빡이 켜기·전환·끄기, 일시정지, 빌드·기존 차량 검사 통과. 실물 패드는 미검증으로 구분한다.

## 실행 결과

1~5 구현 및 검증 완료. 코드 리뷰에서 지적된 운전석 정지선 신호 가시성을 건너편 신호 배치로 수정했다. 초기 택시는 정지선 뒤로 이동했고 리셋 위치의 AI 겹침을 방지했다. 교통 자동 검사와 기존 운전 회귀 모두 `success=True`. 상세 결과는 `docs/traffic-drive-validation.md`와 `artifacts`의 로그·PNG 참조.
