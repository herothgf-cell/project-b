# 승객 대화 UI·스크립트 정리

사용자 첨부 시안과 직접 구현 요청을 적용한다. 추가 디자인 승인·반복 리뷰는 생략하고 최소 검증한다.

1. 요청/유형/실제 상황 대화를 공통 흰 카드, 파란 승객 말풍선, 테두리·배경·키 표시가 있는 선택 버튼으로 표시한다. 대사와 효과를 분리하며 비어 있는 효과는 `효과 없음`으로 표시한다.
2. 선택은 운행 중에도 가능하다. 입력 우선순위/동일 프레임 중복 방지/일시정지·지도 모달·도착 잠금은 유지한다. 실제 적재·정리·재고정·용무는 기존 안전 정차 조건에서만 진행한다.
3. 유형별/상황별 기사 응답을 구체적인 대사로 작성하고 실제 선택 후 노출한다. 수치 효과·작업 조건은 대사와 분리한다. 음악·에어컨·창문 실제 조작은 보류한다.
4. 도움말은 ↑ 가속, ↓ 감속·정차 후 후진, ←/→ 조향으로 통일한다. 기존 WASD 입력은 유지한다.
5. 변경된 실제 응답 경로·정차 작업 유지·일시정지/중복 보호를 기존 전용 저장 probe에서 확인한다. 최종 BuildHybrid와 대화 화면만 확인하고 실행 폴더/manifest/이력을 갱신한다. 전체 캠페인·장시간·다른PC 검증은 반복하지 않는다.
