# HUD 사용성 후속 구현 계획

사용자 승인: 첨부1~5, 밝은 컨셉, 속도계/퇴근 피드백, 숫자 선택키, 설정 이동, main 커밋·push.
1. 빈차 안내 제거·승객 카드 호출 버튼, 내구도 오른쪽 수리 아이콘. 생활거점은 클릭만 열기. 연료/포만25 이하, 피로75 이상, 수리50 이하 레드닷.
2. 흰색/연청색 카드와 남색 글씨. PVP 현황 좌측4행, 상황 안내 우측. 수동 경로 선택 숨김; 승객의 작성된 요청/경로 효과 유지.
3. 속도 표시/반원 채움 검증, 퇴근 거절 사유 표시. 기본 규칙/값 보존.
4. 병렬 담당: 메뉴·방 설정·퇴근 사유, 숫자 입력. 부모는 HUD/생활거점/속도계와 통합 검증. Unity·빌드는 부모만 실행.
5. Editor·실제 Player 캡처·LAN/지도 검사, 이력/기획 갱신, BuildHybrid/manifest 출하 후 main 비강제 push.
