# 승객 행동 확장 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. 구현·검토를 분리하고 사용자 승인된 범위 내에서 계속 진행한다.

**Goal:** 수면+음식/짐, 요청 위반 관찰, 메스꺼움·온도 민감·젖은 우산을 게임/편집기/기획/출하에 연결한다.
**Architecture:** 기존 프리셋과 운송 스냅샷을 유지하며 수면을 소지품과 독립 상태로 처리한다. 신규 특성은 운송당 저장되는 사건·선택 상태를 가지며 안전 정차 중 응대, 일시정지 동결, 효과 중복 방지, 호스트 권한을 따른다.
**Tech Stack:** Unity2022.3 C#, Node vanilla editor, JSON profiles.
**Spec:** 본 계획의 결정과 docs/content-design/19-passenger-trait-expansion.md(최종 실제 구현 기준 작성).

## 결정·경계

- 현재 사용자 요청은 구현·1차 기획 결정·검증·main push까지 승인. 기존 비 개발은 별도 체크아웃에서 진행 중이므로 보존 후 통합한다.
- 수면+음식/짐(오염짐 포함): 소지품 응대/준비→탑승→수면, 수면 중 섭취 억제, 도착 기상과 필요한 일반 짐 하역을 완료 후 정산. 오염짐은 기존 보호/오염 정책이며 별도 하역 시간 없음. 기존 단독 유형/음주 구토 호환.
- 신규 trait IDs: body.nausea, body.temperatureSensitive, item.wetUmbrella. 비 자체를 구현하거나 외부 날씨에 의존하지 않는다. 젖은 우산은 소지품으로 작동하며 추후 날씨 생성조건을 붙일 수 있다.
- 메스꺼움: 운행/거친 조작으로 누적, 안전 정차 휴식/봉투 등 응대가 완화·오염 예방에 영향을 줌. 이미 발생한 사건 취소 불가, 생성 확률 재추첨 금지.
- 온도 민감: 승객별 냉난방 배려 선택을 실제 차내 쾌적 상태로 기록·평가한다. 외부 날씨/실제 에어컨 물리모사와 구분한다.
- 우산: 감싸기/그대로 선택·안전 정차 준비·청결 손실1회. 대사·수치·확률은 공통 상속+프리셋별 덮어쓰기 지원.
- 요청 실패: Quiet 수락 뒤 실제 선택적 잡담 입력을 관찰해 실패(경적 입력은 현재 없음); 안전 필수 안내/경고를 실패로 오인하지 않는다. 기존 Comfort/OnTime/ViaStop 등 관찰 유지. 판단 근거를 결과에 표시하고 스냅샷 복원.
- 사용자 저장/활성프로필 보존; 과거 설정 누락은 호환 정책 명시. 단일 행동을 가정한 검증/UI/상황/효과장부도 함께 수정.
