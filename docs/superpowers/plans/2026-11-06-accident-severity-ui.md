# 지도·신호 표시 및 사고 강도/팝업 수정 계획

**목표:** 사용자 9개 이미지의 실제 오류를 수정하고, 승인한 사고 강도별 영업 손실/복귀를 구현한다.
**기준:** 현재 소스90fadf7/공동 배포a7c49ad·은계 싱글/A2 PVP/LAN v5 및 사용자 콘텐츠 프로필을 보존한다. Unity/빌드/Git은 root에서 직렬 실행한다.

## 확정 요구와 값

- 지도 시설 글자 잘림/아이콘·핀 겹침 수정. 다음 경로를 내비 영역 안에 작은 화살표/거리만 표시하고 한글 다음 행동/회전 후 유지 문구 제거.
- 차량 신호는 실제 도로와 내비 모두4등화로 일치. 좌회전 권한/신호 주기·보행2등화는 유지. 기존 허용 U턴 진입 차로에만 표시 보강.
- 콘텐츠 설정 적용 배너/설명 팝업 제거. 설정 기능·저장 snapshot은 유지.
- 사고 팝업은 아이콘+사고 발생, 운임 결과/비용/시간 손실/점수·재개 행동의 간결한 카드. 장문 설명을 제거한다.
- 사용자 승인: 보행자 경미/중간/중대 비용3,000/8,000/15,000원,45/120/240초, 운전점수−10/−25/−40. 차량·시설은1,000/3,000/6,000원,15/45/90초,−3/−8/−15. 중대는 현장 재개 대신 공업사로 강제 견인한다.
- 구현 초기 확률: 사람60/30/10%, 차량·시설70/25/5%. 호스트가 사건당1회 결정해 저장·복제한다. 강제 이송 비용은 사고 처리비에 포함하며 기계적 수리비는 기존 별도 규칙이다. 기존 미완료45초 사건에 소급 난수/감점을 추가하지 않는다.

## 분업/인터페이스

- map_label_fix: 전체지도 측정/충돌 회피와 실제 렌더에 쓰는 배치 검사.
- road_signal_fix: TrafficSystem/RoadMapFacilities의4등화, 내부 다음 경로, 실제 허용 compiled U턴 마킹 및 회귀.
- severity_model: AccidentState·정책/가변 비용/시간 장부·순수 모델 검사. 고정 결정 결과는 BeginResolved/ProcessingDuration/Fee/ScorePenalty/TowRequired/Kind/Severity로 root에 제공.
