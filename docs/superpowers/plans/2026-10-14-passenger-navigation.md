# 승객·내비게이션·지도 확장

사용자 요청: 호출 선택 또는 길가 승객 탑승 → 목적지 운송 → 시간 내 도착 시 요금. 도로 경로 안내. 후진/깜빡이 자동 보조 카메라. 좁은 지도 확대와 실제 차로 근거 검토.

## 구현 판단

- 원본 도곽 전체 444.03×555.27로 확대(기존260×275의3.45배). 새 지역을 임의 생성하거나 축척을 늘리지 않는다. T3 및 연결 도로 포함.
- 원본 차로수·폭을 JSON에 보존한다. 4는 왕복4차로 표시,5는 방향 배분/회전차로 미확인으로 임시4차로 표시,1·양방향은 임시왕복2차로. 현행 차로 확인과 구분해 기록.
- 도로 정점 기반 양방향 그래프, 최단 경로, 이탈 시 재탐색, 미니맵 경로와 도로 위 안내선, 다음 좌/우회전·남은 거리 안내.
- 호출 3개를 목적지/예상 요금/시간으로 선택(1~3 또는 버튼). 수락 후 픽업 안내, 정차 상태 F로 승차. 길가 손님도 빈 택시로 정차 후 F 승차. 한 번에 한 임무.
- 승차 시 카운트다운 시작. 정차 후 F 하차, 기한 내 도착 시 고정 요금 지급. 실패 시 지급 없음, 중복 지급 방지. 수입은 실행 세션 내 누적. 신호 위반 점수·유지비는 이번 범위 제외.
- 주 시야를 빼앗지 않도록 화면 속 보조 카메라를 자동 표시: 후진 감지 우선, 아니면 좌/우 깜빡이 해당 측후방. C 시점 전환 및 B 수동 뒤보기는 유지.

## 검증 순서

지도 범위·원본 차로수·연결성 테스트 → 임무/지급/시간 정책 RED→GREEN → 지도/차로/내비게이션 → 승객 루프와 HUD → 보조 카메라 → Unity 빌드와 실행 검증·코드 리뷰·화면 확인. 현재 도로 차로는 정확한 위치/최신 영상 연결이 확인되지 않으면 미확정으로 남긴다.

## 완료 기록

위 기능과 작업 도중 추가 요청된 한글 UI를 구현했다. 맑은 고딕으로 창 제목·호출·승객·내비·카메라·메뉴를 한글화했고 PNG에서 글자를 확인했다. 지도6개/기본 운전9개/교통11개/요금9개 정책 검사를 통과했으며, 승객·교통·실제 택시 주행 실행 검사 모두 success=True. 코드 리뷰로 AI의 확대 지도 이탈과 건물 속 승객 배치를 수정했다. 현재 실제 차로는 미확정이라는 한계를 기록했다. 상세: `docs/passenger-navigation-validation.md`, `docs/road-lanes-and-map-expansion.md`.
