# 플레이 피드백 반영 계획

> **For agentic workers:** Use superpowers:executing-plans with independent diagnosis delegated where safe. Steps use checkbox syntax.

**Goal:** 사용자가 제시한 내비·표지·거점/UI·시간 난도·감점을 개선하고 PS08 계획 팝업을 제외한다.
**Architecture:** 기존 Unity/C# 컴포넌트와 저장 구조를 보존한다. 독립 UI/운송/경로 작업은 파일 소유권을 나누며 Unity 실행은 주 작업자가 직렬로 수행한다.
**Tech Stack:** Unity 2022.3.62f2, C#, PowerShell.
**Spec:** 2026-10-27 사용자 스크린샷 피드백 및 추가 PS08 제외 요청. 사용자는 세부 수치 위임·즉시 진행을 승인했다.

## Global Constraints
- 현재 폴더의 새 codex 브랜치 사용, 기존 사용자 변경·마인드맵 미수정.
- 전체 회귀/BuildHybrid는 통합 후 실행, 중간은 변경부 최소 검사만 수행.
- 기존 저장 위치/이미 진행 중인 약정은 유지. 게임 배점이며 법률상 벌점으로 설명하지 않는다.
- 확인되지 않은 통행 방향을 임의로 양방향으로 바꾸지 않는다.
- 이번 변경의 main 병합·push는 자동 수행하지 않는다(직전 요청의 통합은 이미 완료).

## Review Focus
- 기존 저장 PS08 팝업의 시간 정지가 남지 않아야 한다.
- 서비스 영역 밖 F7과 픽업 중 F7이 다른 시설 이용을 허용하지 않아야 한다.
- 신호·양보·역주행·정지선 사건은 매 프레임 중복 차감하지 않는다.
- 새 승객 시간 난도는 저장/요청 경로 변경 시 재추첨되지 않아야 한다.
- 근접 평행 차로/유턴/후진 주차를 역주행으로 오인하지 않는다.
