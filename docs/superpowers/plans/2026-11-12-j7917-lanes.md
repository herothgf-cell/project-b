# J7917 은계로 차로 수정 계획

**Goal:** 최신 거리뷰의 남행 3차로와 북행 정지선 좌/직/직/우 4차로를 주행 그래프와 표시 모두에 반영하고 통합 실행본을 main에 배포한다.

**Architecture:** 기존 프로젝트 지도에 국소 차로와 연결을 추가한다. 기존 차로 ID/배열 순서와 승하차 바인딩을 유지하고 교차로 전후 연결을 검증한다. 폭·테이퍼는 게임 치수이며 거리뷰 외형과 구분한다.

**Tech Stack:** Unity 2022.3 C#, 프로젝트 지도 JSON, PowerShell 배포 검사.

- [ ] J7917LaneMapEdit.Verify: 남북 단면 수, 북행 화살표, 새 차로 진입/출구·552경로 검사. 수정 전 실패 확인.
- [ ] J7917LaneMapEdit.Apply: J7917 남북 은계로 중간 차로와 북행 좌회전 포켓 추가, 기존 연결 보정. 지도 r17 및 입력 manifest 갱신.
- [ ] BusinessProgress: 검증된 기본 r14/r15/r16 저장의 r17 이관. 영향받는 신호 관찰 초기화.
- [ ] 차로 표시·J7973·주차장 좌회전 회귀, Strict, BuildHybrid, 실행본 양방향 위치 제어 렌더 및 저장 이어하기 확인.
- [ ] 기획/체크리스트/이력, 통합/PvP 배포 manifest 검증, 소스·빌드 커밋과 일반 main push 및 원격 해시 확인.
