# 준비 결산·운행 HUD·내비 정리 계획

**Goal:** 사용자 세 이미지 마크업에 따라 정보 중복을 줄이고 실제 상태/결산/신호를 정확하게 표시한다.
**Architecture:** 기존 IMGUI·경로 탐색·장부·신호 권한을 읽는 표시 변경. 1일차는 이전 한 번의 영업 시작을 유지, 2일차부터만 전날 실제 결산 준비 팝업. 저장 스키마/운임/물리/법규/신호 주기/프로토콜은 유지한다.
**Tech Stack:** Unity2022.3.62f2/C#.

## 확정 범위

- 준비: 캠페인 설명·조작법·연습·야간회복 설명·새 캠페인 제거. 전날 실제 이용 비용과 아이콘/현재값·전날 마감 대비 증감, 영업 시작만 표시. 사용자 후속 답변으로2일차부터 적용 확정.
- 기본: 싱글 문구. 호출 보기 (M), 지도 (M), 미니맵 범례·고정 출처 행·중복 호출 버튼 제거. 출처 상세는 도움말에 유지한다.
- 속도계: 기어배지·조향상태배지·방향지시등 화살표 분리(사용자 후속 답변 확정).
- 생활거점: 기록 옆 버튼으로 기존 위치의 메뉴를 열며 제목은 생활 거점.
- 내비: 후속 회전은 오른쪽 작게. 실제 시간/거리 경로가 다르면 토글과 승객 요청 유지. 다음신호는 다음등화 그림+초만, 직진 녹색 예상 대기 문장 제거.
- 운송: 목적지 (...), 빈차/예약/탑승중 무표시. 실제 남은 시간 카운트다운과 예상 운임 비용을 별도 줄로. 큰 도착 액션/조건 문구 제거.
