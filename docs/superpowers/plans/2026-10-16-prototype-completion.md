# 은계 프로토타입 통합 마무리 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans inline. 사용자 기존 기획·자율 구현 승인에 따라 구현과 검증을 연속 수행한다.

**Goal:** 남은 프로토 필수 흐름을 실제 사용할 수 있도록 연결하고 미검증 항목을 정직하게 남긴다.
**Architecture:** 기존 LawLedger, CampaignCheckpoint, ServiceStops, PracticeSession, PassengerJobs를 확장한다. 지도 그래프와 물리 엔진은 유지한다.
**Tech Stack:** Unity 2022.3 / C# / Python 검증 도구.
**Spec:** docs/prototype-scope.md, docs/prototype-development-checklist.md, docs/content-design/01~07 문서.

## Global Constraints
- 은계 지도, 3일 × 480초, 순수익 30,000원. 법규와 매너 분리.
- 개인 예약·단골·사고·수리·청구 제외. 가감속은 운전자 책임.
- v1과 기존 v2 정산을 보존. 추가 필드는 이전 v2에서 비어 있어도 복원한다.
- 현장/실물 패드/수동 체감은 자동 검사로 완료 처리하지 않는다.

## Review Focus
- 결산이 아닌 곳에서 복습을 시작해 캠페인 시간이 흐르는 경우.
- 확인/취소와 중복 클릭으로 비용이 두 번 나가는 경우.
- 마감·고갈·타임아웃 뒤 승객 결과가 누락되거나 재지급되는 경우.
- 과거 v2 저장의 새 필드 누락과 당일 기록 롤백.
- 작은 창에서 모달·HUD 겹침 및 지원/연습이 영업 기록을 변경하는 경우.
