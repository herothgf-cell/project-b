# 은계 전용 프로젝트 정리 계획

사용자 요구: 은계지구만 사용하므로 영통 관련 내용을 제거한다.

범위 결정: 현재 지도 선택·기본 실행·빌드·프로젝트 폴더·개발 안내·배포 입력은 은계로 통일한다. 은계의 국도42 검사용 입력과 공통 수학/가상 연습은 유지한다. 과거 작업/검증 기록의 사실은 바꾸지 않되 프로젝트 소스 링크는 새 경로로 갱신한다. 기존 캠페인 저장은 새 은계 저장 폴더로 1회 복사해 보존한다. 원본 GIS와 정식 은계 프로젝트 지도 값은 변경하지 않는다.

- [x] 지도 정책/저장 경로의 실패 검사 작성·RED 확인.
- [x] Unity 프로젝트를 unity/EungyeTaxi로 이동, 도구·설정·문서 소스 링크 갱신. 영통 지도 설정과 구형 전용 exporter 제거, 재사용 수학 함수만 중립 파일로 분리.
- [x] 은계 전용 catalog/default/build/launcher, 캠페인 저장 이전 구현. 영통 입력 제거·배포 ZIP 경로/manifest 재생성·해시 전수 검증.
- [x] Unity 정책/저장/기존 편집 검사·Python 수입 검사·모델 검사·새 빌드/실행 확인. 현재 사용법/범위/체크리스트/이력 갱신.
- [ ] 최종 독립 리뷰 후 커밋·main 통합·푸시. 기존 사용자 문서 변경을 별도 보존하고 새 경로로 소스 링크만 맞춤.

검증: 기본/오래된 지역 환경설정/테스트 옵션에서도 은계만 로드, 알 수 없는 지도 선택 거부, 기존 저장 무손실 이전과 새 저장 우선, 영통 raw/Resources 없이 빌드, ZIP2입력 실제 SHA256 일치, 정식 지도 SHA256 불변.
