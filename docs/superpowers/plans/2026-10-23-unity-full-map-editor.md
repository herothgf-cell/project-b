# Unity 전체 지도 편집 통합 계획

사용자는 기존 Esc 지도 편집 기능 전체를 Unity에서 3D 지도 선택으로 수행하고 실제 주행/다른 PC에 적용·검증·푸시하도록 요청했다. 기능별 별도 exe 편집 전환을 없애고 같은 RoadMapDocument/Composer/Validator를 재사용한다.

- [x] 세션: 차로/시설/신호 트랜잭션·Undo·초안·정식 저장과 객체 추가/삭제 통합. 건물 드래그는 기존 증분 갱신 유지.
- [x] 공유 편집 연산: 좌/직/우, 진행 반전/반대 차로 폐쇄, 출구/차로변경, 분할/평행/대기차로, 표지/노면 및 참조 정리. synthetic RED→GREEN.
- [x] 네이티브 도구: Scene 차로/시설 클릭, 방향선, 제어점·W/E/R, 클릭 배치/연결/대상 지정, 신호 단계/그룹/타이밍.
- [x] 통합 창: 건물/부지 생성·삭제·꼭짓점, 차로 도구, 검사·시험·JSON 입출력·저장·빌드. 트래픽 편집 종료 후 미리보기 갱신.
- [x] 실지도 복제본 저장·다시 읽기·주행 그래프/규칙 및 exe 적용 검증, 최종 빌드·manifest, 사용법/체크리스트/이력, main 병합·푸시.

설계 선택: UI만 새 네이티브로 구현하고 모델/런타임 합성은 기존을 재사용한다. 일방통행은 표지 외형과 구분해 실제 반대 방향 차로 폐쇄로 적용하며 변경 목록 확인과 전체 접근 검사를 거친다. 진행 반전 후 끊긴 연결은 클릭 연결로 보완하며 무효 지도는 정식 저장/시험 차단. 사용자가 명시한 전체 구현 요청으로 추가 설계 승인 없이 진행한다.

구현/자동 검증은 완료했으며 실제 main 통합/푸시 결과는 작업 이력의 배포 절에서 확인한다.
