# 은계 수동 운전·HUD 개선 실행 계획

요구: 수동 시내 운전을 쉽게 하고 한글 잘림 수정, 큰 전체 지도, 승객 매너/독립 법규 게이지, 세금·보험을 프로토에서 제외한다. 기존 영업·은계 지도·H 조향 전용 정책은 유지한다. 사용자 자율 구현 지시에 따라 기존 기능 보완으로 진행한다.

## 작업과 검증

- [x] 운전: DriveMath/TaxiController/DrivingManners. 완만한 토크·입력, 저속 회전 강화, 고속 안정성 유지, 급가감속 판정 완화. 기존/변경 모델 비교 및 실제 WheelCollider 저속90도·0→30km/h 검사. H는 가감속 직접 유지.
- [x] 경제: CampaignAccount/BusinessProgress/BusinessHUD/ServiceStops. 세금·보험 메뉴/출발 제한/목표 조건/비용 제거. 기존 저장의 비용·미납을 안전하게 이관. 식비/주유/주차 유지. 3일 정산·복원 모델 검사.
- [x] UI: DriveHUD/DrivingReadability. 기존280 미니맵 유지, 별도 큰 전체지도(Tab과 충돌 없는 G키와 버튼), 실제 경로/현재위치/승하차/법규 이름. 지도 열면 영업시간·운전 정지, 닫으면 이전 상태 복원. 1280/1600/1920 한국어 크기·가독성, 다른 모달 중 열기 금지.
- [x] 게이지: 실제 승객 탑승 중 매너와 요구점수, 독립 법규 오늘 점수/판정건수·미관찰 구분. 두 시스템 데이터 분리. 고정 폭 작은 버튼 한국어 스타일·줄바꿈·높이 수정.
- [x] 시작 주차장 좁은 구간 확인: 실제 지도/임시 거점 구분 유지. 필요하면 접근 가능한 넓은 주차 지점 선택. 접근·출발 물리 검사.
- [x] 통합: 모델 전체·기존 법규/교통 회귀, Player 캡처·실제 물리 검사. Unity BuildHybrid, 배포125파일 목록/해시 갱신. 기획/체크리스트/작업 이력 갱신 후 main 푸시.

독립 운전·경제 작업은 각각 제한된 파일 집합으로 위임하고 HUD/전체지도·통합은 주 작업자가 수행한다. 현재 미커밋 README·라이선스 자료는 보존한다. 새 PC 하드웨어·사용자 수동 체감은 자동 검증과 구분한다.

완료 근거: docs/work-history/2026-10-21-playability-and-hud.md. UI/물리/3일 회계/기존 신호·H 회귀 및18개 모델 통과. 사용자 키보드 수동 체감과 새 PC 실제 하드웨어는 자동 검증에 포함하지 않는다.
