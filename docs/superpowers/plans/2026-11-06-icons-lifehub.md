# 아이콘·생활거점 알림 적용

사용자 승인: 가운데 공업사 비교/길안내 제거, 생활거점과 공업사에 수리 레드닷. 시안의 둥근 아이콘 통일 후 HUD 가독성 점검·main 게시. 맵/차량 외형은 유지한다.

- `VehicleDamageController`: 가운데 비고장 수리 유도 버튼만 제거. 내구도0 고장/견인/수리 모달은 유지.
- `ServiceStops`, `CockpitUI`: 현재 내구도50이하를 매 표시마다 읽는 수리 알림. 열람으로 해제하지 않고 수리 후 자동 해제. 생활거점에 공업사 비교 진입 추가, 길안내/결제는 기존 분리된 흐름. 시설5개+닫기 3열2행으로 짧은 제목/아이콘과 거리 표시, 기존 네 항목/추천/가드 보존.
- `HudGlyph`, `DriverStatusGauges`: 기존ID 의미 유지, 96픽셀 캐시·부드러운 경계와 둥근 선·통일된 실루엣으로 교체. 상태계의 중복 픽셀 도형 제거, 공통ID사용. 지도 선/클리핑은 변경하지 않는다.
- `BrightUIProbe`/Editor: 임시 캠페인에서 51/50/21/0/100 알림 경계, 생활거점 열람/닫기·공업사 탐색 무거래/경로보존, 싱글/PVP 두 해상도 실제 화면 확인. 기존 테마/HUD/콘텐츠 계약·BuildHybrid·사용자 저장 hash/Strict·manifest 검증.
- 후속 HUD 점검: 표시 겹침/작은 화면 아이콘/긴 문구 확인, 재현되는 문제만 수정. 실제 화면·검증/미검증 기록 후 소스/실행본·manifest를 main에 푸시.

새 아이콘은 코드에서 그리는 표시 자산이므로 imagegen을 사용하지 않는다. 저장·밸런스·가격·주행/신호·LAN 권한 변경 없음.

검증 완료: 통합 UI160/운전설정17·15·빌드/제동·신호 계약 통과. 게시/manifest 실제 해시는 작업 이력의 최종 영수증을 따른다.
