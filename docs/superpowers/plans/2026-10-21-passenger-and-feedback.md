# 승객 코스·요청·운행 피드백 구현 계획

사용자 승인 범위: 은계 기본 영업에 9개 코스와 승객 요청 확장, 승차 대기 기한, 상단 연료/점수 안내, M 전체 지도·+/- 미니맵과 필터, 복귀 단축키 제거, 창 제목 수정, 교통량 확대와 신호 남은 시간. 개별 기획서 동시 갱신.

2026-10-21 사용자 결정: 운행 점수는 날짜/재실행에 유지하고 새 캠페인에서만 100점 초기화. 승객 매너와 독립한다.

1. 기존 FareTrip/공유 내비/관찰 평가를 재사용하여 9개 코스와 선택 상황 연결.
2. 기존 승객 요청 수명주기에 운전·대화·변경 요청을 연결하고 종료 결과를 기록.
3. 운행 누적 점수/저장·상단 알림·신호 타이머/교통량/게임 표지와 UI 통합.
4. 모델 검사, Unity 빌드, 코스·승객 요청·UI·교통 흐름 런타임 검증. 실패 수정 후 필요한 검사 반복.
5. 개별 문서/체크리스트/작업 이력과 실행 배포 manifest 갱신, 검증한 소스와 실행 폴더를 main에 반영.

실제 표지 위치·운영 방식은 확인되지 않으면 게임 설정으로 구분한다. 수동 3일 플레이와 다른 PC 하드웨어 검사를 자동 검사로 대체하여 완료 표시하지 않는다.
