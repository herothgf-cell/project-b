# 채움 아이콘과 운송 안내 구현
사용자가 점검 결과의 다음 진행을 승인했다. 기존 기능/맵/차량/밸런스·LANv11을 보존한다.

1. HudGlyph/CasualUI/상태계: 채움 실루엣·금색동전/초록만족·안전/파랑시간 배지, 흰 헤더 아이콘 별도 유지. 현재ID/지도클립 보존.
2. CockpitPresentation/CockpitUI: 승차 장소/도착지 단계 구분.
3. PassengerDialogueUI/호출부/정산: 기존 운송 식별값 기반 동일 초상, 저장/네트워크 스키마 추가 없음.
4. 정산 시설찾기를 기존 시설 비교로 연결, 명시적 선택/현장결제 보존.
5. 격리 실제 Player에서 호출수락/승차/요청/하차/정산/시설탐색·초상·무중복지급 검증, 두 해상도 및 싱글/PVP 기존계약 확인. 기존 준비/경유/기상분기 코드를 점검하고 미검증 분기를 명시.
6. 실제 화면·문서·작업이력, 통합빌드/manifest검증 후main게시. 독립 화면 그룹은 dispatching-parallel-agents 워크플로 파일소유범위로 병렬 구현한다.
