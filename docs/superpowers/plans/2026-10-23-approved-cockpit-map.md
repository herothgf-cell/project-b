# 승인된 주행·지도 UI 구현 순서

사용자 승인: 시안13 배치 OK, 추가로 M 승하차 지점 클릭 포커스. 현재 작업폴더의 다른 문서 변경 보존.

1. FullMapOverlay: FocusStop/FocusWorld, 호출선택(수락과 분리), 실제 지점 핀 클릭, 지도내 컨트롤/필터, 위치모달. 클릭과 드래그를 구별하고 모달은 입력차단. 기존 pause 복원/배차 규칙을 재사용.
2. CockpitUI/DriveHUD: 상단지역·시간·정보·퇴근·도움말/잔액,좌하단속도·기존도형게이지,우하단만족도·운행점수. 기존 배차카드는 M로 이관. OneDayHUD는 준비/결과 전용 유지.
3. DrivingReadability/PassengerRequestUI: 신호+내비를 좌상단 정보 아래로 이동,대화는 하단중앙. 출처 유지,소형해상도에 비례축소.
4. 실행파일 검사: 지도포커스가 경로/장부에 영향 없는지,호출 선택/수락 분리,모달/일시정지 복원,3해상도 배치. 모델 회귀/BuildHybrid/기존 HUD 회귀. 자동검사와 수동클릭 구분.
5. 설계13/체크리스트/이력/LATEST 갱신,코드와 검증을 커밋,배포manifest 실제해시 갱신. 미검증 수동플레이 명시.
