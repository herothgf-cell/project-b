# 주행 흐름 개선

사용자 지시: 닉네임만 PVP 전용, 신호/거리/카운트다운/조향은 싱글·PVP 공통. 짧은 PVP의 호출 목록·회전 수용 개선. 반복 리뷰 대신 변경 관련 최소 검사·통합 빌드·게시.

- 기본 보호 신호의 양방향 직진(10초)/황색2/정리2, 합법 좌회전은 방향별4/2/2로 분리. 없는 좌회전 단계 생략, 보행10/정리2 유지. 편집 프로그램·교육·실제 비보호 권한은 보존. 타이머는 현재 접근 신호 색이 실제 바뀔 때까지 계산.
- 네비에 현재 승차/경유/하차 목표의 경로 잔여 거리 표시. 신호 보조 문구는 변경까지 남은 시간만. 계산 불가능한 조건부 신호는 시간 미정.
- 닉네임12자, 제어문자/태그 제거·빈 입력 차단, 로컬 설정 저장. 호스트가 이름을 배포하고 재접속 슬롯 유지. 프로토콜 버전 갱신.
- 10분 이하 신규 공유 호출은 동일한 승차 분산을 유지하며 가까운 도착 후보 중 실제 연결되는 단거리 위주로 선택. 수락된 운송·기한·보상 규칙은 보존.8호출+3길가 슬롯을 유지, 재호출 휴지30초로 단축.
- 키/패드·LAN 원격 동일 조향 응답9→6/s, 저·중속 수동 조향 여유 소폭 증가, 고속 제한/차량 충돌·제동 유지.
- 관련 Editor 검사와 실제 LAN 두 프로세스 검사, BuildHybrid·배포 manifest. 전체 캠페인/다른PC/장시간 검증은 반복하지 않음.
