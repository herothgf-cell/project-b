# 은계 도로 표시·주유소·운송 마감 개선

요구: 도로 위 흰 박스 정체 확인/오류 제거, 황색 중앙선과 백색 차로선·편도 차로수 명확화, 승객 도착 후 마감, 프로토 시간/연료 여유, 입출구가 분리된 주유소 여러 곳, 사용자 표시 용어 ‘운전 점수’.

- [x] 도로/장애물: 실제 차로 그래프와 렌더링 대조. 잘못 겹친 건물/표시 식별 후 제거·보류하고 정상 정차 차량은 차량 외형으로 구분. 로컬 도로 중앙선/차로 경계 혼선 수정, 실제 확인/임시 차로 유지. 기하·충돌·시각 시험.
- [x] 운영: 하루720초(12분),3일/순수익3만원 유지, 운송시간 완화. 승객 탑승 중 N 금지·날짜 타이머0은 하차까지 마감 대기. 운송 제한시간이 지나도 승객 유지·목적지 도착 후0원 처리. 기존 저장에도 새 밸런스 적용. 연료4%포인트/km·공회전0.1%포인트/분, 시작60%.
- [x] 주유소: 은계 3곳 이상, 게임용 명칭·실제 확인과 구분. 도로 오른쪽 입구→주유 구역→별도 출구, 도로 접속/빈 부지/건물·차량 침범 확인. 노면·캐노피·주유기·안내판/화살표, 미니맵/전체지도·메뉴 경유 안내. 내비/H는 공통 도로를 통해 입구까지 안내하며 부지 내부는 수동 진입을 분명히 표시. 주유는 실제 주유 구역 정차만 허용.
- [x] UI: 운전 점수로 사용자 노출 용어 변경. 내부 Law 시스템/승객 매너 분리와 기록 보존. 마감 대기·늦은 도착·시간/연료 설명 갱신.
- [x] 통합: 모델·실제 은계 지도/시설·시각/물리·영업 마감 회귀, 빌드·배포 manifest·작업 이력/기획 갱신 후 main 푸시. 기존 README/라이선스 변경은 보존.

작업 분담: 도로/건물, 시간·연료·승객/마감, 주유시설을 서로 다른 파일 집합으로 위임한다. 주 작업자는 UI 용어·지도 표시·통합·문서·빌드 담당. 지도 입력3개는 바꾸지 않는 런타임 구성/렌더링 수정을 우선한다. 현장 자료 없는 시설/차로를 실제 확인으로 표시하지 않는다.

검증 근거·제한은 [최신 작업 이력](../../work-history/2026-10-21-road-facilities-and-operation.md). 전체 캠페인 수동 밸런스·현장 시설/규제 확인은 이 작업 완료 범위에 포함하지 않는다.
