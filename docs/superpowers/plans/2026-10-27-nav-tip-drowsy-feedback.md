# 내비·TIP·표지·졸음 후속

요구사항: 2026-10-27 사용자 제보 4개와 후속 마인드맵 직접 수정/Detail-Links 갱신/푸시 요청.

## 작업

1. 실제 승하차 후보로 제보 경로 재현. 누락된 연결인지 방향 제한인지 확인하고 합법 연결만 보완한다. 기존 경로 회귀 검사와 비교한다.
2. 점유 안내·정차 대기 버튼을 TIP에 통합. 왼쪽 슬라이드/복귀 탭, 스크롤과 기존 평가 버튼 유지. 화면 크기별 경계와 점유 해소 검증.
3. 표지 전용 글꼴을 화면 글꼴과 분리하고 제한 문구를 읽을 수 있도록 정리. 신호등 상부 배치 유지. 실제 렌더·한글 글자 크기 검증.
4. 초반 눈감김 중 일시적인 가속·조향 응답 중단. 제동은 유지하고 눈을 뜨면 복구. 메뉴/일시정지·정상 수면·최종 암전 정책 보존. 모델과 실제 입력 검사.
5. 기획은 행동/결과만 갱신. 마인드맵 기존 ID·사용자 가지를 보존하며 최신 규칙/후속 구상을 구분하고 전체 Detail-Links를 현재 문서로 교체. JSON/ID/링크/기획 대조 검사.
6. 마지막에 회귀 검증·독립 최종 리뷰·기본 빌드/배포 manifest 검증. 이력과 함께 커밋, main 통합·푸시.

## 판단 기록

- 사용자 지정대로 현재 폴더 작업 브랜치를 사용한다. 중간 전체 테스트는 반복하지 않고 변경별 집중 검사 후 최종 통합 검사한다.
- 졸음은 임의 조향/가속을 생성하지 않는다. 짧은 눈감김에 맞춰 입력이 잠시 반응하지 않되 안전한 제동은 가능하게 한다.
- 마인드맵은 최신 사용자 지시에 따라 직접 수정한다. 기존 사용자 편집을 토대로 변경하며 개발 설명·과거 노트의 중복은 기획 링크와 분리한다.
- 공유 접점: 점유와 평가 버튼은 TIP 하단을 공유하므로 점유 중에는 대기 버튼 우선, 해소 후 평가 버튼 복귀.

## 검증 기준

예상: 제보 경로가 북쪽 블록을 순환하지 않음. TIP 숨김 후 탭만 화면에 남음. 점유 중 대기/기한 보호 유지. 표지 한글이 읽히고 상부 위치 유지. 졸음 입력 차단이 간헐적으로 해제되고 제동 가능. 마인드맵 모든 기획 링크가 존재하는 현재 문서를 가리킴.

자동 위치 제어/입력 검사와 사람의 실제 조작감·전체 캠페인 검사는 구분해 이력에 남긴다.
