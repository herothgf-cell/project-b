# 승객 프리셋별 대사·확률·효과 덮어쓰기 설계

작성 2026-11-07. 사용자 요청: 같은 특성도 프리셋별로 대사·발생 확률·효과 수치를 다르게 제작하고 관리 도구/게임에 적용한다.

## 방식과 결정
공통 설정 전체 복사는 밸런스 수정 전파를 막고, 특성 자체 복제는 중복을 늘린다. 따라서 공통값 상속 + 명시한 항목만 덮어쓰기를 채택한다. 사용자가 개별화 구현을 요청했으므로 기존 조합 구조를 확장하며 별도 승인 대기를 만들지 않는다. 값은 가산/배율이 아니라 교체이다. 0은 유효한 개별값이며 삭제가 상속 복원이다.

## 데이터 계약
`passenger.presets` 내부 version1은 그대로 읽고 원본/hash를 유지한다. version2에서는 각 프리셋에 `overrides:[{id,value}]`가 필수다. 값은 기존 카탈로그처럼 문자열. 첫 개별 편집 때 모든 프리셋에 빈 overrides를 추가하고 내부 version2로 명시 이관. 최대32프리셋, 한 프리셋128개 override, JSON32000자/전체프로필240KiB 제한 유지. 중복·알 수 없는 키·비문자열·범위/형식 위반·사용할 수 없는 특성 키를 거부한다. version1에 overrides 필드는 거부한다. 전체 프로필 schema1/2와 기존 해시 알고리즘 유지.

허용 키는 카탈로그에 실제 존재·editable인 항목 중 소비 경로가 검증된 승객 항목만이다. 공유 등장 정책(type.*.weight/enabled, Drunk.spawnPercent/dailyMax/force*)·schedule·common·manner·법규·경제는 제외한다. 지원 대상은 실제 주 행동의 intro/choice/followup 텍스트 및 choice.type 효과, 모든 승객에게 가능한 request 대사/응답/미응답 및 choice.request 효과, situation.reply/choice.situation 효과, 선택한 신체/소지품/목적의 effect.*와 Drunk.sleepPercent/vomitPercent. legacy 이관용 effect.food.satisfaction/request.success/failure는 새 개별 편집 대상에서 제외한다. 구토 청결 고정 상한10 같은 새 행동 규칙은 이번에 임의 가변화하지 않는다. 정확한 허용 규칙은 JS/C# 공통 fixture로 대조한다.

## 적용과 저장
`개별값 > 현재 세션 공통값 > 코드 기본값`으로 조회한다. 전역 ContentTuning을 바꾸지 않고 승객별 명시적 resolver를 전달한다. 확률은 기존 시점에 한 번 계산하고 저장한다. 상태는 선택한 프리셋과 overrides를 deep copy; 저장된 콘텐츠 세션과 함께 복원. 선택 효과는 실행 시 해결한 definition을 ledger에 저장하고 저장 검증도 같은 승객 context를 쓴다. UI의 표시 효과/대사와 실제 값 일치, 다음 승객·다른 PVP 세션에 누출 없음. LAN 프로토콜 호환 버전 갱신 필요 여부를 실제 payload 계약 기준 판단.

## 관리 화면
특성 선택 아래 '이 승객만의 설정': 대사 / 발생 확률 / 효과 필터, 검색, 항목 추가. 각 행에 이름·단위·범위, 공통값·개별 입력·최종값, '공통값으로 복원'. 개별 설정 개수와 저장 전 오류 표시. 특성 제거로 더는 유효하지 않은 개별값은 조용히 삭제하지 않고 오류와 복원 버튼을 보여준다. 복제는 깊은 복사, 다른 프리셋 값 불변. 공통 설정 이동은 별도 버튼 유지.

## 예와 수용 기준
같은 음주 특성 두 프리셋에서 구토0/100%, 같은 음식 특성에서 흘림0/100%·오염2/9, 같은 짐 특성에서 준비3/17초, 선택 즉시S1/7, 소개/응답 대사를 달리 지정한다. 공유값 변경은 상속 항목에만 반영되고 명시적0과 공통과 같은 값도 고정된다. JS/C# 교차검증, 실제 운송 선택/확률/효과/저장복원, UI 저장·재로드·복원·충돌 및 기존 프로필 호환을 검사한다. 사람 운전과 자동 검사 범위를 구분한다.

구현 보완: 전체 schema1에서 choice.* 개별값은 거부하며 편집 도구의 기존 schema2 이관 후 작성한다. 텍스트 개별값은 공백만/빈값을 거부한다. Sleeping 주 행동은 SleepingFollowup 선택 효과도 지원한다. 카탈로그 editable=false인 중립/참조 미응답 항목은 허용하지 않는다. 화면의 오염/감점은 기존 음수 표시 변환을 재사용한다.
