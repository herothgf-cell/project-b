# 택시 외형·1인칭 운전 표시

상태: 시안 공유 후 사용자 **진행해줘** 승인(2026-11-07). 외형·1인칭 구현 및 실제 실행본 검증. concept-v1.png는 검토용 생성 이미지. 내부 장식/미러·도시 아트는 분위기 표현이며 이번 구현 확정 아님. 실제 적용 시 내구도/청결/포만/피로·운전점수·기한·메뉴 기능도 유지해야 하며 그림의 축약을 기능 제거로 해석하지 않는다.

사용자 요청: 첨부 컨셉처럼 택시 외부부터 수정, 1인칭 운전 UI도 시안에 맞게 조정. 기존 노란 택시·밝은 카드·파란 길안내 유지.

구현 판단: Unity 생성 곡면 메시로 둥근 차체/유리/범퍼/후미등/표시등/번호판/휠을 제작한다. 기존 Rigidbody1400·차체 충돌1.8×.7×4·WheelCollider 위치/반경/마찰·주행/경제 수치는 변경하지 않는다. 외부 구매 에셋 없음. 1인칭은 임시 상자 대시보드를 둥근 짙은 남색 대시보드/핸들로 개선하고, 큰 반원 HUD를 낮은 디지털 속도/기어/방향지시 표시로 대체한다. 지도·대화·경고·메뉴 접근성 유지, 카메라 시점/좌우/후방 확인 동작 유지.

정면/측면은 첨부 후면과 같은 단순하고 둥근 소형 택시 디자인으로 작업자 판단. 3인칭 실루엣과 1인칭 전방 가림을 실제1280/1920 화면으로 확인한다. 정교한 실차 내부·문 열림·손/캐릭터 애니메이션은 범위 밖. 기존 실제 거울 렌더링은 보존하고 UI와 겹치지 않게 위치만 조정했다.
