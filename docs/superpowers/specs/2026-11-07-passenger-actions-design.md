# 승객 행동 팝업 설계 · 검토 시안

2026-11-07. 사용자 선택: **행동이 필요한 상황만 팝업, 일반 대사는 승객 카드 유지**. 현재 밝은 HUD·숫자키·기존 운행 수치 유지. 이 문서는 구현 전 시안이며 사용자 검토 대기다.

## 접근 방식
- 선택한 방식: 행동/작업 필요 상태만 공통 행동 팝업. 카드에는 상태 요약과 ‘행동 보기’를 둔다. 일반 대사 때문에 도로 시야를 가리지 않는다.
- 대안: 모든 대사를 팝업화. 일관성은 있지만 잦은 시야 차단 때문에 채택하지 않음.
- 대안: 카드 안에 버튼만 추가. 변경은 작지만 긴 조건/대기/진행 정보를 계속 작은 영역에 넣게 되어 채택하지 않음.

## 유형 목록과 적용 경계

## 화면 계약
[시안](../../ui/2026-11-07-passenger-actions/concept-v1.png)은 배치/색/계층 검토용이다. 일러스트와 배경은 게임에 새로 넣는 아트가 아니며 실제 구현은 기존 초상/아이콘을 사용한다. 이미지 속 PVP 3인 예시는 장식이며 실제4인 현황 유지. 짐 적재/하역 완료 시 AdvanceBehavior의 기존 자동 승차/정산을 유지한다. 깨우기는 기존 F/Interact와 자동 하차 조건을 유지한다.

- 기존 공통 승객 팝업 영역 사용. 상단 제목, 초상/아이콘, 상태 설명, 안전 정차 배지, 큰 남은 시간/진행바, 행동/접기 버튼.
- 속도계·좌측4인 현황·지도·하단 승객 카드와 겹치지 않는다. 긴 안내는 스크롤.
- 행동 상태 진입 시 한 번 표시. 정차 행동은 실제 지정 장소/정차 조건 충족 때 자동으로 열고, 운행 중에는 카드의 ‘안전 정차 필요’ 요약으로 유도한다. 사용자가 직접 펼칠 수 있으나 조건 불충족 때 실행 버튼은 비활성화하며 이유 표시.
- ‘접어두기’는 UI만 접는다. 행동을 거절/취소/완료하지 않는다. 같은 상태의 매 프레임 재표시 금지. 카드 ‘행동 보기’로 다시 열기.
- 상태가 끝나면 팝업 제거. 정산/지도/일시정지/설정/사고/기존 선택 팝업과 중복 표시하지 않는다. 새 행동 팝업은 게임을 자동 일시정지하지 않는다. 싱글/PVP 기존 시간 흐름 유지.
- 숫자1~n과 마우스 지원, 기존 F 승하차/깨우기 유지. 같은 프레임의 중복 실행 차단. 대기만 가능한 상황에 새 행동을 꾸며 넣지 않는다.
- 타이머/버튼은 실제 모델 상태에서 계산, 기존 API를 사용한다. UI를 위해 시간·요금·만족도·정차 판정·저장을 변경하지 않는다. LAN은 기존 호스트 권한 명령/복제 상태를 사용한다.
- 승객 카드 빈차의 호출 버튼은 유지. 일반 발언/짧은 후속 답변은 카드, 선택 가능한 요청은 기존 팝업 유지. 일반 대사와 중요한 행동 상태가 동시에 있으면 행동 요약 우선.

## 검증·출하와 브랜치 정리
깨우기 전/가능/자리이탈/자동하차·적재/하역·음식/재고정·용무의 기존 상태와 UI 표시를 검사하고1280/1920 실제 화면을 확인한다. 숫자/F 중복·접기/재열기·정산·LAN을 확인한다. 사용자 저장 보호와 통합 BuildHybrid/manifest 검증 후 main 푸시.

최신 fetch 기준 모든 로컬13개 및 원격 작업 브랜치의 origin/main 대비 독자 커밋0. 구현 종료 시 다시 검사. main 미포함 커밋이 생기면 내용을 조사하고 보존 통합 후 삭제. 작업폴더의 미커밋/미추적 파일은 삭제하지 않는다. 다른 worktree는 보존된 커밋의 detached HEAD로 전환해 파일을 남기고 브랜치 이름만 삭제한다. 현재 작업공간도 최종 main 커밋에서 detach 후 정리 가능하다. D: main의 미커밋 문서는 유지한다. 원격 작업 브랜치도 포함해 main만 남기는 것이 요청 범위다.
