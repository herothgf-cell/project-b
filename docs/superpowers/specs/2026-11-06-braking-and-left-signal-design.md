# 감속 민감도·좌회전 신호 후속 설계

사용자 요청: 운전 설정에서 브레이크 감속 조작 민감도를 조절하고, 첨부한 은계로 좌회전 대기에서 신호가 나오지 않는 문제를 수정한다.

브레이크는 기존4항목에 일반 브레이크 민감도50~150%(기본100%)를 추가한다. S/↓/패드의 감속 힘에 적용하며, Space·메뉴/사고 잠금·자동 서비스 제동·봇은 기존 힘을 보존한다. H는 조향만 보조하므로 사람의 일반 감속에는 설정을 적용한다. 기존 preference에 항목이 없으면100%로 보충한다. 개인 저장·취소/적용·기본값·화면 축소 동작을5항목으로 확장한다.

LAN은 입력마다 브레이크 계수를 전달하고 서버가50~150%와 유한수를 검증한다. 사람의 로컬 예측과 서버에 동일 적용하고 v11로 구버전 연결을 차단한다.

신호는 첨부 이미지와 실제 지도/저장·신호 수요를 대조한다. 지도/음식점 위치와 진입 거리 대조 결과 J7973_3744 동행 접근으로 확인했다. 다른 식별자를 쓰는 NGII 좌회전 연결의 누락을 같은 방향/실제 연결/가장 가까운 교차로32m 기준으로 보완한다. 차로 폐쇄와 기존 명시 금지·보행 보호는 보존하며 지도 입력은 변경하지 않는다. 사용자는 Q를 켜도 신호가 나오지 않았다고 확인했다.

추가 요청: 중앙의 수리 안내가 주행 시야를 가리지 않도록 왼쪽 아래 속도/차량 상태 카드의 빈 영역으로 옮긴다. ‘공업사’ 버튼과 기존 비교/길안내 동작·노출 조건을 보존한다.

검증: 기존 기본값·저장 이관·일반/긴급 제동 독립성·정차/후진·H/봇·실제 PhysX 정지 거리와 감속 비교, 설정 렌더·PVP 서버/예측·실제 지도 좌회전 수요/초록 진입, BuildHybrid·두 모드·manifest. 사용자 현재 별도 경로 플레이 저장은 읽기 진단 복사만 하며 되돌리지 않는다.
