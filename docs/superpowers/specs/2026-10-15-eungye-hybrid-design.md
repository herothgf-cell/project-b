# 은계 전체 도로망과 정밀 차로 결합

사용자가 승인한 방향: 기존 은계 전체 주행 영역에 국도42호선 실제 차로를 결합하고 호출·승객 운송·내비게이션·H 보조 조향을 활성화한다. 미확보 교차로는 임시임을 표시하고 별도 설정으로 수정 가능하게 한다.

범위는 현재 확보·생성한 은계 2.1×1.75km이며 시흥시 전체나 은계 행정경계 전체의 현행 교통 규제를 확보했다는 뜻이 아니다. 원본은 수정하지 않는다.

## 구성

- 기존 수치지형도 도로를 바탕으로 임시 방향별 차로와 교차로 연결을 생성한다. 정밀도로지도와 겹치는 주행 차로는 정밀 자료를 우선하며 중복 추정 경로는 제거한다.
- 정밀 차로의 원본 ID 연결은 보존한다. 지역 도로와의 접속은 별도 임시 연결로 분리하고 출처·설정 ID를 표시한다. 원본 연결로 위장하지 않는다. 실제 도로 영역과 방향이 맞는 접속만 허용하고 건물·호수 횡단을 배제한다.
- 내비게이션과 보조 조향은 하나의 결합 그래프를 공유한다. 정밀/임시 상태와 교차로 ID를 HUD에서 확인할 수 있다. H는 가감속을 변경하지 않는다.
- `config/maps/eungye-traffic-overrides.json`에서 교차로 회전 허용·신호와 도로 차로 수, 접속 허용 여부를 수정하고 재생성한다. 생성된 교차로 목록·위치·설정 ID도 별도 카탈로그로 남긴다.
- 승하차 지점을 연결 가능한 도로에 분산하고 진행 방향 오른쪽에 놓는다. 정차 지점까지 그래프 경로를 포함해 H로 접근할 수 있게 한다. 호출/길가 탑승/요금/정산은 기존 게임 흐름을 사용한다.
- 기존 영통과 국도42 단독 시험은 보존한다. 결합 모드는 `Play-Eungye.cmd`에서 실행한다.

## 검증

원본 HD 링크 보존, 중복 경로 배제, 임시 연결 표시, 설정에 의한 회전 차단, 모든 서비스 승하차 지점 쌍의 연결, 지역↔HD 경계 양방향 주행, 실제 승차·하차·요금 지급, H 입력 보존, 기존 국도42 시험 회귀를 검사한다. 수정한 최종 Unity Player를 빌드한다.
