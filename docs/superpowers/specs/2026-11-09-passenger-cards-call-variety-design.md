# 승객 카드·호출 다양성·지도 정리

사용자 후속 지시에 따라 명시적 ‘승객에게 말 걸기’ 입력은 우선 숨긴다. 앞선 85% 내비 축소는 유지하고, 추가 잡담 데이터/중복 방지 모델은 내부 호환을 위해 남기되 실제 카드에서 잡담을 새로 시작하거나 표시하지 않는다.

- 승객 카드 제목은 기존 offer/trip 식별자에서 임의 한국어 이름을 정해 표시한다. 저장·탑승·LAN에서 동일 승객의 이름은 안정적으로 유지한다. 별도 난수 호출로 배정 순서에 영향을 주지 않는다.
- 카드/대화창의 발언 맨 앞에 붙은 `손님:`·`손님 “…”`·`승객:` 화자 표기만 제거한다. ‘손님이 잠들었습니다’ 같은 상태 설명이나 사용자 원문 데이터는 보존한다.
- M지도 상단의 경로 범례 보조 문구를 제거한다. 우측 호출 선택 시 예상 피로 등 예측 카드 전체를 표시하지 않는다. 예상 운임/승하차 위치·수락 버튼과 수락 불가 사유는 보존한다.
- 호출 단조로움은 실제 후보·배정 규칙을 조사한 뒤 기존 합법/도달 가능 후보 안에서 반복을 줄인다. 지도/정차지를 새로 만들지 않는다. 대표 코스·희소 후보 대체·저장/호스트 권한을 보존한다.
- 최종 실행본은 이전 내비 수정과 함께 검증·main 통합/푸시한다. 사용자 게임 종료 후 받은 최신 저장을 보호 기준으로 사용한다.

단순 UI 제거·기존 식별자로 이름 부여는 직접 적용하고, 호출 변경은 회귀 재현과 분포 수치를 확인해 최소 범위로 적용한다. 실제 Player 위치 제어/화면 검사와 순수 배정 미러 검사를 구분하며 사람 장기/전체3일/다른PC 검사는 별도로 기록한다.
