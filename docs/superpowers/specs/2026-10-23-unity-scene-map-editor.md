# Unity 실게임 화면 기반 지도 편집 설계

사용자 승인: 기존 지도 데이터를 유지하고 Unity에서 실제 실행 화면을 바탕으로3D 선택/이동/회전/크기를 조절한다. 빠른 조작과 Git pull→빌드 재현을 유지한다.

- Unity2022.3 전용 편집 작업공간. 실제 WorldBuilder의 형상·재질·시설 생성과 공유하는 렌더러를 이용한다. 정적 월드와 조명/카메라 프리뷰를 제공하며 운전/NPC/영업 시뮬레이션과 구분한다.
- Scene 뷰에서 클릭/선택강조/F초점/W이동/E수평회전/R크기. 건물 높이와 X/Z크기, 보도/부지 꼭짓점, 서비스 정차점/방향/접근차로를 직접 조절한다. m/도 수치와 현재선택만 표시한다.
- 편집 객체와 runtime 배치렌더링을 구분한다. 배경은 청크 배치 유지, 변경 객체/영향 청크만 갱신한다. 드래그 중 전체JSON 복사·지도합성·검사·디스크저장을 하지 않는다. Undo는 변경객체 단위다.
- 정식 저장은 기존 config/maps/project/eungye.project.json 및 ProjectMapPackage/Store 검증·잠금·해시·충돌검사를 유지한다. 개인자료/생성 씬만 바꿔 수정이 유실되지 않게 한다.
- 기존 FirstDrive 씬을 덮어쓰지 않는 별도 작업공간과 변경초안 복구. 기존 사용자 씬의 미저장 작업, 프로젝트 파일 동시수정, 닫기/Play모드/도메인리로드를 안전히 다룬다.
- 주행 그래프 자동 이동은 범위 밖. 노면/부지 이동과 차로 경로가 별개임을 화면 안내하고 저장 검사로 위험한 배치를 차단한다.
- Unity 편집 기능·저장재현·부분갱신 계측·실게임과 렌더자료 동등성을 검사하고 사용법/이력/배포를 갱신한다. 직접사람클릭/다른물리PC 검증과 자동검사를 구분한다.
