# 은계 유턴·중앙분리 시설 보완

사용자 요청(2026-10-26): 첨부 수인로 시작 주차장 주변 및 전체 맵의 유턴 가능 위치를 네이버 거리뷰로 대조하고 구현. 중앙선이 차로 폭처럼 벌어진 이유를 검사하며 실제 중앙분리 시설을 반영한다. 사용자는 현장 확인된 위치/조건만 주행·내비·편집기에 반영하는 기준으로 질문 단계를 생략하고 바로 구현하도록 선택했다.

## 기준
- Unity 2022.3.62f2 / unity/EungyeTaxi / PrototypeBuild.BuildHybrid / builds/EungyeTaxi/EungyeTaxi.exe.
- config/maps/project/eungye.project.json이 정식 지도. 기존 사용자 변경, 영업 저장, 원본 입력은 보존한다.
- 전체 맵 데이터 검사는 전역으로 수행. 거리뷰 검토량/미확인 접근 수는 실제 기록하며 전역 현장확인을 허위로 선언하지 않는다.
- 유턴은 좌회전과 구별한 명시적 진행으로 저작, 검증, 표시, 경로, 교통·신호에 전달한다. 실제 확인된 진입/도착 차로와 보조표지 조건만 적용. 조건 미확인은 실제 규제로 확정하지 않는다.
- 중앙선, 안전지대 외곽, 도로 가장자리 구분. 분리대가 있는 공간은 임의로 차로 폭을 좁히지 않는다. 거리뷰의 외형 관찰과 게임용 치수는 구별한다.
- 유턴 경로/출입구/횡단보도 개구부를 가로막는 분리대를 만들지 않는다. 메시와 충돌체가 같은 배치를 사용한다.
- 새 직렬화 필드로 기존 Unity JSON 해시가 바뀌지 않게 한다. 필요시 검증된 명시적 이행을 제공하며 해시 검사 우회 금지.
- 빌드 배포 폴더 변경 시 manifest 파일 크기/SHA256 재생성/검증. 검증 구분: 모델, 위치 제어, 물리 주행, 사람 수동, 전체 캠페인.

## 채택 방식
기존 정식 지도 및 공통 차로 그래프를 확장하고, 거리뷰 근거 목록을 지도 변경에 연결한다. 그림만 추가하는 방식은 내비/NPC가 이용할 수 없어 제외한다. 모든 교차로 자동 유턴 허용은 현장 근거가 없어 제외한다.
