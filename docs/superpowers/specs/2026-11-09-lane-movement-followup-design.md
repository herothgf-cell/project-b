# 차로별 표시·지속 녹색 후속 설계

사용자는 J866_5285 서향(129.77594,526.7805 /276.4818°), 추가 두 주행 화면, 지도에 그린 동부 순환로/남쪽 줄기의 차로 수를 네이버 로드뷰와 대조하고 엇나간 선·차로별 유턴/좌회전/직진 표시를 정리하도록 요청했다. 별도로 J7917_2565 동향의 지속 녹색/좌회전 미출현과 내비의3·4구/배치 설명 제거를 요청했다. 이전 중단은 요구 이미지가 추가된 것이며 첫 위치 작업도 포함한다.

기존 Unity2022.3 IMGUI·프로젝트 지도 문서와 검토 메타데이터를 확장한다. 도로별 원본 차로·임시 연결·수입 노면선과 합성 표시를 먼저 분리하고, 확인된 접근에 실제 허용 회전만 표시한다. 유턴의 기하와 turn 코드가 다를 수 있어 기존 조건/연결을 확인한다. 4/2차로는 사용자 추정이므로 실제 촬영 방향/월/차로 수를 확인한 뒤 적용한다. 미확인 허용을 임의 추가하지 않는다.

신호는 사용자가 서 있는 실제 차로/정지선/목적지 상태를 재현하고 수요 전달과 녹색 전환을 각각 관찰한다. 이전69검사 통과만으로 새 제보 해결을 판단하지 않는다. 적색·황색·횡단보도 안전·출구 점유와 LAN 권한을 유지한다. 내비의 형식/현장확인/게임배치 설명은 화면에서 제거하되 내부 외형/법규 데이터는 유지한다.

관련 입력의 정식 저장과 SHA256 검증, 기본 BuildHybrid·은계/A2·기존 사용자 저장/설정 보존·실제 렌더·552방향 경로·신호 회귀 후 main에 게시한다. 기존 사용자 V6 PPTX/마인드맵 변경과 미추적 파일을 제외한다. 큰 도로 형상/차로 연결을 변경해야 한다면 도달 가능성과 실제 물리/포즈 검사를 구분한다. 촬영 근거와 게임 추정 치수를 구분하여 인계 문서에 남긴다.
