# 일시정지 운전 설정 설계

사용자 요청: 일시정지에 설정 메뉴를 추가하여 최근 수정한 좌우 운전 조작감을 직접 조절한다.

제안: 기존 게임 UI 안에서 ‘설정 → 운전 설정’을 연다. ‘적용’으로 저장하고 일시정지로 돌아가며 ‘취소’는 편집 전 상태를 유지한다. ‘기본값’은 편집값만 복원하고 적용 전에는 저장하지 않는다. Esc/패드 시작 버튼은 설정에서 일시정지로 한 단계 돌아간다.

상세형 제안 항목:
- 조향 민감도 50~150%, 기본100%: 같은 입력의 수동 회전량. 최대 중심각52도 상한 유지.
- 조향 반응 속도 25~200%, 기본100%: 누르기/반대 방향 전환 속도.
- 핸들 복원 속도 25~200%, 기본100%: 손을 뗐을 때 중앙 복귀 속도.
- 게임패드 데드존 0~40%, 기본15%: 작은 스틱 입력 무시. 키보드 조향에는 영향 없음.

기본값은 기존 조작감 그대로다. 브레이크/가속·H 보조·봇 조향은 변경하지 않는다. 설정은 캠페인 저장/공유 콘텐츠 프로필과 별개인 이 PC의 PlayerPrefs에 저장하며 싱글/연습/로컬 PVP/LAN 사람 수동 입력에 공통 적용한다.

LAN에서는 수동 조향 민감도·반응/복원 속도를 입력과 함께 보내며 서버가 유한수/범위를 검증하고 같은 함수를 적용한다. 데드존은 송신 전에만 적용한다. v10으로 계약을 갱신하고 구버전 접속을 차단한다. 메뉴를 연 사람의 차만 정지하고 LAN 경기 시간은 계속 간다.

화면은 기존 한국어 카드/버튼 스타일을 유지하며 슬라이더와 현재 백분율, 짧은 도움말을 표시한다. 작은 창에서도 전체 패널이 보이게 크기를 맞춘다.

검증: 기본값 일치·좌우/후진 대칭·각 옵션 독립성·유효하지 않은 저장/패킷·봇/H 격리·저장/취소/기본값·Esc 단계·실제 바퀴 각/복원·싱글/PVP 메뉴 렌더·LAN 서버/로컬 예측·사용자 저장 보존·통합 BuildHybrid/manifest.

현재 상태: 사용자가 상세형4항목을 선택했다. 세부 범위/최대각/저장 방식은 기존 코드와 기본값 보존을 위한 구현 판단이다. 설정 중 다른 모달과 승하차를 차단하고 LAN 경기 종료 시 미적용 편집을 폐기한다.
