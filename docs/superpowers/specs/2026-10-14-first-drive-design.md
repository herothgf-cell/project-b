# T1–T2 첫 주행 시제품 설계

사용자 요청: Unity로 개발 환경을 확인하고, 확보한 T1–T2 지도와 임시 택시로 직접 운전하는 시제품을 만든다. 기존 지도 검토와 사용자 구현 요청을 기준으로 진행한다.

- 실행: Windows PC, 키보드·패드, 후방 카메라.
- 환경: 설치된 Unity 2022.3.62f2 사용. Unity 6 추가 설치는 이번 범위에서 제외한다.
- 범위: 원본 좌표 X 206690~206950, Y 516805~517080. T1–T2와 중간 연결 보존. 거리 압축 없음. 높이는 초기 평면, 건물은 층수 기반 가상 높이.
- 지도: NGI/NDA 검사 파생 JSON에서 도로 중심선·폭·건물 외곽을 읽어 로컬 좌표로 변환. 원본은 보존한다. 현행 규칙 재현이 아닌 2008년 데이터 기반 주행 시험임을 화면과 README에 표시.
- 표현: 회색 도로, 따뜻한 색의 단순 건물, 녹지 바닥, 노란 택시, T1/T2 표지. 유료·외부 아트 자산 없음.
- 운전: 가속·제동·후진·속도에 따른 조향 보정, 충돌, 주차 브레이크, 복구. 게임패드 미연결 시 키보드 정상 동작.
- 안내: 조작 설명, 속도계, T1/T2 도착 연습, 미니맵, 일시정지. ESC 재개 및 종료 메뉴.
- 완료 기준: 지도 변환 검사 통과, Unity 컴파일, Windows 빌드, 물리 주행 자동 검사 및 렌더링 확인. 실제 패드 손맛은 하드웨어 테스트가 없으면 미검증으로 명시.
- 제외: 승객, 수익, 교통 AI·신호 위반, 현실 높이, 지역 확장.

구성: Python 데이터 변환 → Unity Resources 지도 JSON → 런타임 도로/건물 생성 → WheelCollider 택시 + 입력/카메라/HUD. 에디터 도구가 시작 장면·Windows 빌드를 생성한다.

경계 도로는 선분 단위로 잘라 원형을 유지하고 가장자리에 경계를 표시한다. 건물은 경계 밖을 버리고 단순 외곽에 한해 벽/지붕을 생성한다. 차량과 건물 충돌을 켜며 바닥은 연속 충돌면을 둔다.
