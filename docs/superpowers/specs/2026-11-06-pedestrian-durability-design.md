# 보행자 사고 내구도 손상

사용자는 보행자 사고에도 0~N 내구도 손상을 요청했고, 경미0~2/중간0~5/중대0~10점(100점 기준)을 승인했다. 각 정수는 균등하게 선택하며 손상0도 가능하다. 기존 차량·시설 물리 충돌의 최대50점보다 작은 상한이다.

기존 사고 등급을 재사용하는 방식을 채택한다. 속도별 별도 사고 등급을 만드는 방식은 이번 범위에 필요하지 않다. 사건 ID와 별도 salt로 호스트가 손상량을 한 번 선택해 사고 상태에 저장하고, 안전 정차 정산 때 적용한다. 같은 사건의 상태 재생·재접속·저장 복원·수리 후 재생으로 중복 손상되지 않도록 차량 손상 snapshot에도 적용 사건 ID를 보존한다.

기존 저장의 진행 사고에는 소급 적용하지 않는다. 새 사건에만 적용 자격 표식을 저장하며, 구 차량/시설 사고가 보행자 사고로 우선 분류되어도 구 사건의 면제는 유지한다. 동시 차량/시설 물리 손상은 별도로 유지하며 내구도는0 아래로 내려가지 않는다. 중대는 기존 공업사 강제 이동, 경미/중간으로 D0이 되면 기존 고장 견인·수리 절차를 따른다. 비용/시간/점수 수치는 이번에 바꾸지 않는다. 팝업에는 실제 내구도 감소량을 추가한다. LAN은 새 상태 계약을 구분하는 v8로 갱신한다.
