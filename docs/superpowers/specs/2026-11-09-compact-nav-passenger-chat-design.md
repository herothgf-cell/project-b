# 작은 내비와 반복 없는 승객 잡담

- 요청: 상단 내비를 조금 줄이고 선택지 없는 잡담을 왼쪽 아래 승객 카드에서 말하는 형태로 표시한다. 동일한 대화는 한 운송에서 한 번만, 다른 대화는 기존 간격을 유지하고 부족한 문구를 추가한다.
- 선택지: 잡담 전체 제거/운송당 한 번 제한 대신 사용자가 지정한 **대사별 중복 방지 + 카드 표시**를 적용한다. 요청·행동 선택지와 기존 만족도·Quiet 약속 위반 효과는 보존한다.
- 내비: 중심/상단 위치를 유지해 본문·신호·다음 회전 전체를 85%로 축소한다. 미니맵과 다른 HUD는 그대로 둔다.
- 잡담: 기존 명시적 말 걸기 입력과 12초 간격·6초 표시를 유지한다. 큰 무선택 대화창과 큰 말 걸기 버튼은 제거하고 승객 카드의 작은 입력과 말풍선으로 표시한다. 기본 잡담 7개를 추가해 기존 1개와 8개를 구성한다. 기사 질문은 카드에서 제외하고 승객 발언을 표시한다.
- 중복: 실제 표시 문구 기준으로 운송별 기록을 저장·복원/LAN snapshot에 함께 전달한다. 구저장은 마지막 잡담을 이미 표시한 대사로 이관한다. Quiet 위반 반응도 동일 대사는 반복하지 않는다. 새 승객이면 초기화한다.
- 기존 설정의 직접 편집 문구/최대 4,000자와 기존 선택 효과를 보존한다. 신규 자동 요청·자동 잡담·만족도 보너스는 만들지 않는다.
- 검증: 대사 중복/구저장/새 승객/서로 다른 문구·Quiet 효과와 실제 Player 카드/선택지/내비 화면, 배포 manifest 및 사용자 저장 불변을 확인한다.

1인칭의 기존 오른쪽 승객 카드는 잡담 표시 동안만 왼쪽 아래로 이동하고 운전 점수창은 오른쪽에 두어 중복 카드와 겹침을 피한다.
