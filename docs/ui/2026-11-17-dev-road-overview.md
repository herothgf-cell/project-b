# 설정 개발용 도로 전체 보기

사용자 지정: 일반 M 지도가 아니라 설정의 별도 개발 기능. 첨부한 실제 게임 도로의 수직 내려보기 화면을 이동·확대하면서 도색, 도로와 보도 폭을 확인한다.

## 방식
- 기존 설정의 개발용 테스트 탭에 `도로 전체 보기` 버튼. 설정 임시 변경값을 적용하거나 버리지 않고 화면만 왕복한다.
- 별도의 비활성 카메라로 현재 월드를 RenderTexture에 촬영한다. 북쪽 위, 수직 정사영. 드래그 이동, 휠/버튼 확대축소, 전체 보기, 내 위치, 중앙 좌표 표시.
- Esc와 돌아가기는 설정으로 복귀. 주행 카메라, 차 위치, 저장, 기존 M 지도, 일시정지 상태를 변경하지 않는다.
- 기존 지도 배경을 확대하는 방식은 실제 차선·보도 형상을 확인할 수 없어 제외. 사전 타일 저장은 현재 수정 내용을 즉시 보여주지 못하므로 제외.
- 열려 있을 때만 제한된 주기로 그리며 닫을 때 렌더 자원을 해제한다.

## 구현·검증 계획
- [x] 독립 좌표 변환/줌/팬 모델 검사. 사각 화면에서 북쪽 위와 커서 기준 확대를 확인.
- [x] 개발용 뷰와 설정 진입/뒤로 연결. 설정 Draft 보존.
- [x] 실제 실행본에서 전체/상세/작은 창 화면, 카메라·차량·일시정지 보존, 재진입/자원 해제 검사.
- [x] 작업 이력과 차로 점검 결과 기록, 통합 빌드 검증.

제안 구현 세부(담당자 판단): 확대 상한64배, 0.25초 이하 간격 재렌더, 별도 개발 화면에서 좌표 표시. 사용자 승인 범위는 설정 개발 기능 배치이며 이 값은 구현상 기본값이다.

## 지점 제보와 이미지 주석 확장
사용자 요청: 클릭한 지점의 좌표·가까운 교차로 ID 복사, 현재 화면 이미지 복사 및 수정 내용 편집.
- 단순 클릭 시 클릭 지점을 선택하고 지역·x/z·가까운 교차로 ID/거리 복사. 드래그는 복사하지 않는다.
- `캡처·편집`은 현재 도로 화면을 고정한다. 선택 지점(없으면 화면 중앙)의 위치 설명과 표식을 포함한다.
- 캡처 위 펜/화살표/텍스트, 텍스트 수정, 되돌리기. 이미지만 바꾸고 지도 데이터는 변경하지 않는다.
- `이미지 복사`는 편집된 캡처와 위치 설명을 Windows PNG/DIB 클립보드에 넣는다. 잠긴 클립보드는 오류를 표시하고 재시도 가능하다.
- Esc는 캡처 편집→도로 보기→설정 순서. 캡처/텍스처는 나갈 때 해제한다.
- 검증: 클릭/드래그/좌표 변환, DIB 바이트 방향·색상, 실제 창에서 한국어 텍스트/표식·이미지 클립보드 형식·설정 복귀.
