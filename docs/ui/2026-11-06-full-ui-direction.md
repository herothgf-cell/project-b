# 전체 UI 스타일 적용 기준

사용자가 최초 캐주얼3D 시안을 기준으로 전체 UI를 통일하는 추천 방향을 승인했다. 맵과 차량 외형은 가장 마지막에 별도 검토한다. 기존 main 게시 지시를 유지한다.

## 공통 기준

밝은 아이보리/하늘색 바탕, 진한 남색 본문, 둥근 카드와 얕은 그림자, 굵고 명료한 아이콘, 초록 주요 행동/파랑 안내/빨강 경고를 공유한다. 큰 제목·짧은 대사·현재 필요한 숫자 순으로 읽힌다. UI용 캐주얼3D 초상을 추가하되 월드 캐릭터/맵/차량 모델은 교체하지 않는다. 의미 없는 장식/허위 보상/미구현 시스템은 추가하지 않는다.

## 화면 목록과 소유 범위

| 그룹 | 현재 화면 | 적용 |
|---|---|---|
| 진입 | 모드 선택, 싱글 준비/복구, PVP 설정/LAN 대기실 | 한 가지 주요 행동·모드별 설명·초상/아이콘·명확한 입력 |
| 주행 | 상태계, 네비/신호/잔여초, 운행 요약, 승객 평가, PVP 현황 | 도로 시야 우선·크기/간격/색 계층·중복 문구 정리 |
| 승객 | 요청/유형/상황 선택·응답·하차 | 초상/말풍선·명확한 답변/효과 분리·스크롤 보존 |
| 지도 | 미니맵·M지도·시설 비교 | 기존 형상/핀/경로 유지, 제목/목록/버튼 체계 통일 |
| 운영 | 시설/수리/사고/경고·일시정지/도움말/운전 설정/기록 | 비용·시간·거부 사유 유지, 공통 패널/확정·취소 |
| 결과 | 운송 완료·하루/캠페인 마감·PVP 결과 | 실수령/순수익·평가·후속 행동 우선, 상세 보존 |
| 개인 공간 | 현재 방/소유/미리보기/구매 확인 | 기존 방 그림/구매 규칙 보존, UI 카드/문구 통일 |
| 연습 | 연습 선택·피드백 | 공통 스킨/제목/행동 명칭 적용 |

지도 제작/성능 진단·밸런스 관리 웹 도구는 게임 플레이 화면이 아니므로 전면 재배치 대상에서 제외하며 공통 게임 스킨 영향을 받는 기존 기능은 유지한다.

## 반드시 보존

기존 기본값93커밋을 반영한 main d292508 위에서 작업한다. 조작/패드·단축키·차량·신호 주기·승객 효과/비용·기한·개인 구매·이어하기/복구·LANv10 권한/시계/재접속은 변경하지 않는다. 신호 잔여 초·5종 상태·승객S/R/운전점수·정산3줄은 유지한다. 싱글/오프라인PVP/LAN은 같은 디자인을 사용하지만 시간·수입 의미는 각각 보존한다. 위험/기한/결제/복구 문구는 짧게 쓰더라도 조건을 없애지 않는다.

1280×720/1920×1080에서 읽고 누를 수 있게 검증하고 긴 대화/긴 장소명은 기존 감싸기/스크롤을 유지한다. UI 픽셀 변화용 단순 모방 검사는 새로 만들지 않고 기존 테마 대비·입력/모드/정산 계약과 실제 화면/격리 저장 검사를 사용한다.
