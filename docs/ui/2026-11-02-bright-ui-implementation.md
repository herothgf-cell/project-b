# 밝은 캐주얼 UI 적용 계획

사용자가 채팅의 밝은 6화면 시안을 기준으로 싱글과 통합 PVP의 UI 적용 및 main 푸시를 승인했다. 배경 그림은 참고이며 맵·차량·월드 아트·운전 물리·경제/승객/저장 규칙은 유지한다.

## 설계와 선택

기존 Unity IMGUI를 유지하고 공유 테마에 흰색/아이보리 카드, 하늘색 보조 버튼, 초록 주요 행동, 진한 글자, 둥근 모서리와 작은 그림자를 도입한다. 별도 Canvas 전면 재작성은 입력/저장 흐름 변경 위험과 이번 스타일 범위를 고려해 선택하지 않는다. 공통 스타일만 바꿔 흰 글자가 흰 카드에 남지 않도록 명시적 색상과 직접 그리는 패널도 함께 수정한다. 도로 신호·차량·맵 원본은 수정하지 않는다.

## 작업 순서와 검증

- [x] 공유 카드·버튼·아이콘/게이지 스타일: 밝은 카드와 글자 대비·모서리 투명도·캐시 재사용 검사, 기존 기능 검증.
- [x] 싱글/통합 PVP 공통 HUD·지도·대화·서비스·정산·준비/하루 마감 및 모드 선택/PVP 결과에 적용. 기존 클릭 영역·단축키·정차 조건 유지.
- [x] Unity 컴파일/Editor 검사와 모델 회귀, 실제 Player에서 1280/1920의 싱글/PVP 화면·지도·대화·정산 검증. 저장은 별도 검사 경로 사용.
- [ ] 기존 맵/차량 소스 불변 확인, BuildHybrid 통합 배포·manifest 실제 크기/SHA256 검증, 작업 이력·관련 기획/체크리스트 갱신·대상 파일만 커밋·main fast-forward 푸시 후 원격 해시 확인.

기존 사용자 미커밋 파일 및 다른 작업의 마인드맵 변경을 보존한다. 현재 작업 디렉터리에서 사용자 지시의 main 배포를 수행하고 별도 작업트리나 새로운 Unity Library를 만들지 않는다. 작업 이력에 실제 명령 결과와 수동 플레이 미검증을 구분한다.

## 후속 요청: 문구와 정보량 정리

사용자는 틀·색상뿐 아니라 시안처럼 간단명료한 문구 적용을 요청했다. 운전 중 안내는 행동과 현재 상태만 짧게 표시하고, 버튼은 ‘호출 수락’, ‘영업 시작’, ‘계속 영업’, ‘모드 선택’처럼 행동으로 쓴다. 준비 화면은 잔액/연료/포만감/피로와 이용 비용을 분리한다. 하루 마감은 순수익·수입/지출·운송 수·상태가 먼저 보이며 기존 비용·공차/탑승·일별 장부는 ‘상세 내역’에서 확인한다.

| 이전 표현 | 적용 표현 |
|---|---|
| 번호를 선택하면 승차·운송 경로를 표시합니다 | 호출을 선택하세요 |
| 호출 수락 · 이용 조건 확인 | 호출 수락 (거부 사유는 바로 위에 유지) |
| 전방 신호 안내 / 접근 방향의 신호를 찾는 중 / 현장 신호·주변 차량을 확인하세요 | 전방 신호 / 도로 신호를 확인하세요 |
| 같은 설정으로 재경기 | 다시 경기 |
| 모드 선택으로 돌아가기 | 모드 선택 |

운임·비용/시간·승객 응답 효과 수치·조건부 확률·저장 초기화/원본 보관 안내는 생략하지 않는다. PVP 지도를 열어도 경기 시간이 흐르고 내 차는 제동한다는 안내를 유지한다. 마감 상세 펼치기는 표시만 바꾸며 장부와 상태를 변경하지 않는다.

## 후속 요청: 회전 안내 카드

첨부 참고처럼 큰 방향 화살표·회전까지 남은 거리·다음 도로명과 작은 후속 회전 안내를 표시한다. 기존 `hdRoute`의 방향 링크와 경로 누적거리를 읽는 표시 전용 기능이며 지도/경로 탐색 규칙은 바꾸지 않는다. 다음 회전의 거리는 첫 회전을 끝낸 뒤의 구간 거리로 ‘이후’라고 표시한다. 좌/우회전·유턴·차로 변경·직진·도착을 구분하고, 도로명이나 후속 회전 정보가 없으면 지어내지 않는다. 경로/차로 위치가 확인되지 않거나 시설 출구 수동 동선인 경우 기존 문자 안내를 유지한다. 경로 전환 버튼과 남은 전체 거리·ETA도 함께 유지한다.
