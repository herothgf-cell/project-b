# 신호 카운트다운 텍스트 복원

사용자 요청대로 기존 네비/운행 요약 두 카드를 유지하면서 네비의 신호 안내를 직진·좌회전 상태 / 우회전 조건 / 신호 변경까지 N초의 텍스트 세 줄로 표시한다. 아이콘·게이지·신호 주기 변경은 없다.

- DrivingReadability에서 기존 TrafficSystem.SecondsToSignalChange를 읽고 올림한 초를 표시한다. 값이 없거나 유효하지 않으면 숫자를 만들지 않는다.
- 네비 하단 신호 안내 시작을4px 올리고 각 줄을18px로 배치하여 기존196px 카드 안에 넣는다. 운행 요약/네비 전체 위치는 유지한다.
- SignalCountdownTests로 실제 신호 시계의 녹색/황색/적색 전환·초 올림·미확인 신호 숨김·시계 불변을 검사하고 BuildHybrid로 배포한다.
- 격리 저장의 신호 UI fixture에서1280/1920 화면을 확인하고 이력·manifest와 함께 기존 승인대로 main에 게시한다.
