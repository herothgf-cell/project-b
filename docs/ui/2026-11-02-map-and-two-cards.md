# 지도 스타일·두 카드 HUD 적용 계획

사용자가 미니맵/M지도 스타일 조정과 네비+운행 요약 두 카드 시안을 승인하고 이어서 구현하도록 요청했다. 기존 main 푸시 지시는 유지한다.

**Goal:** 실제 지도 형상을 밝은 블록·도로·수변으로 읽기 쉽게 표현하고 왼쪽 안내 3개를 2개로 합친다.
**Architecture:** 기존 IMGUI·지도 좌표 투영·클릭 영역을 보존한다. 지도 배경만 실제 MapData의 면/건물/도로를 캐시한 텍스처로 교체하고 공유 핀을 사용한다.
**Tech Stack:** Unity 2022.3 / C# / IMGUI.
**Spec:** 이 문서와 승인된 채팅의 두 카드 시안, content-design/05-interface-and-navigation.md.

## 제약·검토 지점

- 맵/차량/경로 탐색/승객·PVP 규칙과 저장은 유지한다. 없는 건물·도로·장소를 만들지 않는다.
- 승차 파란 실선·운송 분홍 점선. 교통 필터를 켜면 기존 혼잡 색을 경로 안에 표시한다.
- 위치 핀은 기존 클릭 영역·PVP 겹침 회피를 보존하고 플레이어 화살표는 실제 방향을 따른다.
- 일반 신호는 네비 안에 요약, 교육용 신호의 비보호/점멸/우회전 조건은 없애지 않는다.
- 길 찾기 없음/시설 출구/도착, 빈 지도 배열/화면 밖 폴리곤/도로 폭, 1280/1920, 싱글 지도 정지/PVP 지도 진행을 검증한다.
