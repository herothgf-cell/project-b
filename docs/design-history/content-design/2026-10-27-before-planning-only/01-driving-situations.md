# 운전 상황 콘텐츠

현재 기준: 2026-10-27. 상황의 실제 단서·행동·결과를 정의한다. 날짜별 경위와 기존 상세 장면/선택 예시는 [별도 이력](../../../content-design/../design-history/content-design/2026-10-27-before-refresh/01-driving-situations.md)에 보존한다. 게임 규칙과 실제 법령 검토를 혼동하지 않으며 판정 근거·보류 조건은 [02 평가](02-driving-evaluation.md)를 따른다.

## 일반 영업과 연습의 분리

| 콘텐츠 | 일반 은계 영업 | 별도 연습 | 결과 영향 |
|---|---|---|---|
| 출구 앞 정체 PS08 | 계획 팝업/선택지 제외. 도로·차량·대기열과 실제 운전 관찰은 유지 | F6의 대기/우회/앞부분 진입 비교·재시도 유지 | 실제 행동이 법규/운송에 영향. 선택 버튼만으로 점수 없음 |
| 우회전 PS09 | 유효 접근에서 신호·보행자 확인용 계획 안내. 확인/직접 운전 후 같은 상태로 재개 | F5의 R1~R5 조건 비교 | 정지·양보·실제 횡단 상태로 판정 |
| 비보호 좌회전·점멸·유턴 구역 | 현재 지도·접근 방향·표지·신호를 관찰해 실제 운전 | 지원하는 동일 조건만 재시도 | 준수/위반/보류/기회 없음을 구분 |
| 승객 요청 | 상황 안내와 별도. 안전 정차 중 순차 제시 | 영업 운송·수익과 분리 | [04](04-passengers-and-reservations.md)의 요청별 결과에만 반영 |

PS08 팝업이 없다는 것은 대기열을 통과해도 된다는 뜻이 아니다. F6 연습에 남은 선택 화면을 일반 영업의 필수 절차로 설명하지 않는다. 기존 저장에 PS08 계획 화면이 열려 있어도 영업에서는 다시 열지 않는다.

## 공통 경험

| 단계·조건 | 행동 | 즉시 결과 | 다른 시스템 영향·예외 |
|---|---|---|---|
| 지정 접근 | 신호·표지·노면·차량·보행자 확인 | 현재 조건 안내 | 확인되지 않은 규제는 판정 보류, 내비가 위반을 허용하지 않음 |
| 정상 대기 | 정지선 밖·대기열 뒤에서 정차 | 진입 기회까지 대기 | 영업·운송 시계/공회전 지속. 합법 대기 자체 M 감점 없음 |
| 합법 우회 | 연결된 도로로 경로 변경 | 실제 거리·ETA 재탐색 | 시간/연료 변동. 버튼 선택 자체 감점 없음 |
| 위험 진입 | 실제 금지 끼어들기·양보 위반 등 성립 | 해당 사건 기록 | 사건별 최대 법규 감점, 운송 M은 별도 관찰 |
| 구간 종료 | 실제 행동과 주변 영향을 확인 | 사건 카드·이유·운송 결과 | 같은 사건 중복 차감/준수 회복 방지 |
| 연습 재시작 | 같은 조건 또는 변형으로 재시도 | 연습 상태 새로 시작 | 본 영업 수익·위치·원래 기록 덮어쓰기 금지 |

## 출구 정체 판단 (일반 주행·F6 연습)

| 행동 | 결과로 확인할 내용 | 평가·운영 영향 | 잘못 해석하면 안 되는 점 |
|---|---|---|---|
| 줄 뒤 대기 | 앞차 간격·대기 시간·출구 접근 유지 | 합법 대기는 중립. 실제 기회에서 준수 관찰 시 운전 점수 규칙 적용 | 기다렸다는 이유만으로 돈·만족도 자동 보상 없음 |
| 다음 연결도로 우회 | 방향 경로 연결·추가 거리·ETA | 실제 운행시간·연료·도착 결과 변화 | 우회라고 무조건 감점/가점하지 않음 |
| 앞부분 진입 검토 | 금지 대기열 해당 여부·진입 궤적·타차량 통행 영향 | 성립한 위반만 사건에 기록 | 잠깐 들어왔다 빠졌어도 이미 성립한 위반은 유지. 관찰하지 않은 방해를 추정하지 않음 |
| 선택 변경·복귀 | 처음 행동과 이후 행동 순서 | 동일 사건 안에서 변화 기록 | 기존 위반을 지우거나 위반을 두 번 더하지 않음 |

## 우회전 조건과 결과

| 관찰 조건 | 필요한 행동 | 결과 영향 | 예외·보호 |
|---|---|---|---|
| 우회전 전용 적색 | 진행하지 않고 정지 | 위반 시 해당 신호 사건 | 잠깐 멈췄다고 적색 진행 허용 아님 |
| 전용 신호 없고 전방 적색 | 먼저 정지하고 주변 확인 | 단순 정지 누락과 신호·보행 위험 배점 분리 | 정지 후에도 보행자/차량 조건 확인 |
| 보행 녹색·사람 없음 | 필요한 정지·서행과 횡단하려는 사람 확인 후 판단 | 신호 색만으로 보행 방해를 추정하지 않음 | 사람 없음 관찰이 부족하면 보류 |
| 횡단 중/횡단하려는 사람 있음 | 안전하게 기다리고 양보 | 실제 보행 보호 행동 관찰 | 접촉이 없어도 보호 위반 가능 |
| 횡단 도중 적색 전환 | 이미 들어온 사람이 완주하도록 양보 | 완주까지 점유 유지 | 적색 전환을 보행자 삭제/통과 신호로 쓰지 않음 |
| R1~R5 연습 | 같은 신호·보행 조건으로 재시도 | 이번 시도 근거·다음 행동 피드백 | 별도 연습 결과를 영업 거래/점수로 중복 적용하지 않음 |

정확한 감점표는 [02](02-driving-evaluation.md), 승객 M과 S는 [04](04-passengers-and-reservations.md), 실제 시나리오 연결은 [09](09-prototype-scenarios.md), 일반 보행자는 [16](16-ambient-pedestrians-proposal.md)를 따른다.

## 화면·시간·저장

| 조건 | 처리 | 영향 |
|---|---|---|
| 허용된 상황 계획창 | 이전 일시정지/시간 배율 보관 후 정지, 선택·건너뛰기 후 복원 | 해당 화면에서 운송/영업·컨디션 시간 정지 |
| 이미 본 안내 | 캠페인 운행 저널의 노출 상태로 반복 강제 표시 방지 | 새 캠페인은 새 노출 주기 |
| 상황·지도·요청 중첩 | 운전 판단/상황 안내를 우선하고 새 요청 대기 | 움직이며 응답을 강요하지 않음 |
| 영업 이어하기 | 위치·실제 상황 상태·기록 함께 복원 | 복원으로 위반 삭제·보상 재지급 금지 |
| 관찰 불가/지도 불명 | 사실과 보류 사유 보존 | 법규 성과 집계에서 미확정 사건 구분 |

프로토 제외: 전역 돌발 정체·복잡한 군중·날씨/시야 장면의 대량 제작·실제 시험 채점 재현·사고 책임/수리비·예약. 현재 게임 콘텐츠 범위는 [00](00-RoadMap.md), 실제 검증은 [작업 이력](../../../content-design/../work-history/LATEST.md)을 따른다.
