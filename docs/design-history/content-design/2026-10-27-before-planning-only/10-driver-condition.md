# 운전자 설정과 하루 컨디션

기준일: 2026-10-27. 포만감·피로·식사·수면과 피로100의 반복 눈감김/최종 시야 차단·안전 하차·긴급 귀가 후 당일 마감을 정의한다. 수치·시간은 게임 시험값이며 실제 생리 기준이 아니다. 이전 정책·후속 아이디어는 [변경 이력](../../../content-design/../design-history/content-design/2026-10-27-design-decisions.md)에 분리한다.

## 캐릭터와 범위

| 항목 | 설정·조건 |
|---|---|
| 배경 | 경기 악화로 실직한 뒤 개인택시로 생계를 이어가는 운전자 |
| 시작 | 차량 한 대 준비. 면허 취득·차량 구입 과정 생략 |
| 목적 | 운송·경로·식사·휴식을 스스로 배치하고 남긴 수익 비교 |
| 성장 | 플레이어 판단 숙련. 능력치 구매·차량 성능 강화 제외 |
| 이름·나이·성별 | 프로토 진행 조건으로 고정하지 않음 |
| 반복 | 3일 내 상태 이월, 새 캠페인에서 동일 초기값. [07 캠페인](07-campaign.md) 기준 |
| 포함 | 포만감·피로 안내, 거점 식사/수면, 이동 중 졸음, 저장 복원 |
| 제외 | 스트레스·질병·추가 체력, 실내 보행·침대 조작·수면 미니게임, 강제 충돌 |

## 수치와 행동 조건

| 요소·상태 | 수치·시간 | 영향 |
|---|---|---|
| 포만감 | 새 캠페인 80, 범위 0~100. 영업·수면 1분당 -5 | 10 이상25 미만은 깨어 있을 때 피로 증가율1.5배,10 미만은2배 |
| 피로 | 새 캠페인 10, 범위 0~100. 깨어 있는 영업 1분당 +4, 배고프면 +6, 심한 공복은 +8 | 70부터 휴식 권장,100이면 활성 시간에 졸음 누적 |
| 포만감 0 | 하한 유지 | 굶주림만으로 운송 중단·추가 중첩 페널티 없음 |
| 피로 70~99 | 현재 운송·신규 호출·길가 승차 가능 | 운송 후 예상 피로와 휴식 권장 |
| 피로 100 | 최초에는 영업 가능, 활성 영업 누적120초부터 신규 승차 차단 | 졸음 누적은 아래 단계 적용. 정차·빈차도 누적, 메뉴는 정지 |
| 식사 | 50초 경과 후 포만감 +70, 상한 100 | 경과 중 포만감 감소·통상 피로 증가 먼저 반영 |
| 수면 | 100초, 피로 -40(하한 0) | 수면 중 포만감 감소, 통상 피로 증가 없음. 졸음 상태 해제 |
| 다음 날 야간 수면 | 피로 -60(하한 0), 다음 날 예산 미소비 | 포만감 이월. 마감 휴식 회복과 별도로 적용 |
| 최초 예정 20분 경계 | 피로 100으로 설정·초과 영업 | 자동 정산 없음. 경계는 날짜당 한 번만 적용 |
| 서비스 중 경계 통과 | 식사는 경과·회복 뒤 피로 100, 수면은 피로 100에서 수면 회복 적용 | 회복 뒤 이미 초과 시간이라는 이유로 재설정하지 않음 |
| 정차 | 깨어 있는 활성 영업 시간 | 컨디션·졸음 누적 계속, 정차만으로 회복 없음 |
| 일시정지·메뉴·복습·결과 | 시간 정지 | 컨디션·졸음도 정지, 창을 오래 열어 자동 회복하지 않음 |

배고픔 경계는 경과 구간별로 적용해 큰 시간 한 번과 작은 프레임 분할의 결과를 같게 한다. 포만감·피로 숫자만으로 만족도·법규 점수·운임을 자동 감점하지 않는다. 졸음 증상 이외에 상시 조향/가감속 성능 저하를 추가하지 않는다.

## 지속 졸음·귀가 휴식

| 단계·조건 | 동작 |
|---|---|
| 누적 기준 | 피로100인 활성 영업 시간. 이동·정차·빈차·탑승 중 모두 누적. 메뉴·일시정지·상황 선택·지도·결과·연습·시설 확인 중 정지 |
| 초기 안내·졸음 중 표시 | 최초5활성초만 토스트 경고, 이후 택시 위에 Zzzz. 같은 수면 주기에서 반복 경고창 없음. 지도/일시정지·저장복원에도 누적 시간을 기준으로 유지 |
| 초기 졸음 30~120초 | 누적30/50/70/90/110초에 빠르게 눈을 감았다 뜨는 시야 축소·암전. 감김 강도55→87%, 회당1.2→4초로 증가하며 사이에는 시야가 다시 열림. 이는 피로 회복이 아니며 누적 시간은 계속 유지 |
| 최종 시야 축소 120~180초 | 위·아래 눈꺼풀 형태의 차폐와 약한 주변부 암전이 매끄럽게 확대되어180초에 완전히 닫힘. 이 단계는 수면 전까지 다시 열리지 않음 |
| 중도 하차 120초 | 탑승객은 위험 대사 후 자동 감속6m/s²·저속(<0.56m/s) 정차 뒤 하차/운송 취소. 미탑승 호출도 취소, 신규 호출·길가 승차는 수면 전까지 차단 |
| 취소 정산 | 운임/보너스0원, 실패1건·취소 결과1건. 중복 취소/지급 없음. 요청 미이행·법규·매너의 추가 자동 감점 없음. 구토/청결 하차 처리는 보존 |
| 완전 상실 180초 | 전체 주행 시야 차단·입력 차단·자동 정차. `졸음 운전으로 위험합니다. 오늘 영업을 종료합니다.`와 귀가 휴식·영업 종료 버튼 표시 |
| 긴급 귀가 확정 | 차량 정차 후 명시 버튼으로 기존 임시 주차 거점 복귀.100게임초 경과·피로20회복(정상40의 절반), 포만감 통상 감소. 당일 Closing→일일 정산, 같은 날 재영업 불가. 정상 마감 수면40을 추가 적용하지 않음. 다음 날 야간 회복은 기존 규칙 유지 |
| 정상 수면 | 완전 상실 전 거점 수면은 기존100초/피로40회복. 완전 상실 뒤 일반 시설/마감 수면으로 긴급 회복을 우회할 수 없음 |
| 회복·저장 | 피로100 미만 또는 수면 시 누적 해제. 누적 소수초와 취소 결과를 저장/복원. 구형 확률 졸음 필드는 읽을 수 있으며 신규 누적은0부터 시작 |
| 평가 | 졸음 자체 법규 감점 없음. 자동 정차 이전 실제 충돌·법규 위반은 기존 관찰 규칙으로 평가 |

## 거점 이용·마감

| 단계 | 조건·처리 |
|---|---|
| 접근 | 식당 또는 주차장/휴식 구역으로 직접 이동·빈차·지정 방향 정차 |
| 호출 | 미탑승 호출은 취소 후 식사/수면 이용. 탑승 중은 목적지 하차 후 이용 |
| 확인 | 소비 시간·가격·회복 후 예상 상태를 표시. 비용·시설 조건은 [05](05-daily-operation.md) 기준 |
| 확정 | 비용/미납·경과·회복을 동일 이용 ID에 한 번 적용 |
| 취소 | 돈·시간·상태 변화 없음 |
| 계속 영업 | 남은 예정 시간과 관계없이 서비스 이용·호출 재개 가능, 자동 호출 수락 없음 |
| 휴식·영업 종료 | 빈차로 주차장·휴식 구역에 정차 후 무료 수면 100초·피로 40 회복, 실제 초과 시간·비용·결과 한 번 정산 |
| 자금 부족 | 식사는 미납·수면은 무료, 신규 대출 없음. 미납도 비용으로 기록 |
| 세차 | [15](15-drunk-passengers-and-cleanliness.md)의 시간만큼 깨어 있는 컨디션 경과. 식사/수면 대체 아님 |
