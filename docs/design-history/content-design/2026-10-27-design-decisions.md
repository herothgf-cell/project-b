## 별도 승인/개발이 필요한 아이디어

| 제안 | 기대 판단 | 현재 제공 여부 |
|---|---|---|
| 추가 승하차/짐 싣기 시간 | 짧은 운송의 시간 효율 비교 | 미구현. 기존 취객 기상 대기와 다름 |
| 정체 응대 변주 | 실제 관찰된 지연 설명·합법 우회 제안 | 추가 변주는 미구현, 현재 경로/ETA 요청과 구분 |
| 공복 권장 토스트/운송 후 식사 예측 | 식사 시점 판단 지원 | 새 알림/예측 제안은 미구현. 현재 공복 피로 배율만 적용 |
| 소식 메뉴 예시 | 정식보다 짧은 시간/회복·가격 비교 | 1,000원/20초/+30은 과거 제안값이며 실제 메뉴 아님 |
| 안전 대체 승하차 지점 | 막힌 공간을 다른 안전 후보로 이동 | 검증된 후보·보행 동선 확보 전 미구현 |
| 시간대/지역별 추가 대사·보험·예약 등 | 콘텐츠 확장 | 이번 Proto 필수 범위에 자동 추가하지 않음 |

현재 기능의 체감 조정과 신규 콘텐츠 승인은 다른 일이다. 계획 표만으로 구현/물리 주행/사람 수동 검증을 완료 표시하지 않는다.
