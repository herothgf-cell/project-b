# 승객 요청별 콘텐츠와 효과

요청의 배정·발생 시점·복수 요청·저장 규칙과 만족도·운임은 [04 승객 운송](../../../content-design/04-passengers-and-reservations.md)을 기준으로 한다. 이 문서는 17종 요청의 대사, 선택, 실제 효과와 관찰 기준을 정의한다. 과거 산식·구현 대조표는 [11 변경 이력](../../../content-design/../design-history/content-design/11-passenger-request-effects-history.md), 개발 완료 여부는 [체크리스트](../../../content-design/../prototype-development-checklist.md)에 둔다.

## 공통 표현과 평가

아래 표의 **대사·선택·효과는 기존 17종 콘텐츠**를 설명한다. `발생 조건` 열의 중간 정차·복수 요청 충돌 제한과 EV03 하차 후 전용 전환은 **P11 구현·자동 저장 통합 검사 통과** 상태다. 전체 물리 주행/수동 플레이 완료 상태는 작업 이력을 따른다.

- 요청을 선택하는 버튼에는 플레이어가 할 대답과 실제 적용 효과를 함께 표시한다. 클릭과 Y/I/O/U는 같은 선택을 실행한다.
- 응답 자체만으로 보상하지 않는다. 경로·약정 변경은 확정 전에 새 목적지·추가 거리·운임·기한을 보여주고, 운행 뒤 실제 결과를 확인한다.
- 안전상 보류·합법적 거절·후보 없음·관찰 불가는 중립이다. 요청에 답할 안전한 기회가 없으면 미응답 감점을 주지 않는다.
- 요청별 만족도 변화는 조용한 운행 +5, DR +8/-10, CH +5/-5, EV01/02 +6/-8을 초깃값으로 쓴다. ETA·EV03·EV04는 요청 변화 0이다. 조용한 운행 미응답의 기존 M -5는 요청 변화에서 다시 차감하지 않는다. 복수 요청의 합산·상한은 04의 변경 기획을 따른다.
- 보너스는 요청 종류나 응답 버튼이 아니라 최종 승객 만족도 S와 요구 R로 판단한다. 음악·요금·분실물·불법 요구·안전상 보류도 다른 행동으로 S가 R에 도달하면 공통 보너스를 받을 수 있다.
- 결과에는 요청별 제시 시점, 선택, 관찰 결과, 점수와 판정 불가 사유를 보인다. 운송 전체 운임은 한 번만 정산한다.

## 기본 요청 2종

| 요청 | 선택 | 실제 효과·하차 판정 | 발생 조건 |
|---|---|---|---|
| 조용한 운행 | 조용히 모시겠습니다 / 안전상 보류 | 불필요한 후속 대사 억제, 실제 조용한 응대 +5. 안전한 응답 기회를 무시하면 기존 M -5, 요청 변화 중복 차감 없음 | 승차 또는 운행 중 정차. 이후 대화·음악 요청과 충돌하지 않음 |
| 도착 시간 문의 | 조금 빠르게 / 내비 예상대로 / 여유롭게 / 보류 | 안내 시점의 ETA와 실제 도착을 비교. 차량 성능·경로·운송 기한은 변경하지 않음. 요청 변화 0 | 승차 또는 운행 중 정차. 유효한 내비 ETA가 있어야 함 |

ETA 선택은 `현재 ETA ± min(30초, ETA의 10%)` 또는 ETA 그대로다. 4분이면 약 3분36초 / 4분 / 4분24초다. 실제 도착이 안내보다 15초 넘게 빠르면 `예상보다 빠름`, ±15초면 `예상 범위`, 15초 넘게 늦으면 `늦어짐`으로 설명한다. 교통에 따라 바뀔 수 있는 예상이며 오차만으로 감점하지 않는다. 공통 도착 시간 가산의 기준 ETA는 이 대화로 다시 설정하지 않는다. ETA를 계산할 수 없으면 경로 확인 뒤 안내하도록 보류한다.

## 운전 방식 DR01~05

| 요청 | 선택·즉시 효과 | 실제 관찰과 예외 | 발생 조건 |
|---|---|---|---|
| DR01 차멀미·승차감 | 부드러운 운전 약속 / 보류 | 수락 뒤 불필요한 급가속·급제동은 M 각 -4로 기본 -2를 대체. 필요한 위험 회피 제동 제외, 수락 전 사건에 소급 적용하지 않음. 요청 전체의 승차감 관찰 결과는 하차 때 한 번 확정 | 승차 또는 운행 중 정차. 남은 구간에서 관찰 가능해야 함 |
| DR02 정시 도착 | 규칙을 지키며 가능한 빠른 합법 경로 / 보류 | 기존 기한과 실제 위반 여부 확인. 재촉으로 기한을 줄이거나 불법 운전을 보상하지 않음 | 승차 또는 운행 중 정차. 달성 가능한 남은 시간 필요 |
| DR03 큰길 선호 | 큰길 우선 경로 / 보류 | 실제 큰길 비율을 안내 비율과 비교, 15%포인트 허용 오차. 합법적 우회·관찰 불가는 중립 | 큰길 대안과 충분한 남은 경로가 있을 때 |
| DR04 짧은 길 선호 | 합법적인 짧은 경로 / 보류 | 실제 거리와 안내 거리 비교, 참고 기준 125%+30m. 필요한 우회는 실패로 단정하지 않음 | 연결된 대안 경로와 충분한 남은 경로가 있을 때 |
| DR05 안전 하차 위치 | 검증된 가까운 하차 후보 / 원래 목적지 유지 | 새 목적지·내비·약정·기한을 확인하고 확정, 실제 지정 지점 하차 확인 | 안전 후보와 변경 가능한 여유가 있을 때. EV01/02와 동시 배정하지 않음 |

DR01의 한 제동 사건에 기본 -2와 강화 -4를 합쳐 -6으로 처리하지 않는다. 제동 횟수·충돌·필요한 제동의 제외 사유를 구분하며 법규 성향은 별도 관찰한다. 요청 전체 목표 평가와 개별 주행 사건은 구분해서 설명하고, 복수 요청이 같은 주행 사건을 다시 감점하지 않도록 한다.

## 대화·편의 CH01~06

| 요청 | 선택 | 실제 효과·관찰 | 발생 조건 |
|---|---|---|---|
| CH01 고민 이야기 | 공감 / 조용한 배려 / 보류 | 선택에 맞는 응대와 후속 대사. 조용한 배려도 정상 응대이며 말수로 평가하지 않음 | 안전 정차. 조용한 운행 약속 뒤에는 새로 배정하지 않음 |
| CH02 길 추천 | 빠른 길 / 짧은 길 / 보류 | 내비의 거리·ETA 비교 후 선택 경로 적용. 교통·합법적 우회 때문에 바뀐 결과는 불필요한 미이행으로 단정하지 않음 | 합법 대안이 있고 다른 경로 약속과 충돌하지 않을 때 |
| CH03 면접 응원 | 격려 / 조용한 준비 배려 / 보류 | 선택한 응대와 후속 반응. 실제 면접 결과·합격 보상은 없음 | 안전 정차. 조용한 운행 약속과 충돌하지 않음 |
| CH04 음악 | 가능한 제공 범위 안내 / 보류 | 프로토는 텍스트 안내만 제공. 실제 오디오가 바뀐 것처럼 표시하지 않음 | 안전 정차. 조용한 운행 약속과 함께 배정하지 않음 |
| CH05 요금 부족 | 약정 안내 / 하차 시 결제 확인 / 보류 | 현재 약정과 정산 규칙 안내. 대화만으로 할인·미수금·추가 부채를 만들지 않음 | 승차 또는 운행 중 정차 |
| CH06 지역 대화 | 지역 응답 / 안전 운행 안내 / 보류 | 짧은 대화·응대 기록. 검증되지 않은 지역 사실을 보장하지 않음 | 안전 정차. 조용한 운행 약속과 충돌하지 않음 |

## 변경·사건 EV01~04

| 요청 | 선택 | 실제 효과·관찰 | 발생 조건 |
|---|---|---|---|
| EV01 목적지 변경 | 새 안전 목적지 / 원래 운행 | 같은 운송 ID로 목적지·내비·약정 변경, 실제 하차 확인 | 승차 또는 운행 중 정차. 검증된 후보·시간 여유 필요 |
| EV02 중간 경유 | 안전 후보 경유 / 경유 거절 | 확정한 약정 적용, 경유지에서 F 정차 확인 후 원래 목적지로 안내. 경유 중 운송 시계는 흐름 | 운행 중 정차에 제시 가능. DR05/EV01과 중복 배정하지 않음 |
| EV03 분실물 | 보관·신고 / 전달 절차 안내 | 원래 운송 ID의 하차 후 텍스트 사건. 실물·반환 경로 없음, 완료 운송 점수·운임 소급 변경 없음 | 하차 후 전용 사건. 새 무작위 승차/운행 중 요청 후보에서는 제외하며 요청 수를 소비하지 않음 |
| EV04 불법 요구 | 안전하게 거절 / 정차 후 설명 | 불법 수락 선택지 없음. 거절은 중립, 실제 위반은 별도 기록 | 안전 정차. 해당 상황이 성립하고 운전 판단을 방해하지 않을 때 |

EV03은 P11에서 운행 중 요청 수와 분리한 하차 후 텍스트 사건으로 전환했다. 목적지·경유 변경은 장부 거래를 늘리지 않으며 최종 약정으로 하차 때 한 번 정산한다. 기상 대기·하차 완료 뒤에는 운행 중 요청을 새로 제시하지 않는다.

## P11 구현 후 확인할 플레이 사례

- 같은 출발지에서도 새 운송마다 요청 종류와 시점이 달라짐. 같은 후보를 재수락하거나 저장 복원하면 원래 배정 유지.
- 요청 없이 이동, 승차 시 1건, 중간 정차 시 1건, 승차와 중간에 각 1건, 중간의 서로 다른 정차에서 2건을 모두 경험할 수 있음.
- 움직이는 동안 새 요청이 뜨지 않고 합법 정차 뒤 나타남. 출발하면 선택 입력을 보류하며 별도 자동 정지로 영업 시간을 멈추지 않음.
- 앞선 요청의 효과·평가가 다음 요청으로 덮이지 않음. 충돌하는 약속·중복 점수·중복 정산 없음.
- 안전 정차 기회 없는 짧은 운송·취객 기상 대기·저장 복원·목적지 변경 이후에도 미발생 요청의 감점 없음.

수치·빈도·상한은 [04](../../../content-design/04-passengers-and-reservations.md)의 시험값을 사용하며, 수동 운행으로 대화 빈도와 운임 영향을 확인한다.
