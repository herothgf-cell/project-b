# 3일 영업 캠페인과 결과 비교

기준일: 2026-10-26. **3일·하루 예정 20분·초과 영업·거점 휴식 후 마감**이 현재 구현이다. 이전 독립 하루/12분/자동 마감 정책은 [변경 이력](../../../content-design/../design-history/content-design/07-campaign-history.md)에 보존한다. [경제05](../../../content-design/05-daily-operation.md), [운전자10](../../../content-design/10-driver-condition.md)이 비용·상태의 기준이다.

## 진행과 조건

| 단계·콘텐츠 | 조건 | 결과 |
|---|---|---|
| 새 캠페인 | 확인 후 저장 성공 | 날짜 1·현금 10,000원·연료 60%·포만감 80·피로 10·운전 점수 100·청결 100 |
| 영업 | 호출·길가 승차·운송·빈차 이동·생활 거점 방문 선택 | 고정 수익 목표·필수 운송 건수 없음 |
| 예정 20분 도달 | 최초 1,200초 경계 통과 | 피로 100, 초과 영업. 호출·승차·현재 운송 계속, 자동 정산 없음 |
| 초과 영업 | 기존 날짜가 계속 진행 | 실제 경과·거리·연료·비용·수익 누적. 승객 약정 기한은 별도 유지 |
| 피로 100 | 이동 중 | [10 졸음 사건](../../../content-design/10-driver-condition.md#졸음-사건) 가능. 피로만으로 호출 차단·운송 취소 없음 |
| 자발적 마감 | 빈차로 주차장·휴식 구역에 지정 정차 후 휴식·영업 종료 | 무료 수면 100초·피로 40 회복 후 하루 주차비와 결과를 한 번 정산 |
| 탑승 중 마감 시도 | 현재 승객이 있음 | 목적지까지 운송한 뒤 거점으로 이동. 도중 하차·자동 마감 없음 |
| 날짜 1~2 정산 | 다음 날 선택·저장 성공 | 현금·미납·연료·포만감·운전 점수·청결 이월. 야간 피로 60 회복(최소 0) |
| 날짜 3 정산 | 최종 마감 | 일별·누적 수입/비용/순수익과 실제 영업시간 비교 |
| 새 캠페인 재시작 | 명시적 확인·저장 성공 | 새 ID·초기값. 취소·저장 실패는 현 상태 유지, 이전 완료 요약 보존 |

휴식 후 이미 예정 시간을 넘었다는 이유로 피로를 다시 100으로 만들지 않는다. 초과 영업에서도 식사·수면·세차가 가능하다. 청결·구토·세차·기상 대기는 [15](../../../content-design/15-drunk-passengers-and-cleanliness.md)을 따르며 유효 도착 후 기상 대기로 도착 기한 판정을 소급 변경하지 않는다.

## 시간

| 시간·화면 | 경과 규칙 |
|---|---|
| 영업 예산과 표시 시각 | 예정 1,200초에 가상 08:00~20:00 대응. 영업 1초 = 가상 36초, 1분 = 가상 36분 |
| 주행·신호 대기·빈차 이동 | 실제 1초마다 영업 1초 경과 |
| 메뉴·일시정지·계획 선택·복습·운송 결과 | 영업/운송 타이머·컨디션 정지 |
| 생활 거점 추천창 | 안내만 제공하며 영업 시계 계속 |
| 식사·수면 | 각각 영업 50초·100초를 소비. 야간 피로 회복은 다음 날 예산 미소비 |
| 주유·연료 지원 | 각각 10초·30초 소비, 깨어 있는 컨디션 경과 |
| 세차 | [15 서비스 시간](../../../content-design/15-drunk-passengers-and-cleanliness.md)을 영업·컨디션에 반영 |
| 승객 픽업·운송 기한/ETA | 실제 플레이 초 단위, 하루 표시 시각과 구분 |
| 비교용 시간 | 영업 경과·초과 시간·메뉴 포함 실제 소요·생활 행동으로 건너뛴 시간을 구분 |

20분은 예정 예산이다. 예를 들어 식사 1회·수면 1회는 150초를 소비하므로 예정 예산 중 실제 운전 가능한 시간은 17분 30초이며 메뉴와 초과 영업은 별도다. 가상 시각은 실제 도로 통행 시간이나 낮·밤 조명 구현을 뜻하지 않는다.

## 수익과 반복 구성

| 항목 | 규칙·상태 |
|---|---|
| 수입 | [04 운임과 보너스](../../../content-design/04-passengers-and-reservations.md#운임과-보너스-계산)에 따라 하차 거래 한 번 |
| 하루 순수익 | 해당 날짜 실제 운임 − 발생 비용(미납 포함). 시작 자금은 수익 제외 |
| 누적 순수익 | 현금 − 시작 자금 − 미납. 날짜 이월된 미납의 재차감 없음 |
| 결과 | 적자/흑자·종료 사유·생활 이용·운송 건수·실제 시간·종료 컨디션·운행 기록 함께 표시 |
| 점수 | 운전 점수는 독립 누적 평가, 수익과 합산하지 않음. 승차 시 운임 보정은 04 기준 |
| 비교 | 같은 설정·코스·교통 버전의 완료 결과만 비교, 다른 조건과 중도 재시작은 구분 |
| 기본 구성 | [09](../../../content-design/09-prototype-scenarios.md)의 9코스와 17요청, [14](../../../content-design/14-passenger-stop-variety.md)의 일반 후보 재사용. 9코스 강제 완주 없음 |
| 배정 방향 | 초반·후반 짧은 코스, 중반 법규/선택 코스와 식당 접근 고려. 공유 방향 경로로 거리 계산 |
| 체험량 | 3~5건은 초기 측정 후보이며 보장/성공 조건 아님. 시간대·유형별 추가 대사는 후속 |
| 요청 등장 변경 | [04 미구현 배정안](../../../content-design/04-passengers-and-reservations.md#요청-배정과-등장-시점--변경-기획-미구현)을 현재 실행 규칙과 구분 |
| 제외 | 보험·세금·개인 예약·사고/수리·장편 서사·무한 경영 |
