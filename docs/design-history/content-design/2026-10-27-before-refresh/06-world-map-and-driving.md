# 맵·기본 주행·조향 보조·교통

은계 도로망과 국도42 차로를 공유해 내비·H 조향 보조·일반 차량을 운행한다. 원본·현장 확인·게임 보정·임시 시설을 구분한다. 기본 실행은 `builds/EungyeTaxi/EungyeTaxi.exe`, 빌드는 `PrototypeBuild.BuildHybrid`다.

| 기능 | 현재 규칙 | 확인 범위 |
|---|---|---|
| 기본 시작 | 국도42 외측 임시 주차 지점, 수동 주행·목적지 없음 | 호출 수락·탑승·생활 거점 안내 선택 때 경로 생성 |
| 일반 차량 | 최대48대, 공통 차로·신호·안전거리 사용 | 250m 구역별 분산·차량 간격을 고려해 배치. 최신 검사에서28구역, 지도별 고정 보장 아님 |
| 운전과 교통 | 내비·H·NPC는 같은 통행 그래프 사용 | H는 조향만 담당, 가감속·정지·양보는 사용자 판단 |
| 지도 UI | M 전체지도·+/− 미니맵, 지도 모달에서 영업·승객 대기 시간 정지 | 필터·호출·미리보기·화면 배치는 [13 UI](../../../content-design/13-driving-map-ui.md) |
| 승하차 | 기본12지점+게임 정차포켓12곳 | [14 후보와 대기 인구](../../../content-design/14-passenger-stop-variety.md), 실제 정차 허용/수동 진입은 별도 확인 |
| 일반 보행자 | 승인된 안전 보도3명·횡단3명과 상황 보행자 | [16](../../../content-design/16-ambient-pedestrians-proposal.md)의4후보 중3거점. 승객 외형·탑승·핀과 구분 |

| 공간 | 역할 | 프로토 포함 | 제외·확장 후보 |
|---|---|---|---|
| 은계 기반 생활권 | 호출·승하차·빈차 이동, 익숙한 길을 찾아가는 경험 | 연결이 확인된 도로를 중심으로 짧은 운송 동선 구성 | 은계 전역 복원, 연결되지 않은 자료 경계의 무리한 확장 |

| 주유소·식당·주차장 | 운송 사이 운영 행동과 비용 표시의 공간 | 입출구 분리 주유소 3곳·기존 식당/주차장과 접근·정차 구역 | 상점 운영, 내부 자유 탐색, 대형 시설 전체 재현 |
| 조용한 연결 구간 | 상황 사이 호흡과 기본 주행 | 핵심 장면 사이 짧은 일반 주행 | 장시간 단순 이동을 통한 분량 확대 |

|---|---|

## 기본 주행·조향 보조·내비

| 기능 | 플레이어가 결정할 것 | 프로토에서 확인할 것 | 범위 밖 |
|---|---|---|---|
| 수동 주행 | 조향·가감속·정차·방향지시 | 두 핵심 상황과 거점 진출입을 수동으로 수행 가능 | 새 차량 종류·고급 차량 튜닝 |
| 조향 보조 | 경로·차로·회전 선택, 속도·신호·진행 판단 | 차로 유지·변경·회전 조향, 상태·불가 사유 안내 | 자동 신호 정지·자동 양보·충돌 회피를 보장하는 자율주행 |
| 내비 안내 | 목적지·경로 선택과 도로 상황 판단 | 빠른 길/짧은 길 비교, 놓친 출구 재탐색, 조기 회전 안내 | 안내만 따르면 항상 안전·적법하다는 보장 |
| 정체 비교 | 기다릴지 돌아갈지 선택 | 사전 예상 시간과 실제 소요·이동 거리 구분 | 가지 않은 경로의 결과를 확정 사실로 표시 |
| 보조 해제 | 도로 이탈·후진·연결 끝에서 직접 대응 | 해제·수동 전환과 직접 감속 필요를 이해할 수 있음 | 보조 시작 불가 상태의 강제 자동 복구 |
| 숙련 기록 | 플레이어가 수행한 판단 | 보조 사용 여부와 직접 결정한 행동 기록 | 보조가 대신한 행동을 플레이어 숙련으로 자동 인정 |

조향 보조는 신호 판단을 대신하지 않는다. 운전 선택과 [법규 평가](../../../content-design/02-driving-evaluation.md), [승객 매너](../../../content-design/04-passengers-and-reservations.md), [히스토리](../../../content-design/03-history-and-mastery.md)는 각 기준으로 연결한다.

2026-10-27 내비 피드백: 우회를 일방통행으로 단정하지 않는다. [기존 진단](../../../content-design/../work-history/2026-10-27-navigation-playtest-diagnosis.md) 이후 새 첨부의 J7973 서쪽 일반차로→좌회전 포켓과 J7973→J8066 북행 후반에 총14개 점선 변경 연결을 보완했다. 시작 차로를 바꾸지 않고 기존 좌회전/우회전 연결을 사용한다. 마지막 변경 창을 지난 차량이나 다른 미수정 구간까지 직접 회전을 보장하지 않는다. [적용·검증](../../../content-design/../work-history/2026-10-27-road-fatigue-integration.md), [거리뷰 관찰/제보 구분](../../../content-design/../map-observations/2026-10-27-junction-followup.md)을 따른다.

게임용 횡단 안내판은 적용 접근의 신호등 위에 배치한다. 비보호 좌회전은 같은 신호함 위에 명시해 별도 도로변 기둥과 혼동하지 않도록 한다. 실제 현장 표지 실측 위치를 복원했다는 뜻은 아니다.

## AI 차량과 보행자

| 대상 | 필요한 행동 | 프로토 범위 | 제외·확장 후보 |
|---|---|---|---|
| 출구 대기 차량 | 신호 대기·출발·앞차 추종·간격 유지 | 대기와 앞부분 진입의 결과가 보이는 최소 대기열 | 전 지역 교통 수요·출퇴근 시간 재현 |
| 직진·교차 차량 | 진행·정지·양보 조건과 출구 공간 확인 | 우회와 우회전 판단에 필요한 흐름 | 복잡한 운전자 성격·경쟁·보복 행동 |
| 택시에 반응하는 차량 | 진입에 따른 감속·정지 | 실제 위치·속도·간격에 따른 관찰 가능한 반응 | 선택마다 과장된 경적·일괄 제동 연출 |
| 핵심 보행자 | 보도 대기, 횡단 의도, 횡단 시작·완료 | 우회전의 ‘없음/건너려 함/건너는 중’을 구분하는 소수 보행자 | 도시 전역 자유 보행·군중·개인 생활 일정 |
| 승하차 승객 | 지정 위치 대기·탑승·하차 | 기존 승객 동선과 횡단 보행자 역할 구분 | 모든 승객의 장거리 보행 추적 |
| 재현·오류 처리 | 동일 조건 반복, 이상 반응 감지 | 시작 상태 기록, 상황 초기화, 잘못된 AI 반응은 법규 판정 보류 | AI 오류를 플레이어 위반으로 확정 |

차량 수와 보행자 수는 장면 가독성·성능·재현성을 기준으로 조정한다. 프로토에 보행자를 포함하는 목적은 우회전 판단 검증이며, 군중 규모가 완성 기준은 아니다.

## 운영 공간과 역할

| 공간 | 플레이 흐름 | 필요한 공간·표시 | 프로토 범위 | 결정·연결 |
|---|---|---|---|---|
| 주유소 | 내비로 이동 → 안전하게 진입·정차 → 주유 확인 → 운행 복귀 | 진출입로, 정차 구역, 연료·예상 비용·결제 결과 | 거점 이용과 비용 표시를 확인할 최소 기능 | 연료량·단가·차감 시점은 [경제 기획](../../../content-design/05-daily-operation.md) |
| 식당 | 정차 → 식사 선택·비용 확인 → 운행 복귀 | 접근 동선, 정차 구역, 선택·결과 표시 | 매 식사 결제·포만감 회복, 마감 자동 식비 없음 | 비용·빈도·미방문 처리는 [05](../../../content-design/05-daily-operation.md) |
| 주차장 | 안전하게 진입·정차 → 수면·마감 또는 영업 복귀 | 진출입 경계, 주차 구역, 이용 안내 | 영업 거점·일일 주차비·수면 메뉴 | 요금·식사/수면·정산은 [05](../../../content-design/05-daily-operation.md) |
| 수리 공간 | 사고 후 이동·수리 처리 후보 | 위치·입고 방식 미정 | 프로토 제외·기획만. 주유소·주차장의 프로토 기능에 수리를 추가하지 않음 | [사고·수리](../../../content-design/08-accidents-and-repairs.md), [05 경제](../../../content-design/05-daily-operation.md)와의 연결은 후속 |

거점 방문 때문에 장거리 이동이나 긴 대기를 강제하지 않는다. 비용의 숫자·적용 시점은 [경제 기획](../../../content-design/05-daily-operation.md)에서 정의한다. 사고 보험청구는 갱신 관리와 별개이며 프로토에서 제외한다.

## 조작·시야·안내 조건

조건부 유턴 표지는 해당 교차로·접근 축·방향이 일치하는 신호등 신호함 바로 위에 부착한다. 기존 비보호/횡단보도 상부 표지와 겹치지 않게 높이를 확보하고 도로 중앙의 별도 지주를 만들지 않는다. 신호등이 없는 편집 미리보기는 원본 시설 위치를 유지한다. J8066_6364도 같은 규칙을 적용하며 유턴 허용 조건·지도 원본은 변경하지 않는다.

| 항목 | 동작 | 경계 |
|---|---|---|
| 수동 조향 | 저속 최대48도, 추가 조향을30km/h까지 줄임. 안쪽/바깥쪽 앞바퀴 각도 분리 | 고속 한계·H 조향 계산 유지 |
| 코너 감속 | 현재 속도에서 실제 바퀴각을 사용해 가속 제한·소폭 제동 | 수동의 작은 조향에 과도한 감속을 주지 않음 |
| 1인칭 | 자동 코너 시선 기본OFF, 롤/피치 분리, 회전 평활. V로 선택 시 최대6도 | Z/X 수동 확인·B 뒤보기 유지 |
| 신호 안내 | 진행 방향·접근 차로 폭 기준 최대125m 앞의 실제 게임 신호, 남은 초·색·문자 | 접근 후 유지되는 교육 신호/점멸은 고정 시간을 만들어내지 않음 |
| 비보호 안내 | 표지·녹색/대향차 양보 설명 | 게임 설정과 현장 확인을 구분 |
| 복귀 | R/패드 즉시 복귀 제거, 새 캠페인은 메뉴 확인 | 맵 아래 추락 등 자동 안전 복구 유지 |
| 앞차 추종 보완 | Esc ON/OFF, 최초ON·선택 저장. NPC 재생성 없이 적용 | OFF는 기존 AI. 샘플 차량·후진 회피·차로변경 미도입. [출처와 범위](../../../content-design/../mit-traffic-following.md) |

## 검증과 후속 범위

2026-10-27 추가 조향: 수동 저속 조향 증폭을14%에서40%로 높이고 중앙 조향각 상한52도로 조정한다.14~30km/h 사이에서 증폭을 줄여30km/h 이상은 기존 제한, H 자동 조향은 기존42도 기준을 유지한다. 실제 전륜은 Ackermann 보정이 적용되며 최대 중앙각과 다르다. 새 남행 차로변경 연결은 기존 점선/동일 방향 연결의 게임용 보완이며 실도로 규제 실측으로 표시하지 않는다.
