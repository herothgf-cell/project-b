# 프로토타입 개발을 위한 통합 기획

기준일: 2026년 10월 21일 · 버전: 0.5 · 상태: 사용자 결정 반영 통합 기획

2026-10-21 변경: 수동 가속·저속 회전 완화, 넓은 임시 시작 주차 지점, G 전체지도와 매너/법규 별도 게이지를 적용한다. 보험·세금은 아래 현재 범위대로 제외하며 과거 착수 전 표는 이력이다.

2026-10-21 별도 기획 추가: [프로토 시나리오](content-design/09-prototype-scenarios.md)는 기존 승객 요청을 유지하면서 승객별 승하차 위치와 법규/선택 상황을 연결하는 9코스 초안이다. 승차 전·운송 중·하차 접근을 구분하며, 기존 7구역 활용과 P4 선택 2코스를 제안한다. 신규 코스 구현·좌표 확정·캠페인 검증 완료를 뜻하지 않으며, 9코스 전부를 3일 내 필수 운송으로 요구하지 않는다.

2026-10-21 추가: 3일×12분·연료4%포인트/km+0.1%포인트/분·새 캠페인60%. 승객 탑승 중 N 마감 금지·날짜 종료는 목적지 하차까지 대기. 기한 초과 시에도 승객 유지 후 목적지에서0원 처리. 화면 점수 명칭은 ‘운전 점수’이며 승객 매너와 별도다. 차선은 공유 차로 그래프를 따라 중앙 황색/동방향 백색으로 구분하고 도로 겹침 건물은 원본을 보존해 표시·충돌에서 제외한다. 주유소는 실제 시설 확인이 아닌 게임시설이다.

## 2026-10-21 후속 변경 (구현·자동 검증 반영)

- 승객 요구 확장 DR/CH/EV와 9개 일반 운송 코스는 이번 개발 범위로 승격한다. 별도 연습 맵으로 대체하지 않는다. 상세 수치·상태는 개별 문서04/09를 따른다.
- 호출 수락 후 승차 대기 기한을 표시한다. 호출 카드에는 경유 상황 설명을 제거하되 운송 중 안내·지도 구역 표시는 유지한다.
- M 전체지도, +/- 미니맵 확대·축소. 전체지도에는 시설/교통/법규 필터를 둔다. R/패드 복귀 단축키 제거, 새 캠페인은 확인 버튼으로 시작한다.
- 화면 명칭은 운행 점수. 날짜·재실행에 누적 유지하고 새 캠페인만 100점 초기화한다. 실제 준수 사건당1점 회복(최대100), 승객 매너와 독립. 연료15% 이하 아이콘과 점수 변화 알림은 상단에 표시한다.
- 실행 창 제목은 택시 시뮬레이터. 은계 일반 차량 목표36대, 실제 게임 신호 남은 시간과 간략한 게임 표지를 추가한다. 현장 표지 설치 여부와 구분한다.

## 사용자 결정과 세부 제안

| 항목 | 확정 방향 | 세부 설계 |
|---|---|---|
| 보험·세금 | 2026-10-21 사용자 결정으로 프로토 제외 | 메뉴·비용·미납 발생·출발 제한·목표 달성 조건 제거. 기존 저장 비용은 이관 |
| 캠페인 | 3일 × 12분·순수익 30,000원 | 구현 완료: 3일 × 12분·30,000원. 과거 7일 설정은 이전 버전 |

운송 요청 수·신규 감점·거점 비용·연료량은 각 문서의 ‘수치 제안’이다. 사용자가 확정한 설정과 조정 가능한 게임 밸런스를 구분한다.

기존 물리 충돌·조건부 승객 매너 감점은 현재 기반으로 유지한다. 신규 사고 이벤트나 수리 비용을 뜻하지 않는다. 연료 고갈 지원은 주유 콘텐츠의 예외이며 사고 시스템과 분리한다.

| 항목 | 필수 확인 |

| 마감 | 새 수락 차단, 탑승 임무 원래 기한 유지, 완료/실패 후 정산 |

| 복습 | 영업 시간·돈·예약·본 성향에 영향 없음 |

프로토 검증 환경은 현재 PC와 키보드 주행 기준이다. 실물 패드·새 PC 검증은 프로토에서 제외하며 출시 일정은 별도다. 기존 성능·빌드 기록을 신규 프로토 완료 근거로 사용하지 않는다.

## 추가 기획의 개발 단계 (2026-10-20)

은계 지도 접근 시 자동 정지·운전 계획 선택 2곳은 추가 프로토 개발 항목(P4)이며 아직 구현되지 않았다. 승객 DR/CH/EV 15종은 P5, F01~F62 법규 후보 및 공통 관찰 데이터는 P6 후속 개발 목록으로 연결한다. 실제 개발 선행 조건과 미완료 상태는 [최신 체크리스트](prototype-development-checklist.md#2026-10-20-웹-추가-기획을-반영한-개발-목록)를 따른다. 메뉴 선택을 실제 법규 판정으로 간주하지 않고, 기존 법규·매너·운임·연습 분리와 3일 캠페인을 유지한다. 캐주얼 그래픽·HUD 시안 및 리디자인은 사용자 결정으로 프로토에서 제외한다. 기존 HUD의 필수 정보 가독성·오류 수정은 유지한다.

## 사용자 범위 정정 (2026-10-20)

캐주얼 그래픽·HUD 시안, 실물 패드·새 PC 검증은 프로토 개발/완료 기준에서 제외한다. 법규 후보 62개는 [혼동 가능성 검토](road-law-confusion-review.md)를 거쳐 후속 장면을 선별할 자료이며 전체 자동 판정 개발을 프로토 필수로 넣지 않는다. 기존 패드 입력 지원과 현재 PC에서 실행 가능한 빌드 제공은 유지한다.

## 은계 법규 연습 선택 구현 (2026-10-20)

사용자가 창작 교육 구간 구성을 허용해 기존 차로 연결에 점멸·출구 정체·비보호 좌회전 7종을 우선 추가했다. 이 선택 범위는 프로토에 포함하며 62개 일괄 자동화와 구분한다. [검증·후속 조건](eungye-confusion-practice-validation.md).


## 은계 기본 맵 운송 중 상황 (2026-10-20)

사용자 의도에 따라 [법규 상황 7개 구역](eungye-in-service-law-zones.md)을 기본 은계 영업에 통합했다. 호출/길가 승객을 태운 후 내비와 H 조향이 같은 상황 연결 차로를 경유하고 운송·시간·요금 처리를 이어간다. 기존 별도 연습은 재시도 수단이다. 여기서 구현한 것은 연속 운송 중 실제 운전 관찰이며 P4의 자동 정지·계획 메뉴 선택 2곳을 완료한 것은 아니다. 창작 신호/차량 배치와 실제 확인 시설의 구분, 법규·매너·운임 분리를 유지한다.
