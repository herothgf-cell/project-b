## 사용자 결정과 세부 제안

| 항목 | 확정 방향 | 세부 설계 |
|---|---|---|
| 보험·세금 | 갱신·납부일까지 직접 관리 | 2일차 보험 만료·3일차 세금 기한 제안. 금액·실패 흐름은 05 |
| 캠페인 | 3일 × 8분·순수익 30,000원 | 구현 완료: 3일 × 8분·30,000원. 과거 7일 설정은 이전 버전 |
| 개인 예약·사고 | 프로토에서 제외하고 기획만 | 04·08의 후속 흐름은 프로토 작업·완료 기준에 넣지 않음 |

운송 요청 수·신규 감점·거점 비용·연료량은 각 문서의 ‘수치 제안’이다. 사용자가 확정한 설정과 조정 가능한 게임 밸런스를 구분한다.

기존 물리 충돌·조건부 승객 매너 감점은 현재 기반으로 유지한다. 신규 사고 이벤트나 수리 비용을 뜻하지 않는다. 연료 고갈 지원은 주유 콘텐츠의 예외이며 사고 시스템과 분리한다.

## 개발 착수 전 기반과 당시 추가 계획

## 개발 단계와 완료 기준

작업 단위의 상태와 우선순위는 [프로토타입 개발 체크리스트](prototype-development-checklist.md)를 따른다.

| 단계 | 결과물 | 완료 기준 |
|---|---|---|
| 1 기반 정리 | 은계 주행·승객·거점 위치 | 끊김 없는 영업 및 거점 접근, 플레이어가 단서를 인지 |
| 2 대표 상황 | 출구 세 선택·우회전 조건 비교 | 조건마다 행동·주변 반응 재현, 법규 오판정 사례 확인 |
| 3 법규 기록 | 독립 점수·이력·간단 성향 | 승객 매너와 분리, 사건·규칙별 기회 중복 없음 |
| 4 생활과 보상 | 요청·주유·식사·주차·납부 일정 | 100%/70%/0원 결과, 직접 갱신·납부, 중복 결제 없음 |
| 5 캠페인 통합 | 정산·다음 날·최종 결과·저장 | 처음부터 끝까지 짧게 완주, 재실행 후 중복 지급 없음 |
| 6 플레이 확인 | 실제 플레이 기록 | 정상 운전으로 달성 가능성·경로 선택·가독성·길이 평가 |

## 예외와 검증 범위

| 항목 | 필수 확인 |
|---|---|
| 판정 | 같은 사건 반복 감점 방지, 미경험과 보류를 준수로 오인하지 않음 |
| 마감 | 새 수락 차단, 탑승 임무 원래 기한 유지, 완료/실패 후 정산 |
| 비용 | 시작 자금 목표 제외, 주유 소모 이중 차감 방지, 미납 결제 시 이중 비용 없음 |
| 일정 | 기한 알림·직접 납부·보험 만료 후 출발 차단, 미납 비용과 예정 납부 구분 |
| 성공 조건 | 순수익 목표와 보험 갱신·세금 납부 완료를 함께 확인, 미결제 예정 비용으로 조기 성공하지 않음 |
| 복습 | 영업 시간·돈·예약·본 성향에 영향 없음 |
| 저장 | 완료 정산 단위 복원, 당일 수입·비용·납부·기록 함께 재시작. 기존 v1 보존·별도 버전 새 도전 |
| 재미 | 다른 교통 조건에서 대기와 우회의 유불리 변화, 안전 운전이 지속적으로 불리하지 않음 |
| 법규 근거 | 기준일·조건·예외 확인, 현행과 시행 예정 규정 구분 |

프로토 검증 환경은 현재 PC와 키보드 주행 기준이다. 실물 패드·새 PC 검증은 프로토에서 제외하며 출시 일정은 별도다. 기존 성능·빌드 기록을 신규 프로토 완료 근거로 사용하지 않는다.

## 추가 기획의 개발 단계 (2026-10-20)

은계 지도 접근 시 자동 정지·운전 계획 선택 2곳은 추가 프로토 개발 항목(P4)이며 아직 구현되지 않았다. 승객 DR/CH/EV 15종은 P5, F01~F62 법규 후보 및 공통 관찰 데이터는 P6 후속 개발 목록으로 연결한다. 실제 개발 선행 조건과 미완료 상태는 [최신 체크리스트](prototype-development-checklist.md#2026-10-20-웹-추가-기획을-반영한-개발-목록)를 따른다. 메뉴 선택을 실제 법규 판정으로 간주하지 않고, 기존 법규·매너·운임·연습 분리와 3일 캠페인을 유지한다. 캐주얼 그래픽·HUD 시안 및 리디자인은 사용자 결정으로 프로토에서 제외한다. 기존 HUD의 필수 정보 가독성·오류 수정은 유지한다.

## 사용자 범위 정정 (2026-10-20)

캐주얼 그래픽·HUD 시안, 실물 패드·새 PC 검증은 프로토 개발/완료 기준에서 제외한다. 법규 후보 62개는 [혼동 가능성 검토](road-law-confusion-review.md)를 거쳐 후속 장면을 선별할 자료이며 전체 자동 판정 개발을 프로토 필수로 넣지 않는다. 기존 패드 입력 지원과 현재 PC에서 실행 가능한 빌드 제공은 유지한다.
