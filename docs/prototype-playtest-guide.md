# 프로토 잔여 개발과 직접 플레이 확인

기준: 2026-10-21, 은계 기본 영업. 최신 체크리스트·현재 코드 대조. `[x]` 자동 검증과 수동 체감 검증은 다르다.

## 개발 상태 대조

| 우선 | 항목 | 현재 상태/범위 |
|---|---|---|
| 1 | 플레이 중 재현되는 막힘·오판정·가림 수정 | NPC/신호 자동 검사 통과와 별개로, 실제 접근 각도·차속에서 재현 필요 |
| 2 | 10% 단위 주유 | 구현: 주유 구역에서 F7 → +10% 버튼 반복 구매 |
| 2 | 호출별 예상 연료 부족 안내 | 구현: 픽업+운송 거리/시간 추정, 잔량 경고와 별도 |
| 2 | 선택 상황 최초 노출 기록의 재실행 보존 | 구현: 캠페인 저널에 노출 사건 저장, 새 캠페인 초기화 |
| 3 | 지도 임시 시설·차로·표지 대조 | 실제 근거가 있는 구역부터. 은계 전역 실측 완성은 필수 목표 아님 |

9개 승객 코스, 17종 요청, PS08/09 선택 메뉴, 누적 운행 점수, 픽업 기한은 이미 구현됐다. 이를 신규 미구현으로 중복 개발하지 않는다. 음악 재생/실제 미수금/분실물 보관은 현재 텍스트 요청보다 큰 후속 확장이다. 법규62개 전부, 보험/세금, 단골/예약, 사고/수리, 그래픽 시안, 새 PC/실물 패드 검사는 이번 프로토 필수 잔여 항목이 아니다.

## 직접 플레이 순서

1. **기본 운송 1회**: 새 캠페인, 호출 수락→같은 진행 방향 승차→하차. 키보드 수동과 H 조향 보조 각각 확인. H에서도 가감속은 직접 한다. 출발부·좁은 90도 회전에서 조향/연석/전복 여부 기록.
2. **출구 정체**: A 줄 뒤 대기, B 우회, C 앞부분 진입을 각각 시험. 막힌 출구에 진입하지 않아도 운송을 완료하는지, 판정 위치·이유·잘한 점이 실제 행동과 맞는지 확인. 잘못 진입하다 포기한 경우도 확인.
3. **우회전/좌회전**: 적색 정지→보행자 대기→통과, 비보호 대향차 양보. 필요한 급제동/합법적 대기에 매너가 잘못 깎이지 않는지. Tab 재탐색 후 보행자·신호·안내가 멈추지 않는지.
4. **승객 요청/대기**: 픽업 시간 만료, 안전상 보류(U), 목적지 변경/경유를 한 번씩. 운임·남은 시간·도착지가 함께 바뀌고 중복 요금이 없는지. 교차로에서 팝업이 운전을 방해하는지.
5. **시설 왕복**: 주유소1~3 입구→정차·결제→출구, 식당/주차장. 도로 복귀가 가능하고 NPC가 길을 영구적으로 막지 않는지.
6. **화면**: 1/3인칭, 작은 창/전체화면, M 지도 확대·축소/드래그/내 위치/전체 보기/필터. HUD가 신호를 가리지 않는지, 닫으면 직전 정지/진행 상태로 복원하는지.
7. **3일 캠페인**: 정상 운전·우회 선호를 비교해 3일×12분 동안 목표3만원 달성 가능성과 연료/식비/주차비 부담 기록. 탑승 중 시간이 끝나도 목적지 하차까지 유지되어야 한다.
8. **저장/초기화**: 하루 마감→종료→재실행, 운행 점수 유지 확인. 새 캠페인은100점 초기화. 회계는 하루 정산 기준이고 운행 사건은 별도 저널 기준이다.

## 문제 기록 양식

- 실행 버전(배포 manifest sourceCommit), 1/3인칭, 수동/H, 대략 속도
- M 지도 위치/승하차 번호/교차로 ID와 접근 방향
- 기대 행동, 실제 행동, 재현 순서, 스크린샷
- 캠페인 비교는 날짜별 완료 운송 수·순수익·연료·실패 이유를 함께 기록

## 첨부 이미지의 흰 구조물

WorldBuilder는 지도 건물 윤곽을 높이만큼 올려 단색 건물 메시/충돌체로 만든다. 이미지의 길고 밝은 벽·직육면체는 이 외형으로 보이며 개별 건물 ID는 이미지로 확정하지 않았다. RoadConditions 정체는 차체·창문·비상등과 정체 안내로 표시하므로 이 흰 구조물을 정체 표식으로 읽지 않는다. 도로/인도 침범이 있으면 해당 ID·주행 경계를 대조해 보류 처리해야 하며, 전체 건물을 일괄 삭제하지 않는다.

추가 플레이: 체험 구역을 건너뛰어 목적지 하차·요금 지급, 미체험0점 확인. 10% 반복 주유·잔여 용량·현금 부족, 호출 연료 예측과 실제 잔량 비교, 재실행 후 선택 팝업 재노출 방지 확인.

### 이번 수정 직접 확인

- 상황을 우회하고 승차점에서 F → 정상 탑승, 목적지에서도 미체험 하차 가능.
- 승하차8과 다른 승객의 발이 보도 위에 있는지, 주변 흰 건물 박스가 주행 노면을 막지 않는지 확인.
- 우회전 앞차가 출발하면 안전거리로 뒤차가 따르는지 확인. 정지한 출구/횡단 보행자 앞에서는 계속 대기해야 한다.
- F7에서 +10% 구매 반복 시 잔량·금액·10초 비용, 100% 부근 실제량 제한 확인.

## 하루20분·컨디션 직접 확인

새 하루 시작 → 주차장에서 출발 → 기존9코스 중 원하는 호출 또는 길가 승차. 초반/후반은 짧은 후보가 우선이다. 포만감25 미만·피로70 이상 안내를 보고 F7로 식당/주차장에 이동한다. 식사3,000원·50초, 수면무료·100초이며 확정/취소와 반복 이용을 확인한다. 주유는 +10% 그대로다.

피로100은 미탑승 호출을 취소하고 새 승차를 막지만 탑승 승객은 목적지까지 운송한다. 시간 종료도 같은 승객 유지 규칙이며 자발적 퇴근은 주차장 N/F7이다. 결과의 순수익·이전 결과·식사/수면 횟수·최종 연료/컨디션을 비교한다. 새 하루 확인 취소/확정과 재실행 결과도 확인한다.

미검증: 일반 교통 속 수동 한 회차 운송 건수/실제 시간/식사·수면/순수익, 1280×720 이상에서 준비·거점·결과·마감 추가시간 한글 잘림. 자동 캡처가 검게 나와 이번 작업은 화면 검증 완료로 표시하지 않는다.
