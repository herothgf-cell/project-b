# 보조 운전과 경로 선택 시험

브랜치: `feature/assisted-route-driving` · 2026-10-14

## 구현

원본 도로에서 폭 6m 이상인 구간을 방향별 차로로 구성했다. 도형을 이루는 중간 점은 합치고 분기점에 차로 연결을 만든다. 실제 교통법규 전체를 재현한 도로망은 아니다. 내비게이션과 독립적으로 차로와 다음 회전 방향을 선택하며 WheelCollider 조향으로 이동한다.

H로 수동/보조 전환, A/D로 차선 변경, Q/E로 다음 회전 예약을 제공한다. 키를 유지하면 재요청하지 않으며 패드는 중립 복귀 후 다시 입력해야 한다. 정지·후진·이동 중·차로 끝·점유 공간 요청은 거절한다. 뒤차 접근 경고는 자동 충돌 회피가 아니다. 후진·경로 이탈·R 복귀는 보조를 해제한다.

시험 모드는 `Play-AssistedTrial.cmd` 또는 `AssistedTaxi.exe -assistedTrial`로 실행한다. F6 정상/F7 정체 재시작, 같은 출발·도착, 고정 신호 시작 시각, 본선/우회 안내선, 도착 정차 시간 기록을 제공한다. 정체는 고정 차량 3대를 120초 뒤 제거하는 통제된 시험 조건이다. 실제 정체의 발생·해소 시뮬레이션은 후속 개선 항목이다.

## 검증 기록

- 독립 C# 검사 9종 통과: 주행, 코너 보조, 신호, 보호 좌회전, 매너, 승객 상태, 경제, 보조 입력 정책, 한국 신호 운영. 보조 정책은 15개 검사다.
- Python 지도 검사 6개 통과.
- Unity 차로망 검사 통과: 올바른 방향 부착, 반대 차로 거절, 회전 차로 제한, 연결 위치·방향 연속, 중간 점 병합, 실제 지도 100개 방향별 차로 및 본선/우회로 연결.
- 실제 Player 보조 주행: 직선 추종, 양방향 차선 변경, 요청 중복·점유 거절, 정지·후진·일시정지·복귀, 실제 도로 좌우 회전 검사 통과.
- 기존 수동 주행 회귀: 가속·제동·후진·복귀·T2 도착·일시정지 통과.
- 기존 승객 회귀: 호출·승하차·재탐색·운임·중복 지급 차단·길가 승객·시간 초과·카메라 상태 통과.
- 별도 Windows 빌드 생성 성공. `builds/AssistedTaxi`가 전달용이며 기존 `builds/YeongtongTaxi`와 분리했다.

최종 경로 주행 결과(`artifacts/assisted-trial-test.txt`, 종료 코드 0):

| 조건 | 본선 | 우회로 | 유리한 경로 |
|---|---:|---:|---|
| 정상 | 75.28초 | 143.26초 | 본선 |
| 정체 | 211.35초 | 143.30초 | 우회로 |

네 경우 모두 실제 물리 주행·도착 정차에 성공했고, 재시작 직후 택시와 일반 차량이 겹치지 않는 검사도 통과했다. 한국 신호 운영 반영 후 정체 조건의 우회 이득은 약 68초다. 사용자 체험에서 체감 차이와 판단 가능성을 평가한 뒤 조정할 필요가 있다. 자동 운전자는 교통 상태를 읽고 가감속·회전을 선택하는 시험 코드이며 플레이어 기능이 아니다.

## 리뷰 수정

독립 리뷰의 두 중요 항목을 수정했다. 시험 재시작에서 비활성 대기 차량까지 되살려 택시와 겹치는 문제는 재현 검사 `spawn_clear_after_restart=False`를 확인하고, 초기 활성 상태 보존 및 교통 복원 후 택시 위치 정리로 수정했다. 직진 연결에도 회전 속도 상한이 적용되던 문제는 직진 통과·회전 중·회전 접근 정책 검사로 분리해 수정했다.

전체 실제 경로 주행에서는 일부 연결곡선이 차량의 이론 최소 회전 반경보다 좁을 수 있다는 리뷰 우려도 확인한다. 자동 조향의 실제 궤적으로 두 경로를 모두 완주하는 검사가 최종 판단 근거이며, 모든 지도 회전과 진입 속도를 검사했다고 주장하지 않는다.

## 한계

자동 경로 비교는 일반 교통 차량을 비활성화하고 고정 정체 차량과 신호만 사용해 조건을 맞춘다. 사용자가 실행하는 시험에는 일반 교통도 있으므로 기록이 달라질 수 있다. 그래픽 없이 실행한 회귀 검사에서 Null Device의 셰이더 경고가 발생하며, 이 결과는 화면 렌더링이나 시각 품질의 검증이 아니다. 숨긴 창의 화면 캡처는 검은 화면으로 반환돼 화면 품질 검증 자료로 사용하지 않았다.

재미·사용자 조작감·패드 실물 조작·경제 균형은 미검증이다. 현재 단계는 조작과 경로 판단을 비교할 수 있는 시제품이며, 후속 기능 확장 전에 사용자 주행 피드백이 필요하다.


## 2026-10-14 한국 신호 운영 및 회전 시험장

근거는 [교통신호기 설치·운영 업무편람 공개본](https://itskorea.kr/downloadFile.do?fileId=FILE_000000000103037&fileSn=0)의 본문 15–17쪽(등화 의미), 77–80쪽(좌회전 방식 결정과 공용 차로 운영)이다. 내려받은 PDF는 표지/본문에 2024 업무편람으로 표기되어 있다. 차로 수만으로 좌회전 신호를 결정하지 않는다. 교통량, 시거, 속도, 사고 이력 등으로 선택하며, 현재 지도에는 그 실측 운영 자료가 없으므로 공용 차로의 보호 직좌 동시신호를 기본값으로 사용한다. 실제 영통 신호 운영을 복제했다고 주장하지 않는다.

`Play-RoadRulesTrial.cmd`는 600×600m 가상 도로망을 연다. F6은 왕복 2차선(7m) 비보호, F7은 왕복 4차선(14m) 보호, F8은 왕복 2차선 보호다. 각 도로의 폭으로 정지선·횡단보도·신호 위치·AI 주행 경로를 계산한다. 접근 구간은 100m 이상이며 도로망으로 연결된다. 비보호는 3색등과 비보호 표지, 보호 공용 차로는 한 진입 방향씩 직진 녹색과 좌회전 화살표를 함께 점등한다. 신호 시간은 시험용이며 실제 교통량으로 산정한 값이 아니다.

보조 주행의 최소 도로 폭은 9m에서 6m로 바꿨다. 7m 왕복 2차선에서 경로가 누락되는 실패를 `KoreanRoadTests.Run`으로 재현한 뒤 통과시켰다. 기존 실제 지도의 네트워크 검사도 통과했다.

- 독립 C# 검사 9개와 Python unittest 6개 통과.
- Player의 왕복 2차선 비보호/4차선 보호/2차선 보호 각각 네 방향 좌우회전 8개씩, 총 24개 통과. 회전 종료 차로 오차 0.55–0.80m, 도로 경계·신호 위반 사건 증가 없음.
- 보호 좌회전과 적색 우회전이 같은 진출 차로를 사용하는 경우 양보, 분리된 차로를 사용하는 경우 비충돌 판정 검증.
- 비보호 양보 위반 감점, 교차로 안에서 직진 자세로 대기 시 무감점, 맞은편 직진과 충돌하지 않는 정상 우회전 무감점 검증.
- 적색 우회전의 정지 유무에 따른 매너 판정과 황색 신규 직진 진입 감점 검증.
- 기존 수동 운전, 승객 기능, 정상/정체 경로 비교 Player 검사 통과.

독립 코드 리뷰에서 발견한 양보 누락 2건과 정상 우회전 오판 1건은 실제 Player에서 실패를 재현하고 수정했다. 우회전 양보 판정은 AI의 예정 경로와 우회전·진출 경로의 근접도를 표본 검사한다. 이는 게임용 근사 판정이며 법적 사고 책임 판단 모델이 아니다. 정지 인정 속도, 인지 거리, 감점도 게임용 수치다.

보행자 통행과 별도 우회전 신호기는 미구현이다. 녹색/적색 신호 및 양보 규칙의 제한된 구현이며 전체 도로교통법 준수를 보증하는 시뮬레이터가 아니다. 회전 시험은 Null Device 물리 검사로 실행했으며 화면 품질 검증과 구분한다. 기존 CockpitSmokeTest의 신호 가정은 새 직좌 동시 운영에 맞췄지만 거울 렌더링 검사는 이번 변경에서 실행하지 않았다.

## 사용자 화면 피드백 후 교통 정체 및 표시 수정

일반 AI 12대를 활성화한 384초 순환 검사에서 비보호 좌회전과 맞은편 우회전이 서로 양보해 좌회전 차량이 최대 377초 정지하는 결함을 재현했다. 우회전은 교차로 밖에서 대기하는 맞은편 비보호 좌회전보다 우선하도록 수정했다. 이미 교차로에 들어온 좌회전과 보호 좌회전에 대한 양보는 유지한다.

수정 후 같은 Player 검사에서 왕복 2차선 비보호와 왕복 4차선 보호 모두 12대 전원이 순환했다. 비보호 좌회전 차량은 각각 8회와 7회 완주했고 최대 정지는 33초와 30초였다. 로그는 `artifacts/queue-fix-flow2.log`, `artifacts/queue-fix-flow4.log`다. 최종 전달 빌드의 규칙 검사도 통과했으며 대기 중인 비보호 좌회전과 이미 진입한 좌회전을 구분하는 회귀 검사를 포함한다.

지도 분기점에서 중앙선과 가장자리 차선 도색을 끊었다. 직선 연결을 교차로로 잘못 분류하지 않는 Unity 검사도 통과했다. 이는 도형 수정이며 실제 통행 허용을 확인한 것은 아니다. 원본은 NGII 377092296 / 2008 / 1:1000 지도 형상이고 실제 현재 신호·회전 규제는 미검증이다. HUD에 이를 표시하고 시험장을 가상 지도라고 명시했다.

비보호 표지의 글자 크기와 뒷면 투과를 수정했다. 실제 GPU 렌더링으로 `artifacts/road-sign-front.png`, `artifacts/road-sign-back.png`를 생성해 앞면의 정상 글자와 뒷면의 글자 미표시를 확인했다. 이번 검증은 해당 표지에 한정하며 전체 지도와 HUD 시각 품질을 검증했다는 뜻은 아니다. 수동 운전에서는 직접 조향하며, 보조 회전은 H로 전환 후 Q/E 예약과 W 가속이 필요하다는 안내도 추가했다.
