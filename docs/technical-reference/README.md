# 별도 개발·제작 참고

기획 문서에서 분리한 자료다. 플레이어 행동·결과의 기준은 [현재 게임 기획](../content-design/README.md)에서 확인한다. 이 폴더의 클래스·파일·검사·제작 세부는 게임 기획의 필수 콘텐츠나 완료 판정이 아니다.

| 자료 | 내용 |
|---|---|
| [코드·시스템 연결](content-system-implementation.md) | 이전 구조 문서의 코드 책임·지도/저장/배포 설명 |
| [지도 편집 상세](map-editor-specification.md) | 도구 동작·생성/저장·제작 조건 |
| [평가 참고 명세](driving-evaluation-reference.md) | 상세 법규 후보·관찰/예외·후속62항목·판정 참고 |

실행·시험·배포 기록은 [작업 이력](../work-history/LATEST.md), 정리 전 문서는 [기획 원문 보존](../design-history/content-design/2026-10-27-before-planning-only/README.md)에 둔다. 법규 자료는 기존 문서의 당시 검토이며 이번 편집으로 새 법률 검증을 수행한 것이 아니다.
