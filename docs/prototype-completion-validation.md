## 구현

- 승객 운송 결과: 약정/실지급액, 요구/최종 매너, 감점 이유, 요청 응답, 성공/시간 초과/고갈을 운송 ID로 한 번 기록. 하루 정산에 함께 저장.
- 법규 카드: 일일 사건 수와 규칙별 준수/위반/보류/기회 없음 구분. 관찰 조건·진입/방해 사실·보조 사용·빈차/탑승 표시. 유효 기회가 없으면 점수로 오인하지 않도록 표시.
- 거점: 기존 공유 경로의 주유소·식당·주차장 안내, 정차 후 비용 확인·확정/취소. 취소 시 돈/시간 보존, 중복 확인 무효. 준비/결산의 보험·세금도 확인을 거침.
- 연습: 준비 화면에서 별도 우회전 연습, 결산의 사건에서 같은 조건 복습. 실제 별도 Player를 사용해 부모의 시간·경제·법규·매너를 보존하며, 종료 결과를 원래 사건 ID에 연결. 평가 기회 없는 연습을 100점으로 표시하지 않음.
- 화면: 준비·정산·히스토리 연결, 별도 승객 결과 탭, 작은 창에서 모달 바깥 시험 안내 숨김. 기본 주행의 상세 안내를 F10으로 켜고 끔. 미니맵의 자홍색 거점 표시.
- 준비 위치: 새 영업 준비는 임시 주차장 정차 지점에서 시작. 실제 주차장 진입로를 현장 검증했다는 의미가 아님.
