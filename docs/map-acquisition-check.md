# 영통과 은계 지도 자료 확인 및 시험 구역

확인일: 2026년 10월 14일

**2026-10-15 추가:** 사용자가 은계 안양022·023(37612022·37612023), 2025년 1:5,000 SHP ZIP·XML·XLSX 원본을 제공했다. 두 도엽의 PRJ와 XML에서 EPSG:5186을 확인하고 2.1×1.75km 은계 지도를 생성했다. 아래 미확보·검색 결과는 당시 기록이며, 최신 취득·변환 상태는 [은계 실제 원본 검토](eungye-source-review.md)를 따른다. 영통 인접 도엽은 아직 추가 확보가 필요하다.

영통역–반달공원을 기본 제작 지역으로 정한다. 첫 지형 시험은 반달공원 남쪽 교차로 2개와 추가 1개로 제한한다. 시흥 은계지구는 사용자가 아는 도로를 검증할 수 있는 별도 비교 후보로 추가한다.

## 1. 실제 자료 조회 결과

[국토정보플랫폼 국토정보맵](https://map.ngii.go.kr/ms/map/NlipMap.do?tabGb=total)에서 지명 검색 → 검색 결과 선택 → 수치지도 → DXF 및 V2.0 목록을 확인했다. 아래 연도는 화면의 ‘제작’ 값이며 촬영·조사 연도와 구분한다.

| 검색 지역 | 1:1,000 도엽 | 제작 연도 | 확인된 목록 |
|---|---|---|---|
| 반달공원 주변 | 수원2296 / 377092296 | 2008 | DXF, V2.0(SHP·NGI 분류) |
| 반달공원 주변 | 수원2297 / 377092297 | 2008 | DXF, V2.0(SHP·NGI 분류) |
| 반달공원 주변 | 용인0206 / 377130206 | 2014 | DXF, V2.0(SHP·NGI 분류) |
| 반달공원 주변 | 용인0207 / 377130207 | 2008 | DXF, V2.0(SHP·NGI 분류) |

목록의 좌표체계 표시는 GRS80이다. 이것만으로 투영법·EPSG 코드·수직 기준을 확정하지 않는다. 검색 결과는 주변 도엽 목록이며 모든 도엽이 시험 구역에 필요하다는 뜻은 아니다. 수원2296을 번호로 직접 검색해 반달공원 일대 도엽 경계도 확인했다. 남쪽 시험 도로 전체를 포함하는 인접 도엽 조합은 원본 경계와 대조해 확정한다.

반달공원 주변에는 2025년 제작 1:5,000 수원094(37709094), 용인004(37713004)도 표시됐다. 오래된 1:1,000의 세부 형상을 그대로 현재 도로로 간주하지 않고 최신 자료와 비교한다.

은계호수공원(시흥시 은행동 601-150)을 선택한 검색 범위에서는 V2.0에 2025년 제작 1:5,000 안양023(37612023) 1건이 표시됐다. DXF에는 같은 도엽과 1:25,000 소사(376121, 2024), 1:250,000 서울(NJ52-7, 2011)이 표시됐으며 **이 검색 범위에서는 1:1,000이 확인되지 않았다.** 은계지구 전체나 시흥시 보유 자료의 부재를 의미하지 않는다.

## 2. 확보 상태와 남은 절차

수원2296 V2.0을 선택해 다운로드를 실행했다. 최초에는 로그인으로 이동했고, 이후 로그인된 상태에서 다시 실행해 실제 다운로드 신청서까지 확인했다. 신청서에는 생년월일, 사용목적 및 사용자 준수사항 동의가 필요하다. 준수사항에는 측량성과의 국외 반출 관련 안내도 표시된다.

**현재 상태는 사용자가 제공한 NGI·NDA·XML 원본 확보 및 기본 구조 검토 완료다.** 31개 레이어·1,942개 도형을 읽고 속성 ID 대응을 확인했다. 기존 남쪽 시험 구역은 도엽 경계에서 잘려 추가 도엽이 필요하며, 확보 도엽 내부 T1–T2–T3를 대안으로 제안한다. 최신 결과는 [원본 검토 보고서](ngii-sample-review.md)를 따른다.

다운로드 후에는 압축 파일과 동반 메타데이터를 보관하고 도엽별 형식·레이어·좌표 정의·제작/조사 시점·이용조건·해시를 기록한다. SHP·NGI는 화면의 제품 분류이며 두 형식 모두 실제 패키지에 들어 있다는 확인은 아직 아니다. [공식 수치지도 V2.0 취득 안내](https://www.data.go.kr/data/15059719/fileData.do)

## 3. 영통 첫 시험 구역의 기존안

영통역 전체부터 만들지 않고 **반달공원 남단–으뜸공원 북측–청명로/매영로 접점**을 작은 시험 범위로 선정한다. 국토정보맵의 도로 배치와 지명을 기준으로 한 위치 선정이며 차로·신호·회전 허용은 제작 전에 별도로 확인한다.

| 순서 | 선정 위치 | 제작 목적 |
|---|---|---|
| A 필수 | 반달공원삼거리: 공원 남단의 공식 검색 지점 | 분기와 곡선 도로 연결, 회전 시 차량 궤적 |
| B 필수 | 공원 남서 모서리의 교차 지점: 지도상 스타트라인 건물 인근, 영일중학교 동측 도로와 공원 남쪽 둘레 도로가 만나는 곳 | 다른 접근 각도의 교차로, 건물·보도·차도 접합 |
| C 추가 | 으뜸공원 동쪽, 매영로와 청명로가 만나는 지점 | 비교적 넓은 도로의 합류·회전, 다음 구역으로 연결 |

B와 C는 위치 설명이며 공식 교차로 이름을 붙인 것이 아니다. 공원 안 산책로는 차량 도로에서 제외한다. 덕영대로 본선과 영통역 일대는 이 지형 시험에서 제외하고 다음 확장 단계로 둔다.

먼저 A–B 두 교차로와 연결 도로, 교차로 양측 접근부, 도로변 건물 한 줄을 원래 상대 배치로 만든다. C는 같은 데이터 변환이 통과하면 추가한다. 첫 지형 시험에서는 거리 압축을 적용하지 않아 원본 대비 오류를 찾기 쉽게 한다. 이후 반복 직선 구간만 줄인다.

이 2~3개 교차로 시험의 통과 조건은 좌표 일치, 도엽 경계 연결, 도로 폭·높이 확인, 택시 회전과 충돌면 검증이다. 완전한 우회 루프나 캠페인 구현의 완료 조건은 아니다. 합법적인 대안 경로 검증은 핵심 8~12교차로 확장 단계에서 한다.

원본 확인 후 위 남쪽 구역은 단일 도엽으로 부족하다고 판정했다. 먼저 확보 파일 내부의 T1–T2를 시험하는 수정안은 [원본 검토 보고서](ngii-sample-review.md)에 정리했다.

## 4. 은계지구 추가 방식

은계는 **은계호수공원 서남측 은계중앙로–은계호수로 주변 상업 블록**을 비교 후보로 둔다. 위치 확인 기준점은 은계중앙로 214와 은계호수로 49다. 국토정보맵에서 이 주소와 공원 주변 도로 배치를 확인했다. 세부 2~3개 교차로는 대상 블록의 통행 방향과 사용자가 익숙한 구간을 대조한 뒤 선정한다.

익숙한 지역은 교차로 형태, 회전할 때의 시야, 건물과 도로의 거리감, 실제로 통행 가능한 길을 빠르게 평가하기 좋다. 이는 택시 수요가 높다는 주장과는 별개의 제작상 장점이다.

영통과 은계를 하나의 연속 지도에 연결하지 않는다. 영통 시험이 통과한 뒤 같은 변환 방식으로 은계의 작은 비교 장면을 만들고, 익숙한 도로의 재현 효과와 보정 부담을 비교한다. 전체 시제품 두 벌을 만드는 범위로 확대하지 않는다.

은계는 우선 확인된 2025년 1:5,000과 연속수치지형도를 검사한다. 1:1,000이 꼭 필요하면 은계중앙로의 실제 제작 블록을 영역 검색하고, 추가로 시흥시·사업시행기관의 준공 측량 자료 공개 여부와 이용 조건을 문의한다. 해당 기관이 자료를 제공한다는 보장은 아직 없다.
