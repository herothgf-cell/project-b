# 은계 영업 지도 안의 법규 상황 구역

기준일: 2026-10-20. 실행 대상: `builds/EungyeTaxi/EungyeTaxi.exe`의 기본 은계 영업.

## 운송 흐름

호출 선택 또는 길가 승차 → 승객 목적지까지 상황 구역을 경유하는 내비 → 구역의 신호·주변 차량을 보고 운전 → 목적지 하차·요금 지급이다. 맵·택시·승객 운송 상태를 유지하며, 상황 진입이나 결과 표시 때문에 장면을 바꾸거나 자동 일시정지하지 않는다. H는 같은 내비 차로 연결을 따르고 가감속은 운전자가 조작한다.

은계 기존 차로 연결에 서로 다른 7개 구역을 등록한다. 호출의 `상황 구역 경유` 표기, 지도 구역 표시, 선택된 구역의 분홍 표시, 현장 창작 표지와 접근 안내로 알 수 있다. 호출을 만들 때 승차 지점 → 해당 연결 차로 → 하차 지점의 도달 가능성을 검사하고 경유 거리로 요금·제한 시간을 산정한다. 해당 호출의 시간에는 상황 준비 35초와 경유 경로의 임시 신호 연결 1회당 대기 예산 15초도 더한다. 이 시간은 게임 조정값이며 실제 신호 주기나 법적 기준이 아니다. 경유 조건을 충족하는 구역이 없으면 기존 일반 운송을 사용한다. Tab으로 빠른 길/짧은 길을 변경해도 경유 지점을 유지한다.

| 구역 조건 | 도로 위에서 요구하는 판단 |
|---|---|
| 적색 점멸 | 정지선 앞 완전 정지 뒤 다른 교통을 확인해 직진 |
| 황색 점멸 | 주변 확인 후 진행. 강제 정지 요구 없음, 시선 확인은 판정 보류 |
| 녹색·출구 정체 | 내 차가 들어갈 공간이 생길 때까지 정지선 밖 대기 |
| 녹색·출구 공간 있음 | 공간을 확인하고 진행. 정체 위반 평가 기회 없음 |
| 비보호 좌회전·적색 | 적색에서 대기 후 녹색·대향차 확인 |
| 비보호 좌회전·대향차 | 녹색에서도 대향 직진차를 양보한 뒤 좌회전 |
| 비보호 좌회전·대향차 없음 | 녹색·주변 교통 확인 후 좌회전 |

## 배치와 관찰

구역은 실제 현장 규제를 복제했다는 뜻이 아니라 은계 지형 위에 구성한 창작 운전 상황이다. NGII/OSM 원본 자료의 확인 상태를 덮어쓰지 않는다. 접근 65m 이상·출구 32m 이상·1차로에서 올바른 직진/좌회전 연결이 있는 서로 다른 교차로를 고른다. 신호/정체/대향차 연출은 해당 구역을 경유하는 운송 중에 활성화한다.

일반 차량은 계속 운행한다. 교차로에 차량이 있는 동안은 상황 차량과 신호 운용의 배치를 미루고, 안전하게 활성화하지 못한 채 연결 차로를 통과하면 **관찰 보류**로 남긴다. 그 통과를 법규 준수로 자동 채점하지 않는다. 정체·대향 상황은 플레이어가 판단 위치에 도착하기 전에 사라지지 않으며 근처의 일반 차량도 점유 판단에 반영한다.

정지선 진입 당시 신호·출구 점유·정지 여부, 좌회전 충돌 구역의 대향차 유무를 관찰한다. 이후 녹색/빈 공간으로 바뀌어도 이전 위반 기록을 지우지 않는다. 물리 틱에서 연속 이동한 연결 차로 통과만 경유 완료로 인정하고, 도착지로 위치를 옮겨 구역을 건너뛰면 하차를 허용하지 않는다.

## 결과와 캠페인

상황을 통과하면 짧은 결과 알림을 표시한다. 정차 시 `운행 법규 결과`에서 잘한 점·보완 위치·다음 운전 행동을 확인한다. 상세 창도 영업 시간을 멈추지 않는다. 완료 사건은 실제 운송 ID·승객 탑승 여부와 함께 F8 법규 기록에 보존한다. 별도의 승객 매너·요금·연료·하루 시간을 계속 사용하며, 법규 감점을 운임에 중복 반영하지 않는다.

기존 별도 연습 선택은 동일 조건을 재시도하는 보조 수단으로 유지한다. [앞선 격리 연습 검사](eungye-confusion-practice-validation.md)와 일반 영업 통합 검사는 구분한다.

연결 번호는 현재 생성 그래프 기준이며 다음 지도 생성에서 바뀔 수 있다. 구역 정의는 접근 길이·교차로 중복·호출 도달 가능성으로 다시 선택한다. 같은 교차로를 먼저 다른 방향으로 지날 때에는 상황 신호를 고정하지 않는다. 지정 접근 차로와 내비의 실제 경유 방문이 가까워졌을 때만 활성화한다.

- `tools/test_prototype.ps1`: 9종 모델 회귀 통과.
- `artifacts/service-law-zones-test.txt`: 일반 영업 7조건과 추가 적색 점멸 위반/관찰 보류, 총 9회 위치 제어 운송. 호출·승차·경유·하차·정상 요금, 독립 법규 기록·운송 ID, 중복 지급 방지. 72km/h 연속 통과/텔레포트 불인정과 반복 도로 구간 투영 검사 포함.
- `artifacts/service-practice-regression.log`, `artifacts/practice-feedback-test.txt`: 기존 우회전 연습 설명·결과·기록 보존·동일 조건 재시도 회귀.
- 빌드 중 `ASSISTED_NETWORK_TEST_OK`, `HYBRID_NETWORK_TEST_OK`, `HD_NETWORK_TEST_OK`, `DISTRICT_TRAFFIC_TEST_OK`, `EUNGYE_SUPPLEMENT_OK`: 생성 차로의 짧은 역방향 꺾임 제거, 원본 HD 형상 보존, 전체 132개 정류장 쌍 연결, OSM 통행규제 7간선·횡단보도 39개 유지.

물리 주행 검사에서는 NPC와 겹치지 않는 시작 공간 및 바퀴의 도로 접지를 먼저 확인한다. 임시 차로 굴곡의 오프셋으로 생긴 2m 안팎 역방향 꺾임은 생성 경로에서만 제거했다. 원본 HD 끝점·차로·NGII/OSM 원자료는 보존한다.



### 최종 일반 교통 물리 검사

`artifacts/service-law-physical-test.txt`, `artifacts/live-traffic-validation.txt`: 일반 차량 24대가 움직이는 상태에서 녹색 출구 정체 구역을 포함한 **1,104m** 호출을 승차부터 목적지까지 실제 WheelCollider 가감속·H 조향으로 완주했다. 약 **350.2초**, 최대 경로 오차 **1.10m**, NPC 이동 지속, 충돌·신호·급제동·독립 법규 감점 0, 하차와 캠페인 계좌 요금 지급을 확인했다. 시작 지점만 빈 공간에 배치했으며 운송 경로를 위치 이동으로 건너뛰지 않았다. 한 경로의 자동 물리 주행 검사이고 사람이 직접 플레이한 검사나 은계 모든 구역/3일 전체 캠페인 밸런스 검사는 아니다.

`artifacts/driving-judgment-test.txt`에서는 황색 진입을 매너 쪽에서 적색으로 잘못 표시하던 오류를 보완하고, 독립 법규의 황색 시점 판정 보류와 일치하는지 확인했다. 황색을 자동 준수로 채점하지 않는다. 기존 적색 감점·녹색·보행자 필요 제동과 불필요한 급제동 검사도 통과했다. `artifacts/green-flow-smoke.txt`의 녹색 연속 통과/출구 차단 회귀도 통과했다.
